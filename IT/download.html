Usar la librería download de JS para descargar recursos

Categoría Tecnología de programación

La etiqueta `<a>` de HTML5 puede usar el atributo `download` para configurar la descarga de recursos, pero debe ser del mismo origen; si el navegador puede analizarlo, también lo abrirá directamente.

En este caso, podemos usar la librería de terceros `download` para implementar una función de descarga más completa.

Recursos relacionados con download.js:

  • Dirección de GitHub:https://github.com/rndme/download
  • Librería CDN:https://lf26-cdn-tos.bytecdntp.com/cdn/expire-1-M/downloadjs/1.4.8/download.min.js
  • Instalación con NPM:npm install downloadjs

La librería download.js proporciona la función `download()` para descargar archivos.

El contenido de la descarga puede ser una URL, una cadena, un Blob o un array de datos tipado, o un dataURL que representa los datos del archivo como una cadena codificada en base64 o URL.

Independientemente del formato de entrada, `download()` guarda el archivo con el nombre de archivo y la información MIME especificados, de la misma manera que un servidor que usa la cabecera HTTP Content-Disposition.

download(data, strFileName, strMimeType);
  • data - El contenido de los datos a descargar, puede ser un Blob, File, String o dataURL.
  • strFileName - El nombre del archivo a crear.
  • strMimeType - El tipo de contenido MIME del archivo a descargar.

Ejemplo

Texto

Almacena la cadena en el archivo dlText.txt y descárgalo:

download("hello world", "dlText.txt", "text/plain");

Ejemplo de texto dataURL:

download("data:text/plain,hello%20world", "dlDataUrlText.txt", "text/plain");

Ejemplo de texto blob:

download(new Blob(["hello world"]), "dlTextBlob.txt", "text/plain");

Ejemplo de URL:

download("/robots.txt");

Ejemplo de array de texto UInt8:

var str= "hello world",    arr= new Uint8Array(str.length);
str.split("").forEach(function(a,b){
  arr[b]=a.charCodeAt();
});

download( arr, "textUInt8Array.txt", "text/plain" );

HTML

Ejemplo de cadena HTML:
download(document.documentElement.outerHTML, "dlHTML.html", "text/html");

Ejemplo de Blob HTML:

download(new Blob(["hello world".bold()]), "dlHtmlBlob.html", "text/html");

Ejemplo de devolución de llamada ajax:

$.ajax({
        url: "/download.html",
        success: download.bind(true, "text/html", "dlAjaxCallback.html")
});

Archivo binario

URL de la imagen:

download("/diff6.png");

Descargar imagen de forma asíncrona:

var x=new XMLHttpRequest();
x.open( "GET", "/diff6.png" , true);
x.responseType="blob";
x.onload= function(e){download(e.target.response, "awesomesauce.png", "image/png");};
x.send();
