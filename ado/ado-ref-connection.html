Objeto Connection

El objeto ADO Connection se utiliza para crear una conexión abierta a un origen de datos. A través de esta conexión, puede acceder a una base de datos y operar en ella.

Si necesita acceder a una base de datos varias veces, debe usar el objeto Connection para establecer una conexión. También puede crear una conexión pasando una cadena de conexión a través de un objeto Command o Recordset. Sin embargo, este tipo de conexión solo es adecuado para una consulta específica y simple.

ProgID

set objConnection=Server.CreateObject("ADODB.connection")

Propiedades

Propiedad Descripción
Attributes Establece o devuelve los atributos de un objeto Connection.
CommandTimeout Indica el tiempo que se esperará durante la ejecución de un comando antes de terminar el intento y generar un error.
ConnectionString Establece o devuelve la información detallada utilizada para establecer la conexión con un origen de datos.
ConnectionTimeout Indica el tiempo de espera al establecer una conexión antes de terminar el intento y generar un error.
CursorLocation Establece o devuelve la ubicación del servicio de cursor.
DefaultDatabase Indica la base de datos predeterminada del objeto Connection.
IsolationLevel Indica el nivel de aislamiento del objeto Connection.
Mode Establece o devuelve los permisos de acceso del proveedor.
Provider Establece o devuelve el nombre del proveedor del objeto Connection.
State Devuelve un valor que describe si la conexión está abierta o cerrada.
Version Devuelve el número de versión de ADO.

Métodos

Método Descripción
BeginTrans Inicia una nueva transacción.
Cancel Cancela una ejecución.
Close Cierra una conexión.
CommitTrans Guarda los cambios y finaliza la transacción actual.
Execute Ejecuta una consulta, una instrucción SQL, un procedimiento almacenado o texto específico del proveedor.
Open Abre una conexión.
OpenSchema Devuelve información de esquema sobre el origen de datos desde el proveedor.
RollbackTrans Cancela cualquier cambio realizado en la transacción actual y finaliza la transacción.

Eventos

Nota:No puede usar VBScript ni JScript para manejar eventos (solo puede manejar eventos con Visual Basic, Visual C++ y Visual J++).

Eventos Evento
BeginTransComplete Se desencadena después de una operación BeginTrans.
CommitTransComplete Se desencadena después de una operación CommitTrans.
ConnectComplete Se desencadena después de que se inicia una conexión.
Disconnect Se desencadena después de que finaliza una conexión.
ExecuteComplete Se desencadena después de que se ejecuta un comando.
InfoMessage Se desencadena si se produce una advertencia durante una operación ConnectionEvent.
RollbackTransComplete Se desencadena después de una operación RollbackTrans.
WillConnect Se desencadena antes de que se inicie una conexión.
WillExecute Se desencadena antes de que se ejecute un comando.
