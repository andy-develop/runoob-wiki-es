Fundamentos de los Grandes Modelos de Lenguaje (LLM)

El Gran Modelo de Lenguaje (Large Language Model, abreviado LLM) es el cerebro de los agentes de IA; comprenderlo es la base para construir agentes inteligentes.

La razón por la que un Gran Modelo de Lenguaje puede conversar contigo, escribir artículos y programar es, en esencia, que, basándose en el texto (prompt) que le proporcionas, palabra por palabra猜genera la continuación más razonable.

En términos simples, un Gran Modelo de Lenguaje es un modelo de aprendizaje profundo entrenado con enormes volúmenes de datos de texto, capaz de comprender y generar lenguaje humano. Al analizar grandes cantidades de texto en Internet, aprende las reglas estadísticas del lenguaje y, cuando recibe una entrada, genera la continuación más razonable según las reglas aprendidas.

Podemos imaginar un Gran Modelo de Lenguaje como unestudiante extremadamente aplicado y con una memoria excepcional：

  • Fase de aprendizaje (entrenamiento): ha leído casi todos los textos públicos de Internet (libros, artículos, páginas web, código, etc.), con un volumen de datos que puede alcanzar billones de palabras. En este proceso, no memoriza, sino que aprende un conjunto de reglas lingüísticas extremadamente complejas.

  • Fase de aplicación (inferencia): cuando le haces una pregunta o le das una instrucción, aplica las reglas aprendidas y genera, palabra por palabra, la respuesta más lógica y contextualmente adecuada.

Su carácter "grande" se refleja principalmente en dos aspectos:

  • Gran escala de parámetros: el modelo contiene decenas de miles de millones o incluso billones de parámetros ajustables, que almacenan el conocimiento lingüístico aprendido.
  • Grandes volúmenes de datos de entrenamiento: la cantidad de datos de texto utilizados para el entrenamiento es enorme e incluye lo mejor de la información pública de Internet.

Aunque los LLM son muy potentes, también tienen limitaciones claras:

Capacidad Descripción Limitación
Corte de conocimiento Los datos de entrenamiento tienen una fecha de corte No puede conocer información posterior al entrenamiento
Cálculo matemático Puede hacer cálculos simples Los cálculos complejos son propensos a errores
Información en tiempo real Requiere la asistencia de herramientas externas Por sí mismo no puede obtener datos en tiempo real
Precisión factual Puede generar información incorrecta Requiere verificación de hechos
Procesamiento de textos largos La longitud del contexto es limitada Los textos extremadamente largos pierden información
Consistencia lógica Puede ser contradictorio Requiere diseño y verificación cuidadosos

Aviso importante:Los LLM no son omniscientes ni omnipotentes; son esencialmente sistemas de coincidencia de patrones basados en estadísticas. Comprender sus limitaciones permite aprovechar mejor sus capacidades.

Principio de funcionamiento central: breve análisis de la arquitectura Transformer

La asombrosa capacidad de los LLM depende de su tecnología central subyacente:la arquitectura TransformerNo es necesario profundizar en los complejos principios matemáticos, pero se puede entender su idea central.

Imagina que quieres escribir un artículo sobre el sistema solar:

  • Leer todos los materiales: primero consultarías muchos libros y páginas web relacionados.
  • Captar lo esencial: notarías que palabras como sol, planetas, órbita y gravedad aparecen con frecuencia y están interrelacionadas.
  • Organizar el lenguaje: según el punto que quieras transmitir (por ejemplo, presentar Marte), utilizarías selectivamente la información vista antes sobre el tamaño, el color y la posición de Marte, y la organizarías en oraciones fluidas.

El funcionamiento de Transformer es similar a esto; su proceso central se divide en tres etapas:

  1. Procesamiento de entrada: tus palabras se dividen en tokens (palabras o caracteres) y se convierten en números (vectores) que la computadora puede entender.
  2. Comprensión del contexto (núcleo)：El mecanismo de autoatención (Self-Attention)comienza a trabajar. Permite que el modelo, al procesar cada palabra, pondere la importancia detodas las demás palabrasen la oración. Este proceso esparaleloy extremadamente rápido.
  3. Generación y repetición: basándose en la comprensión de todas las palabras, el modelo calcula una distribución de probabilidad y predice la siguiente palabra más probable. Tras seleccionar y generar esa palabra, la toma como nueva entrada y repite todo el proceso hasta generar una respuesta completa.

El mecanismo de autoatención es la innovación más clave de Transformer. Tomando como ejemplo la frase «El teléfono de Apple, la batería de él es muy grande», cuando el modelo procesa它esta palabra, el mecanismo de autoatención ayuda al modelo a determinar que它与«Apple»和y «teléfono»son altamente relevantes. Cómo interactuar con LLM: Introducción a la ingeniería de prompts

Prompt (instrucción)Es la entrada que le das al LLM; le indica al modelo lo que quieres, como dar instrucciones a un asistente: cuanto más claras sean las instrucciones, mejores serán los resultados. La calidad del prompt determina directamente la calidad de la respuesta.

Un buen prompt generalmente consta de las siguientes cuatro partes:

Principios básicos

  • Ser claro y específico: evita las expresiones vagas. No digas«escribe algo sobre perros», sino que deberías decir«escribe, con un lenguaje vivo y animado, una breve introducción de unas 100 palabras sobre las características de personalidad del golden retriever, dirigida a niños de 6 a 8 años»。

  • Proporcionar contexto: indícale al modelo tu identidad, antecedentes y objetivo. Por ejemplo:«Eres un tutor experimentado de programación en Python. Explica a un principiante que acaba de terminar la sintaxis básica qué es la comprensión de listas y proporciona un ejemplo sencillo.»

  • Especificar el formato: si necesitas una salida con un formato específico, indícalo con claridad, por ejemplo:«resume los siguientes puntos en tres viñetas» 或 «genera la salida en formato JSON»。

  • Pensamiento paso a paso (Chain-of-Thought): para problemas complejos, puedes guiar al modelo a razonar paso a paso en el prompt, por ejemplo:«analiza este problema paso a paso: primero enumera las condiciones conocidas, luego deriva los pasos intermedios y finalmente da una conclusión.»Este método puede mejorar significativamente la precisión en tareas de razonamiento complejo.

Llamadas a la API y configuración de parámetros

Para construir un Agente de IA, necesitas aprender a invocar el LLM a través de la API.

En esta sección, tomamos la API de OpenAI como ejemplo para presentar los métodos básicos de llamada.

openai es una potente biblioteca de Python para interactuar con los modelos y servicios de OpenAI. Para más detalles, consulta:Python OpenAI。

Dirección de código abierto:https://github.com/openai/openai-python

Llamadas básicas a la API

1. Instalar las bibliotecas necesarias

pip install openai

Luego, debes registrarte en el sitio web oficial de OpenAI y generar una API Key en la página de claves API.

Ejemplo

import os
from openai import OpenAI

client = OpenAI(
    # This is the default and can be omitted
    api_key="Tu API key solicitada",
)

response = client.responses.create(
    model="gpt-4o",
    instructions="You are a coding assistant that talks like a pirate.",
    input="How do I check if a Python object is an instance of a class?",
)

print(response.output_text)

Actualmente, en nuestro país, acceder a OpenAI sigue siendo un poco complicado; muchos proveedores nacionales también admiten OpenAI, como DeepSeek y Qwen de Alibaba.

DeepSeek

La API de DeepSeek es totalmente compatible con el formato de API de OpenAI. Solo necesitas modificar una pequeña configuración para usar directamente el SDK de OpenAI o herramientas compatibles para acceder a la API de DeepSeek.

Parámetros de configuración principales:

Parámetro Valor/Descripción
base_url Obligatorio, valor fijo:https://api.deepseek.com(También se puede completarhttps://api.deepseek.com/v1, solo por compatibilidad con OpenAI; v1 no está relacionado con la versión del modelo)
api_key Obligatorio; primero debes solicitar una API Key exclusiva en el sitio web oficial de DeepSeek (dirección de solicitud:https://platform.deepseek.com/）
model Obligatorio,
  • deepseek-v4-flash: corresponde al modo de DeepSeekno pensante, con velocidad de respuesta rápida, adecuado para preguntas y respuestas habituales;
  • deepseek-v4-pro: corresponde al modo de DeepSeekpensante, con mayor capacidad de razonamiento, adecuado para resolver problemas complejos.

Ejemplo

import os
from openai import OpenAI

# Inicializar el cliente (configuración principal: reemplaza con tu API Key)
client = OpenAI(
    api_key=os.environ.get('DEEPSEEK_API_KEY'),  # Se recomienda configurar mediante variables de entorno; también se puede escribir directamente (no recomendado)
    base_url="https://api.deepseek.com"  # Dominio fijo de DeepSeek
)

# Llamar a la API de conversación
try:
    response = client.chat.completions.create(
        model="deepseek-v4-flash",  # Especificar el modelo; opciones: deepseek-v4-flash / deepseek-v4-pro
        messages=[
            {"role": "system", "content": "You are a helpful assistant"},  # Definición del rol del sistema
            {"role": "user", "content": "Hello"},  # Pregunta del usuario
        ],
        stream=False  # Salida no transmitida (devuelve el resultado completo de una sola vez)
    )
    # Imprimir el contenido de la respuesta
    print("Resultado de la respuesta:", response.choices[0].message.content)
except Exception as e:
    print("Error en la llamada:", str(e))

from openai import OpenAI

Ejemplo de llamada streaming

Ejemplo

from openai import OpenAI

def get_response():
    client = OpenAI(
        api_key="sk-xxx",
        base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
    )

    completion = client.chat.completions.create(
        model="qwen-plus",
        messages=[
            {'role': 'system', 'content': 'You are a helpful assistant.'},
            {'role': 'user', 'content': '¿Quién eres?'}
        ],
        stream=True,
        stream_options={"include_usage": True}
    )

    for chunk in completion:
        # el chunk puede no tener choices o delta
        if hasattr(chunk, "choices") and len(chunk.choices) > 0:
            choice = chunk.choices[0]
            if hasattr(choice, "delta") and hasattr(choice.delta, "content"):
                print(choice.delta.content, end='', flush=True)

if __name__ == '__main__':
    get_response()
