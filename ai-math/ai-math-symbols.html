Símbolos matemáticos comunes

La primera barrera para entender artículos y tutoriales de IA no suele ser la matemática en sí, sino las páginas llenas de símbolos matemáticos.

Este capítulo organiza en tablas los símbolos más usados en el aprendizaje de IA; puedes echarles un vistazo por encima o consultarlos más adelante cuando los necesites:

  • Lectura en orden: cada símbolo incluye una explicación de cuándo se usa; repásalos rápidamente para tener una impresión general.

  • Consulta según necesites: cuando te quedes atascado en algún símbolo al leer un artículo o tutorial, vuelve a consultar la tabla.

La mayoría de los símbolos incluyen ejemplos de Python ejecutables; calcularlos manualmente una vez es más eficaz que verlos diez veces.

Debes dominar cuatro reglas de cálculo; se usan repetidamente al derivar funciones de pérdida:

La fórmula de cambio de base puede convertir cualquier logaritmo en logaritmo natural; es muy usada en programación:

Ejemplo

# Calcular log_2(100) con la fórmula de cambio de base
# math.log(x, base) de Python hace exactamente esto internamente
import math

x = 100
base = 2

# Llamada directa
print(math.log(x, base))

# Fórmula de cambio de base escrita a mano: log_2(100) = ln(100) / ln(2)
print(math.log(x) / math.log(base))

Ejecutar el código anterior produce el siguiente resultado:

6.643856189774725
6.643856189774725

¿Por qué añadir una pequeña constante ε?: el argumento de un logaritmo debe ser mayor que 0, pero en las primeras etapas del entrenamiento el modelo puede generar una probabilidad de 0; en ese caso,se obtiene menos infinito, lo que provoca que el entrenamiento falle.

Por eso en la implementación normalmente se escribe como, dondees un número positivo muy pequeño, por ejemplo 0.0000001.

En el aprendizaje automático,(se lee y-hat) se refiere específicamente al valor predicho por el modelo,se refiere a la etiqueta real; la diferencia entre ambos es el error de predicción.

La composición de funciones es la clave para entender las redes neuronales: una red de dos capas es, en esencia,la retropropagación calcula los gradientes capa por capa precisamente gracias a la regla de la cadena para derivar funciones compuestas.

Ejemplo

# Cálculo de composición de funciones: y = f(g(x))
# Sean g(x) = x + 1, f(x) = x^2

def g(x):
    return x + 1          # Función interna

def f(x):
    return x ** 2         # Función externa

# Composición: primero calcular g(x), luego sustituir el resultado en f
print(f(g(3)))            # g(3)=4, f(4)=16
print(f(g(3)) == (3 + 1) ** 2)

Ejecutar el código anterior produce el siguiente resultado:

16

Sumatorias y productorias

Es el símbolo que más aparece en las fórmulas de IA, sin igual.

Su significado es: hacer que el subíndice i vaya desde el límite inferior hasta el superior, sumando cada término.

Se lee "i de 1 a n, sumando x sub i". Para leer una sumatoria, se siguen tres pasos:

PasoQué observarEn este ejemplo
1Cuál es la variable de suma (subíndice)i
2Rango de la suma (de límite inferior a superior)1 a n
3Cómo es cada término

Ejemplo

# Entender el símbolo de sumatoria con código: z = sum(w_i * x_i) + b
w = [0.5, -1.0, 2.0]   # Pesos, corresponden a w_i en la fórmula
x = [2.0,  3.0, 1.0]   # Entradas, corresponden a x_i en la fórmula
b = 0.1                # Sesgo (bias)

# sum_{i=1}^{3} w_i * x_i es la siguiente línea

print(z)

# Verificación expandida: 0.5*2 + (-1.0)*3 + 2.0*1 + 0.1
print(0.5*2 + (-1.0)*3 + 2.0*1 + 0.1)

Producto punto (producto interno)

El producto punto es el esqueleto del mecanismo de atención: cada capa del transformer calcula el producto punto entre el vector de consulta y el vector de clave, midiendo su "grado de similitud".

Ejemplo

# Comparación de símbolos entre producto punto y norma L2
# x · y = sum(x_i * y_i)，||x||_2 = sqrt(sum(x_i^2))
import math

x = [1.0, 2.0, 3.0]
y = [4.0, 0.0, -1.0]

# Producto punto x · y
dot = sum(xi * yi for xi, yi in zip(x, y))
print(dot)

# Norma L2 ||x||_2
norm2 = math.sqrt(sum(xi ** 2 for xi in x))
print(norm2)

# Verificación expandida
print(1.0*4.0 + 2.0*0.0 + 3.0*(-1.0))
print(math.sqrt(1 + 4 + 9))

Cálculo

La esencia del entrenamiento es "ajustar los parámetros en la dirección opuesta al gradiente", por lo que las secciones de optimización en los artículos no pueden prescindir de estos símbolos.

No necesitas saber calcular ahora mismo, con reconocer cada símbolo es suficiente.

Gradiente: vector formado por todas las derivadas parciales

La fórmula más importante del aprendizaje profundo solo utiliza dos filas de la tabla anterior: la regla de actualización de parámetros del descenso de gradiente:

Desglose símbolo por símbolo:es el parámetro,indica "actualiza el lado izquierdo con el valor del lado derecho",es la tasa de aprendizaje,es el gradiente de la función de pérdida J con respecto al parámetro θ.

En una frase:Nuevo parámetro = parámetro anterior − tasa de aprendizaje × gradiente, es decir, dar un pequeño paso en la dirección que hace descender la pérdida más rápidamente.

Se lee "nabla" o "operador gradiente"; no es un número, sino una instrucción de operación que "calcula la derivada parcial con respecto a todas las variables posteriores", muy parecido a una función de orden superior en programación.

Consejos de estudio

No necesitas memorizar la tabla de símbolos de memoria; el método es más efectivo que la memorización.

Primero, adquiere el hábito de desglosar símbolo por símbolo: al ver una fórmula, pregúntate primero si cada símbolo es un operador, una variable o una función, y luego qué representa en el contexto actual. Al desglosarla, a menudo deja de ser misteriosa.

Segundo, domina primero tres cosas:Sumatorias, exponenciales y logaritmos, y notación de subíndices. Son el requisito previo para leer fórmulas de álgebra lineal y cálculo; este artículo tiene secciones dedicadas a cada una.

Tercero, cuando encuentres un símbolo que no conozcas, busca directamente "nombre del símbolo + significado matemático"; es más rápido que pelearse con el libro de texto.

Los símbolos son el mapa, no el terreno. La comprensión real proviene de usarlos para calcular ejemplos concretos; cada ejemplo de Python en este artículo vale la pena ejecutarlo personalmente.
