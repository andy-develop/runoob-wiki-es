Fundamentos de álgebra

Este capítulo presenta la transformación de ecuaciones e inecuaciones, los conceptos centrales de funciones, las operaciones con exponentes y logaritmos, y el símbolo de sumatorio Σ con la convergencia de series.

El contenido de este capítulo es la base matemática común de sigmoid, softmax, la entropía cruzada y la entropía de la información. Cada punto de conocimiento incluye una demostración gráfica interactiva; arrastrar el control deslizante genera más intuición que ver la fórmula diez veces.

Resolución y transformación de ecuaciones e inecuaciones

La transformación algebraica depende de una sola frase.

Si se realiza la misma operación en ambos lados de una igualdad, la igualdad se mantiene.

Mientras sumes, restes, multipliques, dividas (con divisor distinto de cero) o hagas raíces (prestando atención al signo) en ambos lados de la ecuación de manera "imparcial", las soluciones de la ecuación no cambiarán.

Ecuación lineal de una variable

La forma más básica es。

解 los pasos completos son:

3x + 5 = 20
3x = 20 - 5        ← 两边同减 5（移项）
3x = 15
x = 15 / 3         ← 两边同除以 3
x = 5

Solo hay dos acciones clave:Transponer términos(en esencia, restar en ambos lados) ydividir ambos lados。

Ecuaciones fraccionarias: la comprobación final es obligatoria

Primero se combinan fracciones o se eliminan denominadores, y se resuelve transformándola en una ecuación ordinaria.

Al final, es obligatorio sustituir la solución en la ecuación original para verificar que ningún denominador sea 0.

Las soluciones que hacen que un denominador sea 0 deben descartarse; se denominanraíces extrañas。

Inecuaciones: la regla donde más se suele fallar

Las reglas de transformación de las inecuaciones son similares a las de las ecuaciones, pero hay una diferencia clave.

Al multiplicar (o dividir) ambos lados de una inecuación por un número negativo, el sentido de la desigualdad debe invertirse.

解 ：

-2x > -6       ← 两边同减 6
x < 3          ← 两边同除以 -2（负数，不等号从 > 变成 <）

Esta regla es muy importante en el aprendizaje automático: al deducir la dirección de convergencia de un algoritmo de optimización o las condiciones de descenso de la función de pérdida, si se maneja mal el signo, la conclusión queda completamente invertida.

Sistema de inecuacionesEl conjunto solución de un sistema de inecuaciones es laintersección：

x > 1
x < 5
→ 解集为 1 < x < 5

Ejemplos

# Resolver una ecuación cuadrática usando el discriminante y la fórmula general
import math

def solve_quadratic(a, b, c):
    """Resolver ax^2 + bx + c = 0, devolver todas las raíces reales"""
    delta = b * b - 4 * a * c   # El discriminante Δ = b² - 4ac
    if delta > 0:               # Δ > 0: dos raíces reales distintas
        r = math.sqrt(delta)
        return [(-b + r) / (2 * a), (-b - r) / (2 * a)]
    elif delta == 0:            # Δ = 0: una raíz doble
        return [-b / (2 * a)]
    else:                       # Δ < 0: no hay raíces reales
        return []

# Verifica x² - 2x - 3 = 0; el resultado calculado a mano anteriormente es x = 3 o x = -1
print(solve_quadratic(1, -2, -3))

# Caso Δ = 0: x² - 4x + 4 = 0, es decir, (x-2)² = 0
print(solve_quadratic(1, -4, 4))

# Caso Δ < 0: x² + x + 1 = 0
print(solve_quadratic(1, 1, 1))

Al ejecutar el código anterior, la salida es:

[3.0, -1.0]
[2.0]

Concepto de función: dominio, rango, función compuesta

Funcióndescribe una regla de correspondencia de "entrada a salida":Para cada entrada x, existe una y solo una salida y correspondiente。

Se escribe, se lee "y es función de x".

Dominio: el conjunto de todas las "entradas válidas"

Determinar el dominio consiste, en esencia, en excluir los valores que hacen que la expresión "no tenga sentido":

Característica de la expresiónRestricciónEjemplo
Denominadorno puede ser 0
Raíz de índice parEl radicando no puede ser negativo
LogaritmoEl argumento debe ser mayor que 0

La regla del logaritmo es especialmente importante en IA: siempre que se use log (por ejemplo, en la pérdida de entropía cruzada), hay que asegurarse de que la entrada sea positiva. Por eso muchas implementaciones en código escriben—añaden una constante muy pequeña ε para evitarerrores o la generación de infinito.

Rango: el conjunto de todas las "salidas posibles"

El rango es, porque el cuadrado siempre es no negativo.

La función sigmoidetiene como rango el intervalo abierto, nunca es igual a 0 o 1, solo se acerca infinitamente.

Esta es la razón matemática por la que se usa para representar "probabilidades": en teoría, una probabilidad puede acercarse infinitamente a 0% o 100%, pero no igualarlos.

Función compuesta: una función dentro de otra

Tomar la salida de una función como entrada de otra se escribe。

El orden de cálculo esprimero se calcula la g(x) interna y luego se sustituye el resultado en la f externa。

设 ，, al calcular：

f(g(x)) = f(x+1) = (x+1)²

normalmente no es igual a, el orden no se puede cambiar arbitrariamente.

Por qué la función compuesta es importante para la IA: una red neuronal es, en esencia, la composición de muchas capas de funciones.

Una red de dos capas puede escribirse como, dondees la primera capa (transformación lineal + función de activación),es la segunda capa.

El algoritmo de retropropagación puede calcular gradientes "capa por capa" gracias precisamente a laregla de la cadena(se desarrollará en detalle en el curso posterior de cálculo).

Ejemplos

# Cálculo de una función compuesta y verificación de que "el orden no es conmutativo"
def f(x):
    return x ** 2          # Función externa f(x) = x²

def g(x):
    return x + 1           # Función interna g(x) = x + 1

# f(g(x)): primero calcula g(3) = 4, luego sustituye en f y se obtiene 16
print(f(g(3)))

# g(f(x)): primero calcula f(3) = 9, luego sustituye en g y se obtiene 10
# No son iguales, lo que demuestra que el orden de composición no se puede intercambiar
print(g(f(3)))

Al ejecutar el código anterior, la salida es:

16
10

Sucesiones y series: entender Σ y la convergencia

Una sucesión es una secuencia de números ordenados, denotada como, abreviada como。

Los dos tipos más básicos de sucesiones:

TipoCaracterísticaEjemploFórmula del término general
Progresión aritméticaLa diferencia entre dos términos consecutivos es constante (diferencia común d)2, 5, 8, 11, ...（d=3）
Progresión geométricaLa razón entre dos términos consecutivos es constante (razón común r)2, 4, 8, 16, ...（r=2）

¿Qué calcula realmente el símbolo de sumatorio Σ?

Significa: deja que el subíndice i vaya de 1 a n, y cadase calcula, y luego se suman todos.

Método de tres pasos para leer la fórmula Σ: primero mirala variable de sumacuál es (el subíndice), luego mirael rango de suma(de dónde a dónde), finalmente miracómo es cada término.。

En las fórmulas de IA casi siempre se ve Σ, por ejemplo en la pérdida de error cuadrático medio, y en la suma ponderada de una neurona.。

Dos fórmulas de suma: progresión aritmética, progresión geométrica (）。

Series y convergencia

Una serie es la suma de los "infinitos términos" de una sucesión, es decir。

Si sumamos infinitos números, ¿el resultado será infinito? Este es el problema de convergencia y divergencia:

Si a medida que aumenta el número de términos, la suma acumulada se aproxima a unvalor finito determinado, la serie es convergente; si la suma crece cada vez más o no tiene tendencia fija, la serie es divergente.

El ejemplo más clásico es la serie geométrica：

当 cuando ..., converge, y su suma es; cuando... diverge.

Demostración interactiva: proceso de convergencia de la serie geométrica
Arrastra el control deslizante para cambiar la razón común r, luego haz clic en "Reproducir" y observa cómo las sumas parciales S₁, S₂, ... se aproximan (o se alejan) al límite 1/(1-r).
La línea punteada roja es el límite teórico 1/(1-r). Cuando |r| se acerca a 0.9, la convergencia se vuelve notablemente más lenta; si |r| ≥ 1 (el control deslizante de esta demostración está limitado a 0.9), la serie diverge.

Por qué la convergencia es importante para la IA

Al entrenar redes neuronales, cada paso de actualización en el descenso de gradiente puede considerarse una sucesión; si la actualización de pesos puede "converger" a un valor estable, la lógica de juicio se relaciona con la intuición de la convergencia de series.

Algunos algoritmos de optimización (como el término de momento en Adam) esencialmente realizanuna suma ponderada con decaimiento exponencial, cuya forma matemática es una serie geométrica con razón menor que 1.

En redes neuronales recurrentes (RNN), si un factor multiplicativo se multiplica repetidamente y su valor absoluto es menor que 1, se produce "desaparición del gradiente" (correspondiente a una serie que converge a 0); si es mayor que 1, se produce "explosión del gradiente" (correspondiente a una serie divergente). Este es un problema clásico del aprendizaje profundo, cuya raíz es precisamente la intuición de las progresiones geométricas.

Ejemplos

# Observa el proceso de aproximación de la suma parcial de una serie geométrica al límite: r = 0.5
# Límite teórico: 1 / (1 - 0.5) = 2

r = 0.5
limit = 1 / (1 - r)      # Valor límite teórico 2
s = 0                    # Suma parcial, acumulando desde 0

for i in range(6):       # Acumulación término a término: 1 + 0.5 + 0.25 + ...
    s += r ** i
    print(i + 1, s)      # Imprime el número de términos y la suma parcial actual

print(limit)             # Límite teórico, la suma parcial se acerca cada vez más a él

5 1.9375

Se puede ver que con cada término añadido, la distancia de la suma parcial al límite se reduce a la mitad: este es el ritmo de convergencia de una serie geométrica con razón 0.5.
