Variables aleatorias continuas y distribuciones comunes

Variable aleatoria discreta: del lanzamiento de dados a la función de masa de probabilidad

La variable aleatoria formaliza los «eventos aleatorios» como una herramienta matemática.Las variables aleatorias discretas toman un número finito o contable de valores.

Explicación de conceptos

Variable aleatoria

Variable aleatoria = variable con valor incierto; cada valor tiene una probabilidad asociada.

PMF (función de masa de probabilidad)

\[ P(X = x_k) = p_k, \quad \sum_k p_k = 1 \]

Distribución de Bernoulli

Un experimento, dos resultados: P(éxito)=p, P(fracaso)=1-p. Modelado matemático de problemas de clasificación binaria.

Distribución binomial

\[ P(X=k) = \binom{n}{k} p^k (1-p)^{n-k} \]

En n experimentos independientes de Bernoulli, probabilidad de que haya k éxitos.

Ejemplos de la vida real

Lanzar un dado: X es el valor obtenido, P(X=1)=1/6, P(X=2)=1/6, ...

Lanzar una moneda 10 veces: el número de caras X sigue una distribución binomial Binomial(10, 0.5); lo más probable es 5.

Práctica con Python

Ejemplo

import numpy as np

# PMF de lanzamiento de dados
rolls = np.random.randint(1, 7, size=10000)
for v in range(1, 7):
    print(f"valor{v}: {np.mean(rolls==v):.4f}")

# Bernoulli
print(f"\n"Bernoulli p=0.3, 1000 ensayos, tasa de éxito={np.random.binomial(1,0.3,1000).mean():.3f}")

# Distribución binomial Binomial(10, 0.3)
samples = np.random.binomial(10, 0.3, 10000)
k_best = np.bincount(samples).argmax()
print(f"Distribución binomial n=10,p=0.3: k más probable={k_best} (teórico=np=3)")

Casos de uso en IA

Etiquetas de clasificación binaria = distribución de Bernoulli

La regresión logística y los clasificadores binarios modelan la etiqueta y ∈ {0,1} como una distribución de Bernoulli: P(y=1|x) = \sigma(wx+b), P(y=0|x) = 1-\sigma(wx+b). La pérdida de entropía cruzada binaria es la log-verosimilitud negativa bajo este supuesto. Por eso la capa de salida de las tareas de clasificación binaria usa Sigmoid + BCE.

Clasificación múltiple = distribución categórica (una prueba de la distribución multinomial)

En la clasificación múltiple, las etiquetas son vectores one-hot; las probabilidades de cada clase que produce Softmax suman 1. Esto equivale a un experimento con un «dado» de n caras, cada una con una probabilidad diferente. La pérdida de entropía cruzada, bajo este supuesto, es igual a la log-verosimilitud negativa.

Regularización por Dropout = experimento de Bernoulli

Durante el entrenamiento, cada neurona se conserva con probabilidad p (experimento de Bernoulli) y se descarta con probabilidad 1-p. Esto equivale a entrenar una subred diferente en cada iteración, lo que produce un efecto de aprendizaje conjunto. En la prueba, todas las neuronas están activas, pero la salida se multiplica por p como compensación de escala.

Exploración en aprendizaje por refuerzo = muestreo de una distribución discreta

En DQN se usa a menudo la estrategia ε-greedy: con probabilidad ε se elige una acción al azar (Bernoulli) y con probabilidad 1-ε se elige la acción óptima. Es la estrategia de exploración más simple y garantiza que el agente no quede atrapado para siempre en una política subóptima.
