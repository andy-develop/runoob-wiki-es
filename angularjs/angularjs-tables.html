AngularJS Tabla

La directiva ng-repeat puede mostrar tablas de manera perfecta.

Mostrar datos en una tabla

Es muy sencillo mostrar tablas con Angular:

Ejemplo de AngularJS

<!DOCTYPE html> <html> <head> <meta charset="utf-8"> <script src="https://cdn.bootcss.com/angular.js/1.6.3/angular.min.js"></script> </head> <body> <div ng-app="myApp" ng-controller="customersCtrl"> <table> <tr ng-repeat="x in names"> <td>{{ x.Name }}</td> <td>{{ x.Country }}</td> </tr> </table> </div> <script> var app = angular.module('myApp', []); app.controller('customersCtrl', function($scope, $http) { $http.get("/try/angularjs/data/Customers_JSON.php") .then(function (result) { $scope.names = result.data.records; }); }); </script>

Declaración obsoleta (v1.5)

En v1.5$http 的 success 和 errorEl método está obsoleto. Usathenel método en su lugar.

Si usas una versión anterior a la v1.5, puedes usar el siguiente código:

var app = angular.module('myApp', []);
app.controller('customersCtrl', function($scope, $http) {
    $http.get("/try/angularjs/data/Customers_JSON.php")
    .success(function (response) {$scope.names = response.records;});
});

Usar estilos CSS

Para que la página sea más vistosa, podemos usar CSS:

Estilos CSS

<style>
table, th , td {
  border: 1px solid grey;
  border-collapse: collapse;
  padding: 5px;
}
table tr:nth-child(odd) {
  background-color: #f1f1f1;
}
table tr:nth-child(even) {
  background-color: #ffffff;
}
</style>

Usar el filtro orderBy

Para la visualización ordenada, puedes usar elorderByfiltro:

Ejemplo de AngularJS

<table>
  <tr ng-repeat="x in names | orderBy : 'Country'">
    <td>{{ x.Name }}</td>
    <td>{{ x.Country }}</td>
  </tr>
</table>

Usar el filtro uppercase

Usauppercaseel filtro para convertir a mayúsculas:

Ejemplo de AngularJS

<table>
  <tr ng-repeat="x in names">
    <td>{{ x.Name }}</td>
    <td>{{ x.Country | uppercase }}</td>
  </tr>
</table>

Mostrar el índice ($index)

El índice de la tabla se puede añadir en <td>$index: 

Ejemplo de AngularJS

<table>
  <tr ng-repeat="x in names">
    <td>{{ $index + 1 }}</td>
    <td>{{ x.Name }}</td>
    <td>{{ x.Country }}</td>
  </tr>
</table>

Usar $even y $odd

Ejemplo de AngularJS

<table>
<tr ng-repeat="x in names">
<td ng-if="$odd" style="background-color:#f1f1f1">{{ x.Name }}</td>
<td ng-if="$even">{{ x.Name }}</td>
<td ng-if="$odd" style="background-color:#f1f1f1">{{ x.Country }}</td>
<td ng-if="$even">{{ x.Country }}</td>
</tr>
</table>
