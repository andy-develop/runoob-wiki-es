ASP.NET HtmlTableRowControl → Control

Control de servidor HTML

Definición y uso

El control HtmlTableRow se utiliza para controlar el elemento <tr>. En HTML, el elemento <tr> se utiliza para crear filas de tabla.

Atributos

Atributos Descripción
Align La alineación de la fila.
Attributes Devuelve todos los pares de nombres y valores de atributos del elemento.
BGColor El color de fondo de la fila.
BorderColor El color del borde.
Cells Devuelve las celdas de la fila.
Disabled Valor booleano que indica si el control está deshabilitado. El valor predeterminado es false.
Height La altura de la fila.
id El id único del control. → El id único del control.
InnerHtml Establece o devuelve el contenido entre la etiqueta de apertura y la etiqueta de cierre de este elemento HTML. Los caracteres especiales no se convierten automáticamente en entidades HTML.
InnerText Establece o devuelve todo el texto entre la etiqueta de apertura y la etiqueta de cierre de este elemento HTML. Los caracteres especiales se convierten automáticamente en entidades HTML.
runat Especifica que el control es un control de servidor. Debe establecerse como "server".
Style Establece o devuelve las propiedades CSS aplicadas a este control.
TagName Devuelve el nombre de la etiqueta del elemento.
VAlign La alineación vertical de las celdas en la fila.
Visible Valor booleano que indica si el control es visible.
