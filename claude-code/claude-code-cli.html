Modo interactivo de Claude Code

A diferencia del Claude de la versión web, Claude Code no es una simple herramienta de chat, sino unsistema de colaboración de desarrollo con contexto de ingeniería, control de permisos y capacidad de ejecución。
Por lo tanto, al manejar tareas, introduce tres modos de pensamiento centralesmodos de pensamiento：

  • Ask (Preguntar)
  • Plan (Planificar)
  • Edit (Editar)

Comprender los límites y responsabilidades de estos tres modos es la clave para usar Claude Code de manera eficiente y segura.

En la ejecución en terminal, en realidad no necesitas cambiar manualmente; Claude cambiará automáticamente. En el complemento de VS Code puedes cambiar el modo manualmente:

Explicación detallada de los tres modos interactivos principales

Al usar Claude Code en la terminal, túno necesitas cambiar manualmente el interruptor de modo; Claude determinará automáticamente en qué modo debe entrar según el contenido de tus instrucciones.

Sin embargo,como usuario, debes expresar claramente tu intención en el Prompt; de lo contrario, Claude puede fácilmente realizar comportamientos inconsistentes con tus expectativas.

1. Modo Ask: solo mirar sin tocar (análisis de solo lectura)

El modo Ask es el modo seguro predeterminado de Claude Code.

Escenarios de uso

Cuando te encuentres en las siguientes situaciones, debes priorizar el uso del modo Ask:

  • No entiendes el código existente
  • Acabas de hacerte cargo de un proyecto nuevo
  • Quieres localizar la causa de un Bug, pero aún no has pensado en cómo corregirlo
  • Quieres confirmar si cierta lógica es razonable

Características del modo

  • Claude Puede leer código
  • Puede analizar, explicar y razonar
  • Nunca modificará ningún archivo
  • No ejecutará ningún comando de Shell

Puedes entender el modo Ask como:

un ingeniero senior con mucha experiencia, pero con las manos detrás de la espalda.

Ejemplos de instrucciones

解释一下 src/auth.ts 里的 JWT 验证流程
¿En este proyecto, dónde se inicializa la conexión de la base de datos?
¿Por qué este código podría tener problemas bajo alta concurrencia?

Consejo profesional:
Cuando no estés seguro de si debes modificar el código, usa siempre primero Ask.

2. Modo Plan: planificar antes de actuar (solo planificar, no ejecutar)

El modo Plan es el modo en Claude Code que más se asemeja al pensamiento de un arquitecto.

Escenarios de uso

Cuando te enfrentas acambios complejos o de gran impactodebes usar el modo Plan, por ejemplo:

  • Agregar un módulo central nuevo
  • Refactorizar interfaces existentes o flujos de negocio
  • Introducir nuevas tecnologías (caché, middleware, soluciones de autenticación, etc.)
  • Modificaciones que involucran múltiples archivos y múltiples niveles

Características del modo

  • Claude no modificará el código directamente
  • primero proporcionaráun plan de implementación completo
  • generalmente presentado en forma de lista de pasos (Lista TODO)
  • Solo después de que confirmes el plan, se entrará en la fase Edit para ejecutarlo

El valor central del modo Plan es:

convertir "escribir código primero" en "llegar a un consenso primero".

Ejemplos de instrucciones

我想给现有的 API 增加一个 Redis 缓存层，请先给我一个实施方案
计划一下如何把这个项目的样式从 CSS 改为 Tailwind CSS
Si se quiere dividir este módulo, ¿cuáles serían los pasos razonables?

Consejo práctico:
Cuanto más uses el modo Plan, menor será la probabilidad de retrabajo.

3. Modo Edit: ejecutar directamente (puede escribir código)

El modo Edit es la fase en la que Claude Code realmente se pone manos a la obra.

Escenarios de uso

Cuando ya sabes claramente:

  • qué se va a modificar
  • en qué se va a convertir
  • el riesgo del cambio es controlable

en este momento puedes entrar directamente en el modo Edit.

Características del modo

  • Claude localizará los archivos relevantes
  • generará un Diff preciso (modificaciones de diferencias)
  • puede solicitar ejecutar comandos como pruebas, compilación, etc.
  • Todas las operaciones de escritura requieren tu confirmación

En el modo Edit, tu rol es:

el revisor final del código, no un espectador.

Ejemplos de instrucciones

把登录接口的响应码从 200 改为 201
修复 main.py 第 45 行的类型错误
Sin cambiar el comportamiento actual, refactorizar la legibilidad de esta función.

Hábito profesional:
Cuanto más específica sea la descripción, más seguro será el cambio de Claude.

Comandos de barra diagonal esenciales (/）

Los comandos de barra diagonal se utilizan paracontrolar el estado y el comportamiento de la sesión de Claude Code, no para escribir código de negocio.

Escribe en la terminal/para activarlos.

Comando Uso Consejo de experto
/help Ver todos los comandos Imprescindible para el primer uso
/cost Ver el consumo de la sesión actual Evitar gastar Tokens sin darte cuenta
/compact Comprimir el contexto Úsalo cuando la conversación se vuelva larga y lenta
/reset Restablecer la sesión Muy importante al cambiar de tarea
/docs Indexar documentos Hacer que Claude consulte documentos específicos
/review Revisión de código Revisar los cambios en el área de preparación de Git

Consejo:
/cost y /compact son comandos de uso frecuente para usuarios de largo plazo.

Un ejemplo de flujo interactivo típico

En el desarrollo real, los tres modos a menudo seutilizan de forma consecutiva。

Flujo de ejemplo

1、Ask

为什么我的注册接口一直返回 400 错误？

Claude analiza el código y los registros, señalando que falta la validación de email.

2、Plan

Quiero agregar validación de formato de email y normalizar los mensajes de error, ¿cómo planeas hacerlo?

Claude proporciona los pasos: modificar la lógica de validación → actualizar las pruebas → ajustar la estructura de retorno.

3、Edit

Ejecuta según el plan.

Claude modifica los archivos y muestra el Diff para que lo confirmes.

Ask es para entender el problema, Plan es para evitar desvíos, Edit es para ejecutar con cuidado.

Mecanismo de confirmación de permisos en la interacción

Claude Code es muy cauteloso con las operaciones del sistema; cualquier comportamiento riesgoso solicitará tu confirmación.

Confirmaciones de permisos comunes

  • Escritura de archivos
    Se mostrará el Diff del código; necesitas confirmarlo antes de que se pueda escribir.

  • Ejecutar comandos
    por ejemplonpm test、pnpm build, siempre preguntará explícitamente si se permite.

Recordatorio importante:
Nunca confirmes directamente sin haber revisado el Diff.
Claude es muy potente, pero aún puede cometer errores o alucinaciones.
