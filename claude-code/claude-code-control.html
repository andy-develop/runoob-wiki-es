Claude Code Control y Modos

Las capacidades principales del modo interactivo de Claude Code incluyen:Atajos de teclado、Modo de edición Vim、Gestión del historial de comandos和Ejecución de comandos Bash en segundo planoA continuación se presentan los puntos clave resumidos:

1. Atajos de teclado

Los efectos de los atajos varían según el terminal y el sistema. Los usuarios de macOS deben configurar la tecla Option como Meta (consulte el texto original para las rutas de configuración en diferentes terminales). Presione?para ver los atajos disponibles en el entorno actual.

Categoría Atajo/Acción Función principal
Control general Ctrl+C Cancelar entrada/generación actual
Ctrl+D Salir de la sesión
Ctrl+L Limpiar pantalla (conservar historial)
Ctrl+O Alternar salida detallada (mostrar registros de ejecución de herramientas)
Ctrl+R Búsqueda inversa en el historial de comandos
Option+P/Alt+P Cambiar modelo (sin borrar el prompt)
Edición de texto Ctrl+K/Ctrl+U Eliminar hasta el final de la línea / eliminar línea completa (el contenido eliminado se puede pegar)
Ctrl+Y PegarCtrl+K/Ctrl+UContenido eliminado
Alt+B/Alt+F Mover el cursor por palabras hacia adelante/atrás (requiere configuración de la tecla Meta)
Visualización del tema Ctrl+T Alternar resaltado de sintaxis en bloques de código (solo válido dentro del/thememenú)
Entrada multilínea \+Enter / Shift+Enter` Entrada con salto de línea (Shift+Enter sin configuración en terminales como iTerm2/WezTerm)
Ctrl+J Salto de línea multilínea
Comandos rápidos /Inicio Activar comandos de barra diagonal (consulte la documentación de comandos de barra diagonal)
!Inicio Ejecutar directamente comandos Bash (la salida se incluye en la sesión)
@ Activar autocompletado de rutas de archivo

2. Modo editor Vim

Mediante/vimhabilitar temporalmente, o/configconfigurar permanentemente, con soporte de la lógica de operación central de Vim.

1. Cambio de modo

Comando Acción Escenario de activación
Esc Entrar al modo NORMAL En modo INSERT
i/I Insertar antes del cursor/inicio de línea En modo NORMAL
a/A Insertar después del cursor/fin de línea En modo NORMAL
o/O Abrir nueva línea debajo/encima En modo NORMAL

2. Operaciones principales (modo NORMAL)

  • Navegación：h/j/k/lmover arriba/abajo/izquierda/derecha;w/e/bsaltar por palabras;gg/Gsaltar al inicio/fin de la entrada
  • Edición：ddeliminar línea;yycopiar línea;p/Ppegar después/antes del cursor;>>/<<indentar/eliminar indentación
  • Objetos de texto: combinar cond/c/yusar, comodi"eliminar contenido dentro de comillas dobles,awseleccionar palabra completa

3. Historial de comandos

  1. Reglas de almacenamiento: se almacena de forma independiente por directorio de trabajo,/clearel comando puede borrar el historial de la sesión actual
  2. Búsqueda inversa (Ctrl+R)
    • Después de presionar, ingrese palabras clave para buscar coincidencias en el historial de comandos y resaltarlas
    • RepetirCtrl+RCiclar para ver coincidencias más antiguas
    • Tab/EscAceptar la coincidencia y editar,Enterejecutar directamente,Ctrl+Ccancelar la búsqueda

4. Comandos Bash en segundo plano

Admite la ejecución asíncrona de comandos que consumen tiempo, sin bloquear las operaciones de la sesión.

  1. Método de ejecución
    • Indicar a Claude que ejecute comandos en segundo plano
    • Al ejecutar el comando, presioneCtrl+B(los usuarios de Tmux presionan dos veces), se genera un ID de tarea único para seguimiento
  2. Modo Bash (prefijo !)
    • Ingrese! comandopuede ejecutar directamente comandos Bash (sin intervención de Claude), ejemplo:! npm test
    • El comando y su salida se incluyen en el contexto de la sesión, admiteCtrl+Bejecución en segundo plano, adecuado para operaciones rápidas de shell
  3. Escenarios aplicables: herramientas de compilación, gestión de paquetes, ejecución de pruebas, servidores de desarrollo y otros procesos de larga duración
