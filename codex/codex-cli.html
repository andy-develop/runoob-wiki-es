Herramienta de línea de comandos Codex

Codex CLI es la herramienta oficial de línea de comandos, escrita en Rust, ligera y eficiente, ideal para entusiastas de la terminal.

Instalar CLI

Codex CLI es compatible con macOS, Linux y Windows (experimental).

Instalación con npm

Instalación global con npm

# Instalar con npm
npm install -g @openai/codex

# Verificar la instalación
codex --version

Instalación con Homebrew

Instalación con Homebrew

# En macOS usar Homebrew
brew install codex

Actualizar CLI

Actualizar versión

# Actualizar con npm
npm install -g @openai/codex@latest

# Actualizar con Homebrew
brew upgrade codex

Primer uso

La primera vez que ejecutes Codex te guiará a través de la autenticación:

Iniciar Codex

# Iniciar la interfaz interactiva
codex

# O especificar una tarea inicial
codex "Explica la estructura de este proyecto"

Codex abrirá el navegador para la autenticación:

  1. Inicia sesión con tu cuenta de ChatGPT
  2. O usa tu clave de API de OpenAI
  3. Después de autorizar, vuelve a la terminal para continuar

TUI interactivo

El CLI entra por defecto en el modo de interfaz de usuario de terminal (TUI), ofreciendo una experiencia inmersiva.

Áreas de la interfaz TUI

ÁreaFunción
Área de mensajesMuestra el historial de conversación, las llamadas a herramientas y los resultados de ejecución
Área de entradaCuadro de entrada inferior, enviar prompt
Barra de estadoMuestra el modelo, el uso de contexto y la información del hilo

Configuración del modo TUI

Configuración de TUI

# ~/.codex/config.toml

[tui]
# Modo de pantalla alternativa
alternate_screen = "auto"  # auto | always | never

# Conservar el historial de desplazamiento al deshabilitar la pantalla alternativa
# alternate_screen = "never"

El modo de pantalla alternativa hace que Codex use una pantalla independiente y restaure el estado original de la terminal al salir.

Modo de aprobación

El modo de aprobación controla el comportamiento de confirmación antes de que Codex ejecute acciones.

Cuatro modos

ModoDescripciónComportamiento
suggestModo sugerenciaCodex ofrece sugerencias pero no ejecuta
auto-editEdición automáticaEjecuta automáticamente la edición de archivos, los comandos requieren confirmación
full-autoTotalmente automáticoEjecuta automáticamente todas las acciones (usar con precaución)
interactiveModo interactivoPregunta antes de operaciones sensibles (predeterminado)

Configurar el modo de aprobación

# Especificar el modo en la línea de comandos
codex --approval-mode full-auto

# O cambiar en la sesión
/approval full-auto

En el modo full-auto, Codex ejecutará automáticamente todas las acciones, incluida la eliminación de archivos. Úsalo con precaución.

Modo sandbox

El modo sandbox restringe el alcance de acceso de Codex a archivos y comandos.

ModoModificación de archivosEjecución de comandosAcceso a red
read-onlyProhibidoProhibidoProhibido
workspace-writeSolo espacio de trabajoPermitidoProhibido
danger-full-accessPermitidoPermitidoPermitido

Configurar el modo sandbox

# Modo de solo lectura
codex --sandbox read-only

# Modo de escritura en el espacio de trabajo (recomendado)
codex --sandbox workspace-write

# Modo de acceso completo (peligroso)
codex --sandbox danger-full-access

Ejecución de comandos Shell

Ejecuta comandos Shell directamente en el CLI:

Ejecutar comandos

# Ejecutar comandos que comienzan con !
! ls -la

# Ejecutar comandos git
! git status

# Ver procesos
! ps aux

Confirmación de comandos

Los comandos peligrosos requieren confirmación:

  • Eliminar archivos (rm)
  • Terminar procesos (kill)
  • Modificar la configuración del sistema

Entrada de imágenes

El CLI admite adjuntar imágenes como contexto:

Adjuntar imágenes

# Adjuntar captura de pantalla
codex -i screenshot.png

# Adjuntar diseño
codex --image design.png "Implementa la página según este diseño"

# Varias imágenes
codex -i img1.png -i img2.png

Usos de las imágenes

  • Analizar mensajes de error con capturas de pantalla
  • Convertir diseños de UI en código
  • Interpretación de datos de gráficos

Modo no interactivo (exec)

Usa el comando exec para ejecutar tareas únicas, ideal para scripts y CI/CD:

Comando exec

# Ejecutar una tarea única
codex exec "Revisa el código y genera un informe"

# Salida a archivo
codex exec "Genera un README" -o README.md

# Usar un modelo específico
codex exec -m gpt-5.4-mini "Analiza la estructura del proyecto"

# Modo totalmente automático
codex exec --full-auto "Ejecuta las pruebas y corrige los fallos"

Parámetros comunes de exec

ParámetroDescripción
-mEspecificar modelo
-oSalida a archivo
--full-autoEjecución totalmente automática
--ephemeralNo guardar archivos de sesión
--jsonFormato de salida JSON

Preguntas frecuentes

P: ¿Soporte para Windows?

El soporte nativo de Windows es experimental; se recomienda usar WSL2 para obtener la mejor experiencia.

P: ¿Cómo deshabilitar la pantalla alternativa?

Usacodex --no-alt-screeno configuraalternate_screen = "never"。

P: ¿Comando no encontrado?

Asegúrate de que PATH incluya el directorio de instalación global de npm, o instala usando Homebrew.

P: ¿Cómo ver los registros detallados?

Los registros se encuentran en~/.codex/log/el directorio.
