Preguntas frecuentes

Instalación y autenticación

P: ¿Cómo instalar Codex CLI?

Usando npm o Homebrew:

npm install -g @openai/codex
# 或
brew install codex

P: ¿Cómo autenticarse en el primer uso?

Ejecutar el comando codex abrirá automáticamente el navegador para autenticarse, iniciando sesión con una cuenta de ChatGPT o una clave API.

P: ¿Situación del soporte en Windows?

El soporte nativo de Windows es experimental; se recomienda usar WSL2 para obtener la mejor experiencia.

Problemas de uso

P: ¿Cómo ver la configuración actual?

Usa el/statuscomando para ver la configuración y el estado de la sesión actual.

P: ¿Cómo deshabilitar la pantalla alternativa?

Usacodex --no-alt-screeno configuraalternate_screen = "never"。

P: ¿Qué hago si no se encuentra el comando?

Asegúrate de que PATH incluya el directorio de instalación global de npm, o instala usando Homebrew.

P: ¿Cómo ver los registros?

Los registros se encuentran en el~/.codex/log/directorio.

Problemas de funciones

P: ¿Diferencia entre exec y modo interactivo?

exec se ejecuta una sola vez y sale, adecuado para scripts de automatización; el modo interactivo mantiene la conversación, adecuado para el desarrollo diario.

P: ¿Cómo restaurar una sesión anterior?

Usa el/resumecomando ocodex resume --last。

P: ¿Puede GitHub Action modificar archivos?

Sí, configura sandbox: workspace-write.

P: ¿Cómo autenticarse en CI/CD?

Usa la variable de entorno CODEX_API_KEY, almacenada como Secrets.

Problemas de seguridad

P: ¿Cómo evitar que Codex elimine archivos importantes?

Usa el modo sandbox read-only o workspace-write, configura Rules para prohibir comandos peligrosos.

P: ¿Es seguro el modo full-auto?

full-auto ejecuta automáticamente todas las operaciones, incluida la eliminación de archivos, úsalo con precaución.

P: ¿Cómo manejar datos sensibles?

Usa el almacenamiento de Secrets, solo disponible en el script de configuración.

Glosario

TérminoDescripción
AgentUnidad de ejecución central de Codex, capaz de comprender tareas y ejecutar operaciones
PromptInstrucciones de tarea enviadas por el usuario a Codex
ThreadSecuencia de sesión que contiene el historial completo de la conversación
ContextEl alcance de información disponible para Codex, incluyendo archivos, conversaciones y configuración
SandboxEntorno de ejecución aislado, que limita el alcance de operación de Codex
ApprovalPolítica de aprobación, que controla el comportamiento de confirmación antes de ejecutar operaciones
AGENTS.mdArchivo de instrucciones del proyecto, que define las normas de comportamiento de Codex
SkillMódulos de capacidades personalizadas reutilizables
SubagentSubagentes, utilizados para procesar tareas complejas en paralelo
RulesMotor de reglas, que define los permisos de ejecución de comandos
MCPModel Context Protocol, protocolo para conectar herramientas externas
WorktreeÁrbol de trabajo de Git, directorio de trabajo para aislar diferentes tareas
