Configuración avanzada de Codex

Integración de Codex con Deepseek

En agosto de 2026, DeepSeek anunció oficialmente que admite la integración con Codex. deepseek-v4-flash fue el primero en lanzarse, y deepseek-v4-pro también será compatible más adelante.

Codex es un asistente de programación con IA lanzado por OpenAI que se comunica con los modelos a través de la API Responses, y la API de DeepSeek admite de forma nativa ese formato de protocolo.

Las distintas variantes de cliente de Codex (Codex CLI, la versión de escritorio de ChatGPT y el complemento Codex IDE para VS Code) comparten el mismo archivo de configuración local, por lo que solo necesitas configurarlo una vez y podrás usar los modelos de DeepSeek en todas ellas.

Requisitos previos

  • Tener instalado Codex CLI o la versión de escritorio de ChatGPT y haberlo ejecutado al menos una vez (para que se cree el directorio ~/.codex).
  • Accede a la plataforma abierta de DeepSeekhttps://platform.deepseek.com/api_keysSolicita una API Key (que comience con sk-).

Configurar DeepSeek como proveedor de modelos

DeepSeek ofrece oficialmente dos métodos de integración; se recomienda usar preferentemente el método 1.

2. Archivo de configuración de Codex ~/.codex/config.toml

En ~/.codex/config.toml, añade (o modifica) el siguiente contenido:

model = "deepseek-v4-flash"
model_provider = "deepseek"
preferred_auth_method = "apikey"
forced_login_method = "api"
model_reasoning_effort = "high"
model_catalog_json = "~/.codex/models.json"

[model_providers.deepseek]
name = "deepseek"
base_url = "https://api.deepseek.com/"
wire_api = "responses"
experimental_bearer_token = "<你的 DeepSeek API Key>"

Explicación de los campos de config.toml:

Campo Función
model Modelo utilizado por defecto
model_provider ID del proveedor de modelos utilizado, correspondiente a la[model_providers.<id>]sección de configuración que aparece a continuación
preferred_auth_method / forced_login_method Configurar para usar autenticación con API Key y omitir el proceso de inicio de sesión de la cuenta de ChatGPT
model_reasoning_effort Intensidad de razonamiento: cuanto mayor sea el valor, más profundo será el razonamiento del modelo y mayor será la calidad de las respuestas, pero también tardará más (opcionallow/high/max）
model_catalog_json Ruta personalizada del archivo de catálogo de modelos; Codex lee desde aquí los metadatos de los modelos
[model_providers.deepseek].name Nombre para mostrar del proveedor de modelos
[model_providers.deepseek].base_url Dirección del endpoint de la API de DeepSeek
[model_providers.deepseek].wire_api Protocolo de comunicación,"responses"indica que se utiliza la API Responses
[model_providers.deepseek].experimental_bearer_token Tu API Key de DeepSeek, escrita directamente en el archivo de configuración
