Selección de modelos Codex

Codex admite múltiples modelos. Conoce las características de cada modelo y elige el más adecuado según el escenario.

En la versión de escritorio, puedes cambiar desde la esquina inferior derecha del campo de entrada:

En Codex CLI puedes usar/modelel comando para cambiar:

Modelos disponibles

Codex admite actualmente los siguientes modelos:

ModeloTipoCaracterísticasEscenario de uso
gpt-5.4InsigniaCapacidad más potente, razonamiento profundoTareas complejas, diseño de arquitectura
gpt-5.4-miniLigeroRespuesta rápida, menor costoTareas simples, iteración rápida
gpt-5.3-codexProfesionalOptimizado para programación, especializado en códigoEscritura de código, corrección de errores
gpt-5.3-codex-sparkRápidoRespuesta extremadamente rápida, interacción de alta frecuenciaColaboración en tiempo real, preguntas y respuestas rápidas

Explicación detallada de las características de los modelos

GPT-5.4

Modelo insignia, con la capacidad de razonamiento y creación más potente.

CaracterísticasDescripción
Profundidad de razonamientoAnálisis profundo de problemas complejos
Comprensión del contextoComprensión de la estructura de grandes bases de código
Tareas de múltiples pasosManejo de flujos de trabajo complejos
PrecisiónAlta precisión, reduce retrabajo

Escenarios de uso

  • Diseño y refactorización de arquitectura
  • Análisis y corrección de errores complejos
  • Desarrollo coordinado de múltiples módulos
  • Revisión de código y análisis de calidad

GPT-5.4-mini

Modelo ligero, de respuesta rápida, adecuado para el desarrollo diario.

CaracterísticasDescripción
Velocidad de respuestaMás rápido que el modelo insignia
RentabilidadMenor consumo de tokens
Tareas diariasAdecuado para operaciones de desarrollo habituales

Escenarios de uso

  • Implementación de funciones simples
  • Formateo y refactorización de código
  • Redacción de documentación
  • Preguntas y respuestas rápidas

GPT-5.3-Codex

Modelo optimizado específicamente para tareas de programación.

CaracterísticasDescripción
Especialización en códigoEntrenado específicamente para tareas de programación
Cobertura de lenguajesAdmite múltiples lenguajes de programación
Calidad del códigoAlta calidad del código generado

Escenarios de uso

  • Escritura y generación de código
  • Corrección de errores y depuración
  • Refactorización de código
  • Escritura de pruebas

GPT-5.3-Codex-Spark

Modelo de respuesta extremadamente rápida, adecuado para escenarios de interacción de alta frecuencia.

CaracterísticasDescripción

Colaboración en tiempo realAdecuado para desarrollo interactivo
Exclusivo de ProDisponible solo en el plan Pro

Escenarios de uso

  • Preguntas y respuestas de código en tiempo real
  • Validación rápida de prototipos
  • Desarrollo de iteración de alta frecuencia

Configuración de la intensidad de razonamiento

Puedes ajustar la intensidad de razonamiento del modelo para equilibrar velocidad y profundidad.

Niveles de intensidad de razonamiento

NivelDescripciónCaracterísticas
minimalRazonamiento mínimoRespuesta más rápida, adecuado para tareas simples
lowIntensidad de razonamiento bajaRápido pero con cierto análisis
mediumRazonamiento medioEquilibra velocidad y profundidad (predeterminado)
highIntensidad de razonamiento altaAnálisis profundo, adecuado para tareas complejas
xhighRazonamiento ultra altoRazonamiento más potente, respuesta más lenta

Configurar la intensidad de razonamiento

Ajustes de intensidad de razonamiento

# Especificar en CLI
codex --reasoning-effort high

# Archivo de configuración
[mycode4 type="toml"]
model_reasoning_effort = "high"
# Cambiar durante la sesión /model gpt-5.4 --reasoning-effort xhigh [/mycode4]

Resumen de razonamiento

Controla el nivel de detalle con el que Codex muestra el proceso de razonamiento.

Modo de resumen

ModoDescripción
autoDecide automáticamente el nivel de detalle (predeterminado)
conciseResumen breve
detailedProceso de razonamiento detallado
noneNo mostrar resumen de razonamiento

Configuración del resumen de razonamiento

# ~/.codex/config.toml
model_reasoning_summary = "detailed"

Cambio de modelo

Cambia entre diferentes modelos según el escenario.

Métodos de cambio

Cambiar modelo

# Comando de barra en CLI
/model gpt-5.4
/model gpt-5.4-mini
/model gpt-5.3-codex

# Con intensidad de razonamiento
/model gpt-5.4 --reasoning-effort high

# Cambio en la aplicación
Haz clic en el selector de modelos y elige el modelo deseado

Recomendaciones de cambio según escenario

EscenarioModelo recomendadoIntensidad de razonamiento
Diseño de arquitecturagpt-5.4high/xhigh
Refactorización complejagpt-5.4high
Corrección de erroresgpt-5.3-codexmedium
Codificación diariagpt-5.4-minilow/medium
Preguntas y respuestas rápidasgpt-5.4-miniminimal
Colaboración en tiempo realgpt-5.3-codex-sparkminimal

Nivel de servicio

Elegir diferentes niveles de servicio afecta la prioridad de respuesta.

Opciones de nivel de servicio

NivelDescripción
flexServicio elástico, la respuesta puede ser algo más lenta (predeterminado)
fastServicio prioritario, respuesta más rápida

Configuración del nivel de servicio

# ~/.codex/config.toml
service_tier = "fast"

Modelos y planes

Los diferentes planes tienen distinto soporte de modelos:

PlanModelos disponibles
FreeModelo básico
Plusgpt-5.4, gpt-5.4-mini, gpt-5.3-codex
ProTodos los modelos + Spark + límites más altos
API KeyFacturación por token, admite modelos principales

Consideraciones de costos

Comparación de consumo de tokens

ModeloCosto relativo
gpt-5.4Más alto
gpt-5.3-codexMedio alto
gpt-5.4-miniBajo
gpt-5.3-codex-spark低

Recomendaciones para optimizar costos

  • Para tareas simples usa el modelo mini o Spark
  • Para desarrollo diario usa intensidad de razonamiento medium
  • Usa el modelo insignia y alta intensidad de razonamiento solo en tareas complejas
  • Usa /compact para comprimir el contexto y reducir el consumo de tokens

Mejores prácticas

Principios de selección de modelos

  • Elige el modelo según la complejidad de la tarea
  • Equilibra la velocidad de respuesta y la profundidad de razonamiento
  • Prioriza la precisión en tareas complejas
  • Prioriza la velocidad de respuesta en interacciones de alta frecuencia

Recomendaciones de configuración

Configuración recomendada

# Configuración de desarrollo diario
model = "gpt-5.4-mini"
model_reasoning_effort = "medium"
model_reasoning_summary = "auto"

# Cambio temporal para tareas complejas
# /model gpt-5.4 --reasoning-effort high

Preguntas frecuentes

P: ¿Qué modelo es el más adecuado para escribir código?

gpt-5.3-codex está optimizado para tareas de programación y es adecuado para la mayoría de los escenarios de escritura de código.

P: ¿Cómo equilibrar velocidad y calidad?

Para tareas diarias usa gpt-5.4-mini con intensidad de razonamiento medium; para tareas complejas cambia a gpt-5.4 con intensidad de razonamiento high.

P: ¿Qué ventajas tiene el modelo Spark?

El modelo Spark es el más rápido en responder, adecuado para interacciones de alta frecuencia y colaboración en tiempo real, solo disponible en el plan Pro.

P: ¿Cómo afecta la intensidad de razonamiento a los resultados?

Una mayor intensidad de razonamiento significa que Codex realiza un análisis más profundo, pero el tiempo de respuesta será más largo.
