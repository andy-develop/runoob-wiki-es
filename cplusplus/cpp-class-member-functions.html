C++ Funciones miembro de clase

Clases y objetos de C++

Las funciones miembro de clase son aquellas cuya definición y prototipo se escriben dentro de la definición de la clase, al igual que otras variables de la definición de la clase. La función miembro de clase es un miembro de la clase, puede operar sobre cualquier objeto de la clase y puede acceder a todos los miembros del objeto.

Veamos la clase Box definida anteriormente; ahora usaremos funciones miembro para acceder a los miembros de la clase, en lugar de acceder directamente a esos miembros de la clase:

class Box { public: double length; // Longitud double breadth; // Ancho double height; // Altura double getVolume(void);// Devuelve el volumen };

Las funciones miembro pueden definirse dentro de la definición de la clase, o por separado utilizando eloperador de resolución de alcance ::para definirlas. Las funciones miembro definidas dentro de la definición de la clase declaran la función comoinlineaunque no se use el identificador inline. Por lo tanto, puede definir de la siguiente maneragetVolume()la función:

class Box { public: double length; // Longitud double breadth; // Ancho double height; // Altura double getVolume(void) { return length * breadth * height; } };

También puede usar fuera de la clase eloperador de resolución de alcance ::para definir la función, como se muestra a continuación:

double Box::getVolume(void) { return length * breadth * height; }

Aquí hay que enfatizar que se debe usar el nombre de la clase antes del operador ::. Llamar a una función miembro se hace usando el operador punto sobre el objeto (.), de modo que pueda operar con los datos relacionados con ese objeto, como se muestra a continuación:

Box myBox; // Crear un objeto myBox.getVolume(); // Llamar a la función miembro de ese objeto

Usemos los conceptos mencionados anteriormente para establecer y obtener los valores de diferentes miembros de la clase:

Ejemplos

#include <iostream> using namespace std; class Box { public: double length; // Longitud double breadth; // Ancho double height; // Altura // Declaración de la función miembro double getVolume(void); void setLength( double len ); void setBreadth( double bre ); void setHeight( double hei ); }; // Definición de la función miembro double Box::getVolume(void) { return length * breadth * height; } void Box::setLength( double len ) { length = len; } void Box::setBreadth( double bre ) { breadth = bre; } void Box::setHeight( double hei ) { height = hei; } // Función principal del programa int main( ) { Box Box1; // Declarar Box1, de tipo Box Box Box2; // Declarar Box2, de tipo Box double volume = 0.0; // Para almacenar el volumen // Detalles de box 1 Box1.setLength(6.0); Box1.setBreadth(7.0); Box1.setHeight(5.0); // Detalles de box 2 Box2.setLength(12.0); Box2.setBreadth(13.0); Box2.setHeight(10.0); // Volumen de box 1 volume = Box1.getVolume(); cout << "Volumen de Box1:" << volume <<endl; // Volumen de box 2 volume = Box2.getVolume(); cout << "Volumen de Box2:" << volume <<endl; return 0; }

    Funciones miembro de la clase e inline

    Las funciones miembro definidas en una clase son inline por defecto. Si en la definición de la clase ya se proporciona la definición de la función, por supuesto es lo mejor. Si no se da la definición de la función miembro en la clase y se quiere que la función sea inline, entonces fuera de la clase hay que añadirinline, de lo contrario no se considera inline. Por ejemplo:

    class A
{
    public:void Foo(int x, int y) {  } // 自动地成为内联函数
}

    Aunque colocar el cuerpo de definición de la función miembro dentro de la declaración de la clase puede resultar conveniente para escribir, no es un buen estilo de programación. El ejemplo anterior debería cambiarse a:

    // 头文件
class A
{
    public:
    void Foo(int x, int y);
}
// 定义文件
inline void A::Foo(int x, int y){}

    inline es una palabra clave utilizada para la implementación

    La palabra clave inline debe colocarse junto con el cuerpo de la definición de la función para que la función sea inline; simplemente poner inline delante de la declaración de la función no tiene ningún efecto.

    Una función del siguiente estiloFoono puede convertirse en una función inline:

    inline void Foo(int x, int y); // inline 仅与函数声明放在一起
void Foo(int x, int y){}

    Mientras que la función Foo del siguiente estilo se convierte en una función inline:

    void Foo(int x, int y);
inline void Foo(int x, int y) {}  // inline 与函数定义体放在一起

    Para más usos de inline, consulte:El uso de inline en C++

    Diferencia en C++ entre llamar a una función miembro no virtual y llamar a una función virtual:

    1. Llamar a una función miembro no virtual: igual que llamar a una función no miembro, se determina la clase a la que pertenece el objeto a través del objeto y luego se encuentra la función miembro de la clase. Este proceso no involucra el contenido del objeto, solo el tipo del objeto; es un enlace estático (static binding).

    2. Llamar a una función virtual es diferente de llamar a una función miembro no virtual; es necesario encontrar la dirección de la función virtual a través de la tabla de funciones virtuales, y la tabla de funciones virtuales se almacena en cada objeto, no se puede implementar en tiempo de compilación. Solo se puede enlazar en tiempo de ejecución; es un enlace dinámico (dynamic binding).

    Código:

    #include<iostream>
using namespace std;

int year = 55;   //全局变量
int month = 56;
int day = 57;

void Set(int y, int m,int d)  //全局函数
{
    year=y;     //给全局变量赋值
    month=m;
    day=d;    
}

void PPP()  //全局函数
{
    cout << "*****global*****" << endl;
    cout << year << " " << month  << " " << day << endl;
}
class TimeDate
{
    public:
        void Set(int y,int m,int d)  //成员函数
        {
            year=y;     //给成员变量赋值
            ::month=m;  //给全局变量赋值
            day=d;
            //使用::表明是全局函数
            //不使用:: 按先成员函数后全局函数的顺序查找函数
            ::PPP();  //使用全局函数，而不是成员函数
            PPP();    //使用成员函数，而不是全局函数
        }
        void PPP()
        {
            cout << "*****local*****" << endl;
            cout << year << " " << month  << " " << day << endl;
        }
        void PPP1()
        {
            cout << "*****local->global*****" << endl;
            cout << ::year << " " << ::month  << " " << ::day << endl;
        }
    private:
        int year;  //成员变量
        int month;
        int day;
};

int main(int argc, const char** argv) {
    TimeDate t;
    cout << "origin value" << endl;
    t.PPP();
    t.PPP1();
    PPP();
    cout << "after global function Set work" << endl;
    Set(1,2,3);
    t.PPP();
    PPP();
    cout << "after member function Set work" << endl;
    t.Set(4,5,6);
    t.PPP();
    PPP();
    cout << "program end" << endl;
    return 0;
}

    Análisis y conclusión:

    1. Mismo nombre para variable global y variable miembro: las funciones globales usan por defecto la variable global; solo a través del acceso al miembro del objeto se puede obtener el valor de la variable miembro. Las funciones miembro usan preferentemente la variable miembro, pero se puede añadir :: delante del nombre de la variable miembro para indicar explícitamente que es una variable global, y entonces la función miembro usará la variable global. Además, las funciones miembro usan las variables en el orden de primero las variables miembro y luego las variables globales; en otras palabras, las funciones miembro usan preferentemente las variables miembro; solo cuando no se encuentra el nombre de la variable entre las variables miembro se buscará y usará la variable global; si tampoco existe ese nombre de variable en las variables globales, se produce un error.

    2. Mismo nombre para función global y función miembro: fuera de la clase, generalmente se llama a la función global; solo a través del acceso a la función miembro del objeto se puede usar la función miembro. Dentro de la clase, se llama a la función miembro, pero se puede añadir :: delante del nombre de la función miembro para indicar explícitamente que se necesita llamar a la función global. Además, las funciones se llaman en el orden de primero la función miembro y luego la función global; en otras palabras, se usa preferentemente la función miembro; si la función miembro no existe, se buscará y usará la función global; si tampoco existe esa función entre las funciones globales, se produce un error.
