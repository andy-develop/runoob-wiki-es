C++ Constantes

Las constantes son valores fijos que no cambian durante la ejecución del programa. Estos valores fijos también se denominanliterales。

Las constantes pueden ser de cualquier tipo de dato básico; se dividen en números enteros, números de punto flotante, caracteres, cadenas y valores booleanos.

Las constantes son como variables normales, excepto que su valor no puede modificarse después de definirse.

Constantes enteras

Las constantes enteras pueden ser decimales, octales o hexadecimales. El prefijo especifica la base: 0x o 0X para hexadecimal, 0 para octal, y sin prefijo significa decimal por defecto.

Las constantes enteras también pueden llevar un sufijo, que es una combinación de U y L. U indica entero sin signo (unsigned) y L indica entero largo (long). El sufijo puede estar en mayúsculas o minúsculas, y el orden de U y L es arbitrario.

A continuación se muestran algunos ejemplos de constantes enteras:

212 // Válido 215u // Válido 0xFeeL // Válido 078 // Inválido: 8 no es un dígito octal 032UU // Inválido: no se puede repetir el sufijo

A continuación se muestran ejemplos de constantes enteras de varios tipos:

85 // Decimal 0213 // Octal 0x4b // Hexadecimal 30 // Entero 30u // Entero sin signo 30l // Entero largo 30ul // Entero largo sin signo

Constantes de punto flotante

Una constante de punto flotante se compone de parte entera, punto decimal, parte fraccionaria y exponente. Puede representar una constante de punto flotante en forma decimal o en forma exponencial.

Al usar la forma decimal, debe incluir la parte entera, la parte fraccionaria, o ambas. Al usar la forma exponencial, debe incluir el punto decimal, el exponente, o ambos. El exponente con signo se introduce con e o E.

A continuación se muestran algunos ejemplos de constantes de punto flotante:

3.14159 // Válido 314159E-5L // Válido 510E // Inválido: exponente incompleto 210f // Inválido: no hay parte fraccionaria ni exponente .e55 // Inválido: falta la parte entera o la fraccionaria

Constantes booleanas

Hay dos constantes booleanas, ambas son palabras clave estándar de C++:

  • trueEl valor representa verdadero.
  • falseEl valor representa falso.

No debemos considerar el valor de true como 1, ni el valor de false como 0.

Constantes de carácter

Las constantes de carácter se encierran entre comillas simples. Si la constante comienza con L (solo en mayúscula), indica que es una constante de carácter ancho (por ejemplo, L'x'), y debe almacenarse enwchar_tuna variable de tipo. De lo contrario, es una constante de carácter estrecho (por ejemplo, 'x'), y puede almacenarse encharuna variable simple de tipo.

Una constante de carácter puede ser un carácter normal (por ejemplo, 'x'), una secuencia de escape (por ejemplo, '\t'), o un carácter universal (por ejemplo, '\u02C0').

En C++, ciertos caracteres tienen un significado especial cuando van precedidos por una barra invertida, y se usan para representar, por ejemplo, el salto de línea (\n) o el tabulador (\t). La siguiente tabla muestra algunos de estos códigos de secuencia de escape:

El siguiente ejemplo muestra algunos caracteres de secuencia de escape:

Ejemplo

#include <iostream> using namespace std; int main() { cout << "Hello\tWorld\n\n"; return 0; }

Hello   World

Constantes de cadena

Las cadenas literales o constantes se encierran entre comillas dobles""Un string contiene caracteres similares a las constantes de carácter: caracteres normales, secuencias de escape y caracteres universales.

Puede usar\como separador para dividir una constante de cadena muy larga en varias líneas.

El siguiente ejemplo muestra algunas constantes de cadena:

Ejemplo

#include <iostream>
#include <string>
using namespace std;

int main() {
    string greeting = "hello, runoob";
    cout << greeting;
    cout << "\n";     // Salto de línea
    string greeting2 = "hello, \
                        runoob";
    cout << greeting2;
    return 0;
}
hello, runoob
hello, runoob

Definición de constantes

En C++, hay dos formas sencillas de definir constantes:

  • Usar#defineel preprocesador.
  • Usarconstla palabra clave.

Preprocesador #define

La siguiente es la forma de definir constantes con el preprocesador #define:

#define identifier value

Vea el siguiente ejemplo:

Ejemplo

#include <iostream> using namespace std; #define LENGTH 10 #define WIDTH 5 #define NEWLINE '\n' int main() { int area; area = LENGTH * WIDTH; cout << area; cout << NEWLINE; return 0; }

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

50

La palabra clave const

Puede usarconstel prefijo para declarar constantes de un tipo específico, como se muestra a continuación:

const type variable = value;

Vea el siguiente ejemplo:

Ejemplo

#include <iostream> using namespace std; int main() { const int LENGTH = 10; const int WIDTH = 5; const char NEWLINE = '\n'; int area; area = LENGTH * WIDTH; cout << area; cout << NEWLINE; return 0; }

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

50

Tenga en cuenta que definir constantes en letras mayúsculas es una buena práctica de programación.
