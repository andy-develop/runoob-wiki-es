C++ Constantes

Las constantes son valores fijos que no cambian durante la ejecución del programa. Estos valores fijos también se denominanliterales。

Las constantes pueden ser de cualquier tipo de dato básico; se dividen en números enteros, números de punto flotante, caracteres, cadenas y valores booleanos.

Las constantes son como variables normales, excepto que su valor no puede modificarse después de definirse.

Constantes enteras

Las constantes enteras pueden ser decimales, octales o hexadecimales. El prefijo especifica la base: 0x o 0X para hexadecimal, 0 para octal, y sin prefijo significa decimal por defecto.

Las constantes enteras también pueden llevar un sufijo, que es una combinación de U y L. U indica entero sin signo (unsigned) y L indica entero largo (long). El sufijo puede estar en mayúsculas o minúsculas, y el orden de U y L es arbitrario.

A continuación se muestran algunos ejemplos de constantes enteras:

212 // Válido 215u // Válido 0xFeeL // Válido 078 // Inválido: 8 no es un dígito octal 032UU // Inválido: no se puede repetir el sufijo

A continuación se muestran ejemplos de constantes enteras de varios tipos:

85 // Decimal 0213 // Octal 0x4b // Hexadecimal 30 // Entero 30u // Entero sin signo 30l // Entero largo 30ul // Entero largo sin signo

Constantes de punto flotante

Una constante de punto flotante se compone de parte entera, punto decimal, parte fraccionaria y exponente. Puede representar una constante de punto flotante en forma decimal o en forma exponencial.

Al usar la forma decimal, debe incluir la parte entera, la parte fraccionaria, o ambas. Al usar la forma exponencial, debe incluir el punto decimal, el exponente, o ambos. El exponente con signo se introduce con e o E.

A continuación se muestran algunos ejemplos de constantes de punto flotante:

3.14159 // Válido 314159E-5L // Válido 510E // Inválido: exponente incompleto 210f // Inválido: no hay parte fraccionaria ni exponente .e55 // Inválido: falta la parte entera o la fraccionaria

Constantes booleanas

Hay dos constantes booleanas, ambas son palabras clave estándar de C++:

  • trueEl valor representa verdadero.
  • falseEl valor representa falso.

No debemos considerar el valor de true como 1, ni el valor de false como 0.

Constantes de carácter

Las constantes de carácter se encierran entre comillas simples. Si la constante comienza con L (solo en mayúscula), indica que es una constante de carácter ancho (por ejemplo, L'x'), y debe almacenarse enwchar_tuna variable de tipo. De lo contrario, es una constante de carácter estrecho (por ejemplo, 'x'), y puede almacenarse encharuna variable simple de tipo.

Una constante de carácter puede ser un carácter normal (por ejemplo, 'x'), una secuencia de escape (por ejemplo, '\t'), o un carácter universal (por ejemplo, '\u02C0').

En C++, ciertos caracteres tienen un significado especial cuando van precedidos por una barra invertida, y se usan para representar, por ejemplo, el salto de línea (\n) o el tabulador (\t). La siguiente tabla muestra algunos de estos códigos de secuencia de escape:

Definición de constantes

En C++, hay dos formas sencillas de definir constantes:

  • Usar#defineel preprocesador.
  • Usarconstla palabra clave.

Preprocesador #define

La siguiente es la forma de definir constantes con el preprocesador #define:

#define identifier value

Vea el siguiente ejemplo:

Ejemplo

#include <iostream> using namespace std; #define LENGTH 10 #define WIDTH 5 #define NEWLINE '\n' int main() { int area; area = LENGTH * WIDTH; cout << area; cout << NEWLINE; return 0; }

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

50

La palabra clave const

Puede usarconstel prefijo para declarar constantes de un tipo específico, como se muestra a continuación:

const type variable = value;

Vea el siguiente ejemplo:

Ejemplo

#include <iostream> using namespace std; int main() { const int LENGTH = 10; const int WIDTH = 5; const char NEWLINE = '\n'; int area; area = LENGTH * WIDTH; cout << area; cout << NEWLINE; return 0; }

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

50

Tenga en cuenta que definir constantes en letras mayúsculas es una buena práctica de programación.

    Diferencia entre la macro #define y la constante const

    Difieren en el tipo y la verificación de seguridad

    La macro es una sustitución de caracteres, no hace distinción de tipos de datos; además, esta sustitución no tiene verificación de seguridad de tipos y puede producir errores como efectos secundarios.

    La constante const es una declaración de constante, tiene distinción de tipos y requiere verificación de tipos en la fase de compilación.

    Difieren en el manejo por el compilador

    La macro es un concepto de 'tiempo de compilación', se expande en la fase de preprocesamiento, no se puede depurar la macro y su ciclo de vida termina en la compilación.

    La constante const es un concepto de 'tiempo de ejecución', se usa durante la ejecución del programa, similar a un dato de solo lectura.

    Difieren en la forma de almacenamiento

    La macro es una sustitución directa, no asigna memoria y se almacena en la sección de código del programa.

    La constante const requiere asignación de memoria y se almacena en la sección de datos del programa.

    Difieren en el ámbito de definición

    void f1 ()
{
    #define N 12
    const int n 12;
}
void f2 ()
{
    cout<<N <<endl; //正确，N已经定义过，不受定义域限制
    cout<<n <<endl; //错误，n定义域只在f1函数中
}

    Si se pueden cancelar después de definirse

    La macro puede invalidarse mediante #undef.

    La constante const permanece válida permanentemente dentro de su ámbito después de definirse.

    void f1()
{
  #define N 12
  const int n = 12;

  #undef N //取消宏定义后，即使在f1函数中，N也无效了
  #define N 21//取消后可以重新定义
}

    Si se pueden usar como parámetros de función

    La macro no puede pasarse como parámetro a una función.

    La constante const puede aparecer en la lista de parámetros de una función.

    La palabra clave const

    const是constantes la abreviatura de 'constante'. Siempre que una variable esté modificada con const, significa que los datos de esa variable pueden ser accedidos pero no modificados. Es decir, const significa solo lectura (readonly).

    Regla: cuanto más cerca esté const de algo, ese algo no puede modificarse;

    Cuando const modifica una variable, es obligatorio inicializarla con un valor; si no se inicializa, no se podrá inicializar más adelante.

    En esencia: lo que está después de const no puede modificarse; si const está al principio, se desplaza una posición hacia la derecha, y ambos son equivalentes.

    Función de la palabra clave const

    • Para transmitir información muy útil a quienes lean tu código, declarar un parámetro como constante sirve para indicar al usuario el propósito de aplicación de este parámetro;
    • Al proporcionar información adicional al optimizador, la palabra clave const quizás pueda generar un código más compacto;
    • El uso razonable de la palabra clave const permite que el compilador proteja de forma natural aquellos parámetros que no se desea modificar, previniendo modificaciones accidentales del código y reduciendo la aparición de errores;

    Aplicación de la palabra clave const

    • Para evitar que una variable sea modificada, se puede usar const. Al definir dicha variable const, debe inicializarse primero; después ya no habrá oportunidad de cambiarla;
    • En cuanto a los punteros, se puede especificar que el propio puntero sea const, o que los datos a los que apunta el puntero sean const, o que ambos se especifiquen como const;
    • En una declaración de función, const puede modificar un parámetro formal para indicar que es un parámetro de entrada; dentro de la función no se puede cambiar su valor;
    • Para las funciones miembro de una clase, a veces es necesario especificarlas como tipo const, lo que indica que son una función constante y no pueden modificar las variables miembro de la clase;
    • Para las funciones miembro de una clase, a veces es necesario especificar su valor de retorno como tipo const, de modo que su valor de retorno no sea un «lvalue».

    Ángulo 1En cuanto a la definición de constantes, la constante definida por const es una variable y también tiene tipo; la definida por #define es solo una constante, sin tipo.

    Ángulo 2En cuanto a la etapa en la que actúan, #define actúa en la etapa de preprocesamiento de la compilación, mientras que const actúa durante la compilación y la ejecución.

    Ángulo 3En cuanto al modo de actuación, #define es solo un reemplazo simple de cadenas, sin verificación de tipos. En cambio, const tiene un tipo de datos correspondiente, por lo que se realiza una comprobación, lo que puede evitar algunos errores básicos. Precisamente porque define es solo un reemplazo simple de cadenas, puede causar efectos de borde; para un ejemplo concreto, consulte el siguiente código:

    #define N 2+3     // 我们预想的 N 值是 5，我们这样使用 
Ndouble a = N/2;  // 我们预想的  a 的值是 2.5，可实际上 a 的值是 3.5

    Ángulo 4En cuanto a la ocupación de espacio, por ejemplo:

    #define PI 3.14     //预处理后 占用代码段空间
const float PI=3.14;    // 本质上还是一个 float，占用数据段空间

    Ángulo 5Desde el punto de vista de la facilidad de depuración del código, la constante const se puede depurar; #define no se puede depurar porque ya se reemplazó en la etapa de precompilación.

    Ángulo 6Desde el punto de vista de si se puede redefinir, la desventaja de const es inherente: const no se puede redefinir, mientras que #define puede cancelar la definición de un símbolo mediante #undef y luego volver a definirlo.

    Modificación de punteros

    Los casos de modificación de punteros son bastante numerosos; principalmente existen las siguientes situaciones:

    1. const modifica*pel objeto al que apunta es de solo lectura, y la dirección del puntero es variable:

    int a = 9;
int b = 10;
const int *p = &a;//p是一个指向int类型的const值,与int const *p等价
*p = 11;    //编译错误，指向的对象是只读的，不可通过p进行改变
p = &b;     //合法，改变了p的指向

    Aquí, para facilitar la comprensión, se puede considerar que const modifica a *p; normalmente se usa*desreferenciar el puntero para acceder al objeto; por lo tanto, el objeto es de solo lectura.

    2. const modifica a p; el objeto al que apunta es variable, pero la dirección del puntero no es variable:

    int a = 9;
int b = 10;
int * const p = &a;//p是一个const指针
*p = 11;    //合法，
p = &b;     //编译错误，p是一个const指针，只读，不可变

    3. El puntero no puede cambiar su dirección, y el contenido al que apunta tampoco puede cambiarse.

    int a = 9;
int b = 10;
const int * const p = &a;//p既是一个const指针，同时也指向了int类型的const值
*p = 11;    //编译错误，指向的对象是只读的，不可通过p进行改变
p = &b;     //编译错误，p是一个const指针，只读，不可变

    Después de ver las situaciones anteriores, ¿no te parece confuso y difícil de recordar? Lo resumimos con una frase:

    Si const se coloca en cualquier posición a la izquierda de *, se limita que el objeto al que apunta el puntero sea de solo lectura; si const se coloca a la derecha de *, se limita que el propio puntero sea de solo lectura, es decir, inmutable.

    Si aún no se entiende bien, podemos verlo así: quitando los calificadores de tipo y observando lo que const modifica. Después de quitar el calificador de tipo int en las tres situaciones anteriores, queda lo siguiente:

    const *p; //修饰*p，指针指向的对象不可变
* const p; //修饰p，指针不可变
const * const p; //第一个修饰了*p，第二个修饰了p，两者都不可变

    Aquello que const modifica a su derecha es lo que es inmutable. Lo anterior solo sirve para ayudar a comprender y memorizar. Con esta comprensión, se descubrirán las siguientes situaciones equivalentes:

    const int NUM = 10; //与int const NUM等价
int a = 9;
const int *p  = &a;//与int const *p等价
const int arr[] = {0,0,2,3,4}; //与int const arr[]等价

    Cuando la palabra clave const aparece a la izquierda de *, el contenido al que apunta el puntero no puede modificarse. Se le llama puntero que apunta a una constante; en este caso también se denomina const de bajo nivel.

    Cuando la palabra clave const aparece a la derecha de *, el puntero en sí no puede modificarse; se le llama puntero constante, y en este caso también se denomina const de nivel superior.

    Cuando la palabra clave const aparece a ambos lados de *: el contenido al que apunta el puntero y el propio puntero no pueden modificarse. En este caso posee tanto const de bajo nivel como const de nivel superior.

    Algunas notas:

    (1) El contenido al que apunta un puntero de bajo nivel no es inmodificable; simplemente no se puede modificar a través de ese puntero. En otras palabras, el puntero de bajo nivel se engaña a sí mismo creyendo que el contenido al que apunta no se puede modificar; en realidad, se puede cambiar el contenido al que apunta mediante asignaciones u otros métodos.

    (2) En uso, el const de nivel superior solo se utiliza para modificar punteros; no puede modificar referencias (porque una referencia no es una variable). En cambio, el const de bajo nivel puede modificar punteros y referencias, y su significado es que el contenido al que se apunta o se referencia es una constante. Solo hay que recordar: el const de bajo nivel limita que el objeto apuntado o referenciado sea constante, pero no limita el puntero o la referencia; el const de nivel superior limita que el puntero sea constante, pero no limita el contenido al que apunta.

    (3) El const de bajo nivel impone una restricción a la variable; al realizar una operación de copia, un objeto que no sea const de bajo nivel no puede asignarse a una variable que tenga const de bajo nivel.

    int main()
{
    int a = 1;
    const int *p1 = &a;         //底层const, 也可以用int const *p1 = &a;.
    *p1 = 2;                    //非法, 无法通过p1更改a的值.
    p1++;                       //合法, p1的值(指向的地址)是可以更改的.
    a = 2;                      //合法, 只是无法通过p1解引用的方式更改a的值, 其他方式可以.

    int *const p2 = &a;         //顶层const, p2是常量.
    *p2 = 3;                    //合法, p2指向地址的内容可以更改.
    p2++;                       //非法, p2的值(指向的地址)无法更改.
    a = 4;                      //合法, p2指向地址的内容可以更改.
    const int *const p3 = &a;   //同时具有底层和顶层const, p3的值(指向的地址)无法修改, 且无法通过p3解引用进行更改.
    int *p4 = p1;               //非法, p1是const *int(底层const), 无法给普通int*赋值.
    int *p5 = p2;               //合法, p2是*const int(顶层const), 赋值时没有限制.
    const int *p6 = p1;         //合法, p6也是const *int(底层const), 可以获得p1的赋值.
}
