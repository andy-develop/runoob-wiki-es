Ejemplo 2

#include <iostream>
using namespace std;

bool isVowel(char letter) {
    // Convertir la letra a minúsculas
    letter = tolower(letter);

    // Determinar si la letra es una vocal
    if (letter == 'a' || letter == 'e' || letter == 'i' || letter == 'o' || letter == 'u') {
        return true;
    } else {
        return false;
    }
}

int main() {
    char letter;
    cout << "Ingrese una letra: ";
    cin >> letter;

    if (isVowel(letter)) {
        cout << letter << " es una vocal." << endl;
    } else {
        cout << letter << " es una consonante." << endl;
    }

    return 0;
}

En el código anterior, definimos una función llamada isVowel, que acepta una letra como parámetro y devuelve un valor booleano. Dentro de la función, convertimos la letra a minúscula y usamos una declaración condicional para determinar si es una vocal. Si la letra es una vocal, la función devuelve true; de lo contrario, devuelve false. En la función principal, aceptamos la letra ingresada por el usuario, llamamos a la función isVowel para realizar la verificación y mostramos el resultado correspondiente.
