C++ Archivos y flujos

Hasta ahora, hemos utilizadoiostreamla biblioteca estándar, que proporcionacin 和 coutmétodos para leer flujos desde la entrada estándar y escribir flujos hacia la salida estándar, respectivamente.

Este tutorial explica cómo leer flujos desde archivos y escribir flujos hacia archivos. Para ello se necesita otra biblioteca estándar de C++fstream, que define tres nuevos tipos de datos:

Tipo de datos Descripción
ofstream Este tipo de datos representa el flujo de archivo de salida y se usa para crear archivos y escribir información en ellos.
ifstream Este tipo de datos representa el flujo de archivo de entrada y se usa para leer información de archivos.
fstream Este tipo de datos generalmente representa un flujo de archivo y tiene tanto las funciones de ofstream como de ifstream, lo que significa que puede crear archivos, escribir información en ellos y leer información de ellos.

Para realizar el procesamiento de archivos en C++, debe incluir los archivos de encabezado <iostream> y <fstream> en el archivo de código fuente de C++.

Abrir archivo

Antes de leer información de un archivo o escribir información en un archivo, primero debe abrir el archivo.ofstream 和 fstreamEl objeto se puede usar para abrir un archivo para operaciones de escritura; si solo necesita abrir el archivo para operaciones de lectura, useifstreamel objeto.

A continuación se muestra la sintaxis estándar de la función open(), que es un miembro de los objetos fstream, ifstream y ofstream.

void open(const char *filename, ios::openmode mode);

Aquí,open()el primer parámetro de la función miembro especifica el nombre y la ubicación del archivo a abrir, y el segundo parámetro define el modo en que se abre el archivo.

Banderas de modo Descripción
ios::app Modo de agregar. Toda escritura se agrega al final del archivo.
ios::ate Se posiciona al final del archivo después de abrirlo.
ios::in Abre el archivo para lectura.
ios::out Abre el archivo para escritura.
ios::trunc Si el archivo ya existe, su contenido se truncará antes de abrir el archivo, es decir, la longitud del archivo se establece en 0.

Puede combinar dos o más de los modos anteriores. Por ejemplo, si desea abrir un archivo en modo escritura y truncar el archivo en caso de que ya exista, puede usar la siguiente sintaxis:

ofstream outfile;
outfile.open("file.dat", ios::out | ios::trunc );

De manera similar, si desea abrir un archivo para lectura y escritura, puede usar la siguiente sintaxis:

ifstream  afile;
afile.open("file.dat", ios::out | ios::in );

Cerrar archivo

Cuando un programa de C++ termina, cierra y vacía automáticamente todos los flujos, libera toda la memoria asignada y cierra todos los archivos abiertos. Sin embargo, el programador debería adquirir el buen hábito de cerrar todos los archivos abiertos antes de que termine el programa.

A continuación se muestra la sintaxis estándar de la función close(), que es un miembro de los objetos fstream, ifstream y ofstream.

void close();

Escribir en archivo

En la programación en C++, usamos el operador de inserción de flujo (<<) para escribir información en un archivo, igual que usamos ese operador para enviar información a la pantalla. La única diferencia es que aquí se usa el objetoofstream 或 fstreamen lugar del objetocout.

Leer archivo

En la programación en C++, usamos el operador de extracción de flujo (>>) para leer información de un archivo, igual que usamos ese operador para ingresar información desde el teclado. La única diferencia es que aquí se usa el objetoifstream 或 fstreamen lugar del objetocin.

Ejemplo de lectura y escritura

El siguiente programa en C++ abre un archivo en modo lectura y escritura. Después de escribir la información ingresada por el usuario en el archivo afile.dat, el programa lee la información del archivo y la muestra en la pantalla:

Ejemplo

#include <fstream> #include <iostream> using namespace std; int main() { char data[100]; // abrir archivo en modo escritura ofstream outfile; outfile.open("afile.dat"); cout << "Writing to the file" << endl; cout << "Enter your name: "; cin.getline(data, 100); // escribir en el archivo los datos ingresados por el usuario outfile << data << endl; cout << "Enter your age: "; cin >> data; cin.ignore(); // escribir nuevamente en el archivo los datos ingresados por el usuario outfile << data << endl; // cerrar el archivo abierto outfile.close(); // abrir archivo en modo lectura ifstream infile; infile.open("afile.dat"); cout << "Reading from the file" << endl; infile >> data; // mostrar datos en la pantalla cout << data << endl; // volver a leer datos del archivo y mostrarlos infile >> data; cout << data << endl; // cerrar el archivo abierto infile.close(); return 0; }

Cuando el código anterior se compila y se ejecuta, produce las siguientes entradas y salidas:

$./a.out
Writing to the file
Enter your name: Zara
Enter your age: 9
Reading from the file
Zara
9

En el ejemplo anterior se utilizan funciones adicionales del objeto cin, como la función getline() para leer una línea desde el exterior, y la función ignore() para ignorar los caracteres sobrantes que dejó la instrucción de lectura anterior.

Puntero de posición en el archivo

istream 和 ostreamAmbos proporcionan funciones miembro para reposicionar el puntero de posición del archivo. Estas funciones miembro incluyen, para istream,seekg("seek get") y, para ostream,seekp（"seek put"）。

Los parámetros de seekg y seekp suelen ser de tipo entero largo. El segundo parámetro se puede usar para especificar la dirección de búsqueda. La dirección de búsqueda puede serios::beg(por defecto, posiciona desde el inicio del flujo), o puede serios::cur(posiciona desde la posición actual del flujo), o puede serios::end(posiciona desde el final del flujo).

El puntero de posición del archivo es un valor entero que especifica el número de bytes desde la posición inicial del archivo hasta la posición del puntero. A continuación se muestra un ejemplo de cómo posicionar el puntero de archivo "get":

// posicionar en el n-ésimo byte de fileObject (asumiendo ios::beg) fileObject.seekg( n ); // mover el puntero de lectura del archivo n bytes hacia adelante desde la posición actual de fileObject fileObject.seekg( n, ios::cur ); // mover el puntero de lectura del archivo n bytes hacia atrás desde el final de fileObject fileObject.seekg( n, ios::end ); // posicionar al final de fileObject fileObject.seekg( 0, ios::end );

    Ejemplo de lectura, escritura y copia

    El siguiente programa en C++ abre un archivo en modo lectura y escritura.

    file_wr() después de escribir en el archivo test.txt la información ingresada por el usuario, el programa lee la información del archivo y la muestra en la pantalla;

    file_copy() lee los datos del archivo test.txt y luego los escribe en test_1.txt.

    #include "iostream"
#include "fstream"
using namespace std;

//向文件内部写入数据，并将数据读出
void file_wr(void)
{
    char data[100];
    //向文件写入数据
    ofstream outfile;
    outfile.open("test.txt");
    cout << "Write to the file" << endl;
    cout << "Enter your name:" << endl;
    cin.getline(data, 100);
    outfile << data << endl;
    cout << "Enter your age:" << endl;
    cin >> data;
    cin.ignore();
    outfile << data << endl;
    outfile.close();
    //从文件读取数据
    ifstream infile;
    infile.open("test.txt");
    cout << "Read from the file" << endl;
    infile >> data;
    cout << data << endl;
    infile >> data;
    cout << data << endl;
    infile.close();
}


//将数据从一文件复制到另一文件中
void file_copy(void)
{
    char data[100];
    ifstream infile;
    ofstream outfile;
    infile.open("test.txt");
    outfile.open("test_1.txt");
    cout << "copy from test.txt to test_1.txt" << endl;
    while (!infile.eof())
    {
        infile >> data;
        cout << data << endl;
        outfile << data << endl;
    }
    infile.close();
    outfile.close();
}

//测试上述读写文件，与文件数据复制
int _tmain(int argc, _TCHAR* argv[])
{
    file_wr();
    file_copy();
    return 0;
}

    Con respecto a cin.ignore(), la versión completa es cin.ignore(int n, char a). Extrae caracteres del flujo de entrada (cin), y los caracteres extraídos se ignoran y no se usan. Por cada carácter descartado, cuenta y compara: si el valor del contador alcanza n o el carácter descartado es a, la ejecución de cin.ignore() termina; de lo contrario, continúa esperando. Una función común de esto es limpiar el contenido del búfer de entrada que termina con un retorno de carro, eliminando la influencia de la entrada anterior en la siguiente. Por ejemplo, se puede usar así: cin.ignore(1024,'\n'). Normalmente el primer parámetro se establece lo suficientemente grande, de modo que en la práctica solo el segundo parámetro '\n' tiene efecto. Por lo tanto, esta instrucción elimina del búfer (flujo) de entrada todos los caracteres anteriores al retorno de carro (incluido el retorno de carro).

    #include <iostream>
using namespace std;
void main()
{
    int a,b,c;
    cout<<"input a:";
    cin>>a;
    cin.ignore(1024, '\n');
    cout<<"input b:";
    cin>>b;
    cin.ignore(1024, '\n');
    cout<< "input c:";
    cin>> c;
    cout<< a << "\t" << b << "\t" << c << endl;
}

    Si cin.ignore() no recibe parámetros, el parámetro predeterminado es cin.ignore(1, EOF), donde EOF es la abreviatura de end of file y representa el final del "flujo de texto" (stream).

    #include <fstream> 
#include <string>
#include <iostream>
#include <streambuf> 

using namespace std; 

int WriteFile(string filepath,const string& Init)
{
    //定义文件输出流 
    ofstream outfile; 

    //根据参数路径创建要输出的文件 
    outfile.open(filepath, ios::out | ios::trunc);    
    if(!outfile)
        return 1;
    outfile << Init << endl;

    outfile.close(); 
    return 0;
}

string Read_Str(string filepath)
{
    ifstream infile;
    infile.open(filepath);
    //打开失败，路径不正确
    if(!infile)
        cout << "Open File Fail!" << endl;
    //读取文本内容到字符串
    string readStr((std::istreambuf_iterator<char>(infile)),  std::istreambuf_iterator<char>()); 
    
    return readStr;

    Algo que contraviene la intuición de C: en C++, es mejor dejar que los recursos se liberen automáticamente para reducir la carga mental.

    Al aprender, se enfatiza recordar close para recordarte que en lenguajes sin GC debes gestionar bien la solicitud y liberación de recursos, pero en realidad los flujos de archivos de C++ cierran automáticamente los archivos abiertos en el destructor.

    A menos que necesites verificar si el cierre fue exitoso después de cerrar, solo en ese caso necesitas mantener el objeto de flujo de archivo.

    Aquí se cita una publicación de stackoverflow:https://stackoverflow.com/questions/4802494/do-i-need-to-close-a-stdfstream

    > fstream es un objeto RAII correcto, que se cierra automáticamente al final del ámbito, y cuando cerrarlo al final del ámbito es suficiente, no es necesario en absoluto llamar a close manualmente. En particular, esto no es una "mejor práctica", ni es necesario vaciar el búfer de salida.
