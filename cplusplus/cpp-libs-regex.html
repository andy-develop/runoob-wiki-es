Biblioteca estándar de C++<regex>

En la biblioteca estándar de C++<regex>El archivo de cabecera proporciona la funcionalidad de las expresiones regulares, permitiendo a los desarrolladores utilizar una forma muy flexible de buscar, reemplazar o dividir cadenas. Las expresiones regulares son una poderosa herramienta de procesamiento de texto, ampliamente utilizadas en campos como la validación de datos, el análisis de texto y la coincidencia de patrones.

Una expresión regular es un patrón que utiliza una sola cadena para describir y hacer coincidir una serie de cadenas que cumplen ciertas reglas sintácticas. En C++, las expresiones regulares se implementan mediante la<regex>implementación de la biblioteca.

En C++11,<regex>al usar expresiones regulares, es necesario escapar la barra invertida en los literales de cadena\para realizar el escape, es decir, escribirla como doble barra invertida\\。

¿Por qué doble barra invertida?

El compilador de C++ procesa primero los caracteres de escape de los literales de cadena, mientras que el motor de expresiones regulares los procesa después.

Por ejemplo, si escribes\d+, el compilador tratará\dcomo un carácter de escape desconocido, generará un error o se convertirá end, la forma correcta es\\d+, el compilador primero\\convierte en\, y el motor de expresiones regulares luego lee\d。

C++11 también admite cadenas sin procesar (raw string), que evitan la doble barra invertida y son muy adecuadas para escribir expresiones regulares complejas:
regex re(R"(\d+)");         // 原始字符串，不需要写 \\d
  • El contenido dentro de R"(...)" no se procesará como secuencias de escape
  • Se recomienda usarla al escribir expresiones regulares complejas con múltiples \.

Sintaxis básica

Componentes básicos de las expresiones regulares

  • Clases de caracteres: como[abc]significa que coincide con cualquier carácter de a, b o c.
  • Cuantificadores: como*(cero o más veces)+(una o más veces)?(cero o una vez)
  • Coincidencia de límites: como^(inicio de línea)$(fin de línea)
  • Agrupación: usa paréntesis()para crear un grupo.

C++ <regex>Principales clases y funciones de la biblioteca

  • std::regex: representa un objeto de expresión regular.
  • std::regex_match: comprueba si toda la cadena coincide con la expresión regular.
  • std::regex_search: busca en la cadena las partes que coinciden con la expresión regular.
  • std::regex_replace: reemplaza en la cadena las partes que coinciden con la expresión regular.
  • std::sregex_iterator: iterador, utilizado para recorrer todas las coincidencias.

Ejemplo

1. Coincidencia completa: regex_match

Ejemplo

#include <iostream>
#include <regex>
using namespace std;

int main() {
    regex re("\\d+");          // coincide con dígitos
    string s = "12345";

    if (regex_match(s, re))
        cout << "coincidencia exitosa"\n";
    else
        cout << "coincidencia fallida"\n";
}

Salida:

Coincidencia exitosa

2. Comprobar si una cadena coincide con una expresión regular

Ejemplo

#include <iostream>
#include <string>
#include <regex>
using namespace std;

int main() {
    string text = "Hello, World!";
    regex pattern("^[a-zA-Z]+, [a-zA-Z]+!$");

    if (regex_match(text, pattern)) {
        cout << "The string matches the pattern." << endl;
    } else {
        cout << "The string does not match the pattern." << endl;
    }

    return 0;
}

Salida:

The string matches the pattern.

3. Buscar coincidencias en una cadena

Ejemplo

#include <iostream>
#include <string>
#include <regex>
using namespace std;

int main() {
    string text = "123-456-7890 and 987-654-3210";
    regex pattern("\\d{3}-\\d{3}-\\d{4}");

    smatch matches;
    while (regex_search(text, matches, pattern)) {
        cout << "Found: " << matches[0] << endl;
        text = matches.suffix().str();  // continuar buscando el resto
    }

    return 0;
}

Salida:

Found: 123-456-7890
Found: 987-654-3210

4. Reemplazar coincidencias en una cadena

Ejemplo

#include <iostream>
#include <string>
#include <regex>
using namespace std;

int main() {
    string text = "Hello, World!";
    regex pattern("World");
    string replacement = "Universe";

    string result = regex_replace(text, pattern, replacement);

    cout << "Original: " << text << endl;
    cout << "Modified: " << result << endl;

    return 0;
}

Salida:

Original: Hello, World!
Modified: Hello, Universe!

En las cadenas del código fuente de C++ hay que escribir\\den lugar de\d, porque\necesita ser escapado.

Ejemplos de uso típicos

Ejemplo

#include <iostream>
#include <regex>
using namespace std;

int main() {
    regex re("\\d+");
    string s = "abc123def456";

    // encontrar la primera coincidencia
    smatch m;
    if (regex_search(s, m, re))
        cout << "primera coincidencia: " << m.str() << endl;

    // recorrer todas las coincidencias
    for (sregex_iterator it(s.begin(), s.end(), re), end_it; it != end_it; ++it)
        cout << "coincidencia: " << it->str() << endl;

    // reemplazar
    string result = regex_replace(s, re, "#");
    cout << result << endl;
}
