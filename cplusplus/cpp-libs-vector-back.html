Función back de C++ <vector>

Clase de contenedor <vector> de C++

En varias operaciones de vector,backes una función muy práctica, utilizada paraobtener el último elemento。

backes una función miembro de la clase de contenedor, utilizada paradevolver el último elemento del contenedor. Equivale aat(size()-1) 或 operator[](size()-1), pero su semántica es más clara.

backProporciona una forma intuitiva de acceder al último elemento del contenedor, comúnmente utilizada en la implementación de estructuras de datos como pilas y colas.

Definición de la palabra： backsignifica 'detrás', es decir, obtener el último elemento (el que está al final).

Sintaxis básica y parámetros

backes una función miembro de la clase de contenedor; llamarla es muy directo, no requiere ningún parámetro.

Formato de sintaxis

reference back();
const_reference back() const;

Descripción de parámetros

  • Parámetros: sin parámetros
    • backNo acepta ningún parámetro.

Descripción de la función

  • Valor de retorno: devuelve unareferencia. Si el contenedor es constante, devuelve una referencia constante.
  • Efecto: Devuelve el último elemento del contenedor (el elemento en el índicesize()-1).
  • Nota: Llamar abackantes debe asegurarse de que el contenedor no esté vacío; de lo contrario, el comportamiento no está definido. Se recomienda usar primeroempty() 或 size() > 0para verificarlo.

Ejemplo

A través de una serie de ejemplos, dominemos completamentebackel uso de.

Ejemplo 1: Uso básico - obtener el último elemento

Ejemplo

#include <iostream>
#include <vector>

int main() {
    // 1. Crear un vector y agregar algunos elementos
    std::vector<int> numbers = {10, 20, 30, 40, 50};

    std::cout << "el tamaño del vector es: " << numbers.size() << std::endl;

    // 2. Usar back para obtener el último elemento
    std::cout << "el último elemento (back): " << numbers.back() << std::endl;
    std::cout << "usando at(size()-1): " << numbers.at(numbers.size() - 1) << std::endl;
    std::cout << "usando [size()-1]: " << numbers[numbers.size() - 1] << std::endl;

    return 0;
}

Resultado esperado de la ejecución:

vector的大小是: 5
最后一个元素 (back): 50
使用 at(size()-1): 50
使用 [size()-1]: 50

Análisis del código:

  1. numbers.back()Devuelve el último elemento50。
  2. Comparado connumbers.at(numbers.size()-1) 和 numbers[numbers.size()-1]devuelve el mismo valor, pero su semántica es más clara.

Ejemplo 2: Modificar el valor del último elemento

backDevuelve una referencia, por lo que se puede usar para modificar el valor del elemento.

Ejemplo

#include <iostream>
#include <vector>
#include <string>

int main() {
    std::vector<std::string> tasks = {"Aprender C++", "Hacer la tarea", "Leer documentación"};

    std::cout << "Antes de la modificación, la última tarea: " << tasks.back() << std::endl;

    // Usar back() para obtener la referencia y modificar el elemento
    tasks.back() = "Completar el proyecto";

    std::cout << "Después de la modificación, la última tarea: " << tasks.back() << std::endl;

    // Ahora el contenido de tasks es: Aprender C++, Hacer la tarea, Completar el proyecto

    return 0;
}

Resultado esperado de la ejecución:

Antes de la modificación, la última tarea: leer documentación  
Después de la modificación, la última tarea: completar el proyecto

Análisis del código:

  • tasks.back() = "完成项目";Se modificó el valor del último elemento mediante la referencia.
  • back()Devuelve una referencia lvalue modificable.

Ejemplo 3: Uso seguro de back - verificar si el contenedor está vacío

Antes de usarback, primero se debe verificar si el contenedor está vacío.

Ejemplo

#include <iostream>
#include <vector>

void printBack(const std::vector<int>& v) {
    if(!v.empty()) {
        std::cout << "El último elemento es: " << v.back() << std::endl;
    }
    else {
        std::cout << "El contenedor está vacío, no se puede obtener el último elemento" << std::endl;
    }
}

int main() {
    std::vector<int> numbers = {10, 20, 30};

    // Caso normal
    printBack(numbers);

    // Caso de contenedor vacío
    std::vector<int> emptyVec;
    printBack(emptyVec);

    return 0;
}

Resultado esperado de la ejecución:

最后一个元素是: 30
容器为空，无法获取最后一个元素

Análisis del código:

  • !v.empty()Verifica si el contenedor no está vacío.
  • Antes de llamar aback, realizar la verificación evita un comportamiento no definido.

Ejemplo 4: Usar back para implementar una pila

backSe usa comúnmente para implementar la estructura de datos de pila (junto conpush_back 和 pop_back）。

Ejemplo

#include <iostream>
#include <vector>

class Stack {
private:
    std::vector<int> data;

public:
    // Empujar a la pila (push)
    void push(int value) {
        data.push_back(value);
    }

    // Sacar de la pila (pop)
    void pop() {
        if(!data.empty()) {
            data.pop_back();
        }
    }

    // Obtener el elemento superior de la pila
    int top() {
        if(!data.empty()) {
            return data.back();
        }
        return 0; // Indica que la pila está vacía
    }

    // Determinar si la pila está vacía
    bool empty() {
        return data.empty();
    }

    // Obtener el tamaño de la pila
    size_t size() {
        return data.size();
    }
};

int main() {
    Stack s;

    // Operación de empuje (push)
    s.push(10);
    s.push(20);
    s.push(30);

    std::cout << "Tamaño de la pila: " << s.size() << std::endl;
    std::cout << "Elemento superior de la pila (back): " << s.top() << std::endl;

    // Operación de extracción (pop)
    s.pop();
    std::cout << "Después del pop, elemento superior de la pila: " << s.top() << std::endl;

    s.pop();
    std::cout << "Después de otro pop, elemento superior de la pila: " << s.top() << std::endl;

    s.pop();
    std::cout << "Después de otro pop, ¿la pila está vacía?: " << (s.empty() ? "Sí" : "No") << std::endl;

    return 0;
}

Resultado esperado de la ejecución:

栈的大小: 3
栈顶元素 (back): 30
出栈后，栈顶元素: 20
再出栈后，栈顶元素: 10
再出栈后，栈是否为空: 是

Análisis del código:

  • back()Se usa para obtener el elemento superior de la pila (el último elemento empujado).
  • La pila es una estructura de datos LIFO (último en entrar, primero en salir),back()y corresponde exactamente a la parte superior de la pila.

Ejemplo 5: Obtener dinámicamente el valor máximo

Se utilizabackjunto consortpara obtener el elemento máximo después de ordenar.

Ejemplo

#include <iostream>
#include <vector>
#include <algorithm>
#include <ctime>
#include <cstdlib>

int main() {
    std::srand(std::time(nullptr));

    std::vector<int> numbers;
    // Generar 5 números aleatoriamente
    for(int i = 0; i < 5; ++i) {
        numbers.push_back(std::rand() % 100);
    }

    std::cout << "Datos originales: ";
    for(int n : numbers) {
        std::cout << n << " ";
    }
    std::cout << std::endl;

    // Ordenar
    std::sort(numbers.begin(), numbers.end());

    std::cout << "Después de ordenar: ";
    for(int n : numbers) {
        std::cout << n << " ";
    }
    std::cout << std::endl;

    std::cout << "Valor mínimo (front): " << numbers.front() << std::endl;
    std::cout << "Valor máximo (back): " << numbers.back() << std::endl;

    return 0;
}

Análisis del código:

  • Después de ordenar,front()devuelve el valor mínimo,back()devuelve el valor máximo.
  • Esta es una forma sencilla de obtener el valor máximo/mínimo.
