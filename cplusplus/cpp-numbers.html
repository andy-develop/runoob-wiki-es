C++ Números

Normalmente, cuando necesitamos usar números, utilizamos los tipos de datos primitivos, como int, short, long, float y double, etc. Los posibles valores y rangos numéricos de estos tipos de datos para números ya los hemos discutido en el capítulo de Tipos de datos de C++.

C++ Definir números

Ya hemos definido números en varios ejemplos de capítulos anteriores. A continuación se muestra un ejemplo completo de cómo definir varios tipos de números en C++:

Ejemplo

#include <iostream> using namespace std; int main () { // Definición de números short s; int i; long l; float f; double d; // Asignación de números s = 10; i = 1000; l = 1000000; f = 230.47; d = 30949.374; // Salida de números cout << "short s :" << s << endl; cout << "int i :" << i << endl; cout << "long l :" << l << endl; cout << "float f :" << f << endl; cout << "double d :" << d << endl; return 0; }

Cuando el código anterior se compila y se ejecuta, produce el siguiente resultado:

short  s :10
int    i :1000
long   l :1000000
float  f :230.47
double d :30949.4

C++ Operaciones matemáticas

En C++, además de poder crear varias funciones, también se incluyen varias funciones útiles para que usted las use. Estas funciones están escritas en las bibliotecas estándar de C y C++, y se denominanintegradasfunciones. Puede hacer referencia a estas funciones en su programa.

C++ incorpora una gran variedad de funciones matemáticas integradas que pueden operar sobre varios números. La siguiente tabla enumera algunas funciones matemáticas integradas útiles en C++.

Para utilizar estas funciones, necesita incluir el archivo de cabecera matemático<cmath>。

N.ºFunción y descripción

Esta función devuelve el coseno de un ángulo en radianes (tipo double).

Esta función devuelve el seno de un ángulo en radianes (tipo double).

Esta función devuelve la tangente de un ángulo en radianes (tipo double).
4double log(double);
Esta función devuelve el logaritmo natural del parámetro.

Suponiendo que el primer parámetro es x y el segundo es y, esta función devuelve x elevado a la potencia y.

Esta función devuelve la raíz cuadrada de la suma de los cuadrados de dos parámetros; es decir, si los parámetros son los dos catetos de un triángulo rectángulo, la función devuelve la longitud de la hipotenusa.

A continuación se muestra un ejemplo sencillo sobre operaciones matemáticas:

Ejemplo

#include <iostream> #include <cmath> using namespace std; int main () { // Definición de números short s = 10; int i = -1000; long l = 100000; float f = 230.47; double d = 200.374; // Operaciones matemáticas cout << "sin(d) :" << sin(d) << endl; cout << "abs(i) :" << abs(i) << endl; cout << "floor(d) :" << floor(d) << endl; cout << "sqrt(f) :" << sqrt(f) << endl; cout << "pow( d, 2) :" << pow(d, 2) << endl; return 0; }

Cuando el código anterior se compila y se ejecuta, produce el siguiente resultado:

C++ Números aleatorios

En muchos casos, es necesario generar números aleatorios. Con respecto al generador de números aleatorios, hay dos funciones relacionadas. Una esrand(), esta función solo devuelve un número pseudoaleatorio. Antes de generar números aleatorios, primero debe llamar asrand()función.

A continuación se muestra un ejemplo sencillo de generación de números aleatorios. En el ejemplo se utilizatime()la función para obtener los segundos de la hora del sistema, y mediante la llamada a la función rand() se generan números aleatorios:

Ejemplo

#include <iostream> #include <ctime> #include <cstdlib> using namespace std; int main () { int i,j; // Establecer la semilla srand( (unsigned)time( NULL ) ); /*Generar 10 números aleatorios*/ for( i = 0; i < 10; i++ ) { // Generar los números aleatorios reales j= rand(); cout <<"Números aleatorios:" << j << endl; } return 0; }

C++ Constantes matemáticas

En C++, las constantes matemáticas (como π, e, la proporción áurea, etc.) son una parte indispensable de muchos algoritmos y aplicaciones. Aunque las primeras versiones de C++ no proporcionaban directamente estas constantes, a partir de C++20, la biblioteca estándar introdujo varias constantes matemáticas de uso común y proporcionó una forma más eficiente y unificada de acceder a ellas.

Para más información, consulte:Biblioteca estándar de C++<numbers>。

π

  • Constante:std::numbers::pi
  • Tipo:std::float32_t(flotante de 32 bits),std::float64_t(flotante de 64 bits)

Ejemplo

#include <cmath>
#include <iostream>

int main() {
    std::cout << "pi: " << std::numbers::pi << std::endl;
}

La base del logaritmo natural e (Número de Euler)

  • Constante:std::numbers::e
  • Tipo:std::float32_t、std::float64_t
std::cout << "e: " << std::numbers::e << std::endl;

La proporción áurea φ (Golden Ratio)

  • Constante:std::numbers::phi
  • Tipo:std::float32_t、std::float64_t
std::cout << "phi: " << std::numbers::phi << std::endl;

Ejemplo

#include <iostream>
#include <cmath>
#include <numbers>

int main() {
    std::cout << "pi: " << std::numbers::pi << std::endl;
    std::cout << "e: " << std::numbers::e << std::endl;
    std::cout << "phi: " << std::numbers::phi << std::endl;

    return 0;
}

El resultado de salida es:

pi: 3.14159
e: 2.71828
phi: 1.61803

    La función srand es la función de inicialización del generador de números aleatorios.

    Prototipo: void srand(unsigned seed);

    Uso:Necesita proporcionar una semilla, y esta semilla corresponderá a un número aleatorio. Si se usa la misma semilla, la función rand() posterior producirá el mismo número aleatorio. Por ejemplo:srand(1);Puede usar directamente 1 para inicializar la semilla. Sin embargo, para evitar que los números aleatorios se repitan cada vez, a menudo se usa la hora del sistema para inicializar. Es decir, se usa la función time para obtener la hora del sistema, cuyo valor de retorno es la cantidad de segundos transcurridos desde 00:00:00 GMT, January 1, 1970 hasta el presente, y luego se convierte el dato de tipo time_t a tipo (unsigned) y se pasa a la función srand, es decir: srand((unsigned) time(&t)); También hay un uso frecuente que no requiere definir la variable t de tipo time_t: srand((unsigned) time(NULL)); se pasa directamente un puntero nulo, porque en su programa a menudo no necesita los datos t obtenidos a través del parámetro.

    Ejemplo:

    #include <stdlib.h>
#include <stdio.h>
#include <time.h> /*用到了time函数，所以要有这个头文件*/
#define MAX 10
 
int main( void)
{
    int number[MAX] = {0};
    int i;
    srand((unsigned) time(NULL)); /*播种子*/
    for(i = 0; i < MAX; i++)
    {
        number[i] = rand() % 100; /*产生100以内的随机整数*/
        printf("%d ", number[i]);
    }
    printf("\n");
    return 0;
}

    1. El rango de generación del número aleatorio rand: en la biblioteca C estándar, la función rand() puede generar un número aleatorio entre 0 y RAND_MAX, donde RAND_MAX es un entero definido en stdlib.h, que depende del sistema y es al menos 32767.

    2. Método para usar rand() y srand() con el fin de generar enteros aleatorios en un rango específico: método de “módulo + suma”. Por ejemplo, para generar un número aleatorio num en el rango [m,n], se puede usar:int num=rand()%(n-m+1)+m;(es decir,rand()%[número de elementos del intervalo]+[valor inicial del intervalo]）

    El valor de RAND_MAX en Windows es: 0x7fff=2^15-1=32767

    El valor de RAND_MAX en Linux es: 2^31-1=2147483647

    Procedamos a explicarlo en Windows:

    La función Rand devuelve un entero (pseudo)aleatorio en el rango de 0 a RAND_MAX (32767).

    Para obtener un número (pseudo)aleatorio en un intervalo específico, no se recomienda usar el método de “módulo + suma”,

    Por ejemplo: si se usa este método para obtener un número aleatorio entre 0 y 10000, la escritura sería

    srand( (unsigned)time( NULL ) );
int n = rand()%10000;

    Entonces la probabilidad de aparición de cada número entre 0 y 2767 es 4/32676, mientras que la probabilidad de los números entre 2768 y 9999 es 3/32676, que es diferente de la anterior. Sin embargo, como rand() genera números pseudoaleatorios, esto no tiene importancia, jaja.

    Se recomienda adoptar el siguiente método:

    int u = (double)rand() / (RAND_MAX + 1) * (range_max - range_min)+ range_min

    A continuación se muestra un ejemplo de la documentación de desarrollo de VS:

    // crt_rand.c
// This program seeds the random-number generator
// with the time, then exercises the rand function.
//

#include <stdlib.h>
#include <stdio.h>
#include <time.h>

void SimpleRandDemo( int n )
{
   // Print n random numbers.
   int i;
   for( i = 0; i < n; i++ )
      printf( "  %6d\n", rand() );
}

void RangedRandDemo( int range_min, int range_max, int n )
{
   // Generate random numbers in the half-closed interval
   // [range_min, range_max). In other words,
   // range_min <= random number < range_max
   int i;
   for ( i = 0; i < n; i++ )
   {
      int u = (double)rand() / (RAND_MAX + 1) * (range_max - range_min)
            + range_min;
      printf( "  %6d\n", u);
   }
}

int main( void )
{
   // Seed the random-number generator with the current time so that
   // the numbers will be different every time we run.
   srand( (unsigned)time( NULL ) );

   SimpleRandDemo( 10 );
   printf("\n");
   RangedRandDemo( -100, 100, 10 );
}

    Se recomienda usar la biblioteca random para generar números verdaderamente aleatorios, como se muestra a continuación:

    #include <random>
#include <iostream>

using namespace std;

int main()
{
    random_device rd;   // non-deterministic generator
    mt19937 gen(rd());  // to seed mersenne twister.
    uniform_int_distribution<> dist(1,6); // distribute results between 1 and 6 inclusive.

    for (int i = 0; i < 5; ++i) {
        cout << dist(gen) << " "; // pass the generator to the distribution.
    }
    cout << endl;
}
