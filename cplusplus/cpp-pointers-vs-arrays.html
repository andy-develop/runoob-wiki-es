C++ Punteros vs Arreglos

Punteros en C++

Los punteros y los arreglos están estrechamente relacionados. De hecho, los punteros y los arreglos son intercambiables en muchos casos. Por ejemplo, un puntero que apunta al inicio de un arreglo puede acceder al arreglo mediante aritmética de punteros o indexación de arreglos. Vea el siguiente programa:

Ejemplo

#include <iostream> using namespace std; const int MAX = 3; int main () { int var[MAX] = {10, 100, 200}; int *ptr; // Dirección del arreglo en el puntero ptr = var; for (int i = 0; i < MAX; i++) { cout << "var[" << i << "La dirección de memoria de ] es"; cout << ptr << endl; cout << "var[" << i << "El valor de ] es"; cout << *ptr << endl; // Moverse a la siguiente posición ptr++; } return 0; }

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

var[0]的内存地址为 0x7fff59707adc
var[0] 的值为 10
var[1]的内存地址为 0x7fff59707ae0
var[1] 的值为 100
var[2]的内存地址为 0x7fff59707ae4
var[2] 的值为 200

Sin embargo, los punteros y los arreglos no son completamente intercambiables. Por ejemplo, vea el siguiente programa:

Ejemplo

#include <iostream> using namespace std; const int MAX = 3; int main () { int var[MAX] = {10, 100, 200}; for (int i = 0; i < MAX; i++) { *var = i; // Esta es la sintaxis correcta var++; // Esto es incorrecto } return 0; }

Aplicar el operador de puntero * a var es perfectamente válido, pero modificar el valor de var es ilegal. Esto se debe a que var es una constante que apunta al inicio del arreglo y no puede usarse como valor l (lvalue).

Dado que un nombre de arreglo corresponde a un puntero constante, siempre que no se cambie el valor del arreglo, todavía se pueden usar expresiones en forma de puntero. Por ejemplo, la siguiente es una declaración válida que asigna 500 a var

*(var + 2) = 500;

La declaración anterior es válida y se compila correctamente porque var no cambia.

    Algunas extensiones al tutorial:

    #include <iostream>

using namespace std;

int *ptr = new int(), n = 0;

int main(int argc,char* argv[])
{
    cout << "设置输入多少个数字: "<< endl;
    cin >> n;
     cout << "开始输入: "<< endl;
    for(int i = 0; i < n; ++i)
    {
        cin >> ptr[i];
    }

    cout << "输入的数字为: "<< endl;
    for(int i = 0; i < n; ++i)
    {
        cout << *(ptr + i) << " ";
    }
    return 0;
}

    1. Al inicializar un puntero, se puede usar la palabra clave new, con la forma "new Tipo(parámetro)". El parámetro de tipo int puede estar vacío o ser un valor int; la palabra clave new devuelve el puntero a esa variable.

    2. El puntero en sí mismo puede usarse como arreglo. En el primer bucle for, el formato de entrada ya muestra esto: ptr[i] es en realidad *(ptr + i), e int ptr[] representa const int* ptr; no hay casi diferencia excepto que la dirección inicial es constante y el tamaño está determinado.

    3. Precisamente por esto, se puede usar un puntero como un arreglo de longitud variable, pasando cualquier cantidad de valores sin necesidad de crear un arreglo grande de antemano, ahorrando espacio. Al inicializar, no se fija la longitud del puntero (arreglo) ptr, por lo que se pueden agregar variables indefinidamente hasta que la RAM se agote.

    4. El tipo de variable inicializado no incluye el puntero. En la definición de variables antes de la función main, primero definimos ptr usando int* como tipo, y luego definimos n con el tipo int. Es evidente que esto muestra que al definir múltiples variables, el tipo de variable por defecto no incluye el puntero. En realidad, el operador de puntero * solo tiene un objeto de operación, así que incluso si lo colocas junto al tipo y le pones paréntesis (aunque poner paréntesis al tipo causará un error), no cambiará esta regla. (No me hables de macros).

    Por cierto, en la última declaración del bucle for, ++i es más rápido que i++. Así que a menos que necesites aprovechar las características de precedencia de estos dos operadores, se recomienda usar ++i como operador de incremento en la declaración. De hecho, también puedes establecer i como variable puntero, e inicializar i en la primera declaración como un puntero que apunta al inicio del arreglo; luego puedes usar *i como variable de arreglo.

    Si decimos que el nombre del arregloa 是 a[0]la dirección de,(a+n)se refiere aa[0]la dirección más un valor,&representa obtener la dirección,*representa obtener el valor, entoncesa[i]es equivalente a*(a+i)，&a[i]es equivalente a(a+i)。

    como se muestra a continuación:

    #include<iostream>
using namespace std;
int main()
{
    int a[5];// 在"int main()"中定义数组 ，数组若没有定义初始值，其初始值是随机的 
    a[2]=100;
    for(int i=-5;i<=10;i++)// 无论i是负数，还是过大溢出，都只是改变数组地址 
    cout<<"a["<<i<<"]="<<a[i]<<" "<<endl;
    cout<<endl;
    for(int i=-5;i<=10;i++)
    cout<<"*(a+"<<i<<")="<<*(a+i)<<" "<<endl;// 取(a+i)地址所存的值 
    cout<<endl;
    for(int i=-5;i<=10;i++)
    cout<<"&a["<<i<<"]="<<&a[i]<<" "<<endl;// 取a[i]的地址 
    cout<<endl;
    for(int i=-5;i<=10;i++)
    cout<<"(a+"<<i<<")="<<a+i<<" "<<endl;// 取(a+i)的地址 
    //最好不要用负数数组和溢出数组，否则可能出问题
}
