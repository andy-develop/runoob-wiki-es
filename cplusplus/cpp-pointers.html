C++ Punteros

Aprender los punteros de C++ es a la vez simple e interesante. Mediante los punteros, se puede simplificar la ejecución de algunas tareas de programación en C++; además, hay algunas tareas, como la asignación de memoria dinámica, que no se pueden realizar sin punteros. Por lo tanto, si se desea ser un buen programador de C++, es muy necesario aprender los punteros.

Como usted sabe, cada variable tiene una ubicación de memoria, y cada ubicación de memoria define una dirección que se puede acceder mediante el operador ampersand (&), que representa una dirección en la memoria. Consulte el siguiente ejemplo, que mostrará la dirección de la variable definida:

Ejemplos

#include <iostream> using namespace std; int main () { int var1; char var2[10]; cout << "Dirección de la variable var1:"; cout << &var1 << endl; cout << "Dirección de la variable var2:"; cout << &var2 << endl; return 0; }

Cuando el código anterior se compila y ejecuta, produce los siguientes resultados:

var1 变量的地址： 0xbfebd5c0
var2 变量的地址： 0xbfebd5b6

A través del ejemplo anterior, hemos aprendido qué es una dirección de memoria y cómo acceder a ella. A continuación, veamos qué es un puntero.

¿Qué es un puntero?

Punteroes una variable cuyo valor es la dirección de otra variable, es decir, la dirección directa de una ubicación de memoria. Al igual que otras variables o constantes, debe declararlo antes de usar un puntero para almacenar la dirección de otra variable. La forma general de declarar una variable puntero es:

type *var-name;

Aquí,typees el tipo base del puntero, y debe ser un tipo de datos válido de C++.var-namees el nombre de la variable puntero. El asterisco * utilizado para declarar punteros es el mismo que el asterisco usado en la multiplicación. Sin embargo, en esta declaración, el asterisco se utiliza para indicar que una variable es un puntero. A continuación se muestran declaraciones de punteros válidas:

int    *ip;    /* 一个整型的指针 */
double *dp;    /* 一个 double 型的指针 */
float  *fp;    /* 一个浮点型的指针 */
char   *ch;    /* 一个字符型的指针 */

El tipo de dato real del valor de todos los punteros, ya sea entero, flotante, carácter u otro tipo de dato, es el mismo: un número hexadecimal largo que representa una dirección de memoria. La única diferencia entre los punteros de diferentes tipos de datos es el tipo de dato de la variable o constante a la que apunta el puntero.

Uso de punteros en C++

Al usar punteros, se realizan con frecuencia las siguientes operaciones: definir una variable puntero, asignar la dirección de una variable al puntero y acceder al valor de la dirección disponible en la variable puntero. Esto se hace mediante el operador unario*que devuelve el valor de la variable ubicada en la dirección especificada por el operando. El siguiente ejemplo involucra estas operaciones:

Ejemplo

#include <iostream> using namespace std; int main () { int var = 20; // declaración de la variable real int *ip; // declaración de la variable puntero ip = &var; // almacenar la dirección de var en la variable puntero cout << "Value of var variable: "; cout << var << endl; // mostrar la dirección almacenada en la variable puntero cout << "Address stored in ip variable: "; cout << ip << endl; // acceder al valor de la dirección en el puntero cout << "Value of *ip variable: "; cout << *ip << endl; return 0; }

Cuando el código anterior se compila y ejecuta, produce los siguientes resultados:

Value of var variable: 20
Address stored in ip variable: 0xbfc601ac
Value of *ip variable: 20

Detalles de los punteros en C++

En C++, hay muchos conceptos relacionados con los punteros; todos son simples, pero muy importantes. A continuación se enumeran algunos conceptos importantes relacionados con los punteros que todo programador de C++ debe tener claro:

ConceptoDescripción
Puntero nulo en C++C++ admite punteros nulos. Un puntero NULL es una constante con valor cero definida en la biblioteca estándar.
Operaciones aritméticas con punteros en C++Se pueden realizar cuatro operaciones aritméticas con punteros: ++, --, +, -
Punteros vs arreglos en C++Los punteros y los arreglos tienen una relación estrecha.
Arreglo de punteros en C++Se pueden definir arreglos que se utilizan para almacenar punteros.
Puntero a puntero en C++C++ permite punteros que apuntan a punteros.
Pasar punteros a funciones en C++Pasar parámetros por referencia o por dirección para que los parámetros pasados se modifiquen en la función llamada.
Devolver punteros desde una función en C++C++ permite que una función devuelva un puntero a variables locales, variables estáticas y memoria asignada dinámicamente.

    Todavía existen malentendidos sobre la transferencia por valor, la transferencia por puntero y la transferencia por referencia;

    Transferencia por valor:

    El parámetro formal es una copia del argumento real; cambiar el valor del parámetro formal no afecta el valor del argumento real externo. Desde la perspectiva de la función llamada, la transferencia por valor es unidireccional (argumento real -> parámetro formal); el valor del parámetro solo se puede pasar hacia adentro, no hacia afuera. Cuando una función necesita modificar el parámetro internamente pero no se desea que este cambio afecte al llamador, se utiliza la transferencia por valor.

    Transferencia por puntero:

    El parámetro formal es un puntero a la dirección del argumento real; cuando se realiza una operación de desreferencia sobre el parámetro formal, equivale a operar sobre el propio argumento real.

    Transferencia por referencia:

    El parámetro formal es equivalente a un 'alias' del argumento real; operar sobre el parámetro formal es en realidad operar sobre el argumento real. En el proceso de transferencia por referencia, aunque el parámetro formal de la función llamada también abre espacio de memoria en la pila como una variable local, lo que se almacena en ese espacio es la dirección de la variable del argumento real proporcionada por la función que llama. Cualquier operación que la función llamada realice sobre el parámetro formal se trata como direccionamiento indirecto, es decir, se accede a la variable del argumento real en la función que llama a través de la dirección almacenada en la pila. Precisamente por esto, cualquier operación que la función llamada realice sobre el parámetro formal afecta a la variable del argumento real de la función que llama.

    En C++ se permite declarar punteros que apuntan a funciones, lo que se conoce como puntero a función.

    La declaración de un puntero a función es similar a la declaración de una función, excepto que el nombre de la función se convierte en(*nombre del puntero), y la forma de definición es la siguiente:

    data_types (*func_pointer)( data_types arg1, data_types arg2, ...,data_types argn);

    Por ejemplo:

    int (*fp)(int a);

    Aquí se define un puntero fp a una función (cuyo único parámetro es de tipo int y cuyo valor de retorno es de tipo int).

    Después de declarar un puntero a función, se puede hacer que apunte a una función que cumpla las condiciones, por ejemplo:

    int a(int b);
{
    cout<<b;
    return ++b;
}

int(*p)(int);
p=a;

    Después de esto, podemos llamar a la función a través del puntero a función:

    (*p)(5);

    Para más información, consulte:Punteros a funciones en C++ y punteros a funciones miembro de clases

    Diferencia entre el nombre de un array y un puntero:

    La cadena literal a la derecha de `char p[]=` y la de `char *p=` se usan de manera diferente.

    La primera declara un array; la cadena literal se utiliza para inicializar el array. La vida útil y el ámbito del array están relacionados con la forma de declaración. Además, si el array no tiene el calificador `const`, el contenido de la cadena se puede modificar. La dirección inicial de este array no se puede devolver desde una función, a menos que la declaración use `static`.

    La segunda declara un puntero. La cadena literal se convierte en un array con duración de almacenamiento estático, y luego se convierte implícitamente en un puntero para inicializar el puntero declarado. Esta cadena no se puede modificar (modificarla provoca un comportamiento indefinido; el array puede estar en una región de memoria de solo lectura). Su dirección inicial puede devolverse desde una función.

    Conversión forzada de tipos de puntero en C++

    El valor del puntero y el valor de la dirección a la que apunta corresponden respectivamente a la dirección de los datos y al valor almacenado en esa dirección. Por lo tanto, según el tipo de endianness de la CPU, al convertir el tipo del puntero y continuar operando se debe prestar atención al endianness.

    #include <cstdlib>
#include <iostream>

using namespace std;

int main()
{
    char str1[4] = {0x12,0x34,0x56,0x78};
    char * ptr = str1;
    cout << "value of *ptr " << hex << (int)(*ptr) << endl;//hex输出必须对应int类型，否则输出ASCII码
    cout << "value of *ptr " << hex << (int)(*(int*)ptr) << endl;//hex输出必须对应int类型，否则输出ASCII码
    return 0;
}

    Salida de compilación:

    E:\CppTest\VScodeTest\pointer_t> g++ .\pointer_t.cpp -o pointer_t        
E:\CppTest\VScodeTest\pointer_t> .\pointer_t.exe 
value of *ptr 12
value of *ptr 78563412
E:\CppTest\VScodeTest\pointer_t>

    Se puede ver que no es el 0x12345678 deseado.
