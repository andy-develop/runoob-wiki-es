C++ Tutorial

C++ es un lenguaje de alto nivel que fue diseñado y desarrollado por Bjarne Stroustrup en los Laboratorios Bell en 1979. C++ amplía y mejora el lenguaje C, y es un lenguaje de programación orientado a objetos. C++ puede ejecutarse en múltiples plataformas, como Windows, el sistema operativo Mac y varias versiones de UNIX.

Este tutorial explica el lenguaje de programación C++ en un lenguaje fácil de entender.

¡Ahora comienza a aprender programación en C++!

¿Quién debería leer este tutorial?

Este tutorial está diseñado específicamente para principiantes, ayudándoles a comprender los conceptos desde básicos hasta avanzados relacionados con el lenguaje de programación C++.

Conocimientos que necesita antes de leer este tutorial:

Antes de comenzar a practicar los ejemplos presentados en este tutorial, necesita tener un conocimiento básico de los programas informáticos y los lenguajes de programación de computadoras.

    En C++,"\n" 与 endl¿cuál es la diferencia?

    "\n" representa una cadena cuyo contenido es un carácter de retorno de carro. std::endl es un manipulador de flujo; su efecto de salida es similar a la salida de "\n", pero puede haber una ligera diferencia.

    std::endl genera un carácter de nueva línea y vacía el búfer inmediatamente.

    Por ejemplo:

    std::cout << std::endl;

    Equivale a:

    std::cout << '\n' << std::flush;
或者
std::cout << '\n'; std::fflush(stdout);

    Debido a la sobrecarga del operador de flujo <<, el efecto de salida es el mismo para '\n' y "\n".

    Para flujos con búfer de salida (como cout, clog), si no se realiza una operación de vaciado del búfer manualmente, la salida se vaciará automáticamente cuando el búfer esté lleno. Sin embargo, para cout (en comparación con los flujos de salida a archivos, etc.), el almacenamiento en búfer generalmente no es muy evidente. No obstante, cuando sea necesario, usar endl en lugar de '\n' suele ser un buen hábito.

    Para flujos sin búfer (como el flujo de salida de error estándar cerr), el vaciado no es necesario y se puede usar directamente '\n'.

    En C++, se utilizan .h y .cpp respectivamente para definir una clase.

    .hEn él se almacenan la declaración de la clase y los prototipos de funciones (dentro de la declaración de la clase).

    .cppSe almacenan los cuerpos de las funciones.

    Es decir, uno almacena declaraciones (declaration) y el otro almacena definiciones (definition).

    Si declaramos una función en un archivo de cabecera, cuando necesitemos definir esta función (esta definición es única, es decir, solo se puede definir una vez), o cuando necesitemos usar esta función, debemos incluir este archivo de cabecera en el cpp.

    De manera similar, si declaramos una clase en un archivo de cabecera, cuando necesitemos definir las funciones miembro de la clase, o cuando necesitemos usar esta clase, debemos incluir este archivo de cabecera en el cpp.

    Para los diseñadores de clases, el archivo de cabecera es como un contrato entre ellos y los usuarios de la clase. El compilador refuerza este contrato: le exige que, al usar las funciones o estructuras de estas clases, deba declararlas.

    "\n"Representa una cadena cuyo único dato es un carácter de retorno de carro.

    '\n'Representa un carácter.

    ¡Estos dos son iguales en la salida!

    Acerca de endl:

    1. En C++, al generar un salto de línea en la terminal, se puede usarcout<<......<<endly "\n" son ambos válidos; esto es un conocimiento básico. Pero hay una pequeña diferencia entre ambos: con endl se vacía el búfer, haciendo que el contenido del búfer se vacíe una vez; con "\n" no se vacía, solo salta de línea y los datos en el búfer no cambian. Sin embargo, en condiciones normales, esta diferencia es muy pequeña; en programas grandes puede tener relevancia. Se recomienda usar endl para los saltos de línea.

    2. Además de escribir '\n', endl también llama a la función flush, que vacía el búfer y escribe los datos del búfer en un archivo o en la pantalla. Si se considera la eficiencia, use '\n'.

    3. cout << endl; además de insertar un '\n' en el flujo de salida, también tiene el efecto de vaciar el flujo de salida.

    cout << endl; 
等价于: 
\cout << '\n' << flush;

    Cuando no sea necesario vaciar el flujo de salida, trate de usarcout << '\n', el uso excesivo de endl es uno de los factores que provocan una baja eficiencia en la ejecución del programa.

    ¿Qué significa realmente using namespace std en C++?

    Significa declarar un espacio de nombres. Los espacios de nombres son muy útiles en el trabajo en equipo, porque si usted define una variable a y otra persona también define una variable a, habrá una definición duplicada. Si usted define a en su propio espacio de nombres y la otra persona define a en el suyo, entonces no se duplican. Por ejemplo:

    using namespace xx;
using namespace yy;

    xx::a 和 yy::aAunque ambas se llaman a, no son la misma variable.

    std es el espacio de nombres estándar del sistema. Para que no se repita con los nombres definidos por el usuario, se declara en el espacio de nombres std. Además, este espacio es como un gran paquete que incluye todo el soporte del sistema.

    ::En C++, representa el ámbito y la relación de pertenencia.::Es el operador con el mayor nivel de precedencia. Se divide en tres tipos, como sigue:

    1. Símbolo de ámbito:

    Símbolo de ámbito::Delante suele ir el nombre de la clase, y detrás suele ir el nombre del miembro de esa clase. C++ utiliza el ámbito como forma de distinción para evitar que diferentes clases tengan miembros con el mismo nombre.

    Por ejemplo: A y B representan dos clases; tanto A como B tienen un miembro llamado member.

    Entonces:

    • 1. A::member representa el miembro member de la clase A.
    • 2. B::member representa el miembro member de la clase B.

    2. Símbolo de ámbito global:

    Símbolo de ámbito global: cuando una variable global tiene el mismo nombre que alguna variable en una función local, se puede usar::para distinguirlas, por ejemplo:

    char  zhou;  //全局变量
void  sleep()
{
  char  zhou; //全局变量
  char(局部变量) = char(局部变量)*char(局部变量);
  ::char(全局变量) =::(全局变量) *char(全局变量)
}

    3. Operador de resolución de ámbito:

    :: es el operador de resolución de ámbito en C++. Por ejemplo, si se declara una clase A y dentro de la clase A se declara una función miembro void f(), pero no se da la definición de f en la declaración de la clase, entonces al definir f fuera de la clase, se debe escribir void A::f(), lo que indica que la función f() es una función miembro de la clase A. Por ejemplo:

    class CA 
{
public:
  int ca_var;
  int add(int a, int b);
  int add(int a);
}
//那么在实现这个函数时，必须这样写：
int CA::add(int a, int b)
{
  return a + b;
}
//另外，双冒号也常常用于在类变量内部作为当前类实例的元素进行表示，比如：
int CA::add(int a)
{
  return a + ::ca_var;
}
//表示当前类实例中的变量ca_var。

    El archivo cpp se utiliza para almacenar la definición (definition) de la clase, y el archivo h se utiliza para almacenar la declaración (declaration) de la clase.

    Declara un espacio de nombres (namespace). Cuando varias personas colaboran, incluso si hay funciones con el mismo nombre, como están en espacios de nombres diferentes, no se producirán errores.

    ¿Por qué usar `using namespace std;`?

    Vamos a entenderlo palabra por palabra:

    • using: Referenciar
    • namespace: Espacio de nombres (namespace)
    • std: Estándar (standard, el nombre de un espacio de nombres; cout, endl, etc. dependen de este espacio de nombres).

    Entonces, ¿qué sucede si no está esta línea de código?

    #include <iostream>
// using namespace std;
int main()
{
    cout << "Hello, world!" << endl;
    return 0;
}//error

    Entonces, ¿cómo deberíamos escribirlo?

    #include <iostream>
// using namespace std;
int main()
{
    std::cout << "Hello, world!" << std::endl;
    return 0;
}

    Se puede ver que, al agregarstd::después, ya funciona.
