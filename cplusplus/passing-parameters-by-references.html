C++ Usar referencias como parámetros

Referencias en C++

Ya hemos discutido cómo usar punteros para implementar la llamada por referencia. El siguiente ejemplo usa referencias para implementar la llamada por referencia.

Ejemplos

#include <iostream> using namespace std; // declaración de función void swap(int& x, int& y); int main () { // declaración de variables locales int a = 100; int b = 200; cout << "Valor de a antes del intercambio:" << a << endl; cout << "Valor de b antes del intercambio:" << b << endl; /*Llamar a la función para intercambiar valores*/ swap(a, b); cout << "Valor de a después del intercambio:" << a << endl; cout << "Valor de b después del intercambio:" << b << endl; return 0; } // definición de la función void swap(int& x, int& y) { int temp; temp = x; /*Guardar el valor de la dirección x*/ x = y; /*Asignar y a x*/ y = temp; /*Asignar x a y*/ return; }

Cuando el código anterior se compila y ejecuta, produce los siguientes resultados:

交换前，a 的值： 100
交换前，b 的值： 200
交换后，a 的值： 200
交换后，b 的值： 100

    Referencias como parámetros de función

    La razón por la cual C++ agregó los tipos de referencia es principalmente utilizarlos como parámetros de función, para ampliar la funcionalidad de pasar datos a las funciones.

    Paso de parámetros a funciones en C++:

    (1) Usar el nombre de la variable como argumento real y parámetro formal. En este caso, lo que se pasa al parámetro formal es el valor de la variable, y la transferencia es unidireccional. Si durante la ejecución de la función el valor del parámetro formal cambia, no se devuelve al argumento real. Porque al llamar a la función, el parámetro formal y el argumento real no son la misma unidad de almacenamiento. // igual que en C

    (2) Pasar el puntero de la variable. El parámetro formal es una variable puntero, y el argumento real es la dirección de una variable. Al llamar a la función, el parámetro formal (variable puntero) apunta a la unidad de almacenamiento del argumento real. De esta manera, se puede modificar el valor del argumento real a través del puntero del parámetro formal. // igual que en C

    (3) C++ proporciona el paso de referencias de variables. El parámetro formal es una variable de referencia y es la misma variable que el argumento real. Al llamar a la función, el parámetro formal (variable de referencia) apunta a la unidad de almacenamiento del argumento real. De esta manera, se puede modificar el valor del argumento real a través de la referencia del parámetro formal.

    Las funciones que usan referencias como parámetros pueden recibir variables, pero no pueden recibir constantes.

    #include <iostream>
using namespace std;

int hls(int& a1, int& a2, int& b1, int& b2) //定义行列式函数
{
   int temp;
   temp=a1*b2-a2*b1;
   return temp;
}

int main()
{
   int x1=11; int x2=9;
   int y1=15; int y2=14;  //定义矩阵
   int result;  //行列式运算结果
   result=hls(x1,x2,y1,y2);   //result=hls(11,9,15,14)会报错
   cout << result << endl;
   return 0;
}

    Por ejemplo, existe esta estructura:

    struct Demo 
{
  char name[10000];
  int  count;
};

int main()
{
  Demo my_demo = {0};
  Demo *my_demo_p = &my_demo;
  Demo &my_demo_ref = my_demo;
  
  // 方式1：传递实参  
  func1(my_demo);

  // 方式2：传递指针  
  func2(my_demo_p);

  // 方式3：传递引用  
  func3(my_demo_ref);

  return 0;
}
如上所示，参数传递可以有三种方式，则三种函数可以这样定义：

// 方式1：传递实参 
void func1(Demo demo)
{
  cout << demo.name;
}

// 方式2：传递指针  
void func2(const Demo *demo_p)
{
  cout << demo->name;
}

// 方式3：传递引用  
void func3(const Demo &demo_ref)
{
  cout << demo.name;
}

    Se puede ver que la forma de usar las referencias y los argumentos reales es muy similar, pero ten en cuenta los siguientes puntos:

    • Desde el punto de vista del uso de memoria, al pasar el argumento real, los datos se copian (se crea una copia); es decir, cualquier modificación que func1 haga a los datos pasados no afectará a my_demo.
    • Dado que pasar el argumento real requiere crear una copia, significa que la eficiencia es menor. En el ejemplo, la longitud del miembro name de la estructura es 10000, precisamente para resaltar este problema de eficiencia.

    Las referencias y los punteros también son muy similares; ninguno crea copias, por lo que ambos son muy eficientes. Sus principales diferencias son:

    • Al seleccionar un miembro, la referencia usa un punto.para acceder, mientras que el puntero usa->para acceder.
    • Un puntero puede recibir un NULL, por lo que se debe verificar su validez antes de usarlo; una referencia siempre representa a algún objeto, por lo que no es necesario hacer esta verificación.

    PS:El propósito de agregar la palabra clave const en el código es evitar que func2 y func3 modifiquen los datos originales, porque la función solo sirve para imprimir name.

    1. Paso por valor simple

    #include <iostream>
using namespace std;
 
// 函数声明
void swap(int x, int y);
 
int main ()
{
   // 局部变量声明
   int a = 100;
   int b = 200;
 
   cout << "交换前，a 的值：" << a << endl;
   cout << "交换前，b 的值：" << b << endl;
 
   /* 调用函数来交换值 */
   swap(a, b);
 
   cout << "交换后，a 的值：" << a << endl;
   cout << "交换后，b 的值：" << b << endl;
 
   return 0;
}
 
// 函数定义
void swap(int x, int y)
{
   int temp;
   cout << "调用的函数中的交换:"<<endl;
   cout  << x <<endl;
   cout << y <<endl;
   temp = x; /* 保存地址 x 的值 */
   x = y;    /* 把 y 赋值给 x */
   y = temp; /* 把 x 赋值给 y  */
   cout  << x <<endl;
   cout << y <<endl;
   return;
}
    Simplemente pasar por valor: el valor solo cambia dentro de la función llamada, el valor original no cambia.

    3. Paso de punteros

    #include <iostream>
using namespace std;
 
// 函数声明
void swap(int *x, int *y);
 
int main ()
{
   // 局部变量声明
   int a = 100;
   int b = 200;
   int *c,*d;
   c=&a;
   d=&b;
   cout << "交换前，a 的值：" << *c << endl;
   cout << "交换前，b 的值：" << *d << endl;
 
   /* 调用函数来交换值 */
   swap(c, d);
   //swap(&a,&b);
   cout << "交换后，a 的值：" << *c << endl;
   cout << "交换后，b 的值：" << *d << endl;
 
   return 0;
}
 
// 函数定义
void swap(int *x, int *y)
{
   int temp;
   cout << "调用的函数中的交换:"<<endl;
   cout  << *x <<endl;
   cout << *y <<endl;
   temp = *x; /* 保存地址 x 的值 */
   *x = *y;    /* 把 y 赋值给 x */
   *y = temp; /* 把 x 赋值给 y  */
   cout  << *x <<endl;
   cout << *y <<endl;
   return;
}

    Esta forma de intercambiar a qué apuntan los punteros no puede lograr un intercambio real, porque al finalizar y retornar la función, los dos punteros desaparecen (sus valores no se devuelven a la función main()). Por lo tanto, el resultado final no es un intercambio. En consecuencia, se debe lograr el intercambio modificando el valor del contenido al que apunta el puntero, en lugar de intercambiar a qué apuntan los punteros.
