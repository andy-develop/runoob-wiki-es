C Arreglo de punteros

Punteros en C

Un arreglo de punteros es un arreglo en el que cada elemento es un puntero a algún tipo de dato.

Un arreglo de punteros almacena un conjunto de punteros, cada puntero puede apuntar a diferentes objetos de datos.

Los arreglos de punteros se utilizan generalmente para manejar múltiples objetos de datos, como arreglos de cadenas u arreglos de otras estructuras de datos complejas.

Veamos un ejemplo que utiliza un arreglo compuesto por 3 enteros:

Ejemplo

#include <stdio.h> const int MAX = 3; int main () { int var[] = {10, 100, 200}; int i; for (i = 0; i < MAX; i++) { printf("Value of var[%d] = %d\n", i, var[i] ); } return 0; }

Cuando el código anterior se compila y ejecuta, produce los siguientes resultados:

Value of var[0] = 10
Value of var[1] = 100
Value of var[2] = 200

Puede haber un caso en el que queramos que un arreglo almacene punteros a int, char u otros tipos de datos.

A continuación se muestra una declaración de un arreglo de punteros a enteros:

int *ptr[MAX];

Aquí, septrdeclara como un arreglo compuesto por MAX punteros a enteros. Por lo tanto, cada elemento en ptr es un puntero a un valor int. El siguiente ejemplo utiliza tres enteros, que se almacenarán en un arreglo de punteros, como se muestra a continuación:

Ejemplo

#include <stdio.h> const int MAX = 3; int main () { int var[] = {10, 100, 200}; int i, *ptr[MAX]; for ( i = 0; i < MAX; i++) { ptr[i] = &var[i]; /*Asigna la dirección de un entero*/ } for ( i = 0; i < MAX; i++) { printf("Value of var[%d] = %d\n", i, *ptr[i] ); } return 0; }

Cuando el código anterior se compila y ejecuta, produce los siguientes resultados:

Value of var[0] = 10
Value of var[1] = 100
Value of var[2] = 200

También puede usar un arreglo de punteros a caracteres para almacenar una lista de cadenas, como sigue:

Ejemplo

#include <stdio.h> const int MAX = 4; int main () { const char *names[] = { "Zara Ali", "Hina Ali", "Nuha Ali", "Sara Ali", }; int i = 0; for ( i = 0; i < MAX; i++) { printf("Value of names[%d] = %s\n", i, names[i] ); } return 0; }

Cuando el código anterior se compila y ejecuta, produce los siguientes resultados:

Value of names[0] = Zara Ali
Value of names[1] = Hina Ali
Value of names[2] = Nuha Ali
Value of names[3] = Sara Ali

Veamos otro ejemplo sencillo: primero declaramos un arreglo de punteros ptrArray que contiene tres punteros a enteros, luego hacemos que estos punteros apunten a diferentes variables enteras num1, num2 y num3, y finalmente usamos el arreglo de punteros para acceder a los valores de estas variables enteras.

Ejemplo

#include <stdio.h> int main() { int num1 = 10, num2 = 20, num3 = 30; // Declara un arreglo de punteros a enteros, que contiene tres punteros int *ptrArray[3]; // Apunta los punteros a diferentes variables enteras ptrArray[0] = &num1; ptrArray[1] = &num2; ptrArray[2] = &num3; // Usa el arreglo de punteros para acceder a los valores de estas variables enteras printf("Value at index 0: %d\n", *ptrArray[0]); printf("Value at index 1: %d\n", *ptrArray[1]); printf("Value at index 2: %d\n", *ptrArray[2]); return 0; }

Cuando el código anterior se compila y ejecuta, produce los siguientes resultados:

Value at index 0: 10
Value at index 1: 20
Value at index 2: 30

Los arreglos de punteros son muy útiles en C, especialmente al manejar estructuras de datos con un número variable de elementos, como arreglos de cadenas asignados dinámicamente o arreglos de estructuras creados dinámicamente.

    Diferencia entre arreglo de punteros y puntero a arreglo

    Arreglo de punteros

    Arreglo de punteros: Un arreglo de punteros puede decirse que es un 'arreglo de punteros'; primero, esta variable es un arreglo.

    En segundo lugar, 'puntero' modifica a este arreglo, lo que significa que todos los elementos de este arreglo son de tipo puntero.

    En un sistema de 32 bits, un puntero ocupa cuatro bytes.

    Puntero a arreglo

    Puntero a arreglo: Un puntero a arreglo puede decirse que es un 'puntero a un arreglo'; primero, esta variable es un puntero.

    En segundo lugar, 'arreglo' modifica a este puntero, lo que significa que este puntero almacena la dirección inicial de un arreglo, o que este puntero apunta a la dirección inicial de un arreglo.

    根

    Según la explicación anterior, se puede entender la diferencia entre un arreglo de punteros y un puntero a arreglo, porque ambos son, en esencia, dos tipos distintos de variables.

    Arreglo de punteros: Es un arreglo de punteros; en realidad es un arreglo, su longitud está determinada por el propio arreglo. Todos los elementos de este arreglo son de tipo puntero y almacenan direcciones.

    int *prt[ 10 ] ; *prt[ 1 ],*prt[ 2 ],*prt[ 3 ]......Cada elemento del arreglo apunta a una dirección.

    Puntero a arreglo: Es un puntero a un arreglo; en realidad es un puntero, de longitud fija (ocupa 4 bytes en un sistema de 32 bits). Este puntero apunta a un arreglo, pero el número de bytes que ocupa el arreglo al que apunta no es fijo.

    int  a[5]={ 1,2,3,4,5 };    //定义一个一维数组 a
int  (*prt)[5];      // 步长为 5 的数组指针，即 prt 指向的数组里有 5 个元素  
prt=&a;    // 把数组 a 的地址付给 prt，则 prt 为数组 a 的地址，*prt 表示数组 a 本身
prt[ 0 ];    //表示数组首元素的地址
*prt[ 0 ]；  //表示数组的首元素的值，即为数组 a 的 1
**prt;         //表示数组的首元素的值，即为数组 a 的 1
*prt[ 1 ] ;   //表示指向数组的下一行元素的首元素的值，但是a是一维数组，只有一行，所以指向的地址中的值不确定

    Cuando un puntero a arreglo se incrementa en 1, el paso es el número de columnas del arreglo al que apunta, es decir, la dirección inicial de la siguiente fila. Esto solo tiene sentido en arreglos de dos o más dimensiones; un arreglo de una dimensión tiene una sola fila, por lo que no tiene sentido.

    Arreglo de punteros:

    int *a[3]: ¿Por qué aquí es un arreglo de punteros,[]tiene mayor prioridad que*, por lo tanto esto es un arreglo, y*modifica al arreglo, por lo tanto es un arreglo de punteros; los elementos del arreglo son punteros a enteros.

    Ejemplo:

    int main() {     
   char *str[3];     
   str[0] = "abc";     
   str[1] = "efg";     
   str[2] = "hij";     
   for (int i = 0; i < 3; ++i) {         
      printf("%s\n", str[i]);     
   } 
}

    Resultado:

    abc 
efg 
hij

    Puntero a arreglo:

    int (*a)[3]: De la misma manera, primero el paréntesis tiene la prioridad más alta, por lo que*aes un puntero, y[]modifica a*a, por lo tanto es un puntero a arreglo, un puntero a un arreglo unidimensional de 3 elementos.

    Ejemplo:

    typedef int arr[3]; 
int main() {     
   arr b = {1, 2, 3};     
   int (*a)[3] = &b;     
   arr *c = a;     
   for (int i = 0; i < 3; ++i) {         
      printf("%d\n", (*a)[i]);     
      
   } 
}

    Resultado:

    1 
2 
3

    Análisis:

    Aquí se usa typedef. Hemos definido un tipo de datos personalizado, que es un tipo de datos de arreglo. Su tipo de datos es un arreglo de tres elementos enteros.

    Definir un puntero a arreglo también tiene dos formas: una es usar el tipo de datos de arreglo que definimos arriba, y la otra es definirlo directamente.

    Arreglo de punteros:

    int *p1[3];

    Los corchetes [] tienen prioridad alta, por lo tanto se combinan primero con p1, lo que representa un arreglo. Este arreglo tiene 3 elementos, y estos 3 elementos son punteros que apuntan a datos de tipo int.

    Puntero a arreglo:

    int (*p2)[3];

    El paréntesis hace que p2 se combine con *, lo que indica que p2 es un puntero. Este puntero apunta a un arreglo, el cual tiene 3 elementos, y el tipo de cada elemento es int.
