Puntero a función

Un puntero a función es una variable puntero que apunta a una función.

Normalmente, cuando hablamos de variables puntero, nos referimos a variables que apuntan a un entero, un carácter, un arreglo, etc., mientras que un puntero a función apunta a una función.

Un puntero a función puede usarse como una función normal, para invocar funciones y pasar parámetros.

Declaración de un tipo de puntero a función:

typedef int (*fun_ptr)(int,int); // 声明一个指向同样参数、返回值的函数指针类型

Ejemplo

El siguiente ejemplo declara una variable puntero a función p, que apunta a la función max:

Ejemplo

#include <stdio.h> int max(int x, int y) { return x > y ? x : y; } int main(void) { /*p es un puntero a función*/ int (* p)(int, int) = & max; // & se puede omitir int a, b, c, d; printf("Por favor ingrese tres números:"); scanf("%d %d %d", & a, & b, & c); /*Equivalente a llamar directamente a la función, d = max(max(a, b), c)*/ d = p(p(a, b), c); printf("El número más grande es: %d\n", d); return 0; }

Compile y ejecute, el resultado de salida es el siguiente:

请输入三个数字:1 2 3
最大的数字是: 3

Función de devolución de llamada

Puntero a función como parámetro de una función

Una variable puntero a función puede usarse como parámetro de una función; una función de devolución de llamada es una función que se invoca a través de un puntero a función.

En términos simples: una función de devolución de llamada es una función que tú implementas y que es invocada cuando se ejecuta la función de otra persona.

La siguiente es una explicación de Chang Xiling, autor de Zhihu:

Vas a una tienda a comprar algo, justamente lo que quieres no está en stock, entonces le dejas tu número de teléfono al empleado. Unos días después la tienda tiene el artículo, el empleado te llama, y cuando recibes la llamada vas a la tienda a recogerlo. En este ejemplo, tu número de teléfono se llama función de devolución de llamada; dejarle el teléfono al empleado se llama registrar la función de devolución de llamada; que la tienda tenga el artículo después se llama disparar el evento asociado a la devolución de llamada; que el empleado te llame se llama invocar la función de devolución de llamada; y que tú vayas a la tienda a recoger el artículo se llama responder al evento de devolución de llamada.

    Una escritura más estándar que GCC puede compilar directamente; la variable puntero se maneja como variable puntero.

    #include <stdlib.h>
#include <stdio.h>

// 回调函数
void populate_array(int *array, int arraySize, int (*getNextValue)(void))
{
    int i;
    for(i=0; i<arraySize; i++){
        *(array+i) = getNextValue();
    }
}

// 获取随机值
int getNextRandomValue(void)
{
    return rand();
}

int main(void)
{
    int myarray[10];
    int i;
    populate_array(myarray, 10, getNextRandomValue);
    for(i=0; i<10; i++) {
        printf("%d ", myarray[i]);
    }
    printf("\n");
    return 0;
}

    Algunas reflexiones sobre funciones de devolución de llamada

    En la función A, se pasan los parámetros y la función C a la función B; la función B llama a la función C. La acción de llamar desde la función B se llama devolución de llamada, y la función C se llama función de devolución de llamada.

    Por ejemplo

    #include <stdio.h>

// 回调函数a
void callback_a(int var_a){    
    printf("Call callback_a, var: %d\n\n", var_a);
}

// 回调函数b
void callback_b(int var_b){    
    printf("Call callback_b, var: %d\n\n", var_b);
}

// 回调动作
void callback_act(int x, void (*callback) (int var)){    
    printf("Call callback_act, var_x: %d\n\n", x);    
    callback(x);
}


void main(){    
    int a = 1, b = 2;    
    callback_act(a, callback_a);    
    callback_act(b, callback_b);    
    printf("Main program has done.");
}

    Resultado de la ejecución:

    Call callback_act, var_x: 1
Call callback_a, var: 1
Call callback_act, var_x: 2
Call callback_b, var: 2
Main program has done.

    Si lo piensas detenidamente, el efecto de una función de devolución de llamada se puede lograr completamente con una función normal; de hecho, el mayor significado de las funciones de devolución de llamada es el desacoplamiento, reduciendo el acoplamiento entre códigos.

    Sobre size_t, vi la siguiente definición en vcruntime.h:

    // Definitions of common types
#ifdef _WIN64
    typedef unsigned __int64 size_t;
    typedef __int64          ptrdiff_t;
    typedef __int64          intptr_t;
#else
    typedef unsigned int     size_t;
    typedef int              ptrdiff_t;
    typedef int              intptr_t;
#endif

    Es decir, se determina si tu máquina es de 64 bits; si lo es:

    typedef unsigned __int64 size_t;

    Si no lo es:

    typedef unsigned int     size_t;

    Así que, en resumen, según los bits del sistema, será un int de 64 bits o un int de 32 bits.

    Además de almacenar diversos tipos de variables en la memoria, las funciones también se almacenan en la memoria al compilarse; por lo tanto, un puntero a función es un puntero que apunta a una función.

    Los punteros a función pueden realizar operaciones de funciones de devolución de llamada; a continuación se enumeran algunas operaciones comunes con punteros a función:

    // 函数指针示例 
#include <stdio.h>
#include <stdlib.h>
// 几个示例函数 
void print() { printf("哈哈哈\n"); } 
void print1() { printf("哈哈哈哈哈哈\n"); } 
int sum(int a, int b) { return a + b; } 
void printInt(int a) { printf("%d ", a); } 
int *pointer() { 
    int *a = (int *)malloc(sizeof(int)); 
    *a = 11; return a; 
} 
// 把函数指针作为函数参数传递（回调函数） 
// 函数声明（注意类型的表示） 
void traverse(int[], void (*)(int)); 
/// @brief 遍历数组元素（回调函数例子） 
/// @param array 数组 
/// @param callback 回调函数，无返回值，一个int参数 
void traverse(int array[], void (*callback)(int)) { 
    // 遍历前面3个用回调函数访问 
    int i; 
    for (i = 0; i < 3; i++) { 
        callback(array[i]); 
    } 
    printf("\n"); 
} 
// 函数返回函数指针 
// 返回一个返回值为int，带两个int参数的函数指针
// 函数本身名为fun，本身无参数 
int (*fun())(int, int) { return sum; } 
// 函数返回函数指针，带参数型 
// 返回一个返回值为void，不带参数的函数指针 
// 函数本身名为fun1，带一个int参数 
void (*fun1(int a))() { if (a == 1) { return print1; } return print; } 
int main() { 
    // 函数指针p：无参，返回类型void 
    // 让函数指针p指向print函数 
    void (*p)() = print; 
    //执行p 
    p(); 
    // 函数指针sp：两个int参数，返回类型int 
    // 让函数指针sp指向sum函数 
    int (*sp)(int, int); 
    // 执行sp 
    printf("%d\n", sum(1, 2)); 
    // 一个返回类型为指针的函数指针 
    // 把pointer赋值给函数指针ip 
    int *(*ip)() = pointer; printf("%d\n", *ip()); 
    // 一个长度为2的函数指针数组fp[2]，其中函数指针是void无参函数 
    void (*fp[2])(); 
    // 给函数指针数组中元素赋值 
    fp[0] = print; fp[1] = print1; 
    // 执行它们 
    fp[0](); fp[1](); 
    // 使用回调函数 
    int arr[] = {1, 2, 3}; traverse(arr, printInt); 
    // 执行返回函数指针的函数得到函数指针，将函数返回值赋值给函数指针getSum 
    int (*getSum)(int, int) = fun(); 
    printf("%d\n", getSum(3, 4)); 
    // 传参的返回函数指针的函数，下面两个分别赋值给函数指针pp1，pp2 
    void (*pp1)() = fun1(1); void (*pp2)() = fun1(0); 
    // 执行 
    pp1(); 
    pp2(); 
    // 输出函数指针类型变量的大小，可见使用"返回值 (*)(参数)"可以表示一个函数指针类型的指针变量 
    printf("%d %d %d\n", sizeof(void (*)()), sizeof(void (*)(int)), sizeof(int (*)())); return 0; 
}

    Mi punto de vista personal sobre la reflexión y la modificación de @comentario 5 y @comentario 8 es el siguiente:

    #include <stdio.h>

int sum(int num1, int num2){
    return num1 + num2;
}

//sum2调用sum函数
int sum2(int num3, int (*shapePara)(int, int), int num4, int num5){
    /*
        shapePara形式--函数参数名，名字不重要（与sum函数一致，亦可），
        实际的指向关系是shapePara --> callback_sum(可省,详见下面多行注释) --> sum,调用sum函数里面的功能;
    */
    return  num3 * shapePara(num4, num5);
}

int main()
{
    printf("SUM = %d\n", sum(1, 2));
    printf("SUM2(2倍的SUM) = %d\n", sum2(2, sum, 1, 2));
    /*
        函数指针的建立，以便回调使用
        int (*callback_sum)(int, int) = sum;（可省略，写成上面形式）
        printf("SUM2(2倍的SUM) = %d\n", sum2(2, callback_sum, 1, 2));  (功能相同)

        其次上面只用函数名sum，是作为函数指针，以便减少代码量。
    */
    return 0;
}
/*
    此外多提一嘴，以上代码采用顺序编写，所以无需进行事先的函数声明；
    否则，要将main函数后面的函数统统进行事先声明，不然会报错的；
