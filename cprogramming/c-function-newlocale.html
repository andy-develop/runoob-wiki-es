Funciones de la biblioteca C -newlocale()

Biblioteca estándar de C - <locale.h>

Descripción

newlocale()Es una función en la biblioteca estándar de C, utilizada para crear un nuevo objeto de localización. Esta función permite al programa crear una configuración regional específica, y puede modificarse o ampliarse basándose en la configuración regional existente.

Declaración

A continuación se muestra la declaración de la función newlocale().

#include <locale.h>

locale_t newlocale(int category_mask, const char *locale, locale_t base);

Parámetros

  • category_mask: una máscara de una o más categorías de localización a configurar. Puede ser una combinación de las siguientes macros (a través del operador OR bit a bit|combinadas):

    • LC_COLLATE_MASK: información de localización relacionada con la comparación de cadenas.
    • LC_CTYPE_MASK: información de localización relacionada con la clasificación y conversión de caracteres.
    • LC_MONETARY_MASK: información de localización relacionada con el formato de moneda.
    • LC_NUMERIC_MASK: información de localización relacionada con el formato numérico.
    • LC_TIME_MASK: información de localización relacionada con el formato de hora.
    • LC_MESSAGES_MASK: información de localización relacionada con la visualización de mensajes.
    • LC_ALL_MASK: todas las categorías de localización.

  • locale: una cadena que especifica el nombre de la configuración regional a establecer (por ejemplo, "en_US.UTF-8"). Si esNULL, se utilizará la configuración regional predeterminada.

  • base: unlocale_tobjeto existente, utilizado como base para crear el nuevo objeto de localización. Si esNULL, se crea un nuevo objeto desde cero.

Valor de retorno

  • En caso de éxito, devuelve el nuevo objeto de localización creado (de tipolocale_t）。
  • En caso de error, devuelveNULL。

Ejemplos

El siguiente es un código de ejemplo que utiliza newlocale() para crear y usar un nuevo objeto de localización:

Ejemplos

#include <stdio.h>
#include <locale.h>
#include <xlocale.h> // Se necesita cuando se usan extensiones GNU

int main() {
    // Crear un nuevo objeto de localización, utilizando la configuración regional "en_US.UTF-8"
    locale_t newloc = newlocale(LC_ALL_MASK, "en_US.UTF-8", (locale_t)0);
    if (newloc == (locale_t)0) {
        perror("newlocale");
        return 1;
    }

    // Establecer el objeto de localización del hilo actual al nuevo objeto de localización
    locale_t oldloc = uselocale(newloc);

    // Obtener e imprimir la información de localización actual
    struct lconv *lc = localeconv();
    printf("Decimal point character in new locale: %s\n", lc->decimal_point);
    printf("Thousands separator in new locale: %s\n", lc->thousands_sep);

    // Restaurar el objeto de localización anterior
    uselocale(oldloc);

    // Liberar el nuevo objeto de localización
    freelocale(newloc);

    return 0;
}

Compilemos y ejecutemos el programa anterior, esto producirá el siguiente resultado:

Decimal point character in new locale: .
Thousands separator in new locale: ,

Análisis de código

Crear un nuevo objeto de localización

  • newlocale(LC_ALL_MASK, "en_US.UTF-8", NULL): crear un nuevo objeto de localización, utilizando la configuración regional "en_US.UTF-8", basado en el objeto de localización predeterminado.
  • newlocale(LC_NUMERIC_MASK | LC_TIME_MASK, "fr_FR.UTF-8", NULL): crear un nuevo objeto de localización, configurando los formatos numérico y de hora como "fr_FR.UTF-8" (francés - Francia), y usando la configuración predeterminada para las demás categorías.

Configurar el objeto de localización del hilo

  • Usaruselocale(newloc)para establecer el objeto de localización del hilo actual como el nuevo objeto de localización creado.
  • Usaruselocale(oldloc)para restaurar el objeto de localización anterior.

Liberar el objeto de localización

  • Usarfreelocale(newloc)para liberar el nuevo objeto de localización creado, evitando fugas de memoria.

Notas

  • newlocale()Es parte del estándar POSIX.1-2008, no es compatible con todas las plataformas. Si se utiliza la biblioteca GNU C, asegúrese de incluir<xlocale.h>el archivo de cabecera.
  • newlocale()El objeto devueltolocale_tpuede pasarse auselocale()función, para usar temporalmente una configuración regional diferente en el hilo.

Resumen

newlocale()La función permite crear y usar nuevos objetos de localización, de modo que el programa pueda manejar diferentes configuraciones regionales y necesidades de localización. Al combinarnewlocale()、uselocale()yfreelocale()la función, los programadores pueden gestionar y alternar la información de localización del programa de manera más flexible, apoyando así el desarrollo de aplicaciones internacionales.
