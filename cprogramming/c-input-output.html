C Entrada y salida

Cuando hablamos deentrada, esto significa que hay que introducir algunos datos al programa. La entrada puede realizarse en forma de archivo o desde la línea de comandos. El lenguaje C proporciona una serie de funciones integradas para leer la entrada dada y completar el programa según sea necesario.

Cuando hablamos desalida, esto significa que hay que mostrar algunos datos en la pantalla, en una impresora o en cualquier archivo. El lenguaje C proporciona una serie de funciones integradas para enviar datos a la pantalla del ordenador y guardar datos en archivos de texto o archivos binarios.

Archivos estándar

El lenguaje C trata todos los dispositivos como archivos. Por lo tanto, los dispositivos (como el monitor) se manejan de la misma manera que los archivos. Los siguientes tres archivos se abren automáticamente cuando el programa se ejecuta para acceder al teclado y a la pantalla.

Archivo estándarPuntero de archivoDispositivo
Entrada estándarstdinTeclado
Salida estándarstdoutPantalla
Error estándarstderrSu pantalla

El puntero de archivo es la forma de acceder a los archivos. Esta sección explicará cómo leer valores desde el teclado y cómo mostrar los resultados en la pantalla.

La E/S (entrada/salida) en C generalmente utilizaprintf()yscanf()dos funciones.

La función scanf() se utiliza para leer y formatear desde la entrada estándar (teclado), y la función printf() envía la salida formateada a la salida estándar (pantalla).

Función printf()

La función printf() se utiliza para enviar datos formateados al dispositivo de salida estándar (normalmente la pantalla).

Sintaxis:

int printf(const char *format, ...);

Parámetros:

  • format: cadena de formato, especifica el formato de salida.

  • ...: lista de argumentos variables, proporciona los datos a enviar según los especificadores de formato en la cadena de formato.

Ejemplo

#include <stdio.h>// Se necesita esta biblioteca para ejecutar la función printf() int main() { printf("Tutorial para novatos"); // Muestra el contenido entre comillas return 0; }

Tutorial para principiantes

  • Todos los programas en C necesitan incluir lamain()función. El código comienza a ejecutarse desde lamain()función.
  • printf()Se utiliza para enviar salida formateada a la pantalla.printf()La función está declarada en el"stdio.h"archivo de cabecera.
  • stdio.hes un archivo de cabecera (archivo de cabecera de entrada/salida estándar) y#includees un comando de preprocesamiento que se utiliza para incluir el archivo de cabecera.printf()función, si no se encuentra elstdio.harchivo de cabecera, se producirá un error de compilación.
  • return 0;La declaración se utiliza para indicar la salida del programa.

%d formatea la salida de enteros

#include <stdio.h> int main() { int testInteger = 5; printf("Number = %d", testInteger); return 0; }

Al compilar el programa anterior, el resultado de salida es:

Number = 5

En las comillas de la función printf(), use "%d" (entero) para hacer coincidir la variable entera testInteger y mostrarla en la pantalla.

Función scanf()

La función scanf() se utiliza para leer entrada formateada desde el dispositivo de entrada estándar (normalmente el teclado).

Sintaxis:

int scanf(const char *format, ...);

Parámetros:

  • format: cadena de formato, especifica el formato de entrada.

  • ...: lista de argumentos variables, proporciona las direcciones de las variables que almacenan los datos de entrada según los especificadores de formato en la cadena de formato.

Ejemplo

#include <stdio.h>

int main() {
    int a;
    float b;
    printf("Enter an integer and a float: ");
    scanf("%d %f", &a, &b);
    printf("You entered: %d and %.2f\n", a, b);
    return 0;
}

Ejecute el código anterior y luego ingrese:

10 3.14

Salida:

You entered: 10 and 3.14

Entrada y salida de caracteres

Funciones getchar() y putchar()

int getchar(void)La función lee el siguiente carácter disponible desde la pantalla y lo devuelve como un entero. Esta función solo lee un único carácter a la vez. Puede usar este método dentro de un bucle para leer varios caracteres desde la pantalla.

int putchar(int c)La función envía el carácter a la pantalla y devuelve el mismo carácter. Esta función solo emite un único carácter a la vez. Puede usar este método dentro de un bucle para enviar varios caracteres a la pantalla.

Vea el siguiente ejemplo:

Ejemplo

#include <stdio.h> int main( ) { int c; printf( "Enter a value :"); c = getchar( ); printf( "\nYou entered: "); putchar( c ); printf( "\n"); return 0; }

Cuando el código anterior se compila y ejecuta, esperará a que usted ingrese algún texto. Cuando ingresa un texto y presiona la tecla Intro, el programa continúa y solo leerá un único carácter, como se muestra a continuación:

$./a.out
Enter a value :runoob

You entered: r

Entrada y salida de cadenas

Funciones gets() y fgets()

La función gets() se utiliza para leer una línea de cadena desde el dispositivo de entrada estándar, pero no se recomienda su uso porque es propensa a provocar desbordamiento del búfer. Se recomienda usarfgets()la función.

Sintaxis:

char *fgets(char *str, int n, FILE *stream);

Parámetros:

  • str: puntero a un arreglo de caracteres, utilizado para almacenar la cadena leída.

  • n: número máximo de caracteres a leer (incluido el carácter nulo\0）。

  • stream: flujo de archivo, generalmente se usastdinpara representar la entrada estándar.

Ejemplo

#include <stdio.h>

int main() {
    char str[100];
    printf("Enter a string: ");
    fgets(str, sizeof(str), stdin);
    printf("You entered: %s", str);
    return 0;
}

Función puts()

La función puts() se utiliza para enviar una cadena al dispositivo de salida estándar y agrega automáticamente un salto de línea al final.

Sintaxis:

int puts(const char *str);

Parámetros:

  • str: la cadena a enviar.

Valor de retorno:

  • Devuelve un valor no negativo en caso de éxito y, en caso de error, devuelveEOF。

Ejemplo

#include <stdio.h>

int main() {
    char str[] = "Hello, World!";
    puts(str);
    return 0;
}

Salida:

Hello, World!

Función fputs()

La función fputs() se utiliza para enviar una cadena a un flujo especificado (como la salida estándar, archivos, etc.), pero no agrega automáticamente un salto de línea al final de la cadena.

Sintaxis:

int fputs(const char *str, FILE *stream);

Parámetros:

  • str: la cadena a enviar (un arreglo de caracteres terminado en carácter nulo\0).

  • stream: el flujo de salida especificado, puede ser la salida estándar (stdout), un flujo de archivo, etc.

Valor de retorno:

  • Devuelve un valor no negativo en caso de éxito (normalmente el número de caracteres enviados).

  • En caso de error, devuelveEOF。

Características:

  1. Sin salto de línea：fputs()No agrega automáticamente un salto de línea después de la cadena de salida.

  2. Flujo de salida flexible：fputs()Puede enviar la salida a cualquier flujo, como la salida estándar, archivos, etc.

Ejemplo

#include <stdio.h>

int main() {
    char str[] = "Hello, World!";
    fputs(str, stdout);  // Imprime "Hello, World!" sin salto de línea
    return 0;
}

Funciones scanf() y printf()

int scanf(const char *format, ...)La función desde el flujo de entrada estándarstdinlee la entrada y, según elformatformato proporcionado, explora la entrada.

int printf(const char *format, ...)La función escribe la salida en el flujo de salida estándarstdout y genera la salida según el formato proporcionado.

formatPuede ser una simple cadena constante, pero puede especificar %s, %d, %c, %f, etc., para generar o leer cadenas, enteros, caracteres o números de punto flotante, respectivamente. Hay muchas otras opciones de formato disponibles que puede usar según sea necesario. Para conocer todos los detalles, puede consultar los manuales de referencia de estas funciones. Ahora, aclaremos nuestra comprensión con el siguiente ejemplo sencillo:

Ejemplo

#include <stdio.h> int main( ) { char str[100]; int i; printf( "Enter a value :"); scanf("%s %d", str, &i); printf( "\nYou entered: %s %d ", str, i); printf("\n"); return 0; }

Cuando el código anterior se compila y ejecuta, esperará a que usted ingrese algún texto. Cuando ingresa un texto y presiona la tecla Intro, el programa continúa y lee la entrada, como se muestra a continuación:

$./a.out
Enter a value :runoob 123

You entered: runoob 123

Aquí, debe señalarse que scanf() espera que el formato de entrada sea el mismo que los %s y %d que usted proporciona, lo que significa que debe proporcionar una entrada válida, como "string integer". Si proporciona "string string" o "integer integer", se considerará una entrada incorrecta. Además, al leer una cadena, scanf() deja de leer en cuanto encuentra un espacio, por lo que "this is test" son tres cadenas para scanf().

Entrada y salida de archivos

El lenguaje C también proporciona funciones de entrada y salida de archivos, que permiten leer datos de un archivo o escribir datos en un archivo.

Función fopen()

Sintaxis:

FILE *fopen(const char *filename, const char *mode);

Parámetros:

  • filename: el nombre del archivo a abrir.

  • mode: el modo de abrir el archivo, como"r"(solo lectura),"w"(solo escritura),"a"(añadir), etc.

Valor de retorno:

  • En caso de éxito, devuelve un puntero alFILEobjeto; en caso de fallo, devuelveNULL。

Función fclose()

La función fclose() se utiliza para cerrar un archivo que ya está abierto.

Sintaxis:

int fclose(FILE *stream);

Parámetros:

  • stream: puntero alFILEobjeto.

Valor de retorno:

  • En caso de éxito, devuelve0; en caso de fallo, devuelveEOF。

Ejemplo

#include <stdio.h>

int main() {
    FILE *file;
    file = fopen("example.txt", "w");
    if (file != NULL) {
        fprintf(file, "Hello, world!\n");
        fclose(file);
    }

    char buffer[100];
    file = fopen("example.txt", "r");
    if (file != NULL) {
        fgets(buffer, sizeof(buffer), file);  // Lee una línea completa
        printf("Read from file: %s", buffer);  // fgets conserva el carácter de nueva línea
        fclose(file);
    }
    return 0;
}

Contenido de salida:

Read from file: Hello, world!
