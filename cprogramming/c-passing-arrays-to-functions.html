C Pasar arrays a funciones

C Arrays

Si desea pasar un array unidimensional como argumento a una función, debe declarar los parámetros formales de la función de las siguientes tres maneras. Los resultados de estas tres declaraciones son los mismos, porque cada una le indica al compilador que recibirá un puntero a entero. Del mismo modo, también puede pasar un array multidimensional como parámetro formal.

Método 1

El parámetro formal es un puntero (podrá aprender sobre punteros en el próximo capítulo):

void myFunction(int *param) { . . . }

Método 2

El parámetro formal es un array de tamaño definido:

void myFunction(int param[10]) { . . . }

Método 3

El parámetro formal es un array de tamaño indefinido:

void myFunction(int param[]) { . . . }

Ejemplo

Ahora, veamos la siguiente función que toma un array como parámetro y además pasa otro parámetro. Según el parámetro pasado, devuelve el promedio de los elementos del array:

double getAverage(int arr[], int size) { int i; double avg; double sum; for (i = 0; i < size; ++i) { sum += arr[i]; } avg = sum / size; return avg; }

Ahora, llamemos a la función anterior de la siguiente manera:

Ejemplo

#include <stdio.h> /*Declaración de la función*/ double getAverage(int arr[], int size); int main () { /*Array de enteros con 5 elementos*/ int balance[5] = {1000, 2, 3, 17, 50}; double avg; /*Pasar un puntero al array como argumento*/ avg = getAverage( balance, 5 ) ; /*Salida del valor devuelto*/ printf( "El promedio es: %f", avg ); return 0; } double getAverage(int arr[], int size) { int i; double avg; double sum=0; for (i = 0; i < size; ++i) { sum += arr[i]; } avg = sum / size; return avg; }

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

平均值是： 214.400000

Puede ver que, en lo que respecta a la función, la longitud del array es irrelevante, porque C no realiza comprobación de límites en los parámetros formales.

    Pasar un array bidimensional a una función

    Si queremos pasar un array bidimensional como argumento real a una función, el siguiente código tiene problemas:

    double * MatrixMultiple(double a[][], double b[][]);

    La razón se puede entender simplemente como: el compilador no es tan avanzado; para arrays de más de dos dimensiones, se debe especificar la dimensión máxima:

    double * MatrixMultiple(double a[][2], double b[][3]);  /* 这才是正确的 */

    Pasar un array bidimensional a una función

    Enumere los métodos para pasar arrays bidimensionales en C.

    Método 1: La longitud de la primera dimensión puede no especificarse, pero se debe especificar la longitud de la segunda dimensión:

    void print_a(int a[][5], int n, int m)

    Método 2: Un puntero a un array unidimensional de 5 elementos:

    void print_b(int (*a)[5], int n, int m)

    Método 3: Aprovechando la característica de que los arrays se almacenan secuencialmente, ¡acceda al array original reduciendo la dimensión!

    void print_c(int *a, int n, int m)

    Si se conoce la longitud del array bidimensional, por supuesto se elige el primer o segundo método, pero cuando la longitud no es segura, solo se puede pasar el tamaño del array para recorrer los elementos.

    #include <stdio.h>
/*********************************
* 方法1: 第一维的长度可以不指定
*        但必须指定第二维的长度
*********************************/ 
void print_a(int a[][5], int n, int m){ 
    int i, j;
    for(i = 0; i < n; i++) {
        for(j = 0; j < m; j++) 
            printf("%d ", a[i][j]); 
        printf("\n"); 
    } 
} 

/***************************************** 
* 方法2: 指向一个有5个元素一维数组的指针
*****************************************/ 
void print_b(int (*a)[5], int n, int m) { 
    int i, j;
    for(i = 0; i < n; i++) { 
        for(j = 0; j < m; j++) 
            printf("%d ", a[i][j]);
        printf("\n"); 
    } 
}

/*********************************** 
* 方法3: 利用数组是顺序存储的特性, 
*       通过降维来访问原数组!
***********************************/ 
void print_c(int *a, int n, int m) { 
    int i, j; 
    for(i = 0; i < n; i++) { 
        for(j = 0; j < m; j++) 
            printf("%d ", *(a + i*m + j));
        printf("\n"); 
    } 
}
int main(void) 
{ 
    int a[5][5] = {{1, 2}, {3, 4, 5}, {6}, {7}, {0, 8}}; 

    printf("\n方法1:\n");   
    print_a(a, 5, 5); 

    printf("\n方法2:\n");   
    print_b(a, 5, 5);   

    printf("\n方法3:\n");   
    print_c(&a[0][0], 5, 5); 

//    getch(); 
    return 0; 
}

    Usar arrays como parámetros para calcular el promedio:

    #include<stdio.h>

double outputs(float arr2[],int size);  //声明一个求平均数的函数

int main()
{
    int k;
    printf("你想求几个数的平均数：");
    scanf("%d",&k);
    int arr1[k];              // 创建一个存放k个数的一维数组
    for(int n = 0;n < k;n++)    // 使用 for 循环依次向数组添加元素
    {
        printf("请输入第%d个数：",n+1);
        scanf("%f",&arr1[n]);
    }
    printf("平均数为：%.4f\n",outputs(arr1,k));  // 向平均数函数赋值并输出结果（保留4位小数）
}
double outputs(float arr2[],int size)    // 定义平均数函数并传值
{
    double sum = 0;
    for(int i = 0;i < size;i++)   // 使用 for 循环求和
    {
        sum += arr2[i];
    }
    return sum/size;       // 返回平均值
}

    Cuando un array se usa como parámetro de entrada de una función, es mejor incluir su longitud.

    1. El resultado de sizeof con el array como parámetro de entrada es el tamaño del puntero al tipo de elemento del array.

    void getSize(int a[]){
  int i;
  i=sizeof(a);//这里的i在linux中是4，在Windows中也是4，是int *的大小，不管你传入的a有几个元素
  int b;
  b=sizeof(a)/sizeof(a[0]);//逻辑没错，a的大小除以元素的大小得到长度，可是sizeof(a)并不是数组占的空间，而是指针,也就是i
}
int main(){
  int a[]={1,2,3,4,5};
  getSize(a);
}

    2. Manejo

  //int i;

  int k = size;//已经保存入参大小
