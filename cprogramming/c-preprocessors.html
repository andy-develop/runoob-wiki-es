C Preprocesador

Preprocesador de C (CPP)Es una etapa independiente en el proceso de compilación, antes dela compilación realRealiza el procesamiento de texto del código fuente. Las funciones principales incluyen:

  • Expansión de macros
  • Inclusión de archivos
  • Compilación condicional
  • Procesamiento de directivas especiales

El preprocesador de CNo es parte del compilador, pero es un paso separado en el proceso de compilación.

En resumen, el preprocesador de C no es más que una herramienta de reemplazo de texto; indica al compilador que realice el preprocesamiento necesario antes de la compilación real.

Abreviaremos el preprocesador de C (C Preprocessor) como CPP.

Todos los comandos del preprocesador comienzan con el símbolo de almohadilla#al principio. Debe ser el primer carácter que no sea un espacio en blanco. Para mejorar la legibilidad, las directivas del preprocesador deben comenzar en la primera columna.

A continuación se enumeran todas las directivas importantes del preprocesador:

Ejemplo de preprocesador

Analiza el siguiente ejemplo para comprender las diferentes directivas.

#define MAX_ARRAY_LENGTH 20

Esta directiva le indica a CPP que defina todas las MAX_ARRAY_LENGTH como 20. Use#definela definición de constantes para mejorar la legibilidad.

#include <stdio.h>
#include "myheader.h"

Estas directivas le indican a CPP que obtenga dela biblioteca del sistemaobtenga stdio.h, y agregue el texto al archivo fuente actual. La siguiente línea le indica a CPP que obtenga del directorio localmyheader.h, y agregue su contenido al archivo fuente actual.

#undef  FILE_SIZE
#define FILE_SIZE 42

Esta directiva le indica a CPP que cancele la definición de FILE_SIZE y lo defina como 42.

#ifndef MESSAGE
   #define MESSAGE "You wish!"
#endif

Esta directiva le indica a CPP que defina MESSAGE solo si MESSAGE no está definido.

#ifdef DEBUG
   /* Your debugging statements here */
#endif

Esta directiva le indica a CPP que, si DEBUG está definido, ejecute las declaraciones de procesamiento. Al compilar, si le pasa al compilador gcc-DDEBUGel indicador, esta directiva es muy útil. Define DEBUG y usted puede activar o desactivar la depuración en cualquier momento durante la compilación.
