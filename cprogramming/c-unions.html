C Unión

UniónEs un tipo de datos especial que le permite almacenar diferentes tipos de datos en la misma ubicación de memoria. Puede definir una unión con varios miembros, pero en cualquier momento solo un miembro puede tener un valor. La unión proporciona una forma eficiente de utilizar la misma ubicación de memoria.

Definir una unión

Para definir una unión, debe utilizarunionla declaración `union`, de manera similar a la definición de estructuras. La declaración `union` define un nuevo tipo de datos con varios miembros. El formato de la declaración `union` es el siguiente:

union [union tag] { member definition; member definition; ... member definition; } [one or more union variables];

union tagEl `tag` es opcional; cada `member definition` es una definición de variable estándar, por ejemplo `int i;` o `float f;` u otra definición de variable válida. Al final de la definición de la unión, antes del último punto y coma, puede especificar una o más variables de la unión; esto es opcional. A continuación se define un tipo de unión llamado `Data` con tres miembros `i`, `f` y `str`:

union Data { int i; float f; char str[20]; } data;

Ahora,Data` ocupa 20 bytes), en lugar de 4+4+20=28 bytes cada una.

La memoria ocupada por una unión debe ser suficiente para almacenar el miembro más grande de la unión. Por ejemplo, en el ejemplo anterior, `Data` ocupará 20 bytes de espacio de memoria, porque entre los miembros, la cadena es la que ocupa más espacio. El siguiente ejemplo mostrará el tamaño total de memoria que ocupa la unión anterior:

Ejemplo

#include <stdio.h> #include <string.h> union Data { int i; float f; char str[20]; }; int main( ) { union Data data; printf( "Memory size occupied by data : %d\n", sizeof(data)); return 0; }

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

Memory size occupied by data : 20

Acceder a los miembros de la unión

Para acceder a los miembros de la unión, utilizamosel operador de acceso a miembros (`.`). El operador de acceso a miembros es un punto entre el nombre de la variable de la unión y el miembro de la unión al que queremos acceder. Puede utilizarunionla palabra clave `union` para definir variables del tipo de unión. El siguiente ejemplo demuestra el uso de la unión:

Ejemplo

#include <stdio.h> #include <string.h> union Data { int i; float f; char str[20]; }; int main( ) { union Data data; data.i = 10; data.f = 220.5; strcpy( data.str, "C Programming"); printf( "data.i : %d\n", data.i); printf( "data.f : %f\n", data.f); printf( "data.str : %s\n", data.str); return 0; }

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

data.i : 1917853763
data.f : 4122360580327794860452759994368.000000
data.str : C Programming

Aquí, podemos ver que los valores de los miembros de la unióni 和 festán dañados, porque el último valor asignado a la variable ocupó la ubicación de memoria; esta es tambiénstrla razón por la que el miembro puede mostrarse correctamente.

Ejemplo

#include <stdio.h> #include <string.h> union Data { int i; float f; char str[20]; }; int main( ) { union Data data; data.i = 10; printf( "data.i : %d\n", data.i); data.f = 220.5; printf( "data.f : %f\n", data.f); strcpy( data.str, "C Programming"); printf( "data.str : %s\n", data.str); return 0; }

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

data.i : 10
data.f : 220.500000
data.str : C Programming

Aquí, todos los miembros pueden mostrarse correctamente, porque solo se usa un miembro a la vez.

    Función de la unión

    Ahorra memoria: hay dos estructuras de datos muy largas que no se usan al mismo tiempo, por ejemplo, una que representa a un profesor y otra a un estudiante. Si se quiere registrar la información de profesores y estudiantes usando estructuras, ¡sería un desperdicio! Con una unión, basta con ocupar el espacio que ocupa la estructura de datos más larga.

    Escenarios de aplicación de la unión

    Los paquetes de datos en las comunicaciones utilizan uniones: como no se sabe qué tipo de paquete enviará la otra parte, con una unión es muy sencillo: se definen varios formatos de paquete y, después de recibir el paquete, se pueden extraer los datos directamente según el formato del paquete.

data=0x01020304;

    Después de ver los cálculos del tamaño de ocupación de memoria de los anteriores, ninguno analiza el punto clave. A continuación se dan algunos conceptos:

    • Bit:El bit es la unidad de datos más pequeña en una computadora electrónica. Cada bit solo puede tener el estado 0 o 1.
    • Byte:8 bits binarios forman 1 byte. El byte es la unidad básica de medida del espacio de almacenamiento. 1 byte puede almacenar 1 letra inglesa o medio carácter chino; en otras palabras, 1 carácter chino ocupa 2 bytes de espacio de almacenamiento.
    • Palabra:Una "palabra" está formada por varios bytes; el número de bits de una palabra se llama longitud de palabra, y máquinas de diferentes niveles tienen diferentes longitudes de palabra. Por ejemplo, en una máquina de 8 bits, 1 palabra equivale a 1 byte y la longitud de palabra es de 8 bits. Si es una máquina de 16 bits, entonces 1 palabra se compone de 2 bytes y la longitud de palabra es de 16 bits. La palabra es la unidad con la que la computadora realiza el procesamiento de datos y los cálculos.
    • Las computadoras comunes ya han llegado a ser máquinas de 64 bits, es decir, una unidad básica es de 64 bits, o sea 8 bytes. Así, combinando el análisis anterior, no es difícil ver que en la definición de estructuras, uniones y campos de bits, la memoria se asigna en orden; si el tamaño que ocupa el siguiente campo supera la parte restante de la unidad de memoria ocupada por el campo anterior, entonces solicitará la siguiente unidad de memoria, y la parte sobrante del campo anterior quedará vacía.

    Complementando el comentario anterior;

    La memoria ocupada por la unión no es 9 chars, es decir, 9 bytes, sino el doble de double, es decir, 16 bytes, y además cada salida es el valor más cercano que le precede.

    Nota complementaria:Esto se debe a la alineación de bytes.

    Principios de alineación:

    • 【Principio 1】Regla de alineación de miembros de datos: el primer miembro de datos de una estructura (struct) (o unión (union)) se coloca en el offset 0; a partir de entonces, la alineación de cada miembro de datos se realiza según el valor más pequeño entre el valor especificado por `#pragma pack` y la longitud de ese miembro de datos.
    • 【Principio 2】Regla de alineación general de la estructura (o unión): después de que los miembros de datos completen su respectiva alineación, la estructura (o unión) en sí también debe alinearse; la alineación se realizará según el valor más pequeño entre el valor especificado por `#pragma pack` y la longitud del miembro de datos más grande de la estructura (o unión).
    • 【Principio 3】Estructura como miembro: si una estructura contiene ciertos miembros de tipo estructura, el miembro de tipo estructura debe comenzar a almacenarse en una dirección que sea múltiplo entero del tamaño de su elemento interno más grande.
    union Data{
    int i;
    float f;
    char str[9];
    double d;
}data;

    Según el principio 2, en VS el valor predeterminado es `#pragma park(8)`, y `char

    8<9;

    Según un múltiplo de 8 y >9, se toma como 16;
