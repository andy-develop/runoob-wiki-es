C# Enumeración (Enum)

Una enumeración es un conjunto de constantes enteras con nombre. El tipo de enumeración se declara utilizando laenumpalabra clave enum.

Las enumeraciones de C# son tipos de valor. En otras palabras, la enumeración contiene sus propios valores y no puede heredar ni transmitir herencia.

DeclaraciónenumVariable

La sintaxis general para declarar una enumeración es:

enum <enum_name>
{ 
    enumeration list 
};

Donde,

  • enum_nameespecifica el nombre de tipo de la enumeración.
  • enumeration listes una lista de identificadores separados por comas.

Cada símbolo en la lista de enumeración representa un valor entero, un valor entero mayor que el símbolo que le precede. Por defecto, el valor del primer símbolo de enumeración es 0. Por ejemplo:

enum Days { Sun, Mon, tue, Wed, thu, Fri, Sat };

Ejemplo

El siguiente ejemplo demuestra el uso de variables de enumeración:

Ejemplo

using System;

public class EnumTest
{
    enum Day { Sun, Mon, Tue, Wed, Thu, Fri, Sat };

    static void Main()
    {
        int x = (int)Day.Sun;
        int y = (int)Day.Fri;
        Console.WriteLine("Sun = {0}", x);
        Console.WriteLine("Fri = {0}", y);
    }
}

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

Sun = 0
Fri = 5

    using System;
namespace EnumApplication
{
    class EnumProgram
    {
        enum Days {
            Mon=71, 
            tue=61, 
            Wed=51, 
            thu=41, 
            Fri=51, 
            Sat=61, 
            Sun=71

        static void Main(string[] args)
        {
            int WeekdayStart = (int)Days.Mon;
            int WeekdayEnd = (int)Days.Fri;

            Console.WriteLine("Friday: {0}", WeekdayEnd);
            Console.ReadKey();
        }
    }
}

    Monday: 71
Friday: 51

    La enumeración se usa para dar significado a las posiciones de índice específicas en una matriz, lo que hace que el programa sea más fácil de leer y modificar.

    enum len  { Length, width, height};

static void Main(string[] args)
{
    int[] parameter = new int[3] {1,5,8};
    Console.WriteLine("Length: {0}", parameter[(int)len.Length]);
    Console.WriteLine("width: {0}", parameter[(int)len.width]);
    Console.WriteLine("height: {0}", parameter[(int)len.height]);
}

    En este momento, se puede ver de un vistazo que el valor impreso corresponde al largo, ancho y alto de los parámetros.

    En comparación con el uso de

    #define length 0
#define width  1
#define height 2

    Este método es más conveniente al insertar un parámetro:

    #define area   0
#define length 1
#define width  2
#define height 3

enum len  {area, Length, width, height};

    Obviamente, usar el método Enum es más fácil de modificar.

    Enumeración de marcas de bits (flags enumeration)

    En la realidad no siempre se usan enumeraciones de valores discretos. Tomando como ejemplo los 7 días de la semana, supongamos que se pide al usuario de la aplicación que especifique cualquier combinación de días de la semana; entonces se puede usar una "enumeración de marcas de bits". Al usar una enumeración de marcas de bits, se pueden crear nuevos valores combinados mediante la operación OR. Tomando los días de la semana como ejemplo, el método de declaración es el siguiente:

    [Flags]
public enum Days
{
    None = 0,
    Sunday = 0x01,          //0000 0001
    Monday = 0x02,          //0000 0010
    Tuesday = 0x04,         //0000 0100
    Wednesday = 0x08,       //0000 1000
    Thursday = 0x10,        //0001 0000
    Friday = 0x20,          //0010 0000
    Saturday = 0x40,        //0100 0000
    Weekend = Sunday | Saturday,     //0100 0001
    Workdays = Monday | Tuesday | Wednesday | Tuesday | Friday, //0011 1110
}

    Para que los valores de la enumeración de marcas de bits puedan combinarse, todos los valores deben ser potencias de 2. Porque al combinar múltiples valores, se debe poder determinar a qué valor discreto corresponde el resultado.

    En una enumeración simple, se puede hacer que el nombre None o el nombre predeterminado más común corresponda a 0, pero la enumeración de marcas de bits requiere que 0 corresponda al nombre None; este valor significa que ninguna marca está establecida.

    Ejecutar:

    Days days = Days.Weekend;
Console.WriteLine("{0} : {1}",days,(int)days);

    Resultado de salida:

    Weekend : 65

    Cada símbolo en la lista de enumeración representa un valor entero, un valor entero mayor que el símbolo que le precede. Por defecto, el valor del primer símbolo de enumeración es 0. Pero también puedes establecer el valor de cada símbolo. Si no estableces el valor del símbolo n, su valor será el del símbolo (n-1)+1. Por ejemplo: si el símbolo de enumeración es g, su valor será el valor del símbolo f + 1, pero como no se conoce el valor de f, buscará el valor del (n-1), es decir, el valor de e, y así sucesivamente. Encuentra que el valor de c es 1, e=c+1=2, f=e+1=3, g=f+1=4;

    using System;

class Program
{
    enum Day  {a=8,b,c=1,e,f,g};
    static void Main(string[] args)
    {
            int a = (int)Day.a;//8
            int x = (int)Day.b;//9
            int c = (int)Day.c;//1
            int b = (int)Day.e;//2
            int g = (int)Day.g;//4
    }
}

    Por defecto, el valor del primer símbolo de enumeración es 0.

    using System;

class Program
{
    enum Day  { a, b, c, e = 1, f, g };
    static void Main(string[] args)
    {

            int x = (int)Day.b;//1
            int c = (int)Day.c;//2
            int b = (int)Day.e;//1
            int g = (int)Day.g;//3
    }

    Cada número en la enumeración es de tipo entero. Si no se asigna valor a ningún elemento, por defecto comienza desde 0 y crece de 1 en 1. Si se asignan todos los valores, no hace falta decirlo porque el compañero que compartió la nota anterior ya habló de este caso. Quiero hablar sobre el caso de asignar valores a elementos internos de la lista de enumeración (elementos que no son ni el primero ni el último). Tomando el enésimo elemento de la lista y asignándole el valor a, el resultado de ejecución es Mon=1, Fri=22. Por lo tanto, se puede ver que antes del elemento asignado, se sigue la regla de asignación predeterminada: comienza desde 0 y crece con incremento de 1 hasta la posición N-1. Pero a partir de la posición N asignada, con su valor a como punto de partida, el incremento es 1, es decir: a+1, a+2, a+3...

    using System;
public class EnumTest
{
    enum Day {  Sun, Mon, Tue=19, Wed, Thu, Fri, Sat };  /*列举其中的元素*/
    static void Main()
    {
        int x = (int)Day.Mon;
        int y = (int)Day.Fri;
        Console.WriteLine("Mon = {0}", x);   /*一般数组中默认的数值第一个就是0，其后是一次增大的，但是也是可以对数组中的每个元素进行赋值*/
        Console.WriteLine("Fri = {0}", y);
        Console.ReadKey();
    }
}

    • La enumeración es un tipo
    • Es adecuada para datos con un rango de valores limitado. Por ejemplo: solo quiero el rango de valores de estas cuatro opciones: primavera, verano, otoño e invierno. Si se usa string, no se puede fijar el rango de valores.
    • Sintaxis de enumeración: [modificador de acceso] enum NombreDeEnumeración { ValorDeEnumeración }
    • El modificador de acceso de la enumeración es igual que el de las clases; el acceso predeterminado, igual que en las clases, es internal.
    • El nombre de la enumeración sigue la convención de nomenclatura PascalCase.
    • Cada valor de la enumeración es de tipo entero y, por defecto, comienza desde 0.

    Las características anteriores ya han sido mencionadas en las notas de arriba; además, hay dos puntos más:

    • 1. Los valores de los elementos de la enumeración pueden establecerse iguales, pero no se recomienda.
    • 2. El tipo de valor predeterminado de los elementos de la enumeración es int; se puede cambiar a otros tipos enteros: byte, sbyte, short, ushort, int, uint, long y ulong.
    public enum Season_1
{
    spring_1 = 3,  //3
    sunmmer_1,     //4
    autumn_1 = 3,  //3
    winter_1       //4

    sunmmer_2, //1
    autumn_2,  //2
    winter_2   //3
}

{
    static void Main(string[] args)
    {
      Season_1 s2 = Season_1.autumn_1;
      Console.WriteLine(s2);  //显示spring_1，而不是autumn_1的原因是spring_1和autumn_1都是3，从前往后                                  //第一个3是spring_1，所以就输出spring_1
      Season_1 s3 = Season_1.spring_1;
        Console.WriteLine(s2 == s3);  //结果是true，表明spring_1和autumn_1是一样的
    }

    1. La enumeración se puede declarar y referenciar directamente en la clase, como hace el autor.

    public class EnumTest
{   
  enum Day { Sun, Mon, Tue, Wed, Thu, Fri, Sat };
}

    2. También se puede usar fuera de la clase.

    public enum CustomType  // 如果是类外写，按照命名规则我们最好在后边加上 Type 字样
{
  Sun = -1,  // 如同文中所说，默认为 0，但我们可以改成我们自己想要的 
  Mon, 
  Tue, 
  Wed = 10,  // 当然我们也可以不按照规则，给他主动往上加、往下减，都是可以的
  Thu = -5, 
  Fri, 
  Sat
}
public class EnumTest
{   
  CustomType Day  = CustomType.Sun;
}

    Por supuesto, estas dos formas de escritura dependen del escenario de uso del código; hay que adaptarse a las circunstancias.

    Podemos usar indicadores de enumeración bit a bit para combinar múltiples enumeraciones en un solo valor. Al hablar de indicadores de enumeración bit a bit, no se puede evitar mencionar el atributo Flags.

    En pocas palabras, hace que la enumeración sea más inteligente y proporciona un formato más inteligente para los valores de los indicadores de bits. Por ejemplo:

    public enum a:byte
{
    None=0b_0000_0000,
    apple=0b_0000_0001,
    banana=0b_0000_0010,
    watermelon=0b_0000_0100,
    pineapple=0b_0000_1000  
}

    Cuando estableces apple y banana juntos, el compilador generará 3. Pero si se añade Flags, el compilador sabrá que esto es 1+2=3, y por lo tanto generará apple y banana.

    using System;
namespace HelloWorldApplication
{
   class A
   {
       [Flags]
           public enum a:byte//这种格式的值大家应该都看得懂的吧，对吧
       {
           None=0b_0000_0000,
           apple=0b_0000_0001,
           banana=0b_0000_0010,
           watermelon=0b_0000_0100,
           pineapple=0b_0000_1000  
       }
      static void Main(string[] args)
      {
          a bb=a.apple|a.banana;//设置多个位标志
         Console.WriteLine(bb);
         Console.ReadKey();
      }
   }
}

    Usamos el OR bit a bit (|) para establecer múltiples indicadores de bits:

    a bb=a.apple|banana|watermelon;

    También se puede usar el AND bit a bit (&) para comprobar si un bit específico está marcado.

    a bb=a.banana|a.watermelon;
bool cha=(bb&a.apple)==a.apple;
