C# Entorno de desarrollo

Para hacer un buen trabajo, primero hay que afilar las herramientas. Antes de empezar a escribir código C#, necesitamos configurar el entorno de desarrollo en la computadora.

La configuración del entorno de desarrollo de C# no es complicada: solo necesitas instalar dos cosas:Una plataforma de ejecución (SDK de .NET)和Un editor de código, y ya puedes comenzar tu viaje de programación en C#.

Paso 1: Comprender la relación entre .NET y C#

Antes de instalar las herramientas, aclaremos una duda común:¿Son C# y .NET lo mismo?

No. Su relación se puede entender así:

  • C#Es el lenguaje de programación que usas para escribir código, como las "palabras" que usas para escribir artículos.
  • .NETEs la plataforma y el conjunto de herramientas que ejecutan ese código, como la "imprenta y el papel" que permiten imprimir y difundir el texto.

Los programas que escribes en C# deben depender de .NET para ejecutarse en la computadora. Por lo tanto, el primer paso para configurar el entorno de desarrollo de C# es instalar el SDK de .NET.

La versión principal actual de .NET es.NET 8(versión de soporte a largo plazo), que admite las tres plataformas principales: Windows, macOS y Linux. Ya no es como antes, cuando solo se podía ejecutar en Windows.

Paso 2: Instalar el SDK de .NET

El SDK de .NET (kit de desarrollo de software) incluye el compilador, el entorno de ejecución y varias herramientas de desarrollo; es la base del desarrollo en C#. Los pasos de instalación son los siguientes:

  • Visita la página de descarga oficial de .NET:https://dotnet.microsoft.com/download
  • Elige la últimaversión LTS (soporte a largo plazo), se recomienda que los principiantes elijan primero la versión LTS, es estable y tiene abundante documentación.
  • Descarga el paquete de instalación correspondiente según tu sistema operativo (Windows / macOS / Linux) y completa la instalación siguiendo las indicaciones.

Una vez completada la instalación, abre la línea de comandos (en Windows usa "Símbolo del sistema" o "PowerShell"; en macOS/Linux usa "Terminal") e ingresa el siguiente comando para verificar si la instalación fue exitosa:

dotnet --version

Si se muestra un número de versión (por ejemplo,8.0.xxx), significa que el SDK de .NET se ha instalado correctamente.

Paso 3: Elegir un editor de código

Con el SDK de .NET, en teoría ya puedes escribir código con el Bloc de notas y compilarlo/ejecutarlo con la línea de comandos. Pero en el desarrollo real, todos usamos uneditor de código o IDE (entorno de desarrollo integrado) especializado, que ofrecen funciones como autocompletado de código, sugerencias de errores, depuración, etc., lo que mejora enormemente la eficiencia del desarrollo.

Para principiantes en C#, se recomiendan las siguientes dos herramientas:

① Visual Studio (recomendado para usuarios de Windows)

Visual Studio es el IDE insignia de Microsoft creado específicamente para C#; tiene las funciones más completas y una excelente experiencia de depuración. Es la herramienta de desarrollo en C# más utilizada en las empresas actualmente.

  • Ventajas: Potente, integra escritura de código, depuración, pruebas y publicación; es especialmente adecuado para desarrollar aplicaciones de escritorio de Windows y proyectos de nivel empresarial.
  • Desventajas: El paquete de instalación es grande (varios GB), el inicio es lento, y solo admite Windows y macOS.
  • Precio: Para uso personal de aprendizajela versión Community (comunidad) es gratuita, y sus funciones ya son muy completas.
  • Dirección de descarga：https://visualstudio.microsoft.com/zh-hans/downloads/

💡 Durante la instalación, en la página "Cargas de trabajo", marca"ASP.NET y desarrollo web" 或 "Desarrollo de escritorio con .NET", y así se instalarán automáticamente todos los componentes necesarios para C#, sin necesidad de configuración adicional.

② Visual Studio Code (recomendado para usuarios multiplataforma)

VS Code es un editor de código ligero, de tamaño reducido y inicio rápido, compatible con Windows, macOS y Linux. Al instalar la extensión de C#, también puedes obtener una completa experiencia de desarrollo en C#.

  • Ventajas: Ligero y flexible, multiplataforma, con un rico ecosistema de complementos; adecuado para desarrolladores que buscan un entorno sencillo.
  • Desventajas: Requiere instalar complementos manualmente, y algunas funciones avanzadas de depuración no son tan completas como en Visual Studio.
  • Precio: Completamente gratuito y de código abierto.
  • Dirección de descarga：https://code.visualstudio.com/

💡 Después de instalar VS Code, busca e instala en la tienda de extensionesC# Dev Kitel complemento (creado oficialmente por Microsoft), y así obtendrás funciones completas como sugerencias inteligentes, depuración, gestión de proyectos, etc.

¿Cómo elegir?

  • Si usasWindows, y tu objetivo principal es aprender los fundamentos de C# o desarrollar aplicaciones de Windows → se recomiendaVisual Studio Community。
  • Si usasmacOS o Linux, o prefieres un editor más ligero → se recomiendaVisual Studio Code + C# Dev Kit。

Paso 4: Escribe tu primer programa en C#

Una vez configurado el entorno, verifiquemos: crea y ejecuta un proyecto de C# muy simple usando la línea de comandos:

Abre la línea de comandos y ejecuta los siguientes comandos en orden:

dotnet new console -n HelloWorld
cd HelloWorld
dotnet run

Si ves la salida:

Hello, World!

¡Felicitaciones! Tu entorno de desarrollo de C# se ha configurado correctamente y has ejecutado tu primer programa con éxito.

Desarrollar en C# en macOS y Linux

Como se mencionó antes, el .NET moderno (.NET 5 y versiones superiores) ya es compatible de forma nativa con la ejecución multiplataforma. Los usuarios de macOS y Linux solo necesitan instalar el SDK de .NET y la experiencia es básicamente la misma que en Windows.

Además, es posible que hayas oído hablar de algo llamadoMono. Mono es una implementación multiplataforma de código abierto de .NET creada por la comunidad en sus inicios; fue la principal forma de ejecutar C# en Linux y macOS. Sin embargo, con la completa multiplataforma del .NET oficial de Microsoft, los casos de uso de Mono se han reducido drásticamente; actualmente se utiliza principalmente en contextos específicos como el motor de juegos Unity.Para proyectos nuevos, se recomienda usar directamente el SDK oficial de .NET, sin necesidad de instalar Mono.

Si deseas obtener más información sobre Mono, visita:http://www.mono-project.com/

    Diferencia entre VC y VS

    VS es Visual Studio, un conjunto de herramientas proporcionado por Microsoft, compuesto por diversas herramientas. VS admite programación en C/C++, VB, JAVA y C#. Sin embargo, solo puede admitir una forma de programación a la vez. Cuando se completa la instalación de VS, en la primera ejecución te pide que elijas un lenguaje común. Si eliges C/C++, entonces se convierte en una plataforma capaz de programar en C/C++, quizás eso sea lo que llamas VC. Si no quieres usar C/C++, solo necesitas modificar su configuración inicial y elegir otro lenguaje de programación, y se convertirá en un entorno de programación para otro lenguaje.

    VC es Visual C++, una herramienta de desarrollo independiente para C/C++. La más conocida es VC6.0; el actual VC2010 es en realidad VC10.0.

    Para ponerlo más simple, tomemos VS2010 y VC2010 como ejemplo: VS2010 es como Office2010, que incluye Word2010, Excel2010, etc., mientras que VC2010 sería como Word2010.
