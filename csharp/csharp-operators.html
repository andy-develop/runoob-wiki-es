C# Operadores

Un operador es un símbolo que le indica al compilador realizar operaciones matemáticas o lógicas específicas. C# tiene una rica variedad de operadores integrados, clasificados de la siguiente manera:

  • Operadores aritméticos
  • Operadores relacionales
  • Operadores lógicos
  • Operadores bit a bit
  • Operadores de asignación
  • Otros operadores

Este tutorial explicará uno a uno los operadores aritméticos, relacionales, lógicos, bit a bit, de asignación y otros operadores.

Operadores aritméticos

La siguiente tabla muestra todos los operadores aritméticos admitidos por C#. Supongamos que la variableAtiene el valor 10, y la variableBtiene el valor 20, entonces:

OperadorDescripciónEjemplo
+Suma los dos operandosA + B dará 30
-Resta el segundo operando del primer operandoA - B dará -10
*Multiplica los dos operandosA * B dará 200
/Divide el numerador por el denominadorB / A dará 2
%Operador de módulo, el resto después de la división enteraB % A dará 0
++Operador de incremento, aumenta el valor entero en 1A++ dará 11
--Operador de decremento, disminuye el valor entero en 1A-- dará 9

Ejemplo

Vea el siguiente ejemplo para comprender todos los operadores aritméticos disponibles en C#:

Ejemplo

using System;

namespace OperatorsAppl
{
    class Program
    {
        static void Main(string[] args)
        {
            int a = 21;
            int b = 10;
            int c;

            c = a + b;
            Console.WriteLine("Línea 1 - el valor de c es {0}", c);
            c = a - b;
            Console.WriteLine("Línea 2 - el valor de c es {0}", c);
            c = a * b;
            Console.WriteLine("Línea 3 - el valor de c es {0}", c);
            c = a / b;
            Console.WriteLine("Línea 4 - el valor de c es {0}", c);
            c = a % b;
            Console.WriteLine("Línea 5 - el valor de c es {0}", c);

            // ++a primero realiza el incremento y luego asigna
            c = ++a;
            Console.WriteLine("Línea 6 - el valor de c es {0}", c);

            // en este momento el valor de a es 22
            // --a primero realiza el decremento y luego asigna
            c = --a;
            Console.WriteLine("Línea 7 - el valor de c es {0}", c);
            Console.ReadLine();
        }
    }
}

  • c = a++: primero asigna a a c, y luego incrementa a.
  • c = ++a: primero incrementa a, y luego asigna a a c.
  • c = a--: primero asigna a a c, y luego decrementa a.
  • c = --a: primero decrementa a, y luego asigna a a c.

Ejemplo

using System;

namespace OperatorsAppl
{
    class Program
    {
        static void Main(string[] args)
        {
            int a = 1;
            int b;

            // a++ primero asigna y luego realiza el incremento
            b = a++;
            Console.WriteLine("a = {0}", a);
            Console.WriteLine("b = {0}", b);
            Console.ReadLine();

            // ++a primero realiza el incremento y luego asigna
            a = 1; // reinicializa a
            b = ++a;
            Console.WriteLine("a = {0}", a);
            Console.WriteLine("b = {0}", b);
            Console.ReadLine();

            // a-- primero asigna y luego realiza el decremento
            a = 1;  // reinicializa a
            b= a--;
            Console.WriteLine("a = {0}", a);
            Console.WriteLine("b = {0}", b);
            Console.ReadLine();

            // --a primero realiza el decremento y luego asigna
            a = 1;  // reinicializa a
            b= --a;
            Console.WriteLine("a = {0}", a);
            Console.WriteLine("b = {0}", b);
            Console.ReadLine();
        }
    }
}

Operadores relacionales

La siguiente tabla muestra todos los operadores relacionales admitidos por C#. Supongamos que la variableAtiene el valor 10, y la variableBtiene el valor 20, entonces:

OperadorDescripciónEjemplo
==Comprueba si los valores de dos operandos son iguales; si lo son, la condición es verdadera.(A == B) no es verdadero.
!=Comprueba si los valores de dos operandos son iguales; si no lo son, la condición es verdadera.(A != B) es verdadero.
>Comprueba si el valor del operando izquierdo es mayor que el del derecho; si es así, la condición es verdadera.(A > B) no es verdadero.
<Comprueba si el valor del operando izquierdo es menor que el del derecho; si es así, la condición es verdadera.(A < B) es verdadero.
>=Comprueba si el valor del operando izquierdo es mayor o igual que el del derecho; si es así, la condición es verdadera.(A >= B) no es verdadero.
<=Comprueba si el valor del operando izquierdo es menor o igual que el del derecho; si es así, la condición es verdadera.(A <= B) es verdadero.

Ejemplo

Vea el siguiente ejemplo para comprender todos los operadores relacionales disponibles en C#:

Ejemplo

using System;

class Program
{
  static void Main(string[] args)
  {
      int a = 21;
      int b = 10;
     
      if (a == b)
      {
          Console.WriteLine("Línea 1 - a es igual a b");
      }
      else
      {
          Console.WriteLine("Línea 1 - a no es igual a b");
      }
      if (a < b)
      {
          Console.WriteLine("Línea 2 - a es menor que b");
      }
      else
      {
          Console.WriteLine("Línea 2 - a no es menor que b");
      }
      if (a > b)
      {
          Console.WriteLine("Línea 3 - a es mayor que b");
      }
      else
      {
          Console.WriteLine("Línea 3 - a no es mayor que b");
      }
      /* cambiar los valores de a y b */
      a = 5;
      b = 20;
      if (a <= b)
      {
         Console.WriteLine("Línea 4 - a es menor o igual que b");
      }
      if (b >= a)
      {
         Console.WriteLine("Línea 5 - b es mayor o igual que a");
      }
  }
}

Line 2 - a 不小于 b
Line 3 - a 大于 b
Line 4 - a 小于或等于 b
Line 5 - b 大于或等于 a

Operadores lógicos

La siguiente tabla muestra todos los operadores lógicos admitidos por C#. Supongamos que la variableAes el valor booleano true, y la variableBes el valor booleano false, entonces:

OperadorDescripciónEjemplo
&&Se llama operador AND lógico. Si ambos operandos son distintos de cero, la condición es verdadera.(A && B) es falso.
||Se llama operador OR lógico. Si cualquiera de los dos operandos es distinto de cero, la condición es verdadera.(A || B) es verdadero.
!Se llama operador NOT lógico. Se usa para invertir el estado lógico del operando. Si la condición es verdadera, el operador NOT lógico la hará falsa.!(A && B) es verdadero.

Operadores bit a bit

Los operadores bit a bit operan sobre bits y realizan operaciones bit por bit. La tabla de verdad de &, | y ^ es la siguiente:

pqp & qp | qp ^ q
00000
01011
11110
10011

Supongamos que si A = 60 y B = 13, ahora representados en formato binario, son los siguientes:

A = 0011 1100

B = 0000 1101

-----------------

A&B = 0000 1100

A|B = 0011 1101

A^B = 0011 0001

~A  = 1100 0011

La siguiente tabla enumera los operadores bit a bit admitidos por C#. Supongamos que la variableAtiene el valor 60, y la variableBtiene el valor 13, entonces:

OperadorDescripciónEjemplo
&Si el bit existe en ambos operandos, el operador AND binario copia un bit al resultado.(A & B) dará 12, es decir 0000 1100
|Si el bit existe en cualquiera de los operandos, el operador OR binario copia un bit al resultado.(A | B) dará 61, es decir 0011 1101
^Si el bit existe en uno de los operandos pero no en ambos, el operador XOR binario copia un bit al resultado.(A ^ B) dará 49, es decir 0011 0001
~El operador de complemento bit a bit es un operador unario que tiene el efecto de "voltear" los bits, es decir, 0 se convierte en 1 y 1 se convierte en 0, incluido el bit de signo.(~A) dará -61, es decir 1100 0011, la forma de complemento a dos de un número binario con signo.
<<Operador de desplazamiento a la izquierda binario. El valor del operando izquierdo se desplaza a la izquierda el número de bits especificado por el operando derecho.A << 2 dará 240, es decir 1111 0000
>>Operador de desplazamiento a la derecha binario. El valor del operando izquierdo se desplaza a la derecha la cantidad de bits especificada por el operando derecho.A >> 2 dará 15, es decir, 0000 1111

Ejemplo

Consulte el siguiente ejemplo para conocer todos los operadores de bits disponibles en C#:

Ejemplo

using System;
namespace OperatorsAppl
{
    class Program
    {
        static void Main(string[] args)
        {
            int a = 60;            /* 60 = 0011 1100 */  
            int b = 13;            /* 13 = 0000 1101 */
            int c = 0;          

             c = a & b;           /* 12 = 0000 1100 */
             Console.WriteLine("Line 1 - el valor de c es {0}", c );

             c = a | b;           /* 61 = 0011 1101 */
             Console.WriteLine("Line 2 - el valor de c es {0}", c);

             c = a ^ b;           /* 49 = 0011 0001 */
             Console.WriteLine("Line 3 - el valor de c es {0}", c);

             c = ~a;               /*-61 = 1100 0011 */
             Console.WriteLine("Line 4 - el valor de c es {0}", c);

             c = a << 2;     /* 240 = 1111 0000 */
             Console.WriteLine("Line 5 - el valor de c es {0}", c);

             c = a >> 2;     /* 15 = 0000 1111 */
             Console.WriteLine("Line 6 - el valor de c es {0}", c);
            Console.ReadLine();
        }
    }
}

Cuando el código anterior se compila y ejecuta, produce el siguiente resultado:

Line 1 - c 的值是 12
Line 2 - c 的值是 61
Line 3 - c 的值是 49
Line 4 - c 的值是 -61
Line 5 - c 的值是 240
Line 6 - c 的值是 15

Precedencia de operadores en C#

La precedencia de operadores determina la combinación de términos en una expresión. Esto afecta a cómo se evalúa una expresión. Algunos operadores tienen mayor precedencia que otros; por ejemplo, los operadores de multiplicación y división tienen mayor precedencia que los de suma y resta.

Por ejemplo, x = 7 + 3 * 2; aquí, a x se le asigna 13, no 20, porque el operador * tiene mayor precedencia que +, por lo que primero se calcula la multiplicación 3*2 y luego se suma 7.

La siguiente tabla enumera los operadores por precedencia de mayor a menor. Los operadores con mayor precedencia aparecen en la parte superior de la tabla, y los de menor precedencia en la parte inferior. En una expresión, los operadores con mayor precedencia se evalúan primero.

Resumen simple de precedenciaPrimero los paréntesis, luego multiplicación/división y suma/resta, después desplazamientos y relaciones, luego lógicos, después condicionales y por último la coma., 。

Categoría OperadorAsociatividad
Sufijo() [] -> . ++ - -   De izquierda a derecha
Unario + - ! ~ ++ - - (type)* & sizeof  De derecha a izquierda
Multiplicación/división * / % De izquierda a derecha
Suma/resta+ -  De izquierda a derecha
Desplazamiento << >>  De izquierda a derecha
Relacional< <= > >=  De izquierda a derecha
Igualdad == !=  De izquierda a derecha
Y bit a bit (AND)&  De izquierda a derecha
XOR bit a bit ^  De izquierda a derecha
O bit a bit (OR) |  De izquierda a derecha
Y lógico (AND)&&  De izquierda a derecha
O lógico (OR) ||  De izquierda a derecha
Condicional?:  De derecha a izquierda
Asignación = += -= *= /= %=>>= <<= &= ^= |= De derecha a izquierda
Coma ,  De izquierda a derecha

(a + b) * c / d 的值是 90
((a + b) * c) / d 的值是 90
(a + b) * (c / d) 的值是 90
a + (b * c) / d 的值是 50

Precedencia de los operadores aritméticos y de asignación:

Ejemplo

int a = 10, b = 5, c = 2;
int result = a + b * c;  // Primero se calcula la multiplicación, luego la suma.
Console.WriteLine(result);  // Imprime 20

result = (a + b) * c;     // Primero se calcula la suma, luego la multiplicación.
Console.WriteLine(result);  // Imprime 30

a += b * c;               // Primero se calcula la multiplicación, luego se ejecuta la asignación con suma.
Console.WriteLine(a);       // Imprime 20

Precedencia de los operadores lógicos:

Ejemplo


bool a = true, b = false, c = true;
bool result = a || b && c;  // Primero se calcula la operación Y, luego la operación O.
Console.WriteLine(result);  // Imprime true

result = (a || b) && c;     // Primero se calcula la operación O, luego la operación Y.
Console.WriteLine(result);  // Imprime true

result = a || (b && c);     // Primero se calcula la operación Y, luego la operación O.
Console.WriteLine(result);  // Imprime true

Precedencia del operador condicional:

Ejemplo

int a = 10, b = 5;
string result = a > b ? "a es mayor que b" : "a no es mayor que b";  // Primero se evalúa la relación de tamaño, luego se ejecuta la sentencia condicional.
Console.WriteLine(result);  // Salida "a es mayor que b"

Nota:Debido a que los paréntesis pueden cambiar la precedencia de los operadores, en la práctica se recomienda usar paréntesis tanto como sea posible para aclarar el orden de las operaciones, mejorando la legibilidad y precisión del código.

    &，|，^ Además de usarse para operaciones de bits, también pueden usarse para operaciones lógicas, correspondiendo respectivamente a Y, O, XOR.

    Operador ^Para tipos enteros y bool, el operador binario ^ está predefinido. Para tipos enteros, ^ calcula el XOR bit a bit de sus operandos. Para operandos bool, ^ calcula el XOR lógico de sus operandos; es decir, el resultado es true si y solo si exactamente uno de sus operandos es true.

    Console.WriteLine(true ^ false);  // 返回 true
Console.WriteLine(false ^ false);  // 返回 false
Console.WriteLine(true ^ true);  // 返回 false

    Operador |Para tipos enteros y bool, el operador binario | está predefinido. Para tipos enteros, | calcula el OR bit a bit de sus operandos. Para operandos bool, | calcula el OR lógico de sus operandos; es decir, el resultado es false si y solo si ambos operandos son false.

    Console.WriteLine(true | false);  // 返回 true
Console.WriteLine(false | false); // 返回 false

    Operador &Para tipos enteros y bool, el operador binario & está predefinido. Para tipos enteros, & calcula el AND bit a bit lógico de sus operandos. Para operandos bool, & calcula el AND lógico de sus operandos; es decir, el resultado es true si y solo si ambos operandos son true.

    Console.WriteLine(true & false);  // 返回 false
Console.WriteLine(true & true);   // 返回 true

    Entre ellos, los resultados de & y | son exactamente iguales a los de && y ||, pero && y || tienen mejor rendimiento. Porque tanto && como || verifican el valor del primer operando; si ya se puede determinar el resultado, no procesan el segundo operando en absoluto.

    Por ejemplo:

    bool a = true;               
bool b = false;              
bool c = a || b;

    Al verificar el primer operando a, ya se obtiene que c es true, por lo que no es necesario procesar el segundo operando b.

    C# usa<< (desplazamiento a la izquierda) 和 >> (desplazamiento a la derecha)operadores se utilizan para realizar operaciones de desplazamiento.

    Desplazamiento a la izquierda (<<): mueve el primer operando a la izquierda el número de bits especificado por el segundo operando, y las posiciones vacías se rellenan con 0.

    El desplazamiento a la izquierda equivale a multiplicar. Desplazar un bit a la izquierda equivale a multiplicar por 2; desplazar dos bits equivale a multiplicar por 4; desplazar tres bits equivale a multiplicar por 8.

    x<<1= x*2
x<<2= x*4
x<<3= x*8
x<<4= x*16

    De manera similar, el desplazamiento a la derecha es lo contrario:

    Desplazamiento a la derecha (>>): mueve el primer operando a la derecha el número de bits especificado por el segundo operando, y las posiciones vacías se rellenan con 0.

    El desplazamiento a la derecha equivale a la división entera. Desplazar un bit a la derecha equivale a dividir entre 2; desplazar dos bits equivale a dividir entre 4; desplazar tres bits equivale a dividir entre 8.

    x>>1= x/2
x>>2= x/4
x>>3= x/8
x>>4= x/16

    Debido a que el desplazamiento es más rápido que la multiplicación y la división, y cuando se requiere alta eficiencia y se trata de multiplicaciones o divisiones por potencias de 2, se puede utilizar el desplazamiento.
