CSS3 Animaciones

CSS3 puede crear animaciones que pueden reemplazar muchos efectos implementados con imágenes animadas de páginas web, animaciones Flash y JavaScript.

CSS3
Animación

Regla @keyframes de CSS3

Para crear animaciones CSS3, necesitas conocer la regla @keyframes.

La regla @keyframes se utiliza para crear animaciones.

Dentro de la regla @keyframes se especifica un estilo CSS y la animación cambiará gradualmente del estilo actual al nuevo estilo.

CSS3 Animaciones

Cuando@keyframesAl crear una animación, debes vincularla a un selector; de lo contrario, la animación no tendrá ningún efecto.

Especifica al menos estas dos propiedades de animación CSS3 vinculadas a un selector:

  • Especifica el nombre de la animación
  • Especifica la duración de la animación

Ejemplo

Vincula la animación "myfirst" al elemento div, duración: 5 segundos:

div { animation: myfirst 5s; -webkit-animation: myfirst 5s; /*Safari y Chrome*/ }

Pruébalo »

Nota:Debes definir el nombre de la animación y la duración de la animación. Si se omite la duración, la animación no se ejecutará porque el valor predeterminado es 0.

¿Qué son las animaciones CSS3?

La animación es el efecto de hacer que un elemento cambie gradualmente de un estilo a otro.

Puedes cambiar tantos estilos como quieras y tantas veces como quieras.

Usa porcentajes para especificar el momento en que ocurren los cambios, o las palabras clave "from" y "to", que equivalen a 0% y 100%.

0% es el inicio de la animación y 100% es la finalización de la animación.

Para obtener el mejor soporte del navegador, siempre debes definir los selectores 0% y 100%.

Ejemplo

Cambia el color de fondo en el 25% y 50% de la animación, y luego vuelve a cambiarlo cuando la animación se complete al 100%:

@keyframes myfirst { 0% {background: red;} 25% {background: yellow;} 50% {background: blue;} 100% {background: green;} } @-webkit-keyframes myfirst /*Safari y Chrome*/ { 0% {background: red;} 25% {background: yellow;} 50% {background: blue;} 100% {background: green;} }

Ejemplo

Cambia el color de fondo y la posición:

@keyframes myfirst { 0% {background: red; left:0px; top:0px;} 25% {background: yellow; left:200px; top:0px;} 50% {background: blue; left:200px; top:200px;} 75% {background: green; left:0px; top:200px;} 100% {background: red; left:0px; top:0px;} } @-webkit-keyframes myfirst /*Safari y Chrome*/ { 0% {background: red; left:0px; top:0px;} 25% {background: yellow; left:200px; top:0px;} 50% {background: blue; left:200px; top:200px;} 75% {background: green; left:0px; top:200px;} 100% {background: red; left:0px; top:0px;} }

Propiedades de animación de CSS3

La siguiente tabla enumera la regla @keyframes y todas las propiedades de animación:

Propiedad Descripción CSS
@keyframes Especifica la animación. 3
animation Propiedad abreviada para todas las propiedades de animación. 3
animation-name Especifica el nombre de la animación @keyframes. 3
animation-duration Especifica los segundos o milisegundos que tarda la animación en completar un ciclo. El valor predeterminado es 0. 3
animation-timing-function Especifica la curva de velocidad de la animación. El valor predeterminado es "ease". 3
animation-fill-mode Especifica el estilo que se aplicará al elemento cuando la animación no se esté reproduciendo (cuando la animación haya terminado o cuando tenga un retraso y aún no haya comenzado). 3
animation-delay Especifica cuándo comenzará la animación. El valor predeterminado es 0. 3
animation-iteration-count Especifica cuántas veces se reproducirá la animación. El valor predeterminado es 1. 3
animation-direction Especifica si la animación se reproducirá en sentido inverso en el siguiente ciclo. El valor predeterminado es "normal". 3
animation-play-state Especifica si la animación está en ejecución o en pausa. El valor predeterminado es "running". 3

Los siguientes dos ejemplos configuran todas las propiedades de animación:

Ejemplo

Ejecuta la animación myfirst y configura todas las propiedades:

div { animation-name: myfirst; animation-duration: 5s; animation-timing-function: linear; animation-delay: 2s; animation-iteration-count: infinite; animation-direction: alternate; animation-play-state: running; /*Safari y Chrome:*/ -webkit-animation-name: myfirst; -webkit-animation-duration: 5s; -webkit-animation-timing-function: linear; -webkit-animation-delay: 2s; -webkit-animation-iteration-count: infinite; -webkit-animation-direction: alternate; -webkit-animation-play-state: running; }

Pruébalo »

Ejemplo

Igual que la animación anterior, pero usando la propiedad abreviada animation:

div { animation: myfirst 5s linear 2s infinite alternate; /*Safari y Chrome:*/ -webkit-animation: myfirst 5s linear 2s infinite alternate; }
