CSS3 Flexbox (Flex Box)

Flexbox es un nuevo modo de diseño de CSS3.

CSS3 Flexible Box (o flexbox) es un método de diseño que garantiza que los elementos tengan un comportamiento adecuado cuando la página necesita adaptarse a diferentes tamaños de pantalla y tipos de dispositivos.

El propósito de introducir el modelo de diseño de caja flexible es proporcionar una forma más eficiente de organizar, alinear y distribuir el espacio en blanco entre los elementos hijos de un contenedor.

Contenido de CSS3 Flexbox

Flexbox se compone de un contenedor flexible (Flex container) y elementos hijos flexibles (Flex item).

El contenedor flexible se define como tal estableciendo el valor de la propiedad display en flex o inline-flex.

El contenedor flexible contiene uno o más elementos hijos flexibles.

Nota:El exterior del contenedor flexible y el interior de los elementos hijos flexibles se renderizan normalmente. Flexbox solo define cómo se distribuyen los elementos hijos flexibles dentro del contenedor flexible.

Los elementos hijos flexibles normalmente se muestran en una sola línea dentro de la caja flexible. De forma predeterminada, cada contenedor tiene una sola línea.

El siguiente elemento muestra los elementos hijos flexibles en una línea, de izquierda a derecha:

Ejemplo

<!DOCTYPE html> <html> <head> <style>
.flex-container { display: -webkit-flex; display: flex; width: 400px; height: 250px; background-color: lightgrey; } .flex-item { background-color: cornflowerblue; width: 100px; height: 100px; margin: 10px; }
</style> </head> <body> <div class="flex-container"> <div class="flex-item">flex item 1</div> <div class="flex-item">flex item 2</div> <div class="flex-item">flex item 3</div> </div> </body> </html>

Por supuesto, podemos modificar la disposición.

Si establecemosdirectionla propiedad enrtl(right-to-left), la disposición de los elementos hijos flexibles también cambiará, y el diseño de la página cambiará en consecuencia:

Ejemplo

body { direction: rtl; } .flex-container { display: -webkit-flex; display: flex; width: 400px; height: 250px; background-color: lightgrey; } .flex-item { background-color: cornflowerblue; width: 100px; height: 100px; margin: 10px; }

flex-direction

flex-directionLa propiedad especifica la posición de los elementos hijos flexibles en el contenedor padre.

Sintaxis

flex-direction: row | row-reverse | column | column-reverse

flex-directionLos valores son:

  • row: disposición horizontal de izquierda a derecha (alineación a la izquierda), es la disposición predeterminada.
  • row-reverse: invierte la disposición horizontal (alineación a la derecha, ordenada de atrás hacia adelante, el último elemento se coloca primero).
  • column: disposición vertical.
  • column-reverse: invierte la disposición vertical, ordenada de atrás hacia adelante, el último elemento se coloca arriba.

El siguiente ejemplo demuestrarow-reverseel uso de:

Ejemplo

.flex-container { display: -webkit-flex; display: flex; -webkit-flex-direction: row-reverse; flex-direction: row-reverse; width: 400px; height: 250px; background-color: lightgrey; }

Ejemplo

.flex-container { display: -webkit-flex; display: flex; -webkit-flex-direction: column; flex-direction: column; width: 400px; height: 250px; background-color: lightgrey; }

Propiedad justify-content

La propiedad de alineación del contenido (justify-content) se aplica al contenedor flexible y alinea los elementos flexibles a lo largo del eje principal (main axis) del contenedor flexible.

La sintaxis de justify-content es la siguiente:

justify-content: flex-start | flex-end | center | space-between | space-around

Explicación de cada valor:

  • flex-start：

    Los elementos flexibles se empaquetan juntos hacia el inicio de la línea. Este es el valor predeterminado. El borde del margen exterior main-start del primer elemento flexible se coloca en el borde main-start de la línea, y los elementos flexibles siguientes se colocan alineados sucesivamente.

  • flex-end：

    Los elementos flexibles se empaquetan juntos hacia el final de la línea. El borde del margen exterior main-end del primer elemento flexible se coloca en el borde main-end de la línea, y los elementos flexibles siguientes se colocan alineados sucesivamente.

  • center：

    Los elementos flexibles se empaquetan juntos en el centro. (Si el espacio libre restante es negativo, los elementos flexibles se desbordarán en ambas direcciones simultáneamente).

  • space-between：

    Los elementos flexibles se distribuyen uniformemente en la línea. Si el espacio restante es negativo o solo hay un elemento flexible, este valor equivale a flex-start. De lo contrario, el margen del primer elemento flexible se alinea con el borde main-start de la línea, y el margen del último elemento flexible se alinea con el borde main-end de la línea; luego los elementos flexibles restantes se distribuyen en la línea con intervalos iguales entre elementos adyacentes.

  • space-around：

    Los elementos flexibles se distribuyen uniformemente en la línea, dejando la mitad del espacio de separación en ambos extremos. Si el espacio restante es negativo o solo hay un elemento flexible, este valor equivale a center. De lo contrario, los elementos flexibles se distribuyen a lo largo de la línea con un espacio igual entre ellos (por ejemplo, 20px), y al mismo tiempo se deja la mitad del espacio (1/2*20px=10px) entre los extremos y el contenedor flexible.

Demostración del efecto:

El siguiente ejemplo demuestraflex-endel uso de:

Ejemplo

.flex-container { display: -webkit-flex; display: flex; -webkit-justify-content: flex-end; justify-content: flex-end; width: 400px; height: 250px; background-color: lightgrey; }

Propiedad align-items

align-itemsEstablece o recupera la alineación de los elementos de la caja flexible en la dirección del eje transversal (eje vertical).

Sintaxis

align-items: flex-start | flex-end | center | baseline | stretch

Explicación de cada valor:

  • flex-start: el borde de la posición inicial del eje transversal (eje vertical) del elemento de la caja flexible se coloca contra el borde inicial del eje transversal de la línea.
  • flex-end: el borde de la posición inicial del eje transversal (eje vertical) del elemento de la caja flexible se coloca contra el borde final del eje transversal de la línea.
  • center: el elemento de la caja flexible se coloca centrado en el eje transversal (eje vertical) de la línea. (Si el tamaño de la línea es menor que el tamaño del elemento de la caja flexible, se desbordará la misma longitud en ambas direcciones).
  • baseline: si el eje en línea y el eje transversal del elemento de la caja flexible son el mismo, este valor equivale a 'flex-start'. En otros casos, este valor participa en la alineación de la línea base.
  • stretch: si el valor de la propiedad que especifica el tamaño del eje transversal es 'auto', este valor hará que el tamaño del cuadro de margen del elemento se acerque lo más posible al tamaño de la línea, pero respetando las restricciones de las propiedades 'min/max-width/height'.

El siguiente ejemplo demuestrastretch(默认值)el uso de:

Ejemplo

.flex-container { display: -webkit-flex; display: flex; -webkit-align-items: stretch; align-items: stretch; width: 400px; height: 250px; background-color: lightgrey; }

Propiedad flex-wrap

flex-wrapEsta propiedad se utiliza para especificar cómo se envuelven los elementos hijos de la caja flexible.

Sintaxis

flex-wrap: nowrap|wrap|wrap-reverse|initial|inherit;

Explicación de cada valor:

  • nowrap- De forma predeterminada, el contenedor flexible es de una sola línea. En este caso, los elementos hijos flexibles pueden desbordar el contenedor.
  • wrap- El contenedor flexible es de varias líneas. En este caso, la parte desbordada de los elementos hijos flexibles se coloca en una nueva línea y se produce un salto de línea dentro del elemento hijo.
  • wrap-reverse- Invierte la disposición wrap.

El siguiente ejemplo demuestranowrapel uso de:

Ejemplo

.flex-container { display: -webkit-flex; display: flex; -webkit-flex-wrap: nowrap; flex-wrap: nowrap; width: 300px; height: 250px; background-color: lightgrey; }

Propiedad align-content

align-contentLa propiedad se utiliza para modificar flex-wrapel comportamiento de la propiedad. Similar aalign-items, pero no establece la alineación de los elementos secundarios flexibles, sino la alineación de cada línea.

Sintaxis

align-content: flex-start | flex-end | center | space-between | space-around | stretch

Descripción de los valores:

  • stretch- Predeterminado. Las líneas se estirarán para ocupar el espacio restante.
  • flex-start- Las líneas se apilan hacia la posición inicial del contenedor flex.
  • flex-end- Las líneas se apilan hacia la posición final del contenedor flex.
  • center- Las líneas se apilan hacia la posición central del contenedor flex.
  • space-between- Las líneas se distribuyen uniformemente en el contenedor flex.
  • space-around- Las líneas se distribuyen uniformemente en el contenedor flex, dejando en ambos extremos la mitad del tamaño del espacio entre los elementos secundarios.

El siguiente ejemplo demuestracenterel uso de:

Ejemplo

.flex-container { display: -webkit-flex; display: flex; -webkit-flex-wrap: wrap; flex-wrap: wrap; -webkit-align-content: center; align-content: center; width: 300px; height: 300px; background-color: lightgrey; }

Alineación

Establecer el valor de 'margin' en 'auto' obtiene automáticamente el espacio restante en el contenedor flex. Por lo tanto, establecer el valor del margen vertical en 'auto' permite que los elementos secundarios flexibles queden completamente centrados en las direcciones de ambos ejes del contenedor flex.

El siguiente ejemplo establece en el primer elemento secundario flexiblemargin-right: auto;. Coloca el espacio restante en el lado derecho del elemento:

Ejemplo

.flex-item { background-color: cornflowerblue; width: 75px; height: 75px; margin: 10px; } .flex-item:first-child { margin-right: auto; }

align-self

align-selfLa propiedad se utiliza para establecer la alineación del propio elemento flexible en la dirección del eje transversal (eje vertical).

Sintaxis

align-self: auto | flex-start | flex-end | center | baseline | stretch

Descripción de los valores:

  • auto: si el valor de 'align-self' es 'auto', su valor calculado es el valor de 'align-items' del elemento padre; si no tiene elemento padre, el valor calculado es 'stretch'.
  • flex-start: el borde de la posición inicial del eje transversal (eje vertical) del elemento flex se ajusta al borde inicial del eje transversal de la línea.
  • flex-end: el borde de la posición final del eje transversal (eje vertical) del elemento flex se ajusta al borde final del eje transversal de la línea.
  • center: el elemento flex se coloca centrado en el eje transversal (eje vertical) de la línea. (Si el tamaño de la línea es menor que el tamaño del elemento flex, se desbordará la misma longitud en ambas direcciones).
  • baseline: si el eje en línea y el eje transversal del elemento flex son el mismo, este valor equivale a 'flex-start'. En otros casos, este valor participa en la alineación de líneas base.
  • stretch: si el valor de la propiedad que especifica el tamaño del eje transversal es 'auto', su valor hará que el tamaño de la caja de margen del elemento se acerque lo más posible al tamaño de la línea, pero respetando las restricciones de las propiedades 'min/max-width/height'.

El siguiente ejemplo demuestra los efectos de aplicar diferentes valores de align-self en los elementos secundarios flexibles:

Ejemplo

.flex-item { background-color: cornflowerblue; width: 60px; min-height: 100px; margin: 10px; } .item1 { -webkit-align-self: flex-start; align-self: flex-start; } .item2 { -webkit-align-self: flex-end; align-self: flex-end; } .item3 { -webkit-align-self: center; align-self: center; } .item4 { -webkit-align-self: baseline; align-self: baseline; } .item5 { -webkit-align-self: stretch; align-self: stretch; }

Inténtalo »

flex

flexLa propiedad se utiliza para especificar cómo los elementos secundarios flexibles distribuyen el espacio.

Sintaxis

flex: auto | initial | none | inherit |  [ flex-grow ] || [ flex-shrink ] || [ flex-basis ]

Descripción de los valores:

  • auto: el valor calculado es 1 1 auto
  • initial: el valor calculado es 0 1 auto
  • none: el valor calculado es 0 0 auto
  • inherit: se hereda del elemento padre.
  • [flex-grow]: define la tasa de expansión del elemento flex.
  • [flex-shrink]: define la tasa de contracción del elemento flex.
  • [flex-basis]: define el valor base predeterminado del elemento flex.

En el siguiente ejemplo, el primer elemento secundario flexible ocupa 2/4 del espacio, y los otros dos ocupan cada uno 1/4 del espacio:

Ejemplo

.flex-item { background-color: cornflowerblue; margin: 10px; } .item1 { -webkit-flex: 2; flex: 2; } .item2 { -webkit-flex: 1; flex: 1; } .item3 { -webkit-flex: 1; flex: 1; }
