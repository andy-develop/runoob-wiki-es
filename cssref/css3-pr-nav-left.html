Ejemplos

Especifica la navegación usando las teclas de navegación de flecha izquierda y derecha:

button#b1
{
top:20%;left:25%;
nav-index:1;
nav-right:#b2;nav-left:#b4;
nav-down:#b2;nav-up:#b4;
}

button#b2
{
top:40%;left:50%;
nav-index:2;
nav-right:#b3;nav-left:#b1;
nav-down:#b3;nav-up:#b1;
}

button#b3
{
top:70%;left:25%;
nav-index:3;
nav-right:#b4;nav-left:#b2;
nav-down:#b4;nav-up:#b2;
}

button#b4
{
top:40%;left:0%;
nav-index:4;
nav-right:#b1;nav-left:#b3;
nav-down:#b1;nav-up:#b3;
}

Definición de atributos e instrucciones de uso

La propiedad nav-left especifica la navegación usando la tecla de navegación de flecha izquierda.

Valor predeterminado: auto
Herencia: no
Versión: CSS3
Sintaxis de JavaScript: object.style.navLeft="#div2"

Sintaxis

nav-left: auto|id|target-name|inherit;

Valor Descripción
auto El navegador decidirá a qué elemento navegar
id Especifica el ID para navegar a ese elemento
target-name Especifica la navegación al marco de destino
inherit Especifica el valor de la propiedad nav-left; debe heredarse del elemento padre.
