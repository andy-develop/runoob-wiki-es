Tipos de colecciones en Dart

Una colección es una estructura de datos que almacena múltiples datos.

Dart incluye tres tipos de colecciones principales: List (lista), Set (conjunto) y Map (mapeo). Este capítulo presentará sus usos uno por uno.

List: lista ordenada

List es el tipo de colección más utilizado; se usa para almacenar un grupo de elementos ordenados y permite duplicados.

Puedes acceder a cualquier elemento de List mediante un índice (comenzando desde 0).

Crear List

Ejemplo

void main() {
  // Crear List con un literal
  List<String> sites = ['EJEMPLO', 'Google', 'GitHub'];
  print('Lista de sitios: $sites');

  // Inferencia de tipo (omitiendo genéricos)
  var numbers = [1, 2, 3, 4, 5];
  print('Lista de números: $numbers');

  // Crear una lista vacía
  var emptyList = <String>[];

  // Crear una lista de longitud fija con List.filled
  var zeros = List.filled(3, 0);  // [0, 0, 0]
  print('Lista rellenada: $zeros');

  // Generar una lista con List.generate
  var squares = List.generate(5, (i) => i * i);
  print('Lista de cuadrados: $squares');
}

Las claves de Map pueden ser de cualquier tipo (String, int, etc.), pero debe garantizarse que la igualdad de las claves sea significativa. Al usar objetos personalizados como claves, hay que asegurarse de que == y hashCode estén correctamente implementados.

Operador de propagación de colecciones ... y ...?

El operador de expansión puede "expandir" los elementos de una colección dentro de otra.

Ejemplo

void main() {
  var basics = ['Dart', 'Flutter'];
  var advanced = [Programación asíncrona, Gestión de estado];

  // ... operador de expansión: inserta los elementos de otra colección
  var allCourses = ['Introducción a EJEMPLO', ...basics, ...advanced];
  print('Todos los cursos: $allCourses');

  // ...? expansión segura contra nulos: si la colección es null, se omite
  List<String>? optionalList;  // podría ser null
  var safeList = ['Primer elemento', ...?optionalList];
  print('Expansión segura: $safeList');  // solo el primer elemento

  optionalList = ['Contenido adicional'];
  safeList = ['Primer elemento', ...?optionalList];
  print('Expansión con valor: $safeList');
}

if y for en colecciones (control de flujo en colecciones)

Dart permite usar if y for directamente en los literales de colección; esto es un azúcar sintáctico muy práctico.

Ejemplo

void main() {
  bool showAdmin = true;

  // if en colecciones: decide si incluir un elemento según una condición
  var menuItems = [
    'Inicio',
    Tutorial,
    if (showAdmin) Panel de administración,  // se agrega solo si la condición es true
    Acerca de,
  ];
  print(Menú: $menuItems);

  // for en colecciones: genera elementos a partir de otra colección
  var numbers = [1, 2, 3];
  var doubled = [
    for (var n in numbers) n * 2,  // recorre para generar nuevos elementos
  ];
  print(Duplicados: $doubled);

  // if + for se pueden combinar
  var tags = ['Dart', 'Flutter'];
  var links = [
    Página principal de EJEMPLO,
    for (var tag in tags) 'https://example.com/$tag',
  ];
  print(Enlaces: $links);
}

Notas

Tanto Set como Map usan{}como literal.

La diferencia es:

  • Map usakey: valueforma (con dos puntos)
  • Set escribe los elementos directamente (sin dos puntos)

Por ejemplo:

var map = {'name': 'Tom'};   // Map
var set = {'Tom', 'Jerry'}; // Set

Se debe prestar especial atención:

var x = {};

Esto no crea un Set vacío, sino que Dart lo infiere como:

Map<dynamic, dynamic>

Porque las llaves vacías no permiten determinar el tipo de elemento, Dart lo trata como Map por defecto.

Si se quiere crear un Set vacío, se debe especificar explícitamente:

var x = <String>{};

o

： 
Set<String> x = {};
