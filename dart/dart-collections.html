Tipos de colecciones en Dart

Una colección es una estructura de datos que almacena múltiples datos.

Dart incluye tres tipos de colecciones principales: List (lista), Set (conjunto) y Map (mapeo). Este capítulo presentará sus usos uno por uno.

List: lista ordenada

List es el tipo de colección más utilizado; se usa para almacenar un grupo de elementos ordenados y permite duplicados.

Puedes acceder a cualquier elemento de List mediante un índice (comenzando desde 0).

Crear List

Ejemplo

void main() {
  // Crear List con un literal
  List<String> sites = ['RUNOOB', 'Google', 'GitHub'];
  print('Lista de sitios: $sites');

  // Inferencia de tipo (omitiendo genéricos)
  var numbers = [1, 2, 3, 4, 5];
  print('Lista de números: $numbers');

  // Crear una lista vacía
  var emptyList = <String>[];

  // Crear una lista de longitud fija con List.filled
  var zeros = List.filled(3, 0);  // [0, 0, 0]
  print('Lista rellenada: $zeros');

  // Generar una lista con List.generate
  var squares = List.generate(5, (i) => i * i);
  print('Lista de cuadrados: $squares');
}

Map 的键可以是任何类型（String、int 等），但必须保证键的相等性有意义。使用自定义对象作为键时，需要确保正确实现了 == 和 hashCode。 → Las claves de Map pueden ser de cualquier tipo (String, int, etc.), pero debe garantizarse que la igualdad de las claves sea significativa. Al usar objetos personalizados como claves, hay que asegurarse de que == y hashCode estén correctamente implementados.

Operador de propagación de colecciones ... y ...?

El operador de expansión puede "expandir" los elementos de una colección dentro de otra.

Ejemplo

void main() {
  var basics = ['Dart', 'Flutter'];
  var advanced = ['异步编程' → 'Programación asíncrona', '状态管理' → 'Gestión de estado'];

  // ... 展开运算符：将另一个集合的元素插入 → // ... operador de expansión: inserta los elementos de otra colección
  var allCourses = ['RUNOOB 入门' → 'Introducción a RUNOOB', ...basics, ...advanced];
  print('所有课程: $allCourses' → 'Todos los cursos: $allCourses');

  // ...? 空安全展开：如果集合为 null，则跳过 → // ...? expansión segura contra nulos: si la colección es null, se omite
  List<String>? optionalList;  // 可能为 null → // podría ser null
  var safeList = ['第一项' → 'Primer elemento', ...?optionalList];
  print('安全展开: $safeList' → 'Expansión segura: $safeList');  // 只有第一项 → // solo el primer elemento

  optionalList = ['额外内容' → 'Contenido adicional'];
  safeList = ['第一项' → 'Primer elemento', ...?optionalList];
  print('有值展开: $safeList' → 'Expansión con valor: $safeList');
}

if y for en colecciones (control de flujo en colecciones)

Dart 允许在集合字面量中直接使用 if 和 for，这是非常实用的语法糖。 → Dart permite usar if y for directamente en los literales de colección; esto es un azúcar sintáctico muy práctico.

Ejemplo

void main() {
  bool showAdmin = true;

  // 集合中的 if：根据条件决定是否包含元素 → // if en colecciones: decide si incluir un elemento según una condición
  var menuItems = [
    '首页' → 'Inicio',
    '教程' → 'Tutorial',
    if (showAdmin) '管理后台' → 'Panel de administración',  // 条件为 true 时才加入 → // se agrega solo si la condición es true
    '关于' → 'Acerca de',
  ];
  print('菜单: $menuItems' → 'Menú: $menuItems');

  // 集合中的 for：从另一个集合生成元素 → // for en colecciones: genera elementos a partir de otra colección
  var numbers = [1, 2, 3];
  var doubled = [
    for (var n in numbers) n * 2,  // 遍历生成新元素 → // recorre para generar nuevos elementos
  ];
  print('翻倍: $doubled' → 'Duplicados: $doubled');

  // if + for 可以组合使用 → // if + for se pueden combinar
  var tags = ['Dart', 'Flutter'];
  var links = [
    'RUNOOB 首页' → 'Página principal de RUNOOB',
    for (var tag in tags) 'https://runoob.com/$tag',
  ];
  print('链接: $links' → 'Enlaces: $links');
}
菜单: [首页, 教程, 管理后台, 关于]
翻倍: [2, 4, 6]
链接: [RUNOOB 首页, https://runoob.com/Dart, https://runoob.com/Flutter]

Notas

Set 和 Map 都使用 → Tanto Set como Map usan{}como literal.

区别在于： → La diferencia es:

  • Map 使用 → Map usakey: value形式（有冒号） → forma (con dos puntos)
  • Set 直接写元素（没有冒号） → Set escribe los elementos directamente (sin dos puntos)

例如： → Por ejemplo:

var map = {'name': 'Tom'};   // Map
var set = {'Tom', 'Jerry'}; // Set

需要特别注意： → Se debe prestar especial atención:

var x = {};

这不会创建空 Set，而会被 Dart 推断为： → Esto no crea un Set vacío, sino que Dart lo infiere como:

Map<dynamic, dynamic>

因为空花括号无法判断元素类型，Dart 默认按 Map 处理。 → Porque las llaves vacías no permiten determinar el tipo de elemento, Dart lo trata como Map por defecto.

如果要创建空 Set，必须显式指定： → Si se quiere crear un Set vacío, se debe especificar explícitamente:

var x = <String>{};

或

： 
Set<String> x = {};
