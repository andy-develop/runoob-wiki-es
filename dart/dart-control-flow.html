Control de flujo en Dart

El control de flujo determina el orden en que se ejecuta el código del programa.

Este capítulo presenta las sentencias condicionales (if/else, switch) y los bucles (for, while) en Dart, así como el uso de break y continue.

Sentencias condicionales if / else / else if

La sentencia if es la estructura de control de flujo más básica; decide si se ejecuta un bloque de código según una condición.

Ejemplo

Sentencia if básica:

void main() {
  int score = 85;

  // if básico: se ejecuta cuando la condición es true
  if (score >= 60) {
    print('RUNOOB ¡Felicidades, aprobaste!');
  }

  // if-else: elegir una de dos opciones
  if (score >= 90) {
    print('Excelente');
  } else {
    print('Sigue esforzándote');
  }

  // if-else if-else: selección de múltiples ramas
  if (score >= 90) {
    print('Calificación: A');
  } else if (score >= 80) {
    print('Calificación: B');
  } else if (score >= 70) {
    print('Calificación: C');
  } else if (score >= 60) {
    print('Calificación: D');
  } else {
    print('Calificación: F (suspenso)');
  }
}
RUNOOB 恭喜，你及格了！
继续加油
等级：B

Las expresiones condicionales en Dart deben ser de tipo bool. No se pueden usar 0, '', null, etc. como condiciones como en JavaScript; estas formas generan errores de compilación en Dart.

Anidamiento de sentencias if

Una sentencia if puede contener otro if dentro, para manejar lógica más compleja.

Ejemplo

void main() {
  bool isLoggedIn = true;
  bool isAdmin = false;
  String username = 'runoob';

  if (isLoggedIn) {
    // Verificación externa: si está conectado
    if (isAdmin) {
      // Verificación interna: si es administrador
      print('Bienvenido de nuevo, administrador $username');
    } else {
      print('Bienvenido de nuevo, $username');
    }
  } else {
    print('Por favor, inicia sesión primero');
  }
}
欢迎回来，runoob

Demasiados niveles de anidamiento reducen la legibilidad; se recomienda no superar 3 niveles.

Si la lógica es realmente compleja, considera usar retorno anticipado (return) o dividir funciones para simplificarla.

Ejemplo

Usar retorno anticipado en lugar de anidamiento profundo:

// Usar retorno anticipado en lugar de anidamiento profundo mejora la legibilidad
String getAccessMessage(bool isLoggedIn, bool isAdmin, String name) {
  // Primero se maneja el caso de "devolver si no se cumple la condición"
  if (!isLoggedIn) {
    return 'Por favor, inicia sesión primero';
  }

  if (!isAdmin) {
    return 'No tienes permisos de administrador';
  }

  // Finalmente, la lógica principal
  return 'Bienvenido de nuevo, administrador $name';
}

void main() {
  print(getAccessMessage(true, false, 'runoob'));
  print(getAccessMessage(true, true, 'runoob'));
}
你没有管理权限
欢迎回来，管理员 runoob

Selección múltiple con switch / case

Cuando una variable tiene varios valores fijos posibles, switch es más claro que if-else if.

Ejemplo

void main() {
  String day = 'Miércoles';

  switch (day) {
    case 'Lunes':
      print('Comienza una nueva semana');
      break;  // break termina el case actual, evita la "caída" al siguiente case
    case 'Martes':
      print('El esfuerzo del segundo día');
      break;
    case 'Miércoles':
      print('Ya pasó la mitad de la semana');
      break;
    case 'Jueves':
      print('Casi es viernes');
      break;
    case 'Viernes':
      print('TGIF！');
      break;
    case 'Sábado':
    case 'Domingo':
      // Varios case pueden compartir un mismo bloque de código
      print('¡Feliz fin de semana!');
      break;
    default:
      // Se ejecuta cuando ningún case coincide
      print('Fecha desconocida');
  }
}
Ya estamos a mitad de semana

El switch de Dart no tiene "caída" (fall-through) automática; cada case no vacío debe terminar con break, return, throw o continue. Para lograr el efecto de "caída", usa continue con una etiqueta (label).

Expresión switch (Dart 3.0+)

Dart 3.0 introdujo la expresión switch, que puede producir directamente un valor y es más concisa.

Ejemplo

void main() {
  String day = 'Miércoles';

  // Expresión switch: devuelve directamente un valor
  String mood = switch (day) {
    'Lunes' => 'Un poco somnoliento',
    'Martes' => 'Empezando a adaptarse',
    'Miércoles' => 'Lleno de energía',
    'Jueves' => 'Esperando el fin de semana',
    'Viernes' => 'De buen humor',
    'Sábado' || 'Domingo' => 'Libre y sin preocupaciones',
    _ => 'Desconocido'  // _ es el comodín, equivalente a default
  };

  print('RUNOOB Estado de ánimo: $mood');
}
RUNOOB 心情: 干劲十足

La expresión switch requiere cubrir todos los casos posibles; el compilador se encarga de comprobar si falta alguno.

Bucle for

El bucle for es la estructura de bucle más utilizada; es adecuada cuando se sabe el número de iteraciones.

Bucle for estándar

Ejemplo

void main() {
  // Bucle for estándar: inicialización; condición; actualización
  for (int i = 1; i <= 5; i++) {
    print('RUNOOB Iteración $i');
  }

  // La variable de bucle también se puede declarar fuera
  int j = 0;
  for (; j < 3; j++) {
    print('j = $j');
  }
}

RUNOOB 第 2 次循环
RUNOOB 第 3 次循环
RUNOOB 第 4 次循环
RUNOOB 第 5 次循环
j = 0
j = 1
j = 2

Bucle for-in (recorrer colecciones)

for-in es la forma más concisa de recorrer colecciones como List, Set, etc.

Ejemplo

void main() {
  List<String> fruits = ['Manzana', 'Plátano', 'Naranja', 'Uva'];

  // for-in: extrae los elementos de la colección uno a uno
  for (var fruit in fruits) {
    print('RUNOOB Fruta: $fruit');
  }
}
RUNOOB 水果: 苹果
RUNOOB 水果: 香蕉
RUNOOB 水果: 橙子
RUNOOB 水果: 葡萄

Método forEach

List y Set también proporcionan el método forEach, que usa una función de callback para procesar cada elemento.

Ejemplo

void main() {
  List<int> scores = [85, 92, 78, 60];

  // forEach: ejecuta la función de callback para cada elemento
  scores.forEach((score) {
    String result = score >= 60 ? 'Aprobado' : 'Reprobado';
    print('RUNOOB Puntuación: $score -> $result');
  });
}
RUNOOB 分数: 85 -> 及格
RUNOOB 分数: 92 -> 及格
RUNOOB 分数: 78 -> 及格
RUNOOB 分数: 60 -> 及格

Bucles while y do-while

El bucle while verifica la condición antes de cada iteración; es adecuado cuando el número de iteraciones es incierto.

Ejemplo

void main() {
  // while: primero evalúa la condición, luego ejecuta
  int count = 3;
  while (count > 0) {
    print('RUNOOB Cuenta regresiva: $count');
    count--;  // Recuerda actualizar la variable de condición, de lo contrario se crea un bucle infinito
  }
  print('¡Lanzamiento!');
}
RUNOOB 倒计时: 3
RUNOOB 倒计时: 2
RUNOOB 倒计时: 1
发射！

La diferencia con while es que do-while ejecuta el cuerpo del bucle al menos una vez, porque la condición se evalúa al final.

Ejemplo

void main() {
  // do-while: ejecuta una vez, luego evalúa la condición
  int num = 0;
  do {
    print('RUNOOB Se ejecuta al menos una vez, num = $num');
    num++;
  } while (num < 0);  // La condición es false desde el principio

  print('Fin del bucle, num = $num');
}
RUNOOB 至少执行一次，num = 0
循环结束，num = 1

do-while garantiza que el cuerpo del bucle se ejecute al menos una vez, incluso si la condición no se cumple al principio. Esto es útil en escenarios de "probar primero y luego decidir", por ejemplo, leer la entrada del usuario hasta que sea válida.

break y continue

break se usa para salir inmediatamente de todo el bucle; continue se usa para omitir la iteración actual y pasar a la siguiente.

Ejemplo

void main() {
  // break: detiene el bucle inmediatamente después de encontrar el objetivo
  List<String> names = ['Alice', 'Bob', 'runoob', 'David'];

  for (var name in names) {
    print('Comprobando: $name');
    if (name == 'runoob') {
      print('¡Encontré RUNOOB!');
      break;  // sale del bucle y deja de comprobar los elementos restantes
    }
  }

  print('---línea divisoria---');

  // continue: omite la iteración actual
  for (int i = 1; i <= 5; i++) {
    if (i == 3) {
      continue;  // omite la iteración en la que i=3
    }
    print('RUNOOB vez $i');
  }
}

break y continue con etiquetas

En bucles anidados, las etiquetas te permiten salir de un bucle exterior específico.

Ejemplo

void main() {
  // la etiqueta outerLoop marca el bucle exterior
  outerLoop:
  for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
      print('i=$i, j=$j');
      if (i == 2 && j == 2) {
        print('Encontré el objetivo, salgo del bucle exterior');
        break outerLoop;  // sale del bucle exterior etiquetado como outerLoop
      }
    }
  }
  print('Fin del bucle');
}
i=1, j=1
i=1, j=2
i=1, j=3
i=2, j=1
i=2, j=2
找到目标，退出外层循环
循环结束

Las etiquetas (label) deben usarse con precaución. En la mayoría de los casos, extraer la lógica de los bucles anidados a una función independiente y usar return para salir es más claro.
