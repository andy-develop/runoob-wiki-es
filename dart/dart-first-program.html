El primer programa en Dart

La mejor forma de aprender un lenguaje de programación no es memorizar primero las reglas de sintaxis, sino ejecutar un programa y luego preguntarse línea por línea qué significa.

En este capítulo partiremos del programa más simple y lo ampliaremos gradualmente hasta un pequeño programa más completo, repasando así los conceptos más básicos de Dart.

La extensión de archivo estándar de Dart.dart, por ejemplohello.dart。

El programa más simple: ¡Hola, Dart!

Abre DartPadhttps://dartpad.dev(o crea un archivo hello.dart con un editor local) e ingresa el siguiente código:

Ejemplo

void main() {
  print('Hello, Dart!');
}

Haz clic en Ejecutar, salida:

Hello, Dart!

Comando para ejecutar en el entorno local:

dart hello.dart

Solo estas 3 líneas de código. Ahora vamos a entender cada carácter.

Análisis línea por línea

void main() {

Esta es la declaración de la función de entrada del programa. Un programa Dart siempre comienza su ejecución en main().

Desglosado:

ParteSignificado
voidTipo de retorno. `void` significa que esta función no devuelve ningún valor después de ejecutarse.
mainNombre de la función. Este es el nombre de función de entrada convenido por Dart; no se puede cambiar por otro.
()Lista de parámetros. Aquí está vacía, lo que indica que la función main no acepta ningún parámetro.
{Inicio del cuerpo de la función. Hace par con la llave `}` de la última línea y envuelve todo el código de la función.

main() es la única entrada de Dart. No importa cuántos archivos o clases tenga tu programa; la ejecución siempre comienza desde la primera línea de main().

print('Hello, Dart!');

Esta es una sentencia que sirve para imprimir el contenido entre paréntesis en la consola.

Desglosado:

ParteSignificado
printNombre de función incorporada, usada para imprimir una línea de texto en la consola.
(...)Lista de parámetros de la llamada a la función.
'Hello, Dart!'Un literal de cadena, delimitado por comillas simples `'`.
;Terminador de sentencia. Cada sentencia debe terminar con punto y coma.
Los dos espacios iniciales.Indentación, indica que esta línea de código pertenece al interior de la función main(). Dart conviene en usar 2 espacios para indentar.

}

Marca el fin del cuerpo de la función main(), hace par con `{` del inicio.

Diagrama de la estructura general

void main() {          ← 函数签名（返回类型 + 函数名 + 参数）
  print('Hello,        ← 函数体：调用 print 函数
         Dart!');      ← 传入字符串参数，以 ; 结尾
}                      ← 函数体结束

Dos formas de escribir cadenas

En Dart, las cadenas pueden delimitarse con comillas simples o dobles; ambas son completamente equivalentes.

Ejemplo

void main() {
  print('Hello, Dart!');   // comillas simples
  print("Hello, Dart!");   // comillas dobles, mismo efecto
}
Hello, Dart!
Hello, Dart!

¿Cuándo usar cada tipo de comilla? Puedes consultar los siguientes escenarios:

EscenarioRecomendaciónEjemplo
Caso generalComillas simples (convención de la comunidad Dart)'Hello'
La cadena contiene comillas simplesComillas dobles"It's a beautiful day!"
La cadena contiene comillas doblesComillas simples'Él dijo: "Hola"'

Cuando el contenido de la cadena contiene comillas simples, es más conveniente usar comillas dobles para evitar el escape. La comunidad Dart acuerda usar preferentemente comillas simples; el resto de este tutorial también usará principalmente comillas simples.

Comentarios

Los comentarios son texto explicativo dirigido a las personas; el compilador de Dart los ignora por completo.

Ejemplo

void main() {
  // Esto es un comentario de una línea, desde // hasta el final de la línea
  print('Hello, Dart!'); // También puede escribirse después de una sentencia

  /*
Esto es un comentario multilínea.
Puede abarcar varias líneas,
Se usa a menudo para comentar temporalmente un bloque grande de código.
  */

  /// Esto es un comentario de documentación, usado para describir la función, clase o variable.
  /// El IDE mostrará los comentarios de documentación como sugerencias emergentes.
}
Tipos de comentariosSintaxisUso
Comentario de una línea// contenidoExplicar una línea de código
Comentario multilínea/* contenido */Comentar un bloque de código o escribir explicaciones largas
Comentario de documentación/// contenidoDescribir una API, usado para generar documentación

Un buen comentario explica el "por qué", no el "qué hace". El código ya muestra lo que hace; el comentario debe complementar la razón o intención detrás de él.

Variables: dar nombre a los datos

Un programa no puede limitarse a imprimir texto fijo; necesitamos variables para almacenar y usar datos.

Ejemplo

void main() {
  String name = 'RUNOOB';
  int age = 25;
  double height = 1.68;
  bool isStudent = true;

  print(name);
  print(age);
  print(height);
  print(isStudent);
}
RUNOOB
25
1.68
true

Formato de declaración de variables

类型名  变量名  =  初始值  ;
 │       │         │    └─ 语句结束符
 │       │         └─ 赋值运算符
 │       └─ 你给这个数据起的名字
 └─ 告诉 Dart 这个变量存储什么类型的数据

Resumen rápido de los tipos de datos básicos

TipoDescripciónEjemplo
StringCadena de texto'RUNOOB'、"hello"
intNúmero entero25、-10、0
doubleNúmero decimal (coma flotante)1.68、3.14
boolValor booleano (verdadero/falso)true、false

Los detalles de los tipos de datos se ampliarán en los siguientes capítulos; por ahora basta con una impresión inicial.

Usar var para inferir el tipo automáticamente

Escribir el nombre del tipo cada vez es un poco tedioso.

Dart admite el uso de la palabra clave `var` para inferir automáticamente el tipo de la variable: el compilador determinará el tipo según el valor asignado.

Ejemplo

void main() {
  var name = 'RUNOOB';    // Se infiere como String
  var age = 25;           // Se infiere como int
  var height = 1.68;      // Se infiere como double
  var isStudent = true;   // Se infiere como bool

  print(name);
  print(age);
}
RUNOOB
25

El tipo inferido por `var` se determina en tiempo de compilación; después no se puede asignar un valor de otro tipo.

Ejemplo

void main() {
  var name = 'RUNOOB';
  name = 'Bob';    // Válido, sigue siendo String
  // name = 123; // Error: no se puede asignar un int a una variable de tipo String
}

¿Cuándo usar var y cuándo especificar el tipo?

EscenarioRecomendaciónMotivo
Variables locales donde el tipo se ve de un vistazovarMás conciso
Parámetros de función, campos de clase, tipos de retornoEspecificar el tipoCódigo más claro y autodocumentado

Interpolación de cadenas: incrustar variables en cadenas

Si quieres incrustar el valor de una variable en una cadena, Dart ofrece una sintaxis muy concisa de interpolación de cadenas: `$nombreVariable` o `${expresión}`.

Ejemplo

void main() {
  var name = 'RUNOOB';
  var age = 25;

  print('Me llamo $name, y tengo $age años.');
  print('El año que viene tendré ${age + 1} años.');
}
我叫 RUNOOB，今年 25 岁。
明年我将 26 岁。
SintaxisUsoEjemplo
$variableIncrusta directamente el valor de la variable, es conciso.$name
${expresión}Incrusta cualquier expresión (cálculos, llamadas a métodos, etc.)${age + 1}、${name.toUpperCase()}

En comparación con la concatenación de cadenas como `print('Me llamo ' + name + ', tengo ' + age.toString() + ' años.')`, la sintaxis de interpolación es más clara y segura, y es el estilo habitual en Dart.

Un pequeño programa más completo

Ahora vamos a integrar lo aprendido anteriormente y escribir un programa un poco más real: un simple generador de presentaciones personales.

  print('=============================');

  print('今年 $age 岁，是一名$occupation。');
  print('我的爱好是${hobby}，很高兴认识大家！');
  print('=============================');
}

Sintaxis nueva: el operador ternario

Ejemplo

var occupation = isStudent ? '学生' : '职场人';

Este es el operador ternario de Dart, con el siguiente formato:

condición ? valor si la condición es verdadera : valor si la condición es falsa

Equivale a la siguiente escritura con if/else:

Ejemplo

String occupation;
if (isStudent) {
  occupation = '学生';
} else {
  occupation = '职场人';
}

El operador ternario es muy conciso cuando solo hay dos valores posibles. En los capítulos siguientes se explicará en detalle el uso completo de if/else.

Estilo de código: convenciones de escritura de Dart

Un buen estilo de código hace que el código sea más legible y más profesional.

Dart tiene un conjunto de convenciones oficialmente recomendadas; en la etapa inicial basta con dominar los siguientes puntos.

Indentar con 2 espacios

Ejemplo

// Correcto: 2 espacios
void main() {
  print('Hello');
}

// No recomendado: 4 espacios (común en otros lenguajes, pero la comunidad de Dart prefiere 2)

Los nombres de variables y funciones usan lowerCamelCase (camelCase en minúscula inicial)

Ejemplo

var firstName = 'RUNOOB';     // lowerCamelCase: correcto
// var first_name = 'RUNOOB'; // Estilo con guion bajo: no es convención de Dart
// var FirstName = 'RUNOOB'; // UpperCamelCase: reservado para nombres de clases

Los nombres de clases usan UpperCamelCase (CamelCase con inicial mayúscula)

Ejemplo

class UserProfile { }   // Correcto
// class user_profile { } // Incorrecto
// class userProfile { } // Incorrecto

Las constantes usan lowerCamelCase (no todo en mayúsculas)

Ejemplo

const maxRetries = 3;       // Convención de Dart: correcto
// const MAX_RETRIES = 3; // Este es el estilo de C/Java, Dart no lo recomienda

Usar dart format para formatear automáticamente

No es necesario memorizar las convenciones, solo ejecuta lo siguiente en el directorio del proyecto:

$ dart format .

La herramienta de formato oficial de Dart ajustará automáticamente el código al estilo estándar. Al guardar, también puedes configurar VS Code para que formatee automáticamente.

Errores comunes y su interpretación

Los principiantes suelen encontrarse con los siguientes errores al escribir su primer programa. ¡Vamos a conocerlos!

Error 1: Olvidar el punto y coma

Ejemplo

void main() {
  print('Hello, Dart!')  // Falta ;
}

Mensaje de error:

Error: Expected ';' after this.

Solución: agrega ; al final de la sentencia.

Error 2: Paréntesis o llaves no coincidentes

Ejemplo

void main() {
  print('Hello, Dart!'   // Falta el paréntesis derecho )
}

Mensaje de error:

Error: Expected ')' before this.

Solución: revisa cuidadosamente que cada ( tenga su correspondiente ). VS Code resaltará los paréntesis que no coinciden.

Error 3: Comillas de cadena no coincidentes

void main() {
  print('Hello, Dart!");  // 一个单引号、一个双引号
}

Mensaje de error:

Error: Unterminated string literal.

Solución: asegúrate de que ambos extremos de la cadena usen el mismo tipo de comillas.

Error 4: Error de ortografía en main

Ejemplo

void Main() {  // La M está en mayúscula
  print('Hello, Dart!');
}

Dart distingue entre mayúsculas y minúsculas. Main y main son nombres completamente diferentes.

El programa compila, pero se produce un error en tiempo de ejecución:

Error: No 'main' method found.

Solución: la función de entrada debe ser main en minúsculas.

Error 5: Variable no asignada antes de usarse

Ejemplo

void main() {
  String name;
  print(name);  // name no está inicializado
}

Mensaje de error del mecanismo de null safety de Dart:

Error: Non-nullable variable 'name' must be assigned before it can be used.

Solución: asigna un valor inicial al declarar la variable, o declárala como tipo anulable String? name (se detallará en capítulos posteriores).
