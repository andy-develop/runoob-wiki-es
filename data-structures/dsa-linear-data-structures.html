En este capítulo, presentaremos el tipo de estructura de datos más básico y común:Estructura de datos lineal。

Estructura de datos linealEs como una fila de personas haciendo cola:

  • Cada persona (elemento) tiene una relación clara de anterior y posterior
  • Excepto el primero y el último, cada persona tiene un predecesor y un sucesor
  • Entre los elementos de datos existe una relación lineal uno a uno

Imagina que estás haciendo cola para comprar café u ordenando los libros de una estantería.

Estas situaciones tienen algo en común: los elementos están dispuestos uno tras otro, formando una línea.

En ciencias de la computación, este conjunto de datos ordenados secuencialmente es una estructura de datos lineal.

La característica de las estructuras de datos lineales es que, excepto el primer y el último elemento, cada elemento tiene exactamente unpredecesory unsucesor。

Estructuras de datos lineales comunes:

  1. Arreglo: como una fila de taquillas numeradas, cada una con una posición fija
  2. Lista enlazada: como una cadena de personas tomadas de la mano, donde cada una solo recuerda a la persona anterior y a la siguiente
  3. 栈: como una pila de platos, solo se puede tomar o colocar desde la parte superior
  4. Cola: como hacer cola para comprar boletos, primero en llegar, primero en ser atendido

Arreglo: el edificio de apartamentos fijo de los datos

El arreglo es la estructura de datos lineal más simple y directa.

Podemos imaginarlo como unedificio de apartamentos con un número fijo de pisos。

Conceptos básicos y características

  • Almacenamiento contiguo: el arreglo ocupa un bloquecontiguode memoria, como las habitaciones de un edificio de apartamentos que están una al lado de la otra.
  • Tamaño fijo: el arreglo debe definir su capacidad (longitud) al crearse y, generalmente, no puede cambiar después, igual que el número de habitaciones de un edificio de apartamentos queda fijo una vez construido.
  • Acceso por índice: cada elemento (habitación) tiene un número único, llamadoíndice. En la mayoría de los lenguajes de programación, los índices comienzan desde00. Puedes acceder directa y rápidamente a cualquier elemento mediante el índice, con una complejidad temporal de O(1).O(1)。

Operaciones principales y ejemplos de código

Ventajas y desventajas

Ventajas Desventajas
Acceso aleatorio rápido: mediante el índice se puede acceder a cualquier elemento en tiempo constante. Tamaño fijo: una vez creado un arreglo estático, su capacidad es difícil de cambiar.
Alta eficiencia de memoria: almacenamiento contiguo, no se necesita espacio adicional para almacenar las relaciones entre elementos. Alto costo de inserción/eliminación: Insertar o eliminar elementos en el medio requiere desplazar muchos elementos posteriores para mantener la continuidad.

Lista enlazada: el tren de búsqueda del tesoro de los datos

Cuando el tamaño fijo de los arrays y la ineficiencia de las inserciones y eliminaciones se convierten en un problema, aparecen las listas enlazadas. Una lista enlazada es como untren, donde cada vagón (nodo) lleva carga (datos) y se conecta con el siguiente vagón mediante un gancho (puntero).

Conceptos básicos y tipos

Cadanodode una lista enlazada contiene al menos dos partes:

  1. Campo de datos: almacena el valor real de los datos.
  2. Campo de puntero: almacena la dirección en memoria del siguiente nodo.

La figura anterior muestra una estructura delista enlazada simple. El puntero de cabecera apunta al primer nodo, elNextpuntero de cada nodo apunta al siguiente nodo, y el del último nodoNextapunta aNULL, lo que indica el final de la lista.

Tipos principales de listas enlazadas:

  • Lista enlazada simple: el nodo solo apunta al siguiente nodo.
  • Lista doblemente enlazada: el nodo apunta tanto al anterior como al siguiente, permitiendo recorrer en ambos sentidos.
  • Lista circular enlazada: el nodo final apunta al nodo cabecera, formando un anillo.

Operaciones principales y ejemplos de código

Implementemos una lista enlazada simple.

Ejemplo

class ListNode:
    """Definir la clase de nodo de la lista enlazada"""
    def __init__(self, data):
        self.data = data  # Campo de datos
        self.next = None  # Campo de puntero, inicialmente apunta a vacío

class LinkedList:
    """Definir la clase de lista enlazada simple"""
    def __init__(self):
        self.head = None  # Puntero de cabecera de la lista

    def append(self, data):
        """Agregar un nodo al final de la lista enlazada"""
        new_node = ListNode(data)
        if not self.head:  # Si la lista está vacía, el nuevo nodo se convierte en el nodo cabecera
            self.head = new_node
            return
        last_node = self.head
        while last_node.next:  # Recorrer hasta el último nodo
            last_node = last_node.next
        last_node.next = new_node  # Colgar el nuevo nodo al final

    def prepend(self, data):
        """Agregar un nodo al inicio de la lista enlazada"""
        new_node = ListNode(data)
        new_node.next = self.head
        self.head = new_node

    def delete(self, key):
        """Eliminar el primer nodo cuyo valor sea key"""
        current_node = self.head

        # Si lo que se va a eliminar es el nodo cabecera
        if current_node and current_node.data == key:
            self.head = current_node.next
            current_node = None
            return

        prev_node = None
        # Recorrer buscando el nodo a eliminar
        while current_node and current_node.data != key:
            prev_node = current_node
            current_node = current_node.next

        if current_node is None:  # No se encontró
            return

        # Una vez encontrado, omitir el nodo para reconectar
        prev_node.next = current_node.next
        current_node = None

    def print_list(self):
        """Imprimir todos los elementos de la lista enlazada"""
        current_node = self.head
        while current_node:
            print(current_node.data, end=" -> ")
            current_node = current_node.next
        print("NULL")

# Probar la lista enlazada
print("=== Demostración de operaciones con lista enlazada simple ===")
train = LinkedList()
train.append("Vagón 1 - Carbón")
train.append("Vagón 2 - Madera")
train.prepend("Locomotora")  # Agregar al inicio
train.append("Vagón 3 - Acero")
print("Tren inicial: ")
train.print_list()  # Salida: Locomotora -> Vagón 1 - Carbón -> Vagón 2 - Madera -> Vagón 3 - Acero -> NULL

train.delete("Vagón 2 - Madera")
print("Después de descargar la madera: ")
train.print_list()  # Salida: Locomotora -> Vagón 1 - Carbón -> Vagón 3 - Acero -> NULL

卸下木材后：

Ventajas y desventajas

Ventajas Desventajas
Tamaño dinámico: no requiere asignar espacio fijo de antemano; puede crecer y reducirse con flexibilidad. Sobrecarga de memoria: cada nodo necesita espacio adicional para almacenar punteros.
Inserción/eliminación eficiente: cuando se conoce la posición del nodo, solo hay que modificar punteros, sin necesidad de mover muchos elementos. Acceso secuencial: no se puede acceder directamente por índice como en un array; hay que recorrer desde el principio.
Poco amigable con la caché: los nodos se almacenan de forma dispersa en memoria, lo que dificulta la precarga de la caché de la CPU.

Pila: el apilamiento de platos de los datos

Una pila es unaestructura de datos LIFO (último en entrar, primero en salir), como los platos apilados en un restaurante: siempre tomas el de arriba (el último que se puso).

Conceptos básicos y operaciones

Una pila solo permite en un extremo (llamadocima de la pila) realizar la inserción (push/apilar) y la eliminación (pop/desapilar). El otro extremo se llamafondo de la pila。

Operaciones principales:

  • push(data): empuja un dato a la cima de la pila.
  • pop(): saca y devuelve el elemento de la cima.
  • peek() / top(): observa el elemento de la cima sin sacarlo.
  • is_empty(): comprueba si la pila está vacía.

Escenarios de aplicación y ejemplos de código

La pila tiene aplicaciones muy amplias en ciencias de la computación, por ejemplo: pila de llamadas a funciones, avanzar/retroceder en el navegador, evaluación de expresiones, comprobación de paréntesis, etc.

Ejemplo

class Stack:
    """Implementar una pila usando una lista"""
    def __init__(self):
        self.items = []

    def push(self, item):
        """Push (apilar)"""
        self.items.append(item)  # El final de la lista actúa como cima de la pila

    def pop(self):
        """Pop (desapilar); si la pila está vacía, devuelve None"""
        if not self.is_empty():
            return self.items.pop()
        return None

    def peek(self):
        """Ver el elemento de la cima"""
        if not self.is_empty():
            return self.items[-1]
        return None

    def is_empty(self):
        """Comprobar si la pila está vacía"""
        return len(self.items) == 0

    def size(self):
        """Devolver el tamaño de la pila"""
        return len(self.items)

# Ejemplo de uso: comprobación de paréntesis balanceados
def is_balanced_parentheses(expression):
    """
Comprueba si los paréntesis de una expresión coinciden correctamente.
Por ejemplo: (()) está balanceado, (() no lo está.
    """
    stack = Stack()
    # Mapa de coincidencia de paréntesis
    matching_bracket = {')': '(', ']': '[', '}': '{'}

    for char in expression:
        if char in '([{':  # Si es un paréntesis de apertura, se apila
            stack.push(char)
        elif char in ')]}':  # Si es un paréntesis de cierre
            if stack.is_empty():
                return False  # La pila está vacía, hay demasiados paréntesis de cierre
            top_char = stack.pop()
            if matching_bracket[char] != top_char:  # Comprobar si coinciden
                return False
    # Al terminar el bucle, la pila debe estar vacía
    return stack.is_empty()

# Probar la pila y la comprobación de paréntesis
print("\n"=== Demostración de pila y paréntesis balanceados ===")
plate_stack = Stack()
plate_stack.push("Plato 1")
plate_stack.push("Plato 2")
plate_stack.push("Plato 3")
print(f"Sacar el plato superior: {plate_stack.pop()}")  # Salida: Plato 3
print(f"Ahora el plato superior es: {plate_stack.peek()}")  # Salida: Plato 2

# Probar la comprobación de paréntesis
test_cases = ["((1+2)*3)", "({[ ]})", "((())", ")( )"]
for test in test_cases:
    result = "balanceados" if is_balanced_parentheses(test) else "no balanceados"
    print(f"La expresión '{test}' tiene los paréntesis {result}.")

Cola: el pasillo de espera de los datos

Una cola es unaestructura de datos FIFO (primero en entrar, primero en salir), como en cualquier lugar de la vida donde hay que hacer cola (por ejemplo, la caja de un supermercado): el que llega primero recibe el servicio primero.

Conceptos básicos y operaciones

Una cola permite en un extremo (llamadofinal de la cola) realizar la inserción (enqueue/encolar), y en el otro extremo (llamadofrente de la cola) realizar la eliminación (dequeue/desencolar).

Operaciones principales:

  • enqueue(data): agrega datos al final de la cola.
  • dequeue(): elimina y devuelve datos desde el frente de la cola.
  • front() / peek(): observa los datos del frente sin eliminarlos.
  • is_empty(): comprueba si la cola está vacía.

Escenarios de aplicación y ejemplos de código

La cola se usa comúnmente en escenarios donde se deben procesar tareas en orden, como: cola de trabajos de impresión, cola de mensajes, búsqueda en anchura, etc.

Ejemplo

from collections import deque  # Usar deque de Python, que proporciona operaciones eficientes en ambos extremos

class Queue:
    """Implementar una cola usando collections.deque"""
    def __init__(self):
        self.items = deque()

    def enqueue(self, item):
        """Enqueue (encolar)"""
        self.items.append(item)  # Agregar desde la derecha (final de la cola)

    def dequeue(self):
        """Dequeue (desencolar); si la cola está vacía, devuelve None"""
        if not self.is_empty():
            return self.items.popleft()  # Eliminar desde la izquierda (frente de la cola)
        return None

    def front(self):
        """Ver el elemento del frente"""
        if not self.is_empty():
            return self.items[0]
        return None

    def is_empty(self):
        """Comprobar si la cola está vacía"""
        return len(self.items) == 0

    def size(self):
        """Devolver el tamaño de la cola"""
        return len(self.items)

# Ejemplo de uso: simular trabajos de impresión
print("\n"=== Simulación de cola y trabajos de impresión ===")
printer_queue = Queue()

# Simular la llegada de tres trabajos de impresión
tasks = ["Currículum de Alice.pdf", "Informe de Bob.doc", "Gráfico de Charlie.png"]
for task in tasks:
    printer_queue.enqueue(task)
    print(f"La tarea '{task}' se ha añadido a la cola de impresión.")

# Procesar los trabajos de impresión
print("\n"Comenzando a imprimir...")
while not printer_queue.is_empty():
    current_task = printer_queue.dequeue()
    print(f"Imprimiendo: {current_task}")
    # Simular el tiempo de impresión
print("Todos los trabajos de impresión se han completado.")
