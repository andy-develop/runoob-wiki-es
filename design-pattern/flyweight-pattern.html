Patrón Flyweight

El patrón Flyweight (Flyweight Pattern) se utiliza principalmente para reducir el número de objetos creados, a fin de disminuir el uso de memoria y mejorar el rendimiento. Este tipo de patrón de diseño pertenece a los patrones estructurales; proporciona una forma de reducir el número de objetos para mejorar la estructura de objetos que la aplicación necesita.

El patrón Flyweight intenta reutilizar los objetos existentes del mismo tipo; si no encuentra un objeto que coincida, crea uno nuevo. Demostraremos este patrón dibujando 20 círculos en diferentes posiciones mediante la creación de 5 objetos. Como solo hay 5 colores disponibles, el atributo color se utiliza para comprobar los existentesCircleobjetos.

Resumen

Intención

Reducir el consumo de memoria al crear una gran cantidad de objetos similares mediante el uso de objetos compartidos.

Problema principal que resuelve

  • Evitar el problema de desbordamiento de memoria causado por la creación de demasiados objetos.
  • Mejorar la eficiencia del uso de memoria compartiendo objetos.

Escenarios de uso

  • Cuando hay una gran cantidad de objetos similares o idénticos en el sistema.
  • Cuando el costo de crear y destruir objetos es alto.
  • Cuando el estado del objeto puede externalizarse, es decir, parte del estado del objeto puede existir independientemente del propio objeto.

Método de implementación

  • Definir la interfaz Flyweight: crear una interfaz Flyweight que especifique el estado que se puede compartir.
  • Crear la clase Flyweight concreta: la clase concreta que implementa la interfaz y contiene el estado interno.
  • Usar la fábrica Flyweight: crear una clase de fábrica para gestionar la creación y reutilización de los objetos Flyweight.

Código clave

  • HashMap: usar una tabla hash para almacenar los objetos Flyweight ya creados, de modo que se puedan recuperar rápidamente.

Ejemplos de aplicación

  1. El objeto String en Java: las cadenas que ya existen en el grupo de constantes de cadenas se reutilizan.
  2. Pool de conexiones de base de datos: las conexiones de base de datos se reutilizan para evitar crear y destruir conexiones con frecuencia.

Ventajas

  • Reducir el consumo de memoria: al compartir objetos, se reduce la cantidad de objetos en memoria.
  • Mejorar la eficiencia: se reduce el tiempo de creación de objetos y se mejora la eficiencia del sistema.

Desventajas

  • Aumentar la complejidad del sistema: es necesario separar el estado interno del estado externo, lo que incrementa la complejidad del diseño y la implementación.
  • Problemas de seguridad en hilos: si el estado externo no se maneja adecuadamente, pueden surgir problemas de seguridad en hilos.

Recomendaciones de uso

  • Considere usar el patrón Flyweight al crear una gran cantidad de objetos similares.
  • Asegúrese de que el estado interno de los objetos Flyweight sea compartido y de que el estado externo sea independiente de los objetos.

Precauciones

  • Separación de estados: distinga claramente entre el estado interno y el estado externo para evitar confusiones.
  • Fábrica Flyweight: use la fábrica Flyweight para controlar la creación y reutilización de los objetos, garantizando la consistencia e integridad de los objetos.

Estructura

El patrón Flyweight incluye los siguientes roles principales:

  • Fábrica Flyweight (Flyweight Factory):

    • Responsable de crear y gestionar los objetos Flyweight; normalmente contiene un pool (caché) para almacenar y reutilizar los objetos Flyweight ya creados.

  • Flyweight concreto (Concrete Flyweight):

    • Implementa la interfaz Flyweight abstracta y contiene el estado interno y el estado externo. El estado interno se puede compartir, mientras que el estado externo lo proporciona el cliente.

  • Flyweight abstracto (Flyweight):

    • Define la interfaz para los flyweights concretos y no compartidos; normalmente incluye un método para establecer el estado externo.

  • Cliente (Client):

    • Utiliza la fábrica Flyweight para obtener los objetos Flyweight y opera sobre ellos estableciendo el estado externo. Normalmente, el cliente no necesita preocuparse por la implementación concreta de los objetos Flyweight.

    El patrón Flyweight, en otras palabras, es compartir objetos. Se usa en situaciones donde ciertos objetos necesitan crearse repetidamente y, al final, solo se necesita un único resultado. Este patrón aprovecha los objetos existentes creados previamente y, mediante ciertas reglas, determina si el objeto que se necesita actualmente puede obtener el efecto deseado modificando el objeto original. Como en el ejemplo del tutorial anterior: se crearon 20 círculos con diferentes efectos, pero los círculos del mismo color solo necesitan crearse una vez; los del mismo color solo necesitan hacer referencia al objeto original y cambiar sus coordenadas. En este modo, aunque los círculos del mismo color tienen posiciones distintas, su dirección de memoria es la misma; por lo tanto, este patrón es adecuado para situaciones en las que se busca un único resultado.

    Pongamos un ejemplo sencillo: en un juego hay diferentes héroes, y los personajes del mismo tipo también tienen héroes con atributos distintos. Por ejemplo, hay muchos héroes de tipo asesino. Si se diseña siguiendo este patrón, se usa el tipo al que pertenece el héroe para hacer referencia a la instancia existente del mismo tipo y, luego, se modifican sus atributos correspondientes para obtener el nuevo héroe deseado. Por ejemplo, si creas el primer héroe asesino y luego necesitas diseñar un segundo héroe asesino, usas el primer héroe modificando sus atributos para obtener el segundo héroe asesino. El nuevo héroe asesino ha nacido, pero los atributos del primer héroe asesino también se vuelven iguales a los del segundo. Evidentemente, esta situación no es aceptable.

    # Flyweight Pattern with Python Code
from abc import abstractmethod,ABCMeta
import random

#创建一个Shape接口
class Shape(metaclass=ABCMeta):
    @abstractmethod
    def draw(self):
        pass
# 创建实现接口的实体类Circle
class Circle(Shape):
    _color=""
    _x =0
    _y =0
    _radius = 0

    def __init__(self, inColor):
        self._color = inColor
    def setX(self, inX):
        self._x = inX
    def setY(self,inY):
        self._y = inY
    def setRadius(self,inRadius):
        self._radius = inRadius
    def draw(self):
        print("Circle: Draw() [Color : {0}, x : {1}, y : {2}, radius : {3}]".format(self._color,self._x,self._y,self._radius))

# 创建一个工厂，生成基于给定信息的实体类的对象
class ShapeFactory():
    circleMap = {}
    @staticmethod
    def getCircle(inColor):
        circle = None
        if inColor in ShapeFactory.circleMap :
            circle = ShapeFactory.circleMap[inColor]
        else:
            circle = Circle(inColor)
            aCircle = {inColor:circle}
            ShapeFactory.circleMap.update(aCircle)
            print("Creating circle of color : " + inColor)
        return circle
# 调用输出
if __name__ == '__main__':
    colors = ["Red","Green","Blue","White","Black"]

    def getRandomColor():
        return colors[random.randint(0,len(colors)-1)]
    def getRandom():
        return random.randint(1,100)

    for i in range(20):
        ranColor = getRandomColor()
        circle = ShapeFactory.getCircle(ranColor)
        circle.setX(getRandom())
        circle.setY(getRandom())
        circle.setRadius(getRandom())
        circle.draw()

    Implementación en C++:

    // 享元模式
#include <iostream>
#include <map>
#include <ctime>

using namespace std;

class Shape {
public:
    virtual void draw() = 0;
};
class Circle : public Shape {
private:
    string color;
    int x;
    int y;
    int radius;
public:
    Circle(string color): color(color), x(0), y(0), radius(0) {}

    void setX(int newx) {
        x = newx;
    }

    void setY(int newy) {
        y = newy;
    }

    void setRadius(int newradius) {
        radius = newradius;
    }

    void draw() {
        cout << "Circle: Draw() [Color : " << color
             << ", x : " << x << ", y :" << y << ", radius :" << radius
             << endl;
    }
};
class ShapeFactory {
public:
    static map<string, Shape*> circleMap;

    static Shape* getCircle(string color) {
        if (circleMap.count(color) > 0) {
            return circleMap[color];
        }
        auto shape = new Circle(color);
        circleMap[color] = shape;
        cout << "Creating circle of color : " << color << endl;
        return shape;
    }

    static void cleanup() {
        for (auto e : circleMap) {
            delete e.second;
        }
    }
};

// 生成随机数
double random() {
    return (rand() % 10) * 0.1;
}

string colors[] = {"Red", "Green", "Blue", "White", "Black"};
string getRandomColor() {
    return colors[(int)(random() * sizeof(colors) / sizeof(colors[0]))];
}
int getRandomX() {
    return (int)(random() * 100);
}
int getRandomY() {
    return (int)(random() * 100);
}

// 定义circleMap
map<string, Shape*> ShapeFactory::circleMap;

int main() {
    srand(time(0));
    for (int i = 0; i < 20; ++i) {
        Circle circle = *(Circle*)ShapeFactory::getCircle(getRandomColor());
        circle.setX(getRandomX());
        circle.setY(getRandomY());
        circle.setRadius(100);
        circle.draw();
    }
    ShapeFactory::cleanup();
    return 0;
}
