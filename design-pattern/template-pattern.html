Patrón de Plantilla

En el patrón de plantilla (Template Pattern), una clase abstracta define públicamente la forma/plantilla para ejecutar sus métodos. Sus subclases pueden sobrescribir la implementación de los métodos según sea necesario, pero la invocación se realizará de la manera definida en la clase abstracta. Este tipo de patrón de diseño pertenece a los patrones de comportamiento.

Introducción

Intención

Define el esqueleto de un algoritmo en la clase padre y permite que las subclases redefinan ciertos pasos específicos del algoritmo sin cambiar su estructura.

Problema principal que resuelve

  • Resuelve el problema de implementar repetidamente los mismos métodos en múltiples subclases, evitando la duplicación de código al abstraer los métodos comunes en la clase padre.

Escenarios de uso

  • Cuando existen métodos comunes que pueden compartirse entre varias subclases.

Forma de implementación

  • Definir la clase padre abstracta: contiene el método plantilla y algunos métodos abstractos o concretos.
  • Implementar las subclases: heredan de la clase padre abstracta e implementan los métodos abstractos sin cambiar la estructura del algoritmo.

Código clave

  • Método plantilla: se define en la clase padre abstracta y llama a métodos abstractos y concretos.
  • Métodos abstractos: implementados por las subclases, representan la parte variable del algoritmo.
  • Métodos concretos: implementados en la clase padre abstracta, representan la parte invariable del algoritmo.

Ejemplos de aplicación

  • Proceso de construcción: pasos como los cimientos, el cableado y las tuberías son iguales; pasos posteriores como añadir armarios empotrados o vallas son diferentes.
  • Los 81 desastres de Viaje al Oeste: los 81 desastres definidos por la bodhisattva representan un esqueleto lógico de alto nivel.
  • El soporte de Spring para Hibernate: encapsula métodos comunes como abrir transacciones, obtener Session y cerrar Session.

Ventajas

  • Encapsula la parte invariable: la parte invariable del algoritmo se encapsula en la clase padre.
  • Extiende la parte variable: las subclases pueden extender o modificar la parte variable del algoritmo.
  • Extrae código común: reduce la duplicación de código y facilita el mantenimiento.

Desventajas

  • Aumento del número de clases: cada implementación diferente requiere una subclase, lo que puede hacer que el sistema sea grande.

Recomendaciones de uso

  • Cuando varias subclases tengan métodos comunes con la misma lógica, considere usar el patrón de método plantilla.
  • Para métodos importantes o complejos, se puede considerar definirlos como métodos plantilla en la clase padre.

Notas

  • Para evitar modificaciones malintencionadas, el método plantilla generalmente se modifica con lafinalpalabra clave, evitando que sea sobrescrito por las subclases.

Los principales roles involucrados

  • Clase padre abstracta (Abstract Class)：

    • Define el método plantilla y algunos métodos abstractos o concretos.

  • Subclases concretas (Concrete Classes)：

    • Heredan de la clase padre abstracta e implementan los métodos abstractos.

  • Método gancho (Hook Method) (opcional)：

    • Se define en la clase padre abstracta y puede ser sobrescrito por las subclases para afectar el comportamiento del método plantilla.

  • Cliente (Client) (opcional)：

    • Utiliza la clase padre abstracta y las subclases concretas sin preocuparse por los detalles del método plantilla.

Implementación

Vamos a crear unaGameclase abstracta que define operaciones, donde el método plantilla se establece como final, de modo que no pueda ser sobrescrito.Cricket 和 Footballson las clases de entidadGameque extienden la clase abstracta y sobrescriben sus métodos.

TemplatePatternDemo, nuestra clase de demostración usaGamepara demostrar el uso del patrón de plantilla.

Paso 1

Crear una clase abstracta cuyo método plantilla se establece como final.

Game.java

public abstract class Game { abstract void initialize(); abstract void startPlay(); abstract void endPlay(); //Plantilla public final void play(){ //Inicializar el juego initialize(); //Iniciar el juego startPlay(); //Finalizar el juego endPlay(); } }

Paso 2

Crear las clases de entidad que extienden la clase anterior.

Cricket.java

public class Cricket extends Game { @Override void endPlay() { System.out.println("Cricket Game Finished!"); } @Override void initialize() { System.out.println("Cricket Game Initialized! Start playing."); } @Override void startPlay() { System.out.println("Cricket Game Started. Enjoy the game!"); } }

Football.java

public class Football extends Game { @Override void endPlay() { System.out.println("Football Game Finished!"); } @Override void initialize() { System.out.println("Football Game Initialized! Start playing."); } @Override void startPlay() { System.out.println("Football Game Started. Enjoy the game!"); } }

Paso 3

UsarGameel método plantilla play() para demostrar la forma en que se define el juego.

TemplatePatternDemo.java

public class TemplatePatternDemo { public static void main(String[] args) { Game game = new Cricket(); game.play(); System.out.println(); game = new Football(); game.play(); } }

Paso 4

Ejecutar el programa y ver el resultado:

Cricket Game Initialized! Start playing.
Cricket Game Started. Enjoy the game!
Cricket Game Finished!

Football Game Initialized! Start playing.
Football Game Started. Enjoy the game!
Football Game Finished!

    Método en Python:

    # Template Pattern code with Python
from abc import abstractmethod,ABCMeta

# 创建一个game父类
class Game(metaclass=ABCMeta):

    # 把几乎不变的公共部分代码集中在父亲类，比如showcopyright
    # 此例子中，初始化、开始、结束三个方法，除了游戏名以外，都一样，所以把共性部分放在父类
    def initialize(self):
        print("%s Game Initialized! Start Playing." %self.setGameName())
    def startPlay(self):
        print("%s Game Started. Enjoy the game!" % self.setGameName())
    def endPlay(self):
        print("%s Game Finished! \n" % self.setGameName())
    def play(self):
        self.initialize()
        self.startPlay()
        self.endPlay()

    # 每个游戏子类的抽象部分仅仅是游戏名称的设定
    @abstractmethod
    def setGameName(self):
        pass

class Cricket(Game):
    def setGameName(self):
        return  "Cricket"

class Football(Game):
    def setGameName(self):
        return "Football"

# 调用输出
if __name__ == '__main__':
    game1 = Cricket()
    game1.play()
    game2 = Football()
    game2.play()

    Método en C++:

    Game.h

    #include <iostream>
class Game
{
protected:
    virtual void initialize() = 0;
    virtual void startPlay()  = 0;
    virtual void endPlay()      = 0;
public:
    virtual void play() {
        initialize();
        startPlay();
        endPlay();
    }
};

    Cricket.h

    #include "Game.h"

class Cricket :
    public Game
{
protected:

    virtual void initialize() {
        std::cout << "Cricket Game Finished!" << std::endl;
    }

    virtual void startPlay() {
        std::cout << "Cricket Game Initialized! Start playing." << std::endl;
    }

    virtual void endPlay() {
        std::cout << "Cricket Game Started. Enjoy the game!" << std::endl;
    }
};

        std::cout << "Football Game Started. Enjoy the game!" << std::endl;

    Implementación en PHP:

    <?php
abstract class Game{   
    abstract function initialize();  
    abstract function startPlay(); 
    abstract function endPlay(); 
    //模板   
    public final function play(){   
        //初始化游戏    
        $this->initialize();   
        //开始游戏    
        $this->startPlay();   
        //结束游戏       
        $this->endPlay();   
    }
}
class Cricket extends Game {   
    public function endPlay() {     
        echo "Cricket Game Finished!".PHP_EOL;   
    } 
    public function initialize() {  
        echo "Cricket Game Initialized! Start playing.".PHP_EOL;   
    }  
    public function startPlay() { 
        echo "Cricket Game Started. Enjoy the game!".PHP_EOL;  
    }
}
class Football extends Game { 
    public function endPlay() {  
        echo "Football Game Finished!";  
    } 
    public function initialize() { 
        echo "Football Game Initialized! Start playing.".PHP_EOL;  
    } 
    public function startPlay() { 
        echo "Football Game Started. Enjoy the game!".PHP_EOL;  
    }
}
class TemplatePatternDemo { 
    public static function main() {   
        $game = new Cricket();   
        $game->play(); 
        echo PHP_EOL;    
        $game = new Football(); 
        $game->play(); 
    }
}
TemplatePatternDemo::main();
?>
