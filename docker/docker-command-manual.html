Referencia completa de comandos Docker

Gestión del ciclo de vida de contenedores

  • run - Crea e inicia un nuevo contenedor.
  • start/stop/restart - Estos comandos se utilizan principalmente para iniciar, detener y reiniciar contenedores.
  • kill - Termina inmediatamente uno o más contenedores en ejecución.
  • rm - Se utiliza para eliminar uno o más contenedores que ya se han detenido.
  • pause/unpause - Pausa y reanuda todos los procesos dentro del contenedor.
  • create - Crea un nuevo contenedor, pero no lo inicia.
  • exec - Ejecuta un nuevo comando dentro de un contenedor en ejecución.
  • rename - Renombra un contenedor.

Operaciones con contenedores

  • ps - Lista los contenedores Docker.
  • inspect - Obtiene información detallada de los objetos Docker (contenedores, imágenes, volúmenes, redes, etc.).
  • top - Muestra los procesos que se están ejecutando en el contenedor especificado.
  • attach - Permite al usuario conectarse a un contenedor en ejecución e interactuar con él.
  • events - Obtiene los eventos generados por el daemon de Docker.
  • logs - Obtiene y visualiza la salida de registros (logs) del contenedor.
  • wait - Permite al usuario esperar a que el contenedor se detenga y obtener su código de salida.
  • export - Exporta el sistema de archivos del contenedor como un archivo tar.
  • port - Muestra la información de mapeo de puertos del contenedor.
  • stats - Muestra en tiempo real el uso de recursos de los contenedores Docker.
  • update - Actualiza los límites de recursos de los contenedores Docker, incluyendo memoria, CPU, etc.

Comandos del sistema de archivos raíz (rootfs) del contenedor

  • commit - Permite al usuario guardar el estado actual del contenedor como una nueva imagen Docker.
  • cp - Se utiliza para copiar archivos o directorios entre el contenedor y el host.
  • diff - Muestra los cambios en el sistema de archivos del contenedor Docker.

Registro de imágenes

  • login/logout - Gestiona la autenticación entre el cliente Docker y el registro Docker.
  • pull - Descarga (trae) imágenes desde un registro de Docker (por ejemplo, Docker Hub) al entorno local.
  • push - Sube (empuja) imágenes Docker construidas localmente a un registro de Docker (como Docker Hub o un registro privado).
  • search - Se utiliza para buscar imágenes en Docker Hub u otros registros.

Gestión de imágenes locales

  • images - Lista las imágenes Docker locales.
  • rmi - Elimina imágenes que ya no son necesarias.
  • tag - Crea una etiqueta (tag) para una imagen local.
  • build - Construye una imagen Docker a partir de un Dockerfile.
  • history - Muestra la información de las capas históricas de una imagen especificada.
  • save - Guarda una o más imágenes Docker en un archivo tar.
  • load - Carga imágenes Docker desde un archivo tar generado por el comando docker save.
  • import - Importa una instantánea de contenedor desde un archivo tar o una URL, creando así una nueva imagen Docker.

info|version

  • info - Muestra información a nivel de sistema de Docker, incluyendo el número actual de imágenes y contenedores.
  • version - Muestra la información de versión del cliente y del servidor Docker.

Docker Compose

  • docker compose run - Inicia un nuevo contenedor y ejecuta una aplicación específica.
  • docker compose rm - Inicia un nuevo contenedor y elimina una aplicación específica.
  • docker compose ps - Comprueba el estado de los contenedores Docker desde docker compose.
  • docker compose build - Construye el archivo docker compose.
  • docker compose up - Ejecuta el archivo docker compose.
  • docker compose ls - Lista los servicios de docker compose.
  • docker compose start - Inicia los contenedores creados por el archivo docker compose.
  • docker compose restart - Reinicia los contenedores creados por el archivo docker compose.
  • docker compose down - Elimina los contenedores y redes asociados a los servicios.

Comandos de red

  • docker network ls: Lista todas las redes.
  • docker network create <network>: Crea una nueva red.
  • docker network rm <network>: Elimina la red especificada.
  • docker network connect <network> <container>: Conecta un contenedor a una red.
  • docker network disconnect <network> <container>: Desconecta un contenedor de una red.

Consulta el contenido detallado:Comandos de docker network

Comandos de volúmenes

  • docker volume ls: Lista todos los volúmenes.
  • docker volume create <volume>: Crea un nuevo volumen.
  • docker volume rm <volume>: Elimina el volumen especificado.
  • docker volume inspect <volume>: Muestra la información detallada del volumen.
