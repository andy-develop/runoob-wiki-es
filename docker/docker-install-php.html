Despliegue de Nginx + PHP

Puedes ver el despliegue de Nginx en:Instalar Nginx con Docker, para parte de la configuración de Nginx, consulta este artículo.

Iniciar PHP:

$ docker run --name  myphp-fpm -v ~/nginx/www:/www  -d php:5.6-fpm

Explicación del comando:

  • --name myphp-fpm: nombra el contenedor 'myphp-fpm'.

  • -v ~/nginx/www:/www: monta el directorio www del proyecto en el host en el directorio /www del contenedor.

Crea el directorio ~/nginx/conf/conf.d:

mkdir ~/nginx/conf/conf.d

Agrega en este directorio~/nginx/conf/conf.d/runoob-test-php.confel archivo, con el siguiente contenido:

server {
    listen       80;
    server_name  localhost;

    location / {
        root   /usr/share/nginx/html;
        index  index.html index.htm index.php;
    }

    error_page   500 502 503 504  /50x.html;
    location = /50x.html {
        root   /usr/share/nginx/html;
    }

    location ~ \.php$ {
        fastcgi_pass   php:9000;
        fastcgi_index  index.php;
        fastcgi_param  SCRIPT_FILENAME  /www/$fastcgi_script_name;
        include        fastcgi_params;
    }
}

Explicación del archivo de configuración:

  • php:9000: indica la URL del servicio php-fpm; lo explicaremos en detalle más adelante.
  • /www/: esmyphp-fpmla ruta de almacenamiento de los archivos php en ..., mapeada al directorio local ~/nginx/www.

Iniciar nginx:

docker run --name runoob-php-nginx -p 8083:80 -d \
    -v ~/nginx/www:/usr/share/nginx/html:ro \
    -v ~/nginx/conf/conf.d:/etc/nginx/conf.d:ro \
    --link myphp-fpm:php \
    nginx
  • -p 8083:80: mapeo de puertos; mapeanginxel puerto 80 de ... al puerto local 8083.
  • ~/nginx/www: es el directorio local de almacenamiento de archivos html; /usr/share/nginx/html es el directorio de almacenamiento de archivos html dentro del contenedor.
  • ~/nginx/conf/conf.d: es el directorio local de almacenamiento de archivos de configuración de nginx; /etc/nginx/conf.d es el directorio de almacenamiento de archivos de configuración de nginx dentro del contenedor.
  • --link myphp-fpm:php: unemyphp-fpmla red de ... connginx, y modificanginxel /etc/hosts de ..., mapeando el dominiophpa 127.0.0.1, para que nginx acceda a php-fpm a través de php:9000.

A continuación, creamos index.php en el directorio ~/nginx/www; el código es el siguiente:

<?php
echo phpinfo();
?>

    Configurar nginx, php-fpm y mysql con Docker

    Entorno de ejecución

    Crear directorio

    mkdir -p /Users/sui/docker/nginx/conf.d && mkdir /Users/sui/www &&  cd /Users/sui/docker/nginx/conf.d && sudo touch default.conf

    Iniciar php-fpm

    Para interpretar y ejecutar php se necesita php-fpm; primero haz que se ejecute:

    docker run --name sui-php -d \
    -v /Users/sui/www:/var/www/html:ro \
    php:7.1-fpm

    --name sui-phpes el nombre del contenedor.

    /Users/sui/wwwes el directorio local de almacenamiento de archivos php; /var/www/html es el directorio de almacenamiento de archivos php dentro del contenedor; ro indica solo lectura.

    Editar el archivo de configuración de nginx

    Ubicación del archivo de configuración: /Users/sui/docker/nginx/conf.d/default.conf.

    server {
    listen       80;
    server_name  localhost;

    location / {
        root   /usr/share/nginx/html;
        index  index.html index.htm;
    }

    error_page   500 502 503 504  /50x.html;
    location = /50x.html {
        root   /usr/share/nginx/html;
    }

    location ~ \.php$ {
        fastcgi_pass   php:9000;
        fastcgi_index  index.php;
        fastcgi_param  SCRIPT_FILENAME  /var/www/html/$fastcgi_script_name;
        include        fastcgi_params;
    }
}

    Explicación:

    • php:9000 indica la ruta de acceso del servicio php-fpm; se mencionará más adelante.
    • /var/www/html es, en sui,-phpla ruta de almacenamiento de los archivos php, que, tras el mapeo de docker, se convierte en la ruta local /Users/sui/www (puedes volver a revisar el comando de inicio de php-fpm

    Iniciar nginx:

    docker run --name sui-nginx -p 80:80 -d \
    -v /Users/sui/www:/usr/share/nginx/html:ro \
    -v /Users/sui/docker/nginx/conf.d:/etc/nginx/conf.d:ro \
    --link sui-php:php \
    nginx
    • -p 80:80 se usa para agregar el mapeo de puertos; mapeasui-nginxexpone el puerto 80 de ...
    • /Users/sui/www es el directorio local de almacenamiento de archivos html; /usr/share/nginx/html es el directorio de almacenamiento de archivos html dentro del contenedor.
    • /Users/sui/docker/nginx/conf.d es el directorio local de almacenamiento de archivos de configuración de nginx; /etc/nginx/conf.d es el directorio de almacenamiento de archivos de configuración de nginx dentro del contenedor.
    • --link sui-php:php unesui-phpla red de ... consui-nginx, y modificasui-nginxel /etc/hosts de ..., mapeando el dominiophpa 127.0.0.1, para que nginx acceda a php-fpm a través de php:9000.

    Resultado de la prueba

    Coloca dos archivos en /Users/sui/www: index.html e index.php

    mysql y phpmyadmin

    servidor mysql

    sudo mkdir -p /Users/sui/docker/mysql/data /Users/sui/docker/mysql/logs /Users/sui/docker/mysql/conf
    • El directorio data se mapeará como la ruta de almacenamiento de los archivos de datos configurada para el contenedor mysql
    • El directorio logs se mapeará como el directorio de registros del contenedor mysql
    • Los archivos de configuración en el directorio conf se mapearán como los archivos de configuración del contenedor mysql
    docker run -p 3307:3306 --name sui-mysql -v /Users/sui/docker/mysql/conf:/etc/mysql -v /Users/sui/docker/mysql/logs:/logs -v /Users/sui/docker/mysql/data:/mysql_data -e MYSQL_ROOT_PASSWORD=123456 -d --link sui-php mysql

    Entrar al cliente mysql:

    docker run -it --link sui-mysql:mysql --rm mysql sh -c 'exec mysql -h"$MYSQL_PORT_3306_TCP_ADDR" -P"$MYSQL_PORT_3306_TCP_PORT" -uroot -p"$MYSQL_ENV_MYSQL_ROOT_PASSWORD"'

    Nota: tengo mysql en el puerto local 3306, así que aquí uso el puerto 3307.

    phpmyadmin

    docker run --name sui-myadmin -d --link sui-mysql:db -p 8080:80 phpmyadmin/phpmyadmin
