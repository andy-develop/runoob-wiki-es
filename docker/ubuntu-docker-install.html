Instalación de Docker en Ubuntu

Docker Engine-Community es compatible con las siguientes versiones de Ubuntu:

  • Xenial 16.04 (LTS)
  • Bionic 18.04 (LTS)
  • Cosmic 18.10
  • Disco 19.04
  • Otras versiones más recientes...

Docker Engine - Community es compatible con las arquitecturas x86_64 (o amd64), armhf, arm64, s390x (IBM Z) y ppc64le (Power de IBM).

Instalación automática con el script oficial

El comando de instalación es el siguiente:

# 下载并执行Docker官方安装脚本
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 启动Docker服务
sudo systemctl start docker
sudo systemctl enable docker

Instalación manual

Desinstalar versiones antiguas

Las versiones antiguas de Docker se llamaban docker, docker.io o docker-engine. Si están instaladas, desinstálelas:

$ sudo apt-get remove docker docker-engine docker.io containerd runc

La versión actual se llama Docker Engine-Community, paquete docker-ce.

Para instalar Docker Engine-Community, a continuación se presentan dos métodos.

Instalación usando el repositorio de Docker

Antes de instalar Docker Engine-Community por primera vez en una máquina nueva, debe configurar el repositorio de Docker. Después, puede instalar y actualizar Docker desde el repositorio.

Configurar el repositorio

Actualice el índice de paquetes apt.

$ sudo apt-get update

Instale los paquetes de dependencia apt para obtener el repositorio a través de HTTPS:

$ sudo apt-get install \
    apt-transport-https \
    ca-certificates \
    curl \
    gnupg-agent \
    software-properties-common

Agregue la clave GPG oficial de Docker:

curl -fsSL https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc

Use las siguientes instrucciones para configurar el repositorio de la versión estable

echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu/ \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt-get update

Instalar Docker Engine-Community

Actualice el índice de paquetes apt.

$ sudo apt-get update

Instale la última versión de Docker Engine-Community y containerd, o vaya al siguiente paso para instalar una versión específica:

$ sudo apt-get install docker-ce docker-ce-cli containerd.io

Para instalar una versión específica de Docker Engine-Community, liste las versiones disponibles en el repositorio y luego elija una para instalar. Liste las versiones disponibles en su repositorio:

$ apt-cache madison docker-ce

  docker-ce | 5:18.09.1~3-0~ubuntu-xenial | https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu  xenial/stable amd64 Packages
  docker-ce | 5:18.09.0~3-0~ubuntu-xenial | https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu  xenial/stable amd64 Packages
  docker-ce | 18.06.1~ce~3-0~ubuntu       | https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu  xenial/stable amd64 Packages
  docker-ce | 18.06.0~ce~3-0~ubuntu       | https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu  xenial/stable amd64 Packages
  ...

Instale una versión específica usando la cadena de versión de la segunda columna, por ejemplo 5:18.09.1~3-0~ubuntu-xenial.

$ sudo apt-get install docker-ce=<VERSION_STRING> docker-ce-cli=<VERSION_STRING> containerd.io

Instalación mediante script de Shell

Dockerget.docker.com 和 test.docker.comproporciona en get.docker.com scripts convenientes para instalar rápidamente las versiones edge y test de Docker Engine-Community. El código fuente de los scripts está en el repositorio docker-install. No se recomienda usar estos scripts en entornos de producción; antes de usarlos, debe conocer los riesgos potenciales:

  • Los scripts requieren ejecutarse como root o tener privilegios sudo. Por lo tanto, antes de ejecutar el script, debe revisarlo y auditarlo cuidadosamente.

  • Estos scripts intentan detectar la distribución y versión de Linux y configurar el sistema de gestión de paquetes por usted. Además, los scripts no le permiten personalizar ningún parámetro de instalación. Esto puede dar lugar a configuraciones no compatibles, tanto desde la perspectiva de Docker como desde las pautas y estándares de su propia organización.

  • Estos scripts instalarán todas las dependencias y recomendaciones del gestor de paquetes sin confirmación. Esto puede instalar una gran cantidad de paquetes, dependiendo de la configuración actual del host.

  • El script no ofrece una opción para especificar qué versión de Docker instalar, sino que instala la última versión publicada en el canal edge.

  • Si ya ha instalado Docker en el host mediante otro mecanismo, no utilice los scripts convenientes.

Este ejemplo usaget.docker.com el script de get.docker.com para instalar la última versión de Docker Engine-Community en Linux. Para instalar la última versión de prueba, use test.docker.com. En cada comando siguiente, reemplace cada aparición de get por test.

$ curl -fsSL https://get.docker.com -o get-docker.sh
$ sudo sh get-docker.sh

Si desea usar Docker como usuario no root, considere agregar al usuario al grupo docker de una manera similar a la siguiente:

$ sudo usermod -aG docker your-user

Desinstalar docker

Elimine el paquete de instalación:

sudo apt-get purge docker-ce

Elimine imágenes, contenedores, archivos de configuración y otros contenidos:

sudo rm -rf /var/lib/docker

    Instalación de Docker en Ubuntu 16.04

    1. Elija un proveedor de servicios en la nube nacional; aquí se toma Alibaba Cloud como ejemplo.

    curl -sSL http://acs-public-mirror.oss-cn-hangzhou.aliyuncs.com/docker-engine/internet | sh -

    2. Instale los paquetes necesarios

    sudo apt-get install linux-image-extra-$(uname -r) linux-image-extra-virtual

    3. Agregue el paquete para transferencia HTTPS y los certificados CA

    sudo apt-get update
sudo apt-get install apt-transport-https ca-certificates

    4. Agregue la clave GPG

    sudo apt-key adv --keyserver hkp://p80.pool.sks-keyservers.net:80 --recv-keys 58118E89F3A912897C070ADBF76221572C52609D

    5. Agregue la fuente de software

    echo "deb https://apt.dockerproject.org/repo ubuntu-xenial main" | sudo tee /etc/apt/sources.list.d/docker.list

    6. Después de agregarla, actualice la caché de paquetes

    sudo apt-get update

    7. Instale Docker

    sudo apt-get install docker-engine

    8. Inicie Docker

    sudo systemctl enable docker
sudo systemctl start docker

    Instalación de Docker-ce en Ubuntu 18.04

    1. Cambie a una fuente de software nacional; se recomienda la fuente de la Universidad de Ciencia y Tecnología de China, es estable y rápida (opcional)

    sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak
sudo sed -i 's/archive.ubuntu.com/mirrors.ustc.edu.cn/g' /etc/apt/sources.list
sudo apt update

    2. Instale los paquetes necesarios

    sudo apt install apt-transport-https ca-certificates software-properties-common curl

    3. Agregue la clave GPG y agregue la fuente de software Docker-ce; aquí se sigue usando la fuente Docker-ce de la Universidad de Ciencia y Tecnología de China como ejemplo

    curl -fsSL https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu/gpg | sudo apt-key add -
sudo add-apt-repository "deb [arch=amd64] https://mirrors.ustc.edu.cn/docker-ce/linux/ubuntu \
$(lsb_release -cs) stable"

    4. Después de agregarla, actualice la caché de paquetes

    sudo apt update

    5. Instale Docker-ce

    sudo apt install docker-ce

    6. Configure el inicio automático y arranque Docker-ce (después de una instalación exitosa, ya está configurado e iniciado por defecto, por lo que se puede ignorar)

    sudo systemctl enable docker
sudo systemctl start docker

    7. Pruebe la ejecución

    sudo docker run hello-world

    8. Agregue el usuario actual al grupo docker para poder ejecutar Docker sin sudo (opcional)

    sudo groupadd docker
sudo usermod -aG docker $USER

    9. Pruebe el grupo de usuarios agregado (opcional)

    docker run hello-world
