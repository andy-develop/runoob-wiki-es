Electron Publicación y Despliegue

Después de desarrollar y empaquetar la aplicación Electron, es necesario publicarla para los usuarios. Los métodos de publicación se dividen principalmente entienda de aplicacionesydistribución independiente, y también se deben considerar el servicio de actualización y la estrategia de gestión de versiones.

Publicación en tienda de aplicaciones

Publicación en Microsoft Store

  • Requisitos de empaquetado: usarelectron-windows-storela herramienta convierte.exeo.msixa paquete Store
  • Firma: se necesita una cuenta de Microsoft Developer y solicitar un certificado de firma de código.

Proceso：

  1. Generar paquete MSIX
  2. Subir en Store Partner Center
  3. Completar información de la aplicación, capturas de pantalla y categoría
  4. Enviar para revisión

Publicación en Mac App Store

  • Requisitos de empaquetado: se debe usar.pkgo.app, y habilitarNotarización de Apple (Notarization)
  • Firma: solicitar un certificado de desarrollador con cuenta de Apple Developer.

Proceso：

  1. Empaquetar y firmar la aplicación
  2. Subir con Xcode o Transporter
  3. Enviar información de la aplicación y capturas de pantalla
  4. Publicar después de la aprobación de la revisión

Publicación en Snap Store (Linux)

Requisitos de empaquetado: use Snapcraft para empaquetar la aplicación como.snapformato.

Proceso：

  1. Escribirsnapcraft.yamlconfiguración
  2. Empaquetar y generar.snap
  3. Subir en Snapcraft Store
  4. Publicar después de la aprobación

Preparación para la revisión

  • El icono y las capturas de pantalla de la aplicación cumplen con los requisitos de la tienda.
  • Enviar descripción de la aplicación, categoría y política de privacidad
  • Asegurar la estabilidad mediante pruebas automáticas o manuales
  • Evitar que la aplicación use API o permisos no permitidos

Distribución independiente

Descarga desde el sitio web oficial

  • Colocar el empaquetado.exe、.dmg、.AppImageen el sitio web oficial para descargar
  • Se puede combinar con CDN para proporcionar una velocidad de descarga estable
  • Se puede proporcionar verificación SHA256 o MD5 para garantizar la integridad de los archivos

GitHub Releases

  • Usar GitHub Releases para subir instaladores de cada plataforma
  • Se puede combinar con electron-updater para implementar actualizaciones automáticas
  • Ventajas: gratuito, fácil de gestionar versiones

Distribución por CDN

  • Se recomienda usar CDN para aplicaciones de alto tráfico
  • Puede proporcionar descargas rápidas entre regiones
  • Combinado con el servidor de actualización automática, permite actualizaciones diferenciales

Configuración del servicio de actualización

Uso de servicios de terceros

  • El servicio proporciona alojamiento de actualizaciones automáticas, por ejemplo:

    • GitHub Releases + electron-updater
    • AWS S3 + CloudFront
    • Alojamiento estático en Netlify / Vercel

Servidor de actualización propio

  • Implementar un servicio HTTP o HTTPS simple
  • Proporcionar un archivo de descripción de actualización JSON (que contenga número de versión, dirección de descarga y registro de cambios)
  • Soporta actualizaciones diferenciales, reduciendo el tráfico de descarga del usuario

Ejemplo delatest.ymlarchivo:

version: 1.0.2
files:
  - url: MyElectronApp-1.0.2.exe
    sha512: "文件哈希值"
releaseDate: "2025-10-15T00:00:00Z"

Estrategia de gestión de versiones

  • Versionado semántico（SemVer）：Versión principal. Versión menor. Número de revisión

  • Estrategia de publicación：

    • Versión menor: corregir errores
    • Versión mayor: añadir nuevas funciones o cambios de interfaz de usuario

  • Estrategia de actualización automática:

    • Comprobar actualizaciones al inicio
    • Actualizaciones por sondeo periódico
    • Activación manual por el usuario

Resumen

Proceso central de publicación y despliegue de Electron:

  • Tienda de aplicaciones: revisión estricta, firma, requisitos de empaquetado de plataforma
  • Distribución independiente: sitio web oficial, GitHub Releases, CDN ofrecen descargas
  • Servicio de actualización: actualización automática, actualización diferencial, estrategia de gestión de versiones

Mediante estrategias razonables de publicación y actualización, se puede garantizar que los usuarios obtengan versiones de aplicación actualizadas, estables y seguras, mejorando al mismo tiempo la experiencia del usuario y la eficiencia del mantenimiento de la aplicación.
