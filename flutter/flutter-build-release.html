Empaquetado y publicación de Flutter

Esta sección explica cómo empaquetar y publicar aplicaciones Flutter en varias plataformas.

Preparación de la compilación

Antes de publicar, asegúrate de que la configuración de la aplicación sea correcta.

Configuración de pubspec.yaml

Ejemplo: Configuración de lanzamiento

# Información de la aplicación
name: my_app
description: "Mi aplicación Flutter"
version: 1.0.0+1  # Número de versión (¡Importante!)

# Icono de la aplicación
flutter:
  uses-material-design: true
  # Para generar el icono se necesita flutter pub run flutter_launcher_icons

Configuración de Android

Modifique la configuración de la aplicación en android/app/build.gradle:

Ejemplo: Configuración de Android

// android/app/build.gradle

android {
    namespace "com.example.myapp"
    compileSdk = 34

    defaultConfig {
applicationId "com.example.myapp" // ID de la aplicación
minSdk = 21 // Versión mínima de Android
targetSdk = 34 // Versión objetivo
versionCode 1 // código de versión (aumenta en cada lanzamiento)
versionName "1.0.0" // nombre de versión
    }

    signingConfigs {
        release {
// Configuración de firma de lanzamiento
            storeFile file("key.jks")
storePassword "contraseña"
keyAlias "alias"
keyPassword "contraseña de la clave"
        }
    }
}

Compilación de Android

Compilar APK

# 调试 APK
$ flutter build apk --debug

# 发布 APK
$ flutter build apk --release

# 带签名（需要配置 signingConfigs）
$ flutter build apk --release --target-platform android-arm64

Compilar App Bundle

# 构建 App Bundle（推荐用于 Google Play）
$ flutter build appbundle --release

Compilación de iOS

Preparativos

  • Instalar Xcode
  • Configura la cuenta de desarrollador de Apple
  • Crea el ID de la aplicación y el certificado

Compilación de línea de comandos

# 模拟器版本
$ flutter build ios --simulator --no-codesign

# 发布版本（需要签名）
$ flutter build ipa --release

Compila con Xcode

  1. Abre el archivo .xcworkspace en el directorio ios/
  2. Seleccione el dispositivo de destino y la configuración de firma (Signing)
  3. Haz clic en Product > Archive

Compilación Web

# 构建 Web 版本
$ flutter build web --release

# 输出目录：build/web/

Configuración Web

Configure la aplicación en web/index.html:

Ejemplo: Configuración Web

<!DOCTYPE html>
<html>
<head>
  <base href="/">
  <title>Mi aplicación</title>
  <meta name="description" content="Aplicación Flutter">
  <!-- Soporte PWA -->
  <link rel="manifest" href="manifest.json">
</head>
<body>
  <script src="flutter.js" defer></script>
</body>
</html>

Compilación de aplicaciones de escritorio

# Windows
$ flutter build windows --release

# macOS
$ flutter build macos --release

# Linux
$ flutter build linux --release

Antes de publicar, asegúrese de probar la versión de lanzamiento de la aplicación; la versión de depuración puede contener información de depuración adicional.
