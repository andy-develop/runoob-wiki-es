Instalación del entorno de Go

Go admite los siguientes sistemas:

  • Linux
  • FreeBSD
  • Mac OS X (también llamado Darwin)
  • Windows

La dirección de descarga del paquete de instalación es:https://go.dev/dl/。

Si no puedes abrirla, puedes usar esta dirección:https://golang.google.cn/dl/。

Nombres de paquete correspondientes a cada sistema:

Nombre de archivo del paquete de instalación Sistema compatible Arquitectura del procesador Requisitos de versión del sistema Descripción
go1.26.3.windows-amd64.msi Microsoft Windows x86-64 (Intel 64-bit) Windows 10 o posterior Instalador gráfico para sistemas Windows de 64 bits
go1.26.3.darwin-arm64.pkg Apple macOS ARM64 (Apple Silicon 64-bit) macOS 12 o posterior Paquete de instalación para Mac con chip de la serie M (incluido tu Mac mini 4)
go1.26.3.darwin-amd64.pkg Apple macOS x86-64 (Intel 64-bit) macOS 12 o posterior Para Mac antiguos con procesador Intel
go1.26.3.linux-amd64.tar.gz Linux x86-64 (Intel 64-bit) Linux 3.2 o posterior Paquete comprimido para la gran mayoría de sistemas Linux de 64 bits
go1.26.3.src.tar.gz Cualquier sistema Código fuente - Paquete de código fuente de Go; requiere compilación manual

Instalación en UNIX/Linux/Mac OS X y FreeBSD

A continuación se presenta el método de instalación desde el código fuente en sistemas UNIX/Linux/Mac OS X y FreeBSD:

1. Descarga el paquete binario: go1.4.linux-amd64.tar.gz.

2. Descomprime el paquete binario descargado en el directorio /usr/local.

tar -C /usr/local -xzf go1.4.linux-amd64.tar.gz

3. Agrega el directorio /usr/local/go/bin a la variable de entorno PATH:

export PATH=$PATH:/usr/local/go/bin

Lo anterior solo agrega PATH temporalmente; al cerrar la terminal, no estará disponible la próxima vez que inicies sesión.

Podemos editar ~/.bash_profile o /etc/profile y agregar el siguiente comando al final de ese archivo para que tenga efecto permanente:

export PATH=$PATH:/usr/local/go/bin

Después de agregarlo, es necesario ejecutar:

source ~/.bash_profile
或
source /etc/profile

Nota:En el sistema MAC puedes usar.pkgel paquete de instalación que termina en ... para completar la instalación con doble clic; el directorio de instalación está en/usr/local/go/debajo.

Instalación en el sistema Windows

En Windows se puede usar el paquete de instalación con extensión .msi (puedes encontrar este archivo en la lista de descargas, como go1.4.2.windows-amd64.msi) para instalar.

Por defecto.msiel archivo se instalará enc:\Goel directorio. Puedes agregar elc:\Go\bindirectorio a laPathvariable de entorno. Después de agregarlo, debes reiniciar la ventana de comandos para que tenga efecto.

Prueba de instalación

Crear el directorio de trabajoC:\>Go_WorkSpace。

Código del archivo test.go:

package main

import "fmt"

func main() {
   fmt.Println("Hello, World!")
}

Usa el comando go para ejecutar el código anterior; el resultado de salida es el siguiente:

C:\Go_WorkSpace>go run test.go

Hello, World!

    Las distribuciones de Linux basadas en Red Hat se pueden instalar con el comando yum:

    sudo yum install golang

    Para ver la versión de Go instalada en el sistema actual, puedes usar el siguiente comando:

    go version

    A continuación, en el directorio Home (por ejemplo, ~/workspace), crea un directorio workspace y define la variable de entorno GOPATH para que apunte a ese directorio; este directorio será usado por las herramientas de Go para guardar y editar archivos binarios.

    mkdir ~/workspace
echo 'export GOPATH="$HOME/workspace"' >> ~/.bashrc
source ~/.bashrc

    Según las diferentes necesidades, podemos usar yum para instalar Go tools:

    yum search golang

    Configuración de variables de entorno en DeepinOS o en sistemas ubuntu (para resolver que las variables de entorno dejen de ser efectivas después de reiniciar la terminal)

    Comando en la terminal:

    vim  ~/.bashrc

    O:

    vim ~/profile

    Nota:bashrc es efectivo para todos los usuarios del sistema; profile es efectivo para el usuario actual.

    Hay tres variables: GOPATH, PATH y GOROOT:

    • GOROOT es la ruta de instalación de Go;
    • GOPATH es el directorio de trabajo de Go;
    • PATH es el directorio bin en la ruta de instalación de Go.

    Después de ingresar el comando, presiona insert para ingresar y pega el siguiente contenido dentro (puede ser en cualquier espacio en blanco; se recomienda al principio o al final):

    export GOROOT="/usr/local/go"
export GOPATH="/go"
export PATH=$PATH:/usr/local/go/bin

    Después de ingresar, presiona ESC para salir, escribe :wq y guarda.

    Después de guardar, queda un paso más: hacer que las variables de entorno modificadas surtan efecto. Ingresa el siguiente comando en la terminal:

    source  ~/.bashrc

    O:

    source ~/profile

    En este momento, la instalación y configuración de golang está completa; se puede verificar con el siguiente comando:

    go version
