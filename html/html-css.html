Cómo usar CSS

CSS comenzó a usarse en HTML 4 y se introdujo para renderizar mejor los elementos HTML.

CSS se puede agregar a HTML de las siguientes maneras:

  • Estilo en línea - Usar 'style' en elementos HTMLatributo
  • Hoja de estilo interna - Usar <style> en la sección <head> del documento HTMLelementopara incluir CSS
  • Referencia externa - Usar CSS externoarchivo

La mejor manera es mediante la referencia externa a un archivo CSS.

En el tutorial de HTML de este sitio, usamos estilos CSS en línea para presentar los ejemplos. Esto es para simplificar los ejemplos y que puedas editar el código en línea y ejecutar los ejemplos más fácilmente.

Puedes, a través delTutorial de CSSaprender más sobre CSS.

Estilos en línea

Cuando se necesita aplicar un estilo especial a un elemento individual, se puede usar el estilo en línea. La forma de usar el estilo en línea es emplear el atributo style en la etiqueta correspondiente. El atributo style puede contener cualquier propiedad CSS. El siguiente ejemplo muestra cómo cambiar el color y el margen izquierdo de un párrafo.

<p style="color:blue;margin-left:20px;">这是一个段落。</p>

Para aprender más sobre estilos, visitaTutorial de CSS.

Ejemplo de estilo HTML - Color de fondo

La propiedad de color de fondo (background-color) define el color de fondo de un elemento:

Ejemplo

<body style="background-color:yellow;"> <h2 style="background-color:red;">Este es un título</h2> <p style="background-color:green;">Este es un párrafo.</p> </body>

Ejemplo de estilo HTML - Fuente, color de fuente, tamaño de fuente

Podemos usar las propiedades font-family (fuente), color (color) y font-size (tamaño de fuente) para definir el estilo de la fuente:

Ejemplo

<h1 style="font-family:verdana;">Un título</h1> <p style="font-family:arial;color:red;font-size:20px;">Un párrafo.</p>

Pruébalo »

Ahora normalmente se utilizan las propiedades font-family (fuente), color (color) y font-size (tamaño de fuente) para definir el estilo del texto, en lugar de usar la etiqueta <font>.

Ejemplo de estilo HTML - Alineación de texto

Usa la propiedad text-align (alineación de texto) para especificar la alineación horizontal y vertical del texto:

Ejemplo

<h1 style="text-align:center;">Título centrado</h1> <p>Este es un párrafo.</p>

Pruébalo »

La propiedad de alineación de texto text-align reemplaza a la antigua etiqueta <center>.

Hoja de estilo interna

Cuando un solo archivo necesita un estilo especial, se puede usar una hoja de estilo interna. Puedes definir una hoja de estilo interna en la sección <head> mediante la etiqueta <style>:

<head>
<style type="text/css">
body {background-color:yellow;}
p {color:blue;}
</style>
</head>

Hoja de estilo externa

Cuando los estilos necesitan aplicarse a muchas páginas, la hoja de estilo externa es la opción ideal. Con una hoja de estilo externa, puedes cambiar la apariencia de todo el sitio modificando un solo archivo.

<head>
<link rel="stylesheet" type="text/css" href="mystyle.css.html">
</head>

Etiquetas de estilo HTML

Etiqueta Descripción
<style> Define el estilo del texto
<link> Define la dirección de referencia del recurso

Etiquetas y atributos obsoletos

En HTML 4, las etiquetas y atributos que originalmente soportaban la definición de estilos de elementos HTML quedaron obsoletos. Estas etiquetas no son compatibles con las nuevas versiones de HTML.

Las etiquetas desaconsejadas son: <font>, <center>, <strike>

Los atributos desaconsejados son: color y bgcolor.

    CSS - Importar etiquetas externas

    Primera forma: la más utilizada y estable

    <link rel="stylesheet" href="标签路径.html">

    Segunda forma:

    <style>
@import url("标签路径")
</style>

    Conocimientos adicionales:¿Cuál es la diferencia entre link e import?

    Diferencia 1:

    Diferencia esencial:linkPertenece a las etiquetas XHTML, mientras que@importes completamente una forma proporcionada por CSS.

    Diferencia 2:

    Diferencia en el orden de carga:Cuando se carga una página (es decir, cuando el visitante la está viendo), el CSS referenciado por link se carga al mismo tiempo, mientras que@importel CSS referenciado se cargará después de que la página se haya descargado por completo. Por lo tanto, a veces al navegar@importpáginas que cargan CSS de esta manera, al principio no tienen estilo (es decir, parpadean), y es bastante notable cuando la conexión es lenta.

    Diferencia 3:

    Diferencia de compatibilidad: @importFue propuesto en CSS2.1, por lo que los navegadores antiguos no lo soportan,@importsolo se reconoce en IE5 o superior, mientras quelinkla etiqueta no tiene este problema.

    Diferencia 4:

    Diferencia al usar el DOM (Document Object Model) para controlar estilos: cuando se usa JavaScript para controlar el DOM y cambiar estilos, solo se puede usar la etiqueta link, porque@importno es algo que el DOM pueda controlar.
