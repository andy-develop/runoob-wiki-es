Etiquetas de formato HTML

HTML utiliza las etiquetas <b> ('negrita') e <i> ('cursiva') para formatear el texto de salida, como:Negrita or Cursiva

Estas etiquetas HTML se denominan etiquetas de formato (consulta el manual de referencia completo de etiquetas al final).

Normalmente, la etiqueta <strong> se usa en lugar de la etiqueta de negrita <b>, y <em> se usa en lugar de <i>.

Sin embargo, el significado de estas etiquetas es diferente:

<b> e <i> definen texto en negrita o cursiva.

<strong> o <em> significa que el texto que quieres presentar es importante, por lo que debe destacarse. Hoy en día, todos los navegadores principales pueden renderizar fuentes con varios efectos. Sin embargo, en el futuro los navegadores podrían admitir mejores efectos de renderizado.

Etiquetas de formato de texto HTML

Etiqueta Descripción
<b> Define texto en negrita
<em> Define texto enfatizado
<i> Define texto en cursiva
<small> Define texto pequeño
<strong> Define énfasis fuerte
<sub> Define texto subíndice
<sup> Define texto superíndice
<ins> Define texto insertado
<del> Define texto eliminado

Etiquetas de "salida de computadora" HTML

Etiqueta Descripción
<code> Define código de computadora
<kbd> Define código de teclado
<samp> Define una muestra de código de computadora
<var> Define una variable
<pre> Define texto preformateado

Citas, referencias y definiciones de etiquetas HTML

Etiqueta Descripción
<abbr> Define una abreviatura
<address> Define una dirección
<bdo> Define la dirección del texto
<blockquote> Define una cita larga
<q> Define una cita corta
<cite> Define una referencia o cita
<dfn> Define un elemento de definición.
