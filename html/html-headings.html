HTML Encabezados

En los documentos HTML, los encabezados son importantes.

Encabezados HTML

Los encabezados (Heading) se definen mediante las etiquetas <h1> - <h6>.

<h1> define el encabezado más grande. <h6> define el encabezado más pequeño.

Ejemplos

<h1>Este es un encabezado.</h1> <h2>Este es un encabezado.</h2> <h3>Este es un encabezado.</h3>

Pruébalo »

Nota:El navegador añade automáticamente líneas en blanco antes y después de los encabezados.

Los encabezados son importantes

Asegúrate de usar las etiquetas de encabezado HTML solo para encabezados. No las uses solo para generarnegrita或de gran tamañoen el texto.

Los motores de búsqueda usan los encabezados para indexar la estructura y el contenido de tu página web.

Dado que los usuarios pueden recorrer rápidamente tu página web mediante los encabezados, es importante usarlos para representar la estructura del documento.

Se debe utilizar h1 como encabezado principal (el más importante), seguido de h2 (el siguiente en importancia), luego h3, y así sucesivamente.

Línea horizontal HTML

La etiqueta <hr> crea una línea horizontal en una página HTML.

El elemento hr se puede usar para separar contenido.

Ejemplos

<p>Este es un párrafo.</p> <hr> <p>Este es un párrafo.</p> <hr> <p>Este es un párrafo.</p>

Comentarios HTML

Se pueden insertar comentarios en el código HTML para mejorar su legibilidad y hacer que el código sea más fácil de entender. El navegador ignora los comentarios y no los muestra.

Los comentarios se escriben de la siguiente manera:

Ejemplos

<!--Esto es un comentario-->

Pruébalo »

Nota:Después del signo de apertura (el signo izquierdo) debe ir inmediatamente un signo de exclamación!(signo de puntuación en inglés); antes del signo de cierre (el signo derecho) no es necesario. Usar los comentarios de forma adecuada puede ayudar en futuras ediciones del código.

Consejos HTML: cómo ver el código fuente

¿Has visto alguna vez una página web y te has maravillado de cómo se implementa?

Si quieres descubrir el secreto, solo haz clic con el botón derecho del ratón y selecciona "Ver código fuente" (IE) o "Ver código fuente de la página" (Firefox). En otros navegadores se hace de manera similar. Esto abrirá una ventana que contiene el código HTML de la página.
