Imágenes HTML - Etiqueta de imagen (<img>) y atributo de origen (Src)

En HTML, las imágenes se definen con la etiqueta <img>.

<img> es una etiqueta vacía, es decir, solo contiene atributos y no tiene etiqueta de cierre.

Para mostrar una imagen en la página, necesitas usar el atributo de origen (src). src significa "source". El valor del atributo de origen es la URL de la imagen.

La sintaxis para definir una imagen es:

<img src="url.html" alt="some_text">

URL se refiere a la ubicación donde se almacena la imagen. Si una imagen llamada "pulpit.jpg" se encuentra en el directorio images de www.runoob.com, entonces su URL eshttp://www.runoob.com/images/pulpit.jpg。

El navegador muestra la imagen en el lugar del documento donde aparece la etiqueta de imagen. Si colocas la etiqueta de imagen entre dos párrafos, el navegador mostrará primero el primer párrafo, luego la imagen y finalmente el segundo párrafo.

Imágenes HTML - Atributo Alt

El atributo alt se utiliza para definir un texto alternativo preparado para la imagen.

El valor del atributo de texto alternativo es definido por el usuario.

<img src="boat.gif.html" alt="Big Boat">

Cuando el navegador no puede cargar la imagen, el atributo de texto alternativo informa al lector de la información que ha perdido. En ese caso, el navegador mostrará este texto alternativo en lugar de la imagen. Es una buena práctica añadir el atributo de texto alternativo a todas las imágenes de la página, ya que ayuda a mostrar mejor la información y es muy útil para quienes utilizan navegadores de solo texto.

Imágenes HTML - Establecer altura y anchura de la imagen

Los atributos height (altura) y width (anchura) se utilizan para establecer la altura y la anchura de la imagen.

Los valores de los atributos están en píxeles por defecto:

<img src="pulpit.jpg.html" alt="Pulpit rock" width="304" height="228">

Consejo:Especificar la altura y la anchura de la imagen es una buena práctica. Si la imagen tiene especificadas la altura y la anchura, la página conservará esas dimensiones al cargarse. Si no se especifica el tamaño de la imagen, es posible que al cargar la página se rompa la maquetación general del HTML.

Notas básicas - Consejos útiles:

Nota:Si un archivo HTML contiene diez imágenes, para mostrar la página correctamente es necesario cargar 11 archivos. Cargar imágenes lleva tiempo, por lo que nuestra recomendación es: utilizar imágenes con moderación.

Nota:Al cargar la página, presta atención a la ruta de las imágenes insertadas. Si la ubicación de la imagen no se configura correctamente, el navegador no podrá cargar la imagen y la etiqueta de imagen mostrará una imagen rota.
