HTML5 Almacenamiento Web

El almacenamiento web HTML5, una mejor forma de almacenamiento local que las cookies.

¿Qué es el almacenamiento Web HTML5?

Usando HTML5 se pueden almacenar localmente los datos de navegación del usuario.

Anteriormente, el almacenamiento local usaba cookies. Pero el almacenamiento Web necesita ser más seguro y rápido. Estos datos no se guardan en el servidor, sino que solo se usan para los datos que el usuario solicita al sitio web. También puede almacenar grandes cantidades de datos sin afectar el rendimiento del sitio web.

Los datos se almacenan como pares clave/valor, y los datos de una página web solo pueden ser accedidos y utilizados por esa página.

Soporte del navegador

Internet Explorer 8+, Firefox, Opera, Chrome y Safari admiten el almacenamiento Web.

Nota:Internet Explorer 7 y versiones anteriores de IE no admiten el almacenamiento web.

localStorage y sessionStorage

Los dos objetos para almacenar datos en el cliente son:

  • localStorage - Se usa para guardar datos de todo el sitio web de forma permanente; los datos guardados no tienen tiempo de expiración hasta que se eliminen manualmente.
  • sessionStorage - Se usa para guardar temporalmente los datos de la misma ventana (o pestaña); estos datos se eliminarán después de cerrar la ventana o pestaña.

Antes de usar el almacenamiento web, se debe comprobar si el navegador admite localStorage y sessionStorage:

if(typeof(Storage)!=="undefined") { //¡Sí! ¡Admite los objetos localStorage y sessionStorage! //Algún código..... } else { //¡Lo sentimos! No se admite el almacenamiento web. }

El objeto localStorage

Los datos almacenados por el objeto localStorage no tienen límite de tiempo. Al día siguiente, a la semana siguiente o al año siguiente, los datos siguen disponibles.

Ejemplo

//Guardar localStorage.setItem("sitename", "Tutorial para novatos"); //Buscar document.getElementById("result").innerHTML = "Nombre del sitio web:" + localStorage.getItem("sitename");

Eliminar "sitename" de localStorage:

localStorage.removeItem("sitename");

Ya sea localStorage o sessionStorage, las API disponibles son las mismas. Las más utilizadas son las siguientes (tomando localStorage como ejemplo):

  • Guardar datos: localStorage.setItem(key,value);
  • Leer datos: localStorage.getItem(key);
  • Eliminar un solo dato: localStorage.removeItem(key);
  • Eliminar todos los datos: localStorage.clear();
  • Obtener la clave de un índice: localStorage.key(index);

Consejo:Los pares clave/valor generalmente se almacenan como cadenas; puedes convertir ese formato según tus necesidades.

El siguiente ejemplo muestra el número de veces que el usuario hace clic en un botón.

El valor de cadena en el código se convierte a tipo numérico:

Ejemplo

if (localStorage.clickcount) { localStorage.clickcount=Number(localStorage.clickcount)+1; } else { localStorage.clickcount=1; } document.getElementById("result").innerHTML="Has hecho clic en el botón" + localStorage.clickcount + "vez";

El objeto sessionStorage

El método sessionStorage almacena datos para una sesión. Cuando el usuario cierra la ventana del navegador, los datos se eliminan.

Cómo crear y acceder a un sessionStorage:

Ejemplo

if (sessionStorage.clickcount) { sessionStorage.clickcount=Number(sessionStorage.clickcount)+1; } else { sessionStorage.clickcount=1; } document.getElementById("result").innerHTML="Has hecho clic en este botón en esta sesión" + sessionStorage.clickcount + "vez";

Desarrollo de un programa simple de lista de sitios web con Web Storage

El programa de lista de sitios web implementa las siguientes funciones:

  • Puedes ingresar el nombre del sitio web y la URL, y guardarlos en localStorage usando el nombre del sitio como clave;
  • Buscar la URL según el nombre del sitio web;
  • Listar todos los sitios web actualmente guardados;

El siguiente código se usa para guardar y buscar datos:

Los métodos save() y find()

//Guardar datos function save(){ var siteurl = document.getElementById("siteurl").value; var sitename = document.getElementById("sitename").value; localStorage.setItem(sitename, siteurl); alert("Agregado con éxito"); } //Buscar datos function find(){ var search_site = document.getElementById("search_site").value; var sitename = localStorage.getItem(search_site); var find_result = document.getElementById("find_result"); find_result.innerHTML = search_site + "la URL es:" + sitename; }
