ionic navegación

ion-nav-view

Cuando el usuario navega en tu aplicación, Ionic puede detectar el historial de navegación. Al detectar el historial, se pueden transicionar correctamente las vistas al deslizar hacia la izquierda o hacia la derecha.

Utilizando el módulo de enrutador AngularUI, la interfaz de la aplicación puede dividirse en diferentes $state (estados). El núcleo de Angular es el servicio de enrutamiento; las URLs pueden usarse para controlar las vistas.

AngularUI Router proporciona una gestión de estados más potente, es decir, los estados pueden ser nombrados, anidados y fusionar vistas, permitiendo que más de una plantilla se presente en la misma página.

Además, cada estado no necesita estar vinculado a una URL, y los datos pueden enviarse a cada estado de manera más flexible.

En el siguiente ejemplo, crearemos una aplicación con vistas de navegación que contienen diferentes estados.

En nuestro marcado, seleccionamos ionNavView como directiva de nivel superior. Para mostrar una barra de encabezado, usamos la directiva ionNavBar que se actualiza mediante la navegación.

A continuación, necesitamos configurar los estados que se renderizarán.

var app = angular.module('myApp', ['ionic']);
app.config(function($stateProvider) {
  $stateProvider
  .state('index', {
    url: '/',
    templateUrl: 'home.html'
  })
  .state('music', {
    url: '/music',
    templateUrl: 'music.html'
  });
});

Al abrir la aplicación, $stateProvider consulta la URL para ver si coincide con el estado 'index', y luego carga index.html en <ion-nav-view>.

La carga de páginas se configura mediante URLs. En Angular, la forma más sencilla de crear una plantilla es colocarla directamente en un archivo de plantilla HTML y envolverla con <script type='text/ng-template'>.

Por lo tanto, esta es también una forma de incorporar Home.html a nuestra aplicación:

<script id="home" type="text/ng-template">
  <!--  ion-view 标题将显示在 navbar 中 -->
  <ion-view view-title="Home">
    <ion-content ng-controller="HomeCtrl">
      <!-- The content of the page -->
      <a href="../index.html">Go to music page!</a>
    </ion-content>
  </ion-view>
</script>

Este es un buen método porque la plantilla se carga rápidamente y se almacena en caché, sin necesidad de volver a cargarla a través de la red.

Caché

Normalmente, las vistas se almacenan en caché para mejorar el rendimiento. Cuando se sale de una vista, sus elementos se conservan en el DOM y su ámbito ($scope) se elimina de $watch.

Cuando navegamos a una vista que ya estaba en caché, la vista se activa, su ámbito se vuelve a conectar y sus elementos se conservan en el DOM. Esto también permite mantener la posición de desplazamiento de la vista anterior.

La caché también se puede activar o desactivar de varias formas. Por defecto, Ionic establece el número máximo de páginas en caché en 10, y no es lo único que se puede personalizar; la aplicación puede establecer explícitamente si una vista debe almacenarse en caché.

Nota: como estamos almacenando en caché estas vistas, no destruimos el ámbito. En cambio, su ámbito también se elimina de $watch.

Dado que el ámbito de la vista no se destruye ni se recrea, el controlador no se vuelve a cargar. Si la aplicación/controlador necesita saber cuándo entrar o salir de una vista, los eventos de vista emitidos desde el ámbito de ionView, como $ionicView.enter, pueden ser útiles.

Deshabilitar caché globalmente

$ionicConfigProvider puede usarse para establecer el número máximo de vistas permitidas en caché, y todas las cachés se deshabilitan estableciéndolo en 0.

$ionicConfigProvider.views.maxCache(0);

Deshabilitar caché en el State Provider

$stateProvider.state('myState', {
   cache: false,
   url : '/myUrl',
   templateUrl : 'my-template.html'
})

Deshabilitar caché mediante atributos

<ion-view cache-view="false" view-title="My Title!">
  ...
</ion-view>

ion-nav-bar

Crea una barra de herramientas superior que se actualiza cuando cambia el estado de la aplicación.

Uso

<body ng-app="starter">
  <!-- 当我们浏览时，导航栏会随之更新。 -->
  <ion-nav-bar class="bar-positive nav-title-slide-ios7">
  </ion-nav-bar>

  <!-- 初始化时渲染视图模板 -->
  <ion-nav-view></ion-nav-view>
</body>

ion-nav-buttons

Pertenece a ionNavView

Usa ionNavButtons para configurar botones en una ionNavBar dentro de un ionView.

Cualquier botón que configures se colocará en la posición correspondiente de la barra de navegación y se destruirá cuando el usuario abandone la vista principal.

Uso

<ion-nav-bar>
</ion-nav-bar>
<ion-nav-view>
  <ion-view>
    <ion-nav-buttons side="left">
      <button class="button" ng-click="doSomething()">
        我是一个在导航栏左侧的按钮！
      </button>
    </ion-nav-buttons>
    <ion-content>
      这里是一些内容！
    </ion-content>
  </ion-view>
</ion-nav-view>

API

Atributos Tipo Detalles
side cadena

En el padreionNavBarla posición donde se colocan los botones. Disponible: 'left' o 'right'.

ion-nav-back-button

Crea un botón en una ionNavBar.

Se mostrará un botón de retroceso cuando el usuario pueda retroceder en la navegación actual.

Uso

Acción del botón por defecto:

<ion-nav-bar>
  <ion-nav-back-button class="button-clear">
    <i class="ion-arrow-left-c"></i> 后退
  </ion-nav-back-button>
</ion-nav-bar>

Acción de clic personalizada, usando $ionicNavBarDelegate:

<ion-nav-bar ng-controller="MyCtrl">
  <ion-nav-back-button class="button-clear"
    ng-click="canGoBack && goBack()">
    <i class="ion-arrow-left-c"></i> 后退
  </ion-nav-back-button>
</ion-nav-bar>

function MyCtrl($scope, $ionicNavBarDelegate) {
  $scope.goBack = function() {
    $ionicNavBarDelegate.back();
  };
}

Muestra el título anterior en el botón de retroceso, también con $ionicNavBarDelegate.

<ion-nav-bar ng-controller="MyCtrl">
  <ion-nav-back-button class="button-icon">
    <i class="icon ion-arrow-left-c"></i>{{getPreviousTitle() || 'Back'}}
  </ion-nav-back-button>
</ion-nav-bar>

function MyCtrl($scope, $ionicNavBarDelegate) {
  $scope.getPreviousTitle = function() {
    return $ionicNavBarDelegate.getPreviousTitle();
  };
}

nav-clear

nav-clear es una directiva de atributo que se usa al hacer clic en un elemento de la vista, como un <a href> o un <button ui-sref>.

Al hacer clic, nav-clear hará que el elemento dado prohíba la transición a la siguiente vista. Esta directiva es útil, por ejemplo, para enlaces dentro de un menú lateral.

Uso

A continuación se muestra un enlace dentro de un menú lateral con la directiva nav-clear agregada. Al hacer clic en el enlace se deshabilitará cualquier animación entre vistas.

<a nav-clear menu-close href="../index.html" class="item">首页</a>

nav-transition

Establece el tipo de transición utilizado, que puede ser: ios, android y none.

Uso

<a nav-transition="none" href="../index.html">Home</a>

nav-direction

Establece la dirección de la animación de transición en la vista de navegación, puede ser: forward, back, enter, exit, swap.

Uso

<a nav-direction="forward" href="../index.html">Home</a>

$ionicNavBarDelegate

Control delegado de la directiva ion-nav-bar.

Uso

<body ng-controller="MyCtrl">
  <ion-nav-bar>
    <button ng-click="setNavTitle('banana')">
      Set title to banana!
    </button>
  </ion-nav-bar>
</body>


function MyCtrl($scope, $ionicNavBarDelegate) {
  $scope.setNavTitle = function(title) {
    $ionicNavBarDelegate.title(title);
  }
}

$ionicHistory

$ionicHistory se usa para rastrear el historial de navegación del usuario dentro de la aplicación.

Métodos

viewHistory()

Se utiliza para ver el historial de navegación.

currentView()

La vista actual de la aplicación.

currentHistoryId()
El ID de la pila de historial, que es el contenedor padre de la vista actual. 
currentTitle([val])

Obtiene o establece el título de la vista actual.

backView()

Devuelve la vista visitada anteriormente.

backTitle()

Obtiene el título de la vista visitada anteriormente.

forwardView()

Volver a la vista anterior de la vista actual en la pila de historial.

currentStateName()

Devolver el nombre del estado actual.

goBack([backCount])

La aplicación retrocede a la vista anterior, si esa vista anterior existe.
