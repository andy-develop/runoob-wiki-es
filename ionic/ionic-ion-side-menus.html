Menú lateral de ionic

Un elemento contenedor contiene el menú lateral y el contenido principal. Al arrastrar el área de contenido principal de un lado al otro, se alterna el menú lateral izquierdo o derecho.

La imagen del efecto se muestra a continuación:

Uso

Para usar el menú lateral, agregue un elemento padre `<ion-side-menus>`, un contenido intermedio `<ion-side-menu-content>` y una o más directivas `<ion-side-menu>`.

<ion-side-menus>
  <!-- 中间内容 -->
  <ion-side-menu-content ng-controller="ContentController">
  </ion-side-menu-content>

  <!-- 左侧菜单 -->
  <ion-side-menu side="left">
  </ion-side-menu>

  <!-- 右侧菜单 -->
  <ion-side-menu side="right">
  </ion-side-menu>
</ion-side-menus>

function ContentController($scope, $ionicSideMenuDelegate) {
  $scope.toggleLeft = function() {
    $ionicSideMenuDelegate.toggleLeft();
  };
}

API

Atributos Tipo Detalles
enable-menu-with-back-views
(Opcional)
 Valor booleano

Confirma si se habilita el menú lateral cuando se muestra el botón de retroceso.
delegate-handle Cadena Este identificador (handle) se utiliza para identificar la vista de desplazamiento con `$ionicScrollDelegate`.

ion-side-menu-content

Un contenedor para el contenido principal visible, con una o más directivas `ionSideMenu` al mismo nivel.

Uso

<ion-side-menu-content
  drag-content="true">
</ion-side-menu-content>

API

Atributos Tipo Detalles
drag-content
(Opcional)
 Valor booleano

Si el contenido se puede arrastrar. Por defecto es true.

ion-side-menu

Un contenedor para un menú lateral, con una directiva `ion-side-menu-content` al mismo nivel.

Uso

<ion-side-menu
  side="left"
  width="myWidthValue + 20"
  is-enabled="shouldLeftSideMenuBeEnabled()">
</ion-side-menu>

API

Atributos Tipo Detalles
side Cadena

En qué lado se encuentra actualmente el menú lateral. Los valores posibles son: 'left' o 'right'.
is-enabled
(Opcional)
 Valor booleano

Si este menú lateral está disponible.
width
(Opcional)
 Valor numérico

Cuántos píxeles de ancho debe tener el menú lateral. Por defecto es 275.

menu-toggle

Alterna el menú en un panel lateral especificado.

Uso

A continuación se muestra un ejemplo de un enlace dentro de la barra de navegación. Al hacer clic en este enlace se abrirá automáticamente el menú lateral especificado.

<ion-view>
  <ion-nav-buttons side="left">
   <button menu-toggle="left" class="button button-icon icon ion-navicon"></button>
  </ion-nav-buttons>
 ...
</ion-view>

menu-close

Cierra el menú lateral actualmente abierto.

Uso

A continuación se muestra un ejemplo de un enlace dentro de la barra de navegación. Al hacer clic en este enlace se abrirá automáticamente el menú lateral especificado.

<a menu-close href="../index.html" class="item">首页</a>

$ionicSideMenuDelegate

Este método activa directamente el servicio `$ionicSideMenuDelegate` para controlar todos los menús laterales. Use el método `$getByHandle` para controlar los `ionSideMenus` en casos específicos.

Uso

<body ng-controller="MainCtrl">
  <ion-side-menus>
    <ion-side-menu-content>
      内容!
      <button ng-click="toggleLeftSideMenu()">
        切换左侧侧栏菜单
      </button>
    </ion-side-menu-content>
    <ion-side-menu side="left">
      左侧菜单!
    <ion-side-menu>
  </ion-side-menus>
</body>

function MainCtrl($scope, $ionicSideMenuDelegate) {
  $scope.toggleLeftSideMenu = function() {
    $ionicSideMenuDelegate.toggleLeft();
  };
}

Métodos

toggleLeft([isOpen])

Alterna el menú lateral izquierdo (si existe).

Parámetros Tipo Detalles
isOpen
(Opcional)
 Valor booleano

Si abrir o cerrar el menú. Por defecto: alternar el menú.

 
toggleRight([isOpen])

Alterna el menú lateral derecho (si existe).

Parámetros Tipo Detalles
isOpen
(Opcional)
 Valor booleano

Si abrir o cerrar el menú. Por defecto: alternar el menú.

 
getOpenRatio()

Obtiene la proporción en que el contenido del menú abierto supera el ancho del menú. Por ejemplo, un menú de 100px de ancho abierto al 50% (50px) devolverá un valor de proporción de 0.5.

Valor de retorno:Flotante 0 indica que no está abierto; de 0 a 1 si el menú izquierdo está abierto o abriéndose; de 0 a -1 si el menú derecho está abierto o abriéndose.

isOpen()

Valor de retorno:Booleano que indica si el menú izquierdo o derecho ya está abierto.

isOpenLeft()

Valor de retorno:Booleano que indica si el menú izquierdo ya está abierto.

isOpenRight()

Valor de retorno:Booleano que indica si el menú derecho ya está abierto.

canDragContent([canDrag])
Parámetros Tipo Detalles
canDrag
(Opcional)
 Valor booleano

Establece si se puede arrastrar el contenido para abrir el menú lateral.

Valor de retorno:Booleano que indica si se puede arrastrar el contenido para abrir el menú lateral.

$getByHandle(handle)
Parámetros Tipo Detalles
handle Cadena

Por ejemplo:

$ionicSideMenuDelegate.$getByHandle('my-handle').toggleLeft();
