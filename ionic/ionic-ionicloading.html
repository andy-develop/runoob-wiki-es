ionic Acción de carga

$ionicLoading es un efecto interactivo de carga predeterminado de ionic. Su contenido también se puede modificar en la plantilla.

Uso

angular.module('LoadingApp', ['ionic'])
.controller('LoadingCtrl', function($scope, $ionicLoading) {
  $scope.show = function() {
    $ionicLoading.show({
      template: 'Loading...'
    });
  };
  $scope.hide = function(){
    $ionicLoading.hide();
  };
});

Métodos

Muestra un efecto de carga.

show(opts)
Parámetros Tipo Detalles
opts object

Opciones del indicador de carga. Propiedades disponibles:

  • {string=} templateContenido HTML del indicador.
  • {string=} templateUrlUna URL de plantilla HTML de carga como contenido del indicador.
  • {boolean=} noBackdropSi se oculta el fondo. Por defecto se muestra.
  • {number=} delayCuántos milisegundos de retraso para mostrar el indicador. Por defecto no hay retraso.
  • {number=} durationCuántos milisegundos esperar para ocultar automáticamente el indicador. Por defecto, el indicador se muestra hasta que se active.hide()。

Ejemplo

Código HTML:

<html ng-app="ionicApp">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="initial-scale=1, maximum-scale=1, user-scalable=no, width=device-width"> 
    
    <title>Ionic Modal</title>

     <link href="../static/ionic/css/ionic.min.css" rel="stylesheet">
    <script src="../static/ionic/js/ionic.bundle.min.js"></script>
  </head>
  <body ng-controller="AppCtrl">
    
      <ion-view title="Home">
        <ion-header-bar>
          <h1 class="title">The Stooges</h1>
        </ion-header-bar>
        <ion-content has-header="true">
          <ion-list>
            <ion-item ng-repeat="stooge in stooges" href="../index.html">{{stooge.name}}</ion-item>
          </ion-list>
        </ion-content>
      </ion-view>
    
  </body>
</html>

Código JavaScript

angular.module('ionicApp', ['ionic'])
.controller('AppCtrl', function($scope, $timeout, $ionicLoading) {

  // Setup the loader
  $ionicLoading.show({
    content: 'Loading',
    animation: 'fade-in',
    showBackdrop: true,
    maxWidth: 200,
    showDelay: 0
  });
  
  // Set a timeout to clear loader, however you would actually call the $ionicLoading.hide(); method whenever everything is ready or loaded.
  $timeout(function () {
    $ionicLoading.hide();
    $scope.stooges = [{name: 'Moe'}, {name: 'Larry'}, {name: 'Curly'}];
  }, 2000);
  
});

$ionicLoadingConfig

Configurar las opciones predeterminadas de carga:

Uso:

var app = angular.module('myApp', ['ionic'])
app.constant('$ionicLoadingConfig', {
  template: '默认加载模板……'
});
app.controller('AppCtrl', function($scope, $ionicLoading) {
  $scope.showLoading = function() {
    $ionicLoading.show(); //配置选项在 $ionicLoadingConfig 设置
  };
});
