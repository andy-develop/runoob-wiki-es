Clase Java String

Las cadenas se utilizan ampliamente en la programación Java. En Java, las cadenas son objetos; Java proporciona la clase String para crear y manipular cadenas.

Crear cadenas

La forma más sencilla de crear una cadena es la siguiente:

String str = "Runoob";

Cuando el código encuentra una constante de cadena, el valor aquí es "Runoob", el compilador usará ese valor para crear un objeto String.

Al igual que otros objetos, se puede utilizar la palabra clave y métodos constructores para crear objetos String.

Crear cadenas con el constructor:

String str2=new String("Runoob");

Las cadenas creadas con String se almacenan en el grupo público (string pool), mientras que los objetos String creados con `new` están en el montón (heap):

String s1 = "Runoob"; //Creación directa con String String s2 = "Runoob"; //Creación directa con String String s3 = s1; //Misma referencia String s4 = new String("Runoob"); //Creación de objeto String String s5 = new String("Runoob"); //Creación de objeto String

La clase String tiene 11 constructores, que proporcionan diferentes parámetros para inicializar cadenas, por ejemplo, un parámetro de matriz de caracteres:

Código del archivo StringDemo.java:

public class StringDemo{ public static void main(String args[]){ char[] helloArray = { 'r', 'u', 'n', 'o', 'o', 'b'}; String helloString = new String(helloArray); System.out.println( helloString ); } }

El resultado de compilar y ejecutar el ejemplo anterior es el siguiente:

runoob

Nota:La clase String es inmutable, por lo que una vez que creas un objeto String, su valor no se puede cambiar (consulte el análisis en la sección de notas).

Si necesitas hacer muchas modificaciones en cadenas, entonces deberías elegir usarlas clases StringBuffer y StringBuilder。

Longitud de la cadena

Los métodos utilizados para obtener información sobre un objeto se denominan métodos de acceso (accessors).

Un método de acceso de la clase String es el método length(), que devuelve el número de caracteres contenidos en el objeto String.

Después de ejecutar el siguiente código, la variable len es igual a 14:

Código del archivo StringDemo.java:

public class StringDemo { public static void main(String args[]) { String site = "www.runoob.com"; int len = site.length(); System.out.println( "Longitud de la URL de Runoob:" + len ); } }

El resultado de compilar y ejecutar el ejemplo anterior es el siguiente:

菜鸟教程网址长度 : 14

Concatenar cadenas

La clase String proporciona un método para concatenar dos cadenas:

string1.concat(string2);

Devuelve una nueva cadena que es la concatenación de string2 y string1. También se puede usar el método concat() con constantes de cadena, como:

"我的名字是 ".concat("Runoob");

Más comúnmente se usa el operador '+' para concatenar cadenas, como:

"Hello," + " runoob" + "!"

El resultado es el siguiente:

"Hello, runoob!"

A continuación se muestra un ejemplo:

Código del archivo StringDemo.java:

public class StringDemo { public static void main(String args[]) { String string1 = "URL del tutorial de Runoob:"; System.out.println("1、" + string1 + "www.runoob.com"); } }

El resultado de compilar y ejecutar el ejemplo anterior es el siguiente:

1、菜鸟教程网址：www.runoob.com

Crear cadenas con formato

Sabemos que para imprimir números con formato se pueden usar los métodos printf() y format().

La clase String utiliza el método estático format() para devolver un objeto String en lugar de un objeto PrintStream.

El método estático format() de la clase String se puede usar para crear cadenas de formato reutilizables, no solo para una salida de impresión única.

Como se muestra a continuación:

System.out.printf("El valor de la variable de tipo flotante es" + "%f, el valor de la variable entera es" + "%d, el valor de la variable de cadena es" + "is %s", floatVar, intVar, stringVar);

También puedes escribir así

String fs; fs = String.format("El valor de la variable de tipo flotante es" + "%f, el valor de la variable entera es" + "%d, el valor de la variable de cadena es" + " %s", floatVar, intVar, stringVar);

    1. Formateo de enteros: %[index$][identificador][ancho mínimo]forma de conversión

    La cadena de formato consta de 4 partes. El formato especial suele comenzar con %index$, donde index toma valores desde 1, lo que indica que se toma el parámetro número index para formatearlo. El significado de [ancho mínimo] también es fácil de entender: es el número mínimo de dígitos que debe contener finalmente la cadena convertida del entero. El significado de las otras 2 partes es:

    Identificador:

    • '-' Se alinea a la izquierda dentro del ancho mínimo; no se puede usar junto con "rellenar con 0".
    • '#' Solo aplica a octal y hexadecimal; en octal añade un 0 delante del resultado, y en hexadecimal añade 0x delante del resultado.
    • '+' El resultado siempre incluye un signo (en general solo aplica a decimal; si el objeto es BigInteger, se puede usar para octal y hexadecimal).
    • ' ' Añade un espacio antes de los valores positivos y un signo menos antes de los negativos (en general solo aplica a decimal; si el objeto es BigInteger, se puede usar para octal y hexadecimal).
    • '0' El resultado se rellenará con ceros.
    • ',' Solo aplica a decimal; cada 3 dígitos se separan con ",".
    • '(' Si el parámetro es negativo, no se añade signo menos al resultado, sino que el número se encierra entre paréntesis (tiene las mismas restricciones que '+').

    Forma de conversión:

    d - decimal; o - octal; x o X - hexadecimal

    La explicación anterior es demasiado árida; veamos algunos ejemplos concretos. Un punto que hay que tener especialmente en cuenta es que la mayoría de los caracteres identificadores se pueden usar simultáneamente.

    System.out.println(String.format("%1$,09d", -3123));
System.out.println(String.format("%1$9d", -31));
System.out.println(String.format("%1$-9d", -31));
System.out.println(String.format("%1$(9d", -31));
System.out.println(String.format("%1$#9x", 5689));
//结果为：
//-0003,123
// -31
//-31
// (31)
// 0x1639　

    2. Formateo de números de punto flotante: %[index$][identificador][ancho mínimo][.precisión]forma de conversión

    Podemos ver que la conversión de números de punto flotante añade una opción de "precisión", que permite controlar el número de dígitos después del punto decimal.

    Identificador:

    • '-' Se alinea a la izquierda dentro del ancho mínimo; no se puede usar junto con "rellenar con 0".
    • '+' El resultado siempre incluye un signo.
    • ' ' Añade un espacio antes de los valores positivos y un signo menos antes de los negativos.
    • '0' El resultado se rellenará con ceros.
    • ',' Cada 3 dígitos se separan con "," (solo aplica a las conversiones f, g, G).
    • '(' Si el parámetro es negativo, no se añade signo menos al resultado, sino que el número se encierra entre paréntesis (solo aplica a las conversiones e, E, f, g, G).

    Forma de conversión:

    • 'e', 'E' -- El resultado se formatea como un número decimal en notación científica computacional.
    • 'f' -- El resultado se formatea en notación decimal ordinaria.
    • 'g', 'G' -- Según el caso específico, se elige automáticamente entre notación ordinaria y notación científica.
    • 'a', 'A' -- El resultado se formatea como un número de punto flotante hexadecimal con dígitos significativos y exponente.

    3. Formateo de caracteres:

    Formatear caracteres es muy sencillo: c representa el carácter, y en el identificador '-' indica alineación a la izquierda; no hay mucho más.

    Aquí se puede analizar según el código fuente de JDK.

    Una cadena es en realidad un array de char, y su interior encapsula precisamente un array de char.

    Y aquí el array de char está modificado por final:

    public final class String
    implements java.io.Serializable, Comparable<String>, CharSequence {
    /** The value is used for character storage. */
    private final char value[];

    Además, todos los métodos de String consisten en cambios sobre el array de char; cada vez que lo modifican, el método devuelve internamente una nueva instancia de String.

    Java: diferencias entre String, StringBuffer y StringBuilder

    String: constante de cadena, la longitud de la cadena es inmutable. En Java, String es immutable (inmutable). El array utilizado para almacenar caracteres se declara como final, por lo que solo se puede asignar una vez y no se puede volver a modificar.

    StringBuffer: variable de cadena (Synchronized, es decir, seguro para hilos). Si se necesita modificar con frecuencia el contenido de la cadena, por consideraciones de eficiencia es mejor usar StringBuffer; si se quiere convertir al tipo String, se puede llamar al método toString() de StringBuffer. java.lang.StringBuffer es una secuencia de caracteres mutable y segura para hilos. En cualquier punto en el tiempo contiene una secuencia de caracteres específica, pero mediante llamadas a ciertos métodos se puede cambiar la longitud y el contenido de dicha secuencia. El búfer de cadenas se puede usar de forma segura en múltiples hilos.

    StringBuilder: variable de cadena (no segura para hilos). Internamente, el objeto StringBuilder se trata como un array de longitud variable que contiene una secuencia de caracteres.

    Principios básicos:

    • Si se opera con una cantidad pequeña de datos, se usa String;
    • para operar con una gran cantidad de datos en un solo hilo, se usa StringBuilder;
    • para operar con una gran cantidad de datos en múltiples hilos, se usa StringBuffer.
