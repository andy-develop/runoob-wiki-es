Interfaces funcionales de Java 8

Nuevas características de Java 8

Una interfaz funcional (Functional Interface) es una interfaz que tiene exactamente un método abstracto, pero puede tener varios métodos no abstractos.

Las interfaces funcionales pueden convertirse implícitamente en expresiones lambda.

En las expresiones lambda y las referencias a métodos (que en realidad también pueden considerarse expresiones lambda).

Por ejemplo, si se define una interfaz funcional como la siguiente:

@FunctionalInterface
interface GreetingService 
{
    void sayMessage(String message);
}

Entonces se puede utilizar una expresión lambda para representar una implementación de esa interfaz (nota: antes de Java 8 generalmente se implementaba con una clase anónima):

GreetingService greetService1 = message -> System.out.println("Hello " + message);

Las interfaces funcionales pueden admitir lambdas de manera amigable con las funciones existentes.

Interfaces funcionales ya existentes antes de JDK 1.8:

  • java.lang.Runnable
  • java.util.concurrent.Callable
  • java.security.PrivilegedAction
  • java.util.Comparator
  • java.io.FileFilter
  • java.nio.file.PathMatcher
  • java.lang.reflect.InvocationHandler
  • java.beans.PropertyChangeListener
  • java.awt.event.ActionListener
  • javax.swing.event.ChangeListener

Ejemplo de interfaz funcional

La interfaz Predicate<T> es una interfaz funcional que acepta un parámetro de entrada T y devuelve un resultado booleano.

Esta interfaz contiene varios métodos predeterminados para combinar Predicate en otra lógica compleja (por ejemplo: AND, OR, NOT).

Esta interfaz se utiliza para comprobar si un objeto es true o false.

Podemos entender el uso de la interfaz funcional Predicate<T> mediante el siguiente ejemplo (Java8Tester.java):

Archivo Java8Tester.java

import java.util.Arrays; import java.util.List; import java.util.function.Predicate; public class Java8Tester { public static void main(String args[]){ List<Integer> list = Arrays.asList(1, 2, 3, 4, 5, 6, 7, 8, 9); // Predicate<Integer> predicate = n -> true //n es un parámetro que se pasa al método test de la interfaz Predicate. //Si n existe, el método test devuelve true. System.out.println("Imprimir todos los datos:"); //Pasar el parámetro n eval(list, n->true); // Predicate<Integer> predicate1 = n -> n%2 == 0 //n es un parámetro que se pasa al método test de la interfaz Predicate. //Si n%2 es 0, el método test devuelve true. System.out.println("Imprimir todos los números pares:"); eval(list, n-> n%2 == 0 ); // Predicate<Integer> predicate2 = n -> n > 3 //n es un parámetro que se pasa al método test de la interfaz Predicate. //Si n es mayor que 3, el método test devuelve true. System.out.println("Imprimir todos los números mayores que 3:"); eval(list, n-> n > 3 ); } public static void eval(List<Integer> list, Predicate<Integer> predicate) { for(Integer n: list) { if(predicate.test(n)) { System.out.println(n + " "); } } } }

    Sobre la anotación @FunctionalInterface

    Java 8 introdujo una nueva anotación @FunctionalInterface para las interfaces funcionales, utilizada principalmente para la comprobación de errores a nivel de compilación. Con esta anotación, cuando la interfaz que escribes no cumple con la definición de interfaz funcional, el compilador mostrará un error.

    Ejemplo correcto, sin errores:

    @FunctionalInterface
interface GreetingService
{
    void sayMessage(String message);
}

    Ejemplo incorrecto: la interfaz contiene dos métodos abstractos, lo que viola la definición de interfaz funcional; Eclipse muestra un error indicando que no es una interfaz funcional.

    Aviso:Se agregue o no@FunctionalInterfaceno afecta si la interfaz es funcional o no; la anotación solo indica al compilador que compruebe si la interfaz contiene únicamente un método abstracto.

    En una interfaz funcional se permite definir métodos predeterminados.

    Una interfaz funcional puede contener métodos predeterminados, porque los métodos predeterminados no son métodos abstractos, tienen una implementación predeterminada, por lo que cumplen con la definición de interfaz funcional.

    El siguiente código no mostrará errores:

    @FunctionalInterface
interface GreetingService
{
    void sayMessage(String message);

    default void doSomeMoreWork1()
    {
        // Method body
    }

    default void doSomeMoreWork2()
    {
        // Method body
    }
}

    En una interfaz funcional se permite definir métodos estáticos.

    Una interfaz funcional puede contener métodos estáticos, porque los métodos estáticos no pueden ser métodos abstractos, son métodos ya implementados, por lo que cumplen con la definición de interfaz funcional.

    El siguiente código no mostrará errores:

    @FunctionalInterface
interface GreetingService 
{
    void sayMessage(String message);
    static void printHello(){
        System.out.println("Hello");
    }
}

    En una interfaz funcional se permite definir métodos públicos de java.lang.Object.

    Una interfaz funcional puede contener métodos públicos de Object; estos métodos no se consideran métodos abstractos para la interfaz funcional (aunque sean métodos abstractos), porque cualquier implementación de una interfaz funcional hereda por defecto de la clase Object, incluyendo las implementaciones de estos métodos abstractos provenientes de java.lang.Object.

    El siguiente código no mostrará errores:

    @FunctionalInterface
interface GreetingService  
{
    void sayMessage(String message);
    
    @Override
    boolean equals(Object obj);
}

    Paquete java.util.function

    El paquete java.util.function de Java 8 contiene muchas interfaces funcionales integradas.

    PredicateLa interfaz Predicate contiene un método abstracto test. El método test evalúa los parámetros de entrada y devuelve un valor booleano como resultado de la evaluación. En cuanto a los criterios de evaluación, se dejan a la implementación concreta. El prototipo de función de Predicate es el siguiente:

    public interface Predicate
{
    public boolean test(T  t);
}

    BinaryOperatorComo su nombre indica, BinaryOperator es una interfaz funcional de entrada binaria. Contiene un método abstracto apply que recibe dos parámetros del mismo tipo y devuelve un resultado del mismo tipo que la entrada.

    public interface BinaryOperator 
{
    public T apply(T x, T y);
}

    FunctionLa interfaz Function tiene un método abstracto apply que recibe una entrada de tipo T y devuelve un resultado de tipo R. Este nombre también refleja su propósito; Function significa función, y la función de una función es la operación de mapear el dominio al codominio. Aquí T es el dominio y R es el codominio. La relación de mapeo se deja a la implementación concreta para que la defina.

    public interface Function 
    {
    public R apply(T t);
}

    Programa de ejemplo:

    // A simple program to demonstrate the use 
// of predicate interface 
import java.util.*; 
import java.util.function.Predicate; 
  
class Test 
{ 
    public static void main(String args[]) 
    { 
  
        // create a list of strings 
        List<String> names = 
            Arrays.asList("Geek","GeeksQuiz","g1","QA","Geek2"); 
  
        // declare the predicate type as string and use 
        // lambda expression to create object 
        Predicate<String> p = (s)->s.startsWith("G"); 
  
        // Iterate through the list 
        for (String st:names) 
        { 
            // call the test method 
            if (p.test(st)) 
                System.out.println(st); 
        } 
    } 
}
