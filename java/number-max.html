Método max() de Java

Clase Number de Java

El método max() se utiliza para devolver el valor máximo entre dos parámetros.

Sintaxis

Este método tiene las siguientes formas de sintaxis:

double max(double arg1, double arg2)
float max(float arg1, float arg2)
int max(int arg1, int arg2)
long max(long arg1, long arg2)

Parámetros

Este método acepta dos tipos de datos primitivos como parámetros.

Valor de retorno

Devuelve el valor máximo de los dos parámetros.

Ejemplo

public class Test{
    public static void main(String args[]){
        System.out.println(Math.max(12.123, 18.456));      
        System.out.println(Math.max(23.12, 23.0));  
    }
}

Compile el programa anterior, el resultado de salida es:

18.456
23.12
