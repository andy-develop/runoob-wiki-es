jQuery UI API - Widget de Acordeón (Accordion Widget)

Categoría

Widgets

Uso

Descripción:Convierte un par de encabezado y panel de contenido en un acordeón.

Novedad en la versión:1.0

El marcado del contenedor del acordeón requiere un par de encabezado y panel de contenido.

<div id="accordion">
  <h3>First header</h3>
  <div>First content panel</div>
  <h3>Second header</h3>
  <div>Second content panel</div>
</div>

El acordeón admite cualquier marcado, pero cada panel de contenido debe ser el hermano siguiente del panel de encabezado correspondiente. Consulteheaderla opción para saber cómo usar una estructura de marcado personalizada.

Los paneles pueden activarse mediante programación estableciendo laactiveopción.

Interacción con el teclado

Cuando el foco está en el encabezado, están disponibles los siguientes comandos de teclado:

  • ARRIBA/IZQUIERDA - Mueve el foco al encabezado anterior. Si está en el primer encabezado, mueve el foco al último encabezado.
  • ABAJO/DERECHA - Mueve el foco al siguiente encabezado. Si está en el último encabezado, mueve el foco al primer encabezado.
  • INICIO - Mueve el foco al primer encabezado.
  • FIN - Mueve el foco al último encabezado.
  • ESPACIO/ENTRAR - Activa el panel asociado al encabezado que tiene el foco.

Cuando el foco está en el panel, están disponibles los siguientes comandos de teclado:

  • CTRL+ARRIBA: Mueve el foco al encabezado correspondiente.

Tematización

El widget de acordeón (Accordion Widget) utiliza elmarco CSS de jQuery UIpara definir el estilo de su apariencia y comportamiento. Si necesita usar estilos específicos del acordeón, puede usar los siguientes nombres de clase CSS:

  • ui-accordion: Contenedor exterior del acordeón.
    • ui-accordion-header: Encabezado del acordeón. Si el encabezado contiene unicons, el encabezado tendrá además unui-accordion-icons class。
    • ui-accordion-content: Panel de contenido del acordeón.

Dependencias

  • Núcleo UI (UI Core)
  • Fábrica de widgets (Widget Factory)
  • Núcleo de efectos (Effects Core)(Opcional; cuando se usa con laanimateopción)

Notas adicionales

  • Este widget requiere algo de CSS funcional; de lo contrario, no funcionará. Si crea un tema personalizado, utilice el archivo CSS específico del widget como punto de partida.

Opciones Tipo Descripción Valor por defecto
active Boolean o Integer Qué panel está abierto actualmente.

Admite varios tipos:

  • Boolean: Establecer aactive 为 falseplegará todos los paneles. Esto requiere que lacollapsibleopción seatrue。
  • Integer: Activa el índice del panel abierto, basado en cero. Un valor negativo selecciona el panel contando hacia atrás desde el último panel.

Ejemplo de código:

Inicializar el acordeón con la opciónactiveespecificada:

$( ".selector" ).accordion({ active: 2 });
    

Después de la inicialización, obtener o establecer la opciónactive:

// getter
var active = $( ".selector" ).accordion( "option", "active" );
 
// setter
$( ".selector" ).accordion( "option", "active", 2 );

Admite varios tipos:

  • Boolean：falseEl valor deshabilitará las animaciones.

  • String: Para la duración predeterminada se usará eleasingnombre del easing.

  • "auto": Todos los paneles se establecerán a la altura del panel más alto.

Eventos Tipo Descripción
activate( event, ui ) accordionactivate Se dispara después de que un panel sea activado (después de que la animación se complete). Si el accordion estaba previamente colapsado, entoncesui.oldHeader 和 ui.oldPanelserá un objeto jQuery vacío. Si el accordion se está colapsando, entoncesui.newHeader 和 ui.newPanelserá un objeto jQuery vacío.

Nota: dado que elactivateevento solo se dispara cuando se activa un panel, el panel inicial no disparará este evento al crear el widget accordion. Si necesita un gancho para la creación del widget, utilice elcreateevento.

  • event
    Tipo: Event
  • ui
    Tipo: Object
    • newHeader
      Tipo: jQuery
      Descripción: El encabezado que acaba de ser activado.
    • oldHeader
      Tipo: jQuery
      Descripción: El encabezado que acaba de ser desactivado.
    • newPanel
      Tipo: jQuery
      Descripción: El panel que acaba de ser activado.
    • oldPanel
      Tipo: jQuery
      Descripción: El panel que acaba de ser desactivado.

Ejemplo de código:

Inicializa el accordion con el callback activate especificado:

$( ".selector" ).accordion({
  activate: function( event, ui ) {}
});
    

Vincula un detector de eventos al evento accordionactivate:

$( ".selector" ).on( "accordionactivate", function( event, ui ) {} );
    
beforeActivate( event, ui ) accordionbeforeactivate Se dispara directamente antes de que un panel sea activado. Puede cancelarse para evitar que el panel se active. Si el accordion está actualmente colapsado, entoncesui.oldHeader 和 ui.oldPanelserá un objeto jQuery vacío. Si el accordion se está colapsando, entoncesui.newHeader 和 ui.newPanelserá un objeto jQuery vacío.
  • event
    Tipo: Event
  • ui
    Tipo: Object
    • newHeader
      Tipo: jQuery
      Descripción: El encabezado que será activado.
    • oldHeader
      Tipo: jQuery
      Descripción: El encabezado que será desactivado.
    • newPanel
      Tipo: jQuery
      Descripción: El panel que será activado.
    • oldPanel
      Tipo: jQuery
      Descripción: El panel que será desactivado.

Ejemplo de código:

Inicializa el accordion con el callback beforeActivate especificado:

$( ".selector" ).accordion({
  beforeActivate: function( event, ui ) {}
});
    

Vincula un detector de eventos al evento accordionbeforeactivate:

$( ".selector" ).on( "accordionbeforeactivate", function( event, ui ) {} );
    
create( event, ui ) accordioncreate Se dispara cuando se crea el accordion. Si el accordion está colapsado,ui.header 和 ui.panelserá un objeto jQuery vacío.
  • event
    Tipo: Event
  • ui
    Tipo: Object
    • header
      Tipo: jQuery
      Descripción: El encabezado activado.
    • panel
      Tipo: jQuery
      Descripción: El panel activado.

Ejemplo de código:

Inicializa el accordion con el callback create especificado:

$( ".selector" ).accordion({
  create: function( event, ui ) {}
});
    

Vincula un detector de eventos al evento accordioncreate:

$( ".selector" ).on( "accordioncreate", function( event, ui ) {} );
