jQuery UI API - Widget Ordenable (Sortable Widget)

Categoría

Interacciones (Interactions)

Uso

Descripción:Permite ajustar el orden de los elementos en una lista o cuadrícula con el ratón.

Nuevo en la versión:1.0

Dependencias:

  • Núcleo de UI (UI Core)
  • Fábrica de widgets (Widget Factory)
  • Interacción con el ratón (Mouse Interaction)

Nota:El complemento Sortable de jQuery UI permite ordenar los elementos seleccionados mediante arrastre con el ratón.

Nota:Para ordenar filas de tabla,tbodydebe ser sortable (ordenable), notable。

appendTo jQuery o Element o Selector o String Dónde se agrega el asistente (helper) que se mueve con el ratón durante el arrastre (por ejemplo, para resolver problemas de overlap/zIndex).

Tipos admitidos:

  • jQuery: Un objeto jQuery que contiene el elemento al que se debe agregar el asistente (helper).
  • Element: El elemento al que se debe agregar el asistente (helper).
  • Selector: Un selector que especifica a qué elemento se debe agregar el asistente (helper).
  • String: String"parent"Hará que el asistente (helper) sea un hermano del elemento sortable.

Ejemplo de código:

Inicializar el sortable con laappendToopción especificada:

$( ".selector" ).sortable({ appendTo: document.body });
    

Después de la inicialización, obtener o establecer laappendToopción:

// getter
var appendTo = $( ".selector" ).sortable( "option", "appendTo" );
 
// setter
$( ".selector" ).sortable( "option", "appendTo", document.body );
    
 "parent"

Métodos Devuelve Descripción
cancel() jQuery (plugin only) Al comenzar la ordenación actual, cancela un cambio en el sortable actual y restaura el estado anterior. Es muy útil en las funciones de devolución de llamada stop y receive.
  • Este método no acepta ningún argumento.

Ejemplo de código:

Llamar al método cancel:

$( ".selector" ).sortable( "cancel" );
    
destroy() jQuery (plugin only) Elimina por completo la funcionalidad de sortable. Esto devuelve el elemento a su estado previo a la inicialización.
  • Este método no acepta ningún argumento.

Ejemplo de código:

Llamar al método destroy:

$( ".selector" ).sortable( "destroy" );
    
disable() jQuery (plugin only) Deshabilita sortable.
  • Este método no acepta ningún argumento.

Ejemplo de código:

serialize( options ) String Serializa los elementos de sortableiden una cadena que se puede enviar mediante form/ajax. Llamar a este método genera un hash que se puede añadir a cualquier URL para enviar fácilmente el nuevo orden de los elementos de vuelta al servidor.

Por defecto, funciona a través delidid de cada elemento, con el formato"setname_number", y producirá un hash de la forma"setname[]=number&setname[]=number".

Nota: si la serialización devuelve una cadena vacía, asegúrese de que elidatributo contenga un guion bajo (_). La forma debe ser"set_number". Por ejemplo,iduna lista de 3 elementos cuyo atributo es"foo_1"、"foo_5"、"foo_2"se serializará como"foo[]=1&foo[]=5&foo[]=2". Puede usar guion bajo (_), signo igual (=) o guion (-) para separar el conjunto y el número. Por ejemplo,"foo=1"、"foo-1"、"foo_1"todos se serializan como"foo[]=1"。

  • options
    Tipo: Object
    Opciones para personalizar la serialización.
    • key(predeterminado:La parte anterior al separador en el atributo）
      Tipo: String
      Descripción: reemplacepart1[]con el valor especificado.
    • attribute(predeterminado:"id"）
      Tipo: String
      Descripción: el nombre del atributo que se utilizará para el valor.
    • expression(predeterminado:/(.+)[-=_](.+)/）
      Tipo: RegExp
      Descripción: la expresión regular utilizada para separar el valor del atributo en dos partes: clave y valor.

Ejemplo de código:

Llamar al método serialize:

var sorted = $( ".selector" ).sortable( "serialize", { key: "sort" } );
