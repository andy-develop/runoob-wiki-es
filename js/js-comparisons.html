Cómo utilizar

Puede utilizar operadores de comparación en declaraciones condicionales para comparar valores y luego actuar según el resultado:

if (age<18) x="Too young";

Aprenderá más sobre las declaraciones condicionales en la próxima sección de este tutorial.

Operador condicional

JavaScript también incluye un operador condicional que asigna un valor a una variable según ciertas condiciones.

Sintaxis

variablename=(condition)?value1:value2 

Ejemplo

Ejemplo

Si el valor de la variable age es menor que 18, se asigna "Demasiado joven" a la variable voteable; de lo contrario, se asigna "Edad suficiente".

voteable=(age<18)?"Demasiado joven":"Edad suficiente";

    Operador múltiple de JavaScript

    function test(p){
    var a=5,b=12;
    return p>1?p<b?p>b:p=6:p=3; // 这一行中出现了多个问号和冒号，看起来很乱怎么办呢
}

document.write(test(9));

    Ejemplo »

    En realidad es muy simple, encontrar la cabeza ? y la cola : del operador múltiple lo hace mucho más fácil.

    Queda así:

    p>1?p<b?p>b:p=6:p=3

p>1? 整体 :p=3

    1. Cuando p>1, devuelve p<b?p>b:p=6

    • 1.1. Cuando p<b, devuelve p>b
    • 1.2. Cuando p>=b, devuelve p=6

    2. Cuando p<=1, devuelve p=3, así que primero se ejecuta 1

    3. En el ejemplo, cuando p=9, devuelve p<b?p>b:p=6 y luego ejecuta 1.1; cuando p=9<12, devuelve p>b, es decir, 9>12, la condición no se cumple, por lo que el resultado final es false.

    Primero, hablemos de las reglas para convertir otros tipos de datos al tipo booleano:null, undefined, 0, NaN, cadena vacíase convierten enfalse, y los demás se convierten entrue。

    En JavaScript hay tres operadores lógicos:

    1. Negación !

    Primero convierte los datos a un valor booleano, luego lo niega, y el resultado es true o false.

    <script type="text/javascript">
var a = [1,2,3];
var b = "hello";
var obj = new Object();
var d;

console.log(!"");   //true
console.log(!d);    //true
console.log(!a);    //false
console.log(!b);    //false
console.log(!obj);  //false
</script>

    2. Y lógico &&

    En JavaScript, el Y lógico es un poco diferente de otros lenguajes. Si el primer operando es true (o puede convertirse en true), el resultado de la operación es el segundo operando; si el primer operando es false, el resultado es false (cálculo de cortocircuito). Para algunos valores especiales no se siguen las reglas anteriores. (Entendimiento personal: si el primer operando de la operación es true, devuelve el segundo operando; de lo contrario, devuelve el primer operando).

    <script type="text/javascript">
var a = [1,2,3];
var b = "hello";
var obj = new Object();
var d;

console.log(true && 10);            //第一个操作数是true，结果是第二个操作，也就是10
console.log(false && b);            //第一个操作数是false，结果flase
console.log(100 && false);          //第一个操作数是100，结果flase
console.log(undefined && false);    //第一个操作数是undefined，结果undefined
console.log(NaN && false);          //第一个操作数是NaN，结果NaN
console.log(null && false);         //第一个操作数是null，结果null
console.log('' && false);           //第一个操作数是空串，结果空串
console.log(0 && 100);              //结果是0
console.log(5 && 100);              //100
console.log(a && b);                //hello
console.log(obj && 200);            //200
</script>

    3. O lógico ||

    Si el primer operando no es false, el resultado es el primer operando; de lo contrario, el resultado es el segundo operando. Si el primer operando puede convertirse en true, el resultado es el primer operando (entendimiento personal: si el primer operando de la operación es true, devuelve el primer operando; de lo contrario, devuelve el segundo operando).

    <script type="text/javascript">
var a = [1,2,3];
var b = "hello";
var obj = new Object();
var d;

console.log(true || 10);        //第一个操作数是true，结果是第一个操作，也就是true
console.log(false || b);        //第一个操作数是false，结果是第二个操作数b
console.log(100 || false);      //第一个操作数是100，结果100
console.log(undefined || 9);    //第一个操作数是undefined转false，结果9
console.log(NaN || false);      //第一个操作数是NaN转false，结果第二个操作数
console.log(null || a);         //第一个操作数是null转false，结果a
console.log('' || false);       //第一个操作数是空串转false，结果第二操作数
console.log(0 || 100);          //结果是100
console.log(5 || 100);          //5
console.log(a || b);            //a
console.log(obj || 200);        //obj
</script>

    1. Y lógico &&

    Lo que se devuelve no es simplemente true o false, sino un valor concreto;

    Si el primer valor se convierte a booleano true, devuelve el segundo valor; de lo contrario, devuelve el primer valor.

    En JavaScript hay dos operadores de igualdad:==和===Sus reglas de comparación son las siguientes:

    • ==是Igualdad abstractaoperador, que intenta convertir los dos operandos al mismo tipo antes de comparar, y luego compara si sus valores son iguales. Por ejemplo,1 == "1"devuelve true, porque la cadena "1" se convierte en el número 1 y luego se compara.
    • ===是Igualdad estrictaoperador, que no realiza conversión de tipo, sino que compara directamente si el tipo y el valor de ambos operandos son exactamente iguales. Por ejemplo,1 === "1"devuelve false, porque el número 1 y la cadena "1" son de tipos diferentes; aunque sus valores sean iguales, no devuelve true.

    En general, se recomienda utilizar===para la comparación, porque puede evitar algunos resultados inesperados, por ejemplo:

    • null == undefineddevolverá true, peronull === undefineddevolverá false.
    • 0 == falsedevolverá true, pero0 === falsedevolverá false.
    • NaN == NaNdevolverá false, peroNaN === NaNtambién devolverá false.

    Igualdad abstractaEl operador, al intentar convertir ambos operandos al mismo tipo, sigue las siguientes reglas:

    • Si ambos operandos son tipos primitivos, la conversión de tipos se realiza en el siguiente orden:
      • Si un operando es booleano, se convierte a número: true se convierte en 1, false en 0.
      • Si un operando es una cadena y el otro es un número, la cadena se convierte a número.
      • Si un operando es null y el otro es undefined, no se realiza conversión de tipos y se devuelve directamente true.
      • Si un operando es null o undefined, y el otro es un valor primitivo no null ni undefined, no se realiza conversión de tipos y se devuelve directamente false.
      • Si ambos operandos son cadenas, no se realiza conversión de tipos y se compara directamente si sus valores literales son iguales.
      • Si ambos operandos son números, no se realiza conversión de tipos y se compara directamente si sus valores numéricos son iguales (nota: NaN no es igual a ningún valor).

    Por ejemplo:"1" == truedevolverá true, porque true se convierte en 1, y la cadena "1" también se convierte en 1, por lo que ambos 1 son iguales; de manera similar,"0" == falsetambién devolverá true

    • Si uno de los dos operandos es de tipo objeto y el otro es de tipo primitivo, el operando de tipo objeto se convierte a tipo primitivo antes de realizar la comparación. El operando de tipo objeto llama a su método valueOf() o toString() (si el método valueOf() no existe o no devuelve un valor primitivo) para obtener un valor primitivo. Por ejemplo,[1,2,3] == "1,2,3"devolverá true, porque el array llama al método toString() y devuelve la cadena "1,2,3".
    • Si ambos operandos son de tipo objeto, no se realiza conversión de tipos y se compara directamente si sus referencias son iguales. Es decir, solo se devuelve true cuando ambos objetos apuntan a la misma dirección de memoria. Por ejemplo,[1,2,3] == [1,2,3]devolverá false, porque son dos objetos de array diferentes.
