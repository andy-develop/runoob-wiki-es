JavaScript Tipos de datos

Tipos de valor (tipos primitivos): cadena (String), número (Number), booleano (Boolean), nulo (Null), no definido (Undefined), Symbol.

Tipos de datos de referencia (tipos de objeto): objeto (Object), arreglo (Array), función (Function), y dos objetos especiales: expresión regular (RegExp) y fecha (Date).

Nota:Symbol es un nuevo tipo de datos primitivo introducido en ES6, que representa un valor único.

JavaScript tiene tipos dinámicos

JavaScript tiene tipos dinámicos. Esto significa que la misma variable puede usarse como diferentes tipos:

Ejemplo

var x; // x es undefined
var x = 5; // ahora x es un número
var x = "John"; // ahora x es una cadena

El tipo de datos de una variable se puede consultar con eltypeofoperador para verlo:

Ejemplo

typeof "John"                // devuelve string
typeof 3.14                  // devuelve number
typeof false                 // devuelve boolean
typeof [1,2,3,4]             // devuelve object
typeof {name:'John', age:34} // devuelve object

Pruébalo »

typeof [1,2,3,4] devuelve "object", esto es un "defecto" del diseño inicial de JavaScript; los arreglos son esencialmente un tipo especial de objeto.

Método correcto para detectar arreglos:

Array.isArray([1,2,3]); // true
[1,2,3] instanceof Array; // true

JavaScript Cadenas

Una cadena es una variable que almacena caracteres (por ejemplo, "Bill Gates").

Las cadenas pueden ser cualquier texto entre comillas. Puede usar comillas simples o dobles:

Ejemplo

var carname="Volvo XC60";
var carname='Volvo XC60';

Puede usar comillas dentro de una cadena, siempre que no coincidan con las comillas que encierran la cadena:

Ejemplo

var answer="It's alright";
var answer="He is called 'Johnny'";
var answer='He is called "Johnny"';

JavaScript Números

JavaScript solo tiene un tipo numérico. Los números pueden tener punto decimal o no:

Ejemplo

var x1=34.00; // escrito usando punto decimal
var x2=34; // escrito sin punto decimal

Los números extremadamente grandes o pequeños se pueden escribir con notación científica (exponencial):

Ejemplo

var y=123e5;      // 12300000
var z=123e-5;     // 0.00123

JavaScript Booleanos

Un booleano (lógico) solo puede tener dos valores: true o false.

var x=true;
var y=false;

Los booleanos se usan a menudo en pruebas condicionales. Aprenderá más sobre pruebas condicionales en capítulos posteriores de este tutorial.

JavaScript Arreglos

El siguiente código crea un arreglo llamado cars:

var cars=new Array();
cars[0]="Saab";
cars[1]="Volvo";
cars[2]="BMW";

O (arreglo condensado):

var cars=new Array("Saab","Volvo","BMW");

O (arreglo literal):

Ejemplo

var cars=["Saab","Volvo","BMW"];

JavaScript Objetos

Los objetos están delimitados por llaves. Dentro de las llaves, las propiedades del objeto se definen como pares de nombre y valor (name : value). Las propiedades están separadas por comas:

var person={firstname:"John", lastname:"Doe", id:5566};

El objeto (person) en el ejemplo anterior tiene tres propiedades: firstname, lastname e id.

Los espacios y los saltos de línea no son importantes. La declaración puede abarcar varias líneas:

var person={
firstname : "John",
lastname  : "Doe",
id        :  5566
};

Hay dos formas de acceder a las propiedades de un objeto:

Ejemplo

name=person.lastname;
name=person["lastname"];

Undefined y Null

El valor undefined indica que una variable no contiene un valor.

Se puede vaciar una variable estableciendo su valor en null.

Ejemplo

cars=null;
person=null;

Pruébalo »

Declarar tipos de variables

Cuando declara una nueva variable, puede usar la palabra clave "new" para declarar su tipo:

var carname=new String;
var x=      new Number;
var y=      new Boolean;
var cars=   new Array;
var person= new Object;

Las variables de JavaScript son todas objetos. Cuando declara una variable, se crea un nuevo objeto.

    Las variables de tipos primitivos se almacenan en la memoria de pila (Stack).

    var a,b;
a = "zyj";
b = a;

console.log(b);   // zyj
a = "呵呵";       // 改变 a 的值，并不影响 b 的值

    El diagrama es el siguiente: la memoria de pila incluye el identificador de la variable y su valor.

    El valor de un tipo de referencia es un objeto (Object) almacenado en la memoria de montón (Heap).

    var a = {name:"percy"};
var b;
b = a;
a.name = "zyj";
console.log(b.name);    // zyj
b.age = 22;
console.log(a.age);     // 22
var c = {
  name: "zyj",
  age: 22
};

    El diagrama es el siguiente:

    • La memoria de pila almacena el identificador de la variable y un puntero al objeto en la memoria de montón.

    • La memoria de montón almacena el contenido del objeto.

    null y undefined

    En JavaScript, null se usa para objetos, undefined para variables, propiedades y métodos.

    Un objeto solo puede ser null si ha sido definido; de lo contrario, es undefined.

    Si queremos comprobar si un objeto existe, se lanzará un error cuando el objeto aún no esté definido.

    Forma incorrecta de usarlo:

    if (myObj !== null && typeof myObj !== "undefined")

    La forma correcta es que necesitamos usar typeof primero para detectar si el objeto está definido:

    if (typeof myObj !== "undefined" && myObj !== null)
