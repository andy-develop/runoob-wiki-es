JavaScript Definición de funciones

JavaScript usa la palabra clavefunctionpara definir funciones.

Las funciones pueden definirse mediante una declaración o mediante una expresión.

Declaración de funciones

En tutoriales anteriores, ya has aprendido la sintaxis de la declaración de funciones:

function functionName(parameters) {
  执行的代码
}

Una función declarada no se ejecuta inmediatamente; se invoca cuando la necesitamos.

Ejemplo

function myFunction(a, b) {
    return a * b;
}

Pruébalo »

El punto y coma se usa para separar sentencias ejecutables de JavaScript.
Dado que la declaración de una función no es una sentencia ejecutable, no termina con punto y coma.

Expresión de función

Las funciones de JavaScript pueden definirse mediante una expresión.

La expresión de función puede almacenarse en una variable:

Ejemplo

var x = function (a, b) {return a * b};

Pruébalo »

Después de almacenar la expresión de función en una variable, la variable también puede usarse como una función:

Ejemplo

var x = function (a, b) {return a * b};
var z = x(4, 3);

Pruébalo »

La función anterior es en realidad unafunción anónima(la función no tiene nombre).

La función se almacena en una variable; no necesita nombre de función y normalmente se invoca mediante el nombre de la variable.

La función mencionada termina con punto y coma porque es una sentencia de ejecución.

Constructor Function()

En los ejemplos anteriores, aprendimos que las funcionesfunctionse definen mediante la palabra clave.

Las funciones también pueden definirse mediante el constructor de funciones incorporado de JavaScript (Function()).

Ejemplo

var myFunction = new Function("a", "b", "return a * b");

var x = myFunction(4, 3);

Pruébalo »

De hecho, no es necesario usar el constructor. El ejemplo anterior puede escribirse como:

Ejemplo

var myFunction = function (a, b) {return a * b};

var x = myFunction(4, 3);

Pruébalo »

En JavaScript, en muchas ocasiones necesitas evitar usarnewla palabra clave.

Elevación de funciones (Hoisting)

En tutoriales anteriores ya hemos aprendido sobre "hoisting (elevación)".

El hoisting (elevación) es el comportamiento predeterminado de JavaScript que eleva el ámbito actual hacia el frente.

El hoisting (elevación) se aplica a la declaración de variables y a la declaración de funciones.

Por lo tanto, las funciones pueden invocarse antes de su declaración:

myFunction(5);

function myFunction(y) {
    return y * y;
}

Las funciones definidas mediante una expresión no se pueden elevar (hoisting).

Funciones autoejecutables

Una expresión de función puede "autoinvocarse".

Una expresión autoejecutable se invoca automáticamente.

Si la expresión va seguida de (), se invocará automáticamente.

Una función declarada no puede autoejecutarse.

Agregando paréntesis para indicar que es una expresión de función:

Ejemplo

(function () {
var x = "Hello!!"; // Me invocaré a mí misma
})();

Pruébalo »

La función anterior es en realidad unafunción anónima autoejecutable(sin nombre de función).

Las funciones se pueden usar como un valor

Las funciones de JavaScript se usan como un valor:

Ejemplo

function myFunction(a, b) {
    return a * b;
}

var x = myFunction(4, 3);

Pruébalo »

Las funciones de JavaScript se pueden usar como una expresión:

Ejemplo

function myFunction(a, b) {
    return a * b;
}

var x = myFunction(4, 3) * 2;

Pruébalo »

Las funciones son objetos

En JavaScript, usandotypeofel operador para determinar el tipo de función devolverá "function".

Pero es más preciso describir las funciones de JavaScript como un objeto.

Las funciones de JavaScript tienenpropiedades 和 y métodos.。

La propiedad arguments.length devuelve el número de argumentos recibidos durante la invocación de la función:

Ejemplo

function myFunction(a, b) {
    return arguments.length;
}

Pruébalo »

El método toString() devuelve la función como una cadena de texto:

Ejemplo

function myFunction(a, b) {
    return a * b;
}

var txt = myFunction.toString();

Pruébalo »

Funciones flecha

ES6 añadió las funciones flecha.

La sintaxis de la expresión de función flecha es más concisa que la de una expresión de función normal.

(参数1, 参数2, …, 参数N) => { 函数声明 }

(参数1, 参数2, …, 参数N) => 表达式(单一)
// 相当于：(参数1, 参数2, …, 参数N) =>{ return 表达式; }

Cuando solo hay un parámetro, los paréntesis son opcionales:

(parámetro único) => {declaración de función}
parámetro único => {declaración de función}

Una función sin parámetros debe escribirse con un par de paréntesis:

() => {declaración de función}

Ejemplo

// ES5 var x = function(x, y) { return x * y; } // ES6 const x = (x, y) => x * y;

Pruébalo »

Las funciones flecha no tienen su propiothisthis.No son adecuadas para definir los métodos de un objeto.。

Cuando usamos funciones flecha, estas nos ayudan a vincular automáticamente el valor de this del ámbito externo, por lo que, dentro de la función flecha, el valor de this es el mismo que el this del ámbito externo.

Las funciones flecha no se pueden elevar (hoisting), por lo que deben definirse antes de usarse.

Usar constconstes más seguro que usar varvarporque una expresión de función siempre es una constante.

Si la parte de la función es solo una sentencia, se pueden omitir la palabra clave return y las llaves {}, lo cual es una buena práctica:

Ejemplo

const x = (x, y) => { return x * y };

Pruébalo »

Nota:IE11 y las versiones anteriores de IE no admiten las funciones flecha.

    Para la autoinvocación de funciones, es necesario envolver la expresión de función entre paréntesis (para indicar que es una expresión de función) y luego invocarla; de lo contrario, se producirá un error, como en el siguiente ejemplo:

    function () { document.write( "Hello! 我是自己调用的" );}();
// 报错：Uncaught SyntaxError: Unexpected token (

    Forma correcta:

    (function () { document.write( "Hello! 我是自己调用的" );})();

    Ahora sabemos que cuando una expresión de función va seguida de()(), se invoca automáticamente; pero si asignas la expresión de función a una variable, no necesitas agregar paréntesis para invocarla directamente. En el código siguiente, el cuerpo de la expresión de función se ejecutará y devolverá una cadena a la variable.a:

    var a = function () {
    document.write("Hello! 我是自己调用的" + "<br />");
    return '返回的东西';
}();

document.write(a);
