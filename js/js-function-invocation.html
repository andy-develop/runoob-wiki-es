Invocar funciones de JavaScript

En capítulos anteriores hemos aprendido a crear funciones.

El código de la función se ejecuta después de que la función es invocada.

Invocar como una función

Ejemplo

function myFunction(a, b) { return a * b; } myFunction(10, 2); //myFunction(10, 2) devuelve 20

Pruébalo »

La función anterior no pertenece a ningún objeto. Pero en JavaScript this siempre es el objeto global predeterminado.

En HTML, el objeto global predeterminado es la propia página HTML, por lo que la función pertenece a la página HTML.

En el navegador, el objeto de la página es la ventana del navegador (objeto window). La función anterior se convierte automáticamente en una función del objeto window.

myFunction() y window.myFunction() son lo mismo:

Ejemplo

function myFunction(a, b) { return a * b; } window.myFunction(10, 2); //window.myFunction(10, 2) devuelve 20

Pruébalo »

Esta es una forma común de invocar funciones de JavaScript, pero no es una buena práctica de programación.
Las variables, métodos o funciones globales pueden causar errores de conflicto de nombres.

Objeto global

Cuando una función no es invocada por su propio objeto,thisel valor de this se convierte en el objeto global.

En un navegador web, el objeto global es la ventana del navegador (objeto window).

Este ejemplo devuelvethisel valor de this es el objeto window:

Ejemplo

function myFunction() { return this; } myFunction(); //Devuelve el objeto window

Invocar funciones mediante el constructor

Ejemplo

Invocar la función como método de función

En JavaScript, las funciones son objetos. Las funciones de JavaScript tienen sus propiedades y métodos.

call()yapply()call() y apply() son métodos de función predefinidos. Ambos métodos pueden utilizarse para invocar funciones, y el primer parámetro de ambos debe ser el propio objeto.

Ejemplo

function myFunction(a, b) { return a * b; } myObject = myFunction.call(myObject, 10, 2); //Devuelve 20

Pruébalo »

Ejemplo

function myFunction(a, b) { return a * b; } myArray = [10, 2]; myObject = myFunction.apply(myObject, myArray); //Devuelve 20

Pruébalo »

Ambos métodos utilizan el propio objeto como primer parámetro. La diferencia entre ellos radica en el segundo parámetro: apply recibe un array de argumentos, es decir, combina varios argumentos en un array y lo pasa, mientras que call los pasa como parámetros de call (a partir del segundo parámetro).

En el modo estricto de JavaScript (strict mode), al invocar una función, el primer parámetro se convierte enthisel valor de this, incluso si ese parámetro no es un objeto.

En el modo no estricto de JavaScript (non-strict mode), si el valor del primer parámetro es null o undefined, se utilizará el objeto global en su lugar.

Mediante los métodos call() o apply() puedes establecerthisel valor de this y llamarlo como un nuevo método de un objeto existente.
