Elevación de declaraciones en JavaScript

En JavaScript, las declaraciones de funciones y variables se elevan hasta la parte superior de la función.

En JavaScript, las variables pueden declararse después de usarse, es decir, una variable puede usarse antes de declararse.

Los siguientes dos ejemplos obtendrán el mismo resultado:

Ejemplo 1

x = 5; // la variable x se establece en 5
elem = document.getElementById("demo"); // buscar el elemento
 elem.innerHTML = x;                     // mostrar x en el elemento

var x; // declarar x

Pruébalo »

Ejemplo 2

var x; // declarar x
 x = 5; // la variable x se establece en 5

elem = document.getElementById("demo"); // buscar el elemento
elem.innerHTML = x;                     // mostrar x en el elemento

Pruébalo »

Para entender los ejemplos anteriores, es necesario entender el "hoisting (elevación de declaraciones)".

Elevación de declaraciones: las declaraciones de funciones y variables siempre son "elevadas" silenciosamente por el intérprete a la parte superior del cuerpo del método.

La inicialización de JavaScript no se eleva

La inicialización de JavaScript no se eleva. En JavaScript, solo la parte de la declaración de variables se eleva; la parte de inicialización no.

Los resultados de los siguientes dos ejemplos no son iguales:

Ejemplo 1

var x = 5; // inicializar x
var y = 7; // inicializar y

elem = document.getElementById("demo"); // buscar el elemento
 elem.innerHTML = x + " " + y;           // mostrar x e y

Pruébalo »

Ejemplo 2

var x = 5; // inicializar x
elem = document.getElementById("demo"); // buscar el elemento
 elem.innerHTML = x + " " + y;           // mostrar x e y
var y = 7; // inicializar y

Pruébalo »

La y del ejemplo 2 mostróundefined, esto se debe a que la declaración de la variable (var y) se elevó, pero la inicialización (y = 7) no se eleva, por lo que la variable y es una variable indefinida.

El ejemplo 2 es similar al siguiente código:

var x = 5; // 初始化 x
var y;     // 声明 y

elem = document.getElementById("demo"); // 查找元素
elem.innerHTML = x + " " + y;           // 显示 x 和 y

y = 7;    // 设置 y 为 7

Declara tus variables en la parte superior

La mayoría de los programadores no conocen la elevación de declaraciones de JavaScript.

Si los programadores no comprenden bien la elevación de declaraciones, los programas que escriban pueden presentar fácilmente algunos problemas.

Para evitar estos problemas, normalmente declaramos estas variables al comienzo de cada ámbito (scope), que también son los pasos normales de análisis de JavaScript y son fáciles de entender.

El modo estricto de JavaScript (strict mode) no permite el uso de variables no declaradas.

    En realidad, basta con entender el mecanismo de análisis (parse) de JS.

    Cuando se encuentra una etiqueta script, JS realiza un análisis previo, elevando las declaraciones de variables var y funciones, pero no ejecuta las funciones. Luego entra en la ejecución del contexto; la ejecución del contexto también realiza la misma operación de análisis previo, hasta que no haya más var y function, entonces comienza a ejecutar el contexto. Por ejemplo:

    a=5;
show();
var a;
function show(){};

    Preanálisis:

    function show(){};
var a;
a=5;
show();

    Cabe señalar que la elevación de declaraciones de funciones eleva directamente toda la función a la parte más alta del entorno de ejecución.

    Además de la forma de declaración de funciones anterior, también se puede usar el método de funciones anónimas.

    Declaración:

    var 变量名称=function(形参列表){
  //函数体
}

    Llamada:

    nombre de variable (lista de argumentos)

    Nota: Usar funciones anónimas no tiene elevación de funciones, porque el nombre de la función se representa con una variable, solo existe elevación de variables. Ejemplo:

    var getName=function(){
  console.log(2);
}

function getName(){
  console.log(1);
}

getName();
//结果为2

    Puede que algunos piensen que el resultado final es 1. Pero getName es una variable, por lo que la declaración de esta variable también se elevará a la parte superior, mientras que la asignación de la variable permanece en su posición original. Cabe señalar que las funciones tienen prioridad: aunque tanto las declaraciones de funciones como las declaraciones de variables se elevan, las funciones se elevan primero y luego las variables.

    //函数、变量声明提升后
function getName(){    //函数声明提升到顶部
  console.log(1);
}

var getName;    //变量声明提升
getName = function(){    //变量赋值依然保留在原来的位置
  console.log(2);
}

getName();    // 最终输出：2

    La elevación de las declaraciones de variables y de funciones ocurre durante el proceso de pre-análisis.

    El proceso de pre-análisis es también el proceso de creación del AO (Activation Object).

    Proceso de creación del AO:

    • Crear el objeto AO.
    • Tomar los parámetros formales y las declaraciones de variables dentro de la función como nombres de propiedades del objeto, con valores de propiedad unificados comoundefined。
    • Asignar los argumentos reales a los parámetros formales.
    • Encontrar las declaraciones de funciones dentro de la función como nombres de propiedades del objeto, con el valor de la propiedad como el cuerpo de la función.

    ¿Qué es la elevación de variables?

    En principio, las variables deben declararse antes de usarse, pero los programadores principiantes a menudo olvidan declararlas y usan la variable. Al hacerlo, el código JS no genera un error al ejecutarse, solo devuelve un `undefined`. Esta situación es la elevación de variables.

    Cuando la computadora ejecuta, coloca implícitamente las variables usadas sin declarar en la parte superior del código. Cabe señalar que aunque la variable se ha elevado, el valor asignado a la variable no se eleva junto con ella, por lo que se obtiene `undefined` como resultado.

    ¿Qué es la elevación de funciones?

    Es similar a la elevación de variables: usar la función primero y declararla después. Esta cosa ilógica está permitida en JavaScript; este lenguaje es así de flexible.

    A diferencia de la elevación de variables, el valor de retorno de la función también se eleva, por lo que descubrirás que puedes llamar a la función en cualquier lugar dentro de la etiqueta `<script>` y usar su valor de retorno.
