Objeto Math

La función del objeto Math (Aritmética) es: realizar tareas aritméticas comunes.

El objeto Math proporciona varios tipos de valores aritméticos y funciones. No es necesario definirlo antes de usar este objeto.

Sintaxis para usar propiedades/métodos de Math:

Ejemplos

var x=Math.PI;
var y=Math.sqrt(16);

Nota:El objeto Math no necesita ser definido antes de usarlo.

    Para números pseudoaleatorios, JS tiene muchas maneras de generar los números pseudoaleatorios que necesitamos.

    Generar números aleatorios según los límites superior e inferior:

    var rand = (min,max) => Math.round(Math.random()*(max-min))+min;
//Max为最大值，Min为最小值

    Generar valores bool aleatoriamente según la probabilidad:

    function randBool(percent=0.5){
  //percent为概率，默认0.5（50%）。
  if(Math.random()<percent)//如果随机数小于概率值，返回true，否则返回false。
    return true;
  else
    return false;
}

    Generar caracteres específicos aleatoriamente:

    function randChar(length,characters="abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789"){
  //length为所需长度，characters为所包含的所有字符，默认为字母+数字。
  characters=characters.split("");//分割字符。
  result="";//返回的结果。
  while(result.length<length) result+=characters[Math.round(Math.random()*characters.length) - 1];
  return result;
}

    Otra forma de generar caracteres aleatoriamente:

    function randCharAnother(length,rangeMin=0x80,rangeMax=0x7FF){
  //length长度，rangeMin为最小Unicode码，rangeMax为最大Unicode码。
  result="";
  while(result.length<length) result+=String.fromCharCode(Math.round(Math.random()*(rangeMax-rangeMin))-rangeMin);
  return result;
}

    Extraer aleatoriamente un elemento de un array:

    Array.prototype.pick = function(){
  //不能为 ()=>{/*函数*/}，否则this会指向Window。
  return this.length?Math.round(Math.random()*(this.length-1)):undefined;//如果长度为0，返回undefined。
}

    Inspirado por los dos comentarios anteriores, pensé que cuando a es mayor que b, y ambos son enteros: los enteros aleatorios entre [a, b] o [a, b) o (a, b] o (a, b). En realidad, todos pueden convertirse al tipo [a, b).

    Ahora, desde una perspectiva matemática, presento el proceso de derivación de los números aleatorios entre [a, b); tal vez sea revelador:

    0<= Math.random() <1  
0<= Math.random() * (b-a) < b-a
a <=Math.random() * (b-a) < b
a<= Math.floor( Math.random() * (b-a)) < b
Math.floor( Math.random() * (b-a)) -------就是[a, b) 之间的随机整数。

    0 <= Math.random() <1
0 <= Math.random()*(b-a) < b-a

    Se concluye: Math.random()*(b-a)+a ----------- es el número aleatorio entre [a,b].
