El operador + para cadenas

El operador + se usa para sumar (concatenar) valores de texto o variables de cadena.

Para concatenar dos o más variables de cadena, use el+operador.

Ejemplo

Para concatenar dos o más variables de cadena, use el+operador:

txt1="What a very"; txt2="nice day"; txt3=txt1+txt2;

txt3El resultado es el siguiente:

What a verynice day

Pruébalo »

Para agregar un espacio entre dos cadenas, inserte el espacio en una de las cadenas:

Ejemplo

txt1="What a very "; txt2="nice day"; txt3=txt1+txt2;

Después de ejecutar las sentencias anteriores, la variabletxt3contiene el valor:

What a very nice day

O inserte el espacio en la expresión:

Ejemplo

txt1="What a very"; txt2="nice day"; txt3=txt1+" "+txt2;

Después de ejecutar las sentencias anteriores, la variabletxt3contiene el valor:

What a very nice day

Sumar cadenas y números

Si se suman dos números, se devuelve la suma de los números; si se suma un número y una cadena, se devuelve la cadena, como en el siguiente ejemplo:

Ejemplo

x=5+5; y="5"+5; z="Hello"+5;

x,y, yzEl resultado de salida es:

10
55
Hello5

Regla:Si suma un número y una cadena, ¡el resultado será una cadena!

    Diferencia entre == y === en JavaScript

    1. Para tipos básicos como string, number, etc., == y === son diferentes.

    • a) Al comparar tipos diferentes, == solo compara el "valor después de convertirlo al mismo tipo" para ver si los "valores" son iguales; con ===, si los tipos son diferentes, el resultado es desigual.
    • b) Al comparar del mismo tipo, se compara directamente el "valor"; el resultado de ambos es el mismo.

    2. Para tipos avanzados como Array, Object, etc., no hay diferencia entre == y ===

    Se compara la "dirección de puntero".

    3. Entre tipos básicos y tipos avanzados, == y === son diferentes.

    • a) Para ==, convierte el tipo avanzado al tipo básico y compara los "valores".
    • b) Debido a que los tipos son diferentes, === da como resultado false.
