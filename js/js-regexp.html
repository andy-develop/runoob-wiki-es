JavaScript Expresiones regulares

Una expresión regular (en inglés: Regular Expression, a menudo abreviada en código como regex, regexp o RE) utiliza una sola cadena para describir y hacer coincidir una serie de patrones de búsqueda de cadenas que se ajustan a una determinada regla sintáctica.

El patrón de búsqueda se puede usar para la búsqueda y el reemplazo de texto.

¿Qué es una expresión regular?

Una expresión regular es un patrón de búsqueda formado por una secuencia de caracteres.

Cuando buscas datos en un texto, puedes usar el patrón de búsqueda para describir lo que quieres consultar.

Una expresión regular puede ser un carácter simple o un patrón más complejo.

Las expresiones regulares se pueden usar en todas las operaciones de búsqueda y reemplazo de texto.

Puedes acceder a más contenido sobre expresiones regulares en:Expresiones regulares - Tutorial.

var patt = /runoob/i

Usar métodos de cadenas

En JavaScript, las expresiones regulares se usan normalmente con dos métodos de cadena: search() y replace().

search() El método se utiliza para buscar la subcadena especificada en una cadena, o la subcadena que coincida con una expresión regular, y devuelve la posición inicial de la subcadena.

replace() El método se utiliza para reemplazar unas cadenas por otras en una cadena, o reemplazar una subcadena que coincida con una expresión regular.

El método search() con una expresión regular

Ejemplo

Buscar la cadena "Runoob" usando una expresión regular, sin distinguir entre mayúsculas y minúsculas:

var str = "Visit Runoob!"; var n = str.search(/Runoob/i);

El resultado es:

6

El método search() con una cadena

El método search() puede usar una cadena como argumento. El argumento de cadena se convierte en una expresión regular:

Ejemplo

Buscar la subcadena "Runoob" en la cadena:

var str = "Visit Runoob!"; var n = str.search("Runoob");

El método replace() con una expresión regular

Ejemplo

Usando una expresión regular sin distinguir entre mayúsculas y minúsculas, reemplaza Microsoft por Runoob en la cadena:

var str = document.getElementById("demo").innerHTML; var txt = str.replace(/microsoft/i,"Runoob");

¿Lo has notado?


Los argumentos de expresiones regulares se pueden usar en los métodos anteriores (en lugar de argumentos de cadena).
Las expresiones regulares hacen que la función de búsqueda sea más potente (como en el ejemplo de no distinguir entre mayúsculas y minúsculas).

Modificadores de expresiones regulares

ModificadorPuede no distinguir entre mayúsculas y minúsculas en una búsqueda global:

Modificador Descripción
i Realiza una coincidencia que no distingue entre mayúsculas y minúsculas.
g Realiza una coincidencia global (encuentra todas las coincidencias en lugar de detenerse después de la primera).
m Realiza una coincidencia multilínea.

Patrones de expresiones regulares

Los corchetes se utilizan para buscar caracteres dentro de un rango:

Expresión Descripción
[abc] Busca cualquier carácter entre corchetes.
[0-9] Busca cualquier dígito del 0 al 9.
(x|y) Busca cualquier opción separada por |.

Los metacaracteres son caracteres que tienen un significado especial:

Metacaracter Descripción
\d Busca un dígito.
\s Busca un carácter de espacio en blanco.
\b Coincide con un límite de palabra.
\uxxxx Busca un carácter Unicode especificado por el número hexadecimal xxxx.

Cuantificadores:

Cuantificador Descripción
n+ Coincide con cualquier cadena que contenga al menos unnde la cadena.
n* Coincide con cualquier cadena que contenga cero o másnde la cadena.
n? Coincide con cualquier cadena que contenga cero o unnde la cadena.

Usar el objeto RegExp

En JavaScript, el objeto RegExp es un objeto de expresión regular con propiedades y métodos predefinidos.

Usar test()

El método test() es un método de expresión regular.

El método test() se utiliza para comprobar si una cadena coincide con un patrón. Si la cadena contiene texto que coincide, devuelve true; de lo contrario, devuelve false.

El siguiente ejemplo se utiliza para buscar el carácter "e" en una cadena:

Ejemplo

var patt = /e/;
patt.test("The best things in life are free!");

La cadena contiene "e", por lo que la salida de este ejemplo es:

true

Pruébalo »

No es necesario crear una variable para la expresión regular; las dos líneas de código anteriores se pueden combinar en una sola línea:

/e/.test("The best things in life are free!")

Usar exec()

El método exec() es un método de expresión regular.

El método exec() se utiliza para buscar una coincidencia de la expresión regular en una cadena.

Esta función devuelve un array que contiene los resultados de la coincidencia. Si no se encuentra ninguna coincidencia, el valor devuelto es null.

El siguiente ejemplo se utiliza para buscar la letra "e" en una cadena:

Ejemplo 1

/e/.exec("The best things in life are free!");

La cadena contiene "e", por lo que la salida de este ejemplo es:

e

    match()、replace()、search()、split()El parámetro de expresión regular en los métodos también se puede reemplazar con una cadena. En este caso, la cadena se convierte implícitamente en una expresión regular. Por ejemplo:

    var str = "abcdeabc";
console.log(str.match("abc")); // 输出["abc"]
console.log(str.replace("abc", "xyz")); // 输出"xyzdeabc"
console.log(str.search("abc")); // 输出0
console.log(str.split("abc")); // 输出["", "de", ""]

    Aquí, la cadena"abc"se trata como una expresión regular literal, y coincide con la parte de la cadena"abc"parte.

    Pero ten en cuenta que los diferentes métodos tienen reglas distintas al convertir el argumento de cadena en una expresión regular:

    split()Los métodos yreplace()Los métodos tratarán todos los metacaracteres del argumento de cadena (como *, +, ?, etc.) como caracteres comunes, y les añadirán una barra invertida delante para escaparlos, a fin de coincidir con los caracteres reales de la cadena.

    match()Los métodos ysearch()Los métodos, en cambio, tratarán todos los metacaracteres del argumento de cadena como los propios metacaracteres, manteniendo su significado original, para hacer coincidir patrones específicos en la cadena.

    Por ejemplo:

    var str = "a*b*c";
console.log(str.split("*")); // 相当于str.split(/\*/)，表示匹配一个星号字符。输出['a', 'b', 'c']
console.log(str.match("*")); // 相当于str.match(/*/)，/*/是一个无效的正则表达式。报错
console.log(str.search("*")); // 相当于str.search(/*/)。报错
console.log(str.replace("*", "+")); // 相当于str.replace(/\*/, "+")。输出a+b*c

    Por lo tanto, al llamarmatch()método ysearch()método, si deseas representar un carácter especial en el parámetro de la expresión regular, debes asegurarte de que, en la expresión regular convertida desde la cadena, el carácter correspondiente tenga una barra invertida delante para escapar. Esto significa que en la cadena pasada necesitas usar dos barras invertidas para escapar. Y al llamarsplit()método yreplace()método, debido a sus reglas de conversión especiales, la cadena no puede representar los metacaracteres de la expresión regular. Ya sea que se añada una barra invertida delante de un metacarácter en la cadena o no, en la expresión regular se considera un carácter de escape.

    Nota:split("\\")、replace("\\")、match("\\\\")、search("\\\\")representa hacer coincidir una barra invertida, equivalente a xxx(/\\/). Ysplit("\")、match("\")、match("\\")、match("\\\")etc. son inválidos. Por ejemplo:

    var str = "a\\b\\c";
console.log(str.split("\\")); // 输出["a", "b", "c"]
console.log(str.replace("\\","+")); // 输出a+b\c
console.log(str.match("\\\\")); // 输出['\\', index: 1, input: 'a\\b\\c', groups: undefined]
console.log(str.search("\\\\")); // 输出1

    Además, ten en cuenta que en una cadena no se pueden especificar los indicadores de la expresión regular, ni se pueden usar o referenciar grupos. Si necesitas esto, debes usar el objeto RegExp.
