JavaScript Alcance

El alcance es el conjunto de variables accesibles.

Alcance de JavaScript

En JavaScript, los objetos y las funciones también son variables.

En JavaScript, el alcance es el conjunto de variables, objetos y funciones accesibles.

Alcance de función en JavaScript: el alcance se modifica dentro de la función.

Alcance local de JavaScript

Las variables declaradas dentro de una función son variables locales y tienen alcance local.

Variables locales: solo pueden accederse dentro de la función.

Ejemplo

//Aquí no se puede invocar la variable carName function myFunction() { var carName = "Volvo"; //Dentro de la función se puede invocar la variable carName }

Pruébalo »

Debido a que las variables locales solo actúan dentro de la función, diferentes funciones pueden usar variables con el mismo nombre.

Las variables locales se crean cuando la función comienza a ejecutarse y se destruyen automáticamente cuando la función termina de ejecutarse.

Variables globales de JavaScript

Las variables definidas fuera de una función son variables globales.

Las variables globales tienenalcance global: pueden ser utilizadas por todos los scripts y funciones de la página web.

Ejemplo

var carName = " Volvo"; //Aquí se puede invocar la variable carName function myFunction() { //Dentro de la función se puede invocar la variable carName }

Pruébalo »

Si una variable no se declara dentro de una función (sin usar la palabra clave var), dicha variable es global.

En el siguiente ejemplo, carName está dentro de una función, pero es una variable global.

Ejemplo

//Aquí se puede invocar la variable carName function myFunction() { carName = "Volvo"; //Aquí se puede invocar la variable carName }

Pruébalo »

Ciclo de vida de las variables de JavaScript

El ciclo de vida de una variable de JavaScript se inicializa en el momento de su declaración.

Las variables locales se destruyen después de que la función termina de ejecutarse.

Las variables globales se destruyen después de cerrar la página.

Parámetros de función

Los parámetros de función solo tienen efecto dentro de la función; son variables locales.

Variables globales en HTML

En HTML, las variables globales son el objeto window, por lo que el objeto window puede acceder a variables locales no declaradas (sin var) dentro de una función.

Nota:Todas las variables globales pertenecen al objeto window.

Ejemplo

//Aquí se puede usar window.carName function myFunction() { carName = "Volvo"; }

¿Sabías?

Tus variables globales o funciones pueden sobrescribir las variables o funciones del objeto window.
Las variables locales, incluyendo el objeto window, pueden sobrescribir variables y funciones globales.

En JavaScript, las variables locales dentro de una función normalmente no pueden ser accedidas directamente por el alcance externo, pero hay varias formas de exponer las variables locales de la función al alcance externo, como se detalla a continuación:

  • Mediante el objeto global:Dentro de una función, se puede hacer que una variable local sea accesible globalmente asignándola a una propiedad del objeto window. Por ejemplo, usarwindow.a = a;declaración, se puede acceder desde fuera de la función mediantewindow.aal valor de esta variable local.
  • Definir variables globales:Dentro de una función, sin usarvar、letoconstpalabras clave como estas para declarar una variable, esa variable se considera global y se puede acceder a ella fuera de la función. Sin embargo, esta práctica generalmente no se recomienda, ya que puede provocar efectos secundarios inesperados y código difícil de mantener.
  • Valor de retorno:Se puede, usando dentro de la función,returnuna declaración para devolver el valor de la variable local, y luego recibir este valor de retorno fuera de la función. De esta manera, aunque la variable local en sí no queda expuesta, su valor puede transferirse al exterior mediante la llamada a la función.
  • Cierre:La característica de cierre en JavaScript permite que las funciones internas accedan a las variables locales de la función externa. Incluso después de que la función externa haya terminado de ejecutarse, sus variables locales aún pueden ser referenciadas por la función interna.
  • Propiedades y métodos:Las variables y funciones definidas en el alcance global se convierten en propiedades y métodos del objeto window, por lo que al llamarlos se puede omitir window y usar directamente el nombre de la variable o función.
