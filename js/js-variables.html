JavaScript Variables

Las variables son "contenedores" utilizados para almacenar información.

En JavaScript, las variables se utilizan para almacenar datos y pueden cambiarse dinámicamente durante la ejecución del programa.

En JavaScript, las variables pueden almacenar varios tipos de datos, como números, cadenas, objetos, funciones, etc.

Los nombres de variables son identificadores que se utilizan para hacer referencia a los datos almacenados en la variable.

En JavaScript, se pueden usarvar、let 和 constpalabras clave para declarar variables.

  • varvar: método de declaración de variables introducido en ES5, con ámbito de función.

  • letlet: método de declaración de variables introducido en ES6, con ámbito de bloque.

  • constconst: método de declaración de constantes introducido en ES6, con ámbito de bloque y valor inmutable.

Ejemplos

var x=5; var y=6; var z=x+y;

Como en álgebra

x=5
y=6
z=x+y

En álgebra, usamos letras (como x) para almacenar valores (como 5).

Mediante la expresión anterior z=x+y, podemos calcular que el valor de z es 11.

En JavaScript, estas letras se llaman variables.

Puedes considerar las variables como contenedores para almacenar datos.

Variables de JavaScript

Igual que en álgebra, las variables de JavaScript se pueden usar para almacenar valores (comox = 5) y expresiones (comoz = x + y）。

Las variables pueden usar nombres cortos (como x e y) o nombres más descriptivos (como age, sum, totalvolume).

  • Las variables deben comenzar con una letra
  • Las variables también pueden comenzar con los símbolos $ y _ (aunque no lo recomendamos)
  • Los nombres de variables distinguen entre mayúsculas y minúsculas (y e Y son variables diferentes)
Las declaraciones y las variables de JavaScript distinguen entre mayúsculas y minúsculas.

Tipos de datos de JavaScript

Las variables de JavaScript también pueden almacenar otros tipos de datos, como valores de texto (name="Bill Gates").

En JavaScript, un texto como "Bill Gates" se denomina cadena (string).

Las variables de JavaScript tienen muchos tipos, pero por ahora solo nos centraremos en números y cadenas.

Cuando asignes un valor de texto a una variable, debes encerrar el valor entre comillas dobles o simples.

Cuando el valor que asignas a una variable sea numérico, no uses comillas. Si encierras un valor numérico entre comillas, se tratará como texto.

Ejemplos

var pi=3.14; //Si estás familiarizado con ES6, pi puede usar la palabra clave const, lo que indica una constante // const pi = 3.14; var person="John Doe"; var answer='Yes I am!';

Declarar (crear) variables de JavaScript

En JavaScript, crear una variable generalmente se llama "declarar" la variable.

Usamos la palabra clave var para declarar variables:

var carname;

Después de declarar la variable, esta está vacía (no tiene valor).

Para asignar un valor a la variable, usa el signo igual:

carname="Volvo";

Sin embargo, también puedes asignarle un valor al declarar la variable:

var carname="Volvo";

En el siguiente ejemplo, creamos una variable llamada carname, le asignamos el valor "Volvo" y la colocamos en un párrafo HTML con id="demo":

Ejemplos

var carname="Volvo"; document.getElementById("demo").innerHTML=carname;

Pruébalo »

Características de la declaración con var:

  • La variable puede declararse varias veces (sobrescribiendo la variable original).
  • Cuando la variable no tiene valor asignado, su valor predeterminado es undefined.
  • Las variables declaradas con var se elevan (Hoisting), pero no se inicializan.

Una buena práctica de programación es declarar todas las variables necesarias al inicio del código.

Una declaración, varias variables

Puedes declarar muchas variables en una sola declaración. La declaración comienza con var y separa las variables con comas:

var lastname="Doe", age=30, job="carpenter";

La declaración también puede abarcar varias líneas:

var lastname="Doe",
age=30,
job="carpenter";

No se puede asignar el mismo valor a múltiples variables declaradas en una misma declaración:

var x, y, z = 1;

x, y son undefined, z es 1.


Value = undefined

En los programas de computadora, a menudo se declaran variables sin valor. Una variable declarada sin un valor tiene realmente el valorundefined。

Después de ejecutar la siguiente declaración, el valor de la variable carname será undefined:

var carname;

Volver a declarar variables de JavaScript

Si vuelves a declarar una variable de JavaScript, el valor de la variable no se pierde:

Después de ejecutar las dos declaraciones siguientes, el valor de la variable carname sigue siendo "Volvo":

var
carname="Volvo"; 
var carname;

Usando let y const (ES6)

Antes de 2015, usábamos la palabra clave var para declarar variables de JavaScript.

Las versiones de JavaScript posteriores a 2015 (ES6) nos permiten usar la palabra clave const para definir una constante, y la palabra clave let para definir variables con un ámbito limitado.

let

let es una nueva forma de declarar variables introducida en ES6, y se recomienda su uso.

Sintaxis de let:

let variableName = value;

Ejemplos

let city = "北京";
let age = 30;
console.log(city, age); // Salida: 北京 30

const

const se utiliza para definir constantes, es decir, una vez que se asigna un valor, el valor de la variable no se puede modificar.

Sintaxis de const:

const variableName = value;

Ejemplos

const z = 10;
// z = 20; // Error, una constante no se puede reasignar
if (true) {
    const z = 20; // Diferentes constantes
    console.log(z); // Salida 20
}
console.log(z); // Salida 10

Puedes consultar más contenido sobre const y let en:JavaScript let y const.

    JavaScript permite definir funciones repetidamente.

    JavaScript no tiene el concepto de sobrecarga; solo distingue funciones según el nombre de la función.

    Las funciones con el mismo nombre definidas después sobrescriben a las anteriores, independientemente de los parámetros.

    function test() {
    console.log("test");
}
test();     //输出 "test arg0 + undefined"

function test(arg1) {
    console.log("test arg" + arguments.length + " + " + arg1);
}
test(1,2);  //输出 "test arg2 + 1"

    Si el número de argumentos reales es menor que el de parámetros formales, a los restantes se les asigna por defecto el valorundefined, si se pasan más argumentos reales que parámetros formales, todos se pasan; simplemente no hay un parámetro formal correspondiente al que hacer referencia (pero se puede usar arguments para obtener los parámetros restantes).

    function test(arg1) {
    for(var i=0; i<arguments.length; i++) {
        console.log(arguments[i]);
    }

test(1,2); //输出 1 2

    • Las variables que ya han sido declaradas no se vuelven a declarar.

    El comentario anterior tiene una frase que considero inapropiada:«JavaScript permite declarar variables repetidamente; las declaradas después sobrescriben a las anteriores»。

    JavaScript permite que las variables se declaren repetidamente. Al declarar una variable, JavaScript determina automáticamente si la variable ya ha sido declarada. Si ya ha sido declarada (es decir, ya existe), la declaración repetida (es decir, cualquier declaración que no sea la primera) se omite y no se realiza la operación de declaración.

    El valor de una variable en JavaScript puede ser asignado repetidamente; la última asignación es el resultado final de la variable.

    var a=1;
var a=2;

//赋值覆盖相当于：
var a;
//a=1;
a=2;

//声明覆盖相当于：
//var a=1;
var a=2;

    La sobrescritura mencionada en esta nota es en realidad sobrescritura de asignación. Si se dijera que la declaración posterior sobrescribe la declaración anterior, entonces la declaración posterior debería ser undefined, no el valor de la primera declaración. Es decir, si fuera sobrescritura de declaración, sería como no tener var a=1; una variable que solo se declara sin asignarse tiene el valor undefined.

    ¿Cómo verificamos si esta sobrescritura es de declaración o de asignación? Observa el siguiente código:

    var a=1;
var a;

//赋值覆盖相当于：
var a;
//a=1;
a;

//声明覆盖相当于：
//var a=1;
var a;

    Luego mostramos el valor de a y comprobamos si es undefined o 1 para saberlo.

    console.log(a);

    Variables con el mismo nombre, declaradas y asignadas:Ejecutar una por una: la última sobrescribe a la primera. (Sobrescritura al mismo nivel.)

    var a = 1; 
var a = 2;
console.log(a); // 输出结果：2

    Funciones y variables con el mismo nombre, declaradas y asignadas:Ejecutar una por una: la última sobrescribe a la primera. (Sobrescritura al mismo nivel.)

    var a = 1; 
var a = function () {     
}
console.log(a); //输出结果： a 函数

    -----------------------------------------------------------------

    Nota:var f = function () {} 和 function f () {}La diferencia (con var hay memoria)

    var f = function () {console.log("有var")} // 声明函数
function f () {} // 未声明函数
console.log(f); // 输出结果： 有var的f函数
