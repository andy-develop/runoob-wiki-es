JSP 动作元素

A diferencia de los elementos de directiva de JSP, los elementos de acción de JSP actúan durante la fase de procesamiento de la solicitud. Los elementos de acción de JSP están escritos con sintaxis XML.

Utilizando las acciones de JSP se pueden insertar archivos dinámicamente, reutilizar componentes JavaBean, redirigir al usuario a otra página y generar código HTML para el complemento de Java.

Los elementos de acción tienen una única sintaxis que cumple con el estándar XML:

<jsp:action_name attribute="value" />

Los elementos de acción son básicamente funciones predefinidas. La especificación de JSP define una serie de acciones estándar que usan JSP como prefijo. Los elementos de acción estándar disponibles son los siguientes:

语法描述
jsp:includeInserta un archivo cuando se solicita la página.
jsp:useBeanEncontrar o instanciar un JavaBean.
jsp:setPropertyEstablecer las propiedades del JavaBean.
jsp:getPropertyMuestra el valor de una propiedad de un JavaBean.
jsp:forwardReenviar la solicitud a una nueva página.
jsp:pluginGenera la etiqueta OBJECT o EMBED para el complemento de Java según el tipo de navegador.
jsp:elementDefinir elementos XML dinámicos
jsp:attributeEstablece atributos de elementos XML definidos dinámicamente.
jsp:bodyEstablece el contenido de elementos XML definidos dinámicamente.
jsp:textUtilizar plantillas de texto en páginas y documentos de JSP.

常见的属性

Todos los elementos de acción tienen dos atributos: el atributo id y el atributo scope.

  • id属性：

    El atributo id es el identificador único del elemento de acción y se puede hacer referencia a él en la página JSP. El valor de id creado por el elemento de acción se puede invocar mediante PageContext.

  • scope属性：

    Este atributo se utiliza para identificar el ciclo de vida del elemento de acción. El atributo id y el atributo scope están directamente relacionados; el atributo scope define la vida útil del objeto id asociado. El atributo scope tiene cuatro valores posibles: (a) page, (b) request, (c) session y (d) application.

Elemento de acción <jsp:include>

El elemento de acción `<jsp:include>` se utiliza para incluir archivos estáticos y dinámicos. Esta acción inserta el archivo especificado en la página que se está generando. El formato de sintaxis es el siguiente:

<jsp:include page="相对 URL 地址" flush="true" />

Anteriormente se presentó la directiva include, que introduce el archivo cuando el archivo JSP se convierte en un Servlet. A diferencia de la acción `jsp:include` de aquí, el archivo se inserta cuando se solicita la página.

La siguiente es una lista de atributos relacionados con la acción include.

属性描述
pageLa dirección URL relativa que se incluye en la página.
flushAtributo booleano que define si se debe vaciar el búfer antes de incluir el recurso.

实例

A continuación definimos dos archivosdate.jsp 和 main.jsp, el código es el siguiente:

Código del archivo date.jsp:

<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<p>
   今天的日期是: <%= (new java.util.Date()).toLocaleString()%>
</p>

Código del archivo main.jsp:

<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>菜鸟教程(runoob.com)</title>
</head>
<body>

<h2>include 动作实例</h2>
<jsp:include page="date.jsp" flush="true" />

</body>
</html>

Ahora coloque los dos archivos anteriores en el directorio raíz del servidor y acceda al archivo main.jsp. El resultado mostrado es el siguiente:

Elemento de acción <jsp:useBean>

jsp:useBeanLa acción se utiliza para cargar un JavaBean que se utilizará en la página JSP.

Esta función es muy útil porque nos permite aprovechar las ventajas de la reutilización de componentes Java.

La sintaxis más simple de la acción `jsp:useBean` es:

<jsp:useBean id="name" class="package.class" />

Después de cargar la clase, podemos modificar y recuperar las propiedades del bean mediante las acciones `jsp:setProperty` y `jsp:getProperty`.

La siguiente es una lista de atributos relacionados con la acción useBean.

属性描述
classEspecificar el nombre completo del paquete del Bean.
typeEspecificar el tipo de la variable que hará referencia al objeto.
beanNameEspecifique el nombre del Bean mediante el método instantiate() de java.beans.Beans.

Antes de dar ejemplos concretos, veamos primero los elementos de acción jsp:setProperty y jsp:getProperty:

<jsp:setProperty>动作元素

jsp:setProperty se utiliza para establecer las propiedades de un objeto Bean ya instanciado. Hay dos usos. Primero, puede usar jsp:setProperty fuera (después) del elemento jsp:useBean, como se muestra a continuación:

<jsp:useBean id="myName" ... />
...
<jsp:setProperty name="myName" property="someProperty" .../>

En este caso, tanto si jsp:useBean encuentra un Bean existente como si crea una nueva instancia de Bean, jsp:setProperty se ejecutará. El segundo uso es poner jsp:setProperty dentro del elemento jsp:useBean, como se muestra a continuación:

<jsp:useBean id="myName" ... >
...
   <jsp:setProperty name="myName" property="someProperty" .../>
</jsp:useBean>

En este caso, jsp:setProperty solo se ejecutará cuando se cree una nueva instancia de Bean; si se utiliza una instancia existente, jsp:setProperty no se ejecutará.

La acción `jsp:setProperty` tiene los siguientes cuatro atributos, como se muestra en la tabla:

属性描述
nameEl atributo name es obligatorio. Indica a qué Bean se le van a establecer las propiedades.
propertyEl atributo property es obligatorio. Indica qué propiedad se va a establecer. Hay un uso especial: si el valor de property es "*", significa que todos los parámetros de solicitud cuyos nombres coincidan con los nombres de las propiedades del Bean se pasarán al método setter correspondiente.
valueEl atributo value es opcional. Este atributo se utiliza para especificar el valor de la propiedad del Bean. Los datos de cadena se convierten automáticamente en números, boolean, Boolean, byte, Byte, char, Character en la clase de destino mediante el método estándar valueOf. Por ejemplo, los valores de propiedad de tipo boolean y Boolean (como "true") se convierten mediante `Boolean.valueOf`, y los valores de propiedad de tipo int e Integer (como "42") se convierten mediante `Integer.valueOf`. 　　value y param no se pueden usar al mismo tiempo, pero se puede usar cualquiera de los dos.
paramparam es opcional. Especifica qué parámetro de solicitud se utilizará como valor de la propiedad del Bean. Si la solicitud actual no tiene parámetros, no se hace nada; el sistema no pasa null al método setter de la propiedad del Bean. Por lo tanto, puedes permitir que el Bean proporcione sus propios valores predeterminados y solo modificarlos cuando el parámetro de solicitud especifique explícitamente un nuevo valor.

<jsp:getProperty>动作元素

La acción `jsp:getProperty` extrae el valor de la propiedad especificada del Bean, lo convierte en una cadena y lo genera. El formato de sintaxis es el siguiente:

<jsp:useBean id="myName" ... />
...
<jsp:getProperty name="myName" property="someProperty" .../>

La siguiente tabla enumera los atributos asociados con getProperty:

属性描述
nameEl nombre de la propiedad del Bean que se va a recuperar. El Bean debe estar definido.
propertyIndica el valor de la propiedad del Bean que se va a extraer

实例

En el siguiente ejemplo utilizamos Bean:

package com.runoob.main;

public class TestBean {
   private String message = "菜鸟教程";
 
   public String getMessage() {
      return(message);
   }
   public void setMessage(String message) {
      this.message = message;
   }
}

Compile el archivo de ejemplo anterior TestBean.java:

$ javac TestBean.java

Después de la compilación, se generará un archivo en el directorio actualTestBean.classEl archivo, copie este archivo en el actual proyecto JSP en elWebContent/WEB-INF/classes/com/runoob/maindirectorio (ruta de paquete com/runoob/main, si no existe, debe crearlo manualmente).

Ahora vamos a invocar este Bean en el archivo main.jsp:

    pageEncoding="UTF-8"%>

Elemento de acción <jsp:forward>

La acción `jsp:forward` transfiere la solicitud a otra página. La etiqueta `jsp:forward` tiene un solo atributo: page. El formato de sintaxis es el siguiente:

<jsp:forward page="相对 URL 地址" />

Los siguientes son atributos asociados con forward:

属性描述
pageEl atributo page contiene una URL relativa. El valor de page se puede proporcionar directamente o calcularse dinámicamente en el momento de la solicitud. Puede ser una página JSP o un Servlet de Java.

实例

En el siguiente ejemplo, utilizamos dos archivos: date.jsp y main.jsp.

El código del archivo date.jsp es el siguiente:

<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<p>
   今天的日期是: <%= (new java.util.Date()).toLocaleString()%>
</p>

Código del archivo main.jsp:

<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>菜鸟教程(runoob.com)</title>
</head>
<body>

<h2>forward 动作实例</h2>
<jsp:forward page="date.jsp" />
</body>
</html>

Ahora coloque los dos archivos anteriores en el directorio raíz del servidor y acceda al archivo main.jsp. El resultado mostrado es el siguiente:

今天的日期是: 2016-6-25 14:37:25

Elemento de acción <jsp:plugin>

La acción jsp:plugin se utiliza para insertar, según el tipo de navegador, los elementos OBJECT o EMBED necesarios para ejecutar applets de Java mediante el complemento de Java.

Si el complemento necesario no existe, lo descarga y luego ejecuta el componente Java. El componente Java puede ser un applet o un JavaBean.

La acción plugin tiene varios atributos correspondientes a elementos HTML para formatear el componente Java. El elemento param se puede utilizar para pasar parámetros al Applet o al Bean.

A continuación se muestra un ejemplo típico del uso del elemento de acción plugin:

<jsp:plugin type="applet" codebase="dirname" code="MyApplet.class"
                           width="60" height="80">
   <jsp:param name="fontcolor" value="red" />
   <jsp:param name="background" value="black" />
 
   <jsp:fallback>
      Unable to initialize Java Plugin
   </jsp:fallback>
 
</jsp:plugin>

Si estás interesado, puedes intentar usar un applet para probar el elemento de acción jsp:plugin. El elemento <fallback> es un elemento nuevo que envía un mensaje de error al usuario cuando el componente falla.

<jsp:element> 、 <jsp:attribute>、 <jsp:body>动作元素

Los elementos de acción <jsp:element>, <jsp:attribute> y <jsp:body> definen dinámicamente elementos XML. Lo dinámico es muy importante, lo que significa que los elementos XML se generan dinámicamente en tiempo de compilación, no estáticamente.

El siguiente ejemplo define dinámicamente elementos XML:

<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>菜鸟教程(runoob.com)</title>
</head>
<body>
<jsp:element name="xmlElement">
<jsp:attribute name="xmlElementAttr">
   属性值
</jsp:attribute>
<jsp:body>
   XML 元素的主体
</jsp:body>
</jsp:element>
</body>
</html>

Elemento de acción <jsp:text>

El elemento de acción <jsp:text> permite utilizar plantillas de texto en páginas y documentos JSP. La sintaxis es la siguiente:

<jsp:text>模板数据</jsp:text>

La plantilla de texto anterior no puede contener elementos repetidos, solo texto y expresiones EL (nota: las expresiones EL se presentarán en capítulos posteriores). Ten en cuenta que en archivos XML no se pueden usar expresiones como ${whatever > 0}, porque el símbolo > es ilegal. Puedes usar la expresión ${whatever gt 0} o un valor incrustado en una sección CDATA.

<jsp:text><![CDATA[<br>]]></jsp:text>

Si necesitas declarar el DOCTYPE en XHTML, debes usar el elemento de acción <jsp:text>. Ejemplo:

<jsp:text><![CDATA[<!DOCTYPE html
PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN"
"DTD/xhtml1-strict.dtd">]]>
</jsp:text>
<head><title>jsp:text action</title></head>
<body>

<books><book><jsp:text>  
    Welcome to JSP Programming
</jsp:text></book></books>

</body>
</html>

Puedes probar la diferencia entre usar <jsp:text> y no usar este elemento de acción en el ejemplo anterior.
