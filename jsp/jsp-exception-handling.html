JSP Manejo de excepciones

Al escribir programas JSP, los programadores pueden pasar por alto algunos BUGs, que pueden aparecer en cualquier parte del programa. El código JSP normalmente contiene los siguientes tipos de excepciones:

  • Excepción comprobada: una excepción comprobada es típicamente un error de usuario o un error que el programador no puede prever. Por ejemplo, si se va a abrir un archivo pero no se puede encontrar, se lanza una excepción. Estas excepciones no pueden simplemente ignorarse en tiempo de compilación.
  • Excepción en tiempo de ejecución: una excepción en tiempo de ejecución podría haber sido evitada por el programador, y este tipo de excepción se ignora en tiempo de compilación.
  • Error: un error no es una excepción, pero el problema es que está fuera del control del usuario o del programador. Los errores suelen ignorarse en el código, y casi no se puede hacer nada al respecto. Por ejemplo, el error de desbordamiento de pila. Estos errores se ignoran en tiempo de compilación.

Esta sección presentará algunas formas sencillas y elegantes de manejar excepciones y errores en tiempo de ejecución.

Usar el objeto Exception

El objeto exception es una instancia de una subclase de Throwable y solo está disponible en las páginas de error. La siguiente tabla enumera algunos métodos importantes de la clase Throwable:

N.º Método&Descripción
1 public String getMessage()Devuelve la información de la excepción. Esta información se inicializa en el constructor de Throwable.
2 public ThrowablegetCause()Devuelve la causa que provocó la excepción, de tipo objeto Throwable.
3 public String toString()Devuelve el nombre de la clase.
4 public void printStackTrace()Imprime el rastro de la pila de la excepción en System.err.
5 public StackTraceElement [] getStackTrace()Devuelve el rastro de la pila de la excepción como un array de elementos de rastro de pila.
6 public ThrowablefillInStackTrace()Rellena el objeto Throwable con el rastro de pila actual.

JSP ofrece la opción de especificar una página de error para cada página JSP. Cuando una página lanza una excepción, el contenedor JSP invoca automáticamente la página de error.

El siguiente ejemplo especifica una página de error para main.jsp. Se utiliza la directiva <%@page errorPage="XXXXX"%> para especificar una página de error.

<%@ page errorPage="ShowError.jsp" %>

<html>
<head>
   <title>Error Handling Example</title>
</head>
<body>
<%
   // Throw an exception to invoke the error page
   int x = 1;
   if (x == 1)
   {
      throw new RuntimeException("Error condition!!!");
   }
%>
</body>
</html>

Ahora, escriba el archivo ShowError.jsp de la siguiente manera:

<%@ page isErrorPage="true" %>
<html>
<head>
<title>Show Error Page</title>
</head>
<body>
<h1>Opps...</h1>
<p>Sorry, an error occurred.</p>
<p>Here is the exception stack trace: </p>
<pre>
<% exception.printStackTrace(response.getWriter()); %>

Tenga en cuenta que el archivo ShowError.jsp utiliza la directiva <%@page isErrorPage="true"%>, que le indica al compilador JSP que necesita generar una variable de instancia de excepción.

Ahora intente acceder a la página main.jsp, que producirá el siguiente resultado:

java.lang.RuntimeException: Error condition!!!
......

Opps...
Sorry, an error occurred.

Usar etiquetas JSTL en la página de error

Se puede utilizar la etiqueta JSTL para escribir la página de error ShowError.jsp. La lógica del código en este ejemplo es casi la misma que la del ejemplo anterior, pero el código de este ejemplo tiene una mejor estructura y puede proporcionar más información:

<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>
<%@page isErrorPage="true" %>
<html>
<head>
<title>Show Error Page</title>
</head>
<body>
<h1>Opps...</h1>
<table width="100%" border="1">
<tr valign="top">
<td width="40%"><b>Error:</b></td>
<td>${pageContext.exception}</td>
</tr>
<tr valign="top">
<td><b>URI:</b></td>
<td>${pageContext.errorData.requestURI}</td>
</tr>
<tr valign="top">
<td><b>Status code:</b></td>
<td>${pageContext.errorData.statusCode}</td>
</tr>
<tr valign="top">
<td><b>Stack trace:</b></td>
<td>
<c:forEach var="trace" 
         items="${pageContext.exception.stackTrace}">
<p>${trace}</p>
</c:forEach>
</td>
</tr>
</table>
</body>
</html>

Usar el bloque try…catch

Si desea poner el manejo de excepciones en una sola página y realizar un tratamiento diferente para diferentes excepciones, entonces necesitará utilizar el bloque try…catch.

El siguiente ejemplo muestra cómo utilizar el bloque try…catch, colocando este código en main.jsp:

<html>
<head>
   <title>Try...Catch Example</title>
</head>
<body>
<%
   try{
      int i = 1;
      i = i / 0;
      out.println("The answer is " + i);
   }
   catch (Exception e){
      out.println("An exception occurred: " + e.getMessage());
   }
%>
</body>
</html>

Intente acceder a main.jsp, que producirá el siguiente resultado:

An exception occurred: / by zero
