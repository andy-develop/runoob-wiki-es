JSP Lenguaje de expresiones

El lenguaje de expresiones JSP (EL) hace que acceder a los datos almacenados en JavaBeans sea muy simple. JSP EL se puede usar tanto para crear expresiones aritméticas como lógicas. Dentro de las expresiones JSP EL se pueden usar números enteros, números de coma flotante, cadenas, las constantes true, false y null.

Una sintaxis simple

Típicamente, cuando necesita especificar un valor de atributo en una etiqueta JSP, simplemente usa una cadena:

<jsp:setProperty name="box" property="perimeter" value="100"/>

JSP EL le permite especificar una expresión para representar el valor de un atributo. Una sintaxis simple de expresión es la siguiente:

${expr}

Donde expr se refiere a la expresión. Los operadores comunes en JSP EL son. 和 {}Estos dos operadores le permiten acceder a varias propiedades de JavaBeans a través de objetos JSP integrados.

Por ejemplo, la etiqueta <jsp:setProperty> anterior se puede reescribir con el lenguaje de expresiones de la siguiente manera:

<jsp:setProperty name="box" property="perimeter" 
                 value="${2*box.width+2*box.height}"/>

Cuando el compilador JSP ve el formato "${}" en un atributo, genera código para evaluar esta expresión y produce un sustituto para reemplazar el valor de la expresión.

También puede usar el lenguaje de expresiones en el texto de plantilla de una etiqueta. Por ejemplo, la etiqueta <jsp:text> simplemente inserta el texto de su cuerpo en la salida JSP:

<jsp:text>
<h1>Hello JSP!</h1>
</jsp:text>

Ahora, use una expresión en el cuerpo de la etiqueta <jsp:text>, de esta manera:

<jsp:text>
Box Perimeter is: ${2*box.width + 2*box.height}
</jsp:text>

En las expresiones EL se pueden usar paréntesis para organizar subexpresiones. Por ejemplo, ${(1 + 2) * 3} es igual a 9, pero ${1 + (2 * 3)} es igual a 7.

Para desactivar la evaluación de expresiones EL, debe usar la directiva page para establecer el valor del atributo isELIgnored a true:

<%@ page isELIgnored ="true|false" %>

De esta manera, las expresiones EL se ignorarán. Si se establece en false, el contenedor evaluará la expresión EL.

Funciones en JSP EL

JSP EL le permite usar funciones en expresiones. Estas funciones deben definirse en la biblioteca de etiquetas personalizadas. La sintaxis para usar funciones es la siguiente:

${ns:func(param1, param2, ...)}

ns se refiere al espacio de nombres (namespace), func se refiere al nombre de la función, param1 se refiere al primer parámetro, param2 al segundo parámetro, y así sucesivamente. Por ejemplo, la función fn:length, definida en la biblioteca JSTL, se puede usar de la siguiente manera para obtener la longitud de una cadena:

${fn:length("Get my length")}

Para usar funciones de cualquier biblioteca de etiquetas, debe instalar esas bibliotecas en el servidor y luego incluir las bibliotecas en el archivo JSP usando la etiqueta <taglib>.

Objetos implícitos de JSP EL

JSP EL admite los objetos implícitos enumerados en la siguiente tabla:

Objeto implícito Descripción
pageScope Ámbito page
requestScope Ámbito request
sessionScope Ámbito session
applicationScope Ámbito application
param Parámetro del objeto Request, cadena
paramValues Parámetros del objeto Request, colección de cadenas
header Cabecera HTTP, cadena
headerValues Cabeceras HTTP, colección de cadenas
initParam Parámetro de inicialización de contexto
cookie Valores de Cookie
pageContext El pageContext de la página actual

Puede usar estos objetos en expresiones como si fueran variables. A continuación se darán algunos ejemplos para comprender mejor este concepto.

El objeto pageContext

El objeto pageContext es una referencia al objeto pageContext en JSP. A través del objeto pageContext, puede acceder al objeto request. Por ejemplo, para acceder a la cadena de consulta pasada por el objeto request, se hace así:

${pageContext.request.queryString}

Objetos de ámbito

Las variables pageScope, requestScope, sessionScope, applicationScope se usan para acceder a las variables almacenadas en los diferentes niveles de ámbito.

Por ejemplo, si necesita acceder explícitamente a la variable box en el nivel applicationScope, puede acceder así: applicationScope.box.

Objetos param y paramValues

Los objetos param y paramValues se usan para acceder a los valores de los parámetros, mediante los métodos request.getParameter y request.getParameterValues.

Por ejemplo, para acceder a un parámetro llamado order, puede usar la expresión: ${param.order}, o ${param["order"]}.

El siguiente ejemplo muestra cómo acceder al parámetro username en request:

<%@ page import="java.io.*,java.util.*" %>
<%
    String title = "Accessing Request Param";
%>
<html>
<head>
<title><% out.print(title); %></title>
</head>
<body>
<center>
<h1><% out.print(title); %></h1>
</center>
<div align="center">
<p>${param["username"]}</p>
</div>
</body>
</html>

El objeto param devuelve una única cadena, mientras que el objeto paramValues devuelve un array de cadenas.

Objetos header y headerValues

Los objetos header y headerValues se usan para acceder a las cabeceras, mediante los métodos request.getHeader y request.getHeaders.

Por ejemplo, para acceder a una cabecera llamada user-agent, puede usar la expresión: ${header.user-agent}, o ${header["user-agent"]}.

El siguiente ejemplo muestra cómo acceder a la cabecera user-agent:

<%@ page import="java.io.*,java.util.*" %>
<%
    String title = "User Agent Example";
%>
<html>
<head>
<title><% out.print(title); %></title>
</head>
<body>
<center>
<h1><% out.print(title); %></h1>
</center>
<div align="center">
<p>${header["user-agent"]}</p>
</div>
</body>
</html>

El resultado de la ejecución es el siguiente:

El objeto header devuelve un único valor, mientras que headerValues devuelve un array de cadenas.
