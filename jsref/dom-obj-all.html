HTML DOM ElementoObjeto

Nodo HTML DOM

En HTML DOM (Document Object Model), todo esnodo:

  • El documento en sí mismo es un objeto de documento
  • Todos los elementos HTML son nodos de elemento
  • Todos los atributos HTML son nodos de atributo
  • El texto insertado en un elemento HTML es un nodo de texto
  • Los comentarios son nodos de comentario

Objeto de elemento

En HTML DOM,el objeto de elementorepresenta un elemento HTML.

Del objeto de elementonodos hijospueden ser: nodos de elemento, nodos de texto, nodos de comentario.

Objeto NodeListRepresenta una lista de nodos, similar a una colección de nodos hijos de un elemento HTML.

Los elementos pueden tener atributos. Los atributos pertenecen a los nodos de atributo (ver la siguiente sección).

Soporte del navegador

Todos los navegadores principales admiten el objeto de elemento y el objeto NodeList.
