Objeto Embed

El objeto Embed es nuevo en HTML5.

El objeto Embed representa un elemento HTML <embed>.

Acceder al objeto Embed

Puedes usar getElementById() para acceder al elemento <embed>:

var x = document.getElementById("myEmbed"); Pruébalo

Crear un objeto Embed

Puedes usar document.createElement() para crear un elemento <embed>:

var x = document.createElement("myEmbed"); Pruébalo

Propiedades del objeto Embed

Property Descripción
height Establece o devuelve la altura del archivo incrustado (valor del atributo height)
src Establece o devuelve el valor del atributo src del elemento embed (dirección del archivo incrustado)
type Establece o devuelve el valor del atributo type del elemento embed (tipo de archivo incrustado)
width Establece o devuelve el ancho del archivo incrustado (valor del atributo width)

Atributos y eventos estándar

El objeto Embed también admite estándaresAtributoyEvento。
