Julia Funciones matemáticas

Julia ofrece un conjunto de funciones matemáticas estándar eficientes y portátiles.

Comparación numérica

La siguiente tabla enumera las funciones utilizadas para la comparación numérica:

Función Prueba si se cumple la siguiente propiedad
isequal(x, y) xyySi el valor y el tipo son exactamente iguales
isfinite(x) xSi es un número finito
isinf(x) xSi es infinito (positivo/negativo)
isnan(x) xSi esNaN

isequal considera que los NaN son iguales entre sí:

Ejemplo

julia> isequal(NaN, NaN)
true

julia> isequal([1 NaN], [1 NaN])
true

julia> isequal(NaN, NaN32)
true

isequal también se puede utilizar para distinguir ceros con signo:

Ejemplo

julia> -0.0 == 0.0
true

julia> isequal(-0.0, 0.0)
false

Ejemplos de otras funciones:

Ejemplo

julia> isfinite(5)
true

julia> isfinite(NaN32)
false

Funciones trigonométricas e hiperbólicas

Julia también proporciona todas las funciones trigonométricas e hiperbólicas estándar:

sin    cos    tan    cot    sec    csc
sinh   cosh   tanh   coth   sech   csch
asin   acos   atan   acot   asec   acsc
asinh  acosh  atanh  acoth  asech  acsch
sinc   cosc

En la siguiente figura, un ángulo en radianes corresponde a un punto en el círculo unitario, cuyas coordenadas definen el seno y el coseno del ángulo.

Ejemplo

julia> pi
π = 3.1415926535897...

julia> sin(0)
0.0

julia> sin(pi/6)
0.49999999999999994

julia> sin(pi/4)
0.7071067811865475

julia> cos(0)
1.0

julia> cos(pi/6)
0.8660254037844387

julia> cos(pi/3)
0.5000000000000001

Las funciones proporcionadas anteriormente son todas de un solo parámetro, aunque atan también puede aceptar dos parámetros para representar la función tradicional atan2.

atan(y)
atan(y, x)

Calcula la arcotangente de y o de y/x, respectivamente.

Ejemplo

julia> theta = 3pi/4
2.356194490192345

julia> x,y = (cos(theta), sin(theta))
(-0.7071067811865475, 0.7071067811865476)

julia> atan(y/x)
-0.7853981633974484

julia> atan(y, x)
2.356194490192345

Además, sinpi(x) y cospi(x) se utilizan para calcular con mayor precisión sin(pi*x) y cos(pi*x), respectivamente.

Para calcular funciones trigonométricas con ángulos en grados en lugar de radianes, se utiliza el sufijo d. Por ejemplo, sind(x) calcula el seno de x, donde x es un valor en grados. A continuación se muestra la lista completa de funciones trigonométricas para ángulos:

sind   cosd   tand   cotd   secd   cscd
asind  acosd  atand  acotd  asecd  acscd

Ejemplo

julia> cos(56)
0.853220107722584

julia> cosd(56)
0.5591929034707468
