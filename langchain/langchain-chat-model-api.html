LangChain Chat Model API

Este documento enumera la referencia completa de la API de init_chat_model() y BaseChatModel.

Parámetros completos de init_chat_model()

ParámetroTipoValor predeterminadoDescripción
modelstr o None无Nombre del modelo, con formato provider:model_name. Pase None para crear un modelo configurable.
model_providerstr o NoneNoneEspecifica el proveedor por separado. Se usa cuando model no puede inferirse automáticamente.
configurable_fields"any", list o NoneNoneCampos modificables en tiempo de ejecución. None=modelo fijo, "any"=todo configurable.
config_prefixstr o NoneNonePrefijo de clave de configuración en escenarios de múltiples modelos.
temperaturefloatDepende del modeloControla la aleatoriedad, 0~2. 0=determinista, 2=máxima creatividad.
max_tokensintLímite del modeloNúmero máximo de tokens de salida
timeoutint/float o NoneNoneSegundos de tiempo de espera de la solicitud
max_retriesintDepende del modeloNúmero de reintentos en caso de fallo
base_urlstr o NoneDirección oficialPunto de conexión (endpoint) de API personalizado
rate_limiterBaseRateLimiter无Limitador de velocidad
top_pfloat o NoneDepende del modeloParámetro de muestreo nuclear, 0~1
stoplist[str]无Secuencia de parada

Ejemplos de uso comunes

Ejemplo

from langchain.chat_models import init_chat_model

# Modelo fijo
model = init_chat_model("deepseek:deepseek-v4-flash", temperature=0)
response = model.invoke("Hola")

# Modelo configurable
model = init_chat_model(configurable_fields=("model", "temperature"))
response = model.invoke("Hola", config={
    "configurable": {"model": "deepseek:deepseek-v4-flash", "temperature": 0.3}
})

# Vincular herramienta
model_with_tools = model.bind_tools([my_tool])
response = model_with_tools.invoke("Consultar el clima")

# Salida estructurada
model_structured = model.with_structured_output(MySchema)
result = model_structured.invoke("Extraer información")
