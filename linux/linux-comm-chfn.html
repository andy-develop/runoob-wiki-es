Comando chfn de Linux

Manual completo de comandos Linux

chfn(Change Finger Information) es una herramienta de línea de comandos en Linux que se utiliza para modificar la información descriptiva personal del usuario.

chfnEl comando se utiliza para modificar la información finger del usuario en el sistema, incluyendo el nombre completo, la dirección de la oficina, el teléfono de la oficina y el teléfono particular, entre otros.

Esta información puede serfingerconsultada por otros usuarios mediante el comando, lo que facilita conocer la información de contacto de los demás en entornos de servidor con colaboración multiusuario.

En los primeros sistemas Unix,fingerel comando finger permitía ver la información detallada de los usuarios,chfnmientras que chfn proporciona el acceso para modificar dicha información.

Aunquefingeren los sistemas modernos su uso ha disminuido,chfnel campo GECOS que gestiona sigue siendo utilizado por muchos programas como fuente del nombre visible del usuario.

El campo GECOS es/etc/passwdel quinto campo separado por dos puntos en /etc/passwd, que almacena la información descriptiva del usuario.chfnEn esencia, se trata de modificar este campo.

Sintaxis del comando

chfnLa sintaxis básica del comando es la siguiente:

chfn [选项] [用户名]

Si no se especifica un nombre de usuario, por defecto se modifica la información del usuario actualmente conectado.

Los usuarios normales solo pueden modificar su propia información, mientras que el usuario root puede modificar la información de cualquier usuario.

Descripción de opciones

chfnLas opciones de uso común se resumen a continuación:

OpciónFunciónEjemplo
-f, --full-nameEstablece el nombre completo del usuario (Full Name)chfn -f "Zhang San"
-r, --roomEstablece el número de oficina (Room Number)chfn -r "A-301"
-w, --work-phoneEstablece el número de teléfono del trabajo (Work Phone)chfn -w "010-12345678"
-h, --home-phoneEstablece el número de teléfono particular (Home Phone)chfn -h "010-87654321"
-o, --otherEstablece otra información (Other, el resto del campo GECOS)chfn -o "Developer"
-u, --helpMuestra la información de ayudachfn -u

Uso detallado

Modificación interactiva de la información personal

Si se ejecuta sin ninguna opciónchfn, se mostrarán indicaciones interactivas al usuario para que introduzca los datos campo por campo:

# 交互式修改当前用户信息
$ chfn
Password:
Changing the user information for runoob
Enter the new value, or press ENTER for the default
        Full Name: runoob
        Room Number []: A-301
        Work Phone []: 010-12345678
        Home Phone []: 010-87654321

Cada línea de aviso mostrará el valor actual; si no se desea modificar algún campo, basta con pulsar Enter para omitirlo.

El sistema solicitará primero la verificación de la contraseña para garantizar que solo el propio usuario o root puedan realizar la modificación.

Modificación directa mediante opciones

En scripts u operaciones por lotes, se pueden utilizar opciones para omitir los avisos interactivos y especificar directamente los nuevos valores:

# 一次性设置用户全名和办公室号码
$ chfn -f "Li Si" -r "B-202" runoob

Tras la ejecución, el usuariorunoobtendrá el nombre completo establecido como "Li Si" y el número de oficina como "B-202".

Ver la información modificada

Una vez completada la modificación, se puedefingerver la información actualizada mediante el comando finger:

# 使用 finger 查看用户信息
$ finger runoob
Login: runoob                    Name: Li Si
Directory: /home/runoob          Shell: /bin/bash
Office: B-202, 010-12345678      Home Phone: 010-87654321
Last login Tue May 19 10:30 (CST) on pts/0
No mail.
No Plan.

Si el sistema no tiene instalado fingerfinger, se puede usar catgetent passwd runoobpara ver directamente/etc/passwdel campo GECOS en /etc/passwd.

Verificación leyendo directamente /etc/passwd

Las distintas partes del campo GECOS están separadas por comas, con el siguiente formato:Nombre completo, Oficina, Teléfono del trabajo, Teléfono de casa, Otro。

# 查看 /etc/passwd 中 runoob 用户的 GECOS 字段
$ grep runoob /etc/passwd
runoob:x:1001:1001:Li Si,B-202,010-12345678,010-87654321:/home/runoob:/bin/bash

Se puede observar que el campo GECOS (el quinto elemento separado por dos puntos) registra por completo toda la información que se acaba de establecer.

Modificar un solo campo

Se puede modificar solo un campo manteniendo el resto de la información sin cambios:

# 只修改全名，其他信息保持不变
$ chfn -f "Wang Wu" runoob

# 验证修改结果
$ finger runoob | grep Name
Login: runoob                    Name: Wang Wu

Archivo de configuración de chfn

chfnEl comportamiento de chfn está controlado por/etc/login.defsla configuración en /etc/login.defs:

Opción de configuraciónDescripciónValor por defecto
CHFN_RESTRICTRestringe los campos que se pueden modificar, mediante combinaciones de letras:f(nombre completo),r(habitación),w(teléfono del trabajo),h(teléfono particular)frwh

Si se establece como una cadena vacía, no se permitirá a ningún usuario modificar la información finger.

Los administradores del sistema pueden controlar qué campos pueden modificar los usuarios ajustando esta configuración.

Notas importantes

Los usuarios normales solo pueden modificar su propia información finger y deben proporcionar la contraseña actual para la verificación. El usuario root puede modificar la información de cualquier usuario sin necesidad de verificación de contraseña.

chfnLa información modificada se escribirá en /etc/passwd/etc/passwd; una modificación incorrecta puede provocar que algunos programas que dependen del campo GECOS presenten comportamientos anómalos. Antes de modificar, se recomienda hacer una copia de seguridad de las líneas correspondientes.

Si el sistema tiene deshabilitadachfnla función CHFN (CHFN_RESTRICTCHFN_RESTRICTestá vacío), al ejecutar este comando se mostrará un aviso de permisos insuficientes.

Algunas distribuciones modernas de Linux (como Ubuntu) no instalan por defectofingerel paquete finger; es necesario ejecutar manualmenteapt install fingerla instalación.

En entornos de autenticación centralizada como LDAP o NIS,chfnes posible que chfn no funcione correctamente; en este tipo de entornos se deben utilizar las herramientas de administración correspondientes.
