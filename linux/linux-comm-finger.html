Comando Linux finger

Manual completo de comandos Linux

fingerEl comando se utiliza para ver información detallada de los usuarios en sistemas locales o remotos, incluyendo nombre de inicio de sesión, nombre completo, hora de inicio de sesión, tiempo de inactividad, etc.

Es máswhoyidEl comando proporciona una visualización más rica de la información del usuario, adecuada para conocer el estado de otros usuarios en servidores compartidos por múltiples personas.

fingerEs una herramienta de consulta de información de usuarios comúnmente utilizada en los primeros sistemas Unix; su nombre proviene de la idea de «señalar» a alguien.

Puede, desde/etc/passwdel campo GECOS, leer la información de descripción personal del usuario y mostrar su estado de inicio de sesión.

Aunque por razones de seguridad, las distribuciones modernas de Linux ya no lo instalan por defectofinger, sigue siendo útil en entornos de red interna y escenarios educativos.

fingerRequiere que el sistema ejecutefingerdel servicio para poder consultar información de usuarios remotos. Por razones de seguridad, la mayoría de los servidores públicos han deshabilitado este servicio.

Sintaxis del comando

fingerLa sintaxis básica es la siguiente:

finger [选项] [用户@主机]

Si no se especifica ningún parámetro, se muestra un resumen de todos los usuarios actualmente conectados.

Si se especifica un nombre de usuario, se muestra información detallada de ese usuario.

Al especificarusuario@hostel formato, se puede consultar la información de usuarios en un host remoto.

fingerLas opciones comunes se enumeran a continuación:

OpciónFunciónEjemplo
-sMuestra la información del usuario en formato brevefinger -s
-lMuestra la información del usuario en formato largo detalladofinger -l runoob
-pNo muestra el contenido de los archivos .plan y .projectfinger -p runoob
-mDesactiva la búsqueda de coincidencias para el nombre de usuariofinger -m runoob

Uso detallado

Ver usuarios conectados actualmente

Ejecutando sin parámetrosfinger, se listará un resumen de todos los usuarios conectados en el sistema.

# 查看所有当前登录的用户
$ finger
Login     Name           Tty      Idle  Login Time   Office     Office Phone
root      root           tty1           May 19 09:00
runoob    Zhang San      pts/0      3  May 19 10:30  A-301      010-12345678

La salida incluye información como nombre de inicio de sesión, nombre completo, terminal, tiempo de inactividad, hora de inicio de sesión, oficina y teléfono.

Ver información detallada de un usuario específico

Especificar un nombre de usuario permite ver la información completa de ese usuario.

# 查看 runoob 用户的详细信息
$ finger runoob
Login: runoob                    Name: Zhang San
Directory: /home/runoob          Shell: /bin/bash
Office: A-301, 010-12345678      Home Phone: 010-87654321
Last login Tue May 19 10:30 (CST) on pts/0
Mail last read Tue May 19 09:00 2026 (CST)
No Plan.

La información detallada incluye el directorio principal del usuario, el shell predeterminado, la última hora de inicio de sesión, la hora de lectura de correo, etc.

«No Plan.» indica que en el directorio principal del usuario no hay.planarchivo. Después de crear el archivo, su contenido se mostrará aquí; puede utilizarse para mostrar una breve presentación personal o el estado actual.

Salida en formato breve

Usando la-sopción, se pueden mostrar solo los campos clave, ideal para una consulta rápida.

# 以简短格式查看用户信息
$ finger -s runoob
Login     Name           Tty      Idle  Login Time   Office     Office Phone
runoob    Zhang San      pts/0      3  May 19 10:30  A-301      010-12345678

El formato breve omite detalles como el directorio principal, el shell y la última hora de inicio de sesión, y la salida es una tabla de una sola línea.

Prohibir coincidencia difusa

De forma predeterminada,fingerse intenta hacer coincidir todos los nombres de usuario, nombres completos y otra información que contengan la cadena especificada.-mSe puede desactivar este comportamiento para que solo se corresponda exactamente con el nombre de usuario.

# 精确匹配用户名，不搜索全名和其他字段
$ finger -m runoob

Cuando en el sistema existen nombres completos o alias similares al nombre de usuario objetivo,-mse pueden evitar resultados inesperados.

Ver múltiples usuarios

Se pueden especificar varios nombres de usuario a la vez para ver la información de múltiples usuarios de una sola vez.

# 同时查看多个用户
$ finger runoob root
Login: runoob                    Name: Zhang San
Directory: /home/runoob          Shell: /bin/bash
Office: A-301, 010-12345678      Home Phone: 010-87654321
Last login Tue May 19 10:30 (CST) on pts/0
No Plan.

Login: root                      Name: root
Directory: /root                 Shell: /bin/bash
Last login Tue May 19 09:00 (CST) on tty1
No Plan.

Ver información de usuarios remotos

fingerPermite consultar usuarios en un host remoto, con el formatonombre de usuario@dirección de host。

# 查看远程主机上的用户信息（需要远程主机开启 fingerd 服务）
$ finger runoob@192.168.1.100
Login: runoob                    Name: Zhang San
Directory: /home/runoob          Shell: /bin/bash
Last login Tue May 19 08:00 (CST) on pts/1
No Plan.

La consulta remota requiere que el host de destino ejecutefingerd(el daemon de finger) y abra el puerto 79 al exterior. La mayoría de los servidores en la nube han deshabilitado esta función por razones de seguridad.

Configurar los archivos .plan y .project

El usuario puede crear en su directorio principal.plany.projectarchivos para mostrar información personalizada.

# 创建 .project 文件（单行项目说明）
$ echo "RUNOOB Platform Development" > ~/.project

# 创建 .plan 文件（多行计划或简介）
$ cat > ~/.plan &lt;&lt; 'EOF'
当前任务：
1. 负责 RUNOOB 后端 API 开发
2. 维护数据库迁移脚本
3. Code Review 本周三之前完成
EOF

# 再次查看用户信息
$ finger runoob
Login: runoob                    Name: Zhang San
Directory: /home/runoob          Shell: /bin/bash
Office: A-301, 010-12345678      Home Phone: 010-87654321
Last login Tue May 19 10:30 (CST) on pts/0
Project: RUNOOB Platform Development
Plan:
当前任务：
1. 负责 RUNOOB 后端 API 开发
2. 维护数据库迁移脚本
3. Code Review 本周三之前完成

.projectEl contenido del archivo se muestra en una sola línea,.planel contenido del archivo puede tener varias líneas, adecuado para escribir una breve presentación personal o las tareas de trabajo actuales.

.planLa sangría adicional que aparece por defecto en los archivos es para alinear el formato. Si se desea eliminar la sangría, se puede añadir una línea en blanco antes del contenido.

Preguntas frecuentes

Las distribuciones modernas de Linux (como Ubuntu, Debian, CentOS) no lo instalan por defectofinger. Es necesario ejecutar manualmenteapt install fingeroyum install fingerpara instalarlo.

fingerLa instalación y el uso de este comando pueden conllevar riesgos de seguridad: expone la información personal de los usuarios y su estado de inicio de sesión. Antes de usarlo en servidores de empresa, asegúrese de que la política de seguridad lo permita.

fingerLa información mostrada como oficina, teléfono, etc., proviene del campo GECOS; se puede usarchfnel comando para modificarla.

Sifingerno muestra ninguna información de usuario, compruebe/etc/passwdsi la entrada del usuario en el archivo existe y si los permisos de operación son suficientes.
