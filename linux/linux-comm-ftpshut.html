Comando Linux ftpshut

Manual completo de comandos Linux

El comando Linux ftpshut apaga el servidor FTP en un momento especificado.

ftpshutPermite al administrador del sistema apagar el servicio FTP en un momento especificado y enviar mensajes de advertencia a los usuarios FTP conectados antes del apagado.

Este comando se usa normalmente para mantenimiento del sistema, actualizaciones u otras situaciones que requieren detener temporalmente el servicio FTP.

code>ftpshutSi el tiempo de apagado se establece como "none", el servidor se apagará inmediatamente. Si se usa el formato "+30", indica que el servidor se apagará en 30 minutos. Si se usa el formato "1130", significa que el servidor se apagará a las 11:30 todos los días, en formato de 24 horas.

Después de apagar el servidor FTP, se generará un archivo llamado shutmsg en el directorio /etc. Una vez eliminado, se puede reiniciar la funcionalidad del servidor FTP.

Sintaxis

ftpshut [选项] [时间] [警告消息]

Parámetros：

  • Tiempo: Especifica el tiempo de apagado del servicio FTP. El tiempo puede expresarse en+minutosel formato (por ejemplo+10indica que se apagará después de 10 minutos), también puede expresarse enHHMMel formato (por ejemplo1430indica que se apagará a las 2:30 p.m.).

  • Mensaje de advertencia: Mensaje de advertencia enviado a todos los usuarios FTP conectados antes de que se apague el servicio FTP. El contenido del mensaje puede incluir los siguientes placeholders:

    • %s: Representa el tiempo de apagado del servicio FTP.
    • %r: Representa el tiempo de reinicio después de apagar el servicio FTP.
    • %d: Representa el tiempo restante hasta el apagado del servicio FTP (en minutos).

Opciones comunes:

  • -l <分钟>: Especifica el tiempo (en minutos) antes del apagado del servicio FTP durante el cual se rechazan los nuevos inicios de sesión.
  • -d <分钟>: Especifica el tiempo (en minutos) antes del apagado del servicio FTP durante el cual se desconectan todas las conexiones de usuarios.

Ejemplos

Para apagar el servidor FTP a las 11:00 p.m., rechazar nuevos inicios de sesión FTP 5 minutos antes del apagado, cerrar todas las conexiones FTP 3 minutos antes y mostrar un mensaje de advertencia, se puede usar el siguiente comando:

ftpshut-d 3 -1 5 1100 "Server will be shutdown at 23:00:00"

Supongamos que deseas apagar el servicio FTP en 10 minutos y enviar un mensaje de advertencia a los usuarios. Puedes usar el siguiente comando:

ftpshut +10 "FTP 服务将在 %s 关闭，请尽快完成操作。"

En este ejemplo,+10representa el apagado del servicio FTP en 10 minutos,"FTP 服务将在 %s 关闭，请尽快完成操作。"es el mensaje de advertencia enviado a los usuarios,%sserá reemplazado por el tiempo real de apagado.

Si deseas apagar el servicio FTP a las 3:00 p.m., puedes usar el siguiente comando:

ftpshut 1500 "FTP 服务将在 %s 关闭，预计在 %r 重新启动。"

En este ejemplo,1500representa el apagado del servicio FTP a las 3:00 p.m.,"FTP 服务将在 %s 关闭，预计在 %r 重新启动。"es el mensaje de advertencia enviado a los usuarios,%sy%rserá reemplazado por el tiempo real de apagado y el tiempo de reinicio.

Si deseas rechazar nuevos inicios de sesión 5 minutos antes de apagar el servicio FTP, puedes usar el siguiente comando:

ftpshut -l 5 +10 "FTP 服务将在 %s 关闭，请尽快完成操作。"

En este ejemplo,-l 5representa el rechazo de nuevos inicios de sesión 5 minutos antes del apagado,+10representa el apagado del servicio FTP en 10 minutos.

Si deseas desconectar a todos los usuarios 2 minutos antes de apagar el servicio FTP, puedes usar el siguiente comando:

ftpshut -d 2 +10 "FTP 服务将在 %s 关闭，请尽快完成操作。"

En este ejemplo,-d 2representa la desconexión de todos los usuarios 2 minutos antes del apagado,+10representa el apagado del servicio FTP en 10 minutos.
