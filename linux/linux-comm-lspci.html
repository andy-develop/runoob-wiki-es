Comando Linux lspci

Manual completo de comandos de Linux

¿Qué es el comando lspci?

lspciEs un comando de utilidad en el sistema Linux que se utiliza para listar la información de todos los dispositivos PCI. PCI (Peripheral Component Interconnect) es un estándar de bus de computadora que se utiliza para conectar la placa base con diversos dispositivos de hardware.

Mediante ellspcicomando, los administradores de sistemas y desarrolladores pueden:

  • Ver todos los dispositivos PCI instalados en el sistema
  • Obtener información detallada de los dispositivos, incluidos el ID del fabricante, el ID del dispositivo, etc.
  • Diagnosticar problemas de compatibilidad de hardware
  • Verificar si los controladores están cargados correctamente

Sintaxis básica

lspciEl formato de sintaxis básica del comando es el siguiente:

lspci [选项]

Si no se incluye ninguna opción,lspcise mostrará una lista con la información resumida de todos los dispositivos PCI del sistema.

Opciones y parámetros comunes

Mostrar información detallada

Ejemplo

lspci -v      # Mostrar información detallada (verbose)
lspci -vv     # Mostrar información más detallada (very verbose)
lspci -vvv    # Mostrar información mucho más detallada (very very verbose)

Consulta de dispositivos específicos

Ejemplo

lspci -s <Bus>:<Dispositivo>.<Función>  # Ver la información de un dispositivo específico

Por ejemplo:

Ejemplo

lspci -s 00:02.0  # Ver el dispositivo del bus 00, dispositivo 02, función 0

Otras opciones comunes

Ejemplo

lspci -n      # Mostrar el ID del fabricante y del dispositivo en formato numérico
lspci -nn     # Mostrar tanto el ID numérico como el nombre del dispositivo
lspci -k      # Mostrar la información del módulo de controlador del kernel
lspci -t      # Mostrar la jerarquía de dispositivos en forma de árbol
lspci -mm     # Salida en formato legible por máquina
lspci -D      # Mostrar el nombre de dominio completo (incluido el número de dominio)

Una salida típica delspcies la siguiente:

00:01.0 PCI bridge: Intel Corporation 440BX/ZX/DX - 82443BX/ZX/DX AGP bridge (rev 01)
00:07.0 ISA bridge: Intel Corporation 82371AB/EB/MB PIIX4 ISA (rev 08)
00:07.1 IDE interface: Intel Corporation 82371AB/EB/MB PIIX4 IDE (rev 01)
00:07.2 USB controller: Intel Corporation 82371AB/EB/MB PIIX4 USB (rev 01)
00:07.3 Bridge: Intel Corporation 82371AB/EB/MB PIIX4 ACPI (rev 08)

Explicación del formato de salida:

  • Primera parte：00:00.0es la dirección del dispositivo, con formatoBus: dispositivo.función
  • Segunda parte: tipo de dispositivo, como "Host bridge", "VGA compatible controller", etc.
  • Tercera parte: fabricante del dispositivo y modelo específico

Ejemplos de aplicación práctica

Ejemplo 1: Ver la información básica de todos los dispositivos PCI

Ejemplo

lspci

Ejemplo 2: Ver la información detallada de la tarjeta gráfica

Ejemplo

lspci -v | grep -i vga -A 12

Ejemplo 3: Ver el controlador USB y la información de su driver

Ejemplo

lspci -v -k | grep -i usb -A 3

Ejemplo 4: Mostrar los dispositivos PCI en estructura de árbol

Ejemplo

lspci -t

Solución de problemas comunes

1. Comando no encontrado

Si el sistema indicalspci: command not found, significa que es necesario instalarpciutilsel paquete:

Ejemplo

# Debian/Ubuntu
sudo apt-get install pciutils

# CentOS/RHEL
sudo yum install pciutils

2. Permisos insuficientes

Cuando un usuario normal ejecutalspci, es posible que no pueda obtener información completa; se puede usarsudo：

Ejemplo

sudo lspci -v

3. Problemas de reconocimiento de dispositivos

Si algunos dispositivos no se reconocen, se puede intentar actualizar la base de datos de ID PCI:

Ejemplo

sudo update-pciids

Técnicas avanzadas

1. Combinar con grep para filtrar dispositivos específicos

Ejemplo

lspci | grep -i ethernet  # Buscar tarjeta de red
lspci | grep -i audio     # Buscar tarjeta de sonido

2. Exportar la información de dispositivos a un archivo

Ejemplo

lspci -vvv > pci_info.txt

3. Ver el espacio de configuración completo del dispositivo

Ejemplo

lspci -xxxx  # Mostrar el espacio de configuración en hexadecimal
