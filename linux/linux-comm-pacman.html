Comando pacman de Linux

Referencia completa de comandos de Linux

pacman (Package Manager) es la herramienta de gestión de paquetes predeterminada en Arch Linux y sus distribuciones derivadas (como Manjaro). Es una herramienta de línea de comandos muy potente que se utiliza para instalar, actualizar, eliminar y gestionar paquetes de software.

Características principales de pacman:

  • Interfaz de línea de comandos sencilla y fácil de usar
  • Manejo automático de dependencias
  • Soporte para paquetes locales y remotos
  • Proporciona funciones completas de actualización del sistema
  • Capacidades eficientes de consulta y búsqueda de paquetes

Sintaxis básica

El formato básico de sintaxis del comando pacman es el siguiente:

sudo pacman [选项] [操作] [包名/其他参数]

Donde:

  • sudoLa mayoría de las operaciones de pacman requieren permisos de root
  • OpcionesBanderas que modifican el comportamiento del comando
  • OperaciónEspecifica la función principal a ejecutar
  • Nombre del paqueteEl nombre del paquete sobre el que se va a operar

Comandos de operaciones comunes

Actualización del sistema

Ejemplo

# Actualizar todos los paquetes instalados
sudo pacman -Syu

# Actualizar solo la base de datos de paquetes (sin actualizar el software en realidad)
sudo pacman -Sy

Instalación de paquetes

Ejemplo

# Instalar un solo paquete
sudo pacman -Snombre_del_paquete

# Instalar varios paquetes
sudo pacman -Snombre_del_paquete1nombre_del_paquete2nombre_del_paquete3

# Instalar un archivo de paquete local (sin gestionar dependencias)
sudo pacman -U /ruta/到/nombre_del_paquete.pkg.tar.zst

Eliminación de paquetes

Ejemplo

# Eliminar el paquete pero conservar sus dependencias
sudo pacman -Rnombre_del_paquete

# Eliminar el paquete y sus dependencias que ya no se necesitan
sudo pacman -Rsnombre_del_paquete

# Eliminar el paquete y todos sus archivos de configuración
sudo pacman -Rnsnombre_del_paquete

Consulta de paquetes

Ejemplo

# Buscar paquetes (por nombre y descripción)
pacman -Sspalabra_clave

# Listar los paquetes instalados
pacman -Q

# Consultar a qué paquete pertenece un archivo
pacman -Qo /ruta/到/archivo

# Mostrar información detallada del paquete
pacman -Qinombre_del_paquete

Limpiar caché

Ejemplo

# Limpiar la caché de paquetes no instalados
sudo pacman -Sc

# Limpiar la caché de todos los paquetes (incluidos los instalados)
sudo pacman -Scc

Opciones y parámetros comunes

Opción Descripción
-S Sincronizar/instalar paquetes
-R Eliminar paquetes
-Q Consultar la base de datos local de paquetes
-U Instalar un archivo de paquete local
-y Actualizar la base de datos de paquetes
-u Actualizar/mejorar paquetes
-s Incluir descripción al buscar
-i Mostrar información del paquete
-c Limpiar caché
-d Omitir comprobación de dependencias
-f Operación forzada
--noconfirm Omitir todas las indicaciones de confirmación

Ejemplos de aplicación práctica

Ejemplo 1: Instalar y configurar un entorno de desarrollo

Ejemplo

# Actualizar el sistema
sudo pacman -Syu

# Instalar el paquete de herramientas de desarrollo
sudo pacman -S base-devel git python

# Verificar la instalación
pacman -Q | grep python

Ejemplo 2: Buscar e instalar un reproductor multimedia

Ejemplo

# Buscar reproductores multimedia
pacman -Ss media player

# Instalar el reproductor multimedia VLC
sudo pacman -S vlc

# Ver las dependencias de VLC
pacman -Qi vlc

Ejemplo 3: Eliminar por completo el software que ya no se necesita

Ejemplo

# Buscar el paquete que se desea eliminar
pacman -Qs game

# Eliminar el juego, sus dependencias y configuración
sudo pacman -Rns steam

Resolución de problemas comunes

1. Conflictos de dependencias

Cuando se encuentre un conflicto de dependencias, puede intentar:

Ejemplo

# Forzar la degradación de un paquete específico
sudo pacman -U https://archive.archlinux.org/packages/p/nombre_del_paquete/nombre_del_paquete-versión.pkg.tar.zst

# O intentar reparar las dependencias
sudo pacman -Syu --overwrite '*'

2. Bloqueo de la base de datos

Si aparece el error «could not lock database»:

Ejemplo

# Eliminar el archivo de bloqueo
sudo rm /var/lib/pacman/db.lck

3. Espacio insuficiente

Limpiar la caché de versiones antiguas:

Ejemplo

# Ver el espacio ocupado por la caché
du -sh /var/cache/pacman/pkg/

# Limpiar versiones antiguas
sudo pacman -Sc

Recomendaciones de mejores prácticas

  1. Actualice el sistema periódicamente: ejecútelo al menos una vez a la semanasudo pacman -Syu
  2. Lea la información de salida: la salida de pacman contiene información importante, no confirme a ciegas
  3. Haga una copia de seguridad de los datos importantes: realice una copia de seguridad de los archivos importantes antes de una actualización importante del sistema
  4. Utilice un asistente de AUR: para el software en el repositorio de usuarios de Arch (AUR), considere usar yay o paru
  5. Consulte la Arch Wiki: cuando tenga problemas, la Arch Wiki suele tener soluciones detalladas

Técnicas avanzadas

Ver el contenido de los archivos de un paquete

Ejemplo

# Listar los archivos incluidos en el paquete
pacman -Qlnombre_del_paquete

# Extraer archivos específicos de un paquete
sudo pacman -Swnombre_del_paquete&amp;&amp; tar -xf /var/cache/pacman/pkg/nombre_del_paquete*.pkg.tar.zst

Construir paquetes personalizados

Ejemplo

# Descargar el archivo PKGBUILD
asp exportnombre_del_paquete

# Entrar en el directorio y construir
cdnombre_del_paquete
makepkg -si

Consultar la pertenencia de un archivo

Ejemplo

# Averiguar qué paquete proporciona un comando específico
pacman -Qo $(whichnombre_del_comando)

# Por ejemplo, averiguar a qué paquete pertenece el comando vim
pacman -Qo $(which vim)

Al dominar el comando pacman, puedes gestionar de manera eficiente todos los paquetes de software en el sistema Arch Linux. Recuerda que pacman es una herramienta poderosa; un comando incorrecto puede provocar problemas en el sistema, por lo que debes entender el efecto del comando antes de ejecutarlo.
