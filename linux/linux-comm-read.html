Comando read de Linux

Enciclopedia de comandos Linux

El comando read de Linux se utiliza para leer datos de la entrada estándar.

El comando interno read se utiliza para leer una sola línea de datos desde la entrada estándar. Este comando se puede usar para leer la entrada del teclado; cuando se utiliza la redirección, puede leer una línea de datos de un archivo.

Sintaxis

read [-ers] [-a aname] [-d delim] [-i text] [-n nchars] [-N nchars] [-p prompt] [-t timeout] [-u fd] [name ...]

Descripción de parámetros:

  • -a va seguido de una variable; dicha variable se considera un array y se le asigna un valor, siendo el espacio el separador predeterminado.
  • -d va seguido de un delimitador; en realidad, solo el primer carácter que le sigue es útil, actuando como marca de fin.
  • -p va seguido de un mensaje, es decir, imprime el mensaje antes de la entrada.
  • -e permite usar la función de autocompletar comandos al introducir.
  • -n va seguido de un número, define la longitud del texto de entrada; es muy práctico.
  • -r bloquea \. Si no se usa esta opción, \ se trata como un carácter de escape; si se usa, \ es un carácter normal.
  • -s es el modo silencioso; no muestra los caracteres introducidos en la pantalla, por ejemplo, al introducir la contraseña en el login.
  • -t va seguido de un número de segundos, define el tiempo de espera para la entrada de caracteres.
  • -u va seguido de fd; lee desde el descriptor de archivo, el cual puede ser abierto recientemente por exec.

Ejemplos

1. Lectura simple

#!/bin/bash

#这里默认会换行  
echo "输入网站名: "  
#读取从键盘的输入  
read website  
echo "你输入的网站名是 $website"  
exit 0  #退出

El resultado de la prueba es:

输入网站名: 
www.runoob.com
你输入的网站名是 www.runoob.com

2. El parámetro -p permite especificar directamente un mensaje en la línea de comandos de read.

#!/bin/bash

read -p "输入网站名:" website
echo "你输入的网站名是 $website" 
exit 0

El resultado de la prueba es:

输入网站名:www.runoob.com
你输入的网站名是 www.runoob.com

3. El parámetro -t especifica los segundos que el comando read espera la entrada. Cuando el tiempo se agota, el comando read devuelve un estado de salida distinto de cero.

#!/bin/bash

if read -t 5 -p "输入网站名:" website
then
    echo "你输入的网站名是 $website"
else
    echo "\n抱歉，你输入超时了。"
fi
exit 0

Ejecute el programa sin entrada; después de 5 segundos:

Introduce el nombre del sitio web:

4. Además de temporizar la entrada, también se puede usar-nConfiguración de parámetrosreadEl comando cuenta los caracteres introducidos. Cuando el número de caracteres introducidos alcanza la cantidad predeterminada, sale automáticamente y asigna los datos introducidos a la variable.

#!/bin/bash

read -n1 -p "Do you want to continue [Y/N]?" answer
case $answer in
Y | y)
      echo "fine ,continue";;
N | n)
      echo "ok,good bye";;
*)
     echo "error choice";;

esac
exit 0

Este ejemplo utiliza la opción -n, seguida del valor 1, que indica al comando read que salga en cuanto reciba un carácter. Basta con pulsar un carácter para responder; el comando read acepta inmediatamente la entrada y la asigna a la variable, sin necesidad de pulsar Enter.

Sale al recibir solo 2 entradas:

#!/bin/bash

read -n2 -p "请随便输入两个字符: " any
echo "\n您输入的两个字符是:$any"
exit 0

Ejecute el programa e introduzca dos caracteres:

请随便输入两个字符: 12
您输入的两个字符是:12

5、-sLa opción permite quereadlos datos introducidos en el comando no se muestren en la terminal de comandos (en realidad, los datos se muestran, solo quereadel comando establece el color del texto al mismo color que el fondo). Esta opción se usa a menudo para introducir contraseñas.

#!/bin/bash

read  -s  -p "请输入您的密码:" pass
echo "\n您输入的密码是 $pass"
exit 0

Al ejecutar el programa e introducir la contraseña, no se muestra:

请输入您的密码:
您输入的密码是 runoob

6. Leer un archivo

Cada invocación del comando read lee una 'línea' de texto del archivo. Cuando el archivo no tiene líneas legibles, el comando read saldrá con un estado distinto de cero.

¿Cómo se transfieren los datos del archivo al comando read? Use el comando cat y, mediante una tubería, envíe el resultado directamente al comando while que contiene el comando read.

El contenido del archivo de prueba test.txt es el siguiente:

123
456
runoob

Código de prueba:

#!/bin/bash
  
count=1    # 赋值语句，不加空格
cat test.txt | while read line      # cat 命令的输出作为read命令的输入,read读到>的值放在line中
do
   echo "Line $count:$line"
   count=$[ $count + 1 ]          # 注意中括号中的空格。
done
echo "finish"
exit 0

El resultado de la ejecución es:

Line 1:123
Line 2:456
Line 3:runoob
finish

$ read -e -p "输入文件名:" str

a.out    a.py     a.pyc    abc.txt  
输入文件名:a
