Comando scp de Linux

Manual completo de comandos de Linux

El comando scp de Linux se utiliza para copiar archivos y directorios entre sistemas Linux.

scp es la abreviatura de secure copy; scp es un comando de copia remota segura de archivos basado en el inicio de sesión ssh en sistemas Linux.

scp está cifrado,rcprcp no está cifrado; scp es una versión mejorada de rcp.

En los sistemas Linux,scpel comando es una herramienta muy práctica.scpEs la abreviatura de "secure copy"; se basa en el protocolo SSH (Secure Shell) para garantizar la seguridad de la transferencia de datos.

Sintaxis

scp [-1246BCpqrv] [-c cipher] [-F ssh_config] [-i identity_file]
[-l limit] [-o ssh_option] [-P port] [-S program]
[[user@]host1:]file1 [...] [[user@]host2:]file2

Escritura simplificada:

scp [选项] [源文件] [目标路径]
  • [Opciones]: se utiliza para especificarscpel comportamiento del comando, por ejemplo, copia recursiva, conservación de atributos de archivo, etc.
  • [Archivo de origen]: la ruta del archivo o directorio a copiar.
  • [Ruta de destino]: la ruta de destino a la que se copiará el archivo o directorio.

Opciones comunes:

A continuación se presentan algunasscpopciones de comando comunes:

  • -r: copia recursivamente todo el directorio.
  • -P: especifica el número de puerto SSH del host remoto (por defecto es 22).
  • -p: conserva la hora de modificación, la hora de acceso y los permisos del archivo.
  • -v: muestra información de depuración detallada, útil para solucionar problemas.
  • -C: habilita la compresión, lo que puede acelerar la velocidad de transferencia.

Descripción completa de las opciones:

  • -1: Obliga al comando scp a usar el protocolo ssh1.
  • -2: Obliga al comando scp a usar el protocolo ssh2.
  • -4: Obliga al comando scp a usar solo direccionamiento IPv4.
  • -6: Obliga al comando scp a usar solo direccionamiento IPv6.
  • -B: Usa el modo de procesamiento por lotes (no solicita contraseñas ni frases de contraseña durante la transferencia).
  • -C: Permite la compresión. (Pasa el indicador -C a ssh, habilitando así la compresión).
  • -p: Conserva la hora de modificación, la hora de acceso y los permisos del archivo original.
  • -q: No muestra la barra de progreso de la transferencia.
  • -r: Copia recursivamente todo el directorio.
  • -v: Muestra la salida de forma detallada. scp y ssh(1) mostrarán información de depuración de todo el proceso. Esta información se utiliza para depurar problemas de conexión, verificación y configuración.
  • -c cipher: Cifra la transferencia de datos con cipher; esta opción se pasará directamente a ssh.
  • -F ssh_config: Especifica un archivo de configuración ssh alternativo; este parámetro se pasa directamente a ssh.
  • -i identity_file: Lee el archivo de clave utilizado en la transferencia desde el archivo especificado; este parámetro se pasa directamente a ssh.
  • -l limit: Limita el ancho de banda que el usuario puede utilizar, en Kbit/s.
  • -o ssh_option: Si estás acostumbrado a la forma de pasar parámetros en ssh_config(5),
  • -P port: Ten en cuenta que es P mayúscula; port es el número de puerto especificado para la transferencia de datos.
  • -S program: Especifica el programa utilizado para la transferencia cifrada. Este programa debe poder entender las opciones de ssh(1).

Copiar archivos desde el local a un host remoto

Supongamos que tienes un archivoexample.txt, quieres copiarlo al directorio/home/user/del host remoto, puedes usar el siguiente comando:

scp example.txt user@remote_host:/home/user/

En este comando:

  • example.txtes el archivo local.
  • user@remote_hostes el nombre de usuario y la dirección del host remoto.
  • /home/user/es la ruta de destino en el host remoto.

Copiar archivos desde un host remoto al local

Si deseas copiar el archivo del host remotoexample.txtal directorio local actual, puedes usar el siguiente comando:

scp user@remote_host:/home/user/example.txt .

En este comando:

  • user@remote_host:/home/user/example.txtes la ruta del archivo en el host remoto.
  • .representa el directorio actual.

Copiar directorios recursivamente

Si deseas copiar todo el directorio y su contenido, puedes usar-rla opción. Por ejemplo, el directorio localmy_directoryse copia al directorio del host remoto/home/user/en el directorio:

scp -r my_directory user@remote_host:/home/user/

Especificar número de puerto

Si el servicio SSH del host remoto se ejecuta en un puerto no predeterminado (por ejemplo, 2222), puedes usar-Pla opción para especificar el número de puerto:

scp -P 2222 example.txt user@remote_host:/home/user/

Conservar atributos de archivo

Si deseas conservar la hora de modificación, la hora de acceso y los permisos del archivo al copiarlo, puedes usar-pla opción:

scp -p example.txt user@remote_host:/home/user/

Habilitar compresión

Para archivos grandes o redes lentas, puedes usar-Cla opción para habilitar la compresión y acelerar la velocidad de transferencia:

scp -C large_file.zip user@remote_host:/home/user/

Ejemplos de aplicación

1. Copiar de local a remoto

Formato del comando:

scp local_file remote_username@remote_ip:remote_folder 
或者 
scp local_file remote_username@remote_ip:remote_file 
或者 
scp local_file remote_ip:remote_folder 
或者 
scp local_file remote_ip:remote_file

  • Los ejemplos 1 y 2 especifican el nombre de usuario; después de ejecutar el comando, se debe ingresar la contraseña. El primero solo especifica el directorio remoto, el nombre del archivo no cambia; el segundo especifica el nombre del archivo.
  • Los ejemplos 3 y 4 no especifican el nombre de usuario; después de ejecutar el comando, se debe ingresar el nombre de usuario y la contraseña. El tercero solo especifica el directorio remoto, el nombre del archivo no cambia; el cuarto especifica el nombre del archivo.

Ejemplo de aplicación:

scp /home/space/music/1.mp3 root@www.runoob.com:/home/root/others/music 
scp /home/space/music/1.mp3 root@www.runoob.com:/home/root/others/music/001.mp3 
scp /home/space/music/1.mp3 www.runoob.com:/home/root/others/music 
scp /home/space/music/1.mp3 www.runoob.com:/home/root/others/music/001.mp3

Formato del comando para copiar directorios:

scp -r local_folder remote_username@remote_ip:remote_folder 
或者 
scp -r local_folder remote_ip:remote_folder
  • El primero especifica el nombre de usuario; después de ejecutar el comando, se debe ingresar la contraseña.
  • El segundo no especifica el nombre de usuario; después de ejecutar el comando, se debe ingresar el nombre de usuario y la contraseña.

Ejemplo de aplicación:

scp -r /home/space/music/ root@www.runoob.com:/home/root/others/ 
scp -r /home/space/music/ www.runoob.com:/home/root/others/

El comando anterior copia el directorio local music al directorio remoto others.

2. Copiar de remoto a local

Para copiar de remoto a local, basta con intercambiar el orden de los últimos 2 parámetros del comando de copiar de local a remoto, como en el siguiente ejemplo.

Ejemplo de aplicación:

scp root@www.runoob.com:/home/root/others/music /home/space/music/1.mp3 
scp -r www.runoob.com:/home/root/others/ /home/space/music/

Explicación

1. Si el firewall del servidor remoto ha configurado un puerto específico para el comando scp, debemos usar el parámetro -P para establecer el número de puerto del comando. El formato del comando es el siguiente:

#scp 命令使用端口号 4588
scp -P 4588 remote@www.runoob.com:/usr/local/sin.sh /home/administrator

2. Al usar el comando scp, asegúrate de que el usuario utilizado tenga permiso para leer el archivo correspondiente en el servidor remoto; de lo contrario, el comando scp no funcionará.

Precauciones

  • Asegúrate de tener permisos suficientes para acceder al archivo de origen y a la ruta de destino.
  • Si el servicio SSH del host remoto no está en ejecución o está configurado incorrectamente,scpel comando no funcionará correctamente.
  • El uso de-vla opción puede ayudarte a depurar problemas de conexión.
