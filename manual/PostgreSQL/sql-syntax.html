Capítulo 4 Sintaxis de SQL

Este capítulo describe la sintaxis de SQL. Constituye la base para comprender los capítulos posteriores que presentan específicamente cómo usar SQL para definir y modificar datos.

Al mismo tiempo, recomendamos a los usuarios que ya estén familiarizados con SQL que lean este capítulo detenidamente, porque contiene algunas implementaciones inconsistentes en las bases de datos SQL, y.PostgreSQLLas reglas y conceptos específicos.
