TypeScript Handbook (Versión en chino)

Antes odiaba de todo corazón los lenguajes que se compilan a JavaScript, como Coffee, Dart, etc. Pero alrededor del Año Nuevo Chino de 2015, me enamoré de TypeScript. Al mismo tiempo, los frameworks que me gustan mucho, Dojo y AngularJS, también anunciaron que usarían TypeScript para el desarrollo de sus nuevas versiones. Entonces, ¿qué es exactamente TypeScript? ¿Y qué atractivo tiene?

TypeScript es una marca registrada de Microsoft Corporation.

TypeScript tiene un sistema de tipos y es un superconjunto de JavaScript. Puede compilarse en código JavaScript normal. TypeScript es compatible con cualquier navegador, cualquier entorno, cualquier sistema y es de código abierto.

TypeScript todavía se encuentra en pleno desarrollo y mejora, y constantemente se añadirán nuevas características. Por lo tanto, este manual seguirá de cerca cada commit oficial, actualizando continuamente nuevos capítulos y corrigiendo las expresiones inadecuadas.

Si te enamoras de TypeScript a primera vista, puedes suscribirte aand stareste manual para conocer oportunamente las nuevas características nativas de ECMAScript 2015 y 2016, ¡y dominar de antemano la forma de usarlas con la ayuda de TypeScript!
