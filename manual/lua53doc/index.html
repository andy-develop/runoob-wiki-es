安装 Lua

Lua 以 源代码se publica en forma de...; antes de usarlo, necesitas construirlo. Construir Lua es muy sencillo, porque Lua está implementado en ANSI C puro y se puede compilar directamente en todas las plataformas que tengan un compilador ANSI C. Asimismo, Lua también puede compilarse directamente como C++. A continuación se describe el proceso de compilación en plataformas tipo Unix; además, hay其它系统构建介绍 与 配置选项 以作参考。

Si no tienes tiempo o interés en compilar Lua tú mismo, puedesLuaBinariesobtener los binarios compilados, o desdeLuaDistaquí obtener la distribución multiplataforma de Lua (con las baterías incluidas).

Construyendo Lua

En la mayoría de las plataformas tipo Unix, escribe "make" más el nombre de plataforma adecuado es suficiente. Los pasos son:

  1. Abra una ventana de consola y cambie alua-5.3.0directorio.MakefileEl archivo contiene el proceso de construcción e instalación.

  2. 运行 "make" y comprueba si tu plataforma está incluida. Las plataformas soportadas actualmente son:

    aix bsd c89 freebsd generic linux macosx mingw posix solaris

    Si su plataforma está entre ellas, ejecute "make xxx" es suficiente, donde xxx representa el nombre de tu plataforma.

    Si tu plataforma no está entre ellas, prueba primero la más parecida y luego intenta en orden: posix, generic, c89.

  3. El proceso de compilación es muy corto y, finalmente, ensrcse generan tres archivos en el directorio: lua (intérprete), luac (compilador) y liblua.a (biblioteca estática).

  4. Una vez completada la compilación, puede ejecutar "make test" para comprobar si se ha realizado correctamente. Ejecutará el intérprete e imprimirá el número de versión.

Si usas Linux y aparecen errores de compilación, verifica si has instaladoreadline （也可能叫 libreadline-dev 或者 readline-develpaquete de desarrollo). Después, si todavía hay errores de enlace, pruebe con "make linux MYLIBS=-ltermcap" 。

Instalando Lua

Una vez que hayas terminado de construir, puede que quieras instalar Lua en la ubicación predeterminada del sistema; entonces ejecuta "make install" es suficiente. La ubicación predeterminada del sistema y cómo instalar están definidos enMakefileen. Este proceso puede requerir los permisos pertinentes.

运行 "make xxx install" permite construir e instalar en un solo paso, donde xxx se refiere al nombre de tu plataforma.

Si quieres instalar Lua localmente, ejecuta "make local". Creará uninstall 目录，内有 bin, include, lib, man, share, subdirectorio, e instalará en él los siguientes archivos. Si deseas instalarlo en otro directorio local, ejecuta "make install INSTALL_TOP=xxx", donde xxx indica el directorio que elijas.src 以及 docdirectorio, así que cuandoINSTALL_TOPSi no es una ruta absoluta, tenga cuidado.

bin:
lua luac
include:

man/man1:

Estos son los directorios necesarios para el desarrollo. Si solo quieres ejecutar algunos programas Lua, entonces solo necesitasbin 和 man 下的文件。 include 和 libLos archivos de dicho directorio se utilizan para incrustar Lua en programas C o C++.

定制

Hay tres tipos de personalizaciones que se pueden realizar editando archivos:

  • Cómo instalar Lua y dónde instalarlo — editaMakefile。
  • Cómo compilar Lua — editarsrc/Makefile。
  • Características de Lua — editarsrc/luaconf.h。

En realidad, no es necesario editar el archivo Makefile; basta con especificar las variables correspondientes en la línea de comandos al ejecutar make. Por supuesto, editar y guardar el Makefile puede dejar un registro de la personalización.

Por otro lado, si necesitas personalizar algunas características de Lua, entonces debes, antes de construir e instalar Lua, editarsrc/luaconf.h. Los archivos editados deben garantizar la coherencia, es decir, instalarse en un solo lugar, de modo que todos los programas que compiles y que usen Lua utilicen esa única copia. Los expertos pueden personalizar más cosas editando el código fuente de Lua.

在其它系统上构建 Lua

Si no utilizas las herramientas Unix habituales, el proceso de compilación de Lua dependerá del compilador que uses. Necesitas crear varios proyectos para compilar la biblioteca, el intérprete y el compilador, etc. Añade los siguientes archivos fuente a los proyectos correspondientes:

库:
lapi.c lcode.c lctype.c ldebug.c ldo.c ldump.c lfunc.c lgc.c llex.c lmem.c lobject.c lopcodes.c lparser.c lstate.c lstring.c ltable.c ltm.c lundump.c lvm.c lzio.c lauxlib.c lbaselib.c lbitlib.c lcorolib.c ldblib.c liolib.c lmathlib.c loslib.c lstrlib.c ltablib.c lutf8lib.c loadlib.c linit.c
解释器:
library, lua.c
编译器:
library, luac.c

Para usar Lua como biblioteca en tus programas, necesitas saber cómo crear y usar bibliotecas con tu compilador. Por ejemplo, para usar Lua como una biblioteca C de carga dinámica, necesitas saber cómo crear una biblioteca dinámica y hacer que las funciones de la API de Lua sean visibles en la biblioteca dinámica —不要Enlaza la biblioteca de Lua en cada biblioteca dinámica. En Unix, recomendamos enlazar estáticamente la biblioteca de Lua en el programa anfitrión y luego exportar los símbolos para el enlace dinámico;src/MakefileAsí se maneja el intérprete de Lua. En Windows, recomendamos compilar la biblioteca de Lua como un DLL. En cualquier caso, el compilador luac debe estar enlazado estáticamente.

Como se dijo anteriormente, puedes editar antes de construir Luasrc/luaconf.hpara personalizar algunas características.
