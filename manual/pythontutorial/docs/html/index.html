Guía de introducción a Python¶

Release:2.7.13
Date:Feb 13, 2017

Python es un lenguaje de programación simple de aprender y muy potente. Dispone de estructuras de datos de alto nivel eficientes y permite programación orientada a objetos de una manera sencilla y eficaz. La elegante sintaxis de Python y su tipado dinámico, junto con su carácter interpretado, lo convierten en un lenguaje ideal para escribir scripts o desarrollar aplicaciones en muchos ámbitos de la mayoría de las plataformas.

Puedes libremente desde el sitio oficial de Python: http://www.python.orgObtener el intérprete de Python y su biblioteca de extensión estándar en forma de código fuente o binario, y poder distribuirlos libremente. Este sitio también proporciona una gran cantidad de módulos, programas y herramientas de Python de terceros, así como documentación adicional.

Puede usar fácilmente C o C++ (u otros lenguajes que se puedan llamar desde C) para ampliar el intérprete de Python con nuevas funciones y tipos de datos. Python también se puede utilizar como un lenguaje de extensión para personalizar aplicaciones.

Este manual introduce informalmente al lector los conocimientos y conceptos básicos del lenguaje Python y su sistema relacionado. Es útil utilizar el intérprete de Python junto con la práctica de aprendizaje, aunque todos los ejemplos son completos, por lo que este manual también se puede leer sin conexión.

Si necesita conocer los detalles de las bibliotecas estándar u objetos relacionados, consulte Python documentación de referencia 。Python manual de referencia Proporciona más explicaciones formales relacionadas con el lenguaje. Si desea escribir extensiones en C o C++, consulte Capítulo de extensión e integración del intérprete de Python y C API Manual de referencia Por supuesto, también puedes leer algunos libros que profundicen en el conocimiento de Python.

Este manual no pretende cubrir todos los conocimientos de Python ni todas sus características, ni siquiera todas las características de uso común. En cambio, presenta muchas de las características más destacadas de Python y le dará una idea de las particularidades y el estilo del lenguaje. Tras su lectura, podrá leer y escribir módulos o programas en Python, y para su uso posterior. Python manual de referencia Prepárate para seguir aprendiendo las numerosas bibliotecas de módulos de Python.
