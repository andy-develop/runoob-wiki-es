Escapar

Markdown utiliza muchos símbolos especiales para representar significados específicos; si necesita mostrar símbolos concretos, debe usar caracteres de escape. Markdown usa una barra invertida para escapar caracteres especiales:

**texto en negrita** \*\* mostrar asterisco normalmente \*\*

Markdown admite agregar una barra invertida antes de los siguientes símbolos para insertar símbolos normales:

\   反斜线
`   反引号
*   星号
_   下划线
{}  花括号
[]  方括号
()  小括号
#   井字号
+   加号
-   减号
.   英文句点
!   感叹号
