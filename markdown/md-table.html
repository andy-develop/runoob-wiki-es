Tablas Markdown

Las tablas y las citas son herramientas importantes para organizar el contenido en Markdown.

Las tablas pueden mostrar datos estructurados con claridad, mientras que las citas se usan para resaltar información importante o citar las opiniones de otros.

Para crear tablas en Markdown se usa|para separar las distintas celdas, use-para separar el encabezado de las demás filas.

El formato de sintaxis es el siguiente:

|   Encabezado   | Encabezado  |
|  ----  | ----  |
| Celda  | Celda |
| Celda  | Celda |

Puntos clave de sintaxis：

  • Debe haber una línea separadora entre el encabezado y las filas de datos.
  • La línea separadora necesita al menos tres guiones.---
  • Las barras verticales en ambos extremos|son opcionales, pero se recomienda mantenerlas para mejorar la legibilidad.
  • No es necesario alinear estrictamente, pero queda más bonito si se alinea.

Alineación

Podemos establecer la alineación de la tabla:

  • ---:Establece el contenido y el encabezado alineados a la derecha.
  • :---Establece el contenido y el encabezado alineados a la izquierda.
  • :---:Establece el contenido y el encabezado alineados al centro.

Ejemplo:

| Alinear a la izquierda | Alinear a la derecha | Alineación centrada |
| :-----| ----: | :----: |
| Celda | Celda | Celda |
| Celda | Celda | Celda |

Técnicas para manejar tablas complejas

Formato del contenido de las celdas

Se puede usar la mayoría de la sintaxis de Markdown dentro de las celdas de la tabla:

| 功能 | 描述 | 状态 |
|------|------|:----:|
| **用户登录** | 支持邮箱和手机号登录 | &#x2705; |
| *密码重置* | 通过邮箱重置密码 | &#x26a0;&#xfe0f; |
| `API接口` | RESTful API 设计 | &#x2705; |
| [文档链接](https://example.com) | 查看详细文档 | &#x1f4d6; |

Manejo de texto largo

Cuando el contenido de la celda es largo, puedes usar los siguientes trucos:

Manejo de saltos de línea：

| 项目 | 详细说明 |
|------|----------|
| 需求分析 | 1. 收集用户需求<br>2. 分析业务场景<br>3. 确定功能范围 |
| 技术选型 | 前端：React + TypeScript<br>后端：Node.js + Express<br>数据库：MongoDB |

Abreviaturas y enlaces:

| 技术栈 | 说明 | 官网 |
|--------|------|------|
| React | 用户界面库 | [链接](https://reactjs.org) |
| Vue.js | 渐进式框架 | [链接](https://vuejs.org) |
| Angular | 完整的框架 | [链接](https://angular.io) |

Caracteres especiales en las tablas

Algunos caracteres tienen un significado especial en las tablas y deben escaparse:

| 字符 | 转义方法 | 示例 |
|------|----------|------|
| 竖线 | `\|` | 显示 \| 符号 |
| 反斜杠 | `\\` | 显示 \\ 符号 |
| HTML | 直接使用 | <code>&lt;div&gt;</code> |
