Sobreajuste, subajuste, sesgo y varianza

En el mundo del aprendizaje automático, construir un modelo es como entrenar a un estudiante; nuestro objetivo es que esteestudianteno solo pueda memorizar los ejemplos del libro de texto (datos de entrenamiento), sino que también comprenda profundamente los principios subyacentes, logrando así buenos resultados en preguntas de examen completamente nuevas y nunca antes vistas (datos de prueba). Sin embargo, esteestudiantepuede encontrarse con dos problemas típicos durante el proceso de aprendizaje:

  • uno es aprender de manera demasiado rígida, limitándose a aplicar mecánicamente los ejemplos (subajuste）；
  • el otro es aprender de manera demasiado astuta, memorizando incluso los signos de puntuación y las características de la escritura de los ejemplos, lo que lo deja perplejo ante problemas nuevos (sobreajuste）。

Comprenderel sobreajuste 与 y el subajuste, así como los conceptos teóricos más profundos que hay detrás —sesgo 与 varianza, es un paso clave para que todo profesional del aprendizaje automático pase de principiante a experto. Explican por qué el modelo comete errores y nos señalan la dirección para mejorar el modelo.

I. Conceptos clave: el rendimiento del modelo y el estado de "ajuste"

Primero, comprendamos a través de un ejemplo intuitivo qué es elajuste. Supongamos que queremos ajustar un conjunto de datos de puntos dispersos con un modelo matemático.

Nuestro objetivo es encontrar una curva (modelo) que describa de la mejor manera la regla que reflejan estos puntos azules (datos).

El grado en que el modelo describe los datos es elajuste。

1. Subajuste

El subajustese refiere a un modelo demasiado simple que no puede capturar las reglas o patrones básicos de los datos. Es como un estudiante que solo ha aprendido a sumar pero quiere resolver problemas de cálculo.

  • Manifestación: el modelo en losdatos de entrenamientotiene un rendimiento deficiente (por ejemplo, baja precisión, gran error).
  • Causa: la complejidad del modelo es demasiado baja, las características son insuficientes o el entrenamiento es inadecuado.
  • Analogía: usar una línea recta (polinomio de grado 1) para ajustar datos con una tendencia claramente curva.

3. Sobreajuste

El sobreajustese refiere a un modelo demasiado complejo que no solo aprende las reglas reales de los datos, sino que también "memoriza" el ruido aleatorio y los valores atípicos de los datos de entrenamiento.

  • Manifestación: el modelo en losdatos de entrenamientotiene un rendimiento excelente (error mínimo), pero en losdatos nuevos y no vistossu rendimiento cae drásticamente y su capacidad de generalización es deficiente.
  • Causa: la complejidad del modelo es demasiado alta y la cantidad de datos de entrenamiento es demasiado pequeña.
  • Analogía: ajustar los datos con un polinomio de grado muy alto (por ejemplo, grado 15), lo que hace que la curva pase por casi todos los puntos y se distorsione extremadamente.

II. Fundamento teórico: descomposición de sesgo y varianza

en:

sesgo² + varianza + error irreducible1. SesgoDefinición: la diferencia entre el。

1. Sesgo

  • (es decir, la predicción media) y el valor real. Refleja elerror sistemático, es decir, si la suposición del modelo sobre la naturaleza del problema es incorrecta.Manifestaciones de un sesgo alto系统性错误, es decir, si las suposiciones del modelo sobre la naturaleza del problema son erróneas.
  • Manifestaciones de alto sesgo: El modelo es demasiado simple, no puede capturar las características de los datos, lo que lleva asubajuste. No importa con qué datos se entrene, el resultado se desvía del valor real.
  • Ejemplo: Siempre usar el modelo lineal simple "precio = área × 1000" para predecir diferentes casas, ignorando factores importantes como la ubicación o el piso; esto es un sesgo alto.

2. Varianza

  • Definición: el rango de fluctuaciónde los propios valores predichos por el modelo.. Refleja la sensibilidad del modeloal ruido aleatorioen los datos de entrenamiento.
  • Manifestación de alta varianza: el modelo es demasiado complejo y reacciona excesivamente a pequeñas variaciones en los datos de entrenamiento (incluido el ruido), lo que lleva asobreajuste. Si se entrena con otro conjunto de datos, el modelo resultante puede ser completamente diferente.
  • Ejemplo: una red neuronal profunda, sin restricciones, puede generar un conjunto de reglas de predicción completamente diferente y extremadamente complejo para cada conjunto de datos de entrenamiento único; esto es alta varianza.

3. Compensación sesgo-varianza

Este es un equilibrio central en el aprendizaje automático.No podemos minimizar el sesgo y la varianza al mismo tiempo.

  • Aumentar la complejidad del modelo: normalmente puedereducir el sesgo(el modelo se vuelve más capaz), peroaumentar la varianza(es más fácil aprender ruido).
  • Reducir la complejidad del modelo: normalmente puedereducir la varianza(el modelo es más estable), peroaumentar el sesgo(el modelo se vuelve menos capaz).

Nuestro objetivo es encontrar el "punto óptimo" en el gráfico para minimizar el error total.

III. Diagnóstico y estrategias de solución

¿Cómo determinar en qué estado se encuentra el modelo? ¿Cómo solucionarlo?

1. Método de diagnóstico: curva de aprendizaje

La curva de aprendizaje traza el rendimiento del modelo enel conjunto de entrenamiento和el conjunto de validación(como el error) a medida queel número de muestras de entrenamiento或la complejidad del modelocambian.

Ejemplo

# Usar solo una característica (más adecuado para la demostración de regresión polinómica)

# Definir la función de trazado de la curva de aprendizaje (versión optimizada)
def plot_learning_curve(estimator, title, X, y, cv=5, train_sizes=np.linspace(0.1, 1.0, 10)):
    """
Trazar la curva de aprendizaje
Parámetros:
estimator: estimador del modelo
title: título del gráfico
X: datos de características
y: variable objetivo
cv: número de pliegues de validación cruzada
train_sizes: proporción de muestras de entrenamiento
    """
    # Obtener datos de la curva de aprendizaje
    train_sizes_abs, train_scores, test_scores = learning_curve(
        estimator, X, y, cv=cv, scoring='neg_mean_squared_error',
        train_sizes=train_sizes, random_state=42, n_jobs=-1
    )
   
    # Calcular media y desviación estándar
    train_scores_mean = -train_scores.mean(axis=1)
    train_scores_std = train_scores.std(axis=1)
    test_scores_mean = -test_scores.mean(axis=1)
    test_scores_std = test_scores.std(axis=1)
   
    # Trazar la curva de aprendizaje
    plt.figure(figsize=(10, 6))
    plt.fill_between(train_sizes_abs,
                     train_scores_mean - train_scores_std,
                     train_scores_mean + train_scores_std,
                     alpha=0.1, color='r')
    plt.fill_between(train_sizes_abs,
                     test_scores_mean - test_scores_std,
                     test_scores_mean + test_scores_std,
                     alpha=0.1, color='g')
   
    # Trazar la curva de la media
    plt.plot(train_sizes_abs, train_scores_mean, 'o-', color='r', linewidth=2,
             markersize=8, label='MSE del conjunto de entrenamiento')
    plt.plot(train_sizes_abs, test_scores_mean, 'o-', color='g', linewidth=2,
             markersize=8, label='MSE del conjunto de validación')
   
    # Configurar atributos del gráfico
    plt.xlabel('Número de muestras de entrenamiento', fontsize=12)
    plt.ylabel('Error cuadrático medio (MSE)', fontsize=12)
    plt.title(title, fontsize=14, pad=20)
    plt.legend(loc='upper right', fontsize=11)
    plt.tight_layout()
    plt.show()
   
    # Imprimir el rendimiento del modelo en el conjunto de prueba
    estimator.fit(X_train, y_train)
    y_pred = estimator.predict(X_test)
    mse = mean_squared_error(y_test, y_pred)
    print(f{title} - MSE del conjunto de prueba: {mse:.2f})

¿Cómo interpretar la curva de aprendizaje?

Estado de ajuste Error de entrenamiento Error de validación Características de la curva
Subajuste 高 高 Ambas curvas son altas y están muy cerca; agregar datos no ayuda.
Buen ajuste 低 低 Ambas curvas son bajas y están cerca entre sí, alcanzando un punto de equilibrio.
Sobreajuste Muy bajo 高 El error de entrenamiento es muy bajo, pero el error de validación es alto, con una brecha clara en el medio. Agregar datos generalmente acerca ambas curvas.

2. Estrategias de solución

Según el diagnóstico, podemos adoptar diferentes estrategias:

Resolver el subajuste (sesgo alto):

  • Aumentar la complejidad del modelo: usar un modelo más potente (por ejemplo, cambiar de un modelo lineal a un modelo de árbol o red neuronal).
  • Agregar más características: extraer o construir características más significativas.
  • Reducir la regularización: si se usa regularización (como L1, L2), intentar reducir su intensidad.
  • Extender el tiempo de entrenamiento: para modelos iterativos (como redes neuronales), entrenar más épocas.

Resolver el sobreajuste (varianza alta):

  • Obtener más datos de entrenamiento: uno de los métodos más efectivos.
  • Reducir la complejidad del modelo: elegir un modelo más simple (por ejemplo, reducir el grado del polinomio, la profundidad del árbol o el número de capas de la red neuronal).
  • Selección de características: eliminar características irrelevantes o redundantes.
  • Aumentar la regularización：
    • Regularización L1 (Lasso): tiende a producir pesos dispersos, útil para la selección de características.
    • Regularización L2 (Ridge): hace que los pesos decaigan, tendiendo a que todos los pesos sean pequeños.
    • Dropout(para redes neuronales): durante el entrenamiento, "descarta" aleatoriamente una parte de las neuronas.
  • Parada temprana(para modelos iterativos): detener el entrenamiento cuando el error del conjunto de validación deja de disminuir.

    train_error = mean_squared_error(y_train, y_train_pred)
    test_error = mean_squared_error(y_test, y_test_pred)

    train_errors.append(train_error)
    test_errors.append(test_error)

    print(f"Profundidad máxima del árbol: {depth if depth is not None else 'Sin límite'}")
    print(f" MSE del conjunto de entrenamiento: {train_error:.2f}")
    print(f" MSE del conjunto de prueba: {test_error:.2f}")
    print("-" * 30)

# Visualización
plt.figure(figsize=(10, 6))
depths = [str(d) if d else 'Sin límite' for d in max_depths]
x_index = np.arange(len(depths))
width = 0.35

plt.bar(x_index - width/2, train_errors, width, label='Error de entrenamiento', color='skyblue')
plt.bar(x_index + width/2, test_errors, width, label='Error de prueba', color='lightcoral')

plt.xlabel('Profundidad máxima del árbol de decisión (complejidad del modelo)')
plt.ylabel('Error cuadrático medio (MSE)')
plt.title('Equilibrio sesgo-varianza: rendimiento de árboles de decisión con diferente complejidad')
plt.xticks(x_index, depths)
plt.legend()
plt.grid(True, axis='y')
plt.tight_layout()
plt.show()

Resultados del análisis：

  • Profundidad=1: el modelo es muy simple, el error de entrenamiento y de prueba son altos ->Sesgo alto, subajuste。
  • Profundidad=3: A medida que aumenta la complejidad del modelo, ambos errores disminuyen significativamente y están relativamente cerca.Equilibrio entre sesgo y varianza, buen ajuste.。
  • Profundidad=10 o sin límite.: Modelo muy complejo, error de entrenamiento extremadamente bajo, pero el error de prueba comienza a aumentar (o es mucho mayor que el error de entrenamiento).Alta varianza, sobreajuste.。

Resumen

Comprender el sobreajuste, el subajuste, el sesgo y la varianza es la base para construir excelentes modelos de aprendizaje automático. Recuerda este ciclo central:

  1. Entrenar el modelo. -> Evaluar su rendimiento en el conjunto de entrenamiento y en el conjunto de validación.。
  2. Diagnosticar problemas mediante curvas de aprendizaje o comparación de errores.: ¿Es alto sesgo (subajuste) o alta varianza (sobreajuste)?
  3. Aplicar la estrategia correspondiente.(Aumentar complejidad/datos, regularización, etc.) para mejorar.
  4. Volver al paso 1., hasta obtener un modelo satisfactorio y con buena capacidad de generalización en el conjunto de validación.
