MySQL Crear tabla de datos

Para crear una tabla de datos MySQL se necesita la siguiente información:

  • Nombre de la tabla
  • Nombre de los campos de la tabla
  • El tipo de datos de cada campo de la tabla

Sintaxis

La siguiente es la sintaxis general SQL para crear una tabla de datos MySQL:

CREATE TABLE table_name (
    column1 datatype,
    column2 datatype,
    ...
);

Descripción de parámetros:

  • table_namees el nombre de la tabla que deseas crear.
  • column1, column2, ... son los nombres de las columnas de la tabla.
  • datatypees el tipo de datos de cada columna.

A continuación se muestra un ejemplo concreto para crear una tabla de usuariosusers：

Ejemplo

CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL,
    birthdate DATE,
    is_active BOOLEAN DEFAULT TRUE
);

Análisis del ejemplo:

  • id: id de usuario, tipo entero, autoincremental, como clave primaria.
  • username: nombre de usuario, cadena de longitud variable, no se permite nulo.
  • email: correo electrónico del usuario, cadena de longitud variable, no se permite nulo.
  • birthdate: fecha de nacimiento del usuario, tipo fecha.
  • is_active: si el usuario está activado, tipo booleano, valor predeterminado true.

Lo anterior es solo un ejemplo simple, utiliza algunos tipos de datos comunes incluyendo INT, VARCHAR, DATE, BOOLEAN. Puedes elegir diferentes tipos de datos según tus necesidades reales. La palabra clave AUTO_INCREMENT se usa para crear una columna autoincremental, y PRIMARY KEY se usa para definir la clave primaria.

Si deseas especificar el motor de datos, el conjunto de caracteres y la regla de ordenamiento al crear la tabla, puedes usarCHARACTER SET 和 COLLATEla cláusula:

Ejemplo

CREATE TABLE mytable (
    id INT PRIMARY KEY,
    name VARCHAR(50)
) CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;

El código anterior crea una tabla que utiliza el conjunto de caracteres utf8mb4 y la regla de ordenamiento utf8mb4_general_ci.

En el siguiente ejemplo crearemos la tabla de datos runoob_tbl en la base de datos RUNOOB:

Ejemplo

CREATE TABLE IF NOT EXISTS `runoob_tbl`(
   `runoob_id` INT UNSIGNED AUTO_INCREMENT,
   `runoob_title` VARCHAR(100) NOT NULL,
   `runoob_author` VARCHAR(40) NOT NULL,
   `submission_date` DATE,
   PRIMARY KEY ( `runoob_id` )
)ENGINE=InnoDB DEFAULT CHARSET=utf8;

Análisis del ejemplo:

  • Si no quieres que el campo sea空puedes establecer el atributo del campo comoNOT NULL, como en el ejemplo anterior con los campos runoob_title y runoob_author, si al operar la base de datos ingresas datos vacíos en ese campo, se producirá un error.

  • AUTO_INCREMENTDefine la propiedad de autoincremento de la columna, generalmente se usa para la clave primaria, el valor aumentará automáticamente en 1.
  • PRIMARY KEYLa palabra clave se usa para definir la columna como clave primaria. Puedes usar múltiples columnas para definir la clave primaria, separadas por comas,separadas.
  • ENGINEEstablece el motor de almacenamiento,CHARSETEstablece la codificación.

Crear tabla mediante el símbolo del sistema

A través de mysql>la ventana de comandos puede crear tablas de datos MySQL de forma muy sencilla.

Puedes usar la sentencia SQLCREATE TABLEpara crear la tabla de datos.

Ejemplo

El siguiente es un ejemplo de creación de la tabla de datos runoob_tbl:

Ejemplo

root@host# mysql -u root -p
Enter password:*******
mysql> USE RUNOOB;
DATABASE changed
mysql> CREATE TABLE runoob_tbl(
   -> runoob_id INT NOT NULL AUTO_INCREMENT,
   -> runoob_title VARCHAR(100) NOT NULL,
   -> runoob_author VARCHAR(40) NOT NULL,
   -> submission_date DATE,
   -> PRIMARY KEY ( runoob_id )
   -> )ENGINE=InnoDB DEFAULT CHARSET=utf8;
Query OK, 0 ROWS affected (0.16 sec)
mysql>

Nota:El terminador de comandos MySQL es el punto y coma; 。

Nota: ->es el identificador de nueva línea, no lo copies.

Crear tabla de datos usando script PHP

Puedes usar la función de PHPmysqli_query()para crear una tabla de datos en una base de datos existente.

Esta función tiene dos parámetros; devuelve TRUE si la ejecución es exitosa, de lo contrario devuelve FALSE.

Sintaxis

mysqli_query(connection,query,resultmode);
Parámetros Descripción
connection Obligatorio. Especifica la conexión MySQL que se utilizará.
query Obligatorio. Especifica la cadena de consulta.
resultmode

Opcional. Una constante. Puede ser cualquiera de los siguientes valores:

  • MYSQLI_USE_RESULT (si necesitas recuperar una gran cantidad de datos, usa este)
  • MYSQLI_STORE_RESULT (por defecto)

Ejemplo

El siguiente ejemplo utiliza un script PHP para crear la tabla de datos:

Crear tabla de datos

<?php $dbhost = 'localhost'; //Dirección del servidor MySQL $dbuser = 'root'; //nombre de usuario de MySQL $dbpass = '123456'; //contraseña del usuario de MySQL $conn = mysqli_connect($dbhost, $dbuser, $dbpass); if(! $conn ) { die('Error de conexión:' . mysqli_error($conn)); } echo 'Conexión exitosa<br />'; $sql = "CREATE TABLE runoob_tbl( ". "runoob_id INT NOT NULL AUTO_INCREMENT, ". "runoob_title VARCHAR(100) NOT NULL, ". "runoob_author VARCHAR(40) NOT NULL, ". "submission_date DATE, ". "PRIMARY KEY ( runoob_id ))ENGINE=InnoDB DEFAULT CHARSET=utf8; "; mysqli_select_db( $conn, 'RUNOOB' ); $retval = mysqli_query( $conn, $sql ); if(! $retval ) { die('Error al crear la tabla de datos:' . mysqli_error($conn)); } echo "Tabla de datos creada exitosamente\n"; mysqli_close($conn); ?>

    Los atributos de los campos MySQL deben configurarse como NOT NULL siempre que sea posible

    A menos que tengas una razón muy especial para usar valores NULL, siempre debes mantener tus campos como NOT NULL. Esto parece un poco controvertido, sigue leyendo.

    1、Primero, tenemos que aclarar el concepto de valor vacío"" 和 NULLconcepto:

    • 1) El valor vacío no ocupa espacio
    • 2) NULL en MySQL en realidad ocupa espacio

    El llamado NULL es que no hay nada, ni siquiera\0ni siquiera hay,\0En las cadenas, '\0' es el terminador, pero en la memoria física ocupa espacio, equivale a un byte, mientras que NULL es que ni siquiera tiene ese byte.

    2、En segundo lugar, en la base de datos se distingue estrictamente. Cualquier operación de un número con NULL da como resultado NULL. Para determinar si un valor es igual a NULL, no puedes simplemente usar =, sino que debes usar la palabra clave IS NULL.

    3、Si el campo col1 de la base de datos se establece como NOT NULL, solo indica que ese campo no puede ser NULL, es decir, solo cuando:

    INSERT INTO table1(col1) VALUES(NULL);

    En este caso la base de datos mostrará un error, mientras que:

    INSERT INTO table1(col1) VALUES('');

    no mostrará error.

    (Si el campo es una ID autoincremental, la primera frase no mostrará error; esto no significa que pueda ser NULL, sino que el sistema de base de datos lo rellenará según el valor predeterminado establecido para la ID, o si es un campo autoincremental, realizará operaciones predeterminadas como aumentar automáticamente en uno.)

    4、Las columnas que contienen valores vacíos son difíciles de optimizar en las consultas, y al indexar tablas no se almacenan valores NULL, por lo que si un campo indexado puede ser NULL, la eficiencia del índice disminuirá mucho. Porque hacen que el índice, las estadísticas del índice y las operaciones de comparación sean más complejas. Deberías usar 0, un valor especial o una cadena vacía en lugar de valores vacíos.

    5、Al realizar consultas con unión de tablas, por ejemplo LEFT JOIN table2, si no hay registros, los campos de table2 que se obtienen son todos null. Si algunos campos de table2 pueden ser null por sí mismos, a menos que se consulten los campos not null de table2, es difícil distinguir si no hay registros asociados u otras situaciones.

    Motores de almacenamiento MySQL InnoDB y MyISAM

    ENGINE = innodb

    El motor de almacenamiento es InnoDB. InnoDB es el primer motor de almacenamiento de datos en MySQL que proporciona restricciones de clave externa. Además del procesamiento de transacciones, InnoDB también admite bloqueos a nivel de fila y proporciona lecturas consistentes sin bloqueo como Oracle, lo que puede aumentar el número de usuarios de lectura concurrente y mejorar el rendimiento, sin aumentar el número de bloqueos. El objetivo de diseño de InnoDB es maximizar el rendimiento al manejar grandes volúmenes de datos, y su uso de CPU es el más eficiente entre todos los motores de bases de datos relacionales basados en disco.

    InnoDB es un sistema de base de datos completo que se ejecuta en segundo plano de MySQL. InnoDB tiene su propio grupo de búferes, que puede almacenar en búfer datos e índices. InnoDB también guarda datos e índices en un espacio de tabla, que puede contener varios archivos. Esto es completamente diferente de las tablas MyISAM, donde las tablas se almacenan en archivos individuales. El tamaño de la tabla InnoDB solo está limitado por el tamaño de archivo del sistema operativo, generalmente 2 GB.
