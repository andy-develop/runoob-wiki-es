Interacción con modelos de Ollama

Ollama ofrece múltiples formas de interactuar con los modelos; la más común es realizar operaciones de inferencia a través de la línea de comandos.

1. Interacción por línea de comandos

Interactuar directamente con el modelo mediante la línea de comandos es la forma más sencilla.

Ejecutar el modelo

Useollama runel comando para iniciar el modelo y entrar en el modo interactivo:

ollama run <model-name>

Por ejemplo, descargamos el modelo qwen3.5:

Ejemplo

ollama run qwen3.5

Una vez iniciado, puede escribir directamente preguntas o instrucciones, y el modelo generará respuestas en tiempo real.

>>> 你好，你能帮我写一段代码吗？
当然可以。但是首先我想知道您希望在哪种编程语言中实现这个功能（例如Python、JavaScript等）和要解决什么问题或者完成的任务是什么样的例子呢？这样我们可以为您提供更准确的
内容，同时也方便我帮助你写出最适合您的代码片段。


>>> 写一段 python hello world
当然可以！这是一个简单的 "Hello, World!" 程序：

```python
print("Hello, World!")
```
这个脚本会输出 `Hello, World!`，并将其打印到控制台上。这只是最基本的 Python Hello world示例；Python是一种解释型、通用型的编程语言以其简洁性和易读性而闻名。它还允许
用户在代码中插入变量和表达式来创建复杂的行为。

Salir del modo interactivo

En el modo interactivo, escriba/byeo presioneCtrl+d para salir.

2. Interacción con un solo comando

Si solo necesita que el modelo genere una respuesta, puede pasar la entrada directamente en la línea de comandos.

Uso de entrada por tubería (pipe)

Pase la entrada al modelo a través de la tubería (pipe):

Ejemplo

echo "¿Quién eres?" | ollama run qwen3.5

Uso de argumentos de línea de comandos

在 Python 中，"Hello World!" 通常是这段简单的脚本：
```python
print("Hello World!")
```
当你运行这个程序时，它会输出 `Hello, World`。这是因为 print() 函数将字符串 "Hello, World" 打印到标准输出设备 (stdout) - 也就是你的屏幕上显示的信息（在这种情况下是命
令行终端或类似的工具中运行 Python 脚本时，它会直接写入控制台。

3. Conversación de múltiples turnos

Ollama admite conversaciones de múltiples turnos; el modelo puede recordar el contexto.

Ejemplo

>>>Hola, ¿puedes ayudarme a escribir un fragmento de código en Python?
¡Claro que sí! Por favor, dime qué funcionalidad necesitas implementar.

>>>Quiero escribir una función que calcule la secuencia de Fibonacci.
Bien, a continuación tienes una función simple en Python:
def fibonacci(n):
    if n <= 1:
        return n
    else:
        return fibonacci(n-1) + fibonacci(n-2)

4. Entrada de archivo

Se puede pasar el contenido de un archivo como entrada al modelo.

Supongamos que el contenido del archivo input.txt es:

 Python 的 hello world 代码？

Pase el contenido del archivo input.txt como entrada:

ollama run qwen3.5 < input.txt

5. Prompt personalizado

Defina prompts personalizados o instrucciones del sistema mediante el Modelfile para que el modelo siga reglas específicas durante la interacción.

Crear un modelo personalizado

Escriba un Modelfile:

Ejemplo

FROM qwen3.5
SYSTEM "Eres un asistente de programación, especializado en ayudar a los usuarios a escribir código."
Luego cree el modelo personalizado:
ollama create ejemplo-coder -f ./Modelfile

Ejecutar el modelo personalizado:

ollama run ejemplo-coder

6. Registro de interacciones

Ollama guarda logs de interacción para facilitar la depuración y el análisis.

Ver logs:

ollama logs
