Introducción a los módulos básicos de C++ OpenCV

OpenCV es una potente biblioteca de visión por computadora que contiene múltiples módulos, cada uno enfocado en diferentes tareas.

A continuación se presentan algunos de los módulos principales de OpenCV:

1. Módulo Core

coreEl módulo Core es el módulo central de OpenCV y proporciona estructuras de datos y funciones básicas.

Funciones principales

  • Estructuras de datos básicas：

    • Mat: se utilizan para almacenar datos de imágenes y matrices.

    • Point、Size、Rect: se utilizan para representar puntos, dimensiones y regiones rectangulares.

    • Scalar: se utilizan para representar colores o valores de píxeles.

  • Operaciones con matrices：

    • Creación, copia, conversión, operaciones aritméticas de matrices, etc.

  • E/S de archivos：

    • Lectura y guardado de imágenes, videos, archivos XML/YAML, etc.

  • Gestión de memoria：

    • Gestión automática de memoria, compatible con conteo de referencias.

Ejemplo

#include <opencv2/core.hpp>
#include <iostream>

using namespace cv;
using namespace std;

int main() {
    // Crea una matriz de 3x3
    Mat mat = (Mat_<int>(3, 3) << 1, 2, 3, 4, 5, 6, 7, 8, 9);

    // Muestra la matriz
    cout << "Matrix:\n" << mat << endl;

    // Accede a los elementos de la matriz
    int value = mat.at<int>(1, 1);
    cout << "Value at (1, 1): " << value << endl;

    return 0;
}

2. Módulo Imgproc

imgprocEl módulo Imgproc proporciona funciones de procesamiento de imágenes, incluyendo filtrado, transformaciones geométricas, conversión de espacios de color, etc.

Funciones principales

  • Filtrado de imágenes：

    • Filtrado medio, filtrado gaussiano, filtrado mediano, etc.

  • Transformaciones geométricas：

    • Escalado, rotación, transformación afín, transformación de perspectiva, etc.

  • Conversión de espacios de color：

    • Conversión de RGB a escala de grises, HSV, Lab y otros espacios de color.

  • Detección de bordes：

    • Algoritmos de detección de bordes como Canny, Sobel, Laplacian, etc.

  • Operaciones morfológicas：

    • Erosión, dilatación, apertura, cierre, etc.

  • Umbralizado：

    • Umbralizado simple, umbralizado adaptativo, etc.

Ejemplo

#include <opencv2/imgproc.hpp>
#include <opencv2/highgui.hpp>

using namespace cv;

int main() {
    // Lee la imagen
    Mat image = imread("test.jpg");
    if (image.empty()) return -1;

    // Convierte a imagen en escala de grises
    Mat grayImage;
    cvtColor(image, grayImage, COLOR_BGR2GRAY);

    // Filtro gaussiano
    Mat blurredImage;
    GaussianBlur(grayImage, blurredImage, Size(5, 5), 0);

    // Muestra el resultado
    imshow("Original Image", image);
    imshow("Blurred Image", blurredImage);
    waitKey(0);

    return 0;
}

3. Módulo Highgui

highguiEl módulo Highgui proporciona visualización de imágenes y videos, gestión de ventanas y funciones de interacción con el usuario.

Funciones principales

  • Visualización de imágenes：

    • Crear ventanas, mostrar imágenes, esperar la entrada del usuario.

  • Captura de video：

    • Leer fotogramas desde una cámara o un archivo de video.

  • Interacción del usuario：

    • Eventos de ratón, barras deslizantes, botones, etc.

Ejemplo

#include <opencv2/highgui.hpp>

using namespace cv;

int main() {
    // Lee la imagen
    Mat image = imread("test.jpg");
    if (image.empty()) return -1;

    // Crea una ventana y muestra la imagen
    namedWindow("Display Window", WINDOW_AUTOSIZE);
    imshow("Display Window", image);

    // Espera a que el usuario pulse una tecla
    waitKey(0);

    // Cierra la ventana
    destroyAllWindows();

    return 0;
}

4. Módulo Video

videoEl módulo Video proporciona funciones de procesamiento de video, incluyendo captura de video, sustracción de fondo, cálculo de flujo óptico, etc.

Funciones principales

  • Captura de video：

    • Leer fotogramas desde una cámara o un archivo de video.

  • Sustracción de fondo：

    • Extraer los objetos en primer plano del video.

  • Cálculo de flujo óptico：

    • Calcular el movimiento de los objetos en una imagen.

Ejemplo

#include <opencv2/videoio.hpp>
#include <opencv2/highgui.hpp>

using namespace cv;

int main() {
    // Abre la cámara
    VideoCapture cap(0);
    if (!cap.isOpened()) return -1;

    Mat frame;
    while (true) {
        // Lee un fotograma
        cap >> frame;
        if (frame.empty()) break;

        // Muestra el fotograma
        imshow("Camera Feed", frame);

        // Presiona ESC para salir
        if (waitKey(30) == 27) break;
    }

    // Libera la cámara y cierra la ventana
    cap.release();
    destroyAllWindows();

    return 0;
}

5. Módulo Calib3d

calib3dEl módulo Calib3d proporciona funciones como calibración de cámaras, reconstrucción 3D, estimación de pose, etc.

Funciones principales

  • Calibración de cámaras：

    • Calcular los parámetros intrínsecos de la cámara y los coeficientes de distorsión.

  • Reconstrucción 3D：

    • Reconstruir escenas 3D a partir de imágenes multivista.

  • Estimación de pose：

    • Estimar la pose 3D de los objetos.

Ejemplo

#include <opencv2/calib3d.hpp>
#include <opencv2/highgui.hpp>

using namespace cv;

int main() {
    // Lee la imagen
    Mat image1 = imread("left.jpg");
    Mat image2 = imread("right.jpg");
    if (image1.empty() || image2.empty()) return -1;

    // Detección y coincidencia de puntos característicos
    Ptr<Feature2D> detector = ORB::create();
    vector<KeyPoint> keypoints1, keypoints2;
    Mat descriptors1, descriptors2;
    detector->detectAndCompute(image1, noArray(), keypoints1, descriptors1);
    detector->detectAndCompute(image2, noArray(), keypoints2, descriptors2);

    BFMatcher matcher(NORM_HAMMING);
    vector<DMatch> matches;
    matcher.match(descriptors1, descriptors2, matches);

    // Calcula la matriz fundamental
    vector<Point2f> points1, points2;
    for (const auto& match : matches) {
        points1.push_back(keypoints1[match.queryIdx].pt);
        points2.push_back(keypoints2[match.trainIdx].pt);
    }
    Mat fundamentalMatrix = findFundamentalMat(points1, points2, FM_RANSAC);

    // Muestra la matriz fundamental
    cout << "Fundamental Matrix:\n" << fundamentalMatrix << endl;

    return 0;
}

6. Módulo DNN

dnnEl módulo DNN proporciona funciones de carga e inferencia de modelos de aprendizaje profundo.

Funciones principales

  • Carga de modelos：

    • Compatible con modelos de frameworks como TensorFlow, PyTorch, Caffe, etc.

  • Inferencia：

    • Clasificación de imágenes, detección de objetos, segmentación semántica, etc.

Ejemplo

#include <opencv2/dnn.hpp>
#include <opencv2/highgui.hpp>

using namespace cv;
using namespace dnn;

int main() {
    // Carga el modelo
    Net net = readNetFromTensorflow("model.pb", "config.pbtxt");

    // Lee la imagen
    Mat image = imread("test.jpg");
    if (image.empty()) return -1;

    // Preprocesamiento
    Mat blob = blobFromImage(image, 1.0, Size(300, 300), Scalar(127.5, 127.5, 127.5), true, false);
    net.setInput(blob);

    // Inferencia
    Mat output = net.forward();

    // Procesa la salida
    // ...

    return 0;
}
