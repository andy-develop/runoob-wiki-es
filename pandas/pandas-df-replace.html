Función df.replace() de Pandas

Funciones comunes de Pandas

df.replace()Es una función de Pandas utilizada para reemplazar datos en un DataFrame.

El reemplazo de datos es una operación común en la limpieza de datos,replace()puede ayudarte a reemplazar valores específicos por nuevos valores, y admite múltiples formas flexibles como reemplazo de un solo valor, reemplazo de múltiples valores, reemplazo con expresiones regulares, etc. Esto es muy útil en escenarios como el manejo de valores atípicos, la unificación de formatos de datos, la conversión de codificaciones, entre otros.

Sintaxis básica y parámetros

replace()Es una función miembro de DataFrame, mediante el operador de punto.se invoca.

Formato de sintaxis

DataFrame.replace(to_replace=None, value=None, inplace=False, limit=None, regex=False, method='pad')

Descripción de parámetros

Parámetro Tipo ¿Obligatorio? Descripción Valor predeterminado
to_replace str, regex, list, dict, int, float, None Obligatorio El valor a reemplazar. Puede ser un solo valor, una lista de valores, un diccionario, una expresión regular, etc. None
value scalar, dict, list, str, regex, None Opcional El valor de reemplazo. Sito_replacees un diccionario, este parámetro puede omitirse; si no es un diccionario, este parámetro es obligatorio. None
inplace bool Opcional Si esTrue, modifica directamente el DataFrame original y no devuelve un nuevo objeto; si esFalse, devuelve un nuevo DataFrame y los datos originales no cambian. False
limit int Opcional Especifica el número máximo de reemplazos. None
regex bool o str Opcional Si esTrue, seto_replacetrata como expresión regular. False
method str Opcional Cuandoto_replaceSe usa cuando es una lista.'pad'o'ffill'Indica relleno hacia adelante;'backfill'o'bfill'Indica relleno hacia atrás. 'pad'

Descripción del valor de retorno

  • Devuelve un nuevo DataFrame (siinplace=False), oNone(siinplace=True）。
  • Los valores especificados han sido reemplazados en el DataFrame devuelto.

Reemplaza un valor específico en el DataFrame por un nuevo valor.

}
df = pd.DataFrame(data)

print("datos originales:")
print(df)
print("=" * 50)

# Reemplazar Tecnología por "研Publicar"
df_replaced = df.replace('Tecnología', Investigación y desarrollo)

print(Datos reemplazados:)
print(df_replaced)

Ejemplo 4: Reemplazo mediante expresiones regulares

regex=TrueEl parámetro permite usar expresiones regulares para el reemplazo, lo que resulta muy útil al procesar texto que coincide con patrones.

Ejemplo

import pandas as pd

# Crear un DataFrame que contenga datos que requieren procesamiento con expresiones regulares
data = {
    'Nombre': ['Zhang San', 'Li Si', 'Wang Wu', 'Zhao Liu'],
    Teléfono: ['138-0000-0000', '139-1111-1111', '137-2222-2222', '136-3333-3333'],
    Observaciones: [Normal, Clientes VIP, Normal, Cliente VIP]
}
df = pd.DataFrame(data)

print("datos originales:")
print(df)
print("=" * 50)

# Usar expresiones regulares para reemplazar separadores en teléfonos
df_replaced = df.replace(to_replace=r'(d{3})-(d{4})-(d{4})', value=r'1****3', regex=True)

print("Datos después de reemplazar el número de teléfono (ocultando los 4 dígitos del medio):")
print(df_replaced)
print("=" * 50)

# Reemplazar "cliente VIP" en la nota (puede haber diferencias de espacios)
df_replaced2 = df.replace(to_replace=r'VIPs*cliente?', value='VIP', regex=True)

print(Datos después de unificar las notas VIP:)
print(df_replaced2)

替换电话号码（隐藏中间4位）后的数据：

Análisis del código:

  • El primer ejemplo usa la expresión regular(d{3})-(d{4})-(d{4})para coincidir con el formato de número de teléfono y reemplazarlo por1****3, ocultando los 4 dígitos centrales.

Ejemplo 5: Reemplazo de valores faltantes NaN

replace()También se puede usar para reemplazar valores faltantesNaN, lo cual es una operación común en la limpieza de datos.

Ejemplo

import pandas as pd
import numpy as np

# Crear un DataFrame que contenga valores faltantes
data = {
    'Nombre': ['Zhang San', 'Li Si', 'Wang Wu', 'Zhao Liu'],
    'Edad': [25, np.nan, 35, np.nan],
    'Salario': [5000, 6000, np.nan, 8000]
}
df = pd.DataFrame(data)

print("Datos originales:")
print(df)
print("=" * 50)

# Reemplazar NaN por 0
df_replaced = df.replace(np.nan, 0)

print("Datos después de reemplazar NaN por 0:")
print(df_replaced)
print("=" * 50)

# Reemplazar NaN con otro valor, como "desconocido"
df_replaced2 = df.replace(np.nan, 'desconocido')

print("Datos después de reemplazar NaN por 'desconocido':")
print(df_replaced2)

Ejemplo 6: Reemplazo de valores numéricos

Se pueden reemplazar datos de tipo numérico para realizar estandarización de datos o tratamiento de valores atípicos.

Ejemplo

import pandas as pd

# Crear un DataFrame con valores atípicos
data = {
    'Estudiante': ['Zhang San', 'Li Si', 'Wang Wu', 'Zhao Liu', 'Qian Qi'],
    'Calificación': [85, 150, 78, 92, -10]  # 150 y -10 son valores atípicos
}
df = pd.DataFrame(data)

print("Datos originales:")
print(df)
print("=" * 50)

# Reemplazar los valores atípicos por valores en un rango razonable
df_replaced = df.replace({150: 100, -10: 0})

print("Datos después de reemplazar los valores atípicos:")
print(df_replaced)
print("=" * 50)

# Usar una condición para reemplazar múltiples valores
df_replaced2 = df.replace(to_replace=[150, -10], value=[100, 0])

print("Usar una lista para reemplazar múltiples valores:")
print(df_replaced2)

Análisis del código:

  • Diccionario{150: 100, -10: 0}Reemplace el valor atípico 150 por 100, y -10 por 0.
  • Lista[150, -10]y[100, 0]Especifique respectivamente los valores a reemplazar y los valores de reemplazo, correspondiendo en orden.

Notas

  • replace()De forma predeterminada, no se modifica el DataFrame original; si desea modificarlo en el lugar, useinplace=Trueparámetro.
  • Al usar expresiones regulares, asegúrese de que la sintaxis de la expresión regular sea correcta; las expresiones regulares complejas pueden causar resultados inesperados.
  • La operación de reemplazo se basa en la coincidencia de valores y no cambiará el tipo de datos.
  • Tenga en cuenta la distinción entre mayúsculas y minúsculas; 'técnica' y 'Técnica' son valores diferentes.
  • Antes de realizar el reemplazo de datos, se recomienda hacer una copia de seguridad de los datos originales para poder compararlos y rastrearlos.
