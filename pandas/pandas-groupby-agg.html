Pandas groupby.agg() función

Funciones comunes de Pandas

groupby.agg()Es una de las funciones de agregación más potentes de Pandas, que permite aplicar simultáneamente múltiples funciones de agregación diferentes a los datos agrupados.

与 sum()、mean()A diferencia de las funciones de agregación individuales,agg()puede calcular varios indicadores estadísticos de una sola vez, por ejemplo, calcular simultáneamente la suma, el promedio, el máximo, el mínimo de cada grupo, etc.

En el análisis de datos, a menudo es necesario realizar múltiples análisis estadísticos sobre los datos al mismo tiempo,agg()la función puede hacer que este proceso sea conciso y eficiente.

Sintaxis básica y parámetros

agg()Es una función miembro del objeto GroupBy; primero debe usargroupby()agrupar y luego llamarla.

Formato de sintaxis

GroupBy.agg(func=None, axis=0, *args, engine=None, engine_kwargs=None, **kwargs)

Descripción de parámetros

Parámetro Tipo Descripción Valor predeterminado
func str, list, dict o callable Función de agregación. Puede ser un solo nombre de función, una lista de funciones, o un diccionario que especifica diferentes funciones para cada columna. None
axis int La dirección del eje para aplicar la agregación; 0 indica por filas (dimensión de agrupación), 1 indica por columnas. 0
args tuple Parámetros posicionales adicionales que se pasan a la función de agregación. ()
engine str Especifica el motor de cálculo; puede ser 'cython' o 'numba'. None indica que Pandas lo elige automáticamente. None
engine_kwargs dict Diccionario de parámetros adicionales que se pasan al motor subyacente. None

Valor de retorno

  • Tipo de retorno：Series 或 DataFrame
  • Descripción: Devuelve el resultado de la agregación por grupos; la estructura del resultado depende del parámetro func y de la forma de agrupación.

Ejemplos

A través de una serie de ejemplos de simples a complejos, dominemos completamentegroupby.agg()el uso de la función.

Ejemplo 1: Uso de funciones de agregación integradas

La forma más sencilla es usar directamente los nombres de las funciones de agregación integradas de Pandas, como 'sum', 'mean', 'max', 'min', 'count', etc.

Ejemplo

import pandas as pd

# 创建销售数据 DataFrame
data = {
    '地区': ['华北', '华东', '华南', '华北', '华东', '华南', '华北', '华东'],
    '产品': ['A', 'B', 'C', 'B', 'A', 'C', 'A', 'B'],
    '销售额': [1000, 2000, 1500, 1800, 2200, 1600, 1200, 2100],
    '数量': [10, 20, 15, 18, 22, 16, 12, 21]
}
df = pd.DataFrame(data)

print("原始销售数据：")
print(df)
print()

# 按"地区"分组，对"销售额"列同时应用多个聚合函数
# 使用字符串列表指定多个聚合函数
result = df.groupby('地区')['销售额'].agg(['sum', 'mean', 'max', 'min', 'count'])

print("每个地区销售额的汇总统计：")
print(result)
print()

# 同时对"销售额"和"数量"列进行聚合
result_all = df.groupby('地区').agg({
    '销售额': ['sum', 'mean'],
    '数量': ['sum', 'mean']
})

print("各地区销售和数量的综合统计：")
print(result_all)

Análisis del código:

  1. ['sum', 'mean', 'max', 'min', 'count']Usando una lista se pueden especificar múltiples funciones de agregación a la vez.
  2. El resultado devuelto es un DataFrame; los nombres de las columnas se componen del nombre de la función y del nombre de la columna original (índice de columnas de varios niveles).
  3. Usando un diccionario se pueden especificar diferentes funciones de agregación para diferentes columnas.

Ejemplo 2: Uso de funciones de agregación personalizadas

Además de las funciones integradas,agg()también admite funciones personalizadas, lo que amplía enormemente su flexibilidad.

Ejemplo

import pandas as pd
import numpy as np

# 创建学生成绩数据
data = {
    '班级': ['A', 'A', 'A', 'B', 'B', 'B', 'B', 'A'],
    '姓名': ['张三', '李四', '王五', '赵六', '孙七', '周八', '吴九', '郑十'],
    '语文': [85, 92, 78, 88, 95, 82, 90, 87],
    '数学': [90, 85, 92, 78, 88, 91, 85, 89]
}
df = pd.DataFrame(data)

print("学生成绩数据：")
print(df)
print()

# 定义自定义聚合函数
def range_func(x):
    """计算最大值与最小值的差（极差）"""
    return x.max() - x.min()

def coefficient_of_variation(x):
    """计算变异系数（标准差/平均值）"""
    return x.std() / x.mean() * 100

# 使用自定义函数进行聚合
# 可以使用函数名（字符串）或直接传入函数对象
result = df.groupby('班级').agg({
    '语文': ['sum', 'mean', range_func],  # 对语文：总和、平均值、极差
    '数学': ['sum', 'mean', coefficient_of_variation]  # 对数学：总和、平均值、变异系数
})

print("各班级的自定义统计：")
print(result)
print()

# 也可以直接在列表中使用自定义函数
result2 = df.groupby('班级')['数学'].agg(['mean', range_func, 'std'])
print("各班级数学成绩的统计（包含自定义极差和标准差）：")
print(result2)

Análisis del código:

  • Una función personalizada recibe una Serie como parámetro y devuelve un valor escalar.
  • El nombre de la función se puede pasar como cadena (por ejemplo,'sum'), o también se puede pasar directamente el objeto de la función.
  • Con funciones personalizadas se puede implementar cualquier lógica de agregación, por compleja que sea.

Ejemplo 3: Uso de alias de cadena y funciones lambda

agg()Admite múltiples formas de especificar funciones, incluidas expresiones lambda y alias de cadena integrados.

Ejemplo

import pandas as pd

# 创建员工工资数据
data = {
    '部门': ['销售', '销售', '技术', '技术', '行政', '行政', '销售', '技术'],
    '岗位': ['专员', '经理', '专员', '经理', '专员', '经理', '专员', '经理'],
    '工资': [5000, 8000, 7000, 12000, 4500, 9000, 5500, 11000],
    '工龄': [2, 5, 3, 8, 1, 6, 2, 7]
}
df = pd.DataFrame(data)

print("员工工资数据：")
print(df)
print()

# 使用 lambda 函数进行灵活的自定义计算
# 计算每个部门工资的中位数与平均值的差异
result = df.groupby('部门').agg({
    '工资': [
        ('平均工资', 'mean'),  # 给聚合结果起别名
        ('最高工资', 'max'),
        ('最低工资', 'min'),
        ('工资极差', lambda x: x.max() - x.min())
    ],
    '工龄': [
        ('平均工龄', 'mean'),
        ('最高工龄', 'max'),
        ('最低工龄', 'min')
    ]
})

print("各部门工资和工龄的综合统计：")
print(result)
print()

# 使用 agg 的简写形式
result2 = df.groupby('部门')['工资'].agg(
平均='mean',
总和='sum',
人数='count'
)

print("使用命名参数形式的聚合结果：")
print(result2)

  • Usando una tupla('Alias', 'Nombre de función')se puede asignar un nombre personalizado a la columna de resultados de agregación.

Ejemplo 4: Agrupar por múltiples columnas y usar agg

agg()También se puede usar junto con la agrupación por múltiples columnas para manejar necesidades de análisis de datos más complejas.

Ejemplo

import pandas as pd

# 创建销售数据
data = {
    '地区': ['华北', '华东', '华南', '华北', '华东', '华南', '华北', '华东', '华南'],
    '产品': ['A', 'B', 'C', 'B', 'A', 'C', 'A', 'B', 'C'],
    '销售额': [1000, 2000, 1500, 1800, 2200, 1600, 1200, 2100, 1700],
    'Beneficio': [200, 400, 300, 360, 440, 320, 240, 420, 340]
}
df = pd.DataFrame(data)

print("Datos de ventas:")
print(df)
print()

# Agrupar por región y producto, y realizar varias agregaciones de ventas y beneficios
result = df.groupby(['Región', 'Producto']).agg({
    'Ventas': ['sum', 'mean', 'count'],
    'Beneficio': ['sum', 'mean']
})

print("Resultados de agregación después de agrupar por región y producto:")
print(result)
print()

# Usar reset_index para convertir al formato DataFrame normal
result_flat = df.groupby(['Región', 'Producto'], as_index=False).agg({
    'Ventas': ['sum', 'mean'],
    'Beneficio': ['sum', 'mean']
})

# Aplanar el índice de columnas multinivel
result_flat.columns = ['_'.join(col).strip('_') for col in result_flat.columns.values]

print("Resultado después de aplanar:")
print(result_flat)

Análisis del código:

  • Agrupar por varias columnas produce un índice multinivel (MultiIndex).
  • Usaras_index=Falsepuede mantener las columnas de agrupación como columnas normales.

Consejo:agg()Es una de las funciones más utilizadas en la agregación por grupos. No solo puede calcular múltiples indicadores estadísticos de una sola vez, sino que también admite funciones personalizadas, con una flexibilidad muy alta. Se recomienda dominar sus diversos usos en proyectos reales.
