Función groupby.mean() de Pandas

Funciones comunes de Pandas

groupby.mean()Es una función de agregación en Pandas que se utiliza para calcular el promedio después de agrupar. Se usa junto congroupby.sum()primero se agrupan los datos según los valores de una columna, y luego se calcula la media aritmética de las columnas numéricas en cada grupo.

En el análisis de datos, calcular el promedio es una necesidad muy común. Por ejemplo, el salario promedio de cada departamento, las ventas promedio de cada región, las calificaciones promedio de cada clase, etc.mean()La función puede completar estas tareas rápidamente.

Sintaxis básica y parámetros

mean()Es una función miembro del objeto GroupBy, es necesario usar primerogroupby()agrupar y luego llamarla.

Formato de sintaxis

GroupBy.mean(numeric_only=False, engine=None, engine_kwargs=None)

Descripción de parámetros

Parámetro Tipo Descripción Valor predeterminado
numeric_only bool Si es True, solo calcula el promedio de las columnas numéricas; si es False, intenta calcular el promedio de todas las columnas. False
engine str Especifica el motor de cálculo, puede ser 'cython' o 'numba'. None indica que Pandas lo selecciona automáticamente. None
engine_kwargs dict Diccionario de parámetros adicionales que se pasan al motor subyacente. None

Valor de retorno

  • Tipo de retorno：Series 或 DataFrame
  • DescripciónDevuelve el resultado del promedio calculado por grupos. Si se usa en una sola columna, devuelve una Serie; si se usa en varias columnas, devuelve un DataFrame.

Ejemplos

Aprendamos completamente, mediante una serie de ejemplos de simples a complejos,groupby.mean()el uso de la función.

Ejemplo 1: Uso básico: calcular el promedio agrupando por una sola columna

El uso más básico es agrupar según los valores de una columna y luego calcular el promedio de otra columna.

Ejemplo

import pandas as pd

# Crear un DataFrame con los datos de calificaciones de los estudiantes
# Contiene el nombre del estudiante, la clase, y las calificaciones de chino, matemáticas e inglés
data = {
    '姓名': ['张三', '李四', '王五', '赵六', '孙七', '周八', '吴九', '郑十'],
    '班级': ['A', 'A', 'A', 'B', 'B', 'B', 'B', 'A'],
    '语文': [85, 92, 78, 88, 95, 82, 90, 87],
    '数学': [90, 85, 92, 78, 88, 91, 85, 89],
    '英语': [88, 90, 85, 92, 87, 89, 91, 86]
}

# Crear el DataFrame
df = pd.DataFrame(data)

print("学生成绩数据：")
print(df)
print()

# Agrupar por "班级" y calcular la calificación promedio de cada clase
avg_by_class = df.groupby('班级').mean(numeric_only=True)

print("每个班级的平均成绩：")
print(avg_by_class)
print()

# También se puede calcular el promedio solo para una columna específica
math_avg_by_class = df.groupby('班级')['数学'].mean()

print("每个班级的数学平均成绩：")
print(math_avg_by_class)

Análisis del código:

  1. df.groupby('班级')Los estudiantes se dividen en dos grupos, A y B, según los valores de la columna "班级".
  2. .mean(numeric_only=True)Se calcula el promedio de todas las columnas numéricas (chino, matemáticas e inglés).
  3. En el resultado devuelto, la clase actúa como índice y los promedios de cada materia aparecen como datos de columna.

Ejemplo 2: Calcular el promedio agrupando por múltiples columnas

Se puede agrupar por varias columnas al mismo tiempo y luego calcular el promedio de las columnas numéricas.

Ejemplo

import pandas as pd

# Crear datos de ventas
data = {
    '地区': ['华北', '华东', '华南', '华北', '华东', '华南', '华北', '华东'],
    '产品': ['A', 'B', 'C', 'B', 'A', 'C', 'A', 'B'],
    '销售额': [1000, 2000, 1500, 1800, 2200, 1600, 1200, 2100],
    '利润': [200, 400, 300, 360, 440, 320, 240, 420]
}
df = pd.DataFrame(data)

print("销售数据：")
print(df)
print()

# Agrupar por "地区" y "产品", calcular el promedio de ventas y beneficios
avg_grouped = df.groupby(['地区', '产品'], as_index=False).mean(numeric_only=True)

print("按地区和产品分组后的平均销售额和利润：")
print(avg_grouped)
print()

# Mantener la forma de índice multinivel
avg_indexed = df.groupby(['地区', '产品']).mean(numeric_only=True)
print("多级索引形式的结果：")
print(avg_indexed)

Ejemplo 3: Cálculo del promedio al manejar valores faltantes

Cuando hay valores faltantes (NaN) en los datos,mean()se ignoran automáticamente estos valores faltantes para el cálculo.

Ejemplo

import pandas as pd
import numpy as np

# Crear datos de salarios de empleados con valores faltantes
data = {
    '部门': ['销售', '销售', '销售', '技术', '技术', '技术', '行政', '行政'],
    '工资': [5000, 6000, np.nan, 8000, 9000, np.nan, 4500, np.nan]
}
df = pd.DataFrame(data)

print("员工工资数据（包含缺失值）：")
print(df)
print()

# Por defecto, mean() ignora los valores NaN al calcular
avg_with_nan = df.groupby('部门')['工资'].mean()
print("默认计算平均值（忽略NaN）：")
print(avg_with_nan)
print()

# Si se desea incluir los valores NaN como 0, primero hay que rellenarlos
avg_filled = df.groupby('部门')['工资'].apply(lambda x: x.fillna(0).mean())
print("将NaN视为0后的平均工资：")
print(avg_filled)
print()

# Usar el parámetro skipna (por defecto True)
# Si se establece skipna=False, todos los grupos con NaN devuelven NaN
# Nota: el mean de groupby no tiene un parámetro skipna, pero se puede lograr un efecto similar con fillna

    • Ejemplo 4: Calcular la proporción dentro del grupo usando transform

    Se puedetransformmediante el método transform, transmitir el promedio del grupo de vuelta a cada fila de los datos originales, lo cual es muy útil para calcular la proporción dentro del grupo o la diferencia con el promedio del grupo.

    Ejemplo

    import pandas as pd

    # Crear datos de calificaciones de estudiantes
    data = {
        '姓名': ['张三', '李四', '王五', '赵六', '孙七', '周八'],
        '班级': ['A', 'A', 'A', 'B', 'B', 'B'],
        '语文': [85, 92, 78, 88, 95, 82],
        '数学': [90, 85, 92, 78, 88, 91]
    }
    df = pd.DataFrame(data)

    print("学生成绩数据：")
    print(df)
    print()

    # Calcular la calificación promedio de matemáticas de cada clase y luego transmitirla a cada fila
    df['班级数学平均分'] = df.groupby('班级')['数学'].transform('mean')

    # Calcular la diferencia entre la calificación de cada estudiante y el promedio de la clase
    df['与平均分差值'] = df['数学'] - df['班级数学平均分']

    print("添加班级平均分和差值后的数据：")
    print(df)
    print()

    # Calcular el porcentaje de la calificación de matemáticas de cada estudiante respecto al total de la clase
    df['班级内百分比'] = (df['数学'] / df['班级数学平均分'] * 100).round(2)

    print("添加百分比后的数据：")
    print(df)

    Análisis del código:

    • transform('mean')Se calcula el promedio de cada grupo y luego se transmite de vuelta a cada fila de los datos originales.
    • Así cada estudiante puede conocer el promedio de su clase, lo que facilita la comparación.
    • Este método es muy útil en escenarios de análisis como calcular la "posición del individuo dentro del grupo".
