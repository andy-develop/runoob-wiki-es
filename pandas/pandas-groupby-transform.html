Función Pandas groupby-transform()

Funciones comunes de Pandas

groupby.transform()Es una función de Pandas para transformar datos después de agrupar. A diferencia de las funciones de agregación,la agregación devuelve un resumen de cada grupo, mientras que la transformación devuelve un resultado de la misma longitud que los datos originales.。

En términos simples,transform()transmite (broadcast) el resultado del cálculo del grupo a cada fila de los datos originales. Esto es muy útil en escenarios como calcular la posición relativa de cada miembro dentro de su grupo, la estandarización dentro del grupo y la diferencia respecto a la media del grupo.

Sintaxis básica y parámetros

transform()Es una función miembro del objeto GroupBy; primero se debe usargroupby()y llamarla después de agrupar.

Formato de sintaxis

GroupBy.transform(func, axis=0, *args, engine=None, engine_kwargs=None, **kwargs)

Descripción de parámetros

Parámetro Tipo Descripción Valor predeterminado
func str, list, dict o callable Función de transformación. Puede ser el nombre de una función integrada (como 'mean', 'sum', 'std'), una lista de funciones, un diccionario que especifica diferentes funciones para cada columna, o una función personalizada. None
axis int Dirección del eje sobre el que se aplica la transformación; 0 indica por filas (dimensión de agrupación), 1 indica por columnas. 0
args tuple Argumentos posicionales adicionales que se pasan a la función de transformación. ()
engine str Especifica el motor de cálculo; puede ser 'cython' o 'numba'. None indica que Pandas lo selecciona automáticamente. None
engine_kwargs dict Diccionario de argumentos adicionales para pasar al motor subyacente. None

Valor de retorno

  • Tipo de retorno：SeriesoDataFrame
  • Descripción: Devuelve un resultado con el mismo número de filas que los datos originales. Cada fila de datos original recibe el resultado del cálculo de su grupo correspondiente.

Ejemplos

Vamos a dominar por completo, mediante una serie de ejemplos de simples a complejos,groupby.transform()el uso de esta función.

Ejemplo 1: Uso básico - Calcular la media dentro del grupo

transform()El uso más básico es calcular la media de cada grupo y luego transmitir (broadcast) el resultado de vuelta a cada fila.

Ejemplo

import pandas as pd

# Crear datos de calificaciones de estudiantes
data = {
    'Nombre': ['Zhang San', 'Li Si', 'Wang Wu', 'Zhao Liu', Sun Qi, Zhou Ba, Wu Jiu, Zheng Shi],
    'Clase': ['A', 'A', 'A', 'B', 'B', 'B', 'B', 'A'],
    Lengua china: [85, 92, 78, 88, 95, 82, 90, 87],
    Matemáticas: [90, 85, 92, 78, 88, 91, 85, 89]
}

# Crear DataFrame
df = pd.DataFrame(data)

print(Datos de calificaciones de estudiantes:)
print(df)
print()

# Calcular el promedio de matemáticas de cada clase y luego transmitirlo a cada fila
df[Promedio de matemáticas de la clase] = df.groupby('Clase')[Matemáticas].transform('mean')

# Calcular la diferencia entre la calificación de cada estudiante y el promedio de la clase.
df[Diferencia respecto al promedio] = df[Matemáticas] - df[Promedio de matemáticas de la clase]

print("Datos después de añadir el promedio de la clase y la diferencia:")
print(df)
print()

# Calcular simultáneamente el promedio por clase de varias columnas
df[[Promedio de chino de la clase, 'promedio de matemáticas de la clase 2']] = df.groupby('Clase')[[Lengua china, Matemáticas]].transform('mean')

print(Datos después de agregar los promedios de varias columnas:)
print(df)

Ejemplo 2: Estandarización dentro del grupo (Z-Score)

transform()transform se usa a menudo para calcular valores estandarizados dentro del grupo, lo cual es muy útil al comparar la posición relativa de un individuo dentro de su grupo.

Ejemplo

import pandas as pd

# Crear datos de salario de los empleados
data = {
    'Nombre': ['Zhang San', 'Li Si', 'Wang Wu', 'Zhao Liu', Sun Qi, Zhou Ba, Wu Jiu, Zheng Shi],
    'Departamento': [Ventas, Ventas, Ventas, 'Tecnología', 'Tecnología', 'Tecnología', Administración, Administración],
    'Salario': [5000, 8000, 6000, 9000, 12000, 10000, 4500, 7000]
}
df = pd.DataFrame(data)

print(Datos de salarios de empleados:)
print(df)
print()

# Calcula el Z-Score (puntuación estandarizada) del salario de cada empleado dentro del departamento
# Z-Score = (valor original - media del grupo) / desviación estándar del grupo
df[Salario promedio del departamento] = df.groupby('Departamento')['Salario'].transform('mean')
df[Desviación estándar de salarios del departamento] = df.groupby('Departamento')['Salario'].transform('std')
df['Z-Score'] = (df['Salario'] - df[Salario promedio del departamento]) / df[Desviación estándar de salarios del departamento]

print("Datos después de añadir las estadísticas por departamento y el Z-Score:")
print(df)
print()

# Usar una función personalizada para calcular el Z-Score de una vez
def z_score(x):
    """Calcular Z-Score"""
    return (x - x.mean()) / x.std()

df['Z-Score2'] = df.groupby('Departamento')['Salario'].transform(z_score)

print("Z-Score calculado con una función personalizada:")
print(df[['Nombre', 'Departamento', 'Salario', 'Z-Score2']])

Análisis del código:

Ejemplo 3: Ranking y percentil dentro del grupo

transform()transform también se puede usar para calcular la clasificación dentro del grupo, lo cual es muy útil en ordenamiento y análisis de competencia.

Ejemplo

import pandas as pd
import numpy as np

# Crear datos de calificaciones de estudiantes
data = {
    'Nombre': ['Zhang San', 'Li Si', 'Wang Wu', 'Zhao Liu', Sun Qi, Zhou Ba, Wu Jiu, Zheng Shi],
    'Clase': ['A', 'A', 'A', 'B', 'B', 'B', 'B', 'A'],
    Matemáticas: [90, 85, 92, 78, 88, 91, 85, 89]
}
df = pd.DataFrame(data)

print(Datos de calificaciones de estudiantes:)
print(df)
print()

# Calcular la clasificación de cada estudiante en la clase (de mayor a menor)
df[Ranking dentro de la clase] = df.groupby('Clase')[Matemáticas].transform(lambda x: x.rank(ascending=False))

# Calcular el percentil de cada estudiante dentro de la clase (rango porcentual)
df[Percentil dentro de la clase] = df.groupby('Clase')[Matemáticas].transform(lambda x: x.rank(pct=True))

print(Datos después de agregar el rango dentro de la clase y el percentil:)
print(df)
print()

# Otra forma de rellenar valores faltantes: usar la media del grupo
data_with_na = {
    'Nombre': ['Zhang San', 'Li Si', 'Wang Wu', 'Zhao Liu', Sun Qi, Zhou Ba],
    'Clase': ['A', 'A', 'A', 'B', 'B', 'B'],
    'Calificaciones': [85, np.nan, 78, 88, np.nan, 82]
}
df_na = pd.DataFrame(data_with_na)

print(Datos con valores faltantes:)
print(df_na)
print()

# Rellenar los valores faltantes con la media del grupo
df_na[Calificaciones después del relleno] = df_na.groupby('Clase')['Calificaciones'].transform(lambda x: x.fillna(x.mean()))

print(Resultado tras imputar con la media del grupo:)
print(df_na)

Ejemplo 4: Usar una función de transformación personalizada

transform()Se admiten funciones personalizadas, que pueden implementar lógica de transformación de datos dentro de los grupos más compleja.

Ejemplo

import pandas as pd
import numpy as np

# Crear datos de precios de acciones
data = {
    'Código de la acción': ['AAPL', 'AAPL', 'AAPL', 'AAPL', 'GOOG', 'GOOG', 'GOOG', 'GOOG'],
    'Fecha': ['2024-01-01', '2024-01-02', '2024-01-03', '2024-01-04'] * 2,
    'Precio de cierre': [100, 105, 102, 110, 80, 85, 82, 90]
}
df = pd.DataFrame(data)

print("Datos de precios de acciones:")
print(df)
print()

# Función personalizada: calcular la tasa de rendimiento diaria de cada acción
def calc_daily_return(prices):
    """Calcular la tasa de rendimiento diaria: (precio de hoy - precio de ayer) / precio de ayer"""
    return prices.pct_change()

# Calcular la tasa de rendimiento diaria de cada acción
df['Tasa de rendimiento diaria'] = df.groupby('Código de la acción')['Precio de cierre'].transform(calc_daily_return)

print("Datos después de agregar la tasa de rendimiento diaria:")
print(df)
print()

# Función personalizada: calcular la normalización entre el máximo y el mínimo dentro del grupo
def normalize(x):
    """Normalización: (x - min) / (max - min)"""
    return (x - x.min()) / (x.max() - x.min())

# Calcular el valor normalizado del precio de cada acción
df['Precio normalizado'] = df.groupby('Código de la acción')['Precio de cierre'].transform(normalize)

print("Datos después de agregar el precio normalizado:")
print(df)

Análisis del código:

  • La función de transformación recibe una Series (los datos dentro de cada grupo).
  • La longitud de la Series devuelta debe ser igual a la longitud de la Series de entrada.
  • El primer valor es NaN porquepct_change()se calcula un cambio relativo y el primer día no hay datos del día anterior.

Diferencia clave:agg()ytransform()La diferencia radica en:agg()devuelve el resultado resumido de cada grupo (el número de filas es igual al número de grupos), mientras quetransform()devuelve un resultado con la misma longitud que los datos originales. Regla mnemotécnica: agg comprime los datos, transform mantiene la forma de los datos.
