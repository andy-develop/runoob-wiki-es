Escalar Perl

Un escalar es una unidad de datos simple.

Un escalar puede ser un entero, un número de coma flotante, un carácter, una cadena, un párrafo o una página web completa.

El siguiente ejemplo demuestra la aplicación sencilla de los escalares:

Ejemplo

#!/usr/bin/perl $age = 20; # Asignación de entero $name = "Ejemplo"; # Cadena $salary = 130.50; # Número de coma flotante print "Age = $age\n"; print "Name = $name\n"; print "Salary = $salary\n";

Al ejecutar el programa anterior, el resultado es:

Age = 20
Name = Ejemplo
Salary = 130.5

Escalares numéricos

Los escalares suelen ser un número o una cadena. El siguiente ejemplo demuestra el uso de diferentes tipos de escalares numéricos:

Ejemplo

#!/usr/bin/perl $integer = 200; $negative = -300; $floating = 200.340; $bigfloat = -1.2E-23; # Octal 377, decimal 255 $octal = 0377; # Hexadecimal FF, decimal 255 $hexa = 0xff; print "integer = $integer\n"; print "negative = $negative\n"; print "floating = $floating\n"; print "bigfloat = $bigfloat\n"; print "octal = $octal\n"; print "hexa = $hexa\n";

Al ejecutar el programa anterior, el resultado es:

integer = 200
negative = -300
floating = 200.34
bigfloat = -1.2e-23
octal = 255
hexa = 255

Escalares de cadena

El siguiente ejemplo demuestra el uso de diferentes tipos de escalares de cadena. Observa la diferencia entre comillas simples y dobles:

Ejemplo

#!/usr/bin/perl $var = "Escalar de cadena - Tutorial para novatos!"; $quote = 'Estoy dentro de comillas simples - $var'; $double = "Estoy dentro de comillas dobles -$var"; $escape = "Uso de caracteres de escape -\tHello, World!"; print "var = $var\n"; print "quote = $quote\n"; print "double = $double\n"; print "escape = $escape\n";

Al ejecutar el programa anterior, el resultado es:

var = 字符串标量 - Ejemplo!
quote = 我在单引号内 - $var
double = 我在双引号内 - 字符串标量 - Ejemplo!
escape = 转义字符使用 -    Hello, World!

Operaciones con escalares

El siguiente ejemplo demuestra operaciones simples con escalares:

Ejemplo

#!/usr/bin/perl $str = "hello" . "world"; # Concatenación de cadenas $num = 5 + 10; # Suma de dos números $mul = 4 * 5; # Multiplicación de dos números $mix = $str . $num; # Concatenar cadena y número print "str = $str\n"; print "num = $num\n"; print "mix = $mix\n";

Al ejecutar el programa anterior, el resultado es:

str = helloworld
num = 15
mix = helloworld15

Cadenas multilínea

Podemos usar comillas simples para imprimir cadenas multilínea, como se muestra a continuación:

Ejemplo

#!/usr/bin/perl $string = 'Tutorial para novatos —— Lo que se aprende no es solo tecnología, sino también sueños!'; print "$string\n";

Al ejecutar el programa anterior, el resultado es:

Tutorial para novatos
    —— ¡Lo que se aprende no es solo tecnología, sino también sueños!

También puedes usar la sintaxis de documento "here" para imprimir múltiples líneas:

Ejemplo

#!/usr/bin/perl print <<EOF; Tutorial para novatos —— Lo que se aprende no es solo tecnología, sino también sueños!EOF

Al ejecutar el programa anterior, el resultado es:

Tutorial para novatos
    —— ¡Lo que se aprende no es solo tecnología, sino también sueños!

Caracteres especiales

A continuación demostraremos la aplicación de caracteres especiales en Perl, como __FILE__, __LINE__, y __PACKAGE__, que representan el nombre del archivo del script en ejecución, el número de línea y el nombre del paquete, respectivamente.

Nota： __Son dos guiones bajos,__FILE__dos guiones bajos al principio y dos al final.

Estos caracteres especiales son marcadores independientes y no se pueden escribir dentro de las cadenas, por ejemplo:

Ejemplo

#!/usr/bin/perl print "Nombre de archivo". __FILE__ . "\n"; print "Número de línea" . __LINE__ ."\n"; print "Nombre de paquete" . __PACKAGE__ ."\n"; # No se puede analizar print "__FILE__ __LINE__ __PACKAGE__\n";

Al ejecutar el programa anterior, el resultado es:

文件名 test.pl
行号 4
包名 main
__FILE__ __LINE__ __PACKAGE__

Cadena v

Una cadena que comienza con v, seguida de uno o más enteros separados por puntos, se tratará como un literal de cadena.

Cuando quieras declarar directamente el valor numérico de cada carácter, la cadena v proporciona una forma más clara de construir este tipo de cadenas, en lugar de "\x{1}\x{14}\x{12c}\x{fa0}", que no es fácil de entender. Podemos ver el siguiente ejemplo:

Ejemplo

#!/usr/bin/perl $smile = v9786; $foo = v102.111.111; $martin = v77.97.114.116.105.110; print "smile = $smile\n"; print "foo = $foo\n"; print "martin = $martin\n";

Al ejecutar el programa anterior, el resultado es:

Wide character in print at test.pl line 7.
smile = &#x263a;
foo = foo
martin = Martin
