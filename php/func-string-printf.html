Definición y uso

La función printf() genera una cadena formateada.

Los parámetros arg1, arg2, ++ se insertan en los símbolos de porcentaje (%) de la cadena principal. La función se ejecuta paso a paso. En el primer símbolo %, se inserta arg1, en el segundo símbolo %, se inserta arg2, y así sucesivamente.

Notas:Si hay más símbolos % que parámetros arg, debe utilizar marcadores de posición. El marcador de posición se inserta después del símbolo % y se compone de un número y "\$". Consulte el ejemplo 2.

Consejo:Funciones relacionadas:sprintf()、 vprintf()、 vsprintf()、 fprintf()yvfprintf()

Sintaxis

printf(format,arg1,arg2,arg++)

Parámetros Descripción
format Obligatorio. Especifica la cadena y cómo formatear las variables dentro de ella.

Posibles valores de formato:

  • %% - Devuelve un signo de porcentaje %
  • %b - Número binario
  • %c - Carácter correspondiente al valor ASCII
  • %d - Número decimal con signo (negativos, cero, positivos)
  • %e - Notación científica en minúsculas (por ejemplo, 1.2e+2)
  • %E - Notación científica en mayúsculas (por ejemplo, 1.2E+2)
  • %u - Número decimal sin signo (mayor o igual a 0)
  • %f - Número de coma flotante (configuración local)
  • %F - Número de punto flotante (no localizado)
  • %g - El más corto entre %e y %f
  • %G - El más corto entre %E y %f
  • %o - Número octal
  • %s - cadena
  • %x - Número hexadecimal (letras minúsculas)
  • %X - Número hexadecimal (letras mayúsculas)

Valores de formato adicionales. Deben colocarse entre % y la letra (por ejemplo, %.2f):

  • + (Agrega + o - antes del número para definir su signo. De forma predeterminada, solo los números negativos se marcan, los positivos no se marcan)
  • ' (Especifica qué usar como relleno; el valor predeterminado es un espacio. Debe usarse junto con el especificador de ancho. Por ejemplo: %'x20s (usa "x" como relleno))
  • - (Ajusta a la izquierda el valor de la variable)
  • [0-9] (Especifica el ancho mínimo del valor de la variable)
  • .[0-9] (Especifica el número de decimales o la longitud máxima de la cadena)

Notas:Si se utilizan varios de los valores de formato anteriores, deben usarse en el orden indicado arriba, sin alterarlo.
arg1 Obligatorio. Especifica el parámetro que se inserta en el primer símbolo % de la cadena de formato.
arg2 Opcional. Especifica el parámetro que se inserta en el segundo símbolo % de la cadena de formato.
arg++ Opcional. Especifica los parámetros que se insertan en el tercer, cuarto, etc. símbolo % de la cadena de formato.

Detalles técnicos

Valor de retorno: Devuelve la longitud de la cadena de salida.
Versión de PHP: 4+

Ejemplo 3

Demostración de todos los posibles valores de formato:

<?php
$num1 = 123456789;
$num2 = -123456789;
$char = 50; // The ASCII Character 50 is 2

// Note: The format value "%%" returns a percent sign
printf("%%b = %b <br>",$num1); // Binary number
printf("%%c = %c <br>",$char); // The ASCII Character
printf("%%d = %d <br>",$num1); // Signed decimal number
printf("%%d = %d <br>",$num2); // Signed decimal number
printf("%%e = %e <br>",$num1); // Scientific notation (lowercase)
printf("%%E = %E <br>",$num1); // Scientific notation (uppercase)
printf("%%u = %u <br>",$num1); // Unsigned decimal number (positive)
printf("%%u = %u <br>",$num2); // Unsigned decimal number (negative)
printf("%%f = %f <br>",$num1); // Floating-point number (local settings aware)
printf("%%F = %F <br>",$num1); // Floating-point number (not local settings aware)
printf("%%g = %g <br>",$num1); // Shorter of %e and %f
printf("%%G = %G <br>",$num1); // Shorter of %E and %f
printf("%%o = %o <br>",$num1); // Octal number
printf("%%s = %s <br>",$num1); // String
printf("%%x = %x <br>",$num1); // Hexadecimal number (lowercase)
printf("%%X = %X <br>",$num1); // Hexadecimal number (uppercase)
printf("%%+d = %+d <br>",$num1); // Sign specifier (positive)
printf("%%+d = %+d <br>",$num2); // Sign specifier (negative)
?>
