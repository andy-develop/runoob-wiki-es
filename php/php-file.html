PHP Manejo de archivos

La función fopen() se utiliza para abrir archivos en PHP.

Abrir archivos

La función fopen() se utiliza para abrir archivos en PHP.

El primer parámetro de esta función contiene el nombre del archivo a abrir, el segundo parámetro especifica el modo en que se abrirá el archivo:

<html>
<body>

<?php
$file=fopen("welcome.txt","r");
?>

</body>
</html>

El archivo puede abrirse mediante los siguientes modos:

Modo Descripción
r Solo lectura. Comienza al principio del archivo.
r+ Lectura/escritura. Comienza al principio del archivo.
w Solo escritura. Abre y vacía el contenido del archivo; si el archivo no existe, crea un archivo nuevo.
w+ Lectura/escritura. Abre y vacía el contenido del archivo; si el archivo no existe, crea un archivo nuevo.
a Añadir. Abre y escribe al final del archivo; si el archivo no existe, crea un archivo nuevo.
a+ Lectura/añadir. Conserva el contenido del archivo escribiendo al final del archivo.
x Solo escritura. Crea un archivo nuevo. Si el archivo ya existe, devuelve FALSE y un error.
x+ Lectura/escritura. Crea un archivo nuevo. Si el archivo ya existe, devuelve FALSE y un error.

Nota:Si la función fopen() no puede abrir el archivo especificado, devuelve 0 (false).

Ejemplo

Si la función fopen() no puede abrir el archivo especificado, el siguiente ejemplo generará un mensaje:

<html>
<body>

<?php
$file=fopen("welcome.txt","r") or exit("Unable to open file!");
?>

</body>
</html>

Cerrar archivos

La función fclose() se utiliza para cerrar archivos abiertos:

<?php
$file = fopen("test.txt","r");

// ejecutar algún código

fclose($file);
?>

Detectar el final del archivo (EOF)

La función feof() detecta si se ha llegado al final del archivo (EOF).

La función feof() es útil al recorrer en bucle datos de longitud desconocida.

Nota:En los modos w, a y x, ¡no puede leer el archivo abierto!

if (feof($file)) echo "fin del archivo";

Leer archivo línea por línea

La función fgets() se utiliza para leer el archivo línea por línea.

Nota:Después de llamar a esta función, el puntero del archivo se mueve a la siguiente línea.

Ejemplo

El siguiente ejemplo lee el archivo línea por línea hasta el final del archivo:

<?php
$file = fopen("welcome.txt", "r") or exit("¡No se puede abrir el archivo!");
// leer cada línea del archivo hasta el final
while(!feof($file))
{
    echo fgets($file). "<br>";
}
fclose($file);
?>

Leer archivo carácter por carácter

La función fgetc() se utiliza para leer el archivo carácter por carácter.

Nota:Después de llamar a esta función, el puntero del archivo se mueve al siguiente carácter.

Ejemplo

El siguiente ejemplo lee el archivo carácter por carácter hasta el final del archivo:

<?php
$file=fopen("welcome.txt","r") or exit("¡No se puede abrir el archivo!");
while (!feof($file))
{
    echo fgetc($file);
}
fclose($file);
?>
