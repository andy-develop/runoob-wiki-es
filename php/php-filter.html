PHP Filtros

Los filtros PHP se utilizan para validar y filtrar datos de fuentes no seguras, como la entrada del usuario.

¿Qué son los filtros PHP?

Los filtros PHP se utilizan para validar y filtrar datos provenientes de fuentes no seguras.

Probar, validar y filtrar la entrada del usuario o los datos personalizados es una parte importante de cualquier aplicación web.

La extensión de filtros de PHP está diseñada para hacer que el filtrado de datos sea más fácil y rápido.

¿Por qué usar filtros?

Casi todas las aplicaciones web dependen de entradas externas. Estos datos suelen provenir de usuarios u otras aplicaciones (por ejemplo, servicios web). Al usar filtros, usted puede asegurarse de que la aplicación reciba el tipo correcto de entrada.

¡Siempre debe filtrar los datos externos!

El filtrado de entrada es uno de los temas de seguridad más importantes en las aplicaciones.

¿Qué son los datos externos?

  • Datos de entrada de formularios
  • Cookies
  • Web services data
  • Variables de servidor
  • Resultados de consultas a bases de datos

Funciones y filtros

Para filtrar variables, use una de las siguientes funciones de filtro:

  • filter_var() - Filtra una variable con un filtro específico
  • filter_var_array() - Filtra múltiples variables con el mismo o diferentes filtros
  • filter_input - Obtiene una variable de entrada y la filtra
  • filter_input_array - Obtiene múltiples variables de entrada y las filtra con el mismo o diferentes filtros

En el siguiente ejemplo, validamos un entero con la función filter_var():

Ejemplo

<?php $int = 123; if(!filter_var($int, FILTER_VALIDATE_INT)) { echo("No es un entero válido"); } else { echo("es un entero válido"); } ?>

El código anterior utiliza el filtro "FILTER_VALIDATE_INT" para filtrar la variable. Dado que el entero es válido, el código anterior generará lo siguiente:

Si intentamos usar una variable que no es un entero (por ejemplo, "123abc"), se mostrará: "Integer is not valid".

Validación y saneamiento

Hay dos tipos de filtros:

Filtros de validación:

  • Se utilizan para validar la entrada del usuario
  • Reglas de formato estrictas (como validación de URL o correo electrónico)
  • Devuelven el tipo esperado si tienen éxito, o FALSE si fallan

Filtros de saneamiento:

  • Se utilizan para permitir o prohibir caracteres específicos en una cadena
  • Sin reglas de formato de datos
  • Siempre devuelven cadenas (strings)

Opciones y marcadores

Las opciones y los marcadores se utilizan para agregar opciones de filtrado adicionales a los filtros especificados.

Diferentes filtros tienen diferentes opciones y marcadores.

En el siguiente ejemplo, validamos un entero con filter_var() y las opciones "min_range" y "max_range":

Ejemplo

<?php $var=300; $int_options = array( "options"=>array ( "min_range"=>0, "max_range"=>256 ) ); if(!filter_var($var, FILTER_VALIDATE_INT, $int_options)) { echo("No es un entero válido"); } else { echo("es un entero válido"); } ?>

Al igual que en el código anterior, las opciones deben colocarse en un arreglo asociativo llamado "options". Si se usan marcadores, no es necesario que estén dentro del arreglo.

Dado que el entero es "300" y no se encuentra dentro del rango especificado, la salida del código anterior será:

No es un número entero válido

Para ver la lista completa de funciones y filtros, visite nuestroManual de referencia de filtros PHP. Allí puede ver las opciones y marcadores disponibles para cada filtro.

Validación de entrada

Intentemos validar la entrada de un formulario.

Lo primero que debemos hacer es confirmar si existen los datos de entrada que estamos buscando.

Luego usamos la función filter_input() para filtrar los datos de entrada.

En el siguiente ejemplo, la variable de entrada "email" se envía a la página PHP:

Ejemplo

<?php if(!filter_has_var(INPUT_GET, "email")) { echo("No hay parámetro email"); } else { if (!filter_input(INPUT_GET, "email", FILTER_VALIDATE_EMAIL)) { echo "No es un correo electrónico válido"; } else { echo "es un correo electrónico válido"; } } ?>

  2. Si la variable de entrada existe, detecta si es una dirección de correo electrónico válida

Saneamiento de entrada

Intentemos limpiar una URL proveniente de un formulario.

Primero, debemos confirmar si existen los datos de entrada que estamos buscando.

Luego, usamos la función filter_input() para sanear los datos de entrada.

En el siguiente ejemplo, la variable de entrada "url" se envía a la página PHP:

<?php
if(!filter_has_var(INPUT_GET, "url"))
{
    echo("没有 url 参数");
}
else
{
    $url = filter_input(INPUT_GET, 
    "url", FILTER_SANITIZE_URL);
    echo $url;
}
?>

Explicación del ejemplo

El ejemplo anterior tiene una variable de entrada (url) enviada mediante el método "GET":

  1. Detecta si existe una variable de entrada "url" de tipo "GET"
  2. Si esta variable de entrada existe, la sanea (elimina caracteres no válidos) y la almacena en la variable $url

Filtrar múltiples entradas

Los formularios suelen estar compuestos por múltiples campos de entrada. Para evitar llamadas repetidas a las funciones filter_var o filter_input, podemos usar las funciones filter_var_array o filter_input_array.

En este ejemplo, usamos la función filter_input_array() para filtrar tres variables GET. Las variables GET recibidas son un nombre, una edad y una dirección de correo electrónico:

Ejemplo

<?php $filters = array ( "name" => array ( "filter"=>FILTER_SANITIZE_STRING ), "age" => array ( "filter"=>FILTER_VALIDATE_INT, "options"=>array ( "min_range"=>1, "max_range"=>120 ) ), "email"=> FILTER_VALIDATE_EMAIL ); $result = filter_input_array(INPUT_GET, $filters); if (!$result["age"]) { echo("La edad debe estar entre 1 y 120.<br>"); } elseif(!$result["email"]) { echo("El correo electrónico no es válido<br>"); } else { echo("Entrada correcta"); } ?>

Explicación del ejemplo

El ejemplo anterior tiene tres variables de entrada (name, age y email) enviadas mediante el método "GET":

  1. Configura un arreglo que contiene los nombres de las variables de entrada y los filtros para las variables de entrada especificadas
  2. Llama a la función filter_input_array() con los parámetros que incluyen las variables de entrada GET y el arreglo recién configurado
  3. Detecta si las variables "age" y "email" en la variable $result tienen entradas no válidas. (Si hay entradas no válidas, la variable de entrada será FALSE después de usar la función filter_input_array()).

El segundo parámetro de la función filter_input_array() puede ser un arreglo o el ID de un filtro único.

Si este parámetro es el ID de un filtro único, ese filtro especificado filtrará todos los valores del arreglo de entrada.

Si el parámetro es un arreglo, dicho arreglo debe cumplir las siguientes reglas:

  • Debe ser un arreglo asociativo en el que las variables de entrada sean las claves del arreglo (por ejemplo, la variable de entrada "age")
  • Los valores de este arreglo deben ser el ID de un filtro, o un arreglo que especifique el filtro, los marcadores y las opciones

Usar Filter Callback

Al usar el filtro FILTER_CALLBACK, se puede llamar a una función personalizada y utilizarla como filtro. De esta manera, tenemos un control total sobre el filtrado de datos.

Puede crear su propia función personalizada o utilizar funciones PHP ya existentes.

Especifique la función del filtro que desea utilizar, de acuerdo con el método establecido por las opciones especificadas. En el arreglo asociativo, se usa el nombre "options".

En el siguiente ejemplo, usamos una función personalizada para convertir todos los "_" en ".":

Ejemplo

<?php function convertSpace($string) { return str_replace("_", ".", $string); } $string = "www_runoob_com!"; echo filter_var($string, FILTER_CALLBACK, array("options"=>"convertSpace")); ?>
