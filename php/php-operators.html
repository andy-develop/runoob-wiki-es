Operador ternario

Otro operador condicional es el operador "?:" (o ternario).

Sintaxis

(expr1) ? (expr2) : (expr3)

El valor es expr2 cuando expr1 se evalúa como TRUE, y expr3 cuando expr1 se evalúa como FALSE.

Desde PHP 5.3, se puede omitir la parte central del operador ternario. La expresión expr1 ?: expr3 devuelve expr1 si expr1 se evalúa como TRUE; de lo contrario, devuelve expr3.

Ejemplo

En el siguiente ejemplo se comprueba si la solicitud $_GET contiene el valor user; si lo tiene, devuelve $_GET['user']; de lo contrario, devuelve nobody:

Ejemplo

<?php //Escritura normal $username = isset($_GET['user']) ? $_GET['user'] : 'nobody'; echo $username, PHP_EOL; //Escritura en PHP 5.3+ $username = $_GET['user'] ?: 'nobody'; echo $username, PHP_EOL; ?>

Nota:PHP_EOLEs un salto de línea, compatible con más plataformas.

En PHP7+ se añadió el operador de fusión NULL??, como en el siguiente ejemplo:

Ejemplo

<?php //Si $_GET['user'] no existe, devuelve 'nobody'; de lo contrario, devuelve el valor de $_GET['user']. $username = $_GET['user'] ?? 'nobody'; //Operador ternario similar $username = isset($_GET['user']) ? $_GET['user'] : 'nobody'; ?>

Operador de comparación combinado (PHP7+)

PHP7+ admite el operador de comparación combinado (combined comparison operator), también llamado operador nave espacial, cuyo símbolo es<=>. El operador de comparación combinado puede implementar fácilmente la comparación de dos variables; por supuesto, no se limita a la comparación de datos numéricos.

El formato de sintaxis es el siguiente:

$c = $a <=> $b;

Se interpreta de la siguiente manera:

  • Si $a > $b, entonces$cel valor de ... es1。
  • Si$a == $b, entonces$cel valor de ... es0。
  • Si$a < $b, entonces$cel valor de ... es-1。

El ejemplo es el siguiente:

Ejemplo

<?php //Entero echo 1 <=> 1; // 0 echo 1 <=> 2; // -1 echo 2 <=> 1; // 1 //Flotante echo 1.5 <=> 1.5; // 0 echo 1.5 <=> 2.5; // -1 echo 2.5 <=> 1.5; // 1 //Cadena echo "a" <=> "a"; // 0 echo "a" <=> "b"; // -1 echo "b" <=> "a"; // 1 ?>

En la precedencia de operadores, or y ||, && y and son operadores lógicos; tienen el mismo efecto, pero su precedencia es diferente.

Ejemplo

<?php //Precedencia: && > = > and //Precedencia: || > = > or $a = 3; $b = false; $c = $a or $b; var_dump($c); //Aquí $c es un valor int 3, no un valor booleano true $d = $a || $b; var_dump($d); //Aquí $d es el valor booleano true ?>

El resultado del ejemplo anterior es:

int(3)
bool(true)

Uso de paréntesis

Podemos usar el emparejamiento de paréntesis para indicar claramente el orden de las operaciones, en lugar de depender de la precedencia y la asociatividad de los operadores; esto generalmente aumenta la legibilidad del código.

Ejemplo

<?php //Los paréntesis tienen prioridad en la operación $a = 1; $b = 2; $c = 3; $d = $a + $b * $c; echo $d; echo "\n"; $e = ($a + $b) * $c; //Usar paréntesis echo $e; echo "\n"; ?>

El resultado del ejemplo anterior es:

7
9
