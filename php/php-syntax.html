PHP Sintaxis

Los scripts de PHP se ejecutan en el servidor y luego envían el resultado HTML puro de vuelta al navegador.

PHP usa<?php ?>para envolver el código.

Sintaxis básica de PHP

Los scripts de PHP pueden colocarse en cualquier lugar del documento.

El script de PHP comienza con<?phpy termina con?>fin:

<?php
// PHP 代码
?>

La extensión de archivo predeterminada para archivos PHP es.php。

Los archivos PHP suelen contener etiquetas HTML y algo de código de script PHP.

Ejemplos

<?php
// El código PHP se escribe entre <?php y ?>
echo "Hello, PHP!";
?>
  • <?php ...?>son las etiquetas estándar de PHP.
  • echo se utiliza para generar contenido.
  • Cada sentencia debe terminar con;。

A continuación, proporcionamos un ejemplo sencillo de archivo PHP que puede enviar al navegador el texto "Hello World!":

<!DOCTYPE html>
<html>
<body>

<h1>My first PHP page</h1>

<?php
echo "Hello World!";
?>

</body>
</html>

Cada línea de código en PHP debe terminar con un punto y coma. El punto y coma es un separador que se utiliza para distinguir conjuntos de instrucciones.

Con PHP, hay dos instrucciones básicas para mostrar texto en el navegador:echoyprint。

Comentarios en PHP

En PHP, los comentarios se utilizan para explicar la función del código; no se ejecutan ni se muestran en la página.

Hay principalmente tres formas de comentarios:

1. Comentarios de una sola línea (2 formas de escribirlos)

Usar//

<?php
// 这是单行注释
echo "Hello"; // 也可以放在语句后面
?>

Usar#

<?php
# 这是另一种单行注释
echo "World";
?>

Características:

  • desde//o#comienza y va hasta el final de la línea.
  • Se usa comúnmente para explicaciones breves.

2. Comentarios de varias líneas (comentarios de bloque)

Usar/* ... */</p> 

<?php
/*
这是多行注释
可以写多行文字
不会被执行
*/
echo "PHP";
?>

Características:

  • con/*comienza,*/termina.
  • Puede escribirse a lo largo de varias líneas.
  • Se usa comúnmente para explicaciones de código más largas, comentarios de funciones, etc.

3. Comentarios de documentación (comentarios DocBlock)

Esta es una forma especial de comentario de varias líneas, utilizada para generar documentación de API, adecuada para describir clases, funciones, etc.

<?php
/**
 * 打印问候语
 *
 * @param string $name 用户名
 * @return string 返回问候语
 */
function sayHello($name) {
    return "Hello, $name!";
}
?>

Características:

  • usar/** ... */Se envuelve (atención a los dos asteriscos)
  • Admite @param, @return, @var, @author
  • Se usa comúnmente junto con IDE o herramientas de generación de documentación (como phpDocumentor)
Uso Forma de comentario recomendada Ejemplo
Explicar brevemente una línea de código //o# // Información de salida
Explicar un bloque de código /* ... */ Comentarios para dividir bloques lógicos
Documentación de funciones/clases /** ... */ DocBlock Para describir parámetros, valores de retorno, propósitos, etc.
