Métodos de archivos/directorios de Python OS

osEl módulo proporciona métodos muy completos para manejar archivos y directorios. Los métodos comunes se muestran en la siguiente tabla:

N.ºMétodo y descripción
1

os.access(path, mode)


Verificar el modo de permisos
2

os.chdir(path)


Cambiar el directorio de trabajo actual
3

os.chflags(path, flags)


Establecer la marca de la ruta como una marca numérica.
4

os.chmod(path, mode)


Cambiar permisos
5

os.chown(path, uid, gid)


Cambiar el propietario del archivo
6

os.chroot(path)


Cambiar el directorio raíz del proceso actual
7

os.close(fd)


Cerrar el descriptor de archivo fd
8

os.closerange(fd_low, fd_high)


Cerrar todos los descriptores de archivo, desde fd_low (incluido) hasta fd_high (no incluido); los errores se ignoran.
9

os.dup(fd)


Duplicar el descriptor de archivo fd
10

os.dup2(fd, fd2)


Duplicar un descriptor de archivo fd a otro fd2
11

os.fchdir(fd)


Cambiar el directorio de trabajo actual mediante un descriptor de archivo
12

os.fchmod(fd, mode)


Cambiar los permisos de acceso de un archivo, especificado por el parámetro fd; el parámetro mode son los permisos de acceso de archivo en Unix.
13

os.fchown(fd, uid, gid)


Modificar la propiedad de un archivo. Esta función modifica el ID de usuario y el ID de grupo de usuario de un archivo, especificado por el descriptor de archivo fd.
14

os.fdatasync(fd)


Forzar la escritura del archivo al disco, especificado por el descriptor de archivo fd, pero sin forzar la actualización de la información de estado del archivo.
15

os.fdopen(fd[, mode[, bufsize]])


Crear un objeto de archivo mediante el descriptor de archivo fd y devolver este objeto de archivo
16

os.fpathconf(fd, name)


Devolver la información de configuración del sistema de un archivo abierto. name es el valor de configuración del sistema a consultar; puede ser una cadena que define un valor del sistema. Estos nombres se especifican en muchos estándares (POSIX.1, Unix 95, Unix 98 y otros).
17

os.fstat(fd)


Devolver el estado del descriptor de archivo fd, como stat().
18

os.fstatvfs(fd)


Devolver la información del sistema de archivos del archivo que contiene el descriptor de archivo fd, como statvfs().
19

os.fsync(fd)


Forzar la escritura al disco del archivo con descriptor de archivo fd.
20

os.ftruncate(fd, length)


Truncar el archivo correspondiente al descriptor de archivo fd, de modo que como máximo no pueda superar el tamaño del archivo.
21

os.getcwd()


Devolver el directorio de trabajo actual
22

os.getcwdu()


Devolver un objeto Unicode del directorio de trabajo actual
23

os.isatty(fd)


Si el descriptor de archivo fd está abierto y está conectado a un dispositivo tty(-like), devuelve true; de lo contrario, False.
24

os.lchflags(path, flags)


Establecer la marca de la ruta como una marca numérica, similar a chflags(), pero sin enlaces simbólicos
25

os.lchmod(path, mode)


Modificar los permisos del archivo de enlace
26

os.lchown(path, uid, gid)


Cambiar el propietario del archivo, similar a chown, pero sin seguir enlaces.
27

os.link(src, dst)


Crear un enlace duro, llamado parámetro dst, que apunta al parámetro src
28

os.listdir(path)


Devolver una lista de los nombres de los archivos o carpetas contenidos en la carpeta especificada por path.
29

os.lseek(fd, pos, how)


Establecer la posición actual del descriptor de archivo fd en pos, modificado según how: SEEK_SET o 0 establece pos calculada desde el inicio del archivo; SEEK_CUR o 1 calcula desde la posición actual; os.SEEK_END o 2 comienza desde el final del archivo. Válido en Unix y Windows.
30

os.lstat(path)


Similar a stat(), pero sin enlaces simbólicos
31

os.major(device)


Extraer el número major del dispositivo del número de dispositivo original (usando el campo st_dev o st_rdev de stat).
32

os.makedev(major, minor)


Componer un número de dispositivo original a partir de los números de dispositivo major y minor
33

os.makedirs(path[, mode])


Función de creación recursiva de carpetas. Similar a mkdir(), pero todas las carpetas de nivel intermedio creadas deben incluir las subcarpetas.
34

os.minor(device)


Extraer el número minor del dispositivo del número de dispositivo original (usando el campo st_dev o st_rdev de stat).
35

os.mkdir(path[, mode])


Crear una carpeta llamada path con el mode numérico. El mode predeterminado es 0777 (octal).
36

os.mkfifo(path[, mode])


Crear una tubería con nombre (named pipe); mode es numérico, el valor predeterminado es 0666 (octal)
37

os.mknod(filename[, mode=0600, device])
Crear un nodo del sistema de archivos llamado filename (archivo, archivo especial de dispositivo o tubería con nombre).

38

os.open(file, flags[, mode])


Abrir un archivo y establecer las opciones de apertura necesarias; el parámetro mode es opcional
39

os.openpty()


Abrir un nuevo par de pseudo-terminales. Devuelve los descriptores de archivo de pty y tty.
40

os.pathconf(path, name)


Devolver la información de configuración del sistema del archivo relacionado.
41

os.pipe()


Crear una tubería. Devuelve un par de descriptores de archivo (r, w) para lectura y escritura respectivamente.
42

os.popen(command[, mode[, bufsize]])


Abrir una tubería desde un command
43

os.read(fd, n)


Leer como máximo n bytes del descriptor de archivo fd y devolver una cadena que contiene los bytes leídos; si el archivo correspondiente al descriptor de archivo fd ha llegado al final, devolver una cadena vacía.
44

os.readlink(path)


Devolver el archivo al que apunta el enlace simbólico
45

os.remove(path)


Eliminar el archivo en la ruta path. Si path es una carpeta, se lanzará OSError; consulte rmdir() a continuación para eliminar un directorio.
46

os.removedirs(path)


Eliminar directorios de forma recursiva.
47

os.rename(src, dst)


Renombrar un archivo o directorio, de src a dst
48

os.renames(old, new)


Renombrar directorios de forma recursiva; también se pueden renombrar archivos.
49

os.rmdir(path)


Eliminar el directorio vacío especificado por path; si el directorio no está vacío, se lanza una excepción OSError.
50

os.stat(path)


Obtener la información de la ruta especificada por path, funcionalmente equivalente a la llamada al sistema stat() de la API de C.
51

os.stat_float_times([newvalue])
Determinar si stat_result muestra las marcas de tiempo como objetos float

52

os.statvfs(path)


Obtener las estadísticas del sistema de archivos de la ruta especificada
53

os.symlink(src, dst)


Crear un enlace simbólico
54

os.tcgetpgrp(fd)


Devolver el grupo de procesos asociado con el terminal fd (un descriptor de archivo abierto devuelto por os.open())
55

os.tcsetpgrp(fd, pg)


Establecer el grupo de procesos asociado con el terminal fd (un descriptor de archivo abierto devuelto por os.open()) como pg.
56

os.tempnam([dir[, prefix]])


Devolver un nombre de ruta único para crear un archivo temporal.
57

os.tmpfile()


Devolver un objeto de archivo abierto en modo (w+b). Este objeto de archivo no tiene entrada de carpeta ni descriptor de archivo, y se eliminará automáticamente.
58

os.tmpnam()


Devolver una ruta única para crear un archivo temporal
59

os.ttyname(fd)


Devolver una cadena que representa el dispositivo terminal asociado con el descriptor de archivo fd. Si fd no está asociado con un dispositivo terminal, se lanza una excepción.
60

os.unlink(path)


Eliminar archivo
61

os.utime(path, times)


Devolver los tiempos de acceso y modificación del archivo path especificado.
62

os.walk(top[, topdown=True[, onerror=None[, followlinks=False]]])


Generar los nombres de archivo en la carpeta recorriendo el árbol, hacia arriba o hacia abajo.
63

os.write(fd, str)


Escribir una cadena en el descriptor de archivo fd. Devuelve la longitud real de la cadena escrita.
64

Módulo os.path


Obtener la información de atributos del archivo.
