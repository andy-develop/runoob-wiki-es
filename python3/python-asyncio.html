Módulo Python asyncio

asyncioEs un módulo de la biblioteca estándar de Python, utilizado para escribir código de operaciones de E/S asíncronas.

asyncio proporciona una manera eficiente de manejar tareas concurrentes, especialmente adecuada para operaciones intensivas en E/S, como solicitudes de red, lectura/escritura de archivos, etc.

Al usar `asyncio`asyncio, puedes manejar múltiples tareas simultáneamente en un solo hilo, sin necesidad de usar múltiples hilos o múltiples procesos.

¿Por qué se necesita asyncio?

En la programación síncrona tradicional, cuando una tarea necesita esperar a que se complete una operación de E/S (como una solicitud de red), el programa se bloquea hasta que la operación finaliza. Esto provoca una baja eficiencia del programa, especialmente cuando se necesitan manejar muchas operaciones de E/S.

asyncioAl introducir el modelo de programación asíncrona, el programa puede continuar ejecutando otras tareas mientras espera operaciones de E/S, mejorando así la concurrencia y la eficiencia del programa.

Imagina que estás administrando un restaurante:

  • Modo síncrono (funciones normales):Tienes un solo chef. El cliente A pide un filete, el chef comienza a cocinarlo (esto requiere esperar 5 minutos). Durante esos 5 minutos de cocción, el chef está completamente ocupado y no puede hacer nada más; incluso si el cliente B solo quiere pedir un vaso de agua, tiene que esperar sin hacer nada.
  • Modo asíncrono (asyncio):Tienes varios chefs (en realidad sigue siendo uno, pero muy inteligente). Después de que el chef comienza a cocinar el filete del cliente A, se da cuenta de que necesita esperar; inmediatamente marca el filete como en espera y luego se dirige a servir agua al cliente B. Al volver, revisa si el filete está casi listo; si aún no lo está, puede atender el pedido del cliente C. Así, durante el tiempo de espera de E/S (como cocinar el filete, solicitudes de red, lectura/escritura de archivos), el chef (CPU) trabaja eficientemente.

asyncio es la biblioteca estándar que Python utiliza para implementar este inteligente modo de trabajo. Te permite escribir código de concurrencia de un solo hilo, especialmente adecuado para escenarios intensivos en E/S como rastreadores web, servidores web, microservicios, etc.

Su núcleo son el bucle de eventos, las corrutinas y las tareas.

Conceptos centrales de asyncio

1. Corrutina (Coroutine)

Una corrutina esasynciouno de los conceptos centrales de `asyncio`. Es una función especial que puede pausarse durante su ejecución y reanudarse más tarde. Las corrutinas se definen medianteasync defla palabra clave `async def` y, medianteawaitla palabra clave `await` se pausa la ejecución, esperando que se complete la operación asíncrona.

Ejemplo

import asyncio

async def say_hello():
    print("Hello")
    await asyncio.sleep(1)
    print("World")

2. Bucle de eventos (Event Loop)

El bucle de eventos esasyncioel componente central de `asyncio`, responsable de programar y ejecutar corrutinas. Comprueba continuamente si hay tareas que ejecutar y, cuando se completan, llama a las funciones de devolución de llamada correspondientes.

Ejemplo

async def main():
    await say_hello()

asyncio.run(main())

3. Tarea (Task)

Una tarea es una envoltura de una corrutina, que representa una corrutina en ejecución o por ejecutarse. Puedesasyncio.create_task()usar la función `create_task()` para crear tareas y agregarlas al bucle de eventos.

Ejemplo

async def main():
    task = asyncio.create_task(say_hello())
    await task

4. Future

Future`Future` es un objeto que representa el resultado de una operación asíncrona. Generalmente se usa en API de bajo nivel para representar una operación aún no completada. Puedesawaitusar la palabra clave `await` para esperarFuturea que `Future` se complete.

Ejemplo

async def main():
    future = asyncio.Future()
    await future

Explicación gráfica:awaitPor ejemplo, cuando espera una respuesta de la red, queda suspendida y el bucle de eventos inmediatamente busca en la cola la siguiente tarea que pueda ejecutarse (lista) para ejecutarla. Cuando la operación de E/S de la tarea suspendida se completa, el bucle de eventos recibe la notificación, cambia el estado de la tarea de nuevo a lista y continúa ejecutándola en algún momento futuro. De esta manera, durante la espera de E/S, la CPU se utiliza plenamente para ejecutar otras tareas, logrando concurrencia dentro de un solo hilo.

Uso básico de asyncio

1. Ejecutar una corrutina

Para ejecutar una corutina, puedes usar laasyncio.run()función. Esta crea un bucle de eventos y ejecuta la corutina especificada.

Ejemplo

import asyncio

async def main():
    print("Start")
    await asyncio.sleep(1)
    print("End")

asyncio.run(main())

2. Ejecutar múltiples tareas concurrentemente

Puedes usar laasyncio.gather()función para ejecutar varias corutinas concurrentemente y esperar a que todas se completen.

Ejemplo

import asyncio

async def task1():
    print("Task 1 started")
    await asyncio.sleep(1)
    print("Task 1 finished")

async def task2():
    print("Task 2 started")
    await asyncio.sleep(2)
    print("Task 2 finished")

async def main():
    await asyncio.gather(task1(), task2())

asyncio.run(main())

3. Control de tiempo de espera

Puedes usar laasyncio.wait_for()función para establecer un tiempo de espera para la corutina. Si la corutina no se completa en el tiempo especificado, se lanzaráasyncio.TimeoutErroruna excepción.

Ejemplo

import asyncio

async def long_task():
    await asyncio.sleep(10)
    print("Task finished")

async def main():
    try:
        await asyncio.wait_for(long_task(), timeout=5)
    except asyncio.TimeoutError:
        print("Task timed out")

asyncio.run(main())

Escenarios de aplicación de asyncio

asyncioEs especialmente adecuado para los siguientes escenarios:

  1. Solicitudes de red: como solicitudes HTTP, comunicación WebSocket, etc.
  2. E/S de archivos: como lectura y escritura de archivos asíncronas.
  3. Operaciones con bases de datos: como acceso asíncrono a bases de datos.
  4. Procesamiento de datos en tiempo real: como procesamiento de colas de mensajes en tiempo real.

3. Usar una cola asíncrona

Ejemplo

async def producer(queue):
    for i in range(5):
        await queue.put(i)
        await asyncio.sleep(0.1)

async def consumer(queue):
    while True:
        item = await queue.get()
        print(f"Consumed {item}")
        queue.task_done()

async def main():
    queue = asyncio.Queue()
    await asyncio.gather(
        producer(queue),
        consumer(queue)
    )

Notas importantes

  1. Versión de Python: algunas funciones requieren Python 3.7+ (por ejemplo,asyncio.run()）。

  2. Operaciones bloqueantes: evita usar código síncrono bloqueante en las corutinas (por ejemplo,time.sleep()）。

  3. Depuración: configurar laPYTHONASYNCIODEBUG=1variable de entorno habilita el modo de depuración.

  4. Cancelación de tareas: una tarea cancelada lanzaCancelledError, por lo que debe manejarse adecuadamente.
