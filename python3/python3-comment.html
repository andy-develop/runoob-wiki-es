Comentarios en Python3

En Python, los comentarios no afectan la ejecución del programa, pero hacen que el código sea más fácil de leer y entender.

En Python existen los siguientes tipos de comentarios:Comentarios de una sola línea和Comentarios de varias líneas。

Comentarios de una sola línea

En Python, los comentarios de una sola línea se escriben con#al principio,#Todo el texto después del símbolo se considera un comentario y no será ejecutado por el intérprete.

Ejemplo

# 这是一个注释
print("Hello, World!")
# 这也是注释

Comentarios de varias líneas

En Python, las cadenas de varias líneas (bloques de texto delimitados por tres comillas simples'''o tres comillas dobles""") pueden usarse como comentarios de varias líneas.

1. Usar tres comillas simples

Ejemplo

#!/usr/bin/python3

'''
这是多行注释，用三个单引号
这是多行注释，用三个单引号
这是多行注释，用三个单引号
'''
print("Hello, World!")

2. Usar tres comillas dobles

Ejemplo

#!/usr/bin/python3

"""
这是多行注释，用三个双引号
这是多行注释，用三个双引号
这是多行注释，用三个双引号
"""
print("Hello, World!")

Nota: Aunque las cadenas de varias líneas se usan aquí como comentarios de varias líneas, en realidad son cadenas; mientras no las usemos, no afectarán la ejecución del programa.

Estas cadenas se pueden colocar en ciertas posiciones del código sin que se ejecuten realmente, logrando así el efecto de un comentario.

Notas sobre los comentarios de varias líneas

En Python, los comentarios de varias líneas se definen mediante tres comillas simples'''o tres comillas dobles""", yEste tipo de comentario no se puede anidar.。

Cuando comienzas un bloque de comentario de varias líneas, Python tratará todas las líneas siguientes como comentario hasta encontrar otro grupo de tres comillas simples o tres comillas dobles.

Anidar comentarios de varias líneas provocará un error de sintaxis:

Ejemplo (ejemplo incorrecto)

'''
这是外部的多行注释
可以包含一些描述性的内容

    '''
这是尝试嵌套的多行注释
会导致语法错误
    '''
'''

En este ejemplo, las tres comillas simples internas no se reconocen correctamente como el final del comentario de varias líneas, sino que se interpretan como una cadena normal, lo que provoca una estructura de código incorrecta.

Forma correcta: usar comentarios de una sola línea anidados

Ejemplo (ejemplo correcto)

'''
这是外部的多行注释
可以包含一些描述性的内容

# 这是内部的单行注释
# 可以嵌套在多行注释中
'''

Docstring (cadena de documentación)

El Docstring (cadena de documentación) de Python es un tipo especial de comentario que se utiliza para añadir documentación a funciones, clases, módulos, etc. Es similar al Javadoc de Java, pero más potente y flexible.

A diferencia de los comentarios normales,el Docstring se puede__doc__acceder directamente mediante el atributo, o también se puede usar lahelp()función para verlo.

Sintaxis básica

El Docstring se escribe con tres comillas dobles"""o tres comillas simples'''que envuelven el texto, y se coloca al inicio de la función, clase o módulo.

Ejemplo

def add(a, b):
    """返回两数之和"""
    return a + b

# 通过 __doc__ 属性访问
print(add.__doc__)  # 输出: 返回两数之和

Usar help() para ver la documentación

Ejemplo

def add(a, b):
    """返回两数之和"""
    return a + b

# 使用 help() 函数
help(add)

Resultado esperado:

Help on function add in module __main__:

add(a, b)
    返回两数之和

Usar el módulo inspect para extraer la documentación

La biblioteca estándar de Python proporcionainspectmódulo, que puede extraer directamente el contenido de la documentación:

Ejemplo

import inspect

def add(a, b):
    """返回两数之和"""
    return a + b

# 使用 inspect.getdoc() 获取文档
print(inspect.getdoc(add))  # 输出: 返回两数之和

Resultado esperado:

Devuelve la suma de dos números

Docstring de varias líneas

Para funciones complejas, se puede usar un Docstring de varias líneas:

Ejemplo

def calculate(a, b, operation="add"):
    """
执行数学运算

参数:
a: 第一个数字
b: 第二个数字
operation: 操作类型，可选 "add", "subtract", "multiply"

返回:
计算结果
    """
    if operation == "add":
        return a + b
    elif operation == "subtract":
        return a - b
    elif operation == "multiply":
        return a * b
    else:
        raise ValueError("不支持的操作")

# 查看完整文档
help(calculate)

Resultado esperado:

Help on function calculate in module __main__:

calculate(a, b, operation='add')
    执行数学运算

    参数:
        a: 第一个数字
        b: 第二个数字
        operation: 操作类型，可选 "add", "subtract", "multiply"

    返回:
        计算结果

Docstring de clases

El Docstring también se puede usar para clases:

Ejemplo

class Person:
    """人物类，用于表示一个人的基本信息"""

    def __init__(self, name, age):
        """
初始化人物对象

参数:
name: 姓名
age: 年龄
        """
        self.name = name
        self.age = age

    def introduce(self):
        """介绍这个人"""
        return f"我叫{self.name}，今年{self.age}岁"

# 访问类的文档
print(Person.__doc__)

# 访问方法的文档
print(Person.introduce.__doc__)

Resultado esperado:

Clase Persona, utilizada para representar la información básica de una persona
Presentar a esta persona

Estándares de Docstring

En Python existen varios estilos de Docstring; los más comunes son:

  • Estilo Google: utiliza sangría con espacios, y los parámetros y valores de retorno tienen etiquetas claras.
  • Estilo Sphinx/reST: comienza con dos puntos, como:param name:。
  • Estilo NumPy: es similar al estilo Google, pero con un formato ligeramente diferente.

Se recomienda elegir un estilo en el proyecto y mantenerlo de forma consistente.
