Función tuple() de Python3

Funciones integradas de Python3

tuple()Es una función integrada en Python que se utiliza para convertir secuencias en tuplas.

Las tuplas son un tipo de secuencia inmutable; una vez creadas, no se pueden modificar.tuple()La función puede convertir objetos iterables como listas, cadenas, diccionarios, conjuntos, etc., en tuplas.

Definición del término： tupleSignifica 'tupla'; es un tipo de secuencia inmutable en Python.

Sintaxis básica y parámetros

Formato de sintaxis

tuple(iterable)

Descripción de parámetros

  • Parámetro iterable：
    • Tipo: objeto iterable (listas, cadenas, diccionarios, conjuntos, etc.)
    • Descripción: el objeto iterable que se va a convertir en tupla.

Descripción de la función

  • Valor de retorno: Devuelve una tupla.
  • Valor especial: Sin parámetros, devuelve una tupla vacía.()。

Ejemplos

Ejemplo 1: Conversión desde una lista

Ejemplo

# Convertir de lista a tupla
lst = [1, 2, 3, 4, 5]
t = tuple(lst)
print(t)        # Salida: (1, 2, 3, 4, 5)
print(type(t))  # Salida: <class 'tuple'>

# Convertir desde una cadena (cada carácter como un elemento)
s = "hello"
t = tuple(s)
print(t)        # Salida: ('h', 'e', 'l', 'l', 'o')

# Convertir desde un diccionario (solo se toman las claves)
d = {"a": 1, "b": 2}
t = tuple(d)
print(t)        # Salida: ('a', 'b')

# Convertir desde un conjunto
s = {1, 2, 3}
t = tuple(s)
print(t)        # Salida: (1, 2, 3) (el orden puede variar)

# Tupla vacía
t = tuple()
print(t)        # Salida: ()

Resultado esperado de la ejecución:

(1, 2, 3, 4, 5)
<class 'tuple'>
('h', 'e', 'l', 'l', 'o')
('a', 'b')
(1, 2, 3)
()

Análisis del código:

  1. La lista se convierte en tupla, manteniendo el orden de los elementos.
  2. Al convertir una cadena, cada carácter se convierte en un elemento de la tupla.
  3. La conversión de diccionarios solo incluye las claves, no los valores.

Ejemplo 2: Características de las tuplas

Ejemplo

# Las tuplas son inmutables
t = (1, 2, 3)
# t

# Se pueden usar como clave de diccionario
d = {(1, 2): "point", (3, 4): "origin"}
print(d)  # Salida: {(1, 2): 'point', (3, 4): 'origin'}

# Se pueden anidar
t = ((1, 2), (3, 4))
print(t)  # Salida: ((1, 2), (3, 4))

# Desempaquetado de tuplas
a, b, c = (1, 2, 3)
print(f"a={a}, b={b}, c={c}")  # Salida: a=1, b=2, c=3

Resultado esperado de la ejecución:

{(1, 2): 'point', (3, 4): 'origin'}
((1, 2), (3, 4))
a=1, b=2, c=3

Las tuplas son inmutables, se pueden usar como claves de diccionario y admiten operaciones de desempaquetado.
