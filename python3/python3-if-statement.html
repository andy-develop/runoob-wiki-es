Sentencia if de Python

Control de condiciones en Python3

En la programación en Python,ifLa sentencia es la estructura de control condicional más básica e importante. Se utiliza para decidir si se ejecuta un bloque de código específico según si la condición es verdadera o falsa.

De PythonifLa sentencia es muy intuitiva y legible; define bloques de código mediante la indentación, lo que es una gran característica que distingue a Python de otros lenguajes.

Significado de la palabra： ifSignifica "si", y es la entrada de la evaluación condicional.

Sintaxis básica y parámetros

ifLa sentencia es un bloque de código independiente que debe usarse junto con una expresión condicional.

Formato de sintaxis

if 条件表达式:
    代码块

Explicación de sintaxis

  • Expresión condicional: Cualquier expresión que devuelva un valor booleano (los números distintos de cero, cadenas no vacías, contenedores no vacíos, etc., se consideran verdaderos).
  • Dos puntos: Después de la expresión condicional deben añadirse dos puntos.
  • Indentación: El bloque de código debe estar indentado (normalmente 4 espacios); el código indentado pertenece al subbloque de la sentencia if.

Valor de retorno / Efecto

  • Sin valor de retorno: La sentencia if es una declaración de flujo de control y no devuelve ningún valor.
  • Efecto: Cuando la condición es True, se ejecuta el bloque indentado; de lo contrario, se omite.

Ejemplo

Vamos a dominar por completo, mediante una serie de ejemplos de simples a complejos,ifel uso de la sentencia.

Ejemplo 1: Uso básico - Determinar el tamaño de un número

Ejemplo

# Sentencia if básica
age = 18

if age >= 18:
    print("adulto")

print("Fin del programa")

Resultado esperado de la ejecución:

adulto

Análisis del código:

  1. age >= 18Es la expresión condicional, devuelve True.
  2. Como la condición se cumple, se ejecutaprint("成年人")。
  3. print("程序结束")No está dentro del bloque indentado de if, por lo que se ejecutará sin importar la condición.

Ejemplo 2: Determinar si una cadena está vacía

Ejemplo

# Comprobación de cadena
name = ""

# Cuando la cadena está vacía, es False
if name:
    print(f"Hola, {name}")
else:
    print("Por favor, ingresa el nombre")

# Cadena no vacía
name = "Tom"
if name:
    print(f"Hola, {name}")

Resultado esperado de la ejecución:

请输入名字
你好, Tom

Análisis del código:

  • En Python, las cadenas vacías, listas vacías, diccionarios vacíos, etc., se consideran False en la evaluación de condiciones.
  • Las cadenas no vacías se consideran True.

Ejemplo 3: Evaluación de múltiples condiciones

Ejemplo

# Comprobación de condiciones compuestas
score = 85

# Usando operadores lógicos
if score >= 60 and score < 90:
    print("Aprobado")

# Evaluar múltiples condiciones (notación abreviada)
if 60 <= score < 90:  # Comparación encadenada específica de Python
    print("Calificación entre 60-90")

# Usando la comprobación 'in'
colors = ["red", "green", "blue"]
if "red" in colors:
    print("Contiene rojo")

Resultado esperado de la ejecución:

及格了
成绩在 60-90 之间
包含红色

Análisis del código:

  • Python admite comparaciones encadenadas, como60 <= score < 90。
  • inEl operador se utiliza para determinar si un elemento está en una secuencia.

Ejemplo 4: Expresión if en una sola línea (operador ternario)

Ejemplo

# Expresión ternaria de Python
age = 20

# Formato: value1 if condición else value2
result = "Adulto" if age >= 18 else "Menor de edad"
print(result)  # Salida: Adulto

# Ejemplo más complejo
x = 10
y = 20
max_val = x if x > y else y
print(f"Valor mayor: {max_val}")  # Salida: Valor mayor: 20

Resultado esperado de la ejecución:

成年
较大值: 20

La expresión ternaria de Python es más concisa que en los lenguajes tradicionales, con el formatovalue1 if condition else value2。
