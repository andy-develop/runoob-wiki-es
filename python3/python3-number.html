Python3 Números (Number)

El tipo de dato numérico de Python se utiliza para almacenar valores numéricos.

Los tipos de datos no permiten cambios; esto significa que si se cambia el valor de un tipo de dato numérico, se reasignará espacio de memoria.

En el siguiente ejemplo, se creará un objeto Number al asignar la variable:

var1 = 1
var2 = 10

También puede usar la declaración del para eliminar referencias a algunos objetos numéricos.

La sintaxis de la declaración del es:

del var1[,var2[,var3[....,varN]]]

Puede eliminar referencias de uno o varios objetos usando la declaración del, por ejemplo:

del var
del var_a, var_b

Python admite tres tipos numéricos diferentes:

  • Entero (int)- A menudo se le llama entero o número entero; es un entero positivo o negativo sin punto decimal. En Python3, el tipo entero no tiene límite de tamaño y puede usarse como el tipo Long, por lo que Python3 no tiene el tipo Long de Python2. El booleano (bool) es un subtipo del tipo entero.

  • Flotante (float)- El tipo flotante se compone de una parte entera y una parte decimal. El tipo flotante también se puede representar con notación científica (2.5e2 = 2.5 x 102 = 250）

  • Complejo ((complex))- El número complejo se compone de una parte real y una parte imaginaria, y puede representarse como a + bj, o complejo(a, b). Tanto la parte real a como la parte imaginaria b son de tipo flotante.

>>> number

Python Conversión de tipos de números

A veces necesitamos convertir los tipos incorporados de datos. Para convertir un tipo de dato, solo necesita usar el tipo de dato como nombre de función.

  • int(x)Convierte x a un entero.

  • float(x)Convierte x a un número flotante.

  • complex(x)Convierte x a un número complejo, con parte real x y parte imaginaria 0.

  • complex(x, y)Convierte x e y a un número complejo, con parte real x y parte imaginaria y. x e y son expresiones numéricas.

El siguiente ejemplo convierte la variable flotante a a un entero:

>>> a = 1.0
>>> int(a)
1

Python Operaciones numéricas

El intérprete de Python puede usarse como una calculadora simple. Puede ingresar una expresión en el intérprete y este generará el valor de la expresión.

La sintaxis de las expresiones es muy sencilla:+, -, *y/, al igual que en otros lenguajes (como Pascal o C). Por ejemplo:

>>> 2 + 2
4
>>> 50 - 5*6
20
>>> (50 - 5*6) / 4
5.0
>>> 8 / 5  # 总是返回一个浮点数
1.6

Nota:Los resultados de las operaciones de punto flotante pueden variar en diferentes máquinas.

En la división de enteros, la división/siempre devuelve un número flotante. Si solo se desea el resultado entero, descartando la posible parte fraccionaria, puede usar el operador// ：

>>> 17 / 3  # 整数除法返回浮点型
5.666666666666667
>>>
>>> 17 // 3  # 整数除法返回向下取整后的结果
5
>>> 17 % 3  # ％操作符返回除法的余数
2
>>> 5 * 3 + 2 
17

Nota://El resultado no necesariamente es de tipo entero; depende del tipo de dato del numerador y el denominador.

>>> 7//2
3
>>> 7.0//2
3.0
>>> 7//2.0
3.0
>>>

El signo igual=se usa para asignar valores a variables. Después de la asignación, el intérprete no mostrará ningún resultado excepto el siguiente indicador.

>>> width = 20
>>> height = 5*9
>>> width * height
900

Python puede usar**el operador para realizar potencias:

>>> 5 ** 2  # 5 的平方
25
>>> 2 ** 7  # 2的7次方
128

Las variables deben ser "definidas" (es decir, asignarles un valor) antes de usarse; de lo contrario, se producirá un error:

>>> n   # 尝试访问一个未定义的变量
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'n' is not defined

Cuando se mezclan números de diferentes tipos en operaciones, los enteros se convierten a flotantes:

>>> 3 * 3.75 / 1.5
7.5
>>> 7.0 / 2
3.5

En el modo interactivo, el resultado de la última expresión mostrada se asigna a la variable_ . Por ejemplo:

>>> tax = 12.5 / 100
>>> price = 100.50
>>> price * tax
12.5625
>>> price + _
113.0625
>>> round(_, 2)
113.06

Aquí,_ la variable debe ser considerada por el usuario como una variable de solo lectura.

 Si x < y devuelve -1, si x == y devuelve 0, si x > y devuelve 1.Obsoleto en Python 3, use (x>y)-(x<y) en su lugar.。

Funciones de números aleatorios

Los números aleatorios se pueden usar en matemáticas, juegos, seguridad y otros campos. También se integran frecuentemente en algoritmos para mejorar la eficiencia de estos y aumentar la seguridad del programa.

Python incluye las siguientes funciones comunes de números aleatorios:

FunciónDescripción
choice(seq)Selecciona aleatoriamente un elemento de los elementos de una secuencia, por ejemplo random.choice(range(10)), selecciona aleatoriamente un entero de 0 a 9.
randrange ([start,] stop [,step]) Obtiene un número aleatorio de una colección que aumenta según una base específica dentro de un rango determinado. El valor predeterminado de la base es 1.
random() Genera aleatoriamente el siguiente número real, que está en el rango [0,1).
seed([x]) Cambia la semilla (seed) del generador de números aleatorios. Si no comprende su principio, no necesita establecer la semilla especialmente; Python elegirá la semilla por usted.
shuffle(lst) Ordena aleatoriamente todos los elementos de una secuencia.
uniform(x, y)Genera aleatoriamente el siguiente número real, que está en el rango [x,y].
