Python3 Números (Number)

El tipo de dato numérico de Python se utiliza para almacenar valores numéricos.

Los tipos de datos no permiten cambios; esto significa que si se cambia el valor de un tipo de dato numérico, se reasignará espacio de memoria.

En el siguiente ejemplo, se creará un objeto Number al asignar la variable:

var1 = 1
var2 = 10

También puede usar la declaración del para eliminar referencias a algunos objetos numéricos.

La sintaxis de la declaración del es:

del var1[,var2[,var3[....,varN]]]

Puede eliminar referencias de uno o varios objetos usando la declaración del, por ejemplo:

del var
del var_a, var_b

Python admite tres tipos numéricos diferentes:

  • Entero (int)- A menudo se le llama entero o número entero; es un entero positivo o negativo sin punto decimal. En Python3, el tipo entero no tiene límite de tamaño y puede usarse como el tipo Long, por lo que Python3 no tiene el tipo Long de Python2. El booleano (bool) es un subtipo del tipo entero.

  • Flotante (float)- El tipo flotante se compone de una parte entera y una parte decimal. El tipo flotante también se puede representar con notación científica (2.5e2 = 2.5 x 102 = 250）

  • Complejo ((complex))- El número complejo se compone de una parte real y una parte imaginaria, y puede representarse como a + bj, o complejo(a, b). Tanto la parte real a como la parte imaginaria b son de tipo flotante.

Python Conversión de tipos de números

A veces necesitamos convertir los tipos incorporados de datos. Para convertir un tipo de dato, solo necesita usar el tipo de dato como nombre de función.

  • int(x)Convierte x a un entero.

  • float(x)Convierte x a un número flotante.

  • complex(x)Convierte x a un número complejo, con parte real x y parte imaginaria 0.

  • complex(x, y)Convierte x e y a un número complejo, con parte real x y parte imaginaria y. x e y son expresiones numéricas.

El siguiente ejemplo convierte la variable flotante a a un entero:

>>> a = 1.0
>>> int(a)
1

Python Operaciones numéricas

El intérprete de Python puede usarse como una calculadora simple. Puede ingresar una expresión en el intérprete y este generará el valor de la expresión.

La sintaxis de las expresiones es muy sencilla:+, -, * 和 /, al igual que en otros lenguajes (como Pascal o C). Por ejemplo:

>>> 2 + 2
4
>>> 50 - 5*6
20
>>> (50 - 5*6) / 4
5.0
>>> 8 / 5  # 总是返回一个浮点数
1.6

Nota:Los resultados de las operaciones de punto flotante pueden variar en diferentes máquinas.

En la división de enteros, la división/siempre devuelve un número flotante. Si solo se desea el resultado entero, descartando la posible parte fraccionaria, puede usar el operador// ：

>>> 17 / 3  # 整数除法返回浮点型
5.666666666666667
>>>
>>> 17 // 3  # 整数除法返回向下取整后的结果
5
>>> 17 % 3  # ％操作符返回除法的余数
2
>>> 5 * 3 + 2 
17

Nota://El resultado no necesariamente es de tipo entero; depende del tipo de dato del numerador y el denominador.

>>> 7//2
3
>>> 7.0//2
3.0
>>> 7//2.0
3.0
>>>

El signo igual=se usa para asignar valores a variables. Después de la asignación, el intérprete no mostrará ningún resultado excepto el siguiente indicador.

>>> width = 20
>>> height = 5*9
>>> width * height
900

Python puede usar**el operador para realizar potencias:

>>> 5 ** 2  # 5 的平方
25
>>> 2 ** 7  # 2的7次方
128

Las variables deben ser "definidas" (es decir, asignarles un valor) antes de usarse; de lo contrario, se producirá un error:

>>> n   # 尝试访问一个未定义的变量
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'n' is not defined

Cuando se mezclan números de diferentes tipos en operaciones, los enteros se convierten a flotantes:

>>> 3 * 3.75 / 1.5
7.5
>>> 7.0 / 2
3.5

En el modo interactivo, el resultado de la última expresión mostrada se asigna a la variable_ . Por ejemplo:

>>> tax = 12.5 / 100
>>> price = 100.50
>>> price * tax
12.5625
>>> price + _
113.0625
>>> round(_, 2)
113.06

Aquí,_ la variable debe ser considerada por el usuario como una variable de solo lectura.

    "4 se descarta, 6 se redondea hacia arriba, 5 se alinea, los impares suben y los pares no" creo que no es un problema de representación de números de punto flotante en la computadora. La representación de punto flotante en la computadora es una regla estándar definida por IEEE. Si existe en Python, no hay razón para que no exista en otros lenguajes. De hecho, se debe a que este método de redondeo es más preciso en el cálculo científico que el antiguo método de "redondeo tradicional". Y el estándar nacional ya ha estipulado el uso de "4 se descarta, 6 se redondea hacia arriba, 5 se alinea, los impares suben y los pares no" para reemplazar el "redondeo tradicional".

    Desde el punto de vista estadístico, si una gran cantidad de datos adopta ciegamente el redondeo tradicional, los resultados estadísticos tenderán a ser más grandes. En cambio, el "impar sube, par se queda" puede minimizar el error de redondeo.

    "Impar sube, par se queda" es un método de retención de cifras relativamente preciso y científico, una regla de redondeo de números.

    Sus requisitos específicos son los siguientes (tomando como ejemplo la retención de dos decimales):

    • (1) Si el dígito posterior al dígito a conservar es 4 o menor, se descarta. Por ejemplo, 5.214 retiene dos decimales como 5.21.
    • (2) Si el dígito posterior al dígito a conservar es 6 o mayor, se redondea hacia arriba. Por ejemplo, 5.216 retiene dos decimales como 5.22.
    • (3) Si se va a conservar la parte entera o un solo decimal, se debe decidir "impar sube, par se queda" según el dígito retenido:
      >>> round(5.215,2)#实际并没有进位
5.21
>>> round(5.225,2)
5.22
>>>
>>> round(1.5)#此处进位
2
>>> round(1.5)==round(2.5)#偶数舍去
True
>>> round(1.15,1)
1.1
>>> round(1.25,1)
1.2
>>> round(1.151,1)
1.2
>>> round(1.251,1)
1.3
    • (4) Si el dígito posterior al dígito a conservar es 5 y hay más dígitos después, se redondea hacia arriba. Por ejemplo, 5.2152 retiene dos decimales como 5.22, 5.2252 retiene dos decimales como 5.23, 5.22500001 retiene dos decimales como 5.23.
    Desde el punto de vista estadístico, "impar sube, par se queda" es más científico que el "redondeo tradicional"; en operaciones masivas, hace que la media del error de los resultados redondeados tienda a cero, en lugar de redondear hacia arriba siempre que aparece un 5 como en el redondeo tradicional, lo que lleva a que los resultados se sesguen hacia números mayores, acumulando errores y generando así un error sistemático. "Impar sube, par se queda" minimiza el impacto del error de redondeo en los resultados de medición.

    Algunos peligros sobre la comparación de enteros en Python:

    En Python todo es un objeto, la comparación de objetos puede usar==ois。

    ==compara si el contenido de dos objetos es igual; por defecto se llama al método del objeto__eq__()método.

    iscompara si los id de dos objetos son iguales, es decir, si son el mismo objeto y si apuntan a la misma dirección de memoria.

    >>> a = 4
>>> b = 4
>>> a == b
True
>>> a is b
True
>>> a = 256
>>> b = 256
>>> a == b
True
>>> a is b
True
>>> a = 257
>>> b = 257
>>> a == b
True
>>> a is b
False

    Vemos que en los primeros grupos de comparaciones podemos entender los resultados mostrados, pero al final, cuando a/b apuntan al objeto entero 257, el resultado de la comparación con is es False.

    Esto se debe a que Python, por consideraciones de rendimiento, ha realizado una optimización interna: para los objetos enteros, almacena en caché algunos objetos enteros de uso frecuente, guardándolos en una lista llamadasmall_intsde lista enlazada.

    Durante todo el ciclo de vida de Python, cualquier lugar que necesite referenciar estos objetos enteros no volverá a crear nuevos objetos enteros; el rango es[-5,256]。

    Veamos el siguiente ejemplo:

    >>> a = 259
>>> def foo () :
...     b = 259
...     c = 259
...     print(a is b)
...     print(b is c)
...
>>> foo()
False
True

    Esto se debe a que los programas de Python están compuestos por bloques de código, y el bloque de código se ejecuta como la unidad básica más pequeña del programa. Un archivo de módulo / un cuerpo de función / una clase / una línea de código en un comando interactivo se llaman un bloque de código.

    En el programa anterior hay dos bloques de código: uno es el bloque donde se encuentra el nombre a, y otro es el bloque donde se encuentran los nombres b/c. Otra optimización de Python es que, si en el mismo bloque de código dos objetos enteros creados tienen valores iguales, entonces esos dos objetos referencian el mismo objeto entero. Por lo tanto, por consideraciones de rendimiento, para cualquier objeto inmutable en el mismo bloque de código, si los valores son iguales, no se vuelve a crear, sino que se referencia directamente el objeto ya existente. No solo los objetos enteros, sino también los objetos de cadena siguen el mismo principio.

    En realidad, la regla exacta de redondeo es la de los números de punto flotante binarios:

    >>> round(1.5,0) # 1.5d -> 0x3FF8000000000000 -> 1.5, 按照5后为0处理，奇进偶不进
2.0
>>> round(2.5,0) # 2.5 -> 0x4004000000000000 -> 2.5,  按照5后为0处理，奇进偶不进
2.0
>>> round(1.15,1) #1.15 ->0x3FF2666666666666 -> 1.14999999999999991118215802999 按照4处理，退位
1.1
>>> round(1.25,1) # 1.25 ->0x3FF4000000000000 ->1.25 同2.5退位
1.2
>>>

    Se puede considerar que el redondeo primero calcula la distancia al entero; si las distancias son iguales, entonces se produce el redondeo al par más cercano. Ten en cuenta que 1.15, debido al problema de la base, tiene distancias diferentes entre 1.1 y 1.2, por lo que no es el resultado del redondeo decimal.

    >>> abs(1.25-1.2)==abs(1.25-1.2)
True
>>> abs(1.15-1.2)==abs(1.15-1.1)
False

>>> _+1   # 优先引用用户变量（10），10+1=11,同时系统将11这个值赋给只读变量 _

    randrange() 和 uniform()son funciones en Python utilizadas para generar números aleatorios; ambas pertenecen alrandommódulo, pero se diferencian en el tipo y el rango de números aleatorios generados.

    Elige la función adecuada según tus necesidades:

    • Al generar números enteros aleatorios, usarandrange()。

    • Al generar números de punto flotante aleatorios, usauniform()。

    A continuación se presentan sus diferencias y similitudes:

    Diferencia

    1. Módulo al que pertenecen

    • Ambos pertenecen alrandommódulo; antes de usarlo, primero se debe importar el módulo:import random

    2. Tipo de número aleatorio generado

    • randrange()Generanúmeros enteros aleatorios。

    • uniform()Generanúmeros de punto flotante aleatorios。

    3. Rango del número aleatorio generado

    • randrange()El rango es[start, stop), es decir, incluyestartpero no incluyestop. Se puedestepespecificar el paso mediante el parámetro, para controlar el intervalo entre los números aleatorios.

    • uniform()El rango es[a, b], es decir, incluyea 和 b. Los números de punto flotante aleatorios generados estána 和 bdistribuidos uniformemente entre.

    Parte común

    1. Ambos pertenecen al mismorandommódulo

    • Ambos se utilizan para generar números aleatorios, y ambos dependen delrandommódulo.

    2. Control de rango

    • Ambos permiten especificar el rango de números aleatorios generados.

    3. Aleatoriedad

    • Los números aleatorios generados son números pseudoaleatorios; cuando se basan en la misma semilla (seed), los resultados son reproducibles.

    Comparación de ejemplos

    Generar un número aleatorio entre 1 y 10

    Generar un número aleatorio entre 1 y 10, usando randrange():

    import random
num = random.randrange(1, 11)  # 生成 1 到 10 之间的随机整数
print(num)

    Generar un número aleatorio entre 1 y 10, usando uniform():

    import random
num = random.uniform(1.0, 10.0)  # 生成 1.0 到 10.0 之间的随机浮点数
print(num)
