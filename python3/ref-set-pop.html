Método pop() de Python Set

Conjuntos de Python

Descripción

El método pop() se utiliza para eliminar y devolver un elemento aleatorio del conjunto. Si el conjunto está vacío, se lanza una excepción KeyError.

Sintaxis

Sintaxis del método pop():

set.pop()

Parámetros

  • 无

Valor de retorno

Devuelve el elemento eliminado.

Ejemplo

Elimina un elemento aleatorio:

Ejemplo 1

fruits = {"apple", "banana", "cherry"} fruits.pop() print(fruits)

El resultado es:

{'apple', 'banana'}

Valor de retorno (salida):

Ejemplo 1

fruits = {"apple", "banana", "cherry"} x = fruits.pop() print(x)

El resultado es:

banana

Notas

  • Los elementos de un conjunto no están ordenados, por lo que cada vez que se llama alpop()método, el elemento eliminado es aleatorio.
  • Si necesita eliminar un elemento específico, debe usarremove() 或 discard()método, en lugar depop()。

    Durante mi aprendizaje, descubrí que el método pop() del conjunto set no es como se describe arriba, que simplemente elimina un elemento al azar, sino que sigue ciertas reglas. Resumo las reglas que descubrí de la siguiente manera:

    # 执行下面的代码,并查看输出结果:
print('pop()函数的输出结果 看这里:')
s1={4,2,1,5} # 集合里只有数字
s2={'你','我','他'} # 集合里无数字
s3={3,2,4,'你','X'} # 集合里既有数字又有非数字
s1.pop() # 元素是数字时, 删除最小的数字, 其余数字升序排列
s2.pop() # 元素非数字时, 随机删除一个元素, 其余元素随机排序
s3.pop() # 元素既有数字又含非数字时, 如果删除的是数字, 则一定删最小的, 否则随机删除一个非数字元素
print(s1)
print(s2)
print(s3) # 这个代码执行后, 输出的结果是随机的

    El siguiente es el resultado impreso 1 (eliminando aleatoriamente un elemento no numérico):

    pop()函数的输出结果 看这里:
{2, 4, 5}
{'你', '我'}
{2, 3, 4, 'X'}

    El siguiente es el resultado 2 (lo eliminado es un número, pero se elimina el número más pequeño; los demás elementos numéricos se ordenan en orden ascendente, los elementos no numéricos se ordenan aleatoriamente):

    pop()函数的输出结果 看这里:
{2, 4, 5}
{'我', '你'}
{3, 4, 'X', '你'}

    El siguiente es el resultado 3 (lo eliminado es un número, pero se elimina el número más pequeño; los demás elementos numéricos se ordenan en orden ascendente, los elementos no numéricos se ordenan aleatoriamente):

    pop()函数的输出结果 看这里:
{2, 4, 5}
{'他', '你'}
{3, 4, '你', 'X'}

    Resumen:

    1. Si los elementos del conjunto son todos números, al eliminar, se elimina el número más pequeño, y el resto de los números se ordenan en orden ascendente.

    2. Si los elementos del conjunto son no numéricos, al eliminar, se elimina un elemento aleatorio, y el resto de los elementos se ordenan aleatoriamente.

    3. Si el conjunto tiene tanto números como elementos no numéricos, al eliminar:

    • Si lo eliminado es un número, entonces definitivamente se elimina el más pequeño, los otros números se ordenan en orden ascendente, y los elementos no numéricos se ordenan aleatoriamente;
    • Si lo eliminado es un no número, entonces definitivamente se elimina uno al azar, los otros números se ordenan en orden ascendente, y los no números se ordenan aleatoriamente.

    Complementando lo anterior, para la eliminación de números, conjuntos con el mismo contenido producen exactamente el mismo resultado al ejecutarse varias veces, pero no necesariamente se elimina el número más pequeño, sino que muestra una regla de comparación similar a las cadenas, es decir, los números cuyo dígito más alto es 2 se eliminan después de los números cuyo dígito más alto es 1. Sin embargo, el orden de eliminación de 1 y 100 sigue siendo desconocido (los resultados son diferentes en distintos conjuntos).

    El siguiente es el código de prueba:

    def print_pop():
    b = {1, 10, 20, 100}
    print(b.pop(), end="\t")
    print(b.pop(), end="\t")
    print(b.pop(), end="\t")
    print("number only \n")
    d = {1, 10, 20, 100, 101, 200}
    print(d.pop(), end="\t")
    print(d.pop(), end="\t")
    print(d.pop(), end="\t")
    print("another number only \n")


print_pop()

    El siguiente es el resultado de la prueba:

    100    1    10    number only

    Complementando, la versión es 3.11.2:

    En cuanto alset.pop()orden de eliminación, descubrí que está relacionado con el orden real de almacenamiento del conjunto en la memoria, con la siguiente declaración:

    >>>d = {1,10,20,100,101,200}
>>>d
   {1,100,101,20,200,10}
>>>d.pop()
   1
>>>d.pop()
   100
>>>d.pop()
   101
>>>d.pop()
   20
>>>d.pop()
   200
>>>d.pop()
   10

    Se encontrará que set.pop() elimina cada vez el primer elemento del set, pero como el orden de almacenamiento del contenido de d es 1, 100, 101, 20, 200, 10, se eliminarán en ese orden; para el caso en que el set solo tiene elementos no numéricos, lo aleatorio es en realidad el orden de almacenamiento del contenido del conjunto, y cada asignación cambia el orden del contenido, pero pop sigue eliminando en orden de izquierda a derecha, por lo que parece que con asignaciones repetidas, el resultado de la eliminación es diferente.

    >>>d = {'你','我','他'}
>>>d
   {'你','他','我'}
>>>d.pop()
   '你'
>>>d.pop()
   '他'
>>>d.pop()
   '我'
