Función PyTorch torch.linalg.solve

Manual de referencia de Pytorch torch

torch.linalg.solveEs una función en el módulo de álgebra lineal de PyTorch para resolver sistemas de ecuaciones lineales. Resuelve AX = B.

Definición de la función

torch.linalg.solve(A, B, left=True, out=None)

Parámetros:

  • A(Tensor): Matriz de coeficientes.
  • B(Tensor): Matriz o vector del lado derecho.
  • left(bool, opcional): Si es True, resuelve AX = B; de lo contrario, resuelve XA = B. El valor predeterminado es True.
  • out(Tensor, opcional): Tensor de salida.

Valor de retorno:

  • torch.Tensor: Devuelve la solución del sistema de ecuaciones lineales.

Ejemplo de uso

Ejemplo

import torch

# Crear la matriz de coeficientes y el vector del lado derecho
A = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
B = torch.tensor([5.0, 11.0])

# Resolver AX = B
X = torch.linalg.solve(A, B)

print("Matriz de coeficientes A:")
print(A)
print("nVector del lado derecho B:")
print(B)
print("nSolución X:")
print(X)
print("nVerificación: A @ X =")
print(A @ X)

El resultado de salida es:

系数矩阵 A:
tensor([[1., 2.],
        [3., 4.]])
右侧向量 B:
tensor([ 5., 11.])
解 X:
tensor([1., 2.])
验证: A @ X =
tensor([ 5., 11.])
