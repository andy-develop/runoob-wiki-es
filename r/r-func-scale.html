Función scale() en R - Estandarización de datos

Ejemplos en R

La función scale() en R se utiliza para estandarizar datos (estandarización z-score).

Después de la estandarización, la media de los datos es 0 y la desviación estándar es 1, se usa comúnmente para eliminar el impacto de las diferentes escalas de medida.

La sintaxis de la función scale() es la siguiente:

scale(x, center = TRUE, scale = TRUE)

Descripción de parámetros:

  • xIngrese una matriz numérica o data frame.

  • centerSi se realiza el centrado (restar la media), el valor predeterminado es TRUE.

  • scaleSi se realiza el escalado (dividir por la desviación estándar), el valor predeterminado es TRUE.

Ejemplos

# Datos originales: variables en diferentes escalas
height <- c(160, 170, 165, 175, 180)     # Rango 160-180
income <- c(50000, 60000, 55000, 80000, 90000)  # Rango 50000-90000
age <- c(25, 30, 28, 35, 40)             # Rango 25-40

# Combinar en matriz
data_matrix <- cbind(height, income, age)
print("Datos originales:")
print(data_matrix)

# Estandarización
scaled_data <- scale(data_matrix)
print("Después de la estandarización (media 0, desviación estándar 1):")
print(round(scaled_data, 3))

# Verificar la media y la desviación estándar
print("Medias de cada columna después de la estandarización (deberían ser cercanas a 0):")
print(round(colMeans(scaled_data), 3))
print("Desviaciones estándar de cada columna después de la estandarización (deberían ser iguales a 1):")
print(round(apply(scaled_data, 2, sd), 3))
