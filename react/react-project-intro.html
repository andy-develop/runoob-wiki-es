Cuestionario de React

Descripción del proyecto React

Un proyecto React típico está compuesto por múltiples archivos y carpetas, y cada parte tiene su función específica.

Este capítulo dará una explicación básica del código de un proyecto React, para ayudar a todos a comprender la estructura del proyecto y las funciones de cada parte.

  • Un proyecto React está compuesto por varios archivos y carpetas; los archivos centrales incluyen:index.html、index.js 和 App.js。

  • Los componentes de React son los bloques de construcción básicos de una aplicación; pueden ser componentes de función o componentes de clase.

  • JSX es la sintaxis central de React, utilizada para describir la interfaz de usuario (UI).

  • Props y State son las principales formas de gestionar datos en los componentes de React.

Estructura del proyecto

Un proyecto React normalmente incluye los siguientes archivos y carpetas:

my-react-app/
├── node_modules/       # 项目依赖的第三方库
├── public/             # 静态资源文件夹
│   ├── index.html      # 应用的 HTML 模板
│   └── ...             # 其他静态资源（如图片、字体等）
├── src/                # 项目源代码
│   ├── App.js          # 主组件
│   ├── App.css         # 主组件的样式
│   ├── index.js        # 项目入口文件
│   ├── index.css       # 全局样式
│   └── ...             # 其他组件和资源
├── package.json        # 项目配置和依赖管理
├── package-lock.json   # 依赖的精确版本锁定文件
└── README.md           # 项目说明文档

src/index.js

src/index.jsEs el archivo de entrada de la aplicación React.

src/index.jsSe encarga de renderizar el componente raíz (normalmente App) en el div#root de index.html.

Ejemplo

import React from 'react';
import ReactDOM from 'react-dom';
import App from './App';
import './index.css';

ReactDOM.render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
  document.getElementById('root')
);

src/App.js

src/App.jsEs el componente raíz de la aplicación React.

src/App.jsNormalmente contiene la lógica y la estructura principal de la aplicación.

Ejemplo

import React from 'react';
import './App.css';

function App() {
  return (
    <div className="App">
      <h1>Hello, React!</h1>
    </div>
  );
}

export default App;

Estructura básica de los componentes de React

Los componentes de React son los bloques de construcción centrales de una aplicación React.

Un componente normalmente contiene las siguientes partes:

1. Componente de función

Un componente definido mediante una función.

Ejemplo

import React from 'react';

function MyComponent() {
  return (
    <div>
      <h2>Este es un componente definido por función.</h2>
    </div>
  );
}

export default MyComponent;

Explicación:

  • import React from 'react';: Se importa la librería React, que es una librería de JavaScript para construir interfaces de usuario.

  • function MyComponent() { ... }: Este es un componente de función. Un componente de función es una función de JavaScript que devuelve JSX.

  • return (...): del componentereturnLa sentencia devuelve un elemento JSX. JSX es una extensión de sintaxis de JavaScript que te permite escribir código similar a HTML en JavaScript.

  • export default MyComponent;: ExportaMyComponentel componente como exportación predeterminada. De esta manera, otros archivos puedenimport MyComponent from './MyComponent';importar y usar este componente.
