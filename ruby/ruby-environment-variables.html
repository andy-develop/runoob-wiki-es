Ruby Variables de entorno

El intérprete de Ruby utiliza las siguientes variables de entorno para controlar su comportamiento. El objeto ENV contiene una lista de todas las variables de entorno configuradas actualmente.

VariableDescripción
DLN_LIBRARY_PATHRuta de búsqueda para módulos de carga dinámica.
HOMEEl directorio al que moverse cuando no se pasan argumentos a Dir::chdir. También se usa en File::expand_path para expandir "~".
LOGDIREl directorio al que moverse cuando no se pasan argumentos a Dir::chdir y no se ha establecido la variable de entorno HOME.
PATHRuta de búsqueda para ejecutar subprocesos y, cuando se especifica la opción -S, ruta de búsqueda para programas Ruby. Cada ruta se separa con dos puntos (con punto y coma en DOS y Windows).
RUBYLIBRuta de búsqueda de librerías. Cada ruta se separa con dos puntos (con punto y coma en DOS y Windows).
RUBYLIB_PREFIXSe utiliza para modificar la ruta de búsqueda de RUBYLIB, reemplazando el prefijo de librería path1 por path2 mediante el formato path1;path2 o path1path2.
RUBYOPTOpciones de línea de comandos que se pasan al intérprete de Ruby. Se ignoran en modo taint (cuando $SAFE es mayor que 0).
RUBYPATHRuta de búsqueda para programas Ruby tras especificar la opción -S. Tiene prioridad sobre PATH. Se ignora en modo taint (cuando $SAFE es mayor que 0).
RUBYSHELLEspecifica el shell utilizado al ejecutar comandos. Si esta variable de entorno no está establecida, se utiliza SHELL o COMSPEC.
