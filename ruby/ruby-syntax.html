Ruby Sintaxis

Escribamos un programa Ruby simple. Todas las extensiones de archivo Ruby son.rb. Por lo tanto, coloque el siguiente código fuente en el archivo test.rb.

Ejemplo

#!/usr/bin/ruby -w puts "Hello, Ruby!";

Ejecutar ejemplo »

Aquí, asumimos que ya tiene un intérprete de Ruby disponible en el directorio /usr/bin. Ahora, intente ejecutar este programa como se muestra a continuación:

$ ruby test.rb

Esto producirá el siguiente resultado:

Hello, Ruby!

Ya ha visto un programa Ruby simple, ahora veamos algunos conceptos básicos relacionados con la sintaxis de Ruby:

Espacios en blanco en programas Ruby

Los caracteres de espacio en blanco en el código Ruby, como los espacios y las tabulaciones, generalmente se ignoran, a menos que aparezcan en una cadena, en cuyo caso no se ignoran. Sin embargo, a veces se utilizan para interpretar sentencias ambiguas. Cuando se habilita la opción -w, esta interpretación genera una advertencia.

Ejemplo:

a + b 被解释为 a+b （这是一个局部变量）
a  +b 被解释为 a(+b) （这是一个方法调用）

Finales de línea en programas Ruby

Ruby interpreta el punto y coma y el carácter de nueva línea como el final de una sentencia. Sin embargo, si Ruby encuentra un operador al final de la línea, como +, - o una barra invertida, estos indican la continuación de una sentencia.

Identificadores Ruby

Los identificadores son nombres de variables, constantes y métodos. Los identificadores Ruby distinguen entre mayúsculas y minúsculas. Esto significa que Ram y RAM son dos identificadores diferentes en Ruby.

Los nombres de los identificadores Ruby pueden contener letras, números y el carácter de subrayado ( _ ).

Here Document en Ruby

Un "Here Document" se refiere a la creación de cadenas de múltiples líneas. Después de <<, puede especificar una cadena o identificador para terminar la cadena, y todas las líneas desde la línea actual hasta el terminador son el valor de la cadena.

Si el terminador se encierra entre comillas, el tipo de comillas determina el tipo de cadena orientada a líneas. Tenga en cuenta que no debe haber espacios entre << y el terminador.

A continuación se muestran diferentes ejemplos:

Ejemplo

#!/usr/bin/ruby -w # -*- coding : utf-8 -*- print <<EOFEsta es la primera forma de crearhere document. Cadena de múltiples líneas.EOF print <<"EOF"; #Igual que arribaEsta es la segunda forma de crearhere document. Cadena de múltiples líneas.EOF print <<`EOC` #Ejecutar comando echo hi there echo lo there EOC print <<"foo", <<"bar" #Puede apilarlos I said foo. foo I said bar. bar

Ruby BEGINSentencia

Sintaxis

BEGIN {
   code
}

Declaracióncodese llamará antes de que el programa se ejecute.

Ejemplo

#!/usr/bin/ruby puts "Este es el programa Ruby principal" BEGIN { puts "Inicializando el programa Ruby" }

Esto producirá el siguiente resultado:

初始化 Ruby 程序
这是主 Ruby 程序

Ruby ENDSentencia

Sintaxis

END {
   code
}

Declaracióncodese llamará al final del programa.

Ejemplo

#!/usr/bin/ruby puts "Este es el programa Ruby principal" END { puts "Deteniendo el programa Ruby" } BEGIN { puts "Inicializando el programa Ruby" }

Esto producirá el siguiente resultado:

Comentarios en Ruby

Los comentarios ocultan una línea, parte de una línea o varias líneas al intérprete de Ruby. Puede usar el carácter ( # ) al principio de la línea:

#Soy un comentario, ignórame.

O bien, los comentarios pueden ir después de una sentencia o expresión en la misma línea:

name = "Madisetti" #Esto también es un comentario

Puede comentar varias líneas, como se muestra a continuación:

#Esto es un comentario. #Esto también es un comentario. #Esto también es un comentario. #Esto sigue siendo un comentario.

A continuación se muestra otra forma. Este comentario de bloque oculta al intérprete las líneas entre =begin/=end:

=beginEsto es un comentario. Esto también es un comentario. Esto también es un comentario. Esto sigue siendo un comentario.=end
