Optimizador de SciPy

El módulo de SciPyoptimizeproporciona implementaciones de algoritmos comunes de optimización numérica y resolución de ecuaciones. Podemos llamar directamente a estas funciones para resolver problemas reales, como encontrar mínimos, máximos de funciones o las raíces de ecuaciones, entre otros.

NumPy en sí mismo se centra principalmente en el cálculo con arrays y operaciones de álgebra lineal; proporciona herramientas paraencontrar raíces de polinomios(comonumpy.roots),interfaz numérica para resolver raíces de ecuaciones no lineales.

Por ejemplo, la siguiente ecuación no lineal:

x + cos(x)

Para este tipo de problemas, se puede utilizar la funciónscipy.optimize.rootfunción para resolverla. Los dos parámetros principales que se usan comúnmente en esta función son los siguientes:

  • fun- La función que representa la ecuación (cuando el valor de retorno es 0, significa que se ha encontrado la raíz de la ecuación)
  • x0- El valor inicial estimado de la raíz

rootLa función devuelve un objeto de resultado (OptimizeResult),

que contiene información como el estado de la resolución, si fue exitosa, el valor de la función y la solución final. La solución realmente obtenida se almacena en el atributoxdel objeto devuelto, como se muestra a continuación:

Ejemplo

Hallarx + cos(x) = 0la raíz de la ecuación:

from scipy.optimize import root
from math import cos

def eqn(x):
    return x + cos(x)

myroot = root(eqn, 0)

print(myroot.x)

Función de minimización

En problemas matemáticos y de ingeniería, una función suele representarse como una curva, y la curva suele tener puntos altos y bajos.

Los puntos altos de la curva se denominanmáximos。

Los puntos bajos de la curva se denominanmínimos。

El punto más alto de toda la curva se denominamáximo global,los demás puntos altos que no son el más alto se denominan。

máximos localesDe manera similar, el punto más bajo de toda la curva se denominamínimo global,。

los demás puntos bajos que no son el más bajo se denominanscipy.optimize.minimize()mínimos locales

from math import sin

def objective(x):
    return sin(x) + 0.5 * x

result = minimize(objective, 0, method='Nelder-Mead')
