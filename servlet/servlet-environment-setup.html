Servlet Configuración del entorno

El entorno de desarrollo es el lugar donde puede desarrollar, probar y ejecutar Servlets.

Como cualquier otro programa Java, necesita usar el compilador de Javajavacpara compilar Servlets. Después de compilar la aplicación Servlet, despliéguela en el entorno configurado para probarla y ejecutarla.

Si está utilizando el entorno Eclipse, puede consultar directamente:Configuración del entorno Eclipse JSP/Servlet。

Esta configuración del entorno de desarrollo incluye los siguientes pasos:

Configurar el kit de desarrollo de Java (Java Development Kit)

Este paso implica descargar el kit de desarrollo de software de Java (SDK, es decir, Software Development Kit) y configurar adecuadamente la variable de entorno PATH.

Puede descargar el SDK desde el sitio web de Java de Oracle:Java SE Downloads。

Una vez que haya descargado el SDK, siga las instrucciones dadas para instalarlo y configurarlo. Finalmente, establezca las variables de entorno PATH y JAVA_HOME para que apunten a los directorios que contienen java y javac, normalmente java_install_dir/bin y java_install_dir, respectivamente.

Si está ejecutando Windows y ha instalado el SDK en C:\jdk1.5.0_20, debe agregar las siguientes líneas en su archivo C:\autoexec.bat:

set PATH=C:\jdk1.5.0_20\bin;%PATH%
set JAVA_HOME=C:\jdk1.5.0_20

Alternativamente, en Windows NT/2000/XP, también puede hacer clic derecho en 'Mi PC', seleccionar 'Propiedades', luego 'Opciones avanzadas' y 'Variables de entorno'. Después, actualice el valor de PATH y presione el botón 'Aceptar'.

En Unix (Solaris, Linux, etc.), si el SDK está instalado en /usr/local/jdk1.5.0_20 y está utilizando C shell, debe agregar las siguientes líneas en su archivo .cshrc:

setenv PATH /usr/local/jdk1.5.0_20/bin:$PATH
setenv JAVA_HOME /usr/local/jdk1.5.0_20

Además, si utiliza un entorno de desarrollo integrado (IDE, es decir, Integrated Development Environment), como Borland JBuilder, Eclipse, IntelliJ IDEA o Sun ONE Studio, compile y ejecute un programa simple para confirmar que el IDE conoce la ruta de Java que ha instalado.

Para más detalles, consulte:Configuración del entorno de desarrollo de Java

Configurar el servidor de aplicaciones web: Tomcat

Hay muchos servidores de aplicaciones web en el mercado que soportan Servlet. Algunos servidores de aplicaciones web se pueden descargar gratuitamente; Tomcat es uno de ellos.

Apache Tomcat es una implementación de software de código abierto de las tecnologías Java Servlet y JavaServer Pages. Puede usarse como un servidor independiente para probar Servlets y también puede integrarse en el servidor de aplicaciones web Apache. A continuación se muestran los pasos para instalar Tomcat en su computadora:

  • desdehttp://tomcat.apache.org/Descargue la última versión de Tomcat.
  • Una vez que haya descargado Tomcat, descomprímalo en una ubicación conveniente. Por ejemplo, si está utilizando Windows, descomprímalo en C:\apache-tomcat-5.5.29; si está utilizando Linux/Unix, descomprímalo en /usr/local/apache-tomcat-5.5.29, y cree la variable de entorno CATALINA_HOME que apunte a estas ubicaciones.

En Windows, puede iniciar Tomcat ejecutando el siguiente comando:

 %CATALINA_HOME%\bin\startup.bat

 或者

 C:\apache-tomcat-5.5.29\bin\startup.bat

En Unix (Solaris, Linux, etc.), puede iniciar Tomcat ejecutando el siguiente comando:

$CATALINA_HOME/bin/startup.sh

 或者

/usr/local/apache-tomcat-5.5.29/bin/startup.sh

Después de que Tomcat se inicie, puede ingresar en la barra de direcciones del navegadorhttp://localhost:8080/para acceder a la aplicación predeterminada en Tomcat. Si todo va bien, se mostrará el siguiente resultado:

Para obtener más información sobre la configuración y ejecución de Tomcat, puede consultar la documentación incluida en la instalación de la aplicación, o visitar el sitio web de Tomcat:http://tomcat.apache.org。

En Windows, puede detener Tomcat ejecutando el siguiente comando:

C:\apache-tomcat-5.5.29\bin\shutdown

En Unix (Solaris, Linux, etc.), puede detener Tomcat ejecutando el siguiente comando:

/usr/local/apache-tomcat-5.5.29/bin/shutdown.sh

Configurar CLASSPATH

Debido a que Servlet no forma parte de la plataforma Java Standard Edition, debe especificar la ruta de las clases Servlet para el compilador.

Si está ejecutando Windows, debe agregar las siguientes líneas en su archivo C:\autoexec.bat:

set CATALINA=C:\apache-tomcat-5.5.29
set CLASSPATH=%CATALINA%\common\lib\servlet-api.jar;%CLASSPATH%

Alternativamente, en Windows NT/2000/XP, también puede hacer clic derecho en 'Mi PC', seleccionar 'Propiedades', luego 'Opciones avanzadas' y 'Variables de entorno'. Después, actualice el valor de CLASSPATH y presione el botón 'Aceptar'.

En Unix (Solaris, Linux, etc.), si está utilizando C shell, debe agregar las siguientes líneas en su archivo .cshrc:

setenv CATALINA=/usr/local/apache-tomcat-5.5.29
setenv CLASSPATH $CATALINA/common/lib/servlet-api.jar:$CLASSPATH

Nota:Asumiendo que su directorio de desarrollo es C:\ServletDevel (en Windows) o /user/ServletDevel (en UNIX), también necesita agregar estos directorios al CLASSPATH, de manera similar a la forma anterior.
