Sentencia ALTER TABLE

La declaración ALTER TABLE se utiliza para agregar, eliminar o modificar columnas en una tabla existente.

Sintaxis de SQL ALTER TABLE

Para agregar una columna en una tabla, use la siguiente sintaxis:

ALTER TABLE table_name
ADD column_name datatype

Para eliminar una columna de una tabla, use la siguiente sintaxis (tenga en cuenta que algunos sistemas de bases de datos no permiten esta forma de eliminar columnas en una tabla de base de datos):

ALTER TABLE table_name
DROP COLUMN column_name

Para cambiar el tipo de datos de una columna en una tabla, use la siguiente sintaxis:

SQL Server / MS Access：

ALTER TABLE table_name
ALTER COLUMN column_name datatype

My SQL / Oracle：

ALTER TABLE table_name
MODIFY COLUMN column_name datatype

Versiones posteriores a Oracle 10G:

ALTER TABLE table_name
MODIFY column_name datatype;

Ejemplo de SQL ALTER TABLE

Mire la tabla "Persons":

P_Id LastName FirstName Address City
1 Hansen Ola Timoteivn 10 Sandnes
2 Svendson Tove Borgvn 23 Sandnes
3 Pettersen Kari Storgt 20 Stavanger

Ahora, queremos agregar una columna llamada "DateOfBirth" en la tabla "Persons".

Usamos la siguiente declaración SQL:

ALTER TABLE Persons
ADD DateOfBirth date

Tenga en cuenta que el tipo de la nueva columna "DateOfBirth" es date, que puede almacenar fechas. El tipo de datos especifica el tipo de datos que se pueden almacenar en la columna. Para obtener más información sobre los tipos de datos disponibles en MS Access, MySQL y SQL Server, visite nuestro completoManual de referencia de tipos de datos。

Ahora, la tabla "Persons" se verá de la siguiente manera:

P_Id LastName FirstName Address City DateOfBirth
1 Hansen Ola Timoteivn 10 Sandnes
2 Svendson Tove Borgvn 23 Sandnes
3 Pettersen Kari Storgt 20 Stavanger

Ejemplo de cambio de tipo de datos

Ahora, queremos cambiar el tipo de datos de la columna "DateOfBirth" en la tabla "Persons".

Usamos la siguiente declaración SQL:

ALTER TABLE Persons
ALTER COLUMN DateOfBirth year

Tenga en cuenta que ahora el tipo de la columna "DateOfBirth" es year, que puede almacenar años en formato de 2 o 4 dígitos.

Ejemplo de DROP COLUMN

A continuación, queremos eliminar la columna "DateOfBirth" en la tabla "Person".

Usamos la siguiente declaración SQL:

ALTER TABLE Persons
DROP COLUMN DateOfBirth

Ahora, la tabla "Persons" se verá de la siguiente manera:

P_Id LastName FirstName Address City
1 Hansen Ola Timoteivn 10 Sandnes
2 Svendson Tove Borgvn 23 Sandnes
3 Pettersen Kari Storgt 20 Stavanger
