HTML <link> relAtributo

Etiqueta HTML <link>

Ejemplo

Una hoja de estilo externa:

<link rel="stylesheet" type="text/css" href="theme.css.html">

Pruébalo »

Soporte del navegador

Todos los navegadores principales admiten el atributo rel.

Definición y uso

El atributo rel es obligatorio y especifica la relación entre el documento actual y el documento/recurso enlazado.

Diferencias entre HTML 4.01 y HTML5

En HTML5, se eliminaron algunos valores de HTML 4.01 y se agregaron algunos nuevos.

Sintaxis

<link rel="value">

Valor del atributo

Valor Descripción
alternate Enlaza a una versión alternativa de este documento (como página para imprimir, traducción o espejo).
author Enlaza al autor de este documento.
help Enlaza a un documento de ayuda.
icon Importa el icono que representa este documento.
license Enlaza a la información de derechos de autor de este documento.
next Indica que este documento es parte de una colección y que el siguiente documento de la colección es el documento referenciado.
prefetch Especifica que el recurso de destino debe almacenarse en caché.
prev Indica que este documento es parte de una colección y que el documento anterior de la colección es el documento referenciado.
search Enlaza a una herramienta de búsqueda para el documento.
stylesheet La URL de la hoja de estilo que se va a importar.
