Usar atajos de teclado puede ahorrar tiempo.

Atajos de teclado para Windows y Mac

Los atajos de teclado se utilizan con frecuencia en los sistemas operativos modernos y en los programas de software informático.

Usar atajos de teclado le ayuda a ahorrar mucho tiempo.
