Manual de referencia HTML-(HTML5 标准)

Orden alfabético

New: Nueva etiqueta HTML5

标签 描述
<!--...--> 定义注释
<!DOCTYPE> Define el tipo de documento
<a> Define un hipervínculo
<abbr> 定义缩写
<acronym> 定义只取首字母的缩写，不支持HTML5
<address> Define la información de contacto del autor o propietario del documento.
<applet> Obsoleto en HTML5. Define un applet integrado.
<area> Define el área dentro de un mapa de imagen
<article>New Define un área de artículo
<aside>New Define el contenido de la barra lateral de la página
<audio>New Define contenido de audio
<b> Define texto en negrita
<base> Define la dirección o destino predeterminado de todos los enlaces de la página.
<basefont> No soportado en HTML5, obsoleto. Define la fuente, color o tamaño predeterminado del texto de la página.
<bdi>New Permite establecer un texto que se separe de la configuración de dirección del texto de su elemento padre.
<bdo> Define la dirección del texto
<big> Define texto grande, no soportado en HTML5.
<blockquote> Define una cita larga
<body> Define el cuerpo del documento
<br> 定义换行
<button> Define un botón en el que se puede hacer clic
<canvas>New Define gráficos, como diagramas y otras imágenes. La etiqueta es solo un contenedor de gráficos; debe usar scripts para dibujar los gráficos.
<caption> Define el título de la tabla
<center> No soportado en HTML5, obsoleto. Define texto centrado.
<cite> Define una cita (citation)
<code> Define texto de código de computadora
<col> Define los valores de los atributos de una o más columnas en una tabla.
<colgroup> Define un grupo de columnas en una tabla para formatear
<command>New Define un botón de comando, como un botón de opción, casilla de verificación o botón.
<datalist>New Define una lista de opciones. Use este elemento junto con el elemento input para definir los posibles valores de input.
<dd> Define la descripción de un elemento en una lista de definiciones
<del> Define texto eliminado
<details>New Se usa para describir los detalles de un documento o de una parte del documento.
<dfn> Define un término de definición
<dialog>New Define un cuadro de diálogo, como un cuadro de aviso
<dir> HTML5 no lo admite, está en desuso. Define una lista de directorio.
<div> Define una sección en el documento
<dl> Define detalles de lista
<dt> Define un elemento en una lista
<em> Define texto enfatizado
<embed>New Define contenido incrustado, como complementos
<fieldset> Define un borde alrededor de los elementos de un formulario
<figcaption>New Define el título del elemento &lt;figure&gt;.
<figure>New Especifica contenido de flujo independiente (imágenes, diagramas, fotos, código, etc.).
<font> No soportado en HTML5, obsoleto. Define la fuente, tamaño y color del texto.
<footer>New Define el pie de página de una sección o documento.
<form> Define el formulario de un documento HTML
<frame> Define una ventana o marco dentro de un conjunto de marcos
<frameset> 定义框架集
<h1> to <h6> Define un encabezado HTML
<head> Define información sobre el documento
<header>New Define el área de encabezado del documento
<hr> 定义水平线
<html> Define el documento HTML
<i> 定义斜体字
<iframe> Define un marco en línea (iframe)
<img> 定义图像
<input> Define un control de entrada
<ins> Define texto insertado
<kbd> Define texto de teclado
<keygen>New Especifica un campo generador de pares de claves para formularios.
<label> Define la etiqueta para un elemento de entrada (input)
<legend> Define el título del elemento fieldset.
<li> Define un elemento de lista
<link> Define la relación entre el documento y un recurso externo
<main> Define la parte principal del documento
<map> Define un mapa de imagen
<mark>New Define texto marcado. Use la etiqueta &lt;em&gt; cuando necesite resaltar texto.
<menu> En desuso. Define una lista de menú.
<meta> Define metainformación sobre un documento HTML.
<meter>New Define una medida. Úselo solo para medidas con valores máximo y mínimo conocidos.
<nav>New Define una sección con enlaces de navegación
<noframes> Define contenido alternativo para usuarios que no soportan marcos. No soportado en HTML5.
<noscript> Define contenido alternativo para usuarios que no soportan scripts de cliente.
<object> Define un objeto integrado
<ol> Define una lista ordenada.
<optgroup> Define un grupo de opciones relacionadas en una lista de selección.
<option> Define una opción en una lista de selección
<output>New Define diferentes tipos de salida, como la salida de un script.
<p> 定义段落。
<param> Define parámetros para un objeto
<pre> Define texto preformateado
<progress>New Define el progreso de una tarea en curso (proceso).
<q> Define una cita breve.
<rp>New La etiqueta &lt;rp&gt; se usa en comentarios ruby para definir el contenido que mostrarán los navegadores que no soportan el elemento ruby.
<rt>New La etiqueta &lt;rt&gt; define la explicación o pronunciación de los caracteres (anotación fonética o caracteres chinos).
<ruby>New La etiqueta &lt;ruby&gt; define comentarios ruby (anotación fonética o caracteres chinos).
<s> Obsoleto. Define texto tachado.
<samp> Define una muestra de código de computadora
<script> Define un script del lado del cliente
<section>New La etiqueta &lt;section&gt; define secciones en un documento. Por ejemplo, capítulos, encabezados, pies de página u otras partes del documento.
<select> Define una lista de selección (lista desplegable)
<small> Define texto pequeño.
<source>New La etiqueta &lt;source&gt; define recursos multimedia para elementos de medios (como &lt;video&gt; y &lt;audio&gt;).
<span> Define una sección en el documento
<strike> No soportado en HTML5, obsoleto. Define texto tachado.
<strong> Define texto enfatizado.
<style> Define información de estilo para el documento
<sub> Define texto en subíndice.
<summary>New La etiqueta &lt;summary&gt; contiene el título del elemento details. El elemento "details" se usa para describir información detallada sobre un documento o fragmento de documento.
<sup> Define texto en superíndice.
<table> 定义表格。
<tbody> Define el contenido principal de una tabla
<td> Define una celda en una tabla
<textarea> Define un control de entrada de texto multilínea
<tfoot> Define el contenido de las notas de tabla (notas al pie) en una tabla.
<th> Define una celda de encabezado en una tabla
<thead> Define el contenido de encabezado de una tabla
<time>New Define una fecha o una hora, o ambas
<template>New Define contenido que se oculta al cargar la página.
<title> Define el título del documento
<tr> Define una fila en una tabla
<track>New La etiqueta &lt;track&gt; especifica pistas de texto externas para medios como el elemento video.
<tt> Define texto de máquina de escribir
<u> En desuso. Define texto subrayado.
<ul> Define una lista desordenada.
<var> Define una parte variable del texto
<video>New La etiqueta &lt;video&gt; define video, como fragmentos de películas u otras transmisiones de video.
<wbr>New Especifica dónde es apropiado agregar un salto de línea en el texto.
