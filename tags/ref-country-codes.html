Códigos ISO de países y regiones

En HTML, los códigos de país/región se pueden utilizar comolangcomplemento del código de idioma en el atributo.

Los dos primeros caracteres del código de idioma definen el idioma de la página web (consulte la referencia de códigos de idioma）。

Los últimos dos caracteres definen el país/región.

El siguiente ejemplo especifica el chino como idioma y China como país:

<html lang="zh-CN"> ... </html>

El siguiente ejemplo especifica el inglés como idioma y Estados Unidos como país:

<html lang="en-US"> ... </html>
