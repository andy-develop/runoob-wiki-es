Comentario HTML:

Soporte del navegador

Todos los navegadores principales admiten la etiqueta de comentario <!--...-->.

Definición e instrucciones de uso de la etiqueta

La etiqueta de comentario <!--...--> se utiliza para insertar comentarios en el documento fuente. Los comentarios no se mostrarán en el navegador.

Puede usar comentarios para explicar su código, lo que le ayudará a editarlo en el futuro. Es especialmente útil cuando la cantidad de código es muy grande.

También puede almacenar información personalizada para el programa en el contenido del comentario. En este caso, esta información es invisible para el usuario, pero está disponible para el programa. Una buena práctica es colocar comentarios o elementos de estilo dentro del texto del comentario, para evitar que los navegadores antiguos que no admiten scripts o estilos los muestren como texto plano.

<script type="text/javascript"> <!-- function displayMsg() { alert("Hello World!") } //--> </script>

Nota:Las dos barras diagonales (//) al final de la línea son el símbolo de comentario de JavaScript. Esto garantiza que JavaScript no ejecute la etiqueta -->.

Además de su papel evidente en el documento fuente, muchos servidores web también utilizan comentarios para implementar características específicas del software del lado del servidor. Estos servidores pueden escanear el documento, encontrar secuencias de caracteres específicas en los comentarios tradicionales de HTML/XHTML y luego tomar las acciones correspondientes según los comandos incrustados en los comentarios. Estas acciones pueden ser tan simples como incluir texto de otros archivos (lo que se llama inclusión del lado del servidor, server-inside include), o tan complejas como ejecutar otros comandos para generar dinámicamente el contenido del documento.

Diferencias entre HTML 4.01 y HTML5

Ninguna.

Atributos estándar

La etiqueta de comentario <!--...--> no admite ningún atributo estándar.

Para obtener más información sobre los atributos estándar de HTML, visiteAtributos estándar。

Atributos de evento

La etiqueta de comentario <!--...--> no admite ningún atributo de evento.

Para obtener más información sobre los atributos de evento de HTML, visiteAtributos de evento。

    Comentarios en HTML

    Añadir texto de comentario:

    <!-- Escribe aquí tu comentario -->

    También se puede comentar una línea o un bloque de código:

    <!-- 此刻不显示此段落：
<p>这是一个被注释了的段落。</p>
-->

    Comentario condicional:

    <!--[if IE 8]>
    .... some HTML here ....
<![endif]-->

    Nota:Los comentarios condicionales definen etiquetas HTML que solo ejecuta Internet Explorer.

    ¿Para qué se utiliza <!-- //--> en JavaScript?

    Al usar JavaScript en HTML, a menudo se ve la siguiente escritura:

    <script type="text/javascript">
<!--
XXXXXXXX内容略XXXXX
//-->
</script>

    Esto es para evitar que algunos navegadores, que no admiten JavaScript, hagan que el código JavaScript aparezca directamente en la página, afectando la estética.

    Por lo tanto, el código JavaScript se envuelve con comentarios HTML. Si el navegador no admite JavaScript, también se tratará como un comentario. Aunque JavaScript no funcione, el código fuente no se mostrará en la página.

    (Algunos navegadores pueden admitir JavaScript, pero también ofrecen al usuario un interruptor para desactivarlo. Si el usuario desactiva la función de JavaScript, también ocurrirá esto).

    ¿Y si la etiqueta es muy larga? ¿Cómo incrustar un comentario dentro de la etiqueta? La etiqueta de comentario no puede hacerlo. La respuesta es usar el atributo style (estilo en línea) de la etiqueta. El formato es:

    style="/* 注释内容 */"

    Observa el inicio/*y el final*/，son los símbolos de comentario CSS. El atributo style se usa a menudo para cambiar la apariencia del elemento, pero aquí solo contiene un comentario, por lo que no cambiará ninguna apariencia.

    Por ejemplo:

    <a style="/* 菜鸟教程官方网站 */" href="../index.html" target="_blank" rel="noopener">菜鸟教程</a>

    Así se cargará correctamente.

    Si el atributo style ya existe (para cambiar la apariencia), se puede agregar el comentario al principio o al final. Por ejemplo:

    <a style="font-style:italic;font-size:32px;/* 菜鸟教程官方网站 */" href="../index.html" target="_blank" rel="noopener">菜鸟教程</a>

    O:

    <a style="/* 菜鸟教程官方网站 */font-style:italic;font-size:32px;" href="../index.html" target="_blank" rel="noopener">菜鸟教程</a>
