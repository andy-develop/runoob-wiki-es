Compatibilidad del navegador

Actualmente la mayoría de los navegadores admiten la etiqueta <pre>.

Definición e instrucciones de uso de la etiqueta

La etiqueta <pre> puede definir texto preformateado.

El texto dentro de un elemento <pre> generalmente conserva los espacios y los saltos de línea. El texto también se muestra en una fuente monoespaciada.

Consejos y notas

Consejo:Un uso común de la etiqueta <pre> es representar código fuente de computadora.

Diferencias entre HTML 4.01 y HTML5

En HTML 4.01, el atributo "width" está obsoleto y no debe usarse. HTML5 no admite el atributo "width".

Atributos

    • El elemento pre es un elemento de bloque, pero solo puede contener texto o elementos en línea. Es decir, ningún elemento de bloque (comúnmente etiquetas que pueden causar saltos de párrafo) puede estar dentro de un elemento pre.
    • El texto permitido dentro del elemento pre puede incluir variaciones de estilo físico y basadas en contenido, así como enlaces, imágenes y líneas divisorias horizontales. Cuando se colocan otras etiquetas, como <a>, dentro de un bloque <pre>, se hace igual que en cualquier otra parte del documento HTML/XHTML.
    • La tabulación (tab) puede cumplir su función dentro del bloque definido por la etiqueta <pre>; cada tabulación ocupa la posición de 8 caracteres, pero no se recomienda usar tabulaciones porque su comportamiento varía en diferentes navegadores. En segmentos de documento formateados con la etiqueta <pre>, useespacios, se puede garantizar la posición horizontal correcta del texto.
    • Si desea usar la etiqueta <pre> para definir código fuente de computadora, como código fuente HTML, useentidades de símbolospara representar caracteres especiales. Generalmente, la etiqueta <pre> se combina conla etiqueta <code>para obtener una semántica más precisa, y se utiliza para marcar el código fuente que debe mostrarse en la página.
    • Si se desea colocar un cierto segmento deformato de texto predefinidoen HTML, entonces se deben aprovechar las características del elemento pre.

    Definición e instrucciones de uso de la etiqueta <pre>:

    1. Esta etiqueta puede definir texto preformateado. El texto dentro de un elemento pre generalmente conserva los espacios y los saltos de línea, y se muestra en fuente monoespaciada. Un uso común de esta etiqueta es representar código fuente de computadora.

    2. El texto permitido en este elemento puede incluir variaciones de estilo físico y basadas en contenido, así como enlaces, imágenes y líneas divisorias horizontales. Cuando se colocan otras etiquetas (como <a>) dentro de un bloque <pre>, se hace igual que en cualquier otra parte del documento HTML/XHTML.

    3. Los símbolos especiales en la etiqueta se convierten en entidades de símbolos, por ejemplo, "&lt;" representa "<", "&gt;" representa ">".

    4. Las etiquetas que pueden causar saltos de párrafo (como <h1>, <p> y <address>) deben evitarse dentro del bloque definido por <pre>.
