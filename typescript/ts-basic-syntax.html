Sintaxis básica de TypeScript

Un programa TypeScript consta de las siguientes partes:

  • Módulos
  • Funciones
  • Variables
  • Sentencias y expresiones
  • Comentarios

Primer programa TypeScript

Podemos usar el siguiente programa TypeScript para imprimir "Hello World":

Código del archivo Ejemplo.ts:

const hello : string = "Hello World!" console.log(hello)

Pruébalo »

El código anterior primero se compila mediantetscel comando de compilación:

tsc Ejemplo.ts

Se obtiene el siguiente código js:

Código del archivo Ejemplo.js:

var hello = "Hello World!"; console.log(hello);

Finalmente, usamos el comando node para ejecutar este código js.

$ node Ejemplo.js
Hello World

Espacios en blanco y saltos de línea

TypeScript ignora los espacios, tabulaciones y saltos de línea que aparecen en el programa.

Los espacios y tabulaciones se usan normalmente para indentar el código, haciéndolo más fácil de leer y entender.

TypeScript distingue entre mayúsculas y minúsculas

TypeScript distingue entre caracteres en mayúsculas y minúsculas.

El punto y coma es opcional

Cada línea de instrucciones es una sentencia; puedes usar o no el punto y coma. El punto y coma es opcional en TypeScript, pero se recomienda usarlo.

El siguiente código es válido:

console.log("Ejemplo")
console.log("Google");

Si las sentencias se escriben en la misma línea, es obligatorio usar puntos y comas para separarlas; de lo contrario, se producirá un error. Por ejemplo:

console.log("Ejemplo");console.log("Google");

Comentarios en TypeScript

Los comentarios son un buen hábito. Aunque muchos programadores odian los comentarios, se recomienda añadir explicaciones textuales a cada bloque de código.

Los comentarios pueden mejorar la legibilidad del programa.

Los comentarios pueden contener información sobre el programa, como el autor del código, descripciones de funciones, etc.

El compilador ignorará los comentarios.

TypeScript admite dos tipos de comentarios

  • Comentario de una sola línea ( // )− El texto después de // es contenido del comentario.

  • Comentario de varias líneas (/* */)− Este tipo de comentario puede abarcar varias líneas.

Ejemplo de comentario:

// Este es un comentario de una sola línea
 
/* 
 Este es un comentario de varias líneas 
 Este es un comentario de varias líneas 
 Este es un comentario de varias líneas 
*/

TypeScript y la programación orientada a objetos

La programación orientada a objetos es un método para comprender y abstraer el mundo real.

TypeScript es un lenguaje de programación orientado a objetos.

La programación orientada a objetos tiene principalmente dos conceptos: objetos y clases.

  • Objeto: Un objeto es una instancia de una clase (un objeto no es buscar una novia), tiene estado y comportamiento. Por ejemplo, un perro es un objeto; sus estados incluyen: color, nombre, raza; sus comportamientos incluyen: mover la cola, ladrar, comer, etc.
  • Clase: La clase es una plantilla que describe el comportamiento y el estado de un tipo de objetos.
  • Método: El método es el paso de implementación de las operaciones de la clase.

Ejemplo de programación orientada a objetos en TypeScript:

class Site { name():void { console.log("Ejemplo") } } var obj = new Site(); obj.name();

El ejemplo anterior define una clase Site, que tiene un método name(), el cual imprime la cadena Ejemplo en la terminal.

La palabra clave new crea un objeto de la clase, y ese objeto llama al método name().

El código JavaScript generado después de la compilación es el siguiente:

var Site = /** @class */ (function () { function Site() { } Site.prototype.name = function () { console.log("Ejemplo"); }; return Site; }()); var obj = new Site(); obj.name();
