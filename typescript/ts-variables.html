Declaración de variables TypeScript

Una variable es un marcador de posición conveniente que se utiliza para hacer referencia a una dirección de memoria de la computadora.

Podemos considerar las variables como contenedores para almacenar datos.

Reglas de nomenclatura de variables en TypeScript:

  • Los nombres de variables pueden contener números y letras.

  • Excepto el guion bajo_y el signo de dólar$Aparte de esos símbolos, no pueden contener otros caracteres especiales, incluidos los espacios.

  • Los nombres de variables no pueden comenzar con un número.

Antes de usar una variable, debe declararse primero. Podemos usar `var` para declarar variables.

Podemos declarar variables de las siguientes cuatro maneras:

Declarar el tipo de la variable y su valor inicial:

var [变量名] : [类型] = 值;

Por ejemplo:

var uname:string = "Ejemplo";

Declarar el tipo de la variable, pero sin valor inicial; el valor de la variable se establecerá como `undefined`:

var [变量名] : [类型];

Por ejemplo:

var uname:string;

Declarar una variable con valor inicial, pero sin establecer tipo; la variable puede ser de cualquier tipo:

var [变量名] = 值;

Por ejemplo:

var uname = "Ejemplo";

Declarar una variable sin establecer tipo ni valor inicial; el tipo puede ser cualquiera y el valor inicial predeterminado es `undefined`:

var [变量名];

Por ejemplo:

var uname;

Ejemplo

var uname:string = "Ejemplo";
var score1:number = 50;
var score2:number = 42.50
var sum = score1 + score2
console.log("Nombre: "+uname)
console.log("Nota de la primera asignatura: "+score1)
console.log("Nota de la segunda asignatura: "+score2)
console.log("Nota total: "+sum)

Nota:No uses `name` como nombre de variable; de lo contrario, se producirá un conflicto de nombres con la propiedad `name` del objeto global `window` del DOM.

Usa el comando `tsc` para compilar el código anterior y se obtiene el siguiente código JavaScript:

var uname = "Ejemplo"; var score1 = 50; var score2 = 42.50; var sum = score1 + score2; console.log("Nombre:" + uname); console.log("Nota de la primera asignatura:" + score1); console.log("Nota de la segunda asignatura:" + score2); console.log("Nota total:" + sum);

Al ejecutar este código JavaScript, el resultado es:

名字: Ejemplo
第一个科目成绩: 50
第二个科目成绩: 42.5
总成绩: 92.5

TypeScript sigue un tipado fuerte. Si se asigna un tipo diferente a una variable, se producirá un error de compilación, como en el siguiente ejemplo:

var num:number = "hello"     // 这个代码会编译错误

Aserción de tipos (Type Assertion)

La aserción de tipos se puede usar para especificar manualmente el tipo de un valor, es decir, permite que una variable cambie de un tipo a otro.

Formato de sintaxis:

<tipo>valor

o:

值 as 类型

Ejemplo

var str = '1' var str2:number = <number> <any> str //`str`, `str2` son de tipo `string` console.log(str2)

¿Cómo determina TypeScript si una sola aserción es suficiente?

Cuando el tipo S es un subtipo del tipo T, o el tipo T es un subtipo del tipo S, S puede ser afirmado con éxito como T. Esto es para proporcionar seguridad adicional al realizar aserciones de tipos; las aserciones completamente infundadas son peligrosas. Si quieres hacer eso, puedes usar `any`.

No se llamaconversión de tipos, porque la conversión generalmente implica algún tipo de soporte en tiempo de ejecución. Sin embargo, la aserción de tipos es puramente una sintaxis de tiempo de compilación y, al mismo tiempo, es una forma de proporcionar al compilador información sobre cómo analizar el código.

Después de la compilación, el código anterior genera el siguiente código JavaScript:

var str = '1'; var str2 = str; //`str`, `str2` son de tipo `string` console.log(str2);

El resultado de la ejecución es:

1

Inferencia de tipos

Cuando no se especifica un tipo, el compilador de TypeScript utiliza la inferencia de tipos para deducir el tipo.

Si no se puede inferir el tipo debido a la falta de declaración, entonces su tipo se considera como el tipo dinámico `any` por defecto.

var num = 2; //La inferencia de tipo es `number` console.log("El valor de la variable `num` es"+num); num = "12"; //Error de compilación console.log(num);

  • La primera línea de código declara la variable `num` y establece su valor inicial en 2. Observa que la declaración de la variable no especifica un tipo. Por lo tanto, el programa utiliza la inferencia de tipos para determinar el tipo de dato de la variable; la primera asignación es 2,numse establece como tipo `number`.

  • En la tercera línea de código, cuando asignamos nuevamente un valor de tipo cadena a la variable, se producirá un error de compilación, porque la variable ya se ha establecido como tipo `number`.

    error TS2322: Type '"12"' is not assignable to type 'number'.

Ámbito de variables

El ámbito de variables especifica la ubicación donde se define la variable.

La disponibilidad de una variable en el programa está determinada por su ámbito.

TypeScript tiene los siguientes ámbitos:

  • Ámbito global− Las variables globales se definen fuera de la estructura del programa y pueden usarse en cualquier parte de tu código.

  • Ámbito de clase− Esta variable también se puede llamarcampo. Las variables de clase se declaran dentro de una clase, pero fuera de los métodos de la clase. Estas variables se pueden acceder a través de un objeto de la clase. Las variables de clase también pueden ser estáticas; las variables estáticas se pueden acceder directamente mediante el nombre de la clase.

  • Ámbito local− Variables locales: las variables locales solo se pueden usar dentro del bloque de código (por ejemplo, un método) donde se declaran.

El siguiente ejemplo ilustra el uso de los tres ámbitos:

var global_num = 12 //Variable global class Numbers { num_val = 13; //Variable de instancia static sval = 10; //Variable estática storeNum():void { var local_num = 14; //Variable local } } console.log("La variable global es:"+global_num) console.log(Numbers.sval) //Variable estática var obj = new Numbers(); console.log("Variable de instancia:"+obj.num_val)

El código anterior se compila a código JavaScript con el comando `tsc`:

var global_num = 12; //Variable global var Numbers = /** @class */ (function () { function Numbers() { this.num_val = 13; //Variable de instancia } Numbers.prototype.storeNum = function () { var local_num = 14; //Variable local }; Numbers.sval = 10; //Variable estática return Numbers; }()); console.log("La variable global es:" + global_num); console.log(Numbers.sval); //Variable estática var obj = new Numbers(); console.log("Variable de instancia:" + obj.num_val);

Al ejecutar el código JavaScript anterior, el resultado es:

全局变量为: 12
10
实例变量: 13

Si llamamos a la variable local `local_num` fuera del método, se producirá un error:

error TS2322: Could not find symbol 'local_num'.
