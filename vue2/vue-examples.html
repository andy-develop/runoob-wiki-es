Ejemplos de Vue.js

Este capítulo presenta varios ejemplos de Vue.js; mediante la práctica con ejemplos podrás consolidar los conocimientos aprendidos.

Ejemplo de menú de navegación

Menú de navegación

Crea un menú de navegación simple:

<div id="main"> <!--El estilo del menú activo es la clase `active`--> <!--Para evitar que el enlace salte al hacer clic, usamos el modificador `prevent` (abreviatura de preventDefault).--> <nav v-bind:class="active" v-on:click.prevent> <!--Cuando se hace clic en un enlace del menú, llamamos al método `makeActive`, que se crea en la instancia de Vue.--> <a href="#" class="home" v-on:click="makeActive('home')">Home</a> <a href="#" class="projects" v-on:click="makeActive('projects')">Projects</a> <a href="#" class="services" v-on:click="makeActive('services')">Services</a> <a href="#" class="contact" v-on:click="makeActive('contact')">Contact</a> </nav> <!--La variable `active` a continuación cambiará automáticamente según el valor seleccionado actualmente.--> <p>Has seleccionado<b>el menú {{active}}</b></p> </div> <script>// Crear una nueva instancia de Vue var demo = new Vue({ // Elemento DOM, montar el modelo de vista el: '#main', // Definir propiedades y establecer valores iniciales data: { active: 'home' }, // Función utilizada al hacer clic en el menú methods: { makeActive: function(item){ // El modelo cambia, la vista se actualiza automáticamente this.active = item; } } });</script>

Ejemplo de edición de texto

Edición de texto

Haz clic en el texto especificado para editar el contenido:

<!--`v-cloak` oculta las variables no compiladas hasta que la instancia de Vue esté lista.--> <!--Después de hacer clic en el elemento, se llama al método `hideTooltip()`--> <div id="main" v-cloak v-on:click="hideTooltip"> <!--Esto es un cuadro de sugerencias `v-on:click.stop` es un manejador de eventos de clic; el modificador `stop` se usa para detener la propagación del evento `v-if` se usa para determinar que solo se muestre cuando `show_tooltip` sea `true`--> <div class="tooltip" v-on:click.stop v-if="show_tooltip"> <!--`v-model` vincula el contenido del área de texto Cuando el contenido del área de texto cambia, la variable correspondiente también cambia en tiempo real--> <input type="text" v-model="text_content" /> </div> <!--Al hacer clic, se llama al método `toggleTooltip` y se detiene la propagación del evento--> <!--La variable `text_content` cambia según el contenido del área de texto--> <p v-on:click.stop="toggleTooltip">{{text_content}}</p> </div> <script>var demo = new Vue({ el: '#main', data: { show_tooltip: false, text_content: 'Haz clic y edita el contenido.' }, methods: { hideTooltip: function(){ // Cuando el modelo cambia, la vista también se actualiza automáticamente this.show_tooltip = false; }, toggleTooltip: function(){ this.show_tooltip = !this.show_tooltip; } } })</script>

Ejemplo de lista de pedidos

Lista de pedidos

Crea una lista de pedidos y calcula el precio total:

<form id="main" v-cloak> <h1>Services</h1> <ul> <!--Recorre el array `services` y establece el estilo al hacer clic en la opción--> <li v-for="service in services" v-on:click="toggleActive(service)" v-bind:class="{ 'active': service.active}"> <!--Muestra el nombre del servicio y el precio del pedido Vue.js define un filtro de moneda para formatear el precio--> {{service.name}} <span>{{service.price | currency}}</span> </li> </ul> <div class="total"> <!--Calcula el precio de todos los servicios y formatea la moneda--> Total: <span>{{total() | currency}}</span> </div> </form> <script>// Filtro personalizado "currency" Vue.filter('currency', function (value) { return '$' + value.toFixed(2); }); var demo = new Vue({ el: '#main', data: { // Definir propiedades del modelo // La vista recorrerá los datos del array y los mostrará services: [ { name: 'Web Development', price: 300, active:true },{ name: 'Design', price: 400, active:false },{ name: 'Integration', price: 250, active:false },{ name: 'Training', price: 220, active:false } ] }, methods: { toggleActive: function(s){ s.active = !s.active; }, total: function(){ var total = 0; this.services.forEach(function(s){ if (s.active){ total+= s.price; } }); return total; } } });</script>
