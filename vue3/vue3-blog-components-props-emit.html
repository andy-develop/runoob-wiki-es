División de componentes

La componentización es la idea de diseño más central de Vue.

En este capítulo aprenderás a dividir una página en pequeños componentes reutilizables y a lograr la comunicación entre componentes mediante props y emit.

¿Por qué dividir componentes?

A medida que aumentan las funcionalidades, un archivo se vuelve cada vez más largo; cientos de líneas de código metidas en un archivo .vue son difíciles de mantener.

El propósito de dividir componentes:Cada componente hace una sola cosa; combinados, completan funciones complejas.。

¿Qué granularidad es adecuada?

Una buena regla empírica es:Cuando un bloque de código tiene sus propios datos, su propio comportamiento y puede reutilizarse en otro lugar,debería convertirse en un componente independiente.

Área de la página¿Debe dividirse en un componente?Razón
Barra de navegación是Cada página la necesita; función independiente.
Tarjeta de artículo是Cada artículo de la lista tiene la misma estructura.
Grupo de botones de filtro por categoría是Tiene su propio estado e interacción.
Contenedor envolvente simple否Solo es para la maquetación; no tiene un comportamiento independiente.

Padre a hijo: defineProps

El componente padre transmite datos al componente hijo medianteprops`defineProps`.

Puedes entenderlo como el «parámetro de una función»: cuando el componente padre llama al componente hijo, le pasa los datos como parámetro.

Ejemplo

<!-- Ruta del archivo: src/components/BlogCard.vue -->
<script setup>
// Declara los props que recibe este componente
// defineProps es una macro de compilación; no requiere importación para usarse
const props = defineProps({
title: String, // Título del artículo, tipo String
summary: String, // Resumen del artículo
date: String, // Fecha de publicación
category: String // Etiqueta de categoría
})

// También se puede escribir en forma de array (sin validar tipos):
// const props = defineProps(['title', 'summary', 'date', 'category'])
</script>

<template>
  <div class="card">
    <span class="tag">{{ category }}</span>
    <h3>{{ title }}</h3>
    <p>{{ summary }}</p>
    <span class="date">{{ date }}</span>
  </div>
</template>

Cuando el componente padre usa BlogCard, pasa los datos mediante el enlace de atributos con dos puntos:

Ejemplo

<!-- Ruta del archivo: src/views/HomeView.vue -->
<script setup>
import { ref } from 'vue'
import BlogCard from '../components/BlogCard.vue'

const articles = ref([
{ id: 1, title: 'Vue3 入门', summary: '从零学 Vue3', date: '2024-05-10', category: 'Vue' },
{ id: 2, title: 'Promise 详解', summary: '搞懂异步', date: '2024-05-08', category: 'JavaScript' },
])
</script>

<template>
  <div class="article-grid">
    <!-- El componente padre transmite datos al componente hijo mediante :nombre-del-atributo="valor" -->
    <BlogCard
     v-for="article in articles"
     :key="article.id"
     :title="article.title"
     :summary="article.summary"
     :date="article.date"
     :category="article.category"
   />
  </div>
</template>

props esun flujo de datos unidireccional: solo de padre → hijo; el componente hijo no puede modificar el valor de props. Si el componente hijo necesita modificarlo, debe notificar al padre mediante emit para que lo cambie.

Hijo a padre: defineEmits

El componente hijo debe notificar al padre que ha ocurrido algo (por ejemplo, «me han clicado»), medianteemitel envío de un evento (`emit`).

Puedes entenderlo como una «función de retorno» (callback): el componente hijo dispara el evento y el componente padre lo escucha y responde.

Ejemplo

<!-- Ruta del archivo: src/components/CategoryFilter.vue -->
<script setup>
const props = defineProps({
categories: Array, // Lista de todas las categorías
activeCategory: String // Categoría seleccionada actualmente
})

// Declara el evento que se va a enviar
const emit = defineEmits(['update-category'])

function selectCategory(cat) {
// Dispara el evento y pasa la categoría seleccionada al componente padre
  emit('update-category', cat)
}
</script>

<template>
  <div class="filter-bar">
    <button
     v-for="cat in categories"
     :key="cat"
     :class="{ active: activeCategory === cat }"
     @click="selectCategory(cat)"
   >
      {{ cat }}
    </button>
  </div>
</template>

El componente padre, mediante@nombreDeEvento="función de manejo"`@update-category`, escucha los eventos del componente hijo:

Ejemplo

<!-- Ruta del archivo: src/views/HomeView.vue -->
<script setup>
import { ref, computed } from 'vue'
import CategoryFilter from '../components/CategoryFilter.vue'

const activeCategory = ref('全部')

const categories = ['全部', 'Vue', 'JavaScript', 'CSS']

// Responde al evento update-category enviado por el componente hijo
function handleCategoryChange(cat) {
  activeCategory.value = cat
}
</script>

<template>
  <!-- @update-category="handleCategoryChange" -->
  <CategoryFilter
   :categories="categories"
   :active-category="activeCategory"
   @update-category="handleCategoryChange"
 />
</template>

Flujo de datos completo

El componente padre, medianteprops, hacia abajo,transmite datos; el componente hijo, medianteemit, hacia arriba,envía eventos.

Los datos siempre son «poseídos» y modificados por el componente padre; el componente hijo solo se encarga de mostrarlos y de notificar.

HomeView.vue — Integra todos los componentes

Ejemplo

<!-- Ruta del archivo: src/views/HomeView.vue -->
<script setup>
import { ref, computed } from 'vue'
import BlogCard from '../components/BlogCard.vue'
import CategoryFilter from '../components/CategoryFilter.vue'

// Datos de los artículos
const articles = ref([
{ id: 1, title: 'Vue3 入门完全指南', summary: '从零开始学习 Vue3 组合式 API', date: '2024-05-10', category: 'Vue' },
{ id: 2, title: 'JS 异步编程详解', summary: '搞懂 Promise 和 async/await', date: '2024-05-08', category: 'JavaScript' },
{ id: 3, title: 'CSS Grid 布局实战', summary: '用 Grid 实现响应式布局', date: '2024-05-05', category: 'CSS' },
{ id: 4, title: 'Vue3 响应式原理', summary: '深入理解 ref 和 reactive', date: '2024-05-03', category: 'Vue' },
{ id: 5, title: 'Flexbox 完全指南', summary: '一文学会弹性布局', date: '2024-05-01', category: 'CSS' },
])

// Extrae todas las categorías (sin duplicados)
const categories = computed(() => {
  const cats = articles.value.map(a => a.category)
return ['全部', ...new Set(cats)]
})

// Categoría seleccionada actualmente
const activeCategory = ref('全部')

// Filtra los artículos según la categoría
const filteredArticles = computed(() => {
if (activeCategory.value === '全部') return articles.value
  return articles.value.filter(a => a.category === activeCategory.value)
})

// Maneja el evento de cambio de categoría enviado por el componente hijo
function handleCategoryChange(cat) {
  activeCategory.value = cat
}
</script>

<template>
  <div class="home">
    <h2 class="section-title">Artículos recientes</h2>

    <!-- Componente de filtrado por categoría -->
    <CategoryFilter
     :categories="categories"
     :active-category="activeCategory"
     @update-category="handleCategoryChange"
   />

    <!-- Estado vacío -->
    <p v-if="filteredArticles.length === 0" class="empty-tip">
No hay artículos en esta categoría
    </p>

    <!-- Lista de tarjetas de artículo -->
    <div v-else class="article-grid">
      <BlogCard
       v-for="article in filteredArticles"
       :key="article.id"
       :title="article.title"
       :summary="article.summary"
       :date="article.date"
       :category="article.category"
     />
    </div>
  </div>
</template>

<style scoped>
.home { max-width: 960px; margin: 0 auto; padding: 20px; }
.section-title { font-size: 24px; margin-bottom: 20px; }
.article-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 24px;
  margin-top: 20px;
}
.empty-tip { text-align: center; color: #999; padding: 60px 0; }
</style>
