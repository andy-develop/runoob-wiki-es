Hoja de ruta de aprendizaje para desarrolladores web 2018

Categoría Tecnología de programación

La siguiente hoja de ruta de aprendizaje para desarrolladores web proviene del proyecto Githubdeveloper-roadmapProyecto, que actualmente ya tiene una traducción al chino tradicionaldeveloper-roadmap-chinese。

Hay principalmente tres áreas: desarrollo front-end, desarrollo back-end y operaciones. El significado de los diferentes colores en la imagen:

  • Amarillo: recomendado;
  • Gris: aprender en la medida de lo posible;
  • Naranja: elige uno de ellos.

Se puede ver que, como desarrollador web, sin importar el puesto, las siguientes habilidades son imprescindibles de dominar:

  • Git, gestión de versiones de código
  • SSH；
  • HTTP/HTTPs y API. Para convertirte realmente en un desarrollador web, es imprescindible conocer el protocolo HTTP;
  • Uso básico de la línea de comandos;
  • Aprender a investigar, desarrollar el hábito de, cuando te encuentres con un problema, buscar soluciones mediante el autoaprendizaje. Esto es especialmente importante;
  • Estructuras de datos y algoritmos. Creo que en las asignaturas de informática de la universidad suelen estudiarse estas dos materias;
  • Codificación de caracteres;
  • Github. Github (incluyendo Google, Stack Overflow) es una mina de oro para los desarrolladores web, aprovéchalo bien.
