Resulta que una página 404 se puede hacer así

Categoría Tecnología de programación

La página 404 es una página imprescindible en un sitio web; lleva el importante peso de la experiencia del usuario y la optimización SEO. La página 404 suele ser el error 404 devuelto por el servidor cuando el usuario accede a una página que no existe o ha sido eliminada en el sitio web. Si el webmaster no configura una página 404, aparecerán enlaces muertos; cuando los rastreadores (spiders) recorren este tipo de URL, no es favorable para la indexación en los motores de búsqueda.

Dos grandes beneficios de configurar una página 404

  • 1: Guiar a los usuarios para que no cierren el sitio web y mejorar la experiencia del usuario.
  • 2: Evitar que aparezcan enlaces muertos en el sitio web.

Al diseñar una página 404, puedes seguir los siguientes principios

  • 1: Como un portal, volver a la página de inicio en 5 segundos

    Los portales como NetEase, Sina y Tencent tienen páginas de error similares; al entrar en la página de error, se muestra un aviso de que se volverá a la página de inicio del canal en 5 segundos.

    Evita volver inmediatamente a la página de inicio después de entrar en una página de error 404, ya que estas redirecciones hacen que los motores de búsqueda crean erróneamente que la página existe, pero devuelven contenido duplicado.

  • 2: Como 站长之家, saca a los “expertos” (砖家)

    La página 404 debe tener un estilo similar al de tu propio sitio web, de modo que parezca que sigue siendo tu sitio. Además, añade frases divertidas y graciosas, pide a los “expertos” que te ayuden a analizar y haz que el usuario sepa dónde está cuando esté confundido. Dale al error un toque humorístico; resulta que un error también puede ser hermoso...

    Evita configurar el 404 como una redirección 301 a la página de inicio. Esta es una configuración poco amigable para los motores de búsqueda, ya que les hará pensar que el sitio tiene una gran cantidad de páginas con el mismo contenido que la página de inicio. Sin embargo, se puede redirigir la página de error a la página correcta mediante una redirección 301.

  • 3: También puedes, como Yahoo, meter todo lo que puedas

    En la página 404, proporciona tantos enlaces útiles al usuario como sea posible, retén al usuario con contenido rico y evita que una página demasiado simple haga que el usuario se vaya.

    Aunque el contenido sea abundante, la posición más visible debe seguir mostrando el mensaje de error, indicando al usuario que la página a la que quiere acceder no existe. Luego, añade navegación en la parte superior, coloca publicidad a la derecha, y más abajo añade algunos artículos con imágenes y texto. Como si fuera poco, al final añade enlaces de navegación; el usuario no tendrá más remedio que hacer clic.

  • 4: También puedes poner un pequeño juego para que jueguen

    El error 404 no es terrible; lo terrible es que el “404 Not Found” predeterminado deja al usuario desconcertado, preguntándose qué ha pasado. En este momento, puedes incluir un pequeño juego en Flash con el mensaje: “¡Ay, esta es la página de error 404! Tómate un descanso y juega un rato”.

Métodos para configurar una página 404

  • 1: Método de configuración en hosting virtual

    Los proveedores de IDC actuales ofrecen básicamente la función de configuración de 404; basta con subir el archivo directamente y configurarlo.

  • 2: Configurar la página 404 en IIS

    En el administrador de IIS, haz clic derecho en el sitio web que deseas administrar, abre la página de “Errores personalizados” en “Propiedades” y configura la página de error correspondiente para “404”. Sin embargo, aquí, en “Tipo de mensaje”, debes elegir “Archivo” o “Valor predeterminado”, y no elegir “URL”; de lo contrario, se devolverá el código de estado “200”.

  • 3: Configurar la página de error 404 en Apache

    En el archivo .htaccess, solo tienes que añadir el siguiente contenido: ErrorDocument 404 /notfound.php. Recuerda no usar URL absolutas; si se usa una URL absoluta, el código de estado devuelto será “302” + “200”.
