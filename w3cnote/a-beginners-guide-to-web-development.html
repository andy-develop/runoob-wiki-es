Guía de introducción al desarrollo Web

Categoría Tecnología de programación

Si has abierto este artículo, significa que tienes interés en el desarrollo Web, o que estás considerando empezar a aprender desarrollo Web. Aquí te contaré la ruta para convertirte en desarrollador Web, y es una guía sobre el desarrollo Web para principiantes. Este artículo no te enseñará a escribir código, sino que señala las cosas en las que debes pensar antes de escribir código de verdad. El desarrollo Web es algo emocionante y apasionante, y precisamente se adapta a este mundo que cambia y se desarrolla rápidamente. Para entender el desarrollo Web, primero definamos algunos conceptos básicos.

Frontend vs. Backend

Desde el principio hay que distinguir claramente entre el desarrollo frontend y el desarrollo backend. Vamos a presentarlos por separado.

Frontend

Las aplicaciones Web se clasifican como aplicaciones distribuidas, generalmente con una estructura cliente-servidor, por lo que tenemos una parte del código que se ejecuta en el cliente y otra parte que se ejecuta en el servidor. Las aplicaciones que están en el cliente son el frontend, que normalmente se refiere a nuestro navegador. Las tecnologías más utilizadas para el desarrollo frontend son HTML+CSS+JavaScript. Los desarrolladores frontend avanzados suelen utilizar una combinación de estas tecnologías para desarrollar el frontend de las aplicaciones. Otra tecnología común en el frontend es el uso de Photoshop para el diseño, junto con otras tecnologías para completar la creación de páginas Web.

Backend

Los desarrolladores backend escriben el código que se ejecuta en el servidor. Por lo general, este trabajo implica tratar con bases de datos, como leer y escribir datos, leer y escribir archivos, implementar lógica de negocio, etc. A veces, la lógica de negocio se almacena en el cliente, y en ese caso el backend se utiliza para proporcionar los datos de la base de datos en forma de servicios Web. Los desarrolladores backend generalmente necesitan dominar un lenguaje de programación Web y un sistema de gestión de bases de datos.

Puedes dominar tanto las tecnologías de frontend como las de backend, pero la mayoría de los desarrolladores Web tienen cierta preferencia, e incluso algunos solo profundizan en un aspecto. Aunque hay una distinción entre frontend y backend, no hay reglas establecidas sobre sus tareas específicas. A veces el frontend solo se encarga de mostrar los datos, mientras que el resto del trabajo principal se realiza en el backend. Pero otras veces, el backend solo proporciona los datos, y todos los cálculos y funciones específicas se realizan en el frontend. La distribución del trabajo entre frontend y backend suele estar determinada por el diseño y la arquitectura del proyecto.

Lenguajes de programación

Para el desarrollo Web, hay muchos lenguajes de programación entre los que elegir. Cuando se trata de desarrollo frontend, el lenguaje estándar es JavaScript, y cuando se necesita desarrollo backend, tenemos más opciones:

  • PHP
  • JavaScript
  • Ruby on Rails (con el lenguaje Ruby)
  • ASP.NET (con el lenguaje .NET)
  • Java EE
  • Python

En realidad, no hay una lista definitiva; los anteriores son solo los lenguajes que los desarrolladores suelen pensar y usar. Entonces, ¿cómo elegir? Tu elección debe basarse en los siguientes aspectos: el mercado laboral (oportunidades de empleo), los servicios de alojamiento, los recursos de aprendizaje disponibles, el tiempo de aprendizaje disponible, el entorno de desarrollo que te rodea, etc.

Si realmente quieres dedicarte a la industria del desarrollo y encontrar un trabajo de desarrollo Web, el factor de elección más importante es el mercado laboral (oportunidades de empleo). Debes analizar la situación de la industria y elegir un lenguaje de programación para aprender. Otro factor importante es el servicio de alojamiento: por ejemplo, el alojamiento para PHP es mucho más barato que el alojamiento para Java. Y si quieres desarrollar aplicaciones empresariales internas, Java EE puede ser una buena opción. Pero si quieres poner tu aplicación en línea, Java EE es mucho más caro que otros lenguajes.

Con la popularidad de Node.js, JavaScript también se ha vuelto popular en el desarrollo backend. Pero después de todo, sigue siendo una tecnología nueva y no lo suficientemente madura, por lo que no se recomienda para que los principiantes en desarrollo Web la aprendan y la usen.

En mi opinión, PHP tiene la curva de aprendizaje más sencilla, servicios de alojamiento baratos, recursos de aprendizaje abundantes (PHP100 es una muy buena opción) y un entorno de desarrollo relativamente simple, por lo que recomiendo a los desarrolladores Web principiantes que aprendan y usen PHP. Por supuesto, ASP.NET también es una buena opción. Microsoft ofrece muchos recursos de aprendizaje relacionados con ASP.NET y herramientas de desarrollo gratuitas. Si te gusta el entorno de Microsoft, vale la pena considerar ASP.NET.

Frameworks

Si todavía eres un principiante, antes de empezar a aprender frameworks debes sentar una buena base. Los frameworks pueden ayudarte a simplificar el trabajo de desarrollo, ya que tienen muchas bibliotecas de código ya hechas y te proporcionan una estructura para aplicaciones Web, haciendo que tu trabajo de programación sea más simple y rápido. Si quieres convertirte en un desarrollador Web profesional, debes dominar al menos un framework para acelerar tu desarrollo Web.

Hay muchos tipos de frameworks, desde soluciones de propósito general hasta soluciones para problemas específicos. Primero debes evaluar tus necesidades. Si eliges el desarrollo con PHP, recomiendo usar Laravel como framework; es un framework MVC muy popular en los últimos años. Si eliges ASP.NET, recomiendo aprender a usar ASP.NET MVC y EntityFramework.

El desarrollo Web puede ser demasiado grande, y puede que quieras centrarte en un solo tipo de aplicación, como un sistema de gestión de contenidos (CMS). Si sigues eligiendo PHP, entonces recomiendo WordPress, que puede ayudarte a crear sitios web y blogs, y también puedes utilizar plugins o temas existentes como extensiones.

Qué hacer a continuación

Incluso si eliges dedicarte solo al desarrollo frontend o backend, también deberías conocer el desarrollo del otro lado, ya que esto hará que tu equipo sea más eficiente. Si ya has aprendido un lenguaje de programación y su framework correspondiente, deberías empezar a aprender otro lenguaje. Cada lenguaje de programación tiene sus propias ventajas y paradigmas. Conocer más lenguajes te permitirá comprender mejor los problemas que necesitas resolver y encontrar mejores soluciones, convirtiéndote así en un mejor desarrollador. Por último, como dije antes, hay que considerar muchos factores al elegir un lenguaje de programación. Mi elección sigue siendo JavaScript, PHP, ASP.NET y Java EE; todos pueden tomarlos como referencia.
