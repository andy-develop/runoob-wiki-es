10.3 AudioManager (Administrador de audio)

Categoría Tutorial básico de introducción a Android

Introducción a esta sección:

En la primera sección de multimedia, usamos SoundPool para escribir un ejemplo de "Duang". Después de que el cerdito hacía clic en un botón, de repente sonaba un "Duang", y el sonido era muy fuerte, ¡me asustó muchísimo!Por suerte no era horario de trabajo; si el gerente se enterara de que escribo el blog a escondidas durante el trabajo, sería un desastre~ Bien, hablando del volumen, tengo que presentar la API que Android nos proporciona para el control del volumen:

AudioManager (Administrador de audio)Esta clase se encuentra en el paquete Android.Media y proporciona operaciones relacionadas con el control de volumen y el modo de tono de llamada. En esta sección vamos a aprender a usar esta cosa. Puedes escribir un Demo, un simple modo silencioso; antes de ver cada película, entra al Demo, haz clic en silenciar y luego..., solo bromeo~ Bueno, sin más preámbulos, ¡comencemos con el contenido de esta sección!

Documentación oficial de la API:AudioManager

1. Obtener una instancia del objeto AudioManager

AudioManager audiomanage = (AudioManager)context.getSystemService(Context.AUDIO_SERVICE);

2. Explicación detallada de los métodos relacionados

Métodos comunes：

  • adjustVolume(int direction, int flags): Controla el volumen del teléfono, súbelo o bájalo una unidad, según el primer parámetro.AudioManager.ADJUST_LOWERPuede bajar una unidad;AudioManager.ADJUST_RAISEPuede subir una unidad
  • adjustStreamVolume(int streamType, int direction, int flags): Igual que el anterior, pero puedes elegir el tipo de sonido a ajustar. 1) Parámetro streamType, especifica el tipo de sonido; existen los siguientes tipos de sonido:STREAM_ALARM: Alarma del teléfonoSTREAM_MUSIC: Música del teléfono
    STREAM_RING: Tono de llamadaSTREAM_SYSTEAM: Sistema del teléfono
    STREAM_DTMF: TonoSTREAM_NOTIFICATION: Aviso del sistema
    STREAM_VOICE_CALL: Llamada de vozFLAG_SHOW_UI, muestra la barra de progreso, AudioManager.PLAY_SOUND: Reproducir sonido
  • setStreamVolume(int streamType, int index, intflags): Establece directamente el volumen.
  • getMode(): Devuelve el modo de audio actual.
  • setMode(): Establece el modo de sonido. Existen los siguientes modos:MODE_NORMAL(Normal),MODE_RINGTONE(Tono de llamada),MODE_IN_CALL(Llamada),MODE_IN_COMMUNICATION(Conversación)
  • getRingerMode(): Devuelve el modo de tono de llamada actual.
  • setRingerMode(int streamType): Establece el modo de tono de llamada. Existen los siguientes modos: Por ejemplo,RINGER_MODE_NORMAL(Normal),RINGER_MODE_SILENT(Silencio),RINGER_MODE_VIBRATE(Vibración)
  • getStreamVolume(int streamType): Obtiene el volumen actual del teléfono. El valor máximo es 7 y el mínimo es 0. Cuando se establece en 0, se cambia automáticamente al modo vibración.
  • getStreamMaxVolume(int streamType): Obtiene el valor máximo de volumen de un tipo de sonido del teléfono.
  • setStreamMute(int streamType, boolean state): Silencia un tipo de sonido del teléfono.
  • setSpeakerphoneOn(boolean on): Establece si se activa el altavoz.
  • setMicrophoneMute(boolean on): Establece si se silencia el micrófono.
  • isMicrophoneMute(): Determina si el micrófono está silenciado o encendido.
  • isMusicActive(): Determina si hay música en estado activo.
  • isWiredHeadsetOn(): Determina si los auriculares están conectados.

Otros métodos：

  • abandonAudioFocus(AudioManager.OnAudioFocusChangeListener l): Abandona el foco de audio.
  • adjustSuggestedStreamVolume(int, int suggestedStreamType, int flags): Ajusta el volumen del flujo más relevante, o el flujo de respaldo dado.
  • getParameters(String keys): Establece un número variable de valores de parámetros para el hardware de audio.
  • getVibrateSetting(int vibrateType): Devuelve si la vibración del usuario está configurada como tipo de vibración.
  • isBluetoothA2dpOn(): Comprueba si la ruta de audio del auricular Bluetooth A2DP está activada o desactivada.
  • isBluetoothScoAvailableOffCall(): Muestra si la plataforma actual admite el caso de uso fuera de llamada con SCO.
  • isBluetoothScoOn(): Comprueba si la comunicación utiliza Bluetooth SCO.
  • loadSoundEffects(): Carga efectos de sonido.
  • playSoundEffect((int effectType, float volume): Reproduce efectos de sonido.
  • egisterMediaButtonEventReceiver(ComponentName eventReceiver): Registra un receptor único para la intención MEDIA_BUTTON de un componente.
  • requestAudioFocus(AudioManager.OnAudioFocusChangeListener l, int streamType, int durationHint) Solicita el foco de audio.
  • setBluetoothScoOn(boolean on): Requiere usar el auricular Bluetooth SCO para la comunicación.
  • startBluetoothSco/stopBluetoothSco()(): Inicia/detiene la conexión de audio Bluetooth SCO.
  • unloadSoundEffects(): Descarga los efectos de sonido.

MainActivity.java：

public class MainActivity extends AppCompatActivity implements View.OnClickListener {

    private Button btn_start;
    private Button btn_stop;
    private Button btn_higher;
    private Button btn_lower;
    private Button btn_quite;
    private MediaPlayer mePlayer;
    private AudioManager aManager;
    //定义一个标志用来标示是否点击了静音按钮
    private int flag = 1;


    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        //获得系统的音频对象
        aManager = (AudioManager) getSystemService(Service.AUDIO_SERVICE);
        //初始化mediaplayer对象,这里播放的是raw文件中的mp3资源
        mePlayer = MediaPlayer.create(MainActivity.this, R.raw.countingstars);
        //设置循环播放:
        mePlayer.setLooping(true);
        bindViews();
    }

    private void bindViews() {
        btn_start = (Button) findViewById(R.id.btn_start);
        btn_stop = (Button) findViewById(R.id.btn_stop);
        btn_higher = (Button) findViewById(R.id.btn_higher);
        btn_lower = (Button) findViewById(R.id.btn_lower);
        btn_quite = (Button) findViewById(R.id.btn_quite);

        btn_start.setOnClickListener(this);
        btn_stop.setOnClickListener(this);
        btn_higher.setOnClickListener(this);
        btn_lower.setOnClickListener(this);
        btn_quite.setOnClickListener(this);
    }

    @Override
    public void onClick(View v) {
        switch (v.getId()) {
            case R.id.btn_start:
                btn_stop.setEnabled(true);
                mePlayer.start();
                btn_start.setEnabled(false);
                break;
            case R.id.btn_stop:
                btn_start.setEnabled(true);
                mePlayer.pause();
                btn_stop.setEnabled(false);
                break;
            case R.id.btn_higher:
                // 指定调节音乐的音频，增大音量，而且显示音量图形示意
                aManager.adjustStreamVolume(AudioManager.STREAM_MUSIC,
                        AudioManager.ADJUST_RAISE, AudioManager.FLAG_SHOW_UI);
                break;
            case R.id.btn_lower:
                // 指定调节音乐的音频，降低音量，只有声音,不显示图形条
                aManager.adjustStreamVolume(AudioManager.STREAM_MUSIC,
                        AudioManager.ADJUST_LOWER, AudioManager.FLAG_PLAY_SOUND);
                break;
            case R.id.btn_quite:
                // 指定调节音乐的音频，根据isChecked确定是否需要静音
                flag *= -1;
                if (flag == -1) {
                    aManager.setStreamMute(AudioManager.STREAM_MUSIC, true);   //API 23过期- -
//                    aManager.adjustStreamVolume(AudioManager.STREAM_MUSIC, AudioManager.ADJUST_MUTE,
//                            AudioManager.FLAG_SHOW_UI);   //23以后的版本用这个
                    btn_quite.setText("取消静音");
                } else {
                    aManager.setStreamMute(AudioManager.STREAM_MUSIC, false);//API 23过期- -
//                    aManager.adjustStreamVolume(AudioManager.STREAM_MUSIC, AudioManager.ADJUST_UNMUTE,
//                            AudioManager.FLAG_SHOW_UI);  //23以后的版本用这个
                    aManager.setMicrophoneMute(false);
                    btn_quite.setText("静音");
                }
                break;
        }
    }
}

El código sigue siendo muy sencillo. Además, el método para configurar el silenciosetStreamMute() está obsoleto en la API 23. Puedes usar el otro método adjustStreamVolume(int, int, int), y luego configurar el tercer atributo:

ADJUST_MUTE 或 ADJUST_UNMUTE！

Ah, y también:

SiadjustStreamVolumeel tercer parámetro de () lo configuras como vibración (Vibrator), ¡debes agregar este permiso en AndroidManifest.xml!

<**uses-permission android:name="android.permission.VIBRATE"**/>
