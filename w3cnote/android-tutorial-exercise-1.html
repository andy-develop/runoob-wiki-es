Además, todo el código del proyecto estará alojado en Github. Introduciremos gestión de ramas: la rama master se usará como la versión principal formal, y develop como la rama de desarrollo diario. Para añadir cosas nuevas, se crea una rama de funcionalidad a partir de develop, y al terminar se fusiona de vuelta a develop. Más o menos así; los detalles, véelos poco a poco.

1. Crear el repositorio de GitHub

Crea un nuevo proyecto en Android Studio, y asígnale el nombre:DrySisterDrySister, y el nombre del paquete:com.coderpig.drysisterVe al directorio raíz del proyecto, abre git bash y escribe el siguiente comando para crear el repositorio de Git: git init Crea un nuevo repositorio en Github, nómbralo DrySister, luego configura el repositorio remoto y escribe el comando: git remote add origin git@github.com:coder-pig/DrySister.git Se hace pull de la rama master, luego add, commit y push al repositorio de Github. A continuación, modifiqué el archivo .gitignore. Creé una nueva rama develop, hice commit en esa rama y luego la fusioné con la rama master. Bien, los preparativos en Git ya están más o menos listos.

2. Empezar a escribir el programa

Creamos una rama develop en local y empezamos a escribir el código. El diseño es muy simple: un ImageView que muestra la imagen de la chica y un Button,activity_main.xmlLuego escribimos una clase sencilla para descargar y cargar imágenes,PictureLoader.javaLa lógica es muy simple: el hilo convierte el flujo de entrada en un array de bytes; una vez convertido, en el handler se usa decodeByteArray para decodificar el array de bytes en un bitmap, y luego se muestra.

public class PictureLoader {
    private ImageView loadImg;
    private String imgUrl;
    private byte[] picByte;

    Handler handler = new Handler() {
        @Override
        public void handleMessage(Message msg) {
            super.handleMessage(msg);
            if (msg.what == 0x123) {
                if (picByte != null) {
                    Bitmap bitmap = BitmapFactory.decodeByteArray(picByte, 0, picByte.length);
                    loadImg.setImageBitmap(bitmap);
                }
            }
        }
    };

    public void load(ImageView loadImg, String imgUrl) {
        this.loadImg = loadImg;
        this.imgUrl = imgUrl;
        Drawable drawable = loadImg.getDrawable();
        if(drawable != null && drawable instanceof BitmapDrawable) {
            Bitmap bitmap = ((BitmapDrawable)drawable).getBitmap();
            if(bitmap != null && !bitmap.isRecycled()) {
                bitmap.recycle();
            }
        }
        new Thread(runnable).start();
    }

    Runnable runnable = new Runnable() {
        @Override
        public void run() {
            try {
                URL url = new URL(imgUrl);
                HttpURLConnection conn = (HttpURLConnection) url.openConnection();
                conn.setRequestMethod("GET");
                conn.setReadTimeout(10000);
                if (conn.getResponseCode() == 200) {
                    InputStream in = conn.getInputStream();
                    ByteArrayOutputStream out = new ByteArrayOutputStream();
                    byte[] bytes = new byte[1024];
                    int length = -1;
                    while ((length = in.read(bytes)) != -1) {
                        out.write(bytes, 0, length);
                    }
                    picByte = out.toByteArray();
                    in.close();
                    out.close();
                    handler.sendEmptyMessage(0x123);
                }

            } catch (IOException e) {
                e.printStackTrace();
            }
        }
    };
}

Luego estáMainActivity.java, que también es muy simple, así que no lo explicaré.

public class MainActivity extends AppCompatActivity implements View.OnClickListener {
    private Button showBtn;
    private ImageView showImg;
    private ArrayList<String> urls;
    private int curPos = 0;
    private PictureLoader loader;

    @Override protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        loader = new PictureLoader();
        initData();
        initUI();
    }

    private void initData() {
        urls = new ArrayList<>();
        urls.add("http://ww4.sinaimg.cn/large/610dc034jw1f6ipaai7wgj20dw0kugp4.jpg");
        urls.add("http://ww3.sinaimg.cn/large/610dc034jw1f6gcxc1t7vj20hs0hsgo1.jpg");
        urls.add("http://ww4.sinaimg.cn/large/610dc034jw1f6f5ktcyk0j20u011hacg.jpg");
        urls.add("http://ww1.sinaimg.cn/large/610dc034jw1f6e1f1qmg3j20u00u0djp.jpg");
        urls.add("http://ww3.sinaimg.cn/large/610dc034jw1f6aipo68yvj20qo0qoaee.jpg");
        urls.add("http://ww3.sinaimg.cn/large/610dc034jw1f69c9e22xjj20u011hjuu.jpg");
        urls.add("http://ww3.sinaimg.cn/large/610dc034jw1f689lmaf7qj20u00u00v7.jpg");
        urls.add("http://ww3.sinaimg.cn/large/c85e4a5cjw1f671i8gt1rj20vy0vydsz.jpg");
        urls.add("http://ww2.sinaimg.cn/large/610dc034jw1f65f0oqodoj20qo0hntc9.jpg");
        urls.add("http://ww2.sinaimg.cn/large/c85e4a5cgw1f62hzfvzwwj20hs0qogpo.jpg");
    }

    private void initUI() {
        showBtn = (Button) findViewById(R.id.btn_show);
        showImg = (ImageView) findViewById(R.id.img_show);
        showBtn.setOnClickListener(this);
    }

    @Override public void onClick(View v) {
        switch (v.getId()) {
            case R.id.btn_show:
                if (curPos > 9) {
                    curPos = 0;
                }
                loader.load(showImg, urls.get(curPos));
                curPos++;
                break;
        }
    }
}

4. Resumen

Primero hablemos de lo que hicimos en esta sección.：

  • 1. Creamos el proyecto DrySister y lo alojamos en Github.
  • 2. Escribimos una función muy simple para mostrar imágenes de la red.

Por optimizar y cosas que queremos añadir：

  • 1. La fuente de las imágenes en el código está hardcodeada; cada día solo se pueden ver unas pocas imágenes, y no se utiliza la API proporcionada por Gank.
  • 2. La clase de carga de imágenes solo carga desde la red; debería añadirse la carga de imágenes locales.

Lo que se hará en la siguiente sección：

  • 1. Usar el analizador rudimentario integrado de Android para parsear los datos de la interfaz y obtener la fuente de datos para mostrar las imágenes.
  • 2. Optimizar la clase de carga de imágenes.
