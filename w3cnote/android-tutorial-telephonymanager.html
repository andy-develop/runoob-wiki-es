10.1 TelephonyManager (Administrador de telefonía)

Categoría Tutorial básico de introducción a Android

Introducción a esta sección:

Este capítulo es el último del tutorial básico de introducción a Android. Principalmente explica algunos conocimientos dispersos y complementa algunos puntos omitidos. Estos conocimientos dispersos incluyen el uso de varios servicios del sistema, como el administrador de telefonía de esta sección, el administrador de SMS, el vibrador, la alarma, el fondo de pantalla, etc., ¡y también cosas como sensores! ¡Hay de todo un poco! Bien, en esta sección vamos a aprender sobre TelephonyManager, que como su nombre indica: se utiliza para gestionar el estado de las llamadas del teléfono, obtener información telefónica (información del dispositivo, información de la tarjeta SIM e información de red), detectar el estado de las llamadas (estado del servicio de llamadas, estado de intensidad de señal, etc.) y también puede invocar al marcador del teléfono para realizar llamadas. ¡Sin más, comencemos con el contenido de esta sección~

3) Obtener la intensidad de señal del teléfono

La unidad de intensidad de señal de red es dBm (decibelios-milivatios), generalmente expresada en números negativos. El rango normal de señal del teléfono varía de -110dBm (mala) a -50dBm (buena). Si es menor que -50dBm, significa que estás cerca de la estación base. Por ejemplo, mi N5 muestra una intensidad de señal de -51dBm, a veces -59dBm, porque al lado está el edificio Nanruan, que tiene una estación base en la azotea...

Además, para 2G, 3G y 4G, la forma de obtener la intensidad de señal es sobrescribir el método onSignalStrengthsChanged() de PhoneStateListener. Cuando la intensidad de señal cambia, se dispara este evento, y podemos obtener la intensidad de señal en este evento.

Ejemplo de código para obtener la intensidad de señal del teléfono：

dBm =-113+2*asuEsta es una fórmula fija: asu (unidad de señal independiente)

Captura del efecto en ejecución：

Código de implementación：

MainActivity.java：

public class MainActivity extends AppCompatActivity {

    private TextView tv_rssi;
    private MyPhoneStateListener mpsListener;
    private TelephonyManager tManager;


    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        tManager = ((TelephonyManager)getSystemService(Context.TELEPHONY_SERVICE));
        tv_rssi = (TextView) findViewById(R.id.tv_rssi);
        mpsListener  = new MyPhoneStateListener();
        tManager.listen(mpsListener,290);
    }

    private class MyPhoneStateListener extends PhoneStateListener {
        private int asu = 0,lastSignal = 0;
        @Override
        public void onSignalStrengthsChanged(SignalStrength signalStrength) {
            asu = signalStrength.getGsmSignalStrength();
            lastSignal = -113 + 2 * asu;
            tv_rssi.setText("当前手机的信号强度：" + lastSignal + " dBm" );
            super.onSignalStrengthsChanged(signalStrength);
        }
    }
}

4) Escuchar todas las llamadas entrantes del teléfono

En cuanto a los resultados de los registros de llamadas escuchados, puedes obtenerlos de diferentes formas. Aquí se usa escribir los registros de llamadas en un archivo, pero también puedes enviártelos por SMS o subirlos a alguna plataforma. Claro, si no hay muchos registros de comunicación, puedes usar SMS; si son muchos, es fácil que te descubran. Además, aquí se usa Activity en lugar de Service, es decir, hay que abrir esta Activity para poder escuchar. Normalmente nuestros requisitos son correr silenciosamente en segundo plano; por cuestión de tiempo no escribiré el Service, si lo necesitas puedes modificarlo tú mismo, ¡haciendo que el Service se inicie junto con el arranque!

Análisis del código:

Muy sencillo: en realidad es sobrescribir un listener de estado de llamada de TelephonyManagerPhoneStateListenerLuego se llama al método TelephonyManager.listen() para escuchar. Cuando llega una llamada, el programa registra el número entrante en el archivo.

Código de implementación：

MainActivity.java：

public class MainActivity extends Activity  
{  
    TelephonyManager tManager;  
  
    @Override  
    public void onCreate(Bundle savedInstanceState)  
    {  
        super.onCreate(savedInstanceState);  
        setContentView(R.layout.main);  
        // 取得TelephonyManager对象  
        tManager = (TelephonyManager)   
            getSystemService(Context.TELEPHONY_SERVICE);  
        // 创建一个通话状态监听器  
        PhoneStateListener listener = new PhoneStateListener()  
        {  
            @Override  
            public void onCallStateChanged(int state, String number)  
            {  
                switch (state)  
                {  
                // 无任何状态  
                    case TelephonyManager.CALL_STATE_IDLE:  
                        break;  
                    case TelephonyManager.CALL_STATE_OFFHOOK:  
                        break;  
                    // 来电铃响时  
                    case TelephonyManager.CALL_STATE_RINGING:  
                        OutputStream os = null;  
                        try  
                        {  
                            os = openFileOutput("phoneList", MODE_APPEND);  
                        }  
                        catch (FileNotFoundException e)  
                        {  
                            e.printStackTrace();  
                        }  
                        PrintStream ps = new PrintStream(os);  
                        // 将来电号码记录到文件中  
                        ps.println(new Date() + " 来电：" + number);  
                        ps.close();  
                        break;  
                    default:  
                        break;  
                }  
                super.onCallStateChanged(state, number);  
            }  
        };  
        // 监听电话通话状态的改变  
        tManager.listen(listener, PhoneStateListener.LISTEN_CALL_STATE);  
    }  
}

5) Colgar automáticamente llamadas de la lista negra

La llamada lista negra consiste en agregar algunos números de teléfono a una colección, y cuando el teléfono recibe estas llamadas, se cuelgan directamente. Sin embargo, Android no nos proporciona una API para colgar llamadas, por lo que necesitamos usar AIDL para invocar las API del servicio y así colgar la llamada.

Entonces, el primer paso es copiar los siguientes dos archivos del código fuente de Android a las ubicaciones correspondientes en 'src'. Ellos son: en el paquete com.android.internal.telephonyITelephony.aidl;

en el paquete android.telephonyNeighboringCellInfo.aidl;

¡Hay que crear los paquetes correspondientes! ¡Es decir, hay que colocar los archivos AIDL en los paquetes anteriores! Luego solo necesitas llamar a endCall de ITelephony para colgar la llamada.

Aquí se proporciona un simple bloqueo de un solo número. Después de ingresar el número y hacer clic en el botón de bloqueo, si el número bloqueado llama en ese momento, se colgará directamente. El código es bastante simple; lo pego a continuación. Como el emulador usado es Genymotion, no mostraré capturas del programa en ejecución.

MainActivity.java：

public class MainActivity extends Activity {  
  
    private TelephonyManager tManager;  
    private PhoneStateListener pListener;  
    private String number;  
    private EditText locknum;  
    private Button btnlock;  
      
    public class PhonecallListener extends PhoneStateListener  
    {  
        @Override  
        public void onCallStateChanged(int state, String incomingNumber) {  
            switch(state)  
            {  
            case TelephonyManager.CALL_STATE_IDLE:break;  
            case TelephonyManager.CALL_STATE_OFFHOOK:break;  
            //当有电话拨入时  
            case TelephonyManager.CALL_STATE_RINGING:  
                if(isBlock(incomingNumber))  
                {  
                    try  
                    {  
                        Method method = Class.forName("android.os.ServiceManager")  
                                .getMethod("getService", String.class);  
                        // 获取远程TELEPHONY_SERVICE的IBinder对象的代理  
                        IBinder binder = (IBinder) method.invoke(null,  
                            new Object[] { TELEPHONY_SERVICE });  
                        // 将IBinder对象的代理转换为ITelephony对象  
                        ITelephony telephony = ITelephony.Stub.asInterface(binder);  
                        // 挂断电话  
                        telephony.endCall();  
                    }catch(Exception e){e.printStackTrace();}  
                }  
                break;  
            }  
            super.onCallStateChanged(state, incomingNumber);  
        }  
    }  
      
      
    @Override  
    protected void onCreate(Bundle savedInstanceState) {  
        super.onCreate(savedInstanceState);  
        setContentView(R.layout.activity_main);  
          
        locknum = (EditText) findViewById(R.id.locknum);  
        btnlock = (Button) findViewById(R.id.btnlock);  
          
        //获取系统的TelephonyManager管理器  
        tManager = (TelephonyManager) getSystemService(TELEPHONY_SERVICE);  
        pListener = new PhoneStateListener();  
        tManager.listen(pListener, PhoneStateListener.LISTEN_CALL_STATE);  
          
        btnlock.setOnClickListener(new OnClickListener() {  
              
            @Override  
            public void onClick(View v) {  
                number = locknum.getText().toString();                
            }  
        });  
          
    }  
      
    public boolean isBlock(String phone)  
    {  
        if(phone.equals(number))return true;  
        return false;  
    }  
}
