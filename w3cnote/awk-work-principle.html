Cómo funciona AWK

Categoría Tecnología de programación

En este artículo, principalmente les presentamos cómo funciona AWK.

El flujo de trabajo de AWK se puede dividir en tres partes:

  • El segmento de código que se ejecuta antes de leer el archivo de entrada (identificado por la palabra clave BEGIN).
  • El segmento de código que el bucle principal ejecuta sobre el archivo de entrada.
  • El segmento de código que se ejecuta después de leer el archivo de entrada (identificado por la palabra clave END).

Estructura del comando:

awk 'BEGIN{ commands } pattern{ commands } END{ commands }'

El siguiente diagrama de flujo describe el flujo de trabajo de AWK:

  • 1. A través de la palabra clave BEGIN se ejecuta el contenido del bloque BEGIN, es decir, el contenido de las llaves después{}de BEGIN.
  • 2. Una vez completada la ejecución del bloque BEGIN, comience a ejecutar el bloque body.
  • 3. Lea los registros separados por\n caracteres de nueva línea.
  • 4. Divida los registros en campos según el delimitador de campo especificado, y rellene los campos.$0Entonces representa todos los campos (es decir, el contenido de una línea).$1Representa el primer campo.$nRepresenta el enésimo campo.
  • 5. Ejecute cada bloque BODY en orden; solo cuando la parte del patrón coincida exitosamente con el contenido de la línea, se ejecutará el contenido de awk-commands.
  • 6. Lea y ejecute cada línea en bucle hasta el final del archivo, completando así la ejecución del bloque body.
  • 7. Comience la ejecución del bloque END; el bloque END puede generar el resultado final.

Bloque de inicio (BEGIN)

La sintaxis del bloque de inicio es la siguiente:

BEGIN {awk-commands}

El bloque de inicio es la parte del código que se ejecuta cuando el programa se inicia, y solo se ejecuta una vez durante todo el proceso.

Generalmente, podemos inicializar algunas variables en el bloque de inicio.

BEGIN es una palabra clave de AWK, por lo tanto debe estar en mayúsculas.

Nota:El bloque de inicio es opcional; su programa puede no tener la parte del bloque de inicio.

Bloque principal (BODY)

La sintaxis de la parte principal es la siguiente:

/pattern/ {awk-commands}

Los comandos de la parte principal se ejecutan una vez por cada línea de entrada.

De forma predeterminada, AWK ejecuta los comandos para cada línea de entrada. Sin embargo, podemos limitarlo a un patrón específico.

Nota: En el bloque principal no existe ninguna palabra clave.

Bloque de fin (END)

La sintaxis del bloque de fin es la siguiente:

END {awk-commands}

El bloque de fin es el código que se ejecuta al final del programa. END también es una palabra clave de AWK y también debe estar en mayúsculas. Al igual que el bloque de inicio, el bloque de fin también es opcional.

Ejemplo

Primero cree un archivo llamado marks.txt. Este incluye el número de serie, el nombre del estudiante, el nombre del curso y la calificación obtenida.

1)    张三    语文    80
2)    李四    数学    90
3)    王五    英语    87

A continuación, usaremos un script de AWK para mostrar el contenido del archivo de salida y, al mismo tiempo, generar la información del encabezado.

$ awk 'BEGIN{printf "序号\t名字\t课程\t分数\n"} {print}' marks.txt

Después de ejecutar el comando anterior, el resultado de salida es el siguiente:

序号    名字    课程    分数
1)    张三    语文    80
2)    李四    数学    90
3)    王五    英语    87

Cuando el programa comienza a ejecutarse, AWK genera la información del encabezado en el bloque de inicio. En el bloque principal, cada vez que AWK lee una línea, envía el contenido leído al flujo de salida estándar, hasta que todo el archivo haya sido leído por completo.
