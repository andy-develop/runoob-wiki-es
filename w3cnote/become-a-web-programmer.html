Cómo convertirse en programador de desarrollo web

Categoría Tecnología de programación

1. ¿Qué puntos de conocimiento necesita un programador web?

Las aplicaciones web se ejecutan principalmente en el navegador. La página web que abrimos habitualmente es un programa web. Las tecnologías web comunes incluyen:

  • HTTP
  • FTP
  • POP3
  • SMTP
  • TCP
  • IP protocols
  • HTML
  • XML
  • Coldfusion
  • ASP
  • JSP
  • PHP
  • ASP.NET

2. Navegar por varios tipos de sitios web

En los navegadores que solemos usar, como Chrome o Firefox, puede presionar la tecla F12 (o hacer clic derecho y seleccionar "Ver código fuente") para ver el código fuente de la página web.

Los tipos de sitios web incluyen: sitios corporativos, portales, blogs personales, enciclopedias, redes sociales, etc.

3. Aprender a usar un software de diagramas de flujo

Puede ser: MS Visio o Xmind.

4. Familiarizarse con la estructura del sitio web

Familiarícese con la estructura de árbol del sitio web, el mapa del sitio, la configuración de navegación, etc.

5. Puede aprender un software de procesamiento de imágenes

6. Aprender los conceptos básicos de Internet

  • Protocolos básicos de servicios web (HTTP, FTP, SMTP y POP3 o IMAP4)
  • Software de servidor web (Apache, Tomcat, Nginx, etc.)
  • Navegadores (Chrome, Firefox, etc.)
  • Servidores de correo electrónico y software de cliente

7. Aprender HTML y CSS

Si comparamos un sitio web con una casa, HTML es similar a la estructura de ladrillos de la página web, y CSS es el material para decorar la casa.

Puede ir directamente al sitio web Tutorial para novatos para aprender.

8. Aprender XML, JSON y tecnologías relacionadas

También en Tutorial para novatos.

9. Usar HTML para crear una página estática simple

10. Aprender lenguajes de script de cliente

Los lenguajes de script de cliente pueden entenderse como los interruptores dentro de la casa: luces, calentadores de agua, etc.

Los lenguajes incluyen: JavaScript, VBScript, Java Applet (obsoleto). Se recomienda aprender directamente JavaScript.

JavaScript es un lenguaje de script de cliente. Es muy importante, estúdialo bien.

Lo repito: está en Tutorial para novatos.

11. Aprender un lenguaje de backend

Puede ser PHP, JSP, ASP.Net, etc. Estos lenguajes se utilizan principalmente para la interacción con los datos del backend, implicando operaciones como agregar, eliminar, modificar y consultar datos.

12. Intentar escribir un pequeño proyecto por uno mismo

Puede ser un sistema de blog personal, un carrito de compras, etc.

13. Participar en el desarrollo de un proyecto web

Aprender es solo el comienzo; el crecimiento más importante se da en el desarrollo de proyectos...
