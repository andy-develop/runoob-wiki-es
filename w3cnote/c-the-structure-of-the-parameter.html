C: Paso de estructuras como parámetros

Categoría Tecnología de programación

Primero, hay tres formas de pasar una estructura como parámetro de función:

Primera: pasar la variable de estructura, esto es paso por valor; segunda: pasar un puntero a estructura, esto es paso por dirección; tercera: pasar un miembro de la estructura, por supuesto esto también se divide en paso por valor y paso por dirección.

Pasar una estructura mediante llamada por referencia es más eficiente que pasarla por valor. Pasar una estructura por valor requiere hacer una copia de toda la estructura.

A continuación veamos un ejemplo. La estructura student contiene diversa información del estudiante. En la función change modificamos parte de ella y luego mostramos el resultado en la función principal.

1. A continuación se pasa la variable de estructura

#include<stdio.h>
#include<string.h>
#define format "%d\n%s\n%f\n%f\n%f\n"
struct student
{
    int num;
    char name[20];
    float score[3];
};
void change( struct student stu );
int main()
{
    
    struct student stu;
    stu.num = 12345;
    strcpy(stu.name, "Tom");
    stu.score[0] = 67.5;
    stu.score[1] = 89;
    stu.score[2] = 78.6;
    change(stu);
    printf(format, stu.num, stu.name, stu.score[0], stu.score[1],stu.score[2]);
    printf("\n");
    return 0;
}
 
void change(struct student stu)
{
    stu.score[0] = 100;
    strcpy(stu.name, "jerry");
}

Se puede ver que el valor de salida final no ha cambiado...

2. Paso por dirección

#include<stdio.h>
#define format "%d\n%s\n%f\n%f\n%f\n"
struct student
{
    int num;
    char name[20];
    float score[3];
};
void change( struct student* stu );
int main()
{
    
    struct student stu;
    stu.num = 12345;
    strcpy(stu.name, "Tom");
    stu.score[0] = 67.5;
    stu.score[1] = 89;
    stu.score[2] = 78.6;
    change(&stu);
    printf(format, stu.num, stu.name, stu.score[0], stu.score[1],stu.score[2]);
    printf("\n");
    return 0;
}
 
void change(struct student* p)
{
    p->score[0] = 100;
    strcpy(p->name, "jerry");
}

Se puede ver que, mediante el paso por dirección, se modificaron los datos dentro de la estructura.

Se usa &stu como argumento real; &stu es la dirección de la variable de estructura stu. Al llamar a la función, se transmite esa dirección al parámetro formal p (p es una variable puntero). Así, p apunta a stu.

Al cambiar los valores de los miembros de la estructura en la función change, en la función principal se muestran los valores modificados.

3. Paso por dirección y paso por valor de los miembros de la estructura

Esto es similar a la transferencia de una variable única; no es necesario explicarlo aquí. Por supuesto, solo el paso por dirección permite modificar.

Pasar una variable de estructura completa como parámetro requiere transmitir los valores de todos los miembros uno por uno, lo que consume tiempo y espacio, y tiene un gran costo. Si la estructura tiene muchos miembros, o algunos son arreglos, la eficiencia de ejecución del programa se reducirá considerablemente. En este caso, es mejor usar punteros como parámetros de función, lo que puede mejorar la eficiencia de ejecución.
