Resumen de la función time en C

Categoría

En programación, las funciones para expresar y convertir el tiempo se usan con frecuencia; todas están definidas en la biblioteca time.h. Aquí se hace un resumen para facilitar su consulta y uso posterior.

Algunos conceptos de tiempo:

1：Coordinated Universal Time(UTC)：

El Tiempo Universal Coordinado, también llamado Hora Estándar Mundial, es decir, la Hora del Meridiano de Greenwich (Greenwich Mean Time, GMT). La diferencia horaria entre China continental y UTC es +8, es decir, UTC+8; Estados Unidos es UTC-5.

2：Calendar Time：

El tiempo de calendario es el tiempo expresado como "el número de segundos transcurridos desde un punto de tiempo estándar hasta este momento". El punto de tiempo estándar puede variar según el compilador, pero para un sistema de compilación, el tiempo estándar es invariable. Generalmente, se expresa como el número de segundos desde 1970-01-01 00:00:00 UTC.

3：epoch：

Punto de tiempo. En C/C++ estándar es un entero que se expresa mediante la diferencia en segundos entre el tiempo actual y el punto de tiempo estándar (es decir, el tiempo de calendario).

4：clock tick：

Unidad de medición de tiempo del reloj (no llamada número de tics de reloj). La duración de una unidad de medición de tiempo del reloj está controlada por la CPU. Un clock tick no es un ciclo de reloj de la CPU, sino una unidad básica de medición de tiempo de C/C++.

Definición de time.h

El archivo de cabecera time.h define cuatro tipos de variables, dos macros y varias funciones para manipular fechas y horas.

4 variables

size_t Es un tipo entero sin signo, que es el resultado de la palabra clave sizeof.
clock_t Es un tipo adecuado para almacenar tiempo de procesador, de tipo unsigned long.
time_t Es un tipo adecuado para almacenar tiempo de calendario.
struct tm Es una estructura para almacenar hora y fecha.

La definición de la estructura tm es la siguiente:

struct tm
{
   int tm_sec;         /* Segundos, rango de 0 a 59 */
   int tm_min;         /* Minutos, rango de 0 a 59 */
   int tm_hour;        /* Horas, rango de 0 a 23 */
   int tm_mday;        /* Día del mes, rango de 1 a 31 */
   int tm_mon;         /* Mes, rango de 0 a 11 (nota) */
   int tm_year;        /* Años desde 1900 */
   int tm_wday;        /* Día de la semana, rango de 0 a 6 */
   int tm_yday;        /* Día del año, rango de 0 a 365 */
   int tm_isdst;       /* Horario de verano */
};

Dos macros

NULL Esta macro es el valor de una constante de puntero nulo.
CLOCKS_PER_SEC Esta macro representa el número de tics de reloj del procesador por segundo. Se utiliza para convertir el resultado de la función clock() en una cantidad expresada en segundos; su valor específico depende del sistema operativo y suele ser 1000.

Funciones de biblioteca

1: función clock

Prototipo de la función:clock_t clock(void)

Valor de retorno: devuelve el tiempo de reloj del procesador transcurrido desde el inicio de la ejecución de la función clock (generalmente el inicio del programa).

Función: se utiliza para calcular el tiempo de ejecución de un programa o de una parte de él.

Ejemplo

#include<stdio.h>
#include<time.h>

int main()
{
    clock_t start_t,finish_t;
    double total_t = 0;
    int i = 0;
    start_t = clock();
    for(;i<100000;++i)
    {
        //do someting;
    }
    finish_t = clock();
    total_t = (double)(finish_t - start_t) / CLOCKS_PER_SEC;// Convierte el tiempo a segundos

    printf("Tiempo total de CPU: %f\n", total_t);
    return 0;
}

2: función time

Prototipo de la función: time_t time(time_t *timer)

Descripción de parámetros: cuando timer=NULL se obtiene el tiempo de calendario actual (segundos desde 1970-01-01 00:00:00 hasta ahora); cuando timer es un valor de tiempo, se usa para establecer el tiempo de calendario. time_t es un tipo unsigned long. Si timer no es NULL, el valor de retorno también se almacena en la variable timer.

Función: obtener el tiempo de calendario actual o establecerlo.

Valor de retorno: tiempo de calendario actual.

Ejemplo

#include <stdio.h>
#include <time.h>

int main ()
{
  time_t seconds;

  seconds = time(NULL);
  printf("Horas desde 1970-01-01 = %ld\n", seconds/3600);

  return(0);
}

3: función asctime

Prototipo de la función: char* asctime(struct tm * ptr)

Función: representa el tiempo indicado por la estructura struct tm * ptr como una cadena de caracteres.

Valor de retorno: el formato de la cadena de tiempo devuelta es: día de la semana, mes, día, hora:minuto:segundo, año.

Descripción de parámetros: el puntero de estructura ptr debe obtenerse mediante las funciones localtime() o gmtime().

Ejemplo

#include <stdio.h>
#include <time.h>

int main()
{
   struct tm t;// En la mayoría de los casos, la estructura tm se obtiene mediante las funciones localtime y gmtime.

   t.tm_sec    = 10;
   t.tm_min    = 10;
   t.tm_hour   = 6;
   t.tm_mday   = 25;
   t.tm_mon    = 2;
   t.tm_year   = 89;
   t.tm_wday   = 6;

   printf("%s\n",asctime(&t));

   return(0);
}

4: función localtime

Prototipo de la función: struct tm *localtime(const time_t *timer)

Función: utiliza el valor de timer para rellenar la estructura tm. El valor de timer se descompone en una estructura tm y se expresa en la zona horaria local.

Valor de retorno: el tiempo expresado como estructura tm.

Ejemplo

#include <stdio.h>
#include <time.h>

int main ()
{
   time_t timer;
   struct tm *Now;

   time( &timer );
   Now = localtime( &timer );
   printf("Hora y fecha local actual: %s", asctime(Now));

   return(0);
}

5: función ctime

Prototipo de la función: char *ctime(const time_t * timer)

Función: convierte el parámetro de tiempo de calendario timer en una cadena que representa la hora local actual.

Valor de retorno: formato de la cadena devuelta: día de la semana, mes, día, hora:minuto:segundo, año.

Descripción de parámetros: el parámetro timer debe obtenerse mediante la función time; es equivalente a astime( localtime(timer) ).

Ejemplo

#include <stdio.h>
#include <time.h>

int main ()
{
   time_t curtime;
   time(&curtime);
   printf("Hora actual = %s", ctime(&curtime));

   return(0);
}

6: función difftime

Prototipo de la función: double difftime(time_t time2, time_t time1)

Función: obtiene la diferencia entre dos tiempos de máquina, en segundos.

Valor de retorno: la diferencia de tiempo, en segundos.

Descripción de parámetros: time1 y time2 representan dos tiempos de máquina diferentes; estos parámetros deben obtenerse con la función time.

Ejemplo

#include <time.h>  
#include <stdio.h>  
int main()  
{  
    time_t first,second;  
    time(&first);  
    sleep(2000);  
    time(&second);
    printf("The difference is: %f seconds",difftime(second,first));  

    return 0;  
}  

7: función gmtime

Prototipo de la función: struct tm *gmtime(time_t *timer)

Función: obtiene la información de tiempo representada como estructura tm y expresada en hora estándar de Greenwich.

Valor de retorno: puntero a la información de tiempo representada como estructura tm.

Descripción de parámetros: timer es la información de tiempo obtenida con la función time().

Ejemplo

#include <stdio.h>
#include <time.h>

#define BST (+1)
#define CCT (+8)

int main ()
{

   time_t rawtime;
   struct tm *info;

   time(&rawtime);
   /* Obtener la hora GMT */
   info = gmtime(&rawtime );

   printf("Reloj mundial actual:\n");
   printf("Londres: %2d:%02d\n", (info->tm_hour+BST)%24, info->tm_min);
   printf("China: %2d:%02d\n", (info->tm_hour+CCT)%24, info->tm_min);

   return(0);
}

8: función mktime

Prototipo de la función: time_t mktime(struct tm *timeptr)

Función: convierte la estructura a la que apunta timeptr en un valor time_t basado en la zona horaria local.

Valor de retorno: esta función devuelve un valor time_t que corresponde al tiempo de calendario pasado como parámetro. Si se produce un error, devuelve el valor -1.

Ejemplo

#include <stdio.h>
#include <time.h>

int main ()
{
   int ret;
   struct tm info;
   char buffer[80];

   info.tm_year = 2001 - 1900;
   info.tm_mon = 7 - 1;
   info.tm_mday = 4;
   info.tm_hour = 0;
   info.tm_min = 0;
   info.tm_sec = 1;
   info.tm_isdst = -1;

   ret = mktime(&info);
   if( ret == -1 )
   {
       printf("Error: no se puede convertir el tiempo con mktime.\n");
   }
   else
   {
      strftime(buffer, sizeof(buffer), "%c", &info );
      print(buffer);
   }

   return(0);
}

9: función strftime

Prototipo de la función: size_t strftime( char *strDest, size_t maxsize, const char *format, const struct tm *timeptr);

Función: según los comandos de formato de la cadena apuntada por format, coloca la información de tiempo almacenada en timeptr en la cadena apuntada por strDest; almacena como máximo maxsize caracteres en strDest.

Descripción de parámetros: el resultado convertido se guarda en s; se escriben como máximo maxsize caracteres en s.

Valor de retorno: esta función devuelve el número de caracteres colocados en la cadena apuntada por strDest (sin incluir '\0'); si el número de caracteres supera maxsize, la función devuelve 0.

Ejemplo

/* El formato es el siguiente: distinguen entre mayúsculas y minúsculas.
%a Abreviatura del día de la semana
%A Nombre completo del día de la semana
%b Abreviatura del mes
%B Nombre completo del mes
%c Cadena de fecha y hora estándar
%C Los últimos dos dígitos del año
%d Día del mes en decimal
%D mes/día/año
%e Día del mes en decimal, en un campo de dos caracteres
%F año-mes-día
%g Los últimos dos dígitos del año, usando el año basado en semanas
%G Año, usando el año basado en semanas

%I Hora en formato de 12 horas

%T Muestra hora, minutos y segundos: hh:mm:ss
%u Día de la semana, el lunes es el primer día (valores de 0 a 6, el lunes es 0)

#include <stdio.h>
#include <time.h>

int main ()
{
   time_t rawtime;
   struct tm *info;
   char buffer[80];

   time( &rawtime );

   info = localtime( &rawtime );

   strftime(buffer,80,"%Y%m%e_%H%M%S", info);//Representa la hora actual en el formato año-mes-día_hora-minuto-segundo
   printf("%s\n", buffer );

   return(0);
}
