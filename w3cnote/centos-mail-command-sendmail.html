Linux usa comandos para enviar correos

Categoría Tecnología de programación

Al administrar servidores, a menudo necesitamos escribir algunos scripts de monitoreo, y luego notificar por correo cuando ocurren problemas. A continuación te presentamos la forma más sencilla de lograr el envío de correos en Linux:

Comando mail en sistemas Centos, RedHat

1. Cierra el servicio sendmail o el servicio postfix de esta máquina

#执行下面的命令，各位大侠都对号入座吧
#sendmial
service sendmail stop
chkconfig sendmail off
#postfix
service postfix stop
chkconfig postfix off

#再狠一点就直接卸载吧..
yum remove sendmail
yum remove postfix

2. Luego modifica /etc/mail.rc, añade el siguiente contenido al final del archivo, especificando la dirección del servidor smtp externo, cuenta y contraseña, etc.

$ vi /etc/mail.rc  
set from=123456@qq.com
set smtp=smtp.qq.com  
set smtp-auth-user=123456
set smtp-auth-password=runoob
set smtp-auth=login

QQ Mail genera un código de autorización para establecer la contraseña:

3. Luego envía el correo mediante el comando

echo  hello word | mail -s " title" 123456@qq.com

Comando heirloom-mailx en sistemas Ubuntu

1. Instala heirloom-mailx

sudo apt-get install heirloom-mailx

2. Configuración

vi /etc/nail.rcAñade el servidor smtp de QQ Mail que requiere autenticación y está habilitado:
