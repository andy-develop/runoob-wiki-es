Repaso de los diez lenguajes de programación para computación en la nube más cool

Categoría Tecnología de programación

Cuando la gente piensa en elegir un lenguaje informático, puede optar por uno de los lenguajes procedurales de propósito general más conocidos que se aprenden en la escuela, como C, Java o Python. Pero estos lenguajes frecuentemente elegidos son solo la punta del iceberg en el campo de los lenguajes informáticos: si utiliza palabras clave y estructuras para transmitir información, entonces es un lenguaje. A continuación se presentan los diez lenguajes para la nube que merece la pena considerar.

1. Lenguaje de datos SQL

Hablando de lenguajes de datos, SQL ha sido el rey indiscutible durante décadas. Incluso los servidores de bases de datos no relacionales utilizan algún tipo de lenguaje SQL. Como en todas las demás áreas de TI, el campo de la computación en la nube también está lleno de SQL.

Este es un chiste de SQL que hará sonreír a los desarrolladores de todas partes. "Un tipo entra a un bar, ve dos mesas y dice: ¿Puedo unirme a ti?"

2. Lenguaje de datos XML

XML se utiliza para describir documentos, no para transmitir una serie de instrucciones. Dado que XML normalmente no da instrucciones a la computadora, generalmente no se considera un lenguaje informático.

XML es un lenguaje de marcado de datos muy popular, y esto se debe principalmente a Java. Donde hay Java, hay XML. Y como Java ha impulsado sistemas distribuidos a gran escala desde mucho antes de que la computación en la nube se generalizara, los documentos XML están en todas partes. La configuración de Apache Hadoop reside en archivos XML.

3. Lenguaje matemático R

El lenguaje R ayuda a los desarrolladores a manejar estadísticas, informes y gráficos. Los tutoriales interactivos de R permiten a los nuevos desarrolladores descubrir la diversión de los vectores, factores y conjuntos de datos asociados.

Amazon combina el entorno de desarrollo integrado (IDE) RStudio con su servicio EMR (Elastic MapReduce) para ayudar con el análisis de big data.

4. Lenguaje matemático Clojure

Clojure no es solo un lenguaje matemático; es tanto un lenguaje de propósito general como un lenguaje funcional. Además, casualmente, Clojure también es muy popular entre los analistas de datos.

El sistema de procesamiento de flujo de datos en tiempo real Apache Storm está escrito en Clojure. Los lenguajes funcionales no necesitan punto y coma, mientras que los procedurales lo necesitan; puedes ver que el punto y coma solo se usa para los comentarios en este script de Clojure (https://github.com/apache/storm/blob/master/storm-core/src/clj/backtype/storm/clojure.clj).

5. Lenguaje funcional Haskell

Haskell es un lenguaje funcional, ideal para la computación distribuida. El proyecto Cloud Haskell Platform se puso en marcha hace varios años.

A pesar de que Haskell tiene una tasa de adopción bastante alta en la industria y se encuentra entre los 20 principales lenguajes de GitHub, su adopción en el ámbito de la computación en la nube deja mucho que desear, posiblemente porque se considera que Haskell es demasiado difícil de aprender. Puedes probarlo tú mismo en el tutorial Try Haskell.

6. Lenguaje funcional Erlang

Erlang nació en Ericsson. En la industria de las telecomunicaciones, los productos deben funcionar indefinidamente, y todo (clientes, contactos, transacciones y registros) se cuenta por millones.

Un lenguaje funcional de grado de telecomunicaciones suena perfecto para la computación en la nube. Y, de hecho, aunque no se encuentra entre los 20 principales lenguajes de GitHub, Erlang impulsa aplicaciones de nube muy populares, incluyendo Riak, CouchDB, RabbitMQ e incluso el unikernel LING.

7. Lenguaje procedural Python

Python es un lenguaje de alto nivel diseñado para ser fácil de leer. Hoy en día, casi todo el mundo, de hecho todo el mundo, puede empezar rápidamente con Python. Los recursos de aprendizaje incluyen cursos, libros e incluso tutoriales interactivos de Python.

OpenStack, el popular software de gestión de infraestructura como servicio (IaaS), está escrito en Python. Eche un vistazo a este código Python para la interfaz de cliente de Nova (https://github.com/openstack/python-novaclient/blob/master/novaclient/client.py).

8. Lenguaje procedural Go

Hace varios años, Google desarrolló Go, cuando algunos programadores de Google estaban bastante frustrados con lenguajes como el C++ de Stroustrup. Google ofrece el tutorial interactivo de Go y Go Playground para trabajar con código.

Como favorito en el campo de la computación en la nube, Docker está escrito en Go, al igual que muchos otros proyectos del ecosistema Docker.

9. Lenguaje de dominio específico GFM

GFM (GitHub Flavored Markdown) es un lenguaje de formato de texto plano que se puede utilizar para documentar repositorios de software en GitHub. GFM es utilizado por millones de desarrolladores, porque millones de desarrolladores usan GitHub.

Dado que hay tantos proyectos en GitHub específicamente orientados a la nube, como Cloud Foundry, es bueno conocer GFM. Probablemente sea el más fácil de aprender de los diez lenguajes presentados en este artículo.

10. Lenguaje de dominio específico para expresiones regulares

La sintaxis de las expresiones regulares (Regex) hace que los principiantes se rasquen la cabeza, porque en realidad es simbólica: son solo caracteres individuales, no palabras clave. El código de expresiones regulares parece que alguien se durmió sobre el teclado. Si quieres no volver a tocar el lenguaje de las expresiones regulares en tu vida, mira este ejemplo extremo: un analizador JSON (http://www.perlmonks.org/?node_id=995856).

Sin embargo, las expresiones regulares son una piedra angular en el mundo Linux. Uno de los principios fundamentales de los antiguos sistemas UNIX y de los derivados posteriores de Linux es el uso extensivo de texto. El texto se usa en todas partes: en la configuración, en la línea de comandos y en los protocolos. Las expresiones regulares ayudan a los desarrolladores a gestionar bien el texto.

Hay otros cientos de lenguajes más

Hay muchos más lenguajes excelentes para elegir. Tómate un tiempo para leer libros como el clásico de 2010 'Siete lenguajes en siete semanas' (https://pragprog.com/book/btlang/seven-languages-in-seven-weeks), que te da una idea general de varios lenguajes, incluidos Prolog y Scala. O también puedes elegir tu propia combinación de lenguajes.
