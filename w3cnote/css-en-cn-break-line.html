Código CSS para forzar saltos de línea y no saltos de línea en inglés y chino

Categoría Tecnología de programación

  • 1. word-break:break-all;Solo funciona con inglés, usa letras como base para los saltos de línea
  • 2. word-wrap:break-word;Solo funciona con inglés, usa palabras como base para los saltos de línea
  • 3. white-space:pre-wrap;Solo funciona con chino, fuerza el salto de línea
  • 4. white-space:nowrap;Forzar no salto de línea, funciona en ambos casos
  • 5. white-space:nowrap; overflow:hidden; text-overflow:ellipsis;Sin salto de línea, la parte que sobresale se oculta y aparece como puntos suspensivos

Nota:Asegúrese de especificar el ancho (width) del contenedor, de lo contrario no funcionará.

Ejemplo

.p1{ word-break:break-all; width:150px;} .p2{ word-wrap:break-word; width:150px;} .p3{white-space:pre-wrap; width:150px;} .p4{white-space:nowrap; width:10px;} .p5{white-space:nowrap; overflow:hidden; text-overflow:ellipsis; width:100px;}

Sintaxis de word-break

word-break : normal | break-all | keep-all

Parámetros:

  • normal: Sigue las reglas de texto de los idiomas asiáticos y no asiáticos, permite saltos de línea dentro de las palabras
  • break-all: Este comportamiento es el mismo que normal para los idiomas asiáticos. También permite cortes arbitrarios dentro de las palabras en líneas de texto de idiomas no asiáticos. Este valor es adecuado para texto asiático que contiene algo de texto no asiático
  • keep-all: Igual que normal para todos los idiomas no asiáticos. Para chino, coreano y japonés, no permite cortes de palabras. Adecuado para texto no asiático que contiene una pequeña cantidad de texto asiático
