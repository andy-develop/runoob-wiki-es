Barra de navegación con búsqueda CSS

categoría Técnicas de programación

Este artículo presenta cómo usar CSS para crear una barra de navegación con búsqueda.

Los siguientes ejemplos son todos responsivos.

Primero, puedes ver la imagen del efecto:

Crear una barra de búsqueda

Código HTML

<div class="topnav"> <a class="active" href="#home">página principal</a> <a href="#about">Acerca de</a> <a href="#contact">Contáctenos</a> <input type="text" placeholder="Buscar.."> </div>

Código CSS

/*Agregar color de fondo negro a la barra de navegación superior*/ .topnav { overflow: hidden; background-color: #e9e9e9; } /*Establecer el estilo de los enlaces de la barra de navegación*/ .topnav a { float: left; display: block; color: black; text-align: center; padding: 14px 16px; text-decoration: none; font-size: 17px; } /*Cambiar el color del enlace al pasar el ratón por encima*/ .topnav a:hover { background-color: #ddd; color: black; } /*Resaltar el elemento seleccionado actualmente*/ .topnav a.active { background-color: #2196F3; color: white; } /*Establecer el estilo del cuadro de búsqueda de la barra de navegación*/ .topnav input[type=text] { float: right; padding: 6px; border: none; margin-top: 8px; margin-right: 16px; font-size: 17px; } /*Cuando el ancho de la pantalla es menor que 600px, apilar verticalmente las opciones del menú y el cuadro de búsqueda.*/ @media screen and (max-width: 600px) { .topnav a, .topnav input[type=text] { float: none; display: block; text-align: left; width: 100%; margin: 0; padding: 14px; } .topnav input[type=text] { border: 1px solid #ccc; } }
