Agregar barra de desplazamiento a div

Categoría Tecnología de programación

Para agregar una barra de desplazamiento a div, solo necesita especificaroverflowel atributo comoautoy listo. El siguiente ejemplo establece una barra de desplazamiento horizontal para div:

Ejemplo

<div style="height:300px;width:70px;overflow:auto;background:#EEEEEE;">Tutorial de Ejemplo: lo que se aprende no es solo tecnología, ¡también es un sueño!!! El ancho (width) y la altura (height) se pueden establecer según las necesidades reales.

El ejemplo anterior indica que si la altura del contenido del div es mayor que 300px, aparecerá una barra de desplazamiento vertical; si es menor que 300px, no habrá barra de desplazamiento. Si el ancho es mayor que 70px, aparecerá una barra de desplazamiento horizontal; si es menor, no.

Si desea que la barra de desplazamiento en el div esté siempre presente, puede establecer la propiedad overflow en scroll:

También puede establecer overflow en scroll, es decir:

Ejemplo

<div style="height:300px;width:200px;overflow:scroll;background:#EEEEEE;">Tutorial de Ejemplo: lo que se aprende no es solo tecnología, ¡también es un sueño!!! Más configuraciones

Establecer solo la barra de desplazamiento horizontal:

<div style="width:100px;overflow-x:auto"></div>

Establecer solo la barra de desplazamiento vertical:

<div style="height:300px;overflow-y:auto"></div>

Establecer tanto horizontal como vertical:

<div style="width:70px;height:300px;overflow-x:auto;overflow-y:auto"></div>
