Atajos de teclado y consejos de uso comunes de Eclipse

Categoría Tecnología de programación

Los desarrolladores de Java suelen utilizar el entorno de desarrollo integrado Eclipse o MyEclipse. Algunos atajos de teclado y técnicas de uso prácticos de Eclipse pueden ahorrar mucho tiempo y mejorar la eficiencia en el desarrollo diario. A continuación, combinaré mi propia experiencia de desarrollo para compartir con ustedes los atajos y técnicas más utilizados en Eclipse.

15 atajos de teclado y consejos de uso comunes en el desarrollo con Eclipse

1、alt+?oalt+/: Autocompletar código o mostrar sugerencias de código

Esta es mi combinación de atajos favorita. Especialmente después de escribir algunos caracteres como 'syso', con dos dedos presionas fácilmente estas dos teclas y se autocompletaSystem.out.println();automáticamente. Además, Eclipse por defecto muestra.sugerencias de métodos. Si la sugerencia se interrumpe y quieres verla de nuevo, tienes que volver a escribir delante de la clase o variable correspondiente.para ver la sugerencia de nuevo. Sin embargo, si combinas estas dos teclas, también puede funcionar como sugerencia, puedes probarlo. Además, si escribes 'for' y hay variables locales que necesitan ser recorridas arriba, aparecerá una ventana para elegir entre usarfor eachrecorrer ofor(int;;)owhile()y luego generará automáticamente el código.

2、ctrl+o: Vista de esquema rápida

Si quieres ver los métodos de la clase actual o un método específico, pero no quieres desplazarte por el código ni usar la función de búsqueda, usactrl+o, especialmente cuando abres o sigues a una clase con muchos métodos, esto es muy útil. Puedes ver directamente los métodos y variables miembro. Puede enumerar todos los métodos y propiedades de la clase actual. Solo tienes que ingresar el nombre del método que deseas consultar y hacer clic enenterpara saltar directamente a la posición deseada.

3、ctrl+shift+r: Abrir lista de recursos

Este es posiblemente el atajo más ahorrador de tiempo de todos, y también lo uso con frecuencia. Especialmente para buscar un archivo directamente por nombre en el proyecto o espacio de trabajo. Este conjunto de atajos te permite abrir cualquier archivo en tu espacio de trabajo, solo necesitas escribir las primeras letras del nombre del archivo o del patrón (mask), como por ejemplo applic*.xml. El único inconveniente es que este conjunto de atajos no funciona en todas las vistas.

4、ctrl+shift+f: Formatear código

Por defecto, cambia de línea a los 80 caracteres, esto se puede configurar. También se puede reformatear el código según el estilo de código establecido. Nuestro equipo tiene un formato de código unificado y lo colocamos en nuestra wiki. Para hacer esto, abrimos Eclipse, seleccionamos Window Style, luego configuramos Code Formatter, Code Style y Organize Imports. Usamos la función Exportar (Export) para generar los archivos de configuración. Colocamos estos archivos de configuración en la wiki y luego cada miembro del equipo los importa en su propio Eclipse.

5、ctrl+e: Cambiar rápidamente de editor

Este conjunto de atajos te ayudará a navegar entre los editores abiertos, especialmente cuando hay muchos archivos abiertos.ctrl+eSerá más eficiente y muy útil.

6、ctrl+page downoctrl+page up: Cambio rápido entre pestañas

Puedes navegar entre las pestañas anterior y siguiente. Si lo usas con soltura, el cambio entre páginas será muy rápido y se sentirá muy bien.

7、shift+enteryctrl+shift+enter: Crear una línea en blanco encima o debajo de la línea actual.

Shift+enterCrea una línea en blanco debajo de la línea actual, independientemente de si el cursor está al final de la línea.Ctrl+shift+enterInserta una línea en blanco antes de la línea actual. Estos dos atajos también son muy útiles. Al principio puede que no te acostumbres, pero después de usarlos varias veces, te resultarán muy convenientes. En mi caso, así es.

8、Alt + Flechas arriba/abajo: Intercambiar contenido entre líneas o mover el contenido de la línea actual hacia arriba o hacia abajo.

Este también es un truco para ahorrar tiempo. Esta combinación mueve el contenido de la línea actual hacia arriba o hacia abajo. Entry/catchesta parte, este atajo es especialmente útil.

9、Control + Alt + flechas arriba/abajo: Copiar la línea o líneas resaltadas

Este también es un atajo muy útil. Permite copiar fácilmente el código actual a la línea anterior o siguiente. Yo también lo uso con frecuencia.

10、ctrl+m: Maximizar la ventana de la página de edición actual

Todos sabemos que una pantalla grande puede mejorar la eficiencia del trabajo.Ctrl+mEs el atajo para maximizar la ventana del editor. Al presionarlo de nuevo, vuelve a la ventana normal.

11、ctrl+/: Comentar automáticamente la línea actual o las líneas seleccionadas

Comenta automáticamente la línea actual o varias líneas de código. Usa//para comentar, y usactrl+\para descomentar.

12、ctrl+shift+/: Comentar automáticamente el bloque de código seleccionado

Ten en cuenta que esto se hace con/* */se comenta (si es código de lenguaje de programación), también es muy útil en el desarrollo. HTML, CSS, etc. también se pueden comentar con esto, generando las etiquetas de comentario correspondientes. Usactrl+shift+\para descomentar.

13、ctrl+d: Eliminar la línea actual

Elimina la línea actual. Esto es muy útil y también lo uso a menudo, especialmente al depurar, para eliminar el error actual. Combinado con el atajo de deshacer edición Ctrl+Z, se puede usar con soltura.

14、ctrl+shift+xyctrl+shift+y: Convertir letras a mayúsculas o minúsculas

Este atajo se usa comúnmente al escribir sentencias SQL. Yo también lo uso a menudo. Se recomienda escribir las palabras clave en las sentencias SQL en mayúsculas. Aunque las bases de datos no distinguen entre mayúsculas y minúsculas, esto facilita la lectura para otros y para uno mismo, especialmente cuando las sentencias SQL son muy largas, y además se ve más estandarizado.

15、ctrl+shift+o: Importar paquetes automáticamente y eliminar paquetes no utilizados

Este atajo también es muy conveniente. Cuando usamos una clase de otro paquete, si no hemos importado el paquete o la clase correspondiente, aparecerá una línea ondulada roja. En ese momento podemos presionar este atajo y la indicación roja desaparecerá automáticamente volviendo a la normalidad. Si hay varios paquetes que contienen la misma clase, te pedirá que elijas. Si hay paquetes no utilizados que han sido importados, lo cual suele ocurrir por copiar y pegar código repetidamente, también puedes usar esta tecla para eliminarlos rápidamente.

Adjunto algunos consejos útiles:

Bloquear la ventana de línea de comandos: En la vista de línea de comandos (Window -> Show View -> Other -> Basic -> Console), prueba a usar el botón de bloqueo de desplazamiento para bloquear la salida de la consola y evitar que se desplace.

Usar la vista Ant: En mi modo Java o Debug, me gusta mostrar la vista Ant para poder ejecutar rápidamente tareas Ant. Puedes encontrar esta vista a través de Window Ant. Coloca la vista Ant en una esquina de la pantalla y agrega el archivo build.xml mediante el botón "Agregar archivos de compilación (Add -> Other -> Show View -> Buildfiles)". En la versión 3.1, incluso se admite la depuración de scripts de lenguaje Ant.

Recorrer automáticamente una colección: for + Control-Space: Si aún no lo sabes, debes recordar que Control-Space es la función de autocompletar. En Eclipse, también puedes autocompletar estructuras. Dentro de un array o una colección, prueba a escribir 'for' y luego presiona la tecla Control-Space. Eclipse te preguntará qué colección quieres recorrer y luego completará automáticamente el código del bucle.

Usar la distribución jerárquica: En la vista de explorador de paquetes (Package Explorer view), la distribución predeterminada (plana) me confunde, porque muestra el nombre completo del paquete en el árbol de navegación (navigation tree). Prefiero la vista de paquetes y sistema de archivos de mi código fuente, que en Eclipse se llama distribución jerárquica (Hierarchical Layout). Para cambiar a este modo, haz clic en el botón hacia abajo en la vista de explorador de paquetes, selecciona Diseño (Layout) y luego Jerárquico (Hierarchial).

Mostrar varios archivos a la vez: Puedes ver varios archivos a la vez. Arrastra la ventana de edición inactiva hacia la barra de desplazamiento inferior o lateral de la ventana activa para abrir esa ventana de edición. Esta es la mejor manera que puedo describir este truco.

Abrir dos Eclipse al mismo tiempo: Para fusionar cambios de una rama CVS a otra, me gusta abrir dos Eclipse con espacios de trabajo (Workspace) diferentes al mismo tiempo. De esta manera puedo ver todos los cambios comparando con la última versión en CVS (clic derecho en el proyecto y seleccionar Compare Latest from HEAD) y luego fusionar cada cambio en la otra rama CVS. La forma más sencilla de iniciar múltiples Eclipse es usar Eclipse con Launcher.

Complemento ImplementorsInstala un plugin que pueda saltar a la implementación de una interfaz. Si eres fan de la inyección de dependencias o trabajas con interfaces bien diseñadas, necesitas un plugin así para acelerar la navegación por el código. Puedes encontrar este plugin en SourceForge.

Generar automáticamente métodos getter y setterEn el POJO correspondiente, haz clic derecho en un espacio en blanco, selecciona [Source], luego [Generate Getters and Setters], y elige para qué atributos quieres generar estos métodos. Haz clic en [Aceptar] y listo. Especialmente cuando hay muchas variables miembro, ahorra mucho tiempo.

Adjunto la lista completa de atajos de teclado de Eclipse:

  • Ctrl+1:Corrección rápida (el atajo más clásico, no hay mucho que decir)
  • Ctrl+D:Eliminar la línea actual
  • Ctrl+Alt+↓:Copiar la línea actual a la siguiente línea (copiar y añadir)
  • Ctrl+Alt+↑:Copiar la línea actual a la línea anterior (copiar y añadir)
  • Alt+↓:Intercambia la posición de la línea actual con la siguiente (muy práctico, evita tener que cortar y pegar)
  • Alt+↑:Intercambia la posición de la línea actual con la anterior (igual que arriba)
  • Alt+←:Página anterior editada
  • Alt+→:Siguiente página editada (obviamente, en relación con la anterior)
  • Alt+Enter:Muestra las propiedades del recurso seleccionado (proyecto, archivo o carpeta)
  • Shift+Enter:Insertar una línea en blanco debajo de la línea actual (el cursor puede estar en cualquier posición de la línea actual, no necesariamente al final)
  • Shift+Ctrl+Enter:Insertar una línea en blanco en la línea actual (mismo principio que la anterior)
  • Ctrl+Q:Ir a la última ubicación editada
  • Ctrl+L:Ir a una línea específica (una bendición para quienes tienen programas de más de 100 líneas)
  • Ctrl+M:Maximizar el editor o vista actual (pulsar de nuevo revierte el cambio)
  • Ctrl+/:Comenta la línea actual; pulsar de nuevo descomenta
  • Ctrl+O:Mostrar rápidamente el Outline
  • Ctrl+T:Mostrar rápidamente la jerarquía de herencia de la clase actual
  • Ctrl+W:Cerrar el editor actual
  • Ctrl+K:Basándose en la palabra seleccionada, localizar rápidamente la siguiente
  • Ctrl+E:Muestra rápidamente la lista desplegable del editor actual (los elementos no mostrados en la página actual aparecen en negrita)
  • Ctrl+/ (teclado numérico):Plegar todo el código de la clase actual
  • Ctrl+× (teclado numérico):Desplegar todo el código de la clase actual
  • Ctrl+Space:Asistente de código para completar la inserción de código (pero generalmente entra en conflicto con el método de entrada; se puede modificar el atajo del método de entrada o usar temporalmente Alt+/ en su lugar)
  • Ctrl+Shift+E:Muestra el administrador de todas las vistas abiertas actualmente (se puede cerrar, activar, etc.)
  • Ctrl+J:Búsqueda incremental hacia adelante (después de pulsar Ctrl+J, cada letra que escribes permite al editor localizar rápidamente una palabra; si no la encuentra, se muestra en la barra de estado que no se encontró. Muy útil al buscar una palabra; esta función ya existía en Idea hace dos años)
  • Ctrl+Shift+J:Búsqueda incremental hacia atrás (igual que la anterior, pero busca de atrás hacia adelante)
  • Ctrl+Shift+F4:Cerrar todos los editores abiertos
  • Ctrl+Shift+X:Convertir todo el texto seleccionado a minúsculas
  • Ctrl+Shift+Y:Convertir todo el texto seleccionado a minúsculas
  • Ctrl+Shift+F:Formatear el código actual
  • Ctrl+Shift+P:Localizar el delimitador correspondiente (por ejemplo, {}) (al localizar de adelante hacia atrás, el cursor debe estar dentro del delimitador; de atrás hacia adelante, al contrario)

Los siguientes atajos son los más utilizados en la refactorización; he organizado los que personalmente me gustan y uso con frecuencia (nota: generalmente los atajos de refactorización comienzan con Alt+Shift)

  • Alt+Shift+R:Renombrar (es uno de mis favoritos, especialmente el renombrado de variables y clases; ahorra mucho trabajo en comparación con el método manual)
  • Alt+Shift+M:Extraer método (es uno de los métodos más usados en la refactorización, especialmente útil para un montón de código enmarañado)
  • Alt+Shift+C:Cambiar la firma del método (muy práctico; si hay N funciones que llaman a este método, se resuelve de una vez)
  • Alt+Shift+L:Extraer variable local (puede extraer números mágicos y cadenas en una variable, especialmente cuando se usan en múltiples lugares)
  • Alt+Shift+F:Convertir una variable local de una clase en una variable de campo (función bastante práctica)
  • Alt+Shift+I:Fusionar variables (puede que decirlo así no sea muy apropiado, Inline)
  • Alt+Shift+V:Mover funciones y variables (no se usa mucho)
  • Alt+Shift+Z:Deshacer (la cura para el arrepentimiento de la refactorización)
