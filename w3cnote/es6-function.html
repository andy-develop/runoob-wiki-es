4.1 Funciones de ES6

Categoría Tutorial de ES6

Extensión de parámetros de función

Parámetros por defecto

Uso básico

function fn(name,age=17){ console.log(name+","+age); } fn("Amy",18); // Amy,18 fn("Amy",""); // Amy, fn("Amy"); // Amy,17

Nota: al usar parámetros por defecto en funciones, no se permiten parámetros con el mismo nombre.

//Sin errores function fn(name,name){ console.log(name); } //Error //SyntaxError: Duplicate parameter name not allowed in this context function fn(name,name,age=17){ console.log(name+","+age); }

Solo cuando no se pasa un argumento, o el argumento es undefined, se usa el parámetro por defecto; el valor null se considera un paso de valor válido.

function fn(name,age=17){ console.log(name+","+age); } fn("Amy",null); // Amy,null

Los valores por defecto de los parámetros de función tienen una zona muerta temporal; en la expresión del valor por defecto de un parámetro, los valores de parámetros que aún no han sido inicializados no pueden usarse como valores por defecto de otros parámetros.

function f(x,y=x){ console.log(x,y); } f(1); // 1 1 function f(x=y){ console.log(x); } f(); // ReferenceError: y is not defined

Parámetros rest

Los parámetros rest se usan para representar un número indeterminado de parámetros, con la forma ...nombreDeVariable, compuestos por ... más un identificador de parámetro con nombre. El parámetro con nombre solo puede colocarse al final del grupo de parámetros, y solo puede haber un único parámetro rest.

Uso básico

function f(...values){ console.log(values.length); } f(1,2); //2 f(1,2,3,4); //4

Funciones flecha

Las funciones flecha proporcionan una forma más concisa de escribir funciones. La sintaxis básica es:

parámetro => cuerpo de la función

Uso básico:

var f = v => v; //Equivale a var f = function(a){ return a; } f(1); //1

Cuando la función flecha no tiene parámetros o tiene varios parámetros, se deben usar()para encerrarlos.

var f = (a,b) => a+b; f(6,2); //8

Cuando el cuerpo de la función flecha tiene múltiples líneas de sentencias, se usan{}para envolverlo, representando un bloque de código. Cuando solo hay una línea de sentencia y se necesita devolver un resultado, se puede omitir{}y el resultado se devolverá automáticamente.

var f = (a,b) => { let result = a+b; return result; } f(6,2); // 8

Cuando la función flecha necesita devolver un objeto, para distinguirlo de un bloque de código, se deben usar()para envolver el objeto.

//Error var f = (id,name) => {id: id, name: name}; f(6,2); // SyntaxError: Unexpected token : //Sin errores var f = (id,name) => ({id: id, name: name}); f(6,2); // {id: 6, name: 2}

Nota: no hay enlaces de this, super, arguments ni new.target.

var func = () => { //Dentro de la función flecha no hay objeto this; //en este caso, this es el objeto this externo, es decir, Window. console.log(this) } func(55) // Window var func = () => { console.log(arguments) } func(55); // ReferenceError: arguments is not defined

El objeto this en el cuerpo de la función flecha es el objeto en el momento de definir la función, no el objeto en el momento de usar la función.

function fn(){ setTimeout(()=>{ //Al definir, this está vinculado al objeto this dentro de fn. console.log(this.a); },0) } var a = 20; //El objeto this de fn es {a: 18}. fn.call({a: 18}); // 18

No se puede usar como constructor, es decir, no se puede usar el comando new; de lo contrario, se producirá un error.

Escenarios adecuados para su uso

Antes de ES6, el objeto this de JavaScript siempre ha sido un dolor de cabeza. En las funciones de devolución de llamada, a menudo se veía código como var self = this, para pasar el this externo a la función de devolución de llamada. Con las funciones flecha, ya no es necesario hacer eso; se puede usar this directamente.

//Función de devolución de llamada var Person = { 'age': 18, 'sayHello': function () { setTimeout(function () { console.log(this.age); }); } }; var age = 20; Person.sayHello(); // 20 var Person1 = { 'age': 18, 'sayHello': function () { setTimeout(()=>{ console.log(this.age); }); } }; var age = 20; Person1.sayHello(); // 18

Por lo tanto, cuando necesitamos mantener un contexto this, podemos usar funciones flecha.

Escenarios no adecuados para su uso

Definir métodos de función, y que el método contenga this.

var Person = { 'age': 18, 'sayHello': ()=>{ console.log(this.age); } }; var age = 20; Person.sayHello(); // 20 //En este caso, this apunta al objeto global. var Person1 = { 'age': 18, 'sayHello': function () { console.log(this.age); } }; var age = 20; Person1.sayHello(); // 18 //En este caso, this apunta al objeto Person1.

Cuando se necesita this dinámico.

var button = document.getElementById('userClick'); button.addEventListener('click', () => { this.classList.toggle('on'); });

La función de escucha de button es una función flecha, por lo que this dentro de la función de escucha apunta al objeto this externo en el momento de la definición, es decir, Window, lo que impide operar sobre el objeto del botón que se hizo clic.
