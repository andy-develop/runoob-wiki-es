5.2 Funciones Generator de ES6

Clasificación Tutorial de ES6

ES6 introdujo las funciones Generator, que pueden suspender el flujo de ejecución de la función mediante la palabra clave yield, lo que brinda la posibilidad de cambiar el flujo de ejecución y, por lo tanto, proporciona una solución para la programación asíncrona. Uso básico

Composición de la función Generator

Generator tiene dos partes que la diferencian de las funciones normales:

  • Una es que después de function, antes del nombre de la función, hay un *;

  • Dentro de la función hay expresiones yield.

El * se usa para indicar que la función es una función Generator, y yield se usa para definir los estados internos de la función.

function* func(){ console.log("one"); yield '1'; console.log("two"); yield '2'; console.log("three"); return '3'; }

Mecanismo de ejecución

Llamar a una función Generator es igual que llamar a una función normal: basta con añadir () después del nombre de la función. Sin embargo, la función Generator no se ejecuta inmediatamente como una función normal, sino que devuelve un puntero que apunta al objeto de estado interno. Por lo tanto, al llamar al método next del objeto iterador Iterator, el puntero comenzará a ejecutarse desde el inicio de la función o desde el lugar donde se detuvo la última vez.

f.next(); // one // {value: "1", done: false} f.next(); // two // {value: "2", done: false} f.next(); // three // {value: "3", done: true} f.next(); // {value: undefined, done: true}

Al llamar al método next por primera vez, se comienza a ejecutar desde el inicio de la función Generator; primero imprime one, se detiene al llegar a yield, y toma el valor '1' de la expresión después de yield como valor de la propiedad value del objeto devuelto. En este momento, la función aún no ha terminado de ejecutarse, por lo que el valor de la propiedad done del objeto devuelto es false.

Al llamar al método next por segunda vez, igual que el paso anterior.

Al llamar al método next por tercera vez, primero imprime three, luego ejecuta la operación de retorno de la función, y toma el valor de la expresión después de return como valor de la propiedad value del objeto devuelto. En este momento, la función ya ha terminado, por lo que el valor de la propiedad done es true.

Al llamar al método next por cuarta vez, la función ya ha terminado de ejecutarse, por lo que devuelve el valor de la propiedad value como undefined y el valor de la propiedad done como true. Si en el tercer paso no hay una declaración return, se devuelve directamente {value: undefined, done: true}.

Métodos del objeto iterador devuelto por la función

Método next

En general, cuando el método next no recibe parámetros, el valor de retorno de la expresión yield es undefined. Cuando se pasan parámetros a next, ese parámetro se convierte en el valor de retorno del yield anterior.

function* sendParameter(){ console.log("start"); var x = yield '2'; console.log("one:" + x); var y = yield '3'; console.log("two:" + y); console.log("total:" + (x + y)); }

next sin pasar parámetros

var sendp1 = sendParameter(); sendp1.next(); // start // {value: "2", done: false} sendp1.next(); // one:undefined // {value: "3", done: false} sendp1.next(); // two:undefined // total:NaN // {value: undefined, done: true} nextPasar parámetrosvar sendp2 = sendParameter(); sendp2.next(10); // start // {value: "2", done: false} sendp2.next(20); // one:20 // {value: "3", done: false} sendp2.next(30); // two:30 // total:50 // {value: undefined, done: true}

Además de usar next, también se puede usar el bucle for... of para recorrer el objeto Iterator generado por la función Generator.

Método return

El método return devuelve el valor dado y finaliza la iteración de la función Generator.

Cuando el método return recibe un parámetro, devuelve ese parámetro; cuando no recibe parámetros, devuelve undefined.

function* foo(){ yield 1; yield 2; yield 3; } var f = foo(); f.next(); // {value: 1, done: false} f.return("foo"); // {value: "foo", done: true} f.next(); // {value: undefined, done: true} throwMétodothrowEl método puedeGeneratorlanzar una excepción fuera del cuerpo de la función y capturarla dentro del cuerpo de la función.var g = function* () { try { yield; } catch (e) { console.log('catch inner', e); } }; var i = g(); i.next(); try { i.throw('a'); i.throw('b'); } catch (e) { console.log('catch outside', e); } // catch inner a // catch outside b

El objeto iterador lanzó dos errores: el primero fue capturado dentro de la función Generator; el segundo, debido a que la función catch dentro del cuerpo de la función ya se había ejecutado, no volverá a capturar este error, por lo que este error se lanza fuera del cuerpo de la función Generator y es capturado por el catch externo al cuerpo de la función.

Expresión yield*

La expresión yield* indica que yield devuelve un objeto iterador, y se usa para llamar a otra función Generator dentro de una función Generator.

function* callee() { console.log('callee: ' + (yield)); } function* caller() { while (true) { yield* callee(); } } const callerObj = caller(); callerObj.next(); // {value: undefined, done: false} callerObj.next("a"); // callee: a // {value: undefined, done: false} callerObj.next("b"); // callee: b // {value: undefined, done: false} //Equivale a function* caller() { while (true) { for (var value of callee) { yield value; } } }

Casos de uso

Implementar Iterator

Proporcionar un método de iteración para objetos que no tienen la interfaz Iterator.

function* objectEntries(obj) { const propKeys = Reflect.ownKeys(obj); for (const propKey of propKeys) { yield [propKey, obj[propKey]]; } } const jane = { first: 'Jane', last: 'Doe' }; for (const [key,value] of objectEntries(jane)) { console.log(`${key}: ${value}`); } // first: Jane // last: Doe

Reflect.ownKeys() devuelve todas las propiedades del objeto, sin importar si son enumerables, incluidos los Symbol.

De forma nativa, jane no tiene la interfaz Iterator, por lo que no se puede recorrer con for... of. Aquí se usó una función Generator para añadir la interfaz Iterator, por lo que ahora se puede recorrer el objeto jane.
