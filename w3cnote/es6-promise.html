5.1 Objeto Promise de ES6

Categoría Tutorial de ES6

Resumen

Es una solución para la programación asíncrona.

Desde el punto de vista sintáctico, Promise es un objeto del cual se puede obtener la información de las operaciones asíncronas.

Estados de Promise

Características de los estados

Las operaciones asíncronas de Promise tienen tres estados: pending (en curso), fulfilled (exitoso) y rejected (fallido). Aparte del resultado de la operación asíncrona, ninguna otra operación puede cambiar este estado.

El objeto Promise solo tiene cambios de estado: de pending a fulfilled y de pending a rejected. Una vez que se encuentra en fulfilled o rejected, el estado no cambiará más, es decir, resolved (finalizado).

const p1 = new Promise(function(resolve,reject){ resolve('success1'); resolve('success2'); }); const p2 = new Promise(function(resolve,reject){ resolve('success3'); reject('reject'); }); p1.then(function(value){ console.log(value); // success1 }); p2.then(function(value){ console.log(value); // success3 });

Desventajas de los estados

No se puede cancelar Promise; una vez creado, se ejecuta inmediatamente y no se puede cancelar a mitad de camino.

Si no se establece una función de devolución de llamada (callback), los errores lanzados dentro de Promise no se reflejarán al exterior.

Cuando está en estado pending, no se puede saber en qué etapa se encuentra actualmente (si acaba de comenzar o está por completarse).

Método then

El método then recibe dos funciones como parámetros: el primer parámetro es la devolución de llamada cuando Promise se ejecuta con éxito, y el segundo parámetro es la devolución de llamada cuando Promise falla. Solo se llamará a una de las dos funciones.

Características del método then

La función de devolución de llamada nunca se llamará antes de que se complete la ejecución actual de la cola de eventos de JavaScript.

const p = new Promise(function(resolve,reject){ resolve('success'); }); p.then(function(value){ console.log(value); }); console.log('first'); // first // success

A través de.thenLas funciones de devolución de llamada agregadas de esta forma se invocarán en cualquier momento.

Mediante múltiples llamadas

.then
se pueden agregar múltiples funciones de devolución de llamada, que se ejecutarán en el orden de inserción y de forma independiente.

const p = new Promise(function(resolve,reject){ resolve(1); }).then(function(value){ //Primer then // 1 console.log(value); return value * 2; }).then(function(value){ //Segundo then // 2 console.log(value); }).then(function(value){ //Tercer then // undefined console.log(value); return Promise.resolve('resolve'); }).then(function(value){ //Cuarto then // resolve console.log(value); return Promise.reject('reject'); }).then(function(value){ //Quinto then //reject:reject console.log('resolve:' + value); }, function(err) { console.log('reject:' + err); });

El método then devolverá un objeto Promise en estado resolved o rejected para llamadas en cadena, y el valor del objeto Promise es este valor de retorno.

Notas sobre el método then

La programación simple de cadenas Promise debe mantenerse plana; no anidar Promise.

Asegúrate de devolver o terminar siempre la cadena de Promise.

const p1 = new Promise(function(resolve,reject){ resolve(1); }).then(function(result) {   p2(result).then(newResult => p3(newResult)); }).then(() => p4());

Al crear un nuevo Promise pero olvidar devolverlo, la cadena correspondiente se rompe, lo que hace que p4 se ejecute al mismo tiempo que p2 y p3.

En la mayoría de los navegadores, cuando hay una rejection en una cadena de Promise que no se puede terminar, se recomienda siempre continuar con.catch(error => console.log(error));
