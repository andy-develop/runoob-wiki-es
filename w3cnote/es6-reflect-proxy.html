isExtensible(target)

Se utiliza para interceptar la operación Object.isExtensible.

Este método solo puede devolver un valor booleano; de lo contrario, el valor de retorno se convertirá automáticamente a booleano.

Nota: su valor de retorno debe ser coherente con la propiedad isExtensible del objeto objetivo; de lo contrario, se lanzará un error.

ownKeys(target)

Se utiliza para interceptar operaciones de lectura de las propiedades propias del objeto. Incluye principalmente las siguientes operaciones:

- Object.getOwnPropertyNames()
- Object.getOwnPropertySymbols()
- Object.keys()

Si el objeto objetivo no es extensible, se deben devolver todas y solo las propiedades que contiene el objeto objetivo; no se pueden incluir propiedades inexistentes; de lo contrario, también se producirá un error.

Reflect

ES6 Mediova a Object deuna些明显Atributoqueque en el lenguajedentro部de los métodosmover植llegarya Reflect objetoarriba（actualmenteAlgunosMétodopuedeal mismo tiempoexisteque Object y Reflect objetoarriba），未venirdeNuevoMétodopuede只部署En Reflect objetoArriba. → En ES6, algunos métodos de Object que claramente pertenecen a la parte interna del lenguaje se trasladaron al objeto Reflect (actualmente algunos métodos existen tanto en Object como en Reflect), y los nuevos métodos futuros se implementarán solo en el objeto Reflect.

El objeto Reflect ha modificado los resultados de retorno de algunos métodos para hacerlos más razonables.

El objeto Reflect implementa las operaciones imperativas de Object mediante funciones.

Métodos estáticos

Reflect.get(exam, 'birth'); // undefined //Cuando target no es un objeto, se producirá un error. Reflect.get(1, 'name'); // TypeError
Reflect.set(target, name, value, receiver)

Establece la propiedad name de target como value. El valor de retorno es boolean; true indica que la modificación fue exitosa, false indica fallo. Cuando target es un objeto inexistente, se producirá un error.

Reflect.apply(func, thisArg, args)

Equivalente a Function.prototype.apply.call(func, thisArg, args). func representa la función objetivo; thisArg representa el objeto this al que está vinculada la función objetivo; args representa la lista de parámetros pasados al llamar a la función objetivo, que puede ser un array o un objeto similar a un array. Uso combinado

Los métodos del objeto Reflect se corresponden uno a uno con los métodos del objeto Proxy. Por lo tanto, los métodos del objeto Proxy pueden obtener el comportamiento predeterminado llamando a los métodos del objeto Reflect y luego realizar operaciones adicionales.

let exam = { name: "Tom", age: 24 } let handler = { get: function(target, key){ console.log("getting "+key); return Reflect.get(target,key); }, set: function(target, key, value){ console.log("setting "+key+" to "+value) Reflect.set(target, key, value); } } let proxy = new Proxy(exam, handler) proxy.name = "Jerry" proxy.name // setting name to Jerry // getting name // "Jerry"
