3.2.1 Cadenas ES6

Clasificación Tutorial de ES6

Métodos extendidos

Detección de subcadenas

Antes de ES6, para determinar si una cadena contiene una subcadena, se usaba el método indexOf. ES6 agregó nuevos métodos para el reconocimiento de subcadenas.

  • includes(): Devuelve un valor booleano, determina si se encuentra la cadena del parámetro.
  • startsWith(): Devuelve un valor booleano, determina si la cadena del parámetro está al inicio de la cadena original.
  • endsWith(): Devuelve un valor booleano, determina si la cadena del parámetro está al final de la cadena original.

Los tres métodos anteriores pueden aceptar dos parámetros: la cadena a buscar y un índice opcional de posición inicial de búsqueda.

let string = "apple,banana,orange"; string.includes("banana"); // true string.startsWith("apple"); // true string.endsWith("apple"); // false string.startsWith("banana",6) // true

Nota:

  • Estos tres métodos solo devuelven valores booleanos. Si necesita conocer la posición de la subcadena, aún debe usar indexOf y lastIndexOf.
  • Si estos tres métodos reciben una expresión regular en lugar de una cadena, lanzarán un error. En cambio, los métodos indexOf y lastIndexOf convierten la expresión regular en una cadena y la buscan.

Repetición de cadenas

repeat(): Devuelve una nueva cadena que repite la cadena original un número especificado de veces.

console.log("Hello,".repeat(2));  // "Hello,Hello,"

Si el parámetro es un número decimal, se redondea hacia abajo.

console.log("Hello,".repeat(3.2));  // "Hello,Hello,Hello,"

Si el parámetro es un decimal entre 0 y -1, se realiza un redondeo; los decimales entre 0 y -1 se redondean a -0, lo que equivale a repetir cero veces.

console.log("Hello,".repeat(-0.5));  // ""

Si el parámetro es NaN, equivale a repetir cero veces.

console.log("Hello,".repeat(NaN));  // ""

Si el parámetro es un número negativo o Infinity, se producirá un error:

console.log("Hello,".repeat(-1));  
// RangeError: Invalid count value

console.log("Hello,".repeat(Infinity));  
// RangeError: Invalid count value

Si el parámetro pasado es una cadena, primero se convierte la cadena en un número.

console.log("Hello,".repeat("hh")); // ""
console.log("Hello,".repeat("2"));  // "Hello,Hello,"

Relleno de cadenas

  • padStart: Devuelve una nueva cadena, que indica que se rellena la cadena original desde el inicio (lado izquierdo) con la cadena del parámetro.
  • padEnd: Devuelve una nueva cadena, que indica que se rellena la cadena original desde el final (lado derecho) con la cadena del parámetro.

Los dos métodos anteriores aceptan dos parámetros: el primero especifica la longitud mínima de la cadena resultante, y el segundo es la cadena utilizada para rellenar. Si no se especifica el segundo parámetro, se rellena con espacios por defecto.

console.log("h".padStart(5,"o"));  // "ooooh"
console.log("h".padEnd(5,"o"));    // "hoooo"
console.log("h".padStart(5));      // "    h"

Si la longitud especificada es menor o igual a la longitud de la cadena original, se devuelve la cadena original:

console.log("hello".padStart(5,"A"));  // "hello"

Si la longitud de la cadena original más la cadena de relleno es mayor que la longitud especificada, se recorta la parte sobrante de la cadena de relleno:

console.log("hello".padEnd(10,",world!"));  // "hello,worl"

Comúnmente se usa para rellenar dígitos:

console.log("123".padStart(10,"0"));  // "0000000123"

Plantillas de cadena

Las plantillas de cadena son una versión mejorada de las cadenas, y usan comillas invertidas (`)`Además de usarse como cadenas ordinarias, también se pueden usar para definir cadenas multilínea, e insertar variables y expresiones en la cadena.

Uso básico

Cadena ordinaria

let string = `Hello'\n'world`; console.log(string); // "Hello' // 'world"

Cadena multilínea:

let string1 = `Hey, can you stop angry now?`; console.log(string1); // Hey, // can you stop angry now?

Inserción de variables y expresiones en la cadena.

El nombre de la variable se escribe dentro de ${}, y dentro de ${} se puede colocar una expresión de JavaScript.

let name = "Mike"; let age = 27; let info = `My Name is ${name},I am ${age+1} years old next year.` console.log(info); // My Name is Mike,I am 28 years old next year.

Llamar a funciones dentro de la cadena:

function f(){ return "have fun!"; } let string2= `Game start,${f()}`; console.log(string2); // Game start,have fun!

Puntos a tener en cuenta

Los saltos de línea y los espacios en las plantillas de cadena se conservan.

innerHtml = `<ul> <li>menu</li> <li>mine</li> </ul> `; console.log(innerHtml); //Salida <ul> <li>menu</li> <li>mine</li> </ul>

Plantillas etiquetadas

Una plantilla etiquetada es una llamada a una función, donde el parámetro de la llamada es la plantilla de cadena.

alert`Hello world!`; //Equivalente a alert('Hello world!');

Cuando la plantilla de cadena contiene variables, los parámetros de la plantilla se procesan en múltiples parámetros.

function f(stringArr,...values){ let result = ""; for(let i=0;i<stringArr.length;i++){ result += stringArr[i]; if(values[i]){ result += values[i]; } } return result; } let name = 'Mike'; let age = 27; f`My Name is ${name},I am ${age+1} years old next year.`; // "My Name is Mike,I am 28 years old next year." f`My Name is ${name},I am ${age+1} years old next year.`; //Equivalente a f(['My Name is',',I am ',' years old next year.'],'Mike',28);

Aplicaciones

Filtrar cadenas HTML para evitar que los usuarios ingresen contenido malicioso.

function f(stringArr,...values){ let result = ""; for(let i=0;i<stringArr.length;i++){ result += stringArr[i]; if(values[i]){ result += String(values[i]).replace(/&/g, "&amp;") .replace(/</g, "&lt;") .replace(/>/g, "&gt;"); } } return result; } name = '<Amy&MIke>'; f`<p>Hi, ${name}.I would like send you some message.</p>`; // <p>Hi, &lt;Amy&amp;MIke&gt;.I would like send you some message.</p>

Procesamiento de internacionalización (traducción a varios idiomas)

i18n`Hello ${name}, you are visitor number ${visitorNumber}.`; //Hola **, eres el visitante número **
