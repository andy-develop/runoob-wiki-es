Nombre del proyecto: dbgate -- herramienta de gestión de bases de datos gratuita, de código abierto y multiplataforma

Dirección de código abierto de Github: https://github.com/dbgate/dbgate

Dirección del sitio web oficial: https://dbgate.org/

Dirección de descarga: https://dbgate.org/download/

dbgate es un administrador de bases de datos como MySQL, PostgreSQL, SQL Server, MongoDB, SQLite, etc.

dbgate admite ejecutarse en los sistemas operativos Windows, Linux y Mac, lo que brinda a los usuarios flexibilidad multiplataforma.

dbgate no es solo una aplicación local, también puede ejecutarse como una aplicación web, lo que permite a los usuarios acceder y administrar bases de datos fácilmente a través del navegador.

Admite las siguientes bases de datos:

  • MySQL
  • PostgreSQL
  • SQL Server
  • Oracle (experimental)
  • MongoDB
  • Redis
  • SQLite
  • Amazon Redshift
  • CockroachDB
  • MariaDB

Características de dbgate:

  • Edición de datos de tablas, con vista previa de scripts de cambios SQL:Admite la edición de datos de tablas y proporciona una función de vista previa de los scripts de cambios SQL.

  • Editar esquema de tablas, índices, claves primarias y claves externas:Permite a los usuarios editar la estructura de las tablas, los índices y definir claves primarias y externas.

  • Comparar y sincronizar la estructura de la base de datos:Proporciona la función de comparar y sincronizar estructuras de bases de datos, lo que garantiza la consistencia de la estructura de la base de datos.

  • Diagrama ER:Proporciona diagramas de entidad-relación (ER) para visualizar las relaciones entre las tablas de la base de datos.

  • Tema claro y oscuro:Ofrece temas claro y oscuro para satisfacer las necesidades de personalización de los usuarios.

  • Vista maestro/detalle, búsqueda de claves externas:Admite la vista maestro/detalle, así como la función de búsqueda de claves externas.

  • Diseñador de consultas:Proporciona un diseñador de consultas que permite a los usuarios diseñar consultas fácilmente.

  • Vista de formulario:Para tablas con muchas columnas, proporciona una vista de formulario para facilitar su manejo.

  • Vista JSON de colecciones MongoDB:Admite la vista JSON de colecciones MongoDB.

  • Explorar tablas, vistas, procedimientos almacenados, funciones, colecciones MongoDB:Proporciona la función de exploración de varios objetos de la base de datos.

  • Editor SQL:Incluye un editor SQL que admite la ejecución de scripts SQL.

  • Formateo de código SQL, autocompletado de código:Proporciona funciones de formateo de código SQL y autocompletado de código.

  • Utilidad para añadir combinaciones SQL LEFT/INNER/RIGHT:Admite la utilidad para agregar combinaciones izquierdas (LEFT), internas (INNER) y derechas (RIGHT) de SQL.

  • Editor Mongo JavaScript:Incluye un editor Mongo JavaScript que admite la ejecución de scripts Mongo (utilizando sintaxis de NodeJs).

  • Vista de árbol de Redis, generar scripts desde claves, ejecutar scripts de Redis:Proporciona una vista de árbol de Redis, capaz de generar scripts desde claves y ejecutar scripts de Redis.

  • Aplicación que se ejecuta en Windows, Linux y Mac, o como contenedor Docker en un servidor; los clientes pueden ejecutarse en un navegador web:Es multiplataforma; los usuarios pueden elegir ejecutarlo en diferentes entornos, incluidas aplicaciones locales, contenedores Docker en servidores y navegadores web.

  • Importar, exportar CSV, Excel, JSON, NDJSON, XML:Admite la importación y exportación de datos en varios formatos.

  • Editor de tablas gratuito:Proporciona un editor de tablas gratuito para editar rápidamente los datos de las tablas, por ejemplo, para limpiar datos o crear prototipos de tablas después de la importación/exportación.

  • Archivo:Admite la copia de seguridad de datos en archivos NDJSON en el sistema de archivos local (o en el servidor DbGate cuando se usa la aplicación web).

  • Gráficos, exportar gráficos como páginas HTML:Admite la creación de gráficos y puede exportarlos como páginas HTML.

  • Para obtener información detallada sobre la ejecución de DbGate en contenedores Docker, visite Docker Hub:Proporciona información detallada sobre la ejecución de DbGate en contenedores Docker.

  • Arquitectura de plugins extensible:Tiene una arquitectura de plugins extensible que permite a los usuarios agregar nuevas funciones según sea necesario.

  • Vista de perspectiva:Proporciona una vista de perspectiva para la visualización de tablas anidadas en datos relacionales complejos y el diseño de consultas en bases de datos MongoDB.
