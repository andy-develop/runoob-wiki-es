Nombre del proyecto: excalidraw -- Pizarra virtual para dibujar a mano alzada

Dirección de código abierto en Github: https://github.com/excalidraw/excalidraw

Dirección de prueba en línea: https://excalidraw.com/

excalidraw es una pizarra virtual gratuita y de código abierto que ofrece una herramienta de pizarra colaborativa en tiempo real en línea, que permite a los usuarios crear gráficos y diagramas simples.

El objetivo de diseño de excalidraw es proporcionar una herramienta de dibujo fácil de usar que admita la colaboración en equipo, además de ser multiplataforma y tener funciones de colaboración en tiempo real.

  • Fácil de usar:excalidraw ofrece una interfaz simple e intuitiva; los usuarios pueden dibujar fácilmente varios gráficos en la pizarra, incluidas formas básicas, líneas y texto.

  • Colaboración en tiempo real:El proyecto admite colaboración en tiempo real; varios usuarios pueden trabajar simultáneamente en la misma pizarra, y los cambios de cada usuario se reflejan al instante en las pantallas de todos los colaboradores, lo que hace que la colaboración en equipo sea más conveniente.

  • Exportar y compartir:Los usuarios pueden exportar los gráficos que crean como archivos de imagen, y la pizarra se puede compartir con otras personas mediante un enlace.

  • Multiplataforma:excalidraw es una aplicación web que puede ejecutarse en diferentes sistemas operativos y dispositivos; solo necesita un navegador web moderno para usarla.

  • Código abierto:excalidraw es gratuito y de código abierto, alojado en GitHub; cualquiera puede ver, usar, modificar y contribuir al código.

  • Soporte de localización (i18n): admite varios idiomas.

  • Estilo dibujado a mano: el estilo de dibujo de excalidraw es de trazos hechos a mano.

  • Biblioteca de elementos y elementos personalizados: excalidraw proporciona algunos elementos gráficos comunes, como rectángulos, círculos, flechas, etc. Los usuarios pueden seleccionarlos desde la biblioteca de elementos y arrastrarlos al lienzo; también pueden personalizar la apariencia y el estilo de los elementos.

Instalación

git clone https://github.com/excalidraw/excalidraw.git

Luego acceda al directorio de excalidraw:

cd excalidraw

Ejecute los siguientes comandos:

yarn
