Nombre del proyecto: screenshot-to-code -- Convierte capturas de pantalla en código HTML

Dirección de código abierto de Github: https://github.com/abi/screenshot-to-code

Dirección de prueba en línea: https://screenshottocode.com/

La aplicación screenshot-to-code puede convertir capturas de pantalla en código (HTML/Tailwind CSS, React, Bootstrap o Vue).

Utiliza GPT-4 Vision para generar código y DALL-E 3 para generar imágenes similares, por lo que es necesario configurar OPENAI_API_KEY.

También puedes clonar un sitio web en línea ingresando la URL del sitio.

La aplicación usa React/Vite en el frontend y FastAPI de Python en el backend. Además, se necesita una clave de API de OpenAI.

Comenzar

Cargar código:

git clone https://github.com/abi/screenshot-to-code.git

Configuración del backend (aquí se usa Poetry para la gestión de paquetes):

pip install poetry # 安装 poetry
cd backend    # 进入后端目录
echo "OPENAI_API_KEY=sk-****" > .env # 设置 OPENAI_API_KEY，需要去官网获取
poetry install
poetry shell
poetry run uvicorn main:app --reload --port 7001

También puedes usar el siguiente comando para ejecutarlo directamente en el backend:

poetry run pyright

Configuración del frontend:

cd frontend   # 进入前端目录
yarn
yarn dev

Luego abre la página web http://localhost:5173 en el navegador para acceder a la aplicación.
