Herramientas de plataforma (todas son excelentes herramientas de código abierto)

  • Redmine/Trac: plataforma de gestión de proyectos
  • Jenkins/Jira (no es de código abierto): sistema de integración continua (Apache Continuum, este es un sistema de CI bajo Apache, aún no he tenido tiempo de investigarlo)
  • Sonar: plataforma de gestión de calidad de código
  • Git, SVN: sistemas de control de versiones de código fuente
  • GitLib/Gitorious: construye tu propio servidor GitHub
  • gitbook：https://www.gitbook.io/Excelente herramienta para escribir libros, por supuesto también es muy buena para escribir documentación
  • Travis CI: esencial para la integración continua de proyectos de código abierto, se combina con GitHubhttps://travis-ci.org/
  • Herramientas y comunidades de pruebas de código abierto (Selenium, OpenQA.org)
  • Puppet: un motor de gestión automática, aplicable a plataformas Linux, Unix y Windows. El llamado sistema de gestión de configuraciones gestiona recursos como archivos, usuarios, procesos, paquetes de software en las máquinas. Ya sea gestionando una o decenas de miles de máquinas, Puppet puede manejarlo fácilmente.
  • Nagios: monitoreo y alertas de estado del sistema. También está Icinga (totalmente compatible con todos los plugins de Nagios, principios de funcionamiento, archivos de configuración y métodos, casi idénticos. Configuración simple, potente)
  • Ganglia: sistema de monitoreo distribuido
  • Fleet: sistema init distribuido

Herramientas de rendimiento/pruebas de esfuerzo para servidores web / equilibradores de carga

  • http_load: el programa es muy pequeño, no llega ni a 100K después de descomprimir
  • webbench: es una herramienta de pruebas de esfuerzo para sitios web en Linux, puede simular hasta 30,000 conexiones concurrentes para probar la capacidad de carga del sitio
  • ab: ab es una potente herramienta de pruebas que viene con Apache
  • Siege: una herramienta de pruebas de esfuerzo de código abierto que puede realizar accesos concurrentes de múltiples usuarios a un sitio web según la configuración, registra el tiempo de respuesta de todos los procesos de solicitud de cada usuario y se repite bajo un cierto número de accesos concurrentes
  • Squid (caché de front-end), Nginx (balanceo de carga), Node.js (sí, también puede, con un poco de código se puede implementar un equilibrador de carga de alto rendimiento): equilibradores de carga de uso común
  • Piwik: sistema de estadísticas de visitas a sitios web de código abierto
  • ClickHeat: mapa de calor de clics en sitios web de código abierto
  • HAProxy: equilibrador de carga de alto rendimiento TCP/HTTP
  • ElasticSearch: motor de búsqueda basado en Lucene
  • Page Speed SDK y YSlow
  • HAR Viewer: herramienta de análisis HAR
  • Protractor: herramienta de pruebas automatizadas E2E (de extremo a extremo)

Procesamiento de big data / análisis de datos / herramientas distribuidas

  • Hadoop: sistema de archivos distribuido; junto con su modelo de programación MapReduce se puede usar para el procesamiento por lotes de datos masivos (Hive, Pig, HBase, etc., ya no los menciono). Cabe destacar la rama de Hadoop de Cloudera, CDH5, que basada en YARN MRv2 integra Spark y es un Hadoop directamente utilizable en entornos de producción; es muy útil para que las empresas construyan rápidamente data warehouses.

  • Ceph: sistema de archivos distribuido para Linux (característica: sin centro).

  • Storm: procesamiento de datos en flujo (streaming) en tiempo real; se puede ver una introducción de IBM (también está S4 de Yahoo, que también hace procesamiento de datos en streaming).

  • Spark: procesamiento de datos en streaming a gran escala (puede manejar los tres escenarios comunes de procesamiento de datos en las empresas: procesamiento complejo de datos por lotes (batch data processing); consultas interactivas basadas en datos históricos (interactive query); procesamiento de datos basado en flujos de datos en tiempo real (streaming data processing)). Hay un artículo bastante bueno en CSND al respecto.

  • Spark Streaming: framework de computación en tiempo real basado en Spark.

  • Tachyon: sistema de archivos distribuido en memoria.

  • Mesos: un administrador de clústeres para frameworks de computación; proporciona aislamiento y compartición eficiente de recursos entre aplicaciones o frameworks distribuidos. Impala: motor de análisis de big data de código abierto de nueva generación, proporciona semántica SQL, más rápido que Hive.

  • SNAPPY: sistema rápido de compresión de datos, adecuado para el ecosistema Hadoop.

  • Kafka: sistema de cola de mensajes distribuido de alto rendimiento (throughput).

  • ActiveMQ: producido por Apache, el bus de mensajes de código abierto más popular y potente.

  • MQTT: Message Queuing Telemetry Transport (transporte de telemetría de colas de mensajes) es un protocolo de mensajería instantánea desarrollado por IBM, que podría convertirse en un componente importante del Internet de las Cosas (IoT).

  • RabbitMQ: recuerdo que OpenStack usaba esto.

  • ZeroMQ: se dice que hace la computación distribuida más simple; es una cola de mensajes distribuida. Se puede ver un artículo de Yunfeng. Sistemas de recolección de logs de código abierto: scribe, chukwa, kafka, flume. Hay un artículo comparativo.

  • Zookeeper: proyecto de código abierto de coordinación distribuida confiable.

  • Databus: sistema de captura de datos en tiempo real y baja latencia de LinkedIn.

Obtención de fuentes de datos: Flume, Google Refine, Needlebase, ScraperWiki, BloomReach.

Aprendizaje automático: WEKA, Mahout, scikits.learn, SkyTree.

Técnicas de visualización: GraphViz, Processing, Protovis, Google Fusion Tables, Tableau, Highcharts, EChats (el de Baidu es bastante bueno), Raphaël.js.

Herramientas de uso común

  • Fiddler: herramienta de depuración de front-end web muy útil, por supuesto orientada al protocolo HTTP subyacente; en general, las herramientas de depuración integradas de Chrome y otros son suficientes, pero en casos especiales hay que recurrir a ella.
  • Wireshark: conocida herramienta de análisis de paquetes de red.
  • PowerCmd: excelente herramienta para reemplazar el Cmd de Windows.
  • RegexBuddy: potente herramienta de prueba de expresiones regulares.
  • Source Insight: herramienta imprescindible para leer código fuente.
  • Sublime Text: el editor favorito de los programadores.
  • Database.NET: un cliente universal de bases de datos relacionales, desarrollado sobre .NET 4.0, bastante práctico para tareas sencillas.
  • Navicat Premium: cliente que admite MySQL, PostgreSQL, Oracle, SQLite y SQL Server; en universalidad no supera a Database.NET, pero su rendimiento es mucho mejor, y trae función de copia de seguridad que se usa también para la copia de seguridad programada de bases de datos.
  • Synergy: un solo teclado y ratón para controlar varios equipos en la red de área local.
  • DameWare: conjunto de herramientas de asistencia remota (en la empresa la uso principalmente para controlar la pantalla grande).
  • Radmin: herramienta de control remoto, la he usado durante un tiempo.

  • Listary: una «herramienta súper mágica» que mejora enormemente la velocidad y eficiencia de navegación y búsqueda de archivos en Windows.

  • WinLaunch: simula la herramienta Launch de Mac OS.
  • Fritzing: dibujo de esquemas de circuitos.
  • LICEcap: creación de tutoriales GIF.
  • SVN: sistema de control de versiones. Enigma Virtual Box (empaqueta exe, dll, etc. en un único programa ejecutable).
  • Open DBDiff: sincronización de bases de datos (para SQL Server).

  • BIEE, Informatica, SPSS, Weka, R: análisis de datos.
  • CodeSmith, LightSwitch: generación de código.
  • Pandoc: herramienta de conversión de Markdown, utilizada para publicar libros. Antes jugaba con DocBook, pero ahora lo que manda es Markdown.
  • Window Magnet [Mac]: mejora la gestión de ventanas de Mac, con la función de arrastrar ventanas al borde de la pantalla para ajustarlas automáticamente, como Win7.
  • Log Explorer: ver los registros de SQL Server.

  • ngrok: herramienta de penetración en la red interna. Axure: herramienta de creación rápida de prototipos; también hay una herramienta de dibujo en línea creada por un equipo emprendedor nacional que funciona muy bien.http://www.processon.com
