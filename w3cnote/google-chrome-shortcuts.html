Atajos de teclado del navegador Chrome

Categorías Programación

Actualmente, el navegador Chrome es utilizado por la mayoría de los programadores front-end para desarrollar y depurar. A continuación se enumeran los atajos de teclado del navegador Chrome.

Chrome para Windows y Linux

Atajos de teclado para pestañas y ventanas

Acción Atajo de teclado
Abrir una ventana nueva Ctrl + n
Abrir una nueva ventana en modo incógnito Ctrl + Shift + n
Abrir una pestaña nueva y saltar a esa pestaña Ctrl + t
Volver a abrir la última pestaña cerrada y saltar a esa pestaña Ctrl + Shift + t
Saltar a la siguiente pestaña abierta Ctrl + Tab o Ctrl + PgDn
Saltar a la pestaña abierta anterior Ctrl + Shift + Tab o Ctrl + PgUp
Saltar a una pestaña específica Ctrl + 1 a Ctrl + 8
Saltar a la última pestaña Ctrl + 9
Abrir la página de inicio en la pestaña actual Alt + Home
Cerrar la pestaña actual Ctrl + w o Ctrl + F4
Cerrar todas las pestañas abiertas y el navegador Ctrl + Shift + w
Minimizar la ventana actual Alt + Barra espaciadora + n
Maximizar la ventana actual Alt + Barra espaciadora + x
Salir de Google Chrome Ctrl + Shift + q o Alt + F4

Atajos de teclado de funciones de Chrome

Acción Atajo de teclado
Abrir el menú Alt + f, Alt + e o F10
Mostrar u ocultar la barra de marcadores Ctrl + Shift + b
Abrir el administrador de marcadores Ctrl + Shift + o
Abrir la página de historial en una pestaña nueva Ctrl + h
Abrir la página de descargas en una pestaña nueva Ctrl + j
Abrir el administrador de tareas de Chrome Shift + Esc
Colocar el foco en el primer elemento de la barra de herramientas de Chrome Shift + Alt + t
Desplazar el foco hacia adelante entre la barra de direcciones, la barra de marcadores (si está visible) y el contenido de la página F6
Desplazar el foco hacia atrás entre la barra de direcciones, la barra de marcadores (si está visible) y el contenido de la página Shift + F6
Abrir la barra de búsqueda para buscar en la página web actual Ctrl + f o F3
Saltar a la siguiente coincidencia con el término de búsqueda en la barra de búsqueda Ctrl + g
Saltar a la coincidencia anterior con el término de búsqueda en la barra de búsqueda Ctrl + Shift + g
Abrir las herramientas para desarrolladores Ctrl + Shift + j o F12
Abrir la opción 'Borrar datos de navegación' Ctrl + Shift + Delete
Abrir el Centro de ayuda de Chrome en una pestaña nueva F1
Iniciar sesión con otra cuenta o entrar en modo incógnito Ctrl + Shift + m
Abrir el formulario de comentarios Ctrl + Shift + i

Atajos de teclado de la barra de direcciones

Acción Atajo de teclado
Buscar con el motor de búsqueda predeterminado Escriba el término de búsqueda y presione la tecla Enter
Buscar con otro motor de búsqueda Escriba el nombre del motor de búsqueda y presione la tecla Tab
Agregue www. y .com al nombre del sitio web y ábralo en la pestaña actual Escriba el nombre del sitio web y presione Ctrl + Enter
Agregue www. y .com al nombre del sitio web y ábralo en una pestaña nueva Escriba el nombre del sitio web y presione Alt + Enter
Saltar a la barra de direcciones Ctrl + l, Alt + d o F6
Buscar desde cualquier lugar de la página Ctrl + k o Ctrl + e

Acción Atajo de teclado
Abrir las opciones para imprimir la página web actual Ctrl + p
Abrir las opciones para guardar la página web actual Ctrl + s
Volver a cargar la página web actual F5 o Ctrl + r

Detener la carga de la página web Esc

Recorrer el elemento anterior en el que se puede hacer clic Shift + Tab

Guardar la página web actual como marcador Ctrl + d
Guardar todas las pestañas abiertas como marcadores en una carpeta nueva Ctrl + Shift + d
Activar o desactivar el modo de pantalla completa F11

Reducir todo el contenido de la página web Ctrl y -

Desplazarse hacia abajo en la página web, una pantalla a la vez Barra espaciadora o PgDn
Desplazarse hacia arriba en la página web, una pantalla a la vez Shift + Barra espaciadora o PgUp
Ir al principio de la página web Inicio
Ir al final de la página web Fin

Eliminar la palabra anterior en un campo de texto Ctrl + Backspace
Mover el foco a la notificación Alt + n
Permitir en la notificación Alt + Shift + a
Rechazar en la notificación Alt + Shift + d
Abrir la página de inicio en la pestaña actual Alt + Home

Atajos de teclado para páginas web

Acción Atajo de teclado
Abrir un enlace en la pestaña actual (solo con el mouse) Arrastrar el enlace a una pestaña

Mostrar el historial de navegación Haga clic con el botón derecho en la flecha 'Atrás' o 'Adelante', o haga clic y mantenga presionada la flecha 'Atrás' o 'Adelante'
Maximizar o minimizar la ventana Haga doble clic en un área vacía de la barra de pestañas

Reducir todo el contenido de la página web Mantenga presionada la tecla Ctrl mientras desplaza la rueda del mouse hacia abajo
