Tras ocho años, el estándar HTML5 finalmente está terminado

Categoría Noticias de tecnología

El Consorcio World Wide Web (W3C) anunció hoy entre lágrimas que, después de casi ocho años de arduo trabajo, la especificación del estándar HTML5 finalmente se ha completado y se ha publicado oficialmente.

En los años anteriores, muchos desarrolladores ya habían utilizado algunas tecnologías de HTML5; Firefox, Google Chrome, Opera, Safari 4+, Internet Explorer 9+ ya son compatibles con HTML5, pero no fue hasta hoy que vimos la "versión oficial".

HTML5 reemplazará los estándares HTML 4.01 y XHTML 1.0 establecidos en 1999, con el fin de que, en un momento en que las aplicaciones de Internet se desarrollan rápidamente, los estándares web cumplan con las necesidades contemporáneas de la red, proporcionando contenido rico y una integración perfecta para plataformas de escritorio y móviles.

El Dr. Jeff Jaffe, CEO de W3C, declaró: "HTML5 impulsará la Web hacia una nueva era. Hace no mucho tiempo, la Web era solo para ver documentos básicos en línea, pero hoy la Web es una plataforma enormemente rica. Hemos entrado en una etapa estable en la que todos pueden actuar según los estándares, y estos pueden usarse en todos los navegadores. Si no trabajamos juntos, no habrá una Web unificada."

Se espera que HTML5 se convierta también en la piedra angular de la soñada "Plataforma Web Abierta" (Open Web Platform), que, si se logra, podría impulsar aún más aplicaciones web multiplataforma más profundas.

A continuación, el W3C se dedicará a desarrollar especificaciones estándar para comunicaciones en tiempo real, pagos electrónicos, desarrollo de aplicaciones, entre otros, y también creará una serie de medidas de privacidad y protección de seguridad.

El W3C también reveló en 2012 que planeaba publicar HTML 5.1 antes de finales de 2016.
