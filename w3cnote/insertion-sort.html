1.3 Ordenamiento por inserción

Categoría Algoritmo

El ordenamiento por inserción (Insertion Sort) es un algoritmo de ordenamiento simple e intuitivo; su principio de funcionamiento es similar a ordenar cartas de póquer.

El ordenamiento por inserción construye una secuencia ordenada; para los datos no ordenados, escanea la secuencia ya ordenada de atrás hacia adelante, encuentra la posición correspondiente e inserta.

Aunque la implementación del ordenamiento por inserción no es tan simple y directa como la del ordenamiento de burbuja o la del ordenamiento por selección, su principio es probablemente el más fácil de entender, porque cualquiera que haya jugado a las cartas lo entiende al instante.

Al igual que el ordenamiento de burbuja, el ordenamiento por inserción también tiene un algoritmo optimizado llamado inserción binaria.

1. Pasos del algoritmo

  1. Inicialización: Divide la lista en una parte ordenada y una parte no ordenada. Inicialmente, la parte ordenada contiene solo el primer elemento, y la parte no ordenada contiene los elementos restantes.

  2. Seleccionar elemento: Toma el primer elemento de la parte no ordenada.

  3. Insertar en la parte ordenada: Compara este elemento con los elementos de la parte ordenada de atrás hacia adelante, encuentra la posición adecuada e inserta.

  4. Repetir los pasos: Repite los pasos anteriores hasta que la parte no ordenada esté vacía y la lista quede completamente ordenada.

2. Demostración animada

Supongamos que hay una lista por ordenar [5, 2, 4, 6, 1, 3]; el proceso del ordenamiento por inserción es el siguiente:

  1. Estado inicial：

    • Parte ordenada:[5]。

    • Parte no ordenada:[2, 4, 6, 1, 3]。

  2. Primera ronda：

    • Toma el primer elemento de la parte no ordenada2。

    • va a2con el de la parte ordenada5compáralo,2 < 5, insértalo5delante.

    • La lista se convierte en[2, 5, 4, 6, 1, 3]。

    • Parte ordenada:[2, 5], parte no ordenada:[4, 6, 1, 3]。

  3. Segunda ronda：

    • Toma el primer elemento de la parte no ordenada4。

    • va a4con el de la parte ordenada5compáralo,4 < 5, continúa comparando con2compáralo,4 > 2, insértalo2y5entre.

    • La lista se convierte en[2, 4, 5, 6, 1, 3]。

    • Parte ordenada:[2, 4, 5], parte no ordenada:[6, 1, 3]。

  4. Tercera ronda：

    • Toma el primer elemento de la parte no ordenada6。

    • va a6con el de la parte ordenada5compáralo,6 > 5, insértalo directamente al final.

    • La lista se convierte en[2, 4, 5, 6, 1, 3]。

    • Parte ordenada:[2, 4, 5, 6], parte no ordenada:[1, 3]。

  5. Cuarta ronda：

    • Toma el primer elemento de la parte no ordenada1。

    • va a1con el de la parte ordenada6compáralo,1 < 6, continúa comparando con5、4、2compáralo,1es el más pequeño, insértalo al principio.

    • La lista se convierte en[1, 2, 4, 5, 6, 3]。

    • Parte ordenada:[1, 2, 4, 5, 6], parte no ordenada:[3]。

  6. Quinta ronda：

    • Toma el primer elemento de la parte no ordenada3。

    • va a3con el de la parte ordenada6compáralo,3 < 6, continúa comparando con5、4、2compáralo,3 > 2, insértalo2y4entre.

    • La lista se convierte en[1, 2, 3, 4, 5, 6]。

    • Parte ordenada:[1, 2, 3, 4, 5, 6], la parte no ordenada está vacía.

Ejemplo

def insertion_sort(arr):
    n = len(arr)
    for i in range(1, n):
        key = arr[i]  # Toma el primer elemento de la parte no ordenada
        j = i - 1
        # Inserta key en la posición correcta de la parte ordenada
        while j >= 0 and key < arr[j]:
            arr[j + 1] = arr[j]  # Mueve los elementos hacia atrás
            j -= 1
        arr[j + 1] = key  # Inserta key
    return arr

# Ejemplo
arr = [5, 2, 4, 6, 1, 3]
sorted_arr = insertion_sort(arr)
print(sorted_arr)  # Salida: [1, 2, 3, 4, 5, 6]

Complejidad temporal

  • Peor caso: O(n²); cuando la lista está en orden inverso, cada inserción requiere mover todos los elementos ya ordenados.

  • Mejor caso: O(n); cuando la lista ya está ordenada, solo necesita recorrerla una vez.

  • Caso promedio：O(n²)。

Complejidad espacial

  • O(1); el ordenamiento por inserción es un algoritmo de ordenamiento in-place y no necesita espacio de almacenamiento adicional.

Ventajas y desventajas

  • Ventajas：

    • Implementación sencilla y código fácil de entender.

    • Alta eficiencia para datos a pequeña escala o datos casi ordenados.

    • Ordenamiento in-place, sin necesidad de espacio de almacenamiento adicional.

    • Algoritmo de ordenamiento estable (el orden relativo de los elementos iguales no cambia).

  • Desventajas：

    • La complejidad temporal es alta, no es adecuado para conjuntos de datos a gran escala.

Escenarios aplicables

  • Escenarios con una cantidad de datos pequeña o datos casi ordenados.

  • Escenarios que requieren un algoritmo de ordenamiento estable.

  • Como algoritmo auxiliar para algoritmos de ordenamiento más complejos (por ejemplo, ordenamiento rápido o quicksort y ordenamiento por fusión o merge sort).

Implementación del código

JavaScript

Ejemplo

function insertionSort(arr) {
    var len = arr.length;
    var preIndex, current;
    for (var i = 1; i < len; i++) {
        preIndex = i - 1;
        current = arr[i];
        while(preIndex >= 0 && arr[preIndex] > current) {
            arr[preIndex+1] = arr[preIndex];
            preIndex--;
        }
        arr[preIndex+1] = current;
    }
    return arr;
}

Java

Ejemplo

public class InsertSort implements IArraySort {

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        // Hace una copia de arr, no modifica el contenido del parámetro
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        // Se comienza desde el elemento con índice 1 para insertarlo en la posición adecuada, porque hay un solo elemento en el índice 0 y por defecto está ordenado
        for (int i = 1; i < arr.length; i++) {

            // Registra el dato a insertar
            int tmp = arr[i];

            // Compara desde el extremo derecho de la secuencia ya ordenada, encuentra un número menor que él
            int j = i;
            while (j > 0 && tmp < arr[j - 1]) {
                arr[j] = arr[j - 1];
                j--;
            }

            // Si hay un número menor, inserta
            if (j != i) {
                arr[j] = tmp;
            }

        }
        return arr;
    }
}

Ejemplo

public static void InsertSort(int[] array)
{
    for(int i = 1;i < array.length;i++)
    {
        int temp = array[i];
        for(int j = i - 1;j >= 0;j--)
        {
            if(array[j] > temp)
            {
                array[j + 1] = array[j];
                array[j] = temp;
            }
            else
                break;
        }
    }
}
