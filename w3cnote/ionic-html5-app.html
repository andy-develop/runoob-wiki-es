Publicado el tutorial de Ionic: desarrollo de aplicaciones nativas con HTML5

Categorías Tecnología de programación

Ionic es un potente framework de desarrollo de aplicaciones HTML5 (HTML5 Hybrid Mobile App Framework). Puede ayudarle a utilizar tecnologías web como HTML, CSS y Javascript para construir aplicaciones móviles con una experiencia casi nativa. A continuación se muestra un ejemplo de prueba de Ejemplo utilizando el framework Ionic.
