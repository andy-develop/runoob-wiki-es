Grupos de captura en expresiones regulares de Java (capture group)

Categoría Tecnología de programación

Los grupos de captura se dividen en:

  • Grupo de captura normal (Expression)
  • Grupo de captura con nombre (?Expression)

Grupo de captura normal

Comenzando desde el lado izquierdo de la expresión regular, cada aparición de un paréntesis izquierdo "(" se cuenta como un grupo, la numeración de grupos comienza desde 1. 0 representa toda la expresión.

Para la cadena de tiempo: 2017-04-25, la expresión es la siguiente

(\\d{4})-((\\d{2})-(\\d{2}))

Hay 4 paréntesis izquierdos, por lo tanto hay 4 grupos:

Número Grupo de captura Coincidencia
0 (\d{4})-((\d{2})-(\d{2})) 2017-04-25
1 (\d{4}) 2017
2 ((\d{2})-(\d{2})) 04-25
3 (\d{2}) 04
4 (\d{2}) 25
public static final String DATE_STRING = "2017-04-25"; public static final String P_COMM = "(\\d{4})-((\\d{2})-(\\d{2}))"; Pattern pattern = Pattern.compile(P_COMM); Matcher matcher = pattern.matcher(DATE_STRING); matcher.find();//Debe tener esta oración System.out.printf("\nmatcher.group(0) value:%s", matcher.group(0)); System.out.printf("\nmatcher.group(1) value:%s", matcher.group(1)); System.out.printf("\nmatcher.group(2) value:%s", matcher.group(2)); System.out.printf("\nmatcher.group(3) value:%s", matcher.group(3)); System.out.printf("\nmatcher.group(4) value:%s", matcher.group(4));

Grupo de captura con nombre

Cada grupo de captura que comienza con un paréntesis izquierdo, va seguido inmediatamente de?, y después viene la expresión regular.

Para la cadena de tiempo: 2017-04-25, la expresión es la siguiente:

(?<year>\\d{4})-(?<md>(?<month>\\d{2})-(?<date>\\d{2}))

Hay 4 grupos de captura con nombre, que son:

Número Nombre Grupo de captura Coincidencia
0 0 (?\d{4})-(?(?\d{2})-(?\d{2})) 2017-04-25
1 year (?\d{4})- 2017
2 md (?(?\d{2})-(?\d{2})) 04-25
3 month (?\d{2}) 04
4 date (?\d{2}) 25

Los grupos de captura con nombre también pueden usar el número para obtener el valor correspondiente.

public static final String P_NAMED = "(?<year>\\d{4})-(?<md>(?<month>\\d{2})-(?<date>\\d{2}))"; public static final String DATE_STRING = "2017-04-25"; Pattern pattern = Pattern.compile(P_NAMED); Matcher matcher = pattern.matcher(DATE_STRING); matcher.find(); System.out.printf("\n===========Obtener usando el nombre============="); System.out.printf("\nmatcher.group(0) value:%s", matcher.group(0)); System.out.printf("\n matcher.group('year') value:%s", matcher.group("year")); System.out.printf("\nmatcher.group('md') value:%s", matcher.group("md")); System.out.printf("\nmatcher.group('month') value:%s", matcher.group("month")); System.out.printf("\nmatcher.group('date') value:%s", matcher.group("date")); matcher.reset(); System.out.printf("\n===========Obtener usando el número============="); matcher.find(); System.out.printf("\nmatcher.group(0) value:%s", matcher.group(0)); System.out.printf("\nmatcher.group(1) value:%s", matcher.group(1)); System.out.printf("\nmatcher.group(2) value:%s", matcher.group(2)); System.out.printf("\nmatcher.group(3) value:%s", matcher.group(3)); System.out.printf("\nmatcher.group(4) value:%s", matcher.group(4));

PS: Grupo de no captura

Inmediatamente después del paréntesis izquierdo?:, y luego se añade la expresión regular, formando un grupo de no captura.(?:Expression)。

Para la cadena de tiempo: 2017-04-25, la expresión es la siguiente:

(?:\\d{4})-((\\d{2})-(\\d{2}))

Aunque esta expresión regular tiene cuatro paréntesis izquierdos, en teoría tiene 4 grupos de captura. Pero el primer grupo(?:\d{4}), en realidad es ignorado. Cuando se usa matcher.group(4), el sistema reportará un error.

Número Grupo de captura Coincidencia
0 (\d{4})-((\d{2})-(\d{2})) 2017-04-25
1 ((\d{2})-(\d{2})) 04-25
2 (\d{2}) 04
3 (\d{2}) 25
public static final String P_UNCAP = "(?:\\d{4})-((\\d{2})-(\\d{2}))"; public static final String DATE_STRING = "2017-04-25"; Pattern pattern = Pattern.compile(P_UNCAP); Matcher matcher = pattern.matcher(DATE_STRING); matcher.find(); System.out.printf("\nmatcher.group(0) value:%s", matcher.group(0)); System.out.printf("\nmatcher.group(1) value:%s", matcher.group(1)); System.out.printf("\nmatcher.group(2) value:%s", matcher.group(2)); System.out.printf("\nmatcher.group(3) value:%s", matcher.group(3)); // Exception in thread "main" java.lang.IndexOutOfBoundsException: No group 4 System.out.printf("\nmatcher.group(4) value:%s", matcher.group(4));

Resumen

  • El grupo de captura normal es conveniente de usar;
  • El grupo de captura con nombre es claro de usar;
  • El grupo de no captura actualmente no tiene utilidad en los proyectos.
