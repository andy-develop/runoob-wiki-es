JAVA imprimir triángulo

Categoría Tecnología de programación

Primero, determinemos nuestro resultado de salida:

Entonces, ¿cómo podemos lograr esto?

1. Primero, analicemos la estructura de la figura.

Podemos ver que la figura tiene 5 líneas en total. Entonces, ¿podemos crear una declaración de bucle for para controlarla en 5 líneas? La respuesta es sí.

for(int i = 1 ;i <= 5 ;i++ ){

}

Así, creamos un bloque de código de bucle for que se repite 5 veces, siendo el bucle más externo.

2. Luego, analicemos cómo está compuesta la figura. Podemos dividir la figura en las siguientes partes: /p>

Podemos dividir la figura en estos tres triángulos.

3. Crear el triángulo en blanco número 1.

Se puede ver que la primera línea genera 4 espacios, la segunda genera 3 espacios, la tercera genera 2, la cuarta genera 1 y la quinta no genera ninguno.

De esta regla se puede ver que es una regla de decremento sucesivo. Entonces, ¿cómo implementarlo?

Podemos imaginar que de 1 a 5 hay cuatro números en el medio; de 2 a 5 hay 3 números, de 3 a 5...

¿Podemos usar este principio? Por supuesto que sí. Entonces, ¿cómo implementarlo? Mira el código:

for(int i = 1;i<=5 ;i++) {
    for(int j = 5; j >= i ; j--)//建立1号图形
        System.out.print(" ");
    System.out.println();
}

La primera declaración for es la declaración de bucle de cinco repeticiones que acabamos de definir.

El segundo bucle for, vamos a analizarlo:

Primero, define una variable j de tipo int y asigna a j el valor 5.

Luego pensamos, ya que queremos acortar la distancia, entonces en cada bucle j se reduce en 1, lo que justamente cumple con nuestro requisito:

En el primer bucle grande, i=1, j=5, por lo que cumple la condición j>=i y luego genera un espacio, luego j-1, ahora el valor de j es 4, cumple j>=i, y vuelve a generar.

……

Hasta que j=0, j>=i no se cumple, sale del bucle interno.

Ahora llega a System.out.println(); salto de línea.

Ahora regresa al bucle externo, i++, i se convierte en 2, cumple i<=5, entra al bucle interno.

Define j=5, j>=i, cumple, genera un espacio, j-1.

j ahora es 4, j>=i, cumple, genera un espacio, j-1.

……

Hasta que j=1, j>=i no se cumple, sale del bucle interno, luego salto de línea.

Luego i+1, y luego entra nuevamente al bucle interno...

Continuando así el bucle, se forma un triángulo invertido de cuatro líneas, y se forma el patrón número 1.

4. Crear el patrón número 2: el principio es exactamente el mismo que el patrón número 1, pero justo al revés.

for(int i = 1 ;i<=5 ;i++){
    for(int j = 5; j >= i ; j--)//建立1号图形
        System.out.print(" ");
    for(int j = 1; j <= i; j++)//建立2号图形
        System.out.print("*");
    System.out.println();
}

Igual que al crear el patrón número 1, todos pueden entenderlo por sí mismos; así se crea el número 2.

5. Crear el patrón número 3.

for(int i = 1; i <= 5; i++){
    for(int j = 5 ;i <= j; j--)//建立1号图形
        System.out.print(" ");
    for(int j = 1; j <= i; j++)//建立2号图形
        System.out.print("*");
    for(int j = 1; j < i; j ++)//建立3号图形
        System.out.print("*");

}

De igual manera, igual que el número 1 y el número 2, el principio para crear el patrón número 3 es el mismo.

Pero presten atención a un punto: el patrón número 3 no se genera en la primera línea, por lo que hay que cortarlo en el primer bucle grande y hacer que se genere en el segundo bucle grande.

Por lo tanto, esta vez la condición de juicio es j < i, se eliminó la igualdad.

Código fuente completo:

class Demo{ public static void main(String[] args){ for(int i=1;i<=5;i++){ for(int j=5; i<=j; j--) System.out.print(" "); for(int j=1; j<=i; j++) System.out.print("*"); for(int j=1; j<i; j++) System.out.print("*"); System.out.println(); } } }
