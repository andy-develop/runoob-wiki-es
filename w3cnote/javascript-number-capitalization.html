javascript para convertir números arábigos a mayúsculas

Categoría Técnicas de programación

Preparación antes de escribir

A continuación se presentan los puntos de conocimiento clave necesarios para escribir este método:

1. charAt(index): Devuelve el carácter en la posición especificada.

2. substr(start, length): Devuelve una cadena de una longitud especificada que comienza desde una posición especificada.

Parámetros:

  • start:Obligatorio, la posición inicial de la subcadena a extraer;

  • length:Opcional, el número de caracteres que contiene la cadena devuelta; cuando length <= 0, indica que se devuelve una cadena vacía; cuando no se especifica length, la subcadena extraída continúa desde start hasta el final de la cadena.

3. substring(start, end): Devuelve la subcadena especificada.

Parámetros:

  • start:Indica la posición inicial de la subcadena; el índice comienza desde 0;

  • end:Indica la posición final de la subcadena; el índice comienza desde 0.

Casos especiales:

Si solo contiene un parámetro, por defecto se establece como posición inicial y devuelve los caracteres desde ese parámetro hasta el final de la cadena;

Entre start y end, el menor se toma como inicio y el mayor como fin; por ejemplo, a.substring(1, 5) y a.substring(5, 1) devuelven la misma cadena;

Si start o end es NaN o un número negativo, se establece en 0.

Código específico

function ToString(n) {

    if (!/^(0|[1-9]\d*)(\.\d+)?$/.test(n)){
        return "数据非法";  //判断数据是否大于0
    }

    var unit = "千百拾亿千百拾万千百拾元角分", str = "";
    n += "00";  

    var indexpoint = n.indexOf('.');  // 如果是小数，截取小数点前面的位数

    if (indexpoint >= 0){

        n = n.substring(0, indexpoint) + n.substr(indexpoint+1, 2);   // 若为小数，截取需要使用的unit单位
    }

    unit = unit.substr(unit.length - n.length);  // 若为整数，截取需要使用的unit单位
    for (var i=0; i < n.length; i++){
        str += "零壹贰叁肆伍陆柒捌玖".charAt(n.charAt(i)) + unit.charAt(i);  //遍历转化为大写的数字
    }

    return str.replace(/零(千|百|拾|角)/g, "零").replace(/(零)+/g, "零").replace(/零(万|亿|元)/g, "$1").replace(/(亿)万|壹(拾)/g, "$1$2").replace(/^元零?|零分/g, "").replace(/元$/g, "元整"); // 替换掉数字里面的零字符，得到结果

}
