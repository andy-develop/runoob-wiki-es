jQuery Detectar acceso móvil

Categoría Tecnología de programación

Al usar jQuery para determinar si se accede desde un dispositivo móvil, se puede hacer la detección mediante el ancho de la ventana o la cadena de agente de usuario (User Agent String).

A continuación se presentan dos métodos:

Método 1: Detectar el ancho de la ventana

Ejemplo

$(document).ready(function() {
    // Obtener el ancho de la ventana
    var windowWidth = $(window).width();

    // Establecer un umbral, por ejemplo 768px, ajustar según sea necesario
    var mobileThreshold = 768;

    // Determinar si es un dispositivo móvil
    if (windowWidth < mobileThreshold) {
        // Código que se ejecuta en un dispositivo móvil
        console.log("Acceso móvil");
    } else {
        // Código que se ejecuta en un dispositivo no móvil
        console.log("Acceso no móvil");
    }
});

Método 2: Detectar la cadena de agente de usuario

Ejemplo

$(document).ready(function() {
    // Obtener la cadena de agente de usuario
    var userAgent = navigator.userAgent;

    // Comprobar si contiene palabras clave de dispositivos móviles, como "Android", "iPhone", "iPad", etc.
    if (/Android|webOS|iPhone|iPad|iPod|BlackBerry|IEMobile|Opera Mini/i.test(userAgent)) {
        // Código que se ejecuta en un dispositivo móvil
        console.log("Acceso móvil");
    } else {
        // Código que se ejecuta en un dispositivo no móvil
        console.log("Acceso no móvil");
    }
});

El método a elegir depende de sus necesidades específicas y los requisitos del proyecto.

Tenga en cuenta que la detección de la cadena de agente de usuario no es 100% confiable, ya que la cadena de agente de usuario puede ser modificada. Por lo tanto, elija el método adecuado según la situación específica.
