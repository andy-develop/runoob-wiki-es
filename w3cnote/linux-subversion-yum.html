Instalación del servidor SVN en Linux (método yum)

Categoría Tecnología de programación

1. Verificar si yum está instalado

En la terminal, escribe yum. Si ya está instalado, se mostrarán los parámetros de yum; si no está instalado, se indicará que yum no está instalado o que el comando no es válido...

2. Instalar SVN

yum -y install subversion

Una vez que aparece la siguiente captura de pantalla, la instalación está completa.

3. Crear directorio y configurar

Crear el directorio del repositorio

mkdir -p /data/svn/repo

Configuración/p>

svnadmin create  /data/svn/repo

Después de ejecutar el comando anterior, se crea automáticamente el repositorio de prueba repo. Al revisar la carpeta /data/svn/repo se encuentra que contiene archivos como conf, db, format, hooks, locks, README.txt, etc., lo que indica que se ha creado un repositorio SVN.

4. Configuración de contraseña de usuario passwd

[root@localhost password]# cd /data/svn/repos/conf
[root@admin conf]# vim passwd

Modifica passwd con el siguiente contenido:

[users]
# harry = harryssecret
# sally = sallyssecret
hello=123

Nombre de usuario=contraseña

Así creamos el usuario hello, con contraseña 123.

Las declaraciones anteriores deben escribirse desde el principio de la línea, sin dejar espacios a la izquierda, de lo contrario se producirán errores.

5. Configuración de authz para control de permisos

[root@admin conf]# vi  authz

El propósito es establecer qué usuarios pueden acceder a qué directorios. Añade el siguiente contenido al archivo authz:

#设置[/]代表根目录下所有的资源   或者写成[repl:/]
[/]
hello = rw

Significa que el usuario hello tiene permisos de lectura y escritura en todos los directorios del repositorio de prueba repo. Por supuesto, también se puede limitar. Si es para uso personal, simplemente déjalo en lectura y escritura.

Las declaraciones anteriores deben escribirse desde el principio de la línea, sin dejar espacios a la izquierda, de lo contrario se producirán errores.

6. Configuración del servicio svnserve.conf

[root@admin conf]# vim svnserve.conf

Añade el siguiente contenido:

[general]
#匿名访问的权限，可以是read,write,none,默认为read
anon-access=none
#使授权用户有写权限 
auth-access=write
#密码数据库的路径 
password-db=passwd
#访问控制文件 
authz-db=authz
#认证命名空间，subversion会在认证提示里显示，并且作为凭证缓存的关键字 
realm=/data/svn/repositories

Las declaraciones anteriores deben escribirse desde el principio de la línea, sin dejar espacios a la izquierda, de lo contrario se producirán errores.

7. Iniciar el servicio SVN

Verificar si el servicio SVN está iniciado

ps -ef|grep svn

Si no está iniciado, ejecuta el siguiente comando:

svnserve -d -r /data/svn/repo  --listen-port=3690

8. Abrir el puerto

 /sbin/iptables -I INPUT -p tcp --dport 3690 -j ACCEPT
 /etc/rc.d/init.d/iptables save
 /etc/init.d/iptables restart
 /etc/init.d/iptables status

9. Acceso

svn://dirección IP

El puerto predeterminado es 3690; solo ingresa el nombre de usuario y la contraseña configurados.

Nota: Aquí no debes usar svn://dirección IP/repo, de lo contrario no se podrá acceder.
