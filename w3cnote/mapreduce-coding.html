7.0 Programación MapReduce

Categoría Tutorial de Hadoop

Después de aprender a usar MapReduce, ya podemos manejar tareas de conteo y búsqueda como Word Count, pero objetivamente MapReduce puede hacer muchas más cosas.

MapReduce se basa principalmente en que los desarrolladores implementan funciones mediante programación; pueden procesar datos implementando métodos relacionados con Map y Reduce.

Para mostrar este proceso de manera sencilla, escribiremos manualmente un programa Word Count.

Nota:MapReduce depende de las bibliotecas de Hadoop, pero como el entorno de ejecución de Hadoop utilizado en este tutorial es un contenedor Docker, es difícil implementar un entorno de desarrollo, por lo que el trabajo de desarrollo real (incluida la depuración) requerirá una computadora con Hadoop. Aquí solo aprenderemos la implementación de programas ya completados.

Código del archivo MyWordCount.java

/**
* Declaración de referencias
* Este programa está referenciado desde http://hadoop.apache.org/docs/r1.0.4/cn/mapred_tutorial.html
 */
package com.ejemplo.hadoop;
import java.io.IOException;
import java.util.*;
import org.apache.hadoop.fs.Path;
import org.apache.hadoop.io.*;
import org.apache.hadoop.mapred.*;
/**
* Métodos relacionados con `Map`
 */
class Map extends MapReduceBase implements Mapper<LongWritable, Text, Text, IntWritable> {
   private final static IntWritable one = new IntWritable(1);
   private Text word = new Text();
   public void map(LongWritable key,
               Text value,
               OutputCollector<Text, IntWritable> output,
               Reporter reporter)
         throws IOException {
      String line = value.toString();
      StringTokenizer tokenizer = new StringTokenizer(line);
      while (tokenizer.hasMoreTokens()) {
         word.set(tokenizer.nextToken());
         output.collect(word, one);
      }
   }
}
/**
* Métodos relacionados con `Reduce`
 */
class Reduce extends MapReduceBase implements Reducer<Text, IntWritable, Text, IntWritable> {
   public void reduce(Text key,
                  Iterator<IntWritable> values,
                  OutputCollector<Text, IntWritable> output,
                  Reporter reporter)
         throws IOException {
      int sum = 0;
      while (values.hasNext()) {
         sum += values.next().get();
      }
      output.collect(key, new IntWritable(sum));
   }
}
public class MyWordCount {
   public static void main(String[] args) throws Exception {
      JobConf conf = new JobConf(MyWordCount.class);
      conf.setJobName("my_word_count");
      conf.setOutputKeyClass(Text.class);
      conf.setOutputValueClass(IntWritable.class);
      conf.setMapperClass(Map.class);
      conf.setCombinerClass(Reduce.class);
      conf.setReducerClass(Reduce.class);
      conf.setInputFormat(TextInputFormat.class);
      conf.setOutputFormat(TextOutputFormat.class);
      // El primer parámetro representa la entrada
      FileInputFormat.setInputPaths(conf, new Path(args[0]));
      // El segundo parámetro de entrada representa la salida
      FileOutputFormat.setOutputPath(conf, new Path(args[1]));
      JobClient.runJob(conf);
   }
}

Guarde el contenido de este archivo Java en el contenedor NameNode. Ubicación sugerida:

/home/hadoop/MyWordCount/com/ejemplo/hadoop/MyWordCount.java

Nota:Según la situación actual, algunos JDK instalados en entornos Docker no admiten chino, así que por seguridad, elimine los comentarios en chino del código anterior.

Entre al directorio:

cd /home/hadoop/MyWordCount

Compile:

javac -classpath ${HADOOP_HOME}/share/hadoop/mapreduce/hadoop-mapreduce-client-core-3.1.4.jar -classpath ${HADOOP_HOME}/share/hadoop/client/hadoop-client-api-3.1.4.jar com/ejemplo/hadoop/MyWordCount.java

Empaquete:

jar -cf my-word-count.jar com

Ejecute:

hadoop jar my-word-count.jar com.ejemplo.hadoop.MyWordCount /wordcount/input /wordcount/output2

Vea el resultado:

hadoop fs -cat /wordcount/output2/part-00000
