Sección meta

1. Ancho de la ventana gráfica

<meta name="viewport" content="width=device-width,initial-scale=1.0,minimum-scale=1.0,maximum-scale=1.0,user-scalable=no"/>

Dondewidth=device-widthestablece el ancho de la ventana gráfica al ancho de la ventana del dispositivo, también se puede fijar un ancho, por ejemplo:width=640es un ancho de 640px (común en WeChat);

initial-scale=1.0: establece la escala al 1.0;

minimum-scale=1.0ymaximum-scale=1.0: escala mínima y escala máxima;

user-scalable=no: prohíbe al usuario hacer zoom libremente,user-scalableel valor predeterminado esyes 。

Consejo: lo anterior incluye todos los parámetros, los más usados comúnmente, conuser-scalable=nono es necesario usarminimum-scale=1.0ymaximum-scale=1.0para forzar la prohibición de zoom.

<meta name="viewport" content="width=device-width,initial-scale=1.0,user-scalable=no"/>

2. Formato de reconocimiento automático

<meta name="format-detection" content="telephone=no"/>

contentLos parámetros dentro:telephone=noprohíbe al navegador reconocer automáticamente números de teléfono,email=noprohíbe al navegador reconocer automáticamente el correo electrónico.

3. Plantilla completa

<meta name="viewport" content="width=device-width,initial-scale=1.0,user-scalable=no"/>
<meta name="format-detection" content="telephone=no"/>
<meta name="format-detection" content="email=no"/>

Sección básica de Flex

Aquí se supone que el contenedor flex es.box, el elemento hijo es.item 。

1. Definir el contenedor como diseño flex

.box{
    display: -webkit-flex; /*webkit*/
    display: flex;
}

/*行内flex*/
.box{
    display: -webkit-inline-flex; /*webkit*/
    display:inline-flex;
}

2. Estilos del contenedor

.box{
    flex-direction: row | row-reverse | column | column-reverse;
    /*主轴方向：左到右（默认） | 右到左 | 上到下 | 下到上*/

    flex-wrap: nowrap | wrap | wrap-reverse;
    /*换行：不换行（默认） | 换行 | 换行并第一行在下方*/

    flex-flow: <flex-direction> || <flex-wrap>;
    /*主轴方向和换行简写*/

    justify-content: flex-start | flex-end | center | space-between | space-around;
    /*主轴对齐方式：左对齐（默认） | 右对齐 | 居中对齐 | 两端对齐 | 平均分布*/

    align-items: flex-start | flex-end | center | baseline | stretch;
    /*交叉轴对齐方式：顶部对齐（默认） | 底部对齐 | 居中对齐 | 上下对齐并铺满 | 文本基线对齐*/

    align-content: flex-start | flex-end | center | space-between | space-around | stretch;
    /*多主轴对齐：顶部对齐（默认） | 底部对齐 | 居中对齐 | 上下对齐并铺满 | 上下平均分布*/
}

3. Estilos de los elementos hijos

.item{
    order: <integer>;
    /*排序：数值越小，越排前，默认为0*/

    flex-grow: <number>; /* default 0 */
    /*放大：默认0（即如果有剩余空间也不放大，值为1则放大，2是1的双倍大小，以此类推）*/

    flex-shrink: <number>; /* default 1 */
    /*缩小：默认1（如果空间不足则会缩小，值为0不缩小）*/

    flex-basis: <length> | auto; /* default auto */
    /*固定大小：默认为0，可以设置px值，也可以设置百分比大小*/

    flex: none | [ <'flex-grow'> <'flex-shrink'>? || <'flex-basis'> ]
    /*flex-grow, flex-shrink 和 flex-basis的简写，默认值为0 1 auto，*/

    align-self: auto | flex-start | flex-end | center | baseline | stretch;
    /*单独对齐方式：自动（默认） | 顶部对齐 | 底部对齐 | 居中对齐 | 上下对齐并铺满 | 文本基线对齐*/
}

Sección de trucos

1. Personalizar el icono de Apple

Coloca un archivo en el directorio raíz del sitio webapple-touch-icon.pngarchivo, cuando los dispositivos Apple guardan el sitio web como marcador o acceso directo en el escritorio, usarán este archivo como icono. El tamaño recomendado del archivo es: 180px × 180px.

2. Personalizar favicon:

<link rel="icon" href="../favicon.ico" mce_href="../favicon.ico" type="image/x-icon">

3. Definir el comportamiento de clic del navegador:

<a href="020-10086.html">打电话给:020-10086</a>
<a href="10086.html">发短信给: 10086</a>
<a href="me@22278.club.html">发送邮件: me@22278.club</a>

4. Definir el tipo y formato de archivos de carga

<input type=file accept="image/*">

En el cuadro de carga de archivos anterior,acceptse puede restringir el tipo de archivos a cargar, el parámetro esimage/*son todos los tipos de imagen, al hacer clic se abrirá la galería, también se puede especificar el formato de imagen, si el parámetro se establece enimage/pngse puede restringir el tipo de imagen a png; si el parámetro esvideo/*significa seleccionar video;acceptTambién se pueden configurar múltiples formatos de archivo, la sintaxis esaccept="image/gif, image/jpeg" ；

5. Usarbox-shadowCambiar (bloquear) el color amarillo después del autocompletado del formulario

input:-webkit-autofill, textarea:-webkit-autofill, select:-webkit-autofill{
    box-shadow:inset 0 0 0 1000px #fff;
}

6. Usar CSS para truncar texto con puntos suspensivos

white-space: nowrap;
text-overflow: ellipsis;

7. Usar border para dibujar triángulos pequeños

El principio es: la unión de los bordes superior-inferior e izquierdo-derecho forma en realidad un ángulo diagonal. Aprovechando esta característica, haciendo transparente el borde de un lado, poniendo el otro lado del color deseado y ocultando el lado opuesto, se puede convertir en una pequeña forma de flecha.

border-width: 10px 10px 10px 0; //左箭头
border-color: transparent #fff;
border-style: solid;
width: 0;
