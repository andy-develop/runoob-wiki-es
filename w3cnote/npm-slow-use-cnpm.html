Solución al problema de lentitud de NPM en China

Categoría Tecnología de programación

NPM es una herramienta de gestión de paquetes que se instala junto con NodeJS. A menudo la usamos para descargar paquetes de terceros localmente.

Pero en el proceso de uso de NPM, muchos probablemente saben que la velocidad de descarga de paquetes de terceros en China es extremadamente lenta.

Hoy les recomiendo usar el espejo NPM de Taobao. Es un espejo completo de npmjs.org. Puedes usarlo en lugar de la versión oficial (solo lectura). La frecuencia de sincronización actualmente es de 10 minutos para asegurar la sincronización con el servicio oficial tanto como sea posible.

Dirección del espejo NPM de Taobao:https://npm.taobao.org/

Instrucciones de uso

Puedes usar la herramienta de línea de comandos cnpm (con soporte de compresión gzip) personalizada por el espejo NPM de Taobao en lugar del npm predeterminado:

npm install -g cnpm --registry=https://registry.npmmirror.com

Así puedes usar el comando cnpm para instalar módulos:

$ cnpm install [name]

Ejemplo

Instalar el framework de desarrollo Express:

$ cnpm install express
