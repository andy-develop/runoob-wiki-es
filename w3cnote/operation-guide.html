Introducción a operaciones y mantenimiento

Empecemos desde lo más básico

1. Equipos

Orden de los pares de cables de red, cables de red de 100 M y Gigabit, cables de fibra óptica, routers Cisco, routers Huawei, switches, etc., incluida la configuración de VLAN y el aprendizaje entre switches y routers. Generalmente sugiero que con estudiar hasta CCNP es suficiente. En cuanto al conocimiento de hardware de computadoras, si has armado tu propia PC, normalmente lo tienes claro. Entiende la diferencia entre servidores y PC normales; los servidores son 1U, 2U, 4U. Luego está buscar servidores gestionados para alojarlos en centros de datos; el costo depende de la cantidad de líneas del centro de datos, el ancho de banda y la región. Registrar un dominio y también es mejor entender el trámite de registro (ICP/Beian).

2. Capa de enlace de datos

Se trata del flujo de direcciones MAC, el aprendizaje de los switches y las redes de área local.

3. Capa de red

Conocer las desventajas de la interconexión entre los principales ISP de Internet en China: Telecom, Mobile, Unicom y la red educativa. Dominar las herramientas de captura de paquetes tcpdump y Wireshark, el protocolo TCP/IP y, por supuesto, también hay muchos protocolos de routers.

4. Capa de caché

Conocer varios fabricantes famosos de CDN en China.

Varios software de caché de código abierto

  • 1.squid
  • 2.varnish
  • 3.Traffic Server

5. Capa de sistema

Primero están los tres grandes sistemas: Linux, Unix y Windows. En el mercado generalmente se usan estos tres como sistemas de servidor. Linux es el principal en el Internet actual, por lo que normalmente se centra el aprendizaje en él. Windows es Windows 2008 R2; Unix es AIX y FreeBSD. No hay discriminación de plataformas aquí, porque el control de dominio de Windows también es muy potente, pero debido a los problemas de derechos de autor de Windows y su alto costo, la mayoría se enfoca en aprender Linux, e Internet también se inclina hacia esto. AIX y FreeBSD, si ya aprendiste Linux, son parecidos, solo con algunas diferencias. Los interesados pueden estudiar la historia entre Linux y Unix.

6. Capa de base de datos

En cuanto a bases de datos, personalmente suelo preferir MySQL, aunque también he tenido algo de contacto con Oracle. Si dominas bien una, las demás no serán difíciles. ¿Por qué elegir MySQL? Porque se puede usar directamente en aplicaciones y al profundizar se puede entender el código fuente. También existe la base de datos no relacional MongoDB.

7. Capa de contenedores

Tomcat, Nginx, Apache, Redis, IIS. Aquí no hay mucho que decir; cada quien elige varios contenedores según su lenguaje para ejecutar aplicaciones.

    Scripts

    Shell (aquí no tengo muchas sugerencias; yo no compré libros. Se puede ver en línea o comprar libros; pueden elegir libremente en JD o China-Pub)

    Además de Shell, en cuanto a Python y Perl, sugiero que elijas tú mismo. Soy Perler, así que por supuesto te guiaría a elegir Perl.

    Programación eficiente en Perl (2.ª edición) (opcional)

    Perl avanzado (opcional)

    Python

    Tutorial básico de Python (lectura obligatoria)

    Después de entender lo básico, se pueden usar algunos frameworks como Django o Tornado. Si quieres profundizar, por supuesto mira el código fuente. Si sigues con interés y crees que tu nivel de C es bueno, también puedes revisar el código fuente de la máquina virtual de Python.

    Expresiones regulares (principios de las regex, imprescindibles en Linux)

    Ejemplos clásicos de expresiones regulares (opcional)

    Dominar las expresiones regulares (opcional)

    Base de datos

    MySQL de alto rendimiento (lectura obligatoria)

    MySQL de alta disponibilidad (lectura obligatoria)

    Effective MySQL: Respaldo y recuperación (opcional)

    Oracle Database 9i/10g/11g Programming Art: Profundizando en la arquitectura de bases de datos (2.ª edición) (si usas Oracle, échale un vistazo)

    Monitoreo

    Hay muchos tipos de monitoreo; puedes buscar más contenido en Internet, como Cacti, bmon, nload, iftop, vnstat, iptraf, etc.

    Resumen

    CLI (Command line) es la fuente de todo en operaciones y mantenimiento. Debes estar familiarizado con los scripts y poder escribirlos con facilidad. Ten claros los pasos aproximados para la resolución de problemas. Si eres principiante, toma como ejemplo el 'un clic XXX' que ves en Internet y luego mejóralo tú mismo, como inicializar el sistema, configurar SSH, configurar parámetros, etc. Un edificio alto comienza desde el suelo. Aunque los libros anteriores son muchos, aún así es muy necesario leerlos.
