Principales diferencias entre import y from ... import en Python

categoría Técnicas de programación

Python ofrece dos formas comunes de importar módulos:importyfrom ... importEstos dos métodos difieren significativamente en cuanto a uso, gestión del espacio de nombres, legibilidad y problemas potenciales. A continuación se detallan estos aspectos.

1. Forma de uso

import module：

  • Importar todo el módulo.
  • Al usarlo, se debe acceder a los objetos del módulo mediante el nombre del módulo.

Ejemplos

import math

result = math.sqrt(16)
print(result)  # Imprimir 4.0

from module import name：

  • Importa objetos específicos (funciones, clases, variables, etc.) desde un módulo.
  • Al usarlos, se hace referencia directa a los objetos importados, sin necesidad del prefijo del nombre del módulo.

Ejemplos

from math import sqrt

result = sqrt(16)
print(result)  # Imprimir 4.0

2. Gestión de espacios de nombres

import module：

  • Importa el módulo completo como un objeto en el espacio de nombres actual.
  • Los objetos en el módulo a través demodule.nameEl acceso no entra en conflicto con otros objetos del espacio de nombres actual.

from module import name：

  • Importa directamente los objetos del módulo al espacio de nombres actual.
  • Puede provocar conflictos de nombres con otros objetos del espacio de nombres actual.

Ejemplos

from math import sqrt
from cmath import sqrt  # sqrt de números complejos

result = sqrt(-1)  # La función sqrt que puede resultar confusa de usar
print(result)

3. Legibilidad y mantenibilidad

import module：

  • En el código se sabe claramente qué objetos provienen de qué módulo, porque siempre se usa el prefijo del nombre del módulo.
  • Mejorar la legibilidad y mantenibilidad del código.

Ejemplos

import os

current_directory = os.getcwd()
print(current_directory)  # Imprimir el directorio de trabajo actual

from module import name：

  • En el código se usan directamente los nombres de los objetos, por lo que puede ser difícil saber de qué módulo provienen.
  • Se necesita añadir más comentarios o documentación al código para mantener la claridad.

Ejemplos

from os import getcwd

current_directory = getcwd()
print(current_directory)  # Imprimir el directorio de trabajo actual

4. Importación selectiva y uso de memoria

import module：

  • Importa el módulo completo, por lo que todos los objetos del módulo están disponibles.
  • Adecuado cuando se necesitan usar varios objetos del módulo.

from module import name：

  • Importa solo objetos específicos del módulo, ahorrando memoria.
  • Adecuado cuando solo se necesitan usar unos pocos objetos del módulo.

Ejemplos

# Solo es necesario usar el objeto date de datetime
from datetime import date

today = date.today()
print(today)  # Imprimir la fecha actual

5. Importar todos los objetos

from module import *：

  • Importa todos los objetos del módulo al espacio de nombres actual.
  • Puede causar conflictos de nombres, reducir la legibilidad del código y no se recomienda su uso.

Ejemplos

from math import *

print(sqrt(16))  # Usar directamente la función sqrt

problemas potenciales:

Ejemplos

from math import *
from cmath import *

result = sqrt(-1)  # No está claro qué módulo usa la función sqrt
print(result)

Resumen

  • import module: Adecuado cuando se necesita usar todo el módulo, evita conflictos de nombres y mejora la legibilidad del código.
  • from module import name: Adecuado cuando solo se necesitan algunos objetos del módulo, simplifica el código, pero hay que tener cuidado con los conflictos de nombres.
  • from module import *: Evitar su uso en la medida de lo posible, ya que puede provocar conflictos de nombres y confusión en el código.

Elegir el método de importación adecuado depende del escenario de uso y las necesidades específicas; generalmente se recomienda utilizarlo cuando se necesitan evitar conflictos de nombres y mantener el código claro.importSentencia, utilizada cuando se necesita simplificar el código y usar objetos específicos.from ... importSentencia.
