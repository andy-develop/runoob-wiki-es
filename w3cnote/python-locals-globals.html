Python dos funciones integradas: locals y globals

Categoría Tecnología de programación

Estas dos funciones proporcionan principalmente una forma de acceso basada en diccionarios a las variables locales y globales.

Para entender estas dos funciones, primero comprendamos el concepto de espacio de nombres en Python. Python usa algo llamado espacio de nombres para registrar la trayectoria de las variables. Un espacio de nombres es solo un diccionario: sus claves son los nombres de las variables y los valores del diccionario son los valores de esas variables.

De hecho, los espacios de nombres se pueden acceder como diccionarios de Python.

Cada función tiene su propio espacio de nombres, llamado espacio de nombres local, que registra las variables de la función, incluidos los parámetros de la función y las variables definidas localmente. Cada módulo tiene su propio espacio de nombres, llamado espacio de nombres global, que registra las variables del módulo, incluidas funciones, clases, otros módulos importados, variables y constantes a nivel de módulo. Además, está el espacio de nombres incorporado, al que cualquier módulo puede acceder, y que contiene las funciones y excepciones incorporadas.

Cuando una línea de código necesita usar el valor de la variable x, Python busca la variable en todos los espacios de nombres disponibles, en el siguiente orden:

  • 1. Espacio de nombres local- Se refiere específicamente al método de la función o clase actual. Si la función define una variable local x, Python usará esta variable y detendrá la búsqueda.
  • 2. Espacio de nombres global- Se refiere específicamente al módulo actual. Si el módulo define una variable, función o clase llamada x, Python usará esta variable y luego detendrá la búsqueda.
  • 3. Espacio de nombres incorporado- Es global para cada módulo. Como último intento, Python asumirá que x es una función o variable incorporada.

Si Python no encuentra x en estos espacios de nombres, abandonará la búsqueda y lanzará una excepción NameError, al mismo tiempo que pasaThere is no variable named 'x'un mensaje como este.

Ejemplo de la función de variables locales locals (locals devuelve un diccionario de pares nombre/valor):

Ejemplo

def foo(arg, a):
    x = 1
    y = 'xxxxxx'
    for i in range(10):
        j = 1
        k = i
    print(locals())
#Resultado impreso al llamar a la función
foo(1,2)
#{'k': 9, 'j': 1, 'i': 9, 'y': 'xxxxxx', 'x': 1, 'a': 2, 'arg': 1}

from module importyimport moduleLa diferencia entre ellos. Usando import module, el módulo en sí se importa, pero mantiene su propio espacio de nombres, por eso necesitas usar el nombre del módulo para acceder a sus funciones o atributos (module.function). Sin embargo, usando from module import, en realidad importas las funciones y atributos especificados de otro módulo a tu propio espacio de nombres, por eso puedes acceder a ellos directamente sin necesidad de referenciar el módulo del que provienen.

locals es de solo lectura, globals no lo es.

locals no se puede modificar, globals sí se puede modificar. La razón es:

  • locals()En realidad, no devuelve el espacio de nombres local; devuelve una copia. Por lo tanto, modificarlo modifica la copia, y no tiene ningún efecto sobre los valores de las variables en el espacio de nombres local real.
  • globals() devuelve el espacio de nombres global real, no una copia. Su comportamiento es completamente opuesto al de locals.

Por lo tanto, cualquier cambio en el diccionario devuelto por globals afectará directamente al valor de las variables globales.

Ejemplo

#!/usr/bin/env python    

z = 7 #Definir variable global
def foo(arg):  
    x = 1  
    print( locals() )  
    print('x=',x)
    locals()['x'] = 2 #Se modifica la copia del espacio de nombres local, pero los valores de las variables en el espacio de nombres local real no se ven afectados.
    print( locals() )
    print( "x=",x )
 
foo(3)  
print( globals() )
print( 'z=',z )
globals()["z"] = 8 #globals() devuelve el espacio de nombres global real, se modifica el valor de la variable z
print( globals() )
print( "z=",z )
