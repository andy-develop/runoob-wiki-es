Módulos math y cmath de Python

Categoría Tecnología de programación

El módulo math de Python proporciona muchas funciones de operaciones matemáticas para números de punto flotante.

El módulo cmath de Python contiene algunas funciones para operaciones con números complejos.

Las funciones del módulo cmath son básicamente las mismas que las del módulo math; la diferencia es que el módulo cmath opera con números complejos, mientras que el módulo math opera con operaciones matemáticas.

Para usar las funciones math o cmath, primero debe importar:

import math

Consulte math para ver el contenido del paquete:

Soporte de números complejos en Python y aplicación del módulo cmath

Python proporciona soporte para operaciones con números complejos. La expresión de un número complejo en Python es C==c.real+c.imag*j, el número complejo C se compone de su parte real y su parte imaginaria.

Para números complejos, Python admite operaciones de suma, resta, multiplicación y división, y también proporciona el módulo cmath para admitir otras operaciones complejas. El módulo cmath corresponde al módulo math de Python; math proporciona soporte para números reales. Aquí discutimos principalmente el uso de varias funciones del módulo cmath.

Consulte cmath para ver el contenido del paquete:

>>> import cmath
>>> dir(cmath)
['__doc__', '__file__', '__loader__', '__name__', '__package__', '__spec__', 'acos', 'acosh', 'asin', 'asinh', 'atan', 'atanh', 'cos', 'cosh', 'e', 'exp', 'inf', 'infj', 'isclose', 'isfinite', 'isinf', 'isnan', 'log', 'log10', 'nan', 'nanj', 'phase', 'pi', 'polar', 'rect', 'sin', 'sinh', 'sqrt', 'tan', 'tanh', 'tau']

1. Conversión entre representaciones en coordenadas polares y cartesianas.

C==c.real+c.imag*jEl método de representación de números complejos es la representación cartesiana. Los métodos polar() y rect() del módulo cmath pueden convertir entre representación polar y cartesiana. Ejemplo:

>>> import cmath
>>> Z=1+2j
>>> print cmath.polar(Z)
(2.23606797749979, 1.1071487177940904)
>>> a,b=cmath.polar(Z)
>>> print cmath.rect(a,b)
(1+2j)
>>>

La función polar calcula un número complejo en forma cartesiana de entrada; la salida es una tupla de dos valores: el primero es el módulo de Z, el segundo es el valor de la amplitud. La función rect() calcula el módulo y la amplitud de entrada y devuelve la representación cartesiana.

Si necesita obtener el valor de amplitud de un número complejo por separado, puede llamar a la función cmath.phrase(x), que devuelve el valor de amplitud.

2. Funciones exponenciales y logarítmicas de números complejos

La función exponencial de números complejos es cmath.exp(x), que se utiliza para resolver la expresión e^x.

cmath.log(x[,base])Se utiliza para calcular el logaritmo de x en base Base.

cmath.log10(x)Se utiliza para calcular el logaritmo de x en base 10.

cmath.sqrt(x)Se utiliza para calcular la raíz cuadrada de x.

3. Ecuaciones de funciones trigonométricas de números complejos

Incluye todos los cálculos de funciones trigonométricas.acos(x) asin(x) atan(x) sin(x) cos(x) tan(x)。

4. Comprobación de tipos de parámetros

cmath.isinf(x)Si la parte real o imaginaria de x es infinita, devuelve true.

cmath.isnan(x)Si la parte real o imaginaria de x no es un número, devuelve true.

5. Soporte de constantes

cmat.piValor de punto flotante, que representa el valor de pi.

cmat.eValor de punto flotante, que representa la base de los logaritmos naturales.
