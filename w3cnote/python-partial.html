Función parcial de Python

分类 编程技术

Las funciones parciales de Python son invocadas por el usuario mediante el módulo functools.

aplicación parcial

Cuando una función se ejecuta, debe llamarse con todos los parámetros necesarios. Sin embargo, a veces los parámetros pueden conocerse antes de que la función sea llamada. En este caso, uno o más parámetros de una función pueden estar disponibles de antemano, de modo que la función pueda llamarse con menos parámetros.

La función parcial toma la función objetivo como primer parámetro de la función partial(), y los parámetros de la función original se pasan sucesivamente como parámetros posteriores de partial(), a menos que se utilicen argumentos de palabra clave.

Puede que la descripción verbal no permita entender cómo se usan las funciones parciales, así que pongamos un ejemplo habitual para explicarlo. En este ejemplo, implementamos una función de módulo que, para el entero 100, obtiene el resto de 100 % m para diferentes valores de m.

from functools import partial
 
def mod( n, m ):
  return n % m
 
mod_by_100 = partial( mod, 100 )
 
print mod( 100, 7 )  # 2
print mod_by_100( 7 )  # 2

Como los ejemplos anteriores suelen usar la suma o la multiplicación para explicar, no se puede apreciar la cuestión de la posición de los parámetros en las funciones parciales, lo que fácilmente da la falsa impresión de que el segundo parámetro de partial también es el segundo parámetro de la función original. Por eso, aquí elijo mod para explicarlo.

En el caso de los argumentos de palabra clave, no es necesario ceñirse a la posición ni al número de parámetros de la función original. Veamos a continuación otro ejemplo, que trata de cómo realizar conversiones entre diferentes bases numéricas.

from functools import partial
 
bin2dec = partial( int, base=2 )
print bin2dec( '0b10001' )  # 17
print bin2dec( '10001' )  # 17
 
hex2dec = partial( int, base=16 )
print hex2dec( '0x67' )  # 103
print hex2dec( '67' )  # 103

Estas aplicaciones de las funciones parciales parecen sencillas, pero tienen una gran utilidad: pueden aplicar muy bien el principio DRY y ahorrar costos de programación.

    En cuanto a las funciones parciales, estas pueden potenciar funciones existentes.

    >>> import functools
>>> int2 =functools.partial (int, base=2) # 把 int 的转换设为二进制了，这里 base 是 int 函数表示进制的参数。
>>>int2('1000000')
64

>>>int2('1010101')
85

    Después de restablecerlo, también se pueden pasar otros valores al llamar a la función:

    ​>>> int2('1000000', base=10)  # 这里 base 变成了 10，覆盖了已设的默认值 2。
1000000

    Nótese que, después de crear la nueva función parcial, todavía se puede modificar el valor predeterminado ya establecido, pero se debe indicar claramente que se ha cambiado el valor de base.

    De lo contrario, si se pasa directamente un valor numérico, se producirá un error:

    int2('100', 10)  # 报错，10 前未加 base=，不能分辨这是传给 base 的

    原因如下:

    Al crear una función parcial, en realidad se pueden recibir los tres parámetros: el objeto de función, *args y **kw. Cuando se pasa:

    int2 =functools.partial(int, base=2)  # int 是函数对象，base=2 是 **kw，没有传入 *args 参数

    En realidad se fija el argumento de palabra clave base de la función int(), es decir:

    int2('10010')

    相当于：

    kw = { 'base': 2 }
int('10010', **kw)  # 如果不指明 base=2 而只是传入 2 的话，那么 2 被认为是 *args 的值

    当传入：

    max2 =functools.partial(max, 10)  # 这里的 10 显然就是作为 *args 里的值传入的

    En realidad se añade 10 automáticamente como parte de *args a la lista de parámetros, es decir:

    max2(5,6, 7)  # 原本有 *args 的列表，然后会把 10 再加进去

    相当于：

    args = (10, 5, 6, 7)
max(*args)

    El resultado es 10.
