Python2 y Python3 print sin salto de línea

Categoría Tecnología de programación

Este artículo presenta principalmente cómo lograr el efecto de no salto de línea con print en Python2 y Python3.

Python 3.x

En Python 3.x, podemosprint()agregar en la funciónend=""el parámetro, de esta manera se puede lograr el efecto de no salto de línea.

En Python3, para el parámetro de la función printendel valor predeterminado es"\n", es decir,end="\n", indica salto de línea, al asignar aendun valor vacío, es decir,end="", no habrá salto de línea, por ejemplo:

Ejemplo de Python3.x

print('Esta es una cadena,', end="")
print('La cadena aquí no hará un salto de línea')

Al ejecutar el código anterior, el resultado es:

Esta es una cadena, la cadena aquí no comenzará en una nueva línea

end=""Se pueden establecer algunos símbolos o cadenas especiales:

Ejemplo

print('12345', end=" ")  # Configurar espacios
print('6789')

print('admin', end="@")  # Configurar símbolos
print('example.com')

print('Google ', end="Ejemplo ")  # Establecer cadena
print('Taobao')

Al ejecutar el código anterior, el resultado es:

12345 6789
admin@example.com
Google Ejemplo Taobao

Python 2.x

En Python 2.x, se puede usar la coma,para lograr el efecto de no salto de línea:

Ejemplo de Python2.x

#!/usr/bin/python
# -*- coding: UTF-8 -*-

print "Esta es una cadena,",         # Añadir una coma al final
print "La cadena aquí no hará un salto de línea"

# print con paréntesis
print ("Esta es una cadena,"),        # Añadir una coma al final
print ("La cadena aquí no hará un salto de línea")

Al ejecutar el código anterior, el resultado es:

Esta es una cadena, la cadena aquí no comenzará en una nueva línea  
Esta es una cadena, la cadena aquí no comenzará en una nueva línea

Si hay variables, podemos después de la coma,agregar directamente la variable:

Ejemplo de Python2.x

#!/usr/bin/python
# -*- coding: UTF-8 -*-

x= 2
print "El número es:", x

Al ejecutar el código anterior, el resultado es:

字为： 2

Nota:Este método de salida, al,final habrá un espacio de salida, similar al de Python 3end=" "。

Modo de compatibilidad entre Python2.x y Python3.x

Si la versión de Python2.x desea usar laprintfunción de Python3.x, puede importar el__future__paquete, que desactiva la sentencia print de Python2.x y adopta laprintfunción.

El siguiente código se ejecuta correctamente tanto en Python2.x como en Python3.x:

Ejemplo de Python2.x

#!/usr/bin/python
# -*- coding: UTF-8 -*-

from __future__ import print_function

print('12345', end=" ")  # Configurar espacios
print('6789')

print('admin', end="@")  # Configurar símbolos
print('example.com')

print('Google ', end="Ejemplo ")  # Establecer cadena
print('Taobao')

Nota:Muchas de las funciones de compatibilidad entre Python3.x y Python2.x se pueden__future__importar a través de este paquete.
