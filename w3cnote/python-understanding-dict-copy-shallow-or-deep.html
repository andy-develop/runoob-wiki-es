Análisis de asignación directa, copia superficial y copia profunda en Python

Categoría Técnicas de programación

  • Asignación directa:En realidad es una referencia (alias) al objeto.

  • Copia superficial (copy):Copia el objeto padre, pero no copia los objetos secundarios internos del objeto.

  • Copia profunda (deepcopy):El método deepcopy del módulo copy copia completamente el objeto padre y sus objetos secundarios.

Ejemplo de copia superficial de diccionario

Ejemplo

>>>a = {1: [1,2,3]} >>> b = a.copy() >>> a, b ({1: [1, 2, 3]}, {1: [1, 2, 3]}) >>> a[1].append(4) >>> a, b ({1: [1, 2, 3, 4]}, {1: [1, 2, 3, 4]})

La copia profunda requiere importar el módulo copy:

Ejemplo

>>>import copy >>> c = copy.deepcopy(a) >>> a, c ({1: [1, 2, 3, 4]}, {1: [1, 2, 3, 4]}) >>> a[1].append(5) >>> a, c ({1: [1, 2, 3, 4, 5]}, {1: [1, 2, 3, 4]})

Análisis

1、b = a: Asignación por referencia: a y b apuntan al mismo objeto.

2、b = a.copy():Copia superficial: a y b son objetos independientes, pero sus objetos secundarios siguen apuntando al mismo objeto (es una referencia).

b = copy.deepcopy(a):Copia profunda: a y b copian completamente el objeto padre y sus objetos secundarios; ambos son completamente independientes.

Más ejemplos

Los siguientes ejemplos utilizan copy.copy (copia superficial) y copy.deepcopy (copia profunda) del módulo copy:

Ejemplo

#!/usr/bin/python # -*-coding:utf-8 -*- import copy a = [1, 2, 3, 4, ['a', 'b']] # Objeto original b = a # Asignación, pasar la referencia del objeto c = copy.copy(a) # Copia del objeto, copia superficial d = copy.deepcopy(a) # Copia del objeto, copia profunda a.append(5) # Modificar el objeto a a[4].append('c') # Modificar el objeto de lista ['a', 'b'] dentro del objeto a print( 'a = ', a ) print( 'b = ', b ) print( 'c = ', c ) print( 'd = ', d )

El resultado de ejecutar los ejemplos anteriores es:

('a = ', [1, 2, 3, 4, ['a', 'b', 'c'], 5])
('b = ', [1, 2, 3, 4, ['a', 'b', 'c'], 5])
('c = ', [1, 2, 3, 4, ['a', 'b', 'c']])
('d = ', [1, 2, 3, 4, ['a', 'b']])
