1.6 Quicksort

Categoría Algoritmo

El Quicksort (ordenación rápida) es un algoritmo de ordenación eficiente basado en la idea de divide y vencerás (Divide and Conquer). Su núcleo consiste en elegir un elemento pivote y dividir la lista en dos partes: una con elementos menores que el pivote y otra con elementos mayores que el pivote, y luego ordenar recursivamente ambas partes. La complejidad temporal promedio del Quicksort es O(n log n) y su rendimiento es excelente en aplicaciones prácticas.

El Quicksort es un algoritmo de ordenación desarrollado por Tony Hoare. En promedio, ordenar n elementos requiere O(n log n) comparaciones. En el peor caso requiere O(n²) comparaciones, pero esta situación no es común. De hecho, el Quicksort suele ser claramente más rápido que otros algoritmos O(n log n), porque su bucle interno (inner loop) puede implementarse de manera muy eficiente en la mayoría de las arquitecturas.

El Quicksort utiliza la estrategia de divide y vencerás (Divide and conquer) para dividir una lista en dos sublistas (sub-lists).

El Quicksort es también una aplicación típica del pensamiento de divide y vencerás en algoritmos de ordenación. En esencia, el Quicksort puede considerarse un método recursivo de divide y vencerás basado en la ordenación de burbuja.

El nombre del Quicksort es simple y contundente, porque al escucharlo sabes su propósito: es rápido y eficiente. Es uno de los algoritmos de ordenación más rápidos para manejar grandes volúmenes de datos. Aunque la complejidad temporal en el peor caso (Worst Case) alcanza O(n²), es excelente de todos modos; en la mayoría de los casos supera a los algoritmos con complejidad temporal promedio O(n log n). ¿Por qué? El peor caso de ejecución del Quicksort es O(n²), por ejemplo, en una secuencia ya ordenada. Pero su tiempo esperado amortizado es O(n log n), y el factor constante implícito en la notación O(n log n) es muy pequeño, mucho menor que el de la ordenación por fusión (merge sort), cuya complejidad es establemente O(n log n). Por lo tanto, para la gran mayoría de secuencias aleatorias con poca estructura de orden, el Quicksort siempre es superior a la ordenación por fusión.

1. Pasos del algoritmo

  1. Elegir el elemento pivote: Elija un elemento de la lista como pivote. Puede ser el primer elemento, el último, el del medio o un elemento aleatorio.

  2. Partición: Reordene la lista de modo que todos los elementos menores que el pivote queden a la izquierda y todos los mayores queden a la derecha. La posición del pivote queda determinada después de la partición.

  3. Ordenación recursiva: Aplique el Quicksort recursivamente a las sublistas izquierda y derecha del pivote.

  4. Combinación: Como la partición se realiza in situ, al finalizar la recursión toda la lista queda ordenada.

2. Demostración animada

Supongamos que hay una lista por ordenar[3, 6, 8, 10, 1, 2, 1], se elige el último elemento como pivote. El proceso de ordenación es el siguiente:

  1. Estado inicial：

    • Lista:[3, 6, 8, 10, 1, 2, 1]。

    • Elemento pivote:1(el último elemento).

  2. Primera partición：

    • Coloque los elementos menores que el pivote a la izquierda y los mayores a la derecha.

    • Lista después de la partición:[1, 1, 2, 10, 6, 8, 3]。

    • El elemento pivote1queda en su posición definitiva.

  3. Ordenación recursiva：

    • Para la sublista izquierda[1]y la sublista derecha[2, 10, 6, 8, 3]aplique el Quicksort respectivamente.

    • La sublista izquierda ya está ordenada.

    • Para la sublista derecha[2, 10, 6, 8, 3]elija el elemento pivote3(el último elemento):

      • Lista después de la partición:[2, 3, 6, 8, 10]。

      • El elemento pivote3queda en su posición definitiva.

    • Continúe ordenando recursivamente la sublista derecha[6, 8, 10]：

      • elija el elemento pivote10(el último elemento):

        • Lista después de la partición:[6, 8, 10]。

        • El elemento pivote10queda en su posición definitiva.

      • Continúe ordenando recursivamente la sublista izquierda[6, 8]：

        • elija el elemento pivote8(el último elemento):

          • Lista después de la partición:[6, 8]。

          • El elemento pivote8queda en su posición definitiva.

        • Continúe ordenando recursivamente la sublista izquierda[6], ya está ordenada.

  4. Resultado final：

    • La lista queda completamente ordenada:[1, 1, 2, 3, 6, 8, 10]。

Ejemplo

def quick_sort(arr):
    if len(arr) <= 1:
        return arr

    # Elegir el elemento pivote (aquí se elige el último elemento)
    pivot = arr[-1]
    # Partición: colocar los elementos menores que el pivote a la izquierda y los mayores a la derecha
    left = [x for x in arr[:-1] if x <= pivot]
    right = [x for x in arr[:-1] if x > pivot]
    # Ordenar recursivamente y combinar
    return quick_sort(left) + [pivot] + quick_sort(right)

# Ejemplo
arr = [3, 6, 8, 10, 1, 2, 1]
sorted_arr = quick_sort(arr)
print(sorted_arr)  # Salida: [1, 1, 2, 3, 6, 8, 10]

Complejidad temporal

  • División: Cada vez se divide la lista por la mitad, lo que requiere O(log n) niveles de recursión.

  • Combinación: Cada nivel de recursión necesita O(n) tiempo para combinar las sublistas.

  • Complejidad temporal total：O(n log n)。

Complejidad espacial

  • O(n); la ordenación por fusión necesita espacio adicional para almacenar listas temporales.

Ventajas y desventajas

  • Ventajas：

    • La complejidad temporal promedio es O(n log n), muy eficiente en la mayoría de los casos.

    • Es un algoritmo de ordenación in situ (in-place); solo necesita O(log n) de espacio adicional (pila de recursión).

    • Adecuado para ordenar grandes volúmenes de datos en memoria; se usa a menudo en funciones de ordenación genéricas (como std::sort).

  • Desventajas：

    • Ordenación inestable: el orden relativo de elementos iguales puede cambiar.

    • La complejidad temporal en el peor caso es O(n²) (por ejemplo, cuando el arreglo ya está casi ordenado), pero se puede optimizar mediante aleatorización o la técnica de la mediana de tres.

    • El rendimiento es deficiente en datos a pequeña escala; no es tan bueno como algoritmos simples como la ordenación por inserción.

Escenarios de aplicación

  • Ordenación de conjuntos de datos a gran escala.

  • Escenarios que requieren un algoritmo de ordenación estable.

  • Ordenación externa (por ejemplo, ordenar archivos en disco).

function quickSort(arr, left, right) {
    var len = arr.length,
        partitionIndex,
        left = typeof left != 'number' ? 0 : left,
        right = typeof right != 'number' ? len - 1 : right;

    if (left < right) {
        partitionIndex = partition(arr, left, right);
        quickSort(arr, left, partitionIndex-1);
        quickSort(arr, partitionIndex+1, right);
    }
    return arr;
}

function partition(arr, left ,right) {     // Operación de partición
    var pivot = left,                      // Establecer el valor pivote
        index = pivot + 1;
    for (var i = index; i <= right; i++) {
        if (arr[i] < arr[pivot]) {
            swap(arr, i, index);
            index++;
        }        
    }
    swap(arr, pivot, index - 1);
    return index-1;
}

function swap(arr, i, j) {
    var temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}
function partition2(arr, low, high) {
  let pivot = arr[low];
  while (low < high) {
    while (low < high && arr[high] > pivot) {
      --high;
    }
    arr[low] = arr[high];
    while (low < high && arr[low] <= pivot) {
      ++low;
    }
    arr[high] = arr[low];
  }
  arr[low] = pivot;
  return low;
}

function quickSort2(arr, low, high) {
  if (low < high) {
    let pivot = partition2(arr, low, high);
    quickSort2(arr, low, pivot - 1);
    quickSort2(arr, pivot + 1, high);
  }
  return arr;
}

def quickSort(arr, left=None, right=None):
    left = 0 if not isinstance(left,(int, float)) else left

def partition(arr, left, right):
    pivot = left
    index = pivot+1
    i = index
    while  i <= right:
        if arr[i] < arr[pivot]:
            swap(arr, i, index)
            index+=1
        i+=1
    swap(arr,pivot,index-1)
    return index-1

def swap(arr, i, j):
    arr[i], arr[j] = arr[j], arr[i]

func partition(arr []int, left, right int) int {
        pivot := left
        index := pivot + 1

        for i := index; i <= right; i++ {
                if arr[i] < arr[pivot] {
                        swap(arr, i, index)
                        index += 1
                }
        }
        swap(arr, pivot, index-1)
        return index - 1
}

Ejemplo

public class QuickSort implements IArraySort {

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        // Copiar arr, no modifica el contenido del parámetro
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        return quickSort(arr, 0, arr.length - 1);
    }

    private int[] quickSort(int[] arr, int left, int right) {
        if (left < right) {
            int partitionIndex = partition(arr, left, right);
            quickSort(arr, left, partitionIndex - 1);
            quickSort(arr, partitionIndex + 1, right);
        }
        return arr;
    }

    private int partition(int[] arr, int left, int right) {
        // Establecer el valor pivote
        int pivot = left;
        int index = pivot + 1;
        for (int i = index; i <= right; i++) {
            if (arr[i] < arr[pivot]) {
                swap(arr, i, index);
                index++;
            }
        }
        swap(arr, pivot, index - 1);
        return index - 1;
    }

    private void swap(int[] arr, int i, int j) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }

}

typedef struct _Range {

} Range;

Range new_Range(int s, int e) {

    return r;
}

void swap(int *x, int *y) {
    int t = *x;
    *x = *y;
    *y = t;
}

void quick_sort(int arr[], const int len) {
    if (len <= 0)
        return; // Evitar que len sea negativo y cause un error de segmentación (Segment Fault)
    // r[] simula la lista; p es la cantidad; r[p++] es push; r[--p] es pop y obtiene el elemento
    Range r[len];
    int p = 0;
    r[p++] = new_Range(0, len - 1);
    while (p) {
        Range range = r[--p];
        if (range.start >= range.end)
            continue;
        int mid = arr[(range.start + range.end) / 2]; // Elegir el punto medio como pivote
        int left = range.start, right = range.end;
        do {
            while (arr[left] < mid) ++left;   // Comprobar si el lado izquierdo del pivote cumple el requisito
            while (arr[right] > mid) --right; // Comprobar si el lado derecho del pivote cumple el requisito
            if (left <= right) {
                swap(&arr[left], &arr[right]);
                left++;
                right--;               // Mover el puntero para continuar
            }
        } while (left <= right);
        if (range.start < right) r[p++] = new_Range(range.start, right);
        if (range.end > left) r[p++] = new_Range(left, range.end);
    }
}

void swap(int *x, int *y) {
    int t = *x;

void quick_sort_recursive(int arr[], int start, int end) {
    if (start >= end)
        return;
    int mid = arr[end];
    int left = start, right = end - 1;
    while (left < right) {
        while (arr[left] < mid && left < right)
            left++;
        while (arr[right] >= mid && left < right)
            right--;
        swap(&arr[left], &arr[right]);
    }
    if (arr[left] >= arr[end])
        swap(&arr[left], &arr[end]);
    else
        left++;
    if (left)
        quick_sort_recursive(arr, start, left - 1);
    quick_sort_recursive(arr, left + 1, end);
}

void quick_sort(int arr[], int len) {
    quick_sort_recursive(arr, 0, len - 1);
}

template <typename T> // Funciona con enteros o números de punto flotante; si se usa una clase (class), se deben definir los operadores "menor que" (<), "mayor que" (>) y "mayor o igual que" (>=)
void quick_sort(T arr[], const int len) {
    if (len <= 0)
        return; // Evitar que el programa se bloquee al declarar una matriz de pila cuando len es negativo
    // r[] simula la pila; p es la cantidad; r[p++] es push; r[--p] es pop y obtiene el elemento
    Range r[len];
    int p = 0;
    r[p++] = Range(0, len - 1);
    while (p) {
        Range range = r[--p];
        if (range.start >= range.end)
            continue;
        T mid = arr[range.end];
        int left = range.start, right = range.end - 1;
        while (left < right) {
            while (arr[left] < mid && left < right) left++;
            while (arr[right] >= mid && left < right) right--;
            std::swap(arr[left], arr[right]);
        }
        if (arr[left] >= arr[range.end])
            std::swap(arr[left], arr[range.end]);
        else
            left++;
        r[p++] = Range(range.start, left - 1);
        r[p++] = Range(left + 1, range.end);
    }
}

template <typename T>
void quick_sort_recursive(T arr[], int start, int end) {
    if (start >= end)
        return;
    T mid = arr[end];
    int left = start, right = end - 1;
    while (left < right) { // Buscar en todo el rango elementos menores o mayores que el valor del pivote, y luego intercambiar el elemento izquierdo con el derecho
        while (arr[left] < mid && left < right) // Intentar encontrar a la izquierda un elemento mayor que el pivote
            left++;
        while (arr[right] >= mid && left < right) // Intentar encontrar a la derecha un elemento menor que el pivote
            right--;
        std::swap(arr[left], arr[right]); // Intercambiar elementos
    }
    if (arr[left] >= arr[end])
        std::swap(arr[left], arr[end]);
    else
        left++;
    quick_sort_recursive(arr, start, left - 1);
    quick_sort_recursive(arr, left + 1, end);
}
template <typename T> // Funciona con enteros o números de punto flotante; si se usa una clase (class), se deben definir los operadores "menor que" (<), "mayor que" (>) y "mayor o igual que" (>=)
void quick_sort(T arr[], int len) {
    quick_sort_recursive(arr, 0, len - 1);
}
