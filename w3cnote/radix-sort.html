1.10 Ordenamiento Radix

Clasificación Algoritmo

El ordenamiento Radix (Radix Sort) es un algoritmo de ordenamiento no comparativo que ordena comparando cada dígito de los elementos (desde el dígito menos significativo hasta el más significativo). La idea central del ordenamiento Radix es dividir los enteros en dígitos según su posición y luego ordenarlos por cada dígito respectivamente. La complejidad temporal del ordenamiento Radix es O(n * k), donde n es la longitud de la lista y k es el número de dígitos del número más grande.

Pasos del algoritmo:

  1. Determinar el número máximo de dígitos: Encuentra el número de dígitos del número más grande en la lista, determinando así el número de rondas de ordenamiento.

  2. Ordenar por dígitos: Comenzando desde el dígito menos significativo, ordena cada dígito sucesivamente (normalmente usando ordenamiento por conteo o ordenamiento por cubos como subalgoritmo de ordenamiento).

  3. Combinar resultados: Después de cada ronda de ordenamiento, actualiza el orden de la lista hasta que todos los dígitos estén ordenados.

1. Ordenamiento Radix vs Ordenamiento por Conteo vs Ordenamiento por Cubos

El ordenamiento Radix tiene dos métodos:

Estos tres algoritmos de ordenamiento utilizan el concepto de cubos, pero difieren claramente en la forma de usarlos:

  • Ordenamiento Radix: asigna los cubos según cada dígito del valor de la clave;
  • Ordenamiento por conteo: cada cubo almacena un único valor de clave;
  • Ordenamiento por cubos: cada cubo almacena un rango de valores;

2. Demostración animada del ordenamiento Radix LSD

Supongamos que hay una lista a ordenar [170, 45, 75, 90, 802, 24, 2, 66]; el proceso del ordenamiento Radix es el siguiente:

  1. Determinar el número máximo de dígitos：

    • El número más grande es802, tiene 3 dígitos, por lo que se necesitan 3 rondas de ordenamiento.

  2. Primera ronda (ordenar por dígito de las unidades)：

    • Usar ordenamiento por conteo para ordenar los dígitos de las unidades:

      • Conteo de dígitos de las unidades:[0, 2, 4, 5, 6, 0, 2, 6]。

      • Lista después del ordenamiento:[170, 90, 802, 2, 24, 45, 75, 66]。

  3. Segunda ronda (ordenar por dígito de las decenas)：

    • Usar ordenamiento por conteo para ordenar los dígitos de las decenas:

      • Conteo de dígitos de las decenas:[7, 9, 0, 0, 2, 4, 7, 6]。

      • Lista después del ordenamiento:[802, 2, 24, 45, 66, 170, 75, 90]。

  4. Tercera ronda (ordenar por dígito de las centenas)：

    • Usar ordenamiento por conteo para ordenar los dígitos de las centenas:

      • Conteo de dígitos de las centenas:[8, 0, 0, 0, 1, 0, 0, 0]。

      • Lista después del ordenamiento:[2, 24, 45, 66, 75, 90, 170, 802]。

  5. Resultado final：

    • La lista queda completamente ordenada:[2, 24, 45, 66, 75, 90, 170, 802]。

Ejemplo

def counting_sort(arr, exp):
    n = len(arr)
    output = [0] * n  # Inicializar el arreglo de salida
    count = [0] * 10  # Inicializar el arreglo de conteo

    # Contar las ocurrencias de cada dígito
    for num in arr:
        index = (num // exp) % 10
        count[index] += 1

    # Acumular el arreglo de conteo para obtener la posición final de cada dígito
    for i in range(1, 10):
        count[i] += count[i - 1]

    # Colocar los elementos en el arreglo de salida
    i = n - 1
    while i >= 0:
        index = (arr[i] // exp) % 10
        output[count[index] - 1] = arr[i]
        count[index] -= 1
        i -= 1

    # Copiar el arreglo de salida al arreglo original
    for i in range(n):
        arr[i] = output[i]

def radix_sort(arr):
    # Encontrar el número de dígitos del número más grande
    max_num = max(arr)
    exp = 1  # Comenzar por el dígito de las unidades
    while max_num // exp > 0:
        counting_sort(arr, exp)  # Aplicar ordenamiento por conteo al dígito actual
        exp *= 10  # Moverse al siguiente dígito
    return arr

# Ejemplo
arr = [170, 45, 75, 90, 802, 24, 2, 66]
sorted_arr = radix_sort(arr)
print(sorted_arr)  # Salida: [2, 24, 45, 66, 75, 90, 170, 802]

Complejidad temporal

  • Cada ronda de ordenamiento: O(n), usando ordenamiento por conteo para ordenar cada dígito.

  • Número total de rondas: k rondas, donde k es el número de dígitos del número más grande.

  • Complejidad temporal total：O(n * k)。

Complejidad espacial

  • O(n + k), se necesita espacio de almacenamiento adicional para el arreglo de conteo y el arreglo de salida.

Ventajas y desventajas

  • Ventajas：

    • La complejidad temporal es O(n * k); cuando k es pequeño, el rendimiento es excelente.

    • Algoritmo de ordenamiento estable (el orden relativo de elementos iguales no cambia).

  • Desventajas：

    • Solo es aplicable a enteros o cadenas de longitud fija.

    • Cuando el número de dígitos k del número más grande es muy grande, el rendimiento disminuye.

Escenarios de aplicación

  • Ordenamiento de enteros con un rango de datos pequeño.

  • Escenarios que requieren un algoritmo de ordenamiento estable.

  • Apto para ordenamiento externo (por ejemplo, ordenar archivos en disco).

//LSD Radix Sort
var counter = [];
function radixSort(arr, maxDigit) {
    var mod = 10;
    var dev = 1;
    for (var i = 0; i < maxDigit; i++, dev *= 10, mod *= 10) {
        for(var j = 0; j < arr.length; j++) {
            var bucket = parseInt((arr[j] % mod) / dev);
            if(counter[bucket]==null) {
                counter[bucket] = [];
            }
            counter[bucket].push(arr[j]);
        }
        var pos = 0;
        for(var j = 0; j < counter.length; j++) {
            var value = null;
            if(counter[j]!=null) {
                while ((value = counter[j].shift()) != null) {
                      arr[pos++] = value;
                }
          }
        }
    }
    return arr;
}

/**
* Ordenamiento Radix
* Para el caso de números negativos, también se puede consultar: https://code.i-harness.com/zh-CN/q/e98fa9
 */
public class RadixSort implements IArraySort {

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        // Copiar arr, sin modificar el contenido del parámetro
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        int maxDigit = getMaxDigit(arr);
        return radixSort(arr, maxDigit);
    }

    /**
* Obtener el número máximo de dígitos
     */
    private int getMaxDigit(int[] arr) {
        int maxValue = getMaxValue(arr);
        return getNumLenght(maxValue);
    }

    private int getMaxValue(int[] arr) {
        int maxValue = arr[0];
        for (int value : arr) {
            if (maxValue < value) {
                maxValue = value;
            }
        }
        return maxValue;
    }

    protected int getNumLenght(long num) {
        if (num == 0) {
            return 1;
        }
        int lenght = 0;
        for (long temp = num; temp != 0; temp /= 10) {
            lenght++;
        }
        return lenght;
    }

    private int[] radixSort(int[] arr, int maxDigit) {
        int mod = 10;
        int dev = 1;

        for (int i = 0; i < maxDigit; i++, dev *= 10, mod *= 10) {
            // Para considerar números negativos, aquí se duplica el número de colas, donde [0-9] corresponde a negativos y [10-19] a positivos (bucket + 10)
            int[][] counter = new int[mod * 2][0];

            for (int j = 0; j < arr.length; j++) {
                int bucket = ((arr[j] % mod) / dev) + mod;
                counter[bucket] = arrayAppend(counter[bucket], arr[j]);
            }

            int pos = 0;
            for (int[] bucket : counter) {
                for (int value : bucket) {
                    arr[pos++] = value;
                }
            }
        }

        return arr;
    }

    /**
* Expansión automática y guardado de datos
     *
     * @param arr
     * @param value
     */
    private int[] arrayAppend(int[] arr, int value) {
        arr = Arrays.copyOf(arr, arr.length + 1);
        arr[arr.length - 1] = value;
        return arr;
    }
}

function radixSort($arr, $maxDigit = null)
{
    if ($maxDigit === null) {
        $maxDigit = max($arr);
    }
    $counter = [];
    for ($i = 0; $i < $maxDigit; $i++) {
        for ($j = 0; $j < count($arr); $j++) {
            preg_match_all('/\d/', (string) $arr[$j], $matches);
            $numArr = $matches[0];
            $lenTmp = count($numArr);
            $bucket = array_key_exists($lenTmp - $i - 1, $numArr)
                ? intval($numArr[$lenTmp - $i - 1])
                : 0;
            if (!array_key_exists($bucket, $counter)) {
                $counter[$bucket] = [];
            }
            $counter[$bucket][] = $arr[$j];
        }
        $pos = 0;
        for ($j = 0; $j < count($counter); $j++) {
            $value = null;
            if ($counter[$j] !== null) {
                while (($value = array_shift($counter[$j])) !== null) {
                    $arr[$pos++] = $value;
                }
          }
        }
    }

    return $arr;
}

void radixsort(int data[], int n) // Ordenamiento Radix
{
    int d = maxbit(data, n);
    int *tmp = new int[n];
    int *count = new int[10]; // Contador
    int i, j, k;
    int radix = 1;
    for(i = 1; i <= d; i++) // Realizar d pasadas de ordenamiento
    {
        for(j = 0; j < 10; j++)
            count[j] = 0; // Vaciar el contador antes de cada asignación
        for(j = 0; j < n; j++)
        {
            k = (data[j] / radix) % 10; // Contar el número de registros en cada cubo
            count[k]++;
        }
        for(j = 1; j < 10; j++)
            count[j] = count[j - 1] + count[j]; // Asignar las posiciones en tmp a cada cubo sucesivamente
        for(j = n - 1; j >= 0; j--) // Recoger secuencialmente los registros de todos los cubos en tmp
        {
            k = (data[j] / radix) % 10;
            tmp[count[k] - 1] = data[j];
            count[k]--;
        }
        for(j = 0; j < n; j++) // Copiar el contenido del arreglo temporal a data
            data[j] = tmp[j];
        radix = radix * 10;
    }
    delete []tmp;
    delete []count;
}

#include<stdio.h>
#define MAX 20
//#define SHOWPASS
#define BASE 10

void print(int *a, int n) {
  int i;
  for (i = 0; i < n; i++) {
    printf("%d\t", a[i]);
  }
}

void radixsort(int *a, int n) {
  int i, b[MAX], m = a[0], exp = 1;

  for (i = 1; i < n; i++) {
    if (a[i] > m) {
      m = a[i];
    }
  }

  while (m / exp > 0) {
    int bucket[BASE] = { 0 };

    for (i = 0; i < n; i++) {
      bucket[(a[i] / exp) % BASE]++;
    }

    for (i = 1; i < BASE; i++) {
      bucket[i] += bucket[i - 1];
    }

    for (i = n - 1; i >= 0; i--) {
      b[--bucket[(a[i] / exp) % BASE]] = a[i];
    }

    for (i = 0; i < n; i++) {
      a[i] = b[i];
    }

    exp *= BASE;

#ifdef SHOWPASS
    printf("\nPASS   : ");
    print(a, n);
#endif
  }
}

-- Obtener el número de dígitos en la tabla
local maxBit = function (tt)
    local weight = 10;      -- Decimal
    local bit = 1;
   
    for k, v in pairs(tt) do
        while v >= weight do
            weight = weight * 10;
            bit = bit + 1;  
        end
    end
    return bit;
end
-- Ordenamiento Radix
local radixSort = function (tt)
    local maxbit = maxBit(tt);

    local bucket = {};
    local temp = {};
    local radix = 1;
    for i = 1, maxbit do
        for j = 1, 10 do
            bucket[j] = 0;      --- Vaciar los cubos
        end
        for k, v in pairs(tt) do
            local remainder = math.floor((v / radix)) % 10 + 1;    
            bucket[remainder] = bucket[remainder] + 1;      -- La cantidad de cada cubo aumenta automáticamente en 1
        end
       
        for j = 2, 10 do
            bucket[j] = bucket[j - 1] + bucket[j];  -- La cantidad de cada cubo = suma de cantidades de cubos anteriores + cantidad propia
        end
        -- Ordenar según la posición del cubo; esto es ordenamiento por cubos, se debe usar orden inverso, porque el método de ordenamiento es de menor a mayor; si se hace en orden, los grandes pueden quedar encima de los pequeños y se vacían.
        for k = #tt, 1, -1 do
            local remainder = math.floor((tt[k] / radix)) % 10 + 1;
            temp[bucket[remainder]] = tt[k];
            bucket[remainder] = bucket[remainder] - 1;
        end
        for k, v in pairs(temp) do
            tt[k] = v;
        end
        radix = radix * 10;
    end
end;
