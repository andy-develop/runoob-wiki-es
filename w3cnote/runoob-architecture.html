Tecnologías utilizadas en Tutorial para novatos

Categoría Tecnología de programación

El diagrama de estructura técnica de Tutorial para novatos se muestra a continuación:

1. Sistema: CentOS

CentOS es una de las distribuciones de Linux, que proviene de Red Hat Enterprise Linux (la versión comercial de Red Hat), compilada a partir del código fuente publicado de acuerdo con las regulaciones de código abierto.

Versión estable más reciente: 7.3

¿Tiene Tutorial para novatos un tutorial? Sí

Dirección del sitio web oficial:https://www.centos.org/

2. Lenguaje de script: PHP

PHP utiliza HHVM para el análisis y la ejecución.

HHVM es una máquina virtual lanzada por Facebook para ejecutar código PHP. Es un compilador JIT (Just-In-Time) de PHP, que tiene las ventajas de generar código rápido y de compilación justo a tiempo.

El rendimiento de HHVM es superior al de la versión PHP 5.x. Después, PHP lanzó la versión 7.x, y solo entonces su rendimiento pudo igualar al de HHVM.

Versión estable más reciente de HHVM: 3.15.0

Versión estable más reciente de PHP: 7.1.0

¿Tiene Tutorial para novatos un tutorial? Sí

Dirección del sitio web oficial de HHVM:http://hhvm.com/

Dirección del sitio web oficial de PHP:http://php.net/

3. Base de datos: MySQL

MySQL es actualmente un producto de Oracle. La edición comunitaria es la única versión gratuita de MySQL, por lo que hay cierta preocupación sobre si seguirá siendo de código abierto en el futuro.

Actualmente, el fundador de MySQL, Michael Widenius, basándose en MySQL, creó el proyecto derivado MariaDB. Wikipedia anunció oficialmente en 2013 que migraría de MySQL a la base de datos MariaDB.

Versión estable más reciente: 5.7.16

¿Tiene Tutorial para novatos un tutorial? Sí

Dirección del sitio web oficial:https://www.mysql.com/

4. Servidor: Tengine

Tengine es un servidor HTTP que Taobao replicó a partir de Nginx, compatible con la configuración de Nginx.

Sobre la base de Nginx, y para las necesidades de los sitios web con gran volumen de visitas, ha añadido muchas funciones y características avanzadas.

Versión estable más reciente: 2.2.0

¿Tiene Tutorial para novatos un tutorial? No

Dirección del sitio web oficial:http://tengine.taobao.org/

5. Sistema de sitio web: WordPress

WordPress es una plataforma basada en PHP y MySQL, libre y de código abierto, actualmente el sistema de blogs y gestión de contenidos más popular de Internet.

Versión estable más reciente: 4.7

¿Tiene Tutorial para novatos un tutorial? No

Dirección del sitio web oficial:https://cn.wordpress.org/

6. Servidor de caché: Redis

Redis es una base de datos de almacenamiento por pares clave-valor, de código abierto, que admite red, basada en memoria y escrita en ANSI C.

Redis es la base de datos de almacenamiento por pares clave-valor más popular.

Versión estable más reciente: 3.2.5

¿Tiene Tutorial para novatos un tutorial? Sí

Dirección del sitio web oficial:https://redis.io/

7. Ejecución de código en línea: Docker

Docker es un motor de contenedores de aplicaciones de código abierto, basado en el lenguaje Go y publicado bajo la licencia Apache 2.0.

Los contenedores utilizan completamente un mecanismo de sandbox y no tienen ninguna interfaz entre sí (similar a las apps de iPhone). Lo más importante es que la sobrecarga de rendimiento de los contenedores es extremadamente baja.

Versión estable más reciente: 1.10.3

¿Tiene Tutorial para novatos un tutorial? Sí

Sitio web oficial de Docker:http://www.docker.com
