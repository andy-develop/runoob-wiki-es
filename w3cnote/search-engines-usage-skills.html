Un repaso a los motores de búsqueda globales y sus trucos de uso

Categoría Tecnología de programación

Los motores de búsqueda son una de las herramientas indispensables en nuestra vida diaria; a través de ellos podemos encontrar en Internet cualquier información que necesitemos.

Actualmente, los motores de búsqueda más famosos y más utilizados del mundo incluyen Google, Baidu, Bing, Yahoo, etc.

Normalmente, además de ingresar palabras clave directamente en los motores de búsqueda, estos también incluyen algunos trucos avanzados. A continuación, usaremos el motor de búsqueda de Google como ejemplo para demostrarlo.

1. Comillas dobles ""

Comillas dobles""Permiten que las palabras clave de búsqueda coincidan con precisión, sin segmentar las palabras clave que ingresamos.

Por ejemplo, si buscamos "python range uso", podemos ver en los resultados que no es lo mismo usar comillas dobles que no usarlas.

Signo de exclusión: -

Si queremos excluir ciertos resultados, podemos agregar delante del término de búsqueda el-símbolo de menos.

Por ejemplo, si buscamos "python -Ejemplo" se devolverán resultados relacionados con "python", pero no incluirá ningún resultado relacionado con "Ejemplo".

Comodín: *

Usar el comodín*puede ayudarle a encontrar palabras incompletas o deformadas.

Por ejemplo, si buscamos "python * manual", se devolverán todos los resultados que tengan "python" y "manual" como palabras clave.

Símbolo de barra vertical: |

Usar el símbolo de barra vertical|permite buscar varias opciones en una misma búsqueda.

Por ejemplo, si buscamos "python | java", podemos ver que los resultados muestran los dos sitios web oficiales.

Buscar en un sitio web específico: site:

Si solo desea buscar en un sitio web específico, agregue delante del término de búsquedasite:y la URL del sitio web.

Por ejemplo, si buscamos "site:example.com java", se devolverán todos los resultados relacionados con "java" en Ejemplo.

Buscar sitios web relacionados: related:

Usarrelated:puede ayudarle a encontrar otros sitios web relacionados con un sitio web específico.

Por ejemplo, si buscamos "related:example.com", se devolverán todos los sitios web relacionados con Ejemplo.

Uso de paréntesis: ()

Usar paréntesis puede ayudarle a organizar mejor la búsqueda.

Por ejemplo, si buscamos "(python OR java) site:example.com", se devolverán todos los resultados relacionados con "python" o "java" en EJEMPLO.

Rango de búsqueda: ..

Usar dos puntos (..)..permite buscar un rango.

Por ejemplo, si buscamos"mejores películas de ciencia ficción 2000..2010"se devolverán los resultados de todas las películas de ciencia ficción estrenadas entre 2000 y 2010.

Además, hay otros trucos de búsqueda avanzada:

  • Símbolo de definición: define: Usar "define:" permite obtener rápidamente la definición de una palabra. Por ejemplo, buscar "define:inteligencia artificial" devolverá la definición de inteligencia artificial.

  • Rango de tiempo: daterange: Usar "daterange:" permite buscar contenido dentro de un rango de tiempo específico. Por ejemplo, buscar "maratón daterange:2011-01-01..2022-01-01" devolverá resultados relacionados con carreras de maratón entre 2011 y 2022.

  • Tipo de archivo: filetype: Usar "filetype:" permite buscar archivos de un tipo específico. Por ejemplo, buscar "manual de python filetype:pdf" devolverá todos los archivos relacionados con manuales de python almacenados en formato pdf.

  • Buscar palabras clave en el título: intitle:index.of Usar "intitle:index.of" permite buscar todas las páginas cuya etiqueta title contenga una palabra clave determinada. Por ejemplo, buscar "intitle:index.of mp3" devolverá una lista de directorios que contiene archivos mp3.

  • Buscar enlaces: link: Usar "link:" permite buscar todas las páginas web que enlazan a un sitio web específico. Por ejemplo, buscar "link:example.com" devolverá todos los enlaces de páginas web relacionados con EJEMPLO.

  • Buscar acrónimos: acronym: Usar "acronym:" permite buscar la definición de un acrónimo. Por ejemplo, buscar "acronym:AI" devolverá las definiciones relacionadas con inteligencia artificial.
