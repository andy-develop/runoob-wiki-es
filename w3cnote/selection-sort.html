1.2 Ordenamiento por selección

Categoría Algoritmo

El ordenamiento por selección (Selection Sort) es un algoritmo de ordenamiento simple e intuitivo. Sin importar los datos de entrada, su complejidad temporal es O(n²). Por lo tanto, cuanto menor sea la escala de datos, mejor. La única ventaja quizás sea que no ocupa espacio de memoria adicional.

La idea básica del ordenamiento por selección es seleccionar cada vez el elemento más pequeño (o más grande) de los datos a ordenar y colocarlo al final de la secuencia ya ordenada, hasta que todos los datos queden ordenados.

1. Pasos del algoritmo

  1. Inicialización: dividir la lista en una parte ordenada y una parte no ordenada. Inicialmente, la parte ordenada está vacía y la parte no ordenada es toda la lista.

  2. Buscar el valor mínimo: buscar el elemento más pequeño en la parte no ordenada.

  3. Intercambiar posiciones: intercambiar el elemento más pequeño encontrado con el primer elemento de la parte no ordenada.

  4. Actualizar el rango: mover la posición inicial de la parte no ordenada un lugar hacia atrás para ampliar el rango de la parte ordenada.

  5. Repetir los pasos: repetir los pasos anteriores hasta que la parte no ordenada esté vacía y la lista quede completamente ordenada.

2. Demostración animada

Supongamos que hay una lista a ordenar [64, 25, 12, 22, 11]; el proceso del ordenamiento por selección es el siguiente:

  1. Primera ronda：

    • Parte no ordenada:[64, 25, 12, 22, 11]。

    • Encontrar el valor mínimo11, intercambiarlo con el primer elemento64.

    • La lista se convierte en[11, 25, 12, 22, 64]。

    • Parte ordenada:[11], parte no ordenada:[25, 12, 22, 64]。

  2. Segunda ronda：

    • Parte no ordenada:[25, 12, 22, 64]。

    • Encontrar el valor mínimo12, intercambiarlo con el primer elemento25.

    • La lista se convierte en[11, 12, 25, 22, 64]。

    • Parte ordenada:[11, 12], parte no ordenada:[25, 22, 64]。

  3. Tercera ronda：

    • Parte no ordenada:[25, 22, 64]。

    • Encontrar el valor mínimo22, intercambiarlo con el primer elemento25.

    • La lista se convierte en[11, 12, 22, 25, 64]。

    • Parte ordenada:[11, 12, 22], parte no ordenada:[25, 64]。

  4. Cuarta ronda：

    • Parte no ordenada:[25, 64]。

    • Encontrar el valor mínimo25, ya está en la posición correcta, no es necesario intercambiar.

    • La lista permanece igual:[11, 12, 22, 25, 64]。

    • Parte ordenada:[11, 12, 22, 25], parte no ordenada:[64]。

  5. Quinta ronda：

    • Parte no ordenada:[64]。

    • Solo hay un elemento, no se requiere acción.

    • La lista está completamente ordenada:[11, 12, 22, 25, 64]。

Ejemplo

def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        # Supongamos que el primer elemento de la parte no ordenada es el valor mínimo
        min_idx = i
        # Buscar el índice del valor mínimo en la parte no ordenada
        for j in range(i+1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        # Intercambiar el valor mínimo con el primer elemento de la parte no ordenada
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

# Ejemplo
arr = [64, 25, 12, 22, 11]
sorted_arr = selection_sort(arr)
print(sorted_arr)  # Salida: [11, 12, 22, 25, 64]

Complejidad temporal

  • Peor caso: O(n²), sin importar si los datos de entrada están ordenados, se necesitan n(n-1)/2 comparaciones.

  • Mejor caso: O(n²), incluso si la lista ya está ordenada, se requieren la misma cantidad de comparaciones.

  • Caso promedio：O(n²)。

Complejidad espacial

  • O(1), el ordenamiento por selección es un algoritmo de ordenamiento in situ, no requiere espacio de almacenamiento adicional.

Ventajas y desventajas

  • Ventajas：

    • Implementación sencilla, código fácil de entender.

    • Ordenamiento in situ, no requiere espacio de almacenamiento adicional.

    • Para conjuntos de datos de pequeña escala, el rendimiento es aceptable.

  • Desventajas：

    • La complejidad temporal es alta, no es adecuado para conjuntos de datos a gran escala.

    • Algoritmo de ordenamiento inestable (si hay elementos iguales, puede cambiar su orden relativo).

Escenarios de aplicación

  • Escenarios con poca cantidad de datos y sin altos requisitos de rendimiento.

  • Escenarios que requieren una implementación sencilla.

Implementación del código

Implementación en JavaScript

Ejemplo

function selectionSort(arr) {
    var len = arr.length;
    var minIndex, temp;
    for (var i = 0; i < len - 1; i++) {
        minIndex = i;
        for (var j = i + 1; j < len; j++) {
            if (arr[j] < arr[minIndex]) {     // Encontrar el número más pequeño
                minIndex = j;                 // Guardar el índice del número más pequeño
            }
        }
        temp = arr[i];
        arr[i] = arr[minIndex];
        arr[minIndex] = temp;
    }
    return arr;
}

def selectionSort(arr):
    for i in range(len(arr) - 1):
        # Registrar el índice del número mínimo
        minIndex = i
        for j in range(i + 1, len(arr)):
            if arr[j] < arr[minIndex]:
                minIndex = j
        # Si i no es el número mínimo, intercambiar i con el número mínimo
        if i != minIndex:
            arr[i], arr[minIndex] = arr[minIndex], arr[i]
    return arr

Implementación en Java

Ejemplo

public class SelectionSort implements IArraySort {

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        // En total se requieren N-1 rondas de comparación
        for (int i = 0; i < arr.length - 1; i++) {
            int min = i;

            // El número de comparaciones necesarias por ronda es N-i
            for (int j = i + 1; j < arr.length; j++) {
                if (arr[j] < arr[min]) {
                    // Registrar el índice del elemento mínimo encontrado hasta ahora
                    min = j;
                }
            }

            // Intercambiar el valor mínimo encontrado con el valor en la posición i
            if (i != min) {
                int tmp = arr[i];
                arr[i] = arr[min];
                arr[min] = tmp;
            }

        }
        return arr;
    }
}

void selection_sort(int arr[], int len)
{
    int i,j;

        for (i = 0 ; i < len - 1 ; i++)
    {
                int min = i;
                for (j = i + 1; j < len; j++)     // Recorrer los elementos no ordenados
                        if (arr[j] < arr[min])    // Encontrar el valor mínimo actual

Ejemplo

template<typename T> // Acepta enteros o flotantes; para usar objetos (clase), se debe definir el operador mayor que (>)
void selection_sort(std::vector<T>& arr) {
        for (int i = 0; i < arr.size() - 1; i++) {
                int min = i;
                for (int j = i + 1; j < arr.size(); j++)
                        if (arr[j] < arr[min])

}

static void selection_sort<T>(T[] arr) where T : System.IComparable<T>{// Acepta enteros o flotantes
        int i, j, min, len = arr.Length;
        T temp;
        for (i = 0; i < len - 1; i++) {

                for (j = i + 1; j < len; j++)
                        if (arr[min].CompareTo(arr[j]) > 0)

        }
}

Swift

Ejemplo

import Foundation
/// Ordenamiento por selección
///
/// - Parameter list: el array que necesita ser ordenado
func selectionSort(_ list: inout [Int]) -> Void {
    for j in 0..<list.count - 1 {
        var minIndex = j
        for i in j..<list.count {
            if list[minIndex] > list[i] {
                minIndex = i
            }
        }
        list.swapAt(j, minIndex)
    }
}
