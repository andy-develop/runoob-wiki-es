2.1 Sintaxis básica de Verilog

Categoría Tutorial de Verilog

Formato

Verilog distingue entre mayúsculas y minúsculas.

El formato es libre; se puede escribir en una sola línea o en múltiples líneas.

Cada declaración debe terminar con un punto y coma. Los caracteres en blanco (saltos de línea, tabulaciones y espacios) no tienen significado real y pueden ignorarse en la fase de compilación. Por ejemplo, las dos formas de programación siguientes son equivalentes.

Sin salto de línea (no recomendado)

Ejemplo

wire [1:0]  results ;assign results = (a == 1'b0) ? 2'b01 ： (b==1'b0) ? 2'b10 ： 2'b11 ;

Con salto de línea (recomendado)

Ejemplo

wire [1:0]  results ;
assign      results = (a == 1'b0) ? 2'b01 ：
            (b==1'b0) ? 2'b10 ：
                2'b11 ;

Comentarios

Verilog tiene 2 formas de comentarios:

usar//Para comentarios de una sola línea:

reg [3:0] counter ;  // A definition of counter register
usar/*y*/Para comentarios de varias líneas:
wire [11:0]  addr ;
/* 
Next are notes with multiple lines.
Codes here cannot be compiled.
*/
assign   addr = 12'b0 ;

Identificadores y palabras clave

Un identificador puede ser cualquier combinación de letras, números,$símbolos y_símbolos (guion bajo), pero el primer carácter de un identificador debe ser una letra o un guion bajo; no puede comenzar con un número ni con un signo de dólar.

Además, los identificadores distinguen entre mayúsculas y minúsculas.

Las palabras clave son identificadores especiales reservados en Verilog para definir estructuras del lenguaje.

Todas las palabras clave en Verilog están en minúsculas.

Ejemplo

reg [3:0] counter ; //reg es una palabra clave, counter es un identificador
input clk; //input es una palabra clave, clk es un identificador
input CLK; //CLK y clk son 2 identificadores diferentes
