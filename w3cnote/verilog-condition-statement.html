4.5 Declaraciones condicionales de Verilog

Categoría Tutorial de Verilog

Palabras clave: if, selector

Declaraciones condicionales

La declaración condicional (if) se utiliza para controlar si las declaraciones de ejecución se ejecutan según la evaluación de la condición.

La declaración condicional se declara con las palabras clave if y else, y la expresión de condición debe estar entre paréntesis.

La estructura de uso de la declaración condicional se describe a continuación:

if (condition1)       true_statement1 ;
else if (condition2)        true_statement2 ;
else if (condition3)        true_statement3 ;
else                      default_statement ;
  • Cuando se ejecuta la declaración if, si condition1 es verdadera, se ejecuta true_statement1; si condition1 es falsa y condition2 es verdadera, se ejecuta true_statement2; y así sucesivamente.
  • Las estructuras else if y else se pueden omitir, es decir, puede haber solo una condición if y un conjunto de declaraciones de ejecución true_statement1 para formar un proceso de ejecución.
  • Se pueden apilar múltiples else if, no solo limitados a 1 o 2.
  • Las declaraciones de ejecución como true_statement1 pueden ser una sola declaración o varias. Si son varias declaraciones de ejecución, se deben especificar con las palabras clave begin y end.

El siguiente código implementa la función de un multiplexor de 4 vías.

Ejemplo

module mux4to1(
    input [1:0]     sel ,
    input [1:0]     p0 ,
    input [1:0]     p1 ,
    input [1:0]     p2 ,
    input [1:0]     p3 ,
    output [1:0]    sout);

    reg [1:0]     sout_t ;

    always @(*) begin
        if (sel == 2'b00)
            sout_t = p0 ;
        else if (sel == 2'b01)
            sout_t = p1 ;
        else if (sel == 2'b10)
            sout_t = p2 ;
        else
            sout_t = p3 ;
    end
    assign sout = sout_t ;
 
endmodule

El código del testbench es el siguiente:

Ejemplo

`timescale 1ns/1ns

module test ;
    reg [1:0]    sel ;
    wire [1:0]   sout ;

    initial begin
        sel       = 0 ;
        #10 sel   = 3 ;
        #10 sel   = 1 ;
        #10 sel   = 0 ;
        #10 sel   = 2 ;
    end

    mux4to1 u_mux4to1 (
        .sel    (sel),
        .p0     (2'b00),        //path0 are assigned to 0
        .p1     (2'b01),        //path1 are assigned to 1
        .p2     (2'b10),        //path2 are assigned to 2
        .p3     (2'b11),        //path3 are assigned to 3
        .sout   (sout));

   //finish the simulation
    always begin
        #100;
        if ($time >= 1000) $finish ;
    end

 
endmodule

En el ejemplo, la declaración ejecutada por la condición if es solo una cada vez, sin usar las palabras clave begin y end. Pero si es en la forma if-if-else, incluso si la declaración de ejecución es solo una, no usar las palabras clave begin y end puede causar ambigüedad.

Por ejemplo, en el siguiente código, aunque el formato distingue, a qué condición if corresponde else es ambiguo.

Ejemplo

if(en)
    if(sel == 2'b1)
        sout = p1s ;
    else
        sout = p0 ;

Por supuesto, el compilador generalmente sigue el principio de proximidad, haciendo que else se corresponda con el if más cercano (el segundo if en el ejemplo).

Pero obviamente esta forma de escribir no es estándar ni segura.

Por lo tanto, agregar las palabras clave begin y end en las declaraciones condicionales es un buen hábito.

Por ejemplo, si se modifica ligeramente el código anterior, ya no habrá ambigüedad en la escritura.

Ejemplo

if(en) begin
    if(sel == 2'b1) begin
        sout = p1s ;
    end
    else begin
        sout = p0 ;
    end
end
