2.3 Tipos de datos Verilog

Clasificación Tutorial de Verilog

Los 2 tipos de datos más utilizados en Verilog son las redes (wire) y los registros (reg); los demás tipos pueden entenderse como extensiones o ayudas de estos dos tipos de datos.

[3:0] = 4'hF; por lo tanto se puede omitir el ancho;

El tipo wire representa conexiones físicas entre unidades de hardware, conducidas continuamente por las salidas de los dispositivos conectados. Si no hay ningún elemento de conducción conectado a la variable wire, el valor por defecto suele ser "Z". Por ejemplo:

Ejemplo

wire   interrupt ;
wire   flag1, flag2 ;
wire   gnd = 1'b0 ;  

El tipo red también tiene otros tipos de datos, incluyendo wand, wor, wri, triand, trior, trireg, etc. Estos tipos de datos no se utilizan con mucha frecuencia, por lo que no se presentan aquí.

Registros (reg)

El registro (reg) se utiliza para representar celdas de almacenamiento; mantiene el valor original de los datos hasta que se sobrescribe. Ejemplo de declaración:

Ejemplo

reg    clk_temp;
reg    flag1, flag2 ;

Por ejemplo, en un bloque always, un registro puede sintetizarse como un flip-flop de flanco; en lógica combinacional puede sintetizarse como una variable tipo wire. El registro no necesita fuente de conducción ni necesariamente una señal de reloj. Durante la simulación, el valor de un registro puede modificarse mediante operaciones de asignación en cualquier momento. Por ejemplo:

Ejemplo

reg rstn ;
initial begin
    rstn = 1'b0 ;
    #100 ;
    rstn = 1'b1 ;
end

Vectores

Cuando el ancho de bits es mayor que 1, wire o reg pueden declararse en forma de vector. Por ejemplo:

Ejemplo

reg [3:0]      counter ;    // Declara el registro counter de 4 bits de ancho
wire [32-1:0]  gpio_data;   // Declara la variable de red gpio_data de 32 bits de ancho
wire [8:2]     addr ;       // Declara la variable de red addr de 7 bits de ancho, con rango de bits 8:2
reg [0:31]     data ;       // Declara la variable de registro data de 32 bits de ancho, con bit más significativo en 0

Para los vectores anteriores, podemos especificar un bit o varios bits adyacentes para usarlos en otra lógica. Por ejemplo:

Ejemplo

wire [9:0]     data_low = data[0:9] ;
addr_temp[3:2] = addr[8:7] + 1'b1 ;

Verilog admite selección variable de rango de vectores, por ejemplo:

Ejemplo

reg [31:0]     data1 ;
reg [7:0]      byte1 [3:0];
integer j ;
always@* begin
    for (j=0; j<=3;j=j+1) begin
        byte1[j] = data1[(j+1)*8-1 : j*8];
        // Asigna secuencialmente data1[7:0]…data1[31:24] a byte1
    end
end

Verilog también admite acceso a un rango de vector con ancho fijo después de especificar el bit inicial.

  • [bit+: width]: Incrementa desde el bit inicial, con ancho de width.
  • [bit-: width]: Decrementa desde el bit inicial, con ancho de width.

Ejemplo

// Las siguientes 2 asignaciones son equivalentes
A = data1[31-: 8] ;
A = data1[31:24] ;

// Las siguientes 2 asignaciones son equivalentes
B = data1[0+ : 8] ;
B = data1[0:7] ;

Al recombinar señales en un nuevo vector, se necesitan llaves. Por ejemplo:

Ejemplo

wire [31:0]    temp1, temp2 ;
assign temp1 = {byte1[0][7:0], data1[31:8]};  // Concatenación de datos
assign temp2 = {32{1'b0}};  // Asigna el valor de 32 bits 0

Variables de registro de enteros, reales y tiempo

Los tipos de datos enteros, reales y de tiempo también pertenecen en realidad al tipo de registro.

Enteros (integer)

El tipo entero se declara con la palabra clave integer. No es necesario especificar el ancho de bits al declararlo; el ancho depende del compilador y normalmente es de 32 bits. Las variables reg son números sin signo, mientras que las variables integer son números con signo. Por ejemplo:

Ejemplo

reg [31:0]      data1 ;
reg [7:0]       byte1 [3:0]; // Variable de arreglo, se presentará más adelante
integer j ;  // Variable entera, utilizada para ayudar a generar circuitos digitales
always@* begin
    for (j=0; j<=3;j=j+1) begin
        byte1[j] = data1[(j+1)*8-1 : j*8];
        // Asigna secuencialmente data1[7:0]…data1[31:24] a byte1
        end
end

En este ejemplo, la señal integer j actúa como señal auxiliar, asignando secuencialmente los datos de data1 al arreglo byte1. Después de la síntesis, la señal j no existe en el circuito real; j solo ayuda a generar el circuito de hardware correspondiente.

Reales (real)

Los reales se declaran con la palabra clave real y pueden representarse en decimal o notación científica. La declaración de un real no puede incluir un rango; su valor por defecto es 0. Si se asigna un real a un entero, solo la parte entera del real se asignará al entero. Por ejemplo:

Ejemplo

real        data1 ;
integer     temp ;
initial begin
    data1 = 2e3 ;
    data1 = 3.75 ;
end
 
initial begin
    temp = data1 ; // El valor de temp es 3
end

Tiempo (time)

Verilog utiliza variables de registro de tiempo especiales de tipo time para guardar el tiempo de simulación. Su ancho suele ser de 64 bits; se obtiene el tiempo de simulación actual llamando a la función de sistema $time. Por ejemplo:

Ejemplo

time       current_time ;
initial begin
       #100 ;
       current_time = $time ; // El valor de current_time es 100
end

Arreglos

En Verilog se permite declarar arreglos de reg, wire, integer, time, real y sus tipos vectoriales.

No hay límite en la dimensión de los arreglos. Los arreglos de redes también pueden usarse para conectar puertos de módulos instanciados. Cada elemento del arreglo puede usarse como escalar o vector, de la misma manera, con la forma:<nombre_del_arreglo>[<índice>]Para arreglos multidimensionales, el usuario debe especificar el índice de cada dimensión. Por ejemplo:

Ejemplo

integer          flag [7:0] ; // Arreglo de 8 enteros
reg  [3:0]       counter [3:0] ; // Arreglo de 4 contadores de 4 bits
wire [7:0]       addr_bus [3:0] ; // Arreglo de 4 variables tipo wire de 8 bits
wire             data_bit[7:0][5:0] ; // Declara un arreglo bidimensional de variables wire de 1 bit
reg [31:0]       data_4d[11:0][3:0][3:0][255:0] ; // Declara un arreglo de variables de datos de 32 bits de 4 dimensiones

A continuación se muestran operaciones de asignación a elementos de arreglos:

Ejemplo

flag [1]   = 32'd0 ; // Asigna al segundo elemento del arreglo flag el valor de 32 bits 0
counter[3] = 4'hF ;  // Asigna al cuarto elemento del arreglo counter el valor hexadecimal de 4 bits F, equivalente a counter
assign addr_bus[0]        = 8'b0 ; // Asigna al primer elemento del arreglo addr_bus el valor 0
assign data_bit[0][1]     = 1'b1;  // Asigna al elemento de la fila 1, columna 2 del arreglo data_bit el valor 1; aquí no se puede omitir el segundo índice de acceso, es decir, assign data_bit
data_4d[0][0][0][0][15:0] = 15'd3 ;  // Asigna al elemento del arreglo data_4d con índice

Aunque el acceso a arreglos y vectores es similar en cierta medida, no se deben confundir vectores y arreglos. Un vector es un elemento único con ancho de bits n; un arreglo está compuesto por múltiples elementos, cada uno con ancho de bits n o 1. Se diferencian en su definición estructural.

Memoria

Una variable de memoria es un arreglo de registros que puede usarse para describir el comportamiento de RAM o ROM. Por ejemplo:

Ejemplo

reg               membit[0:255] ;  // Memoria de 256 posiciones de 1 bit
reg  [7:0]        mem[0:1023] ;    // Memoria de 1 Kbyte, ancho de 8 bits
mem[511] = 8'b0 ;                  // Establece el valor de la celda de memoria 512 (de 8 bits) a 0

Parámetros

Los parámetros se utilizan para representar constantes; se declaran con la palabra clave parameter y solo pueden asignarse una vez. Por ejemplo:

Ejemplo

parameter      data_width = 10'd32 ;
parameter      i=1, j=2, k=3 ;
parameter      mem_size = data_width * 10 ;

Sin embargo, mediante la instanciación se puede cambiar el valor del parámetro en el módulo. Esta parte se presentará más adelante.

Los parámetros locales se declaran con localparam; su función y uso son los mismos que parameter, con la diferencia de que su valor no puede modificarse. Por lo tanto, cuando un parámetro solo se utiliza en el módulo actual, se puede declarar con localparam.

Cadenas

Las cadenas se almacenan en variables de tipo reg; cada carácter ocupa un byte (8 bits). Por lo tanto, el ancho de la variable de registro debe ser lo suficientemente grande para evitar desbordamiento.

Las cadenas no pueden escribirse en varias líneas, es decir, no pueden contener caracteres de retorno de carro. Si el ancho de la variable de registro es mayor que el tamaño de la cadena, se usa 0 para rellenar los bits sobrantes de la izquierda; si el ancho de la variable de registro es menor que el tamaño de la cadena, se truncan los datos sobrantes de la izquierda de la cadena. Por ejemplo, para almacenar la cadena "run.example.com", se necesitan celdas de 14*8 bits:

Ejemplo

reg [0: 14*8-1]       str ;
initial begin
    str = "run.example.com";
end  

Algunos caracteres especiales tienen un significado especial en cadenas mostradas, como el salto de línea, la tabulación, etc. Si se necesitan mostrar estos caracteres especiales en una cadena, se debe añadir el prefijo de carácter de escape\. Por ejemplo, como se muestra en la siguiente tabla:

Carácter de escapeCarácter mostrado
\nSalto de línea
\tTabulación
%%%
\\
\""
\oooDe 1 a 3 caracteres de dígitos octales

En realidad, en el lenguaje SystemVerilog (un lenguaje de programación utilizado principalmente para la simulación de Verilog), ya se puede usar directamente la palabra clave `string` para representar el tipo de variable de cadena, lo que aporta una gran comodidad a la simulación de Verilog. Los interesados pueden aprender un poco de SystemVerilog.
