1.1 Tutorial de Verilog

Categoría Tutorial de Verilog

Verilog HDL (abreviado como Verilog) es un lenguaje de descripción de hardware utilizado para el diseño de sistemas de circuitos digitales. Puede modelar múltiples niveles de abstracción de diseño, como el nivel de algoritmo, el nivel de compuerta y el nivel de interruptor.

Verilog hereda múltiples operadores y estructuras del lenguaje C. En comparación con otro lenguaje de descripción de hardware, VHDL, su sintaxis no es muy estricta, el código es más conciso y es más fácil de aprender.

Verilog no solo define la sintaxis, sino que también define una semántica de simulación clara para las estructuras sintácticas. Por lo tanto, los modelos digitales escritos en Verilog pueden ser verificados utilizando un simulador de Verilog.

¿Quién debería leer este tutorial?

Este tutorial está diseñado principalmente para principiantes de Verilog.

Aquellos que ya tengan cierta base en Verilog también pueden estudiar e intercambiar ideas en las secciones avanzadas y de ejemplos.

Lo que necesitas saber antes de leer este tutorial

Antes de estudiar este tutorial, necesitas conocer cierta información básica sobre circuitos digitales.

Si tieneslenguaje Ccierto conocimiento, será útil para comenzar rápidamente con Verilog.

Primer diseño en Verilog

Contador decimal de 4 bits de ancho:

Ejemplo

module counter10(
        //Definición de puertos
        input                   rstn,   //Pin de reinicio, activo en bajo
        input                   clk,    //Reloj de entrada
        output [3:0]    cnt,    //Salida de conteo
        output                  cout);  //Bit de desbordamiento

        reg [3:0]               cnt_temp ;      //Registro del contador
        always@(posedge clk or negedge rstn) begin
                if(! rstn)begin         //Al reiniciar, la cuenta vuelve a 0
                        cnt_temp        <= 4'b0 ;
                end
                else if (cnt_temp==4'd9) begin  //Al contar 10 ciclos, la cuenta vuelve a 0
                        cnt_temp        <=4'b000;
                end
                else begin                                      //La cuenta se incrementa en 1
                        cnt_temp        <= cnt_temp + 1'b1 ;
                end
        end

        assign  cout = (cnt_temp==4'd9) ;       //Salida del bit de período
        assign  cnt  = cnt_temp ;                       //Salida del contador en tiempo real

endmodule
