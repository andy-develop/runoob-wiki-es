9.2 Diseño sintetizable en Verilog

Clasificación Tutorial Verilog - Nivel avanzado

Verilog se utiliza principalmente para la descripción de circuitos digitales, pero no todas las formas de descripción pueden sintetizarse en circuitos de hardware reales. Por ejemplo, algunas palabras clave utilizadas para la verificación de simulación pertenecen al lenguaje de verificación de simulación y solo pueden usarse durante la simulación; no pueden sintetizarse en circuitos, como las tareas del sistema $display, las declaraciones initial, etc. Por lo tanto, al usar Verilog para diseñar circuitos digitales, se debe prestar atención a la sintetizabilidad del circuito. El testbench puede hacerse como se desee, siempre que se puedan construir las condiciones de estímulo de simulación necesarias.

Recomendaciones para diseño sintetizable

Al realizar diseño digital con Verilog, se deben seguir los siguientes principios: las estructuras sintetizables se pueden usar con confianza; las estructuras no sintetizables se usan en la simulación; las estructuras que algunas herramientas de síntesis soportan y otras no, deben evitarse en la medida de lo posible.

A menos que se trate de diseños especiales, como clkgate, circuitos de conmutación de reloj, etc., no se debe escribir lógica que potencialmente pueda sintetizarse como Latch. Ver detalles enCapítulo "6.5 Verilog evita Latch" del "Tutorial Verilog"。

Al declarar variables, no se debe imitar el formato del lenguaje C para asignar valores iniciales a variables de registro. Durante la simulación, las variables tendrán el valor inicial establecido, pero después de la síntesis, el valor inicial de los registros es indeterminado. Si el valor inicial de la señal afecta la función lógica, el proceso de simulación podría perder la oportunidad de detectar errores lógicos debido a una verificación insuficiente.

Todos los registros internos deben inicializarse mediante un reset para asegurar que cada registro tenga un estado estable cuando el sistema se reinicia. Si no hay terminal de reset, el valor inicial de los registros en el circuito sintetizado no se puede determinar, lo que puede provocar errores de funcionamiento.

La lógica combinacional usa asignaciones bloqueantes; la lógica secuencial usa asignaciones no bloqueantes. La lógica combinacional generalmente se describe con la sentencia de asignación continua assign; los circuitos descritos con always también pueden sintetizarse como lógica combinacional. Por ejemplo, la lógica AND se puede describir de la siguiente manera:

    reg     F ; // Nota: debe ser una variable de tipo reg
    always @（*） begin
        F = A & B ;
    end  

Las señales asignadas en una sentencia always deben declararse como tipo reg. En lógica combinacional, esa variable reg se sintetizará como una red; en lógica secuencial, esa variable reg se sintetizará como un flip-flop.

Una misma variable no puede ser controlada por múltiples relojes (o bloques always), ni puede ser controlada por ambos flancos del reloj. Este tipo de descripción tampoco es sintetizable.

Evite que en el diseño aparezcaXoZvalor, porque las herramientas de síntesis solo pueden reconocer0o1los valores lógicos.
