Google lanza la herramienta Web Starter Kit para ayudar al desarrollo de páginas web multi-pantalla

Categoría Tecnología de programación

Durante mucho tiempo, Google ha puesto a disposición de los desarrolladores una serie de herramientas que la compañía considera que se ajustan a las mejores prácticas del desarrollo web contemporáneo. Hoy, Google va un paso más allá y ha lanzado una plataforma de desarrollo similar a HTML5 Boilerplate, llamada Web Starter Kit, que incluye plantillas y herramientas para ayudar a los desarrolladores a crear y ejecutar rápidamente aplicaciones multi-pantalla.

Google afirma que el rendimiento y el diseño de estas plantillas están optimizados para ayudar a los desarrolladores a crear rápidamente experiencias web para múltiples dispositivos. Esta plataforma sigue las recomendaciones que Google ha dado anteriormente a los desarrolladores y las convierte en código real, permitiendo un desarrollo rápido de aplicaciones con las herramientas necesarias. Cabe señalar que Web Starter Kit asume que ya tienes instalados Node, Ruby, Ruby Sass y Gulp.js en tu sistema. Con el Gulp opcional, los desarrolladores podrán utilizar funciones como LiveReload, optimización automática de imágenes y minificación de HTML.

Además de la última versión de Chrome, Web Starter Kit también es compatible con la mayoría de los otros navegadores contemporáneos, incluyendo IE10, IE11, Firefox 30, Firefox 31, y los navegadores móviles más populares.

Aunque hay cierta superposición con proyectos como Bootstrap y Foundation de ZURB, Google también ayuda a los usuarios de Web Starter Kit a utilizar fácilmente los estilos de estos proyectos.

A diferencia de estos proyectos, Google no proporciona muchos elementos de interfaz de usuario y otros componentes. Por el momento no está claro si Google planea añadir estos elementos más adelante, pero el ingeniero de Google Addy Osmani dijo hoy a Hacker News que el propósito de Web Starter Kit no es competir con Bootstrap en cuanto a elementos de interfaz de usuario. También señaló que bibliotecas como Bootstrap y Foundation son "un buen punto de partida para desarrollar aplicaciones prototipo", pero el mayor desafío al usar estas bibliotecas es que los desarrolladores pueden seguir usando estos estilos, apariencia y experiencia durante todo el ciclo de vida de la aplicación. A diferencia de estos proyectos, Web Starter Kit anima a los desarrolladores a modificar los estilos base para adaptarlos a sus propias aplicaciones.

Similar a Bootstrap y Foundation, Web Starter Kit se centra en la cuadrícula fluida, aunque la solución de Google es más flexible.

Este proyecto de Google todavía se encuentra en pruebas. Es algo sorprendente que Google haya lanzado esta herramienta una semana antes de la conferencia de desarrolladores I/O. Sin embargo, Google quizás quiera dar a los desarrolladores cierto tiempo para familiarizarse con la herramienta y luego celebrar un taller específico sobre ella en la conferencia. (Trad.: Weijin)
