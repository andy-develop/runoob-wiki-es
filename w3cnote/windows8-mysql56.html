2. Instalación

1. Haga doble clic en el archivo de instalación descargado. La versión de MySQL instalada en este artículo es 5.6.10.1. Aparece la página como se muestra en la figura:

2. Haga clic en "Install MySQL Products" para ingresar a la página como se muestra en la figura 1-4:

3. Marque la casilla "I accept the license

terms", haga clic en "Next". Aparece la página de búsqueda de actualizaciones de productos más recientes como se muestra en la figura. Si no le gustan las actualizaciones, puede seleccionar la opción "Skip the check for updates (not recommended)" en la parte inferior y hacer clic en "Next" para continuar:

4. Seleccione el tipo de instalación que se adapte a sus necesidades según la descripción del tipo de instalación en el lado derecho, como se muestra en la figura. Preste atención para modificar la ruta de instalación, para evitar tener que instalar MySQL nuevamente después de reinstalar el sistema:

5. Según el tipo de instalación que haya elegido, será necesario instalar algunos frameworks. Haga clic en "Execute" para instalar los frameworks necesarios, como se muestra en la figura:

6. Página durante el proceso de instalación de los frameworks, como se muestra en la figura:

7. Aviso después de la instalación exitosa de los frameworks, como se muestra en la figura:

8. Después de que todos los frameworks necesarios se hayan instalado correctamente, como se muestra en la figura, haga clic en "Next":

9. Comience la instalación, como se muestra en la figura 1-11, haga clic en "Execute". La interfaz durante el proceso de instalación se muestra en la figura:

10. Confirmación de la información de configuración, como se muestra en la figura, haga clic en "Next":

11. Selección del tipo de configuración del servidor, Developer

Machine: el servidor MySQL instalado forma parte de una máquina de desarrollo; entre los tres tipos de opciones, ocupa la menor cantidad de memoria. Server Machine: el servidor MySQL instalado forma parte de una máquina servidor; el uso de memoria se encuentra en el punto medio entre los tres tipos. Dedicated MySQL Server Machine: instala un servidor de base de datos MySQL dedicado, que ocupa toda la memoria efectiva de la máquina. No es necesario modificar nada; el puerto predeterminado 3306 y otros valores también pueden dejarse sin cambios. Haga clic en "Next":

12. Configure la contraseña del administrador, como se muestra en la figura. Seleccione "Add User"; también puede crear usuarios, pero desde el punto de vista de la seguridad, es mejor no crear usuarios:

13. En la interfaz que se muestra en la figura, puede establecer el nombre del servicio del sistema y si se debe iniciar automáticamente el servidor de base de datos MySQL al mismo tiempo que se inicia el sistema. Puede usar las opciones predeterminadas. Haga clic en "Next":

14. Confirme que la instalación ha finalizado. Marque "Start MySQL Workbench after Setup" para probar si la instalación fue exitosa. Haga clic en "Finish":
