1. API nativa del cliente de Zookeeper

Usando la API nativa de Zookeeper, conéctese al clúster compuesto por tres servicios construido en el tutorial anterior. Como la conexión requiere tiempo, use CountDownLatch para bloquear y esperar a que la conexión sea exitosa. ¡La consola muestra el estado de la conexión!

Ejemplo

...public static void main(String[] args) { try { final CountDownLatch countDownLatch=new CountDownLatch(1); ZooKeeper zooKeeper= new ZooKeeper("192.168.3.33:2181," + "192.168.3.35:2181,192.168.3.37:2181", 4000, new Watcher() { @Override public void process(WatchedEvent event) { if(Event.KeeperState.SyncConnected==event.getState()){ //Si se recibe el evento de respuesta del servidor, la conexión es exitosa. countDownLatch.countDown(); } } }); countDownLatch.await(); //CONNECTED System.out.println(zooKeeper.getState()); } } ...

La consola muestra 'connected', indicando que la conexión fue exitosa.

Ejemplo simple de API para agregar nodos:

zooKeeper.create("/runoob","0".getBytes(),ZooDefs.Ids.OPEN_ACL_UNSAFE,CreateMode.PERSISTENT);

Sugerencia:Para más funciones de comandos, consulte los capítulos posteriores de este tutorial.

Al mismo tiempo, ejecute el comando en la terminal del servidor; muestra que la configuración fue exitosa.

2. Conexión del cliente con Curator

Curator es un framework de cliente de Zookeeper de código abierto de Netflix que resuelve muchos trabajos de desarrollo de detalles de bajo nivel del cliente de Zookeeper, incluyendo reconexión, registro repetido de Watchers y excepciones como NodeExistsException.

Curator incluye varios paquetes:

  • curator-framework: Algunas encapsulaciones de la API subyacente de Zookeeper.
  • curator-client: Proporciona algunas operaciones de cliente, como estrategias de reintento, etc.
  • curator-recipes: Encapsula algunas características avanzadas, como: monitoreo de eventos Cache, elección, bloqueos distribuidos, contadores distribuidos, Barreras distribuidas, etc.

Ejemplo de uso simple:

Ejemplo

public class CuratorDemo { public static void main(String[] args) throws Exception { CuratorFramework curatorFramework=CuratorFrameworkFactory. builder().connectString("192.168.3.33:2181," + "192.168.3.35:2181,192.168.3.37:2181"). sessionTimeoutMs(4000).retryPolicy(new ExponentialBackoffRetry(1000,3)). namespace("").build(); curatorFramework.start(); Stat stat=new Stat(); //Consultar datos del nodo byte[] bytes = curatorFramework.getData().storingStatIn(stat).forPath("/runoob"); System.out.println(new String(bytes)); curatorFramework.close(); } }

En el paso anterior se configuró/runoobel valor del nodo, por lo que la consola lo muestra.
