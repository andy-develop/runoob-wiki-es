8.0 Comandos de cuatro letras de Zookeeper

Categorías Tutorial de Zookeeper

Zookeeper admite ciertos comandos de cuatro letras específicos para interactuar con él; los usuarios obtienen el estado actual y la información relacionada del servicio Zookeeper. En el cliente, los usuarios pueden enviar los comandos correspondientes a Zookeeper mediante telnet o nc (netcat).

Instalar el comando nc:

$ yum install nc                # centos
或
$ sudo apt install netcat       # ubuntu

Formato de los comandos de cuatro letras:

echo [command] | nc [ip] [port]

Los comandos de cuatro letras más comunes de ZooKeeper son los siguientes:

Comando de cuatro letrasDescripción de la función
conf Introducido en la versión 3.3.0. Imprime la información detallada de la configuración relacionada con el servicio.
cons Introducido en la versión 3.3.0. Lista todos los detalles de conexión/sesión de los clientes conectados a este servidor. Incluye la cantidad de paquetes "recibidos/enviados", ID de sesión, latencia de operaciones, última operación ejecutada, etc.
crst Introducido en la versión 3.3.0. Restablece todas las estadísticas de conexión y sesión de las conexiones.
dump Lista las sesiones y nodos temporales más importantes. Este comando solo es útil en el nodo líder.
envi Imprime la información detallada del entorno del servicio.
reqs Lista las solicitudes no procesadas.
ruok Prueba si el servicio está en el estado correcto. Si es así, el servicio devuelve "imok"; de lo contrario, no responde en absoluto.
stat Genera una lista de clientes con respecto al rendimiento y las conexiones.
srst Restablece las estadísticas del servidor.
srvr Introducido en la versión 3.3.0. Lista la información detallada de las conexiones al servidor.
wchs Introducido en la versión 3.3.0. Lista la información detallada de los watches del servidor.
wchc Introducido en la versión 3.3.0. Lista la información detallada de los watches del servidor por sesión; su salida es una lista de sesiones relacionadas con watches.
wchp Introducido en la versión 3.3.0. Lista la información detallada de los watches del servidor por ruta. Muestra una ruta relacionada con la sesión.
mntr Introducido en la versión 3.4.0. Genera una lista de variables que se pueden utilizar para detectar el estado de salud del clúster.

Referencia a los enlaces oficiales:https://zookeeper.apache.org/doc/current/zookeeperAdmin.html#sc_4lw

Uso de los comandos de cuatro letras

Comando stat

El comando stat se utiliza para ver la información de estado de zk. Ejemplo:

$ echo stat | nc 192.168.3.38 2181

Comando ruok

El comando ruok se utiliza para comprobar si el servidor zk actual está iniciado; si devuelve imok, significa que es normal. Ejemplo:

$ echo ruok | nc 192.168.3.38 2181

Comando dump

El comando dump se utiliza para listar las sesiones y nodos temporales no procesados. Ejemplo:

$ echo dump | nc 192.168.3.38 2181

Comando conf

El comando conf se utiliza para ver la configuración del servidor. Ejemplo:

$ echo conf | nc 192.168.3.38 2181

Comando cons

El comando cons se utiliza para mostrar la información de los clientes conectados al servidor. Ejemplo:

$ echo cons | nc 192.168.3.38 2181

Comando envi

El comando envi se utiliza para ver las variables de entorno. Ejemplo:

$ echo envi | nc 192.168.3.38 2181
