2.0 Instalación y configuración de Zookeeper

Categoría Tutorial de Zookeeper

Instalación en Linux

La dirección de descarga de zookeeper es:https://zookeeper.apache.org/releases.html。

Seleccione una versión estable. La versión release utilizada en este tutorial es 3.4.14. Descárguela e instálela.

Abra la URLhttps://www.apache.org/dyn/closer.lua/zookeeper/zookeeper-3.4.14/zookeeper-3.4.14.tar.gz, verá la siguiente interfaz:

Elija una dirección de descarga y use el comando wget para descargar e instalar:

Descarga e instalación de Zookeeper

$ wget https://mirror.bit.edu.cn/apache/zookeeper/zookeeper-3.4.14/zookeeper-3.4.14.tar.gz
$ tar -zxvf zookeeper-3.4.14.tar.gz
$ cd zookeeper-3.4.14
$ cd conf/
$ cp zoo_sample.cfg zoo.cfg
$ cd ..
$ cd bin/
$ sh zkServer.sh start

Después de ejecutarlo, el servidor se inicia correctamente:

Ver el estado del servidor (iniciar nodo independiente):

Iniciar el cliente:

$ sh zkCli.sh

Comando de ayuda:

ZooKeeper -server host:port cmd args
        stat path [watch]
        set path data [version]
        ls path [watch]
        delquota [-n|-b] path
        ls2 path [watch]
        setAcl path acl
        setquota -n|-b val path
        history 
        redo cmdno
        printwatches on|off
        delete path [version]
        sync path
        listquota path
        rmr path
        get path [watch]
        create [-s] [-e] path data acl
        addauth scheme auth
        quit 
        getAcl path
        close 
        connect host:port

Instalación en Windows

La dirección de descarga de zookeeper es:https://zookeeper.apache.org/releases.html。

Elija una dirección y haga clic en la versión para descargar:

Descomprimir después de la descarga:

Copie el archivo zoo_sample.cfg en el directorio conf y renómbrelo como zoo.cfg:

Cree una carpeta data vacía y una carpeta log en el directorio de instalación:

Modifique el archivo de configuración zoo.cfg: cambie dataDir=/tmp/zookeeper a la carpeta data del directorio de instalación de zookeeper y agregue una configuración de registro de datos (debe modificarla según su propia ruta de instalación).

Haga doble clic en zkServer.cmd para iniciar el programa:

La consola muestrabind to port 0.0.0.0/0.0.0.0:2181, lo que indica que el servidor se inició correctamente.

Haga doble clic en zkCli.cmd para iniciar el cliente

Si aparece "Welcome to Zookeeper!", significa que hemos iniciado el cliente correctamente.
