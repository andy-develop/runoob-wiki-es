XML Reglas de sintaxis

Las reglas de sintaxis de XML son simples y lógicas.

Estas reglas son fáciles de aprender y fáciles de usar.

Declaración XML

La declaración XML es una parte opcional del archivo; si existe, debe colocarse en la primera línea del documento, como se muestra a continuación:

<?xml version="1.0" encoding="utf-8"?>

El ejemplo anterior incluye la versión de XML (version="1.0") e incluso la codificación de caracteres (encoding="utf-8").

UTF-8 también es la codificación predeterminada de HTML5, CSS, JavaScript, PHP y SQL.

Los documentos XML deben tener un elemento raíz

XML debe contener un elemento raíz, que es el elemento padre de todos los demás. Por ejemplo, en el siguiente ejemplo, root es el elemento raíz:

<root> <child> <subchild>.....</subchild> </child> </root>

En el siguiente ejemplo, note es el elemento raíz:

<?xml version="1.0" encoding="UTF-8"?> <note> <to>Tove</to> <from>Jani</from> <heading>Reminder</heading> <body>Don't forget me this weekend!</body> </note>

Un documento XML está formado por elementos; cada elemento incluye una etiqueta de apertura, una etiqueta de cierre y el contenido del elemento.

Atributos

Los elementos pueden contener atributos, que proporcionan información adicional sobre el elemento.

Los atributos se colocan en la etiqueta de apertura, por ejemplo:

<person age="30" gender="male">John Doe</person>

Etiqueta autocerrada XML

Todos los elementos XML generalmente tienen una etiqueta de cierre, pero también se permite el uso de etiquetas autocerradas.

La etiqueta autocerrada se escribe de la siguiente manera:

<elementName attribute="value" />

Una etiqueta autocerrada es aquella que incluye la etiqueta de apertura y cierre en una sola etiqueta, similar a la etiqueta de elemento vacío en HTML.

En XML, puedes representar una etiqueta autocerrada de las siguientes dos maneras:

Usar la etiqueta de elemento vacío:

<exampleTag />

Usar etiquetas de apertura y cierre, pero sin incluir ningún contenido:

<exampleTag></exampleTag>

Estas dos formas son equivalentes; puedes elegir usar una u otra según tus preferencias personales o las convenciones del proyecto.

En muchos analizadores XML, ambas formas se interpretan como la misma estructura.

Ejemplo

<lineBreak />

Aquí<lineBreak />es una etiqueta autocerrada que representa una operación de salto de línea.

Etiqueta autocerrada con atributos:

<image src="logo.png.html" alt="Logo" />

Esta etiqueta representa un elemento de imagen; contiene los atributos src y alt, que indican la ruta de la imagen y el texto alternativo.

Ejemplo de archivo XML:

Ejemplo

<?xml version="1.0" encoding="UTF-8"?>
<root>
    <note to="Tove" from="Jani" heading="Reminder" body="Don't forget me this weekend!" />
    <emptyElement attribute="value" />
</root>

En este ejemplo,<note> 和 <emptyElement />son etiquetas autocerradas.<note>La etiqueta sirve para transmitir información, y<emptyElement />es una etiqueta vacía sin elementos secundarios.

Las etiquetas XML distinguen entre mayúsculas y minúsculas

Las etiquetas XML distinguen entre mayúsculas y minúsculas. La etiqueta <Letter> es diferente de la etiqueta <letter>.

Debes usar las mismas mayúsculas y minúsculas para escribir las etiquetas de apertura y cierre:

<Message>这是错误的</message>
<message>这是正确的</message>

Nota:Las etiquetas de apertura y cierre a menudo se denominan etiquetas de inicio y fin. Independientemente de qué término prefiera, el concepto es el mismo.

El XML debe estar correctamente anidado

En HTML, a menudo se ven elementos que no están correctamente anidados:

<b><i>This text is bold and italic</b></i>

En XML, todos los elementosdebenestar correctamente anidados entre sí:

<b><i>This text is bold and italic</i></b>

En el ejemplo anterior, anidamiento correcto significa: como el elemento <i> se abre dentro del elemento <b>, debe cerrarse dentro del elemento <b>.

Los valores de los atributos XML deben ir entre comillas

De manera similar a HTML, los elementos XML también pueden tener atributos (pares de nombre/valor).

En XML, los valores de los atributos deben ir entre comillas.

Estudie los siguientes dos documentos XML. El primero es incorrecto, el segundo es correcto:

<note date=12/11/2007>
<to>Tove</to>
<from>Jani</from>
</note>

<note date="12/11/2007">
<to>Tove</to>
<from>Jani</from>
</note>

El error en el primer documento es que el atributo date del elemento note no lleva comillas.

Referencias de entidad

En XML, algunos caracteres tienen un significado especial.

Si coloca el carácter "<" en un elemento XML, se producirá un error, porque el analizador lo interpretará como el comienzo de un nuevo elemento.

Esto generará un error XML:

<message>if salary < 1000 then</message>

Para evitar este error, usela referencia de entidadpara reemplazar el carácter "<":

<message>if salary &lt; 1000 then</message>

En XML, hay 5 referencias de entidad predefinidas:

&lt; < less than
&gt; > greater than
&amp; & ampersand
&apos; ' apostrophe
&quot; " quotation mark

Nota:En XML, solo los caracteres "<" y "&" son realmente ilegales. El signo mayor que es legal, pero es una buena práctica reemplazarlo con una referencia de entidad.

Comentarios en XML

La sintaxis para escribir comentarios en XML es muy similar a la de HTML.

<!-- This is a comment -->

En XML, los espacios en blanco se conservan

HTML reduce (combina) varios caracteres de espacio consecutivos en uno solo:

HTML: 
Hello           Tove
Resultado: Hello Tove

En XML, los espacios en el documento no se reducen:

<bookstore>
    <book>
        <title>xx       xxx</title>
        <author>John Doe</author>
        <price>29.99</price>
    </book>
</bookstore>

El contenido de title se muestra de la siguiente manera:

xx       xxx

XML almacena los saltos de línea con LF

En aplicaciones de Windows, los saltos de línea generalmente se almacenan como un par de caracteres: retorno de carro (CR) y avance de línea (LF).

En Unix y Mac OSX, se usa LF para almacenar nuevas líneas.

En los sistemas Mac antiguos, se usa CR para almacenar nuevas líneas.

XML almacena los saltos de línea con LF.
